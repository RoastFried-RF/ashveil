# 지도 생성 워커 예제

검은 숲 정비구의 기존 RegionLayout.Blackwood.genWorker 참조만 패치한다. 최초 지역 후보를 만들 때 시작점 곁의 비보호 흙/길 한 칸을 진흙으로 바꾼다. 기존 사람·출입구·물품·수로를 옮기거나 만들지 않는다. 이후 지도는 원래 각인을 재사용하므로 재입장 때 호출하지 않는다.

MapGenStepWorker.execute는 읽기 전용 후보의 palette/terrainRows/roofRows/protectedCells를 받는다. 지형 행은 palette 인덱스를 두 자리36진 문자열로 이어 붙인 값이다. 반환은 최대256개의 {type:'setTerrain',x,y,terrain,roof?}이며 원래 앵커/실물/수로·출입 설비와 연결 경로를 보존해야 한다.

모든 변경을 별도 후보에서 검사한 뒤 지도/자기 데이터/하위 난수를 함께 반영한다. 실패하면 원래 후보를 유지하고 메서드만 중단한다. 미리보기는 실제 자기 데이터·난수·물품ID·오류를 쓰지 않으며, 동일한 지역 키로 실제 생성과 같은 지형을 예측한다.

현재 첫 연결은 RegionLayout의 최초 후보이다. 원래 주 지상/일반 던전의 다른 생성 단계, 수로·출입 설비·새 주민·새 물품을 생성하는 명령은 별도 후속 범위이다. [현재 API](../../docs/modding-guide.md).
