# 같은 개체와 종별 기록의 ID 이행 예제

기본 비활성 데이터 예제다. 이전0.9의 OldRat를 현재1.0의 RenamedRat로 이행하되 실제 몸·개체 번호·소지품·이름/관계·인구 수·시각·난수를 보존한다. 현재 공급원/저장된 방 배치와 종별 지식/표본·공포 대상/극복·수확 나머지도 같은 식별로 옮긴다.

몸 종류가 다르거나 현재 지식/공포/나머지 기록이 겹치거나 지원하지 않는 참조가 남으면 원래 정의 복원/개별 병합을 요구한다. 사체나 인물을 새로 만들고 과거 로그/원인을 다시 쓰지 않는다. 실제 현재 상태 검토 뒤에만 승인한다.

예제 자체는 개체를 배치하지 않는다. 자동 검증은 이전0.9 정의를 먼저 실제 로드한 정상 새 게임에 실제 createCreature로 선언된 초기 개체 한 마리를 배치하고 정상 시야/현재 관찰 함수를 호출한다. 과거 출생/전투/경과 턴을 실행한 이력으로 주장하지 않는다. 새 Item은 없다.
