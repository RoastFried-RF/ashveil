# 스크립트 명령 예제

기본으로 선택하지 않는 명령 시연용 모드이다. 실제 날짜 전환 때 한 번만 플레이어 왼쪽 아래팔에 심각도1 베임을 만들고, 발밑 바닥에 붕대1개를 배치하고,3턴 뒤 기존 야영지의 순찰을 예약한다. 원래 순찰 확률만 패치로1로 바꾼다. 사람·새 Def·새 Item 종류는 추가하지 않는다.

이 예제는 명시적으로 작은 부상과 아이템 생성을 요청한다. 예약은 현재 지도 원래 공급원·인원·경로·재사용 대기를 확인하므로 출발 조건이 안 되면 무리를 만들지 않고 끝난다. 원래 인원 ID·물품 UID·예약·자기 상태는 각인으로 보존한다.

[실제 지원 API와 제한](../../docs/modding-guide.md). 스크립트는 파일/네트워크/시간/타이머에 접근하지 못하며 반환 명령을 코어가 목록 전체로 검증한다. 상처의 훅 연쇄는4단계/64명령 안에서 멈춘다.
