# 아이템 소비 워커 예제

기존 육포에 FoodNotebook 참조만 패치한다. 새 사람·Def·아이템을 추가하지 않는다. 실제 섭취가 성공해 원래 수량/회분/물량이 감소한 뒤에만 기록을 추가한다. 실패·빈 물병·얼어 있는 물병·밀봉 개봉 시작에는 콜백을 호출하지 않는다.

ItemCompWorker의 첫 연결은 onConsume이다. 제공자/소비자, 원래 쌓음의 UID/Def, 감소한 수량·회분·물량을 전달한다. 음식 쌓음을 나눠 소비하거나 마지막 회분 뒤 원래 빈 용기를 남기는 것은 기존 코어가 처리한다. 구형 음식의 생략한 회분도 실제 Def 회분 수를 기준으로 확인한다.

콜백의 잘못된 명령/예외/예산 초과는 자기 데이터·하위 난수·추가 명령을 반영하지 않는다. 이미 완료한 원래 음식·음료 소비는 되돌리지 않는다. 지속 데이터는 ctx.modState만 사용하며 기본 게임에는 추가 상태가 없다.

현재 연결은 자기/다른 사람의 실제 음식·음료·약·기름·알약 사용 경로이다. 개봉한 음식은 실제 먹는 결과 Def에도 compWorker가 있어야 한다. 장비·제작·의료 재료 같은 다른 생애 주기의 콜백은 후속 범위이다. [실제 API](../../docs/modding-guide.md).
