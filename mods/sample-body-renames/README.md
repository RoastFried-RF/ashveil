# 같은 몸의 ID 이행 예제

기본 비활성 데이터 예제다. 이전0.9의 OldQuadruped 몸 기록을 현재1.0의 RenamedQuadruped로 옮기되 실제 부위 ID 집합·혈액/HP/상처·절단/의수족·기계 상태·개체 번호·현재 지식/과거 원인·시각/난수는 새로 만들지 않는다.

현재 개체 정의가 목적지 몸을 사용하고 저장된 부위 ID 집합/기계 상태가 맞아야 한다. 다른 해부학/기계-유기체 변환과 임의 JSON은 별도 이행을 요구한다. 과거 몸의 모든 수치나 부모 구조가 현재와 같다고 추정하지 않는다.

자동 검증은 이전0.9의 원래 몸/개체/도감 정의를 먼저 로드한 정상 새 게임에 실제 createCreature로 선언된 초기 개체 한 마리를 배치하고 정상 현재 관찰만 호출한다. 과거 출생/전투/경과 턴을 실행한 이력으로 주장하지 않는다. 몸 불일치 시험은 원래 몸의 부모를 실제 다른 해부학으로 바꾼 뒤 생성한다. 새 Item은 없다.
