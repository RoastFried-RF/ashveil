# AI 목표 워커 예제

기존 약탈자의 CreatureDef에 GuardPriority만 패치한다. 새 사람·Def·아이템을 추가하지 않는다. 실제 볼 수 있는 살아 있는 적 후보 중 연합 세력원에게30점의 보정을 더한다. 거리 기본점수는 거리당−10이며 다른 생존/도주/귀환/공격 가능 조건은 코어가 소유한다.

한 실제 판단마다 후보32개 이하를 거리로 제한하고 ID순으로 제공한다. score는 [{targetId,bonus}]만 반환한다. 실제 후보 밖 ID·중복·소수/비정상 수치·명령은 거절하며 실패한 자기 상태/난수를 반영하지 않고 기본 목표 선택으로 진행한다. 가산은 후보마다±30으로 제한한다.

미리보기는 전체 상태를 바꾸지 않는다. 실제 호출의 지속 데이터는 ctx.modState와 자기 하위 난수뿐이다. 예외/예산 초과는 점수 메서드만 중단한다. 정상 AI와 적대 상태의 기계형 AI 모두 같은 검증을 거친다. 기계의 기존 경보/전원/정비 규칙을 우회하지 않는다.

기본으로 선택하지 않는 예제이며 [현재 API](../../docs/modding-guide.md)를 따른다.
