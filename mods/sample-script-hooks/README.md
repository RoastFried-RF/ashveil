# 스크립트 훅 예제

제목 화면에서 선택하면 실제 명중 계산에 +2를 더하고, 날짜 전환 때 개인 수첩 카운터와 로그를 기록한다. 명중 미리보기는 저장 데이터/난수를 변경하지 않는다. 게임 기본값은 이 모드를 선택하지 않는다.

스크립트는 격리 QuickJS 안에서만 실행한다. `defineMod` 기본 내보내기의 동기 훅과 반환 명령을 사용하며 파일/네트워크/시간/타이머를 제공하지 않는다. 실제 지원 범위와 배포 절차는 [모딩 가이드](../../docs/modding-guide.md#동기-스크립트-훅--v0224)에 있다. 원래 소스 해시·모드 상태·하위 난수를 각인에 보존하며 소스가 바뀌면 이어 하기를 거절한다.
