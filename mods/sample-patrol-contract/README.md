# 순찰 장부 예제

ASHVEIL v0.211 이상의 새 게임에서 선택한다. 기존 시장/화덕/상인과 실제 세 지점의 순서 확인은 그대로이고, 새로 맡는 순찰의 유한 예치 보수를30/기한을2일로 바꾼다. 기존 각인에서 이미 맡은 계약의 기록은 다시 쓰지 않는다. 새 인물·물품·화폐를 생성하지 않는다.

`pnpm validate-defs sample-patrol-contract`로 검사하고 `pnpm mod:package sample-patrol-contract`로 로컬 배포 파일을 만든다. 압축 파일을 다른 체크아웃의 `mods/` 안에 풀고 개발 서버/빌드를 다시 시작한다. 이 예제에는 스크립트나 이미지가 없다.
