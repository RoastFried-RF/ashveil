# 실제 의수족 생애 워커 예제

타이틀에서 이 모드만 선택하면 기존 막대 의족·관절 의족·개척 의수의 실제 설치/분리/정비/전원셀 교체/파손을 기록합니다. 가죽끈·전원셀은 실제 소비한 원래 재료 UID를 별도로 기록합니다. 물품이나 몸을 지급하지 않습니다. 게임에서 실제로 얻은 물품과 해당 결손 부위가 필요합니다.

훅 API `^1.4.0`, 단계2 `ItemCompWorker`를 사용합니다. 작업 시작/중단/재료 부족에는 완료 콜백이 없으며 원래 UID가 보존됩니다. 분리한 의족은 배낭이 가득 차면 원래 바닥에 놓이고 `destination`이 이를 알립니다. `ctx.modState.events`에는 최근32회만 저장합니다. 콜백은 이미 끝난 물리 행동을 취소하지 않습니다.

```sh
pnpm mod:package sample-script-prosthetic /tmp/sample-script-prosthetic.tar.gz
```

로컬 패키지 생성은 공유/업로드가 아닙니다. 코어 문서의 검증과 실제 UID·재료·미완료 복원 검사를 함께 참조하세요.
