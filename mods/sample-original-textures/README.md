# 원본 텍스처 예제

모드를 선택하면 소금 아이콘이 새16×16 CC0 원본 봉지로 바뀝니다. 게임 규칙/수량은 그대로입니다. ZIP/tar.gz/폴더 가져오기를 지원합니다.

Item.sprite 또는 Ability.icon에서 `mod:sample-original-textures/textures/salt-pouch.png`를 참조합니다. textures/ 아래 소문자 영문·숫자·밑줄·하이픈 경로와16×16 정적PNG만 지원합니다. PNG 한파일64KiB, 전체패키지8MiB/512파일 제한입니다. PNG가 바뀌면 모드와로드해시가 바뀌어 기존각인 구성검토가 필요합니다.

PNG는 CC0-1.0으로 상업이용·수정·재배포·2차패키지 제작을 허용하며 출처표시는 필수가 아닙니다. 원본SVG/좌표제작도구는 저장소 tools/art/mod-texture/에 있습니다. 스프라이트시트·캐릭터애니메이션·폰트·오디오는 이 예제 지원범위가 아닙니다.
