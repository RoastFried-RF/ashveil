# 상처·상태 ID 이행 예제

활성화하면 기존 코어를 유지하면서 네 상태 정의와 실제 `migrations/rename.json`을 로드한다. 새 물품·인물·과거 상태를 생성하지 않는다. 특성 예제의 시작 추첨 가중치는0이다.

이전0.9 예제의 OldCut/OldFever/OldMemory/OldTrait가 들어 있는 실제 저장을 새1.0 구성으로 열면 먼저 이행할 ID와 현재 기록 수를 보여 준다. 승인하면 같은 상처 번호/피해·질병 진행/잠복·생각의 남은 시간·현재 면역/노출 시계를 유지한다. 중복 상태·지원하지 않는 실제 참조는 원래 정의 복원을 요구한다. 과거 로그·상처/질병의 원인 문구는 다시 쓰지 않는다.

배포 파일에는 현재 네 정의만 들어 있다. 자동 검증의 이전0.9 구성은 이행 전 네 ID를 메모리에서 실제 로드한 뒤 정상 새 게임과 명시적인 초기 상태를 생성한다. 그 초기 조건 이전의 플레이를 실행했다고 주장하지 않는다. 이행 승인 후 실제 저장 복원까지 검증한다.
