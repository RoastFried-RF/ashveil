# 장소 워커 예제

단계2에서 현재 지도 순찰/수색의 PlaceEventWorker를 지원한다. 기존 순찰 Def에 이 모드의 CampPatrol을 패치하고 확률만1로 바꾼다. 새 Def·사람·물품을 추가하지 않는다. 제목 화면에서 명시적으로 선택한다.

실제 날짜 전환 뒤3턴 예약을 요청한다. 코어가 원래 야영지·실제 인원·가능한 경로를 먼저 검사한 뒤 canFire를 호출한다. 허용한 실제 시도는 원래 인원을 배정하고, execute는 출발 기록/자기 데이터/하위 난수를 보존한다. 각 메서드는 새로운 격리 VM이며 지속 상태는 ctx.modState만 사용한다.

canFire의 실제 허용/거절 판정은 자기 상태·난수만 저장한다. 읽기 전용 미리보기는 저장하지 않는다. execute가 실패하면 그 추가 명령/상태/난수는 반영하지 않고 이미 출발한 원래 사람들을 되돌리거나 새로 만들지 않는다. 원래 출발 조건이 틀리면 워커 자체를 호출하지 않는다.

현재는 지상 순찰·수색 두 기존 사건을 연결한다. 동결 지역 사건·새 사건 종류·MapGenStepWorker/AIConsiderationWorker/ItemCompWorker는 별도 후속 구현 범위이다. 파일/네트워크/타이머/시간 접근과 spawnCreature는 제공하지 않는다.
