# 정신 상태 ID 이행 예제

기본 비활성인 데이터 모드다. 이전0.9의 OldCry/OldDark 기록을 현재1.0의 같은 종류·행동으로 명시 검토한 뒤 옮긴다. 상처/물품·긴장·붕괴 남은 시간/횟수/원래 동반 울음·공포 극복 점수/대상·전체 난수는 보존한다. 붕괴 해소·공포 극복을 실행하거나 보상을 만들지 않는다.

진행 중 붕괴의 행동 종류가 목적지와 다르거나, 종족 공포 대상 유무가 맞지 않거나, 같은 대상의 공포가 겹치면 승인하지 않는다. 과거 개인/정신 기록과 로그는 다시 쓰지 않는다. 현재 두 정의와 rename 파일만 배포한다.

자동 검증의 이전0.9는 원래 두 ID를 먼저 실제 로드한 뒤 정상 새 게임에서 선언된 초기 붕괴/공포를 실제 코어 함수로 시작한다. 경과한 과거 플레이를 실행했다고 주장하지 않는다. 새 Item은 추가하지 않는다.
