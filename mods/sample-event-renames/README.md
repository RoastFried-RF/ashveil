# 사건 예약 ID 이행 예제

기본 비활성 데이터 예제다. 이전0.9의 OldPatrol 예약/완료 콜백을 현재1.0의 RenamedPatrol로 옮기되 원래 시각·위치·배우/귀환 기록·번호를 유지한다. 과거 사건 일지와 실제 인물·공급원·예산·난수는 바꾸지 않는다. 새 사건을 즉시 실행하지 않는다.

현재 활동이 원래 사건 ID를 사용하는 경우와 남는 모드의 임의 JSON은 별도 이행을 요구한다. 미래 실행은 기존 실제 출발지/경로/공급원 검사를 계속 따른다. 같은 원문/현재 구성 검토 뒤에만 승인한다.

이전0.9 자동 검증 구성은 원래 정의를 먼저 로드한 정상 새 게임의 선언된 미실행 미래 예약을 사용한다. 과거 사건 실행이나 인물 출발을 실행한 이력으로 주장하지 않는다. 새 Item은 없다.
