# 물품 ID 이행 예제

`migrations/rename.json`은 이전 버전의 `SampleMigration.Item.OldKnife`를 현재 기존 `Item.RustyKnife`로 옮긴다. 현재 버전에는 새 Item Def나 생성/보상을 넣지 않는다. 실제 이전 버전 물품이 없으면 아무 물품도 생기지 않는다.

저장에 기록한 원래 칸 크기와 현재 목적지의 크기가 같아야 한다. 기존 UID·개수·상태·배낭 위치·회전을 유지하고, 이미 보관 중이면 원본을 새 ID로 복원한다. 빠른 슬롯 등 지원하는 현재 `def` 참조도 함께 이행하며 과거 지식/로그는 바꾸지 않는다.

검토와 명시 승인 후에만 적용한다. 원래 크기 기록 없음·종류/크기 변경·이행 사전 충돌/순환/부재 목적지·스크립트 지속 상태/설치 의수족·선체의 별도 이행은 거절한다. 실제 이전 버전 fixture는 새 게임 전에 옛 Def를 메모리 패키지에 선언해 만들며 현재 콘텐츠 파일에 옛 Def를 다시 추가하지 않는다.
