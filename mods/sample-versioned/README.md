# 버전 의존성 예제

게임 `>=0.1.0 <0.2.0`, core `^0.1.0`을 요구한다. 기존 문자열 의존성과 달리 객체의 `id`/`version`으로 실제 선택 버전을 확인한다.

`sample-selector`는 선택 의존성이므로 자동 활성화하지 않는다. 함께 켜면 그 모드의 `^1.0.0` 버전을 검사하고 먼저 적용한 뒤 이 모드가 조용한 흐름의 휴식 간격을48시간으로 바꾼다. 없거나 꺼져 있으면 이 모드만 적용할 수 있다.

지원 범위 문법은 정식 세 자리 버전·비교식·`^`·`~`·`*`·`||`다. 현재 버전 검사에는 사전 배포 버전/부분 버전/하이픈 범위를 지원하지 않는다. 단일 모드의 배포 검증은 필수 의존성만 모아 확인하며, 압축 파일에는 이 모드의 원본 파일만 넣는다.
