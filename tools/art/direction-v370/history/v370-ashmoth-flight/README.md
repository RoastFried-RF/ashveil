## 정확 크롭과 같은 해부학적 몸통 기준점

좌표는 원문 픽셀 기준이며 사각형은 x,y,width,height입니다. `flight-poses.json`에 원문·크롭 내·정규화 thorax 앵커, 직접 본 head/abdomen 표면 샘플, crop RGBA 해시가 있습니다. **보이는 가슴 중심**을 수동 선택했으며 진짜 날개 관절축은 털/몸통에 가려져 관측한 핀으로 주장하지 않습니다. 앵커 수동 정밀도는 약±3px입니다.

크롭은 alpha≥8 bbox+8px 제안입니다. PNG를 실제로 자르거나 alpha를 threshold하지 않았습니다. 각 crop 밖 **alpha≥8 누락0**이며, alpha1–7의 옅은 잔상 일부는 bbox 밖에 있습니다. `alpha-analysis.json`은 alpha1/8/16/32/128/248/255 경계를 따로 보존합니다.

## 실제 실패와 한계

- ≤60% 칸 크기 요구: raised/folded는 통과, **spread 폭 alpha16 532/627=84.85%(alpha8 534/627=85.17%)**, **downstroke alpha16 392/627=62.52%**로 미통과입니다. 원문을 줄이거나 스케일로 실패를 숨기지 않았습니다. 의미 있는 곤충이 이웃 칸·캔버스에 잘린 근거는 없습니다.
- 완전 alpha0 여백 요구도 미통과입니다. 전체 alpha0 **1,334,677px**, alpha1 **22,943px**. 캔버스 가장자리61개 nonzero는 모두 alpha1입니다. 실제 빈 세로띠 x550–634와 가로띠 y530–729에도 alpha1 잔상이 남지만 양쪽 모두 alpha≥8/16 픽셀0입니다. 배경을 지우지 않았습니다.
- 서로 다른 RGBA 원문 영역4개이며 몸통/더듬이 도색도 완전 동일 복사가 아닙니다. 네 정지 포즈만으로 매끄러운 날갯짓 루프·시간/개체별 위상·작은 실게임 표시를 수락하지 않습니다.
- runtime 회전·반전·다수 인스턴스를 만들더라도 새8방향/24프레임 원화가 추가된 것이 아닙니다. 밀도·유도 광원·흩어짐·게임의 군체 수는 부모 정책입니다.

`activationReady:false`, `releaseAccepted:false`, `strictPromptContractPassed:false`이며 부모가 후보 재사용/실제 렌더러 수락을 결정합니다. 원본 의미 검토로는 네 자세가 분리돼 있지만 프롬프트의 모든 조건을 충족한 결과라고 하지 않습니다.
