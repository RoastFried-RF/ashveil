# 원본 원화319

`node tools/art/direction-v319/build.mjs --install`로 사람19종(912프레임), 비인간형7종(336프레임), 무기·탄약30종과 픽셀 초상19종을 만들고 등록한다. Inkscape가 필요하다. 각 그림은 이 폴더의 직접 작성한 SVG/그리기 코드이며 외부 이미지를 입력하지 않는다. 기존 원본316/이전 프레임은 호환용으로 유지한다.

`node --import tsx tools/art/export-public-artbook.ts`는 실제 Def/manifest로 공개 도감을 갱신한다. `public/artbook/index.html`은 native PNG를 표시한다. 큰 DPI로 렌더링한 contact PNG는 제작용 구성 검토이며 native 픽셀 확대와 다르다. 최종 픽셀은 도감과 실제 게임에서 확인한다.
