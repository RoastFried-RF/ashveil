# ASHVEIL 원본 포자 인간 두 번째 외형

실제 `Creature.SporeMan.char=[spore0,spore1]` 중 **두 번째 spore1**을 새 좌표로 직접 그린다. CANON §7.3, lore/bestiary §18의 살아 있는 인간 순례자·포자 피막 설정과 실제 Def/기존 캐릭터 프레임을 읽었다. 외부 이미지 입력·외부팩 추출·재색칠을 하지 않았다. 자체 첫 외형 제작 도구의 표준 라이브러리 캔버스/PNG/SVG/조각 출력 소프트웨어만 재사용하고, 두 번째의 몸·옷·얼굴·피막·팔·다리 좌표는 새로 작성했다. 프로젝트를 위해 제작했으며 프로젝트와 같은 사용 조건으로 제공한다.

첫 외형의 짧은 올리브색 옷과 두피/어깨의 둥근 덩이와 구분해, 회백색 긴 순례복 앞자락·색이 바랜 자주색 두건·낮게 굽은 목을 그렸다. 얇은 포자 판이 등과 팔목, 한쪽 정강이에 겹쳐 자라며 얼굴·목·두 팔·두 다리·신발은 인간으로 남는다. 큰 버섯 머리·언데드 뼈·새 무기·새 장비·새 능력을 추가하지 않는다. 공격은 인간형 맨손 타격의 그림이다.

## 키·크기·표현 계약

- 보행/정지: 기존 `spore1_w_{down,left,right,up}{0,1,2}`12키와 방향별 idle의 `w_*1` 참조·걷기 순서를 유지한다. 셀24×32, 시트72×128이다.
- 새 공격: 기존 spore1에는 공격 키가 없다. 같은24×32 셀의 새 `spore1_a_*`16키(4방향×준비/당김/타격/복귀), 시트96×128을 별도 제안한다.
- 완전한 조각 `ashveil-spore1-frames.json`은 `renderScale=1`, anchor/attackAnchor `[0.5,30/32]=[0.5,0.9375]`를 쓴다. 모든 걷기 자세의 원본 머리/두건 꼭대기는 y4, 발의 마지막 픽셀은 y29다. 지면 경계는 y30이므로 실제 `headOffset=30−4=26`이다. 위쪽 공격의 올라간 손은 머리 높이로 세지 않는다. 보행/공격이 같은 크기라 추가 몸 오프셋은 없다.
- `ashveil-spore1-walk-only.fragment.json`은 비교용 기존0.92 앵커/배율·머리높이 미지정 계약을 보존한 별도 역사 자료다. 새 배율의 통합에는 위 완전한 조각을 사용한다.

캐릭터 키·Core 몸 크기·시야·포자 규칙을 바꾸지 않는다. 제안 이미지 경로는 `public/sprites/original/`이며 실제 게임 저장소/Def/공유 시트/manifest는 수정하지 않는다. spore0는 이 묶음의 대상이 아니다.

## 산출물과 재현

`ashveil-spore1-walk.png/svg`, `ashveil-spore1-attack.png/svg`, 28자세 contact PNG, 팔레트 JSON, 완전한 frames 조각, 역사 walk-only 조각, integrity JSON을 생성한다. contact는 원본 아트를 확대해 그린 검토 자료이며 실제 게임 촬영은 아니다. integrity에는 제작 도구/출처/산출물/각 자세의 SHA256과 프레임·알파·바닥 검사가 있다.

```sh
python3 draw-spore1.py
python3 draw-spore1.py --check
```

제작 도구는 격리된 자기 폴더에만 출력하며 외부 패키지·이미지를 읽지 않는다. `--check`는 정확한 생성 바이트를 다시 계산해 읽기 전용으로 대조한다. 게임 브라우저/GPU/프로젝트 전체 검사는 이 원본 제작 작업에서 실행하지 않는다.
