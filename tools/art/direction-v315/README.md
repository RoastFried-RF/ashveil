# 밭 잔재 원화 v315

soil-residue.svg의 경로는 이 프로젝트에서 직접 작성했다. 외부 그림·추적·팔레트 샘플·글꼴을 쓰지 않았다. CC0,64×64 투명 원본1프레임. 실제 표시는16×16 세계 칸이다.

```sh
inkscape tools/art/direction-v315/soil-residue.svg --export-type=png --export-filename=public/sprites/original/direction-v315/soil-residue.png
```

제작 PNG를 직접 열어 낮은 흙 더미·꺾인 줄기·뿌리 형태를 검토했다. 게임 조명/배율/시야 검토와 독립 재생성 바이트 대조는 이번 구현 묶음 뒤 진행한다. 현재 보이는 정리한 밭의 잔재에만 표시하며 시야 밖에서는 표시하지 않는다.
