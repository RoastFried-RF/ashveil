# v334 잿곰·재까마귀 독자 원화 staging

제작·원본/표시 검토: 2026-10-24. 새 픽셀은 전부 `image_gen.imagegen`으로 만들었다. 타 게임 픽셀·트레이싱을 사용하지 않았고, 기존 자체 hound/rat는 직접 열어 재질/시점 참고만 했다. 생성 도구에 넣은 이미지 입력은 이 작업에서 생성한 자체 PNG뿐이다.

**현재 바로 통합 가능한 캐릭터는 재까마귀 한 종이다. 잿곰은 보행이 미완성이므로 활성화하지 않는다.** 두 종 전체나 v1.0 출시 품질이 완료됐다는 자료가 아니다.

## 확정 범위

| 모델 | 실제 채택한 원본 동작 | 방향·프레임 | 등록 상태 |
| --- | --- | --- | --- |
| 재까마귀 | idle, walk(땅 위 도약/착지), attack(쪼기), hurt, fall, sleep, rise | 각각 4방향 × 4프레임, **112크롭** | `av331_ash_crow` CharDef 준비 |
| 잿곰 | idle, attack(앞발 후려치기), bite(낮게 앞으로 물기) | 각각 4방향 × 4프레임, **48크롭** | 부분 원화만 준비, CharDef 미등록 |
| 잿곰 | walk down | 정면 4프레임 | 반대 앞발의 접지/통과는 확인, 다른 동작과 체형 일치 후속, 활성화 금지 |
| 잿곰 | walk left/right/up | 통과 원본 없음 | 후보 보류, 그림 재사용으로 채우지 않음 |

등록 제안 전체는 **164개 서로 다른 원본 크롭**이다. 재까마귀 112개 + 곰 부분 52개이며, 완성된 캐릭터 수를 2종으로 세지 않는다. 채택 PNG는 12개다. 생성한 PNG 21개 전부를 보존했으며, 그중 보류·대체 원본도 삭제하지 않았다. 전체 후보의 셀 수는 276개지만, 재시도·대체판을 새 동작으로 더해 완성 프레임 수로 주장하지 않는다. 채택하지 않은 셀은 112개(곰 보류 108 + 초기 까마귀 fall 정면 4)다.

프레임 반전 공유·역순 재사용·동일 포즈 복사로 추가한 프레임은 없다. 재까마귀 rise는 독립 생성 원본이며 fall을 뒤집은 것이 아니다. 새 초상은 0개다. 일반 제작 계약의 walk12/attack8 수준 전체를 완성했다는 뜻도 아니며, 이 단계의 각 방향 원본은 4개다.

## 파일과 통합 계약

- `originals/`: 생성 도구가 반환한 PNG 원문을 바이트 그대로 복사한 보존본. 편집·배경 제거·리샘플링·재인코딩하지 않았다. 원래 도구 출력도 `/workspace/generated_images/`에 그대로 있다.
- `requests/`: 요청별 **정확한 prompt와 transparent_background, referenced_image_paths**를 JSON으로 보존했다. `provenance.json`에도 정확한 인수·입력 SHA-256·도구 출력 경로·PNG SHA-256·대체 이유를 기록했다. 도구가 모델 버전은 노출하지 않아 추정 버전명을 쓰지 않았다.
- `sprites.fragment.json`: 실제 registry에 병합 가능한 `sheets`, `sheetSizes`, `frames`, `chars` 조각. 프레임 키는 `av334_...`이고, 준비된 Def와 맞추는 캐릭터 키는 **`av331_ash_crow`**다. 원본을 실제 통합할 때 `sheets`가 지정한 `public/sprites/original/direction-v334/` 경로에 **채택 PNG 원문만** 복사한다. 이 staging 작업 자체는 메인에 복사하지 않았다.
- `cinder-bear.partial.json`: 곰의 채택 clip/변환과 미완성 방향. **runtime CharDef가 아니므로 그대로 활성화하면 안 된다.** `sprites.fragment.json`에는 곰의 원본 frame만 있고 곰 `chars` 항목은 없다. bite도 별도 clip이며, 현재 게임이 공격 방식별로 이를 선택한다는 뜻이 아니다.
- `foot-anchors.json`: 프레임마다 직접 고른 **원래 시트 좌표와 크롭 좌표**의 지면 투영점. 도약 중에는 발 아래 가상 지면이고, 누운 그림은 몸의 지면 투영점이다. 보이지 않는 발이 실제 접촉했다고 주장하는 자료가 아니다.
- `source-analysis.json`: 원본의 실제 크기·알파·실루엣 영역. `registration-analysis.json`: 최종 등록 직사각형의 범위·원본 crop 픽셀 SHA-256·다른 큰 실루엣 유입 수치. Pillow/NumPy/SciPy는 이 읽기 전용 분석과 **명시된 진단 합성**에만 사용했다.

프레임 crop은 `[sheet,x,y,width,height]`의 원본 픽셀 직사각형이다. 생성 결과가 요청한 1024px가 아니거나 간격이 균등하지 않은 경우 실제 PNG 크기와 실제 영역으로 등록했다. 균등 셀이라고 가정하지 않는다. `frameTransforms.anchor`는 크롭 내부 지면 투영점을 너비/높이로 나눈 값이다. 표시 위치는 원래 픽셀 오프셋 `(pixel - cropSize * anchor) * scale`를 따른다. 원화의 방향을 반전시키거나 잘림을 배율로 감추지 않는다.

재까마귀 기본 배율은 .045, 정면 fall의 별도 고해상도 원본은 .0225다. 곰 idle .14, 간격 확대된 swipe/bite .25, 정면 walk 후보 .065다. 이는 원본 해상도가 달라 지면 기준과 대략의 머리/몸 크기를 맞춘 등록값이며, **게임 내 상대 크기·속도 확정은 후속**이다. 곰 정면 walk의 털/몸 비율이 다른 동작과 완전히 같아졌다고 주장하지 않는다.

## 실제 시각 검토

`docs/lore/bestiary.md` §6–7, 확장 생물 제작 계약, 캐릭터 동작/게임 개발 스킬과 관련 규칙을 읽었다. 기존 자체 v322 `hound-locomotion-front-left.png`, `rat-locomotion-front-left.png`를 직접 열었다. 새 원본은 반환 후 전부 직접 열었고, 채택된 164개 크롭은 방향/동작별로 다시 대조했다.

- 잿곰은 둥근 귀·짧고 넓은 주둥이·큰 어깨/엉덩이·짧은 꼬리·굵은 4다리의 큰 곰으로 읽힌다. 늑대 확대 원본을 쓰지 않았다. swipe는 준비→앞발/발톱 전방 이동→가슴 앞 후속 동작→재접지, bite는 낮은 머리/아래턱의 준비→열림/전방 신장→닫힘→회복으로 구분한다. 뒤 방향에서는 얼굴/이빨을 억지로 노출하지 않는다.
- 재까마귀는 2발·2날개·부리·꼬리가 구분된다. walk는 땅 위 웅크림→양발 도약/날개 균형→한 발 착지→접힘 회복이다. attack은 목/부리가 낮게 앞으로 나가고 다시 회복하며, 피해자·사체·눈·혈흔은 원화에 넣지 않았다. 실제 의식 없는 대상 공격 여부는 게임 규칙이 정해야 한다.
- hurt는 날개/체중 반동과 회복, fall은 다리 지지 상실과 낮게 쓰러짐, sleep은 낮은 웅크림·접힌 날개·묻은 머리, rise는 머리를 꺼내고 두 발로 일어서는 동작을 직접 확인했다.
- 알파는 원본 RGBA와 중성 배경 합성을 함께 확인했다. 곰 좌/우 2×2 후보의 갈색 미리보기는 처음에 불투명으로 오판했으나, 실제 배경 alpha=0을 확인해 판단을 정정했다. 보류 이유는 알파가 아니라 보행/모델 일치다. alpha 1–15의 숨은 RGB와 실제 실루엣을 구분하며, 배경색을 Pillow로 지우지 않았다.
- 최종 164개 등록 직사각형은 모두 원본 범위 안이며, alpha≥16·면적≥400 픽셀의 다른 큰 실루엣 유입은 **0**이다. 이 수치가 의미적 방향/자연스러움 검토를 대체하지 않는다. 일부 고립된 작은 픽셀/낮은 알파는 원본 그대로 남는다.

`index.html`은 메인 게임 없이 이 staging의 원본·crop·anchor만 표시하는 자체 canvas 진단이다. 독립 로컬 포트 49534에서 브라우저로 열고, 모든 등록 프레임 0–3을 ×3/×6으로 촬영했다. 기본 까마귀·추가 까마귀·부분 곰의 ×6 프레임 0–3 합성 12장을 직접 열었고, ×3 크기도 대표 프레임으로 직접 확인했다. `diagnostics/`는 **출시 게임 증빙이 아닌 staging 표시 자료**다. 게임 상태·난수·체력을 조작하지 않았고 메인 preview/dist를 사용하지 않았다.

## 남은 범위

- 곰 좌·우·뒤의 진짜 반대발 보행과 정면 보행의 모델 일치. 이 기본 범위가 통과하기 전 곰 hurt/fall/sleep/rise는 제작하지 않았다.
- 재까마귀 진짜 비행/활공/맴돌기/놀라 흩어짐, 전서 개체 장비 변형·전용 초상. 현재 walk는 **땅 위 도약**이며 비행 완료로 세지 않는다.
- 곰 경고 일어서기/포효·붙잡기·깔아뭉개기·동면/기상·손상 변형·초상. 실패한 bite 포효 후보를 새 완성 roar로 재분류하지 않았다.
- 게임의 실제 Creature/공격 모드/자세 전환에 연결한 뒤 상대 몸 크기, 4프레임 주기/이동 거리, 발 미끄러짐, 지면/가림, 실제 타격 장면 확인. staging 캡처만으로 게임 플레이 통과라고 주장하지 않는다.

이번 작업은 메인 src/public/docs/게임 state/dist/preview 수정, 프로젝트 빌드/검사, Full/World, commit/push를 하지 않았다. 후속 통합은 준비된 조각과 정확한 PNG 바이트를 사용하는 별도 부모 작업이다.
