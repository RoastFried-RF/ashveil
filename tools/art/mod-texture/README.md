# 모드 데모용 소금 봉지 원본

2026-10-21 제작. 실제 16×16 픽셀로 직접 그린 투명 소금 작은 봉지 한 종류다. 모드의 16px PNG 지원을 보여 주기 위한 격리 산출물이며 실제 활성 모드의 경로·sprite 바인딩은 Root가 별도 통합한다. 이 묶음은 게임/모드 파일을 수정하거나 게임 기능 완성을 검증하지 않았다.

밝은 염결정이 위로 드러난 찢어진 갈색 봉지와 왼쪽 아래의 밝은 조각을 새 좌표로 구성했다. 회색 고원의 재빛·낡은 갈색·아주 약한 회녹색과 상아색을 사용했다. 투명색을 포함해 16색이며 반투명·블러·고정 그림자가 없다. 결정 조각은 실루엣을 위한 묘사로 실제 stack 수량·순도·오염·효능·물품 상태를 표시하지 않는다.

기존 `Item.Salt`용 원본이나 다른 PNG를 복사·크롭·편집·재색칠하지 않았다. 외부 이미지 입력은 없으며 이 폴더의 Python 소스에 새로운 16행 정수 픽셀 좌표와 팔레트가 직접 들어 있다.

## 제공 파일

| 파일 | 용도 |
| --- | --- |
| `art/demo-salt-pouch.png` | 실제 16×16 RGBA8 투명 원본, 알파 0/255 |
| `art/demo-salt-pouch.svg` | 16×16 정수 픽셀 rect로 편집 가능한 원본; PNG 전 픽셀 일치 |
| `art/demo-salt-pouch-8x.png` | 128×128 최근접 확대; 투명 배경 유지 |
| `art/demo-salt-pouch-contact.png` | 384×208, 어둡고 밝은 배경의 실제 16px·2배·8배 검토 |
| `art/demo-salt-pouch-palette.json` | 불투명 15색 + 투명 1색 |
| `art/demo-salt-pouch-source.json` | 생성기/산출물 SHA-256·크기·제작 방식·권리·경계 기록 |
| `tools/draw-demo-salt.py` | 외부 의존성 없는 새 좌표 제작 및 `--check` 도구 |
| `tools/check-demo-salt.py` | 생성기를 import하지 않는 독립 검사기 |
| `verification.json` | 독립 검사 결과 |
| `LICENSE.txt` | CC0-1.0 권리 선언 |

실제 모드 통합에서는 원본 PNG를 원하는 `textures/` 상대 경로로 복사하고 해당 모드의 sprite 경로를 Root가 선택한다. 이 묶음은 모드 manifest·Def·자동 활성화 코드를 포함하지 않는다.

## 재현과 확인

이 폴더에서 실행한다.

```sh
python3 tools/draw-demo-salt.py --check
python3 tools/check-demo-salt.py
```

생성 도구는 기본 실행 시 이 폴더의 `art/`에만 여섯 산출물을 기록하며 `--check`는 읽기 전용으로 바이트를 대조한다. 독립 검사기는 생성기를 import하지 않고 PNG CRC/단일 종료 IEND·RGBA·알파·여백·팔레트·SVG 전 픽셀·8배 확대·검토 시트의 1/2/8배 픽셀·해시·권리 기록을 검증한다. 원본 16px와 확대 시트는 실제 파일을 열어 시각 검토한다. 프로젝트 테스트·GPU·브라우저·활성 모드 검사는 실행하지 않는다.
