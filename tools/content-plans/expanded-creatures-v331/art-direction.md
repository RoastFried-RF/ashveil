# v331 신규9종 원화 제작 계약

기준은 `docs/CANON.md`, `docs/lore/bestiary.md` §5–13과 이번 Def의 실제 신체/공격이다. 자체 원본만 제작한다. 다른 게임 원화나 현재 늑대·환자·드론 모델을 새 이름으로 등록하지 않는다. 아직 새 PNG를 생성하거나 시각 승인하지 않았다.

일반 프레임 수 기준은4방향, 보행12·대기4·공격8이다. 특수 동작은 실제 실행되는 정책과 대응시킨다. 몸체는 현재 게임의 실제 고정 장비와 충돌하지 않게 빈손/고유 신체 도구를 구분한다. 기계의 집게·낫팔·파종구는 실제 Body/자연 공격이며 소지품 무기로 새로 지급하지 않는다.

캐릭터별 독립 초상 키는 `av331_portrait_<종키>`다. 기본 전신 fallback이 기능적으로 가능하더라도 초상 제작 완료로 세지 않는다. 새 Item32개의 아이콘 키는 `art-requirements.json`을 따른다. 독샘/캡슐/정화액/동력핵은 일반 천이나 창 아이콘으로 최종 표시하지 않는다.

원화 자체는 보존하고 프레임 crop/pivot/방향/배율은 manifest에 명시한다. 최종 등록 전에 각 원본·선택 프레임·게임 합성 화면을 실제로 본다. 투명 이미지 미리보기에서 강한 색 테두리가 보이면 RGBA alpha와 실제 합성을 함께 확인한다. alpha1/255의 숨은 RGB를 불투명 halo로 오판해 원본을 성급히 교체하지 않는다.

이 문서는 제작 계약이며,9모델·32아이콘·전체 동작이 완성되었다는 기록이 아니다.
