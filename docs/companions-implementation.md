# 동료 고용·실제 동행과 장비 공간 — v0.60

X1의 고용/간접 지시와 이동을 현재 규칙에 연결했다. 기존 정착지의 경비를 곁에서 고용하며, 고용을 이유로 사람·장비·보급품을 생성하지 않는다. 몸·개인 현금·소속 세력·출신지와 개인 물품은 유지한다. 전투에서만 고용주와 같은 편으로 판단하며, 동료가 목격된 범죄를 저질러도 고용주 측 평판 사건으로 남긴다.

고용료40표는 첫 하루를 포함한다. 이후 하루 급료6표를 곁에서 실제로 건넨다. 자동 원격 인출은 없다. 선불 기간이 끝나면 그 자리에서 급료를 기다리고 동행을 멈춘다. 만료 처리는 한 번뿐이며 이틀 넘는 선불 누적은 거부한다. 대화·현재 장소·실제 의식/청각·서로 보이는 인접·역할·평판·급료·인원 상한을 검사한다. **40/6표·최대3명·거리/생활 임계는 `Companion.Hearth`의 임시 조정값**이며 CANON의 미확정 화폐/평판 결정을 바꾸지 않는다.

N→해당 주민→동행·고용에서 고용/급료/헤어짐을 선택한다. 동행·현지 대기·주변 방어는 각각 곁에서1턴을 들여 합의한다. 동료는 실제 시야로 고용주 위치를 갱신해 경로를 걷는다. 보이지 않는 위치를 계속 읽지 않는다. 지시한 곳에 대기한 동료를 다음 지도에 복제하지 않는다. 헤어지면 그 장소에 같은 사람이 남고 이미 건넨 돈은 환불하지 않는다.

배낭 물품을 한 묶음씩1턴에 건넨다. 공간은 미리 검사하고, 거부 시 원본/UID/난수/현금은 변하지 않는다. 물병과 같은 비쌓임 물품은 같은 UID를 쓰고 쌓이는 물품은 기존 합치기 규칙을 따른다. 동료는 자기 배낭의 실제 식량·물을 소비하며 피로하면 같은 수면 행동을 한다. 물품/열량/수분을 무료로 채우지 않는다. 전투·피격·상처·몸·탈의도 공통 규칙이다. 전문적인 치료/보급 조달 AI 전체는 아직 없다.

계단은 곁의 걸을 수 있는 동료만 넘긴다. 따라오는 동료가 멀리 있거나 자거나 걷지 못하면 먼저 모이거나 현지 대기를 지시해야 한다. 기존 지도/길목의 빈 도착 칸도 검사한다. 주민을 비활성 층/지역 저장에서 제외한 뒤 같은 인물을 새 지도에 놓으므로 이중 존재하지 않는다. 지역 출입/월드 한 칸 이동도 같은 방식이다. 여행 중 몸과 시간이 계속 진행되고 잠듦·출혈·계약 만료로 함께 걷기 어려워지면 구간 진행을 멈춘다. 현지 대기자는 원래 지도에 남아 재방문할 수 있다. 고용주 사망 때 계약을 끝내며, 동료가 다른 지역에서 사망해도 출신 정착지의 SIR/사망을 한 번만 옮긴다. 조사 인구N은 기존 방식대로 사망 포함이다.

장비 교체는 꺼낼 물품이 만드는 빈자리와 기존 주무기/보조 장비 모두를 한 번에 검사한다. 양손 창의1×4 빈자리만으로2×2 방패가 들어간다고 보지 않는다. 실패 시 가방 밖의 보이지 않는 물품을 만들지 않는다. 다턴 장착은 시작/완료/중단에 같은 검사를 적용해 그 사이 공간이 바뀌어도 원본 장비를 보존한다. **기존 옷을 먼저 벗고 새 옷을 입는 단계별 교체는 후속**이다.

각인v26은25의 몸·장비/착탈 진행을 바꾸지 않는 순수 이관이다. 실제 계약/지시·현지 대기·여행 명단을 저장한다. 기존5개 골든의 전체 초기/최종 상태 차이는 버전25→26뿐이며, 원래 명령과 오류는 유지한다(`golden-v060-diff.json`).

현재 동료22개·장비 공간7개·Def1개를 추가했다. 곁의 실제 고용/돈·거절의 불변·급료/만료·시야 기반 이동·물품/식수·계단 왕복/대기·지역 왕복/길목/실제 여행의 몸 시간·수면 중단·빈 칸·원정 사망·고용주 사망과 저장을 검사한다. 전체61파일942개는36.12초에 통과했고 린트/타입/빌드·Def/Schema55파일 오류0이다. 고정 코드의 브라우저139~142/설정은 콘솔 오류0으로 통과했으며139를 시각 확인했다. 실제 생성한 정착지 경비의 UI고용(1턴/40표·동일 UID), 물병 전달, 대기 후 실제 플레이어 이동/복귀, 급료6표와 동행 재개, 실제 지역 출입·저장 복원·마을 귀환의 같은 인물을 확인했다. 브라우저는 출입구 곁에 인물/정상 몸·초기 현금을 준비한 검사이며 월드 전체 경로를 사람이 왕복했다고 집계하지 않는다. 별도 단위 검사는 실제 한 칸 여행 전체의 몸 시간을 재생한다. 사기 계산의 아군 전력도 동료 편을 사용하도록 보완했다. 보완 뒤의 단독 전체942개36.12초·같은5골든 전체 상태 동일·고정 코드 브라우저 재실행139~142/설정 콘솔0까지 확인했다. 동시4월드 계산을 실행한 검사에서는 기존 보온 검사 한 개가5초 제한을 넘어941개만 통과했고, 작업을 분리한 최종 단독 검사에서942개 모두 통과했다. 최종 고정 코드의30판×최대3일은203.989748072초에 완료했다. 평균0.419056712962963일·3일 생존0·저체온19/치명상5/과다 출혈6이며, v0.59의30개 개별 결과는 최종 세부 상태까지 모두 같다. 봇은 동료를 고용하지 않으므로 기존 규칙 회귀이며 동료의 실제 동작은 별도 단위/브라우저로 검증했다.
