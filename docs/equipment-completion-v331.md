# v0.331 장비 재획득·사제의 실물 향로

리소스/장비 전수 대조에서 기본 장비4종은 해당 배경의 시작 물품 이외에 보충 경로가 없었고, 말라붙은 사제는 향로 물품을 들지 않아도 자연 공격으로 향로 피해를 냈다. 이번 묶음은 두 연결을 실제 콘텐츠와 원화로 보완한다. 저장212를 유지하며 기존 인물의 물품을 새로 지급하지 않는다.

| 장비 | 새 비기본 제작법 | 수첩·입수 |
|---|---|---|
| 경석궁 | 목재4·고철3·실3, 칼날/망치·작업대,900턴 | 고원 공작 수첩, 경비대 한정1개, 경비실 전리품 |
| 뱃사공 장대 | 목재4, 칼날·작업대,240턴 | 같은 수첩, 등불연합 한정1개, 나무 상자 |
| 가죽 앞치마 | 가죽4·실1, 바늘·작업대,360턴 | 같은 수첩, 길드 한정1개, 보관함 |
| 기름 먹인 천 우비 | 리넨3·등잔기름2·실2, 바늘·작업대,480턴 | 같은 수첩, 등불연합 한정1개, 보관함 |

수첩도 길드에 한 권만 추가한다. 새 상점 항목은 일일 생산/소비0이며 전역 상품의 자동 공급에 등록하지 않는다. 이미 생성된 시장을 다시 채우지 않으며, 실제 매진 후100일/시장 재개에서 이 품목이 재생성되지 않는 검사를 넣었다. 기존 배경12개와 시작 물품·장비 성능은 유지한다. 장대/앞치마는 제작 투입보다 분해 산물이 많아지는 순환을 만들지 않는다. 전리품은 아직 생성하지 않은 유한 상자에서만 기존 뽑기 규칙을 따른다.

사제는 생성할 때 **꺼진 사슬 향로** 한 개를 실제로 장착한다. 향로가 기존 타격12·기절 보정4의 공격을 가지며, 사제의 자연 공격은 타격5·기절 보정 없는 맨손으로 바꿨다. 떨어뜨리거나 사용할 수 없게 파손되면 실제 무기 선택이 맨손으로 돌아간다. 사망/바닥/저장 복원에서도 같은 UID를 보존하며 두 번째 향로를 보상으로 만들지 않는다.

image_gen 원본2장을 원문으로 보존하고2차 결과를 선택했다. 위쪽 고리·연결 사슬·꺼진 금속통을 직접 확인했다. PNG를 수정·리샘플링하지 않고 실제1024×1536 시트의 `[329,57,366,1387]` 영역을 등록했다. [정확한 생성 프롬프트·해시](../tools/art/direction-v331/censer-provenance.json). `Item.heldSprite`의 일반 표현 설정은 정규 손잡이·원본 축/길이·휴대 각도·충격 끝 거리만 지정하며 게임 사거리/피해/시간에는 쓰지 않는다. 새 필드의 Schema와 유한 값/범위 검증도 함께 추가했다. 최초28월드픽셀 길이는 실제 화면에서 바닥 아래로 내려가18로 줄였다.

patient 원화의 정지16·걷기48·공격32프레임을 수동 대조해 실제 손 접점을 추가했다.96프레임 키/88고유 크롭, 오른손76·왼손71접점과 가림45슬롯이다. 좌향 공격8개는 우향 반전 공유여서 최종 해부학적 손을 교환해 등록했다. 등록된 손에 가짜 공격 전방 이동을 더하지 않고 실제 원본 주먹 위치를 따른다. 숨은 손에는 근처의 다른 손이나 공중 접점을 대체하지 않는다. [검토 범위·원본4PNG 해시](../tools/art/direction-v331/patient-grips/README.md). 같은 원화를 공유하는 별칭에도 이 접점이 적용된다.

두 화면 크기의4방향 실제 공격→소지품 메뉴로 바닥에 놓기→맨손 재공격을 실행했다. 초기 각인은 명시한 patient 외형의 플레이어와 향로/멈춘 적을 사용했으며, 자연 발생 사제 조우나 모든 파손/손 조합으로 세지 않는다. 도감과 동작 비교도 실제 원본·새 손 접점을 포함해 갱신했다. [검사/화면 근거](release-v331-proof.json).

사슬 전체를 강체로 회전시키므로 유연한 사슬 굽힘과 도구별 팔 자세는 후속이다. 사제는 아직 patient 몸체를 공유한다. 모든 자세/다른 모델의 손목, 실제 착용 의복·보철/절단 외형, 확장9종과 행동·새 지역, 전체 회귀/World/1,000판 및 사람 평가는 계속 남는다. [전수 조사에서 확인한 출시 누락](resource-release-audit-v331.md).
