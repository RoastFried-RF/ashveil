# 정착지 순찰 계약 · v0.211 / 각인153

GDD의 순찰 계약을 정착지 실제 경로·장부·이동·보고에 연결했다. `PatrolContract.Hearth`가 공개 경로와 주기/기한/보수를 설정한다. 기존 정착지의 시장 남쪽(30,20), 진료소 남쪽(35,20), 실제 공동 화덕(32,18)을 차례대로 확인한다. 좌표는 의뢰인이 알려 주는 경로이며 플레이어의 과거 직접 목격이나 원격 적의 현재 상태로 표시하지 않는다. 기존 정착지의 실제 화덕/지도/상인/유한 장부가 있어야 게시된다. 새 인물·Item·전투를 생성하지 않는다.

수락1턴에 기존 시장20고리를 예치한다. 보수20과 위협0은 Def 기본값이며 보수 공식(20+위협×0.8)에 따른다. 별도 경제 정본을 확정한 것으로 주장하지 않는다. 각 지점은 수락 후 실제 플레이어가 같은 지역/지도에서 바로 곁의 지점을 볼 수 있고 위협/포박/활동 없이 의식/시각/손/밝기를 갖춘 때 확인1턴을 쓴다. 다음 지점만 허용하고 복사한 객체·NPC·원격/어둠·같은 시각의 재확인·기한 이후를 거절한다. 조회는 진행·돈·난수·UID를 쓰지 않는다.
