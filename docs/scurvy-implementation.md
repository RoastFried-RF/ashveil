# 실제 괴혈 잇몸 출혈·모든 옛 흉터 재개방과 비타민 회복

v0.102. 설계02 §11/§636과03 §3.4의 괴혈병 단계가 원래 몸의 실제 혈액·흉터/상처·먹은 비타민·같은 회복에 이어지게 보완한다.

기존 totalBleed는20단계 잇몸 출혈을 표시했지만 bodyTick의 실제 차감은 상처만 합했다. 이제 같은 읽기 전용 잇몸 출혈 함수를 표시와 실제 혈액 정산이 함께 사용한다. 실제 기본10ml/일이 상처가 없어도 원래 혈액에서 줄며,80단계의 출혈×1.5는 잇몸에도 적용해15ml/일이 된다. 별도로 실제 숙주 혈액을 차감하는 거머리를 다시 합쳐 두 번 빼지 않는다. 몸의 기존 혈액 재생은 계속 작동하므로 잇몸 출혈만 있을 때 시간 단위 재생으로 혈액량이 다시 찰 수 있다.

기존40단계 처리는 옛 흉터 하나를 무작위로 골랐다. 이제 실제 일일 정산에서40을 넘는 순간 남아 있는 모든 원래 흉터 기록에 각각 심각도3의 베임을 만든다. 원래 흉터 기록/출처는 보존하고, 새 베임에는 실제 새 UID와 ‘괴혈병으로 흉터 재개방’ 원인을 남긴다. 이미 잘린 부위나 구형의 잘못된 부위에는 새 상처를 만들지 않는다.40 이상인 채로 다음 날이 된 것만으로 다시 열지 않는다. 과거 출혈이나 재개방을 세이브 이관에서 소급 생성하지 않는다.

60단계 자연 치유 정지와80단계 상처 출혈×1.5는 같은 원래 상처에서 이어진다. 실제 원본 말린 사과의 비타민5를 먹어도 상처가 즉시 사라지지 않는다. 다음 일일 정산에서 비타민2를 소모한 뒤 남으면 진행이10 줄고,60 아래에서는 같은 상처가 다시 아물 수 있다. 비타민1만 있다면 일일 필요량으로 고갈되어 진행이5 늘어난다. 화면의 다음 정산 설명도 이 순서를 사용한다.

신체 창·일지·실제 의사 진찰은 현재 괴혈 진행/비타민·잇몸 출혈ml/일·다음 정산·치유 정지·출혈 배율을 읽는다. 숫자가 작아0.0ml/턴으로 보이던 잇몸 출혈도 실제 일일 양으로 알 수 있다. 조회가 혈액이나 난수를 바꾸지 않는다. 기계 몸과 잘못된 비유한 진행 값에는 새 생물학적 출혈을 만들지 않는다.

각인v66은 원래 몸·혈액·흉터·새 상처·식사/비타민을 보존한다. 구형65는 버전만 올리며 과거에 빠지지 않았던 혈액을 갑자기 빼거나 옛 흉터를 소급해서 열지 않는다.
