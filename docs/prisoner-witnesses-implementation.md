# 실제 주민의 개인 목격과 대화로 들은 포로 소식

v0.206. 같은 지도에서 실제 차례를 맞은 깨어 식별할 수 있는 인간형NPC가 자기 시야·시선·조명으로 본 포박/이전에 기억한 사람의 해방/시신 모습만 개인 기억에 남긴다. 플레이어에게 곁에 있는 것만으로 전달하지 않는다. NPC가 알지 못하는 개인 이름이나 플레이어가 만난 사실을 NPC에게 나누지 않고, 실제 보이는 기본 인물 분류/공개 주민 소속으로 기록한다.

실제 플레이어와 목격자가 같은 현장에서 바로 곁에 있고 서로 식별/청취할 수 있어야 기존 대화1턴으로 과거 목격 사본을 전한다. 사본은 실제 목격 시각과 전해 들은 시각·전달자ID/알려진 이름을 구분한다. 현재 원격 인물의 위치/생사/몸/포박자는 읽지 않는다. 다른 이에게 들은 사본을 직접 목격으로 다시 전하지 않고, 미래 시각/반복 전언은 거절한다. 자기 편이 잡고 있었다는 NPC 말을 플레이어 소유 포로로 바꾸지 않는다.

더 새 직접 목격은 오래된 전언에 덮이지 않는다. 이후 실제로 식별하면 전언 표시를 없애고 직접 확인한 이름/모습을 갱신한다. 전달자/위치/밧줄 사본 조회를 수정해도 원래 기억을 고치지 못한다. 구조 의뢰는 같은 사람/밧줄/마지막 목격을 쓰되 전해 들은 근거라면 전달자를 게시와 수락 장부에 명시한다. 현재 생존 보증이나 직접 확인으로 꾸미지 않는다.

검증은 실제 원래 주민67/경비85/포박자46/밧줄163/등불162를 보존한다. 실제 주민 차례를 맞도록 공개 대기로 진행해 개인 목격을 만든 뒤, 플레이어의 직접 목격이 없음을 확인한다. 목격자의 초기 지역·위치/등불 소지와 대화 곁 위치·직접 재확인 위치·정착지 곁 위치는 제어 조건이며 주민의 지역간 이동/이전 공격·자연 납치를 완료했다고 주장하지 않는다. 실제 대화1턴과 출처가 붙은 구조 의뢰 수락1턴은 공개 입력이다.
