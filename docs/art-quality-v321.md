# v0.321 인물·타일의 형태와 재질 개선

기존 v319/320의 인물은 몸통·팔다리가 평평하고 방향마다 옷의 형태가 비슷했다. 석판은 넓은 면만 반복되고 야외 바닥은 빈 공간이 많아 캐릭터와 세계가 단순해 보였다. 사용자의 품질 개선 요청에 따라 실제 참고 화면을 다시 조사하고 몸체·초상·바닥·벽을 교체했다. [실제 게임 전후 비교](https://roastfried-rf.github.io/ashveil/artbook/comparison/) · [원화 도감](https://roastfried-rf.github.io/ashveil/artbook/).

이번에는 Stoneshard의 야영지·광산·숲 화면3장, Fear & Hunger와 Eslabong의 공식 Steam 화면 각1장을 직접 열어 인물의 비례, 재질의 명암, 바닥과 사람의 대비를 검토했다. [출처·해시·관찰](../tools/art/direction-v321/research.json). 이전 위키3,937파일 목록/601이미지 검토는 [v319 기록](wiki-resource-study-v319.md)을 유지한다. 이번에3,937개 그림을 새로 전부 시각 검토했다는 뜻은 아니다.

몸체13모델의 앞·옆·뒤 형태와 얼굴·손·옷의 겹침을 만들고 가죽의 마모, 금속판·천의 주름, 동물의 털, 기계의 관절을 구분했다. 각 방향의 걷기6/정지2/공격4로624프레임이다.13모델을 기존28캐릭터 등록에 연결했으며 같은 계열의 주민·적 변형은 모델을 공유한다. 이전26디자인보다 모델 수가 줄어든 점과 개별 나이·성별·복장 변형은 남은 개선 범위다. 역할 초상8종을 HUD·타이틀·대화·캐릭터 창에 연결했다. 캐릭터 창의 옛 고정 프레임도 현재 캐릭터 선택을 따르게 했다.

석재·풀/흙/진흙/재·벽·물의4시트에서52개 기존 프레임 키를 교체했다. 바닥은 큰 재질 무늬를8×8논리 칸에 나눠 표시하며 사람보다 과하게 밝던 첫 결과는 렌더러 명암을 낮췄다. 물가에는 알려진 이웃 지형만 사용하는 좁은 둑과 가장자리 마스크를 표시한다. 지형 충돌·논리 칸·시야12/어둠6규칙은 바꾸지 않았다. 나무·사물·물품·능력·UI 전체를 이번에 다시 제작한 것은 아니다. v319/320의 물품80종과 기존 자체 자산을 유지한다.

31PNG는 OpenAI 이미지 생성 도구로 제작한 새 원본이며 생성된 바이트를 그대로 사용한다. 손으로 작성한 SVG 픽셀 원본과 구분한다. 다른 게임의 그림은 생성 입력·트레이싱·설치 자산에 넣지 않았다. 자체 모델만 후속 생성의 일관성 참고로 사용했다. 인접 동작이 겹친6시트는 거절하고 분리된 시트로 다시 생성했다. Pillow는 알파를 읽어 프레임 영역·발 기준·배율을 계산하는 데만 쓰며 PNG를 수정하지 않는다. [제작 원본·정확한 매핑·해시·재등록 절차](../tools/art/direction-v321/README.md) · [CC0 고지](../tools/art/direction-v321/LICENSE.txt).

새 PNG는 합계54.26MiB다. 원본 보존을 우선했으며 작은 기기의 메모리·전송량 최적화와 성능 평가는 남아 있다. 원화 생성은 비트 단위 재현을 보장하지 않으며 보관 PNG에서 JSON을 만드는 등록 과정은 재현 가능하다. 전체 레지스트리는201시트/4,117프레임/28캐릭터/26UI/고유227PNG다. 옛 프레임은 호환 자료로 유지하므로 전체 프레임 탭에는 이전 그림도 보인다.

타입·대상 린트·PNG/프레임/참조 검사·프로덕션 빌드를 확인했다. 실제 타이틀 이어하기로 동일한 유한 초기 각인의 석실·야외·횃불 장면을1440×1080과1366×768에서 열었다. 최종6PNG를 모두 직접 열었으며 HUD의 이웃 초상이 비치던 클립 문제를 수정했다. 실제 오른쪽 이동1걸음은100TU/20,20→21,20이고, C 입력으로 연 캐릭터 창은 별도 수정 화면도 열어 확인했다. 비교 페이지의 이전/현재3개 초기 각인 바이트는 같다. 자연 탐험이나 실제 전투의 품질 평가와는 구분한다.

도감은13모델의4방향×정지/걷기/공격×선택 프레임4개를 표시 검사했다. 생성한9화면(정지 앞/걷기 옆/공격4방향/초상/비교 데스크톱·모바일)을 모두 직접 열었다. 이는624개 포즈 모두를 각각 확대해서 검토했다는 뜻은 아니다. 브라우저 오류는0이었다. [검증 근거](release-v321-proof.json).
