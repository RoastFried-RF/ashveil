단계1 반환 명령에 applyWound/spawnItem/queueEvent를 연결한다. 모든 명령을 사전에 검증하며 잘못된 호출의 앞 명령/모드 데이터/난수를 적용하지 않는다. 기존 상처 처리와 makeItem을 사용하므로 같은 신체/원래 UID체계/생존 규칙을 따른다. 가짜 플레이어 가해자 ID를 만들지 않는다.

아이템은 당사자 주변 통과 가능한 바닥이나 열린 원래 용기에만 놓는다. 실제 최대 묶음과 용기 빈 칸을 합산 검산하고 원래 내용/UID를 덮지 않는다. 상처는 실제 살아 있는 당사자/존재하는 부위만 허용한다. 절단된 부모의 하위 부위도 거절한다. 재귀 상처는4단계/전체64명령으로 제한한다.
