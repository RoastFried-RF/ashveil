# v343 지도별 원본 이미지 수명 관리

v340까지 원래 캐릭터 전체를 초기 로딩했다. v343은 현재 지도의 실제 저장 외형·Def 별칭으로 몸 모델을 고르고, 선택한 모델의 모든 방향/동작/초상화 원본 시트를 그대로 읽는다. 공용 지형·소품·장비·FX와 실제 모드 아이콘은 유지한다. 원본 PNG와 프레임 사각형은 변경하지 않는다. 픽셀 샘플링은 nearest로 명시한다.

`world-assets.ts`는 현재 살아 있는 맵의 실제 생물 외형과 해석된 콘텐츠만 조회한다. 과거 외형의 명시된 프레임은 보존하며, 알 수 없는 저장 외형 문자열을 임의 URL로 읽지 않는다. 원본 경로나 숨은 개체 이름을 공개 관찰에 추가하지 않는다.

`asset-lifecycle.ts`는 이미지 요청을 직렬화하고 화면 소유자와 요청 세대로 구분한다. 새 원본 로딩 → 새 화면 동기화/옛 스프라이트 제거 → 불필요한 원본 해제 순서다. 옛 화면의 늦은 요청·unmount는 새 화면 원본을 해제할 수 없다. 실패한 요청은 마지막 사용 가능한 화면을 보존하고, 성공한 일부 이미지는 실제 재시도에서 재사용한다. 타이틀로 나가면 이 로더의 원본/프레임 캐시를 비운다.

처음 펼치기와 새 모델 로딩 중에는 불투명한 로딩 화면을 표시하며 게임 행동 입력을 막는다. 실패하면 실제 재시도 버튼을 제공한다. 로딩 자체는 코어 턴을 추가하지 않는다. 이미 시작된 자동 작업/시뮬레이션 전체를 일시정지한다는 뜻은 아니다.

기존 선로딩314시트의 너비×높이×4 합계는919.61MiB다. 같은 원본 레지스트리에서 떠돌이+측량기 장면198시트는223.71MiB, 떠돌이+까마귀 장면200시트는235.71MiB다. 이는 로더가 소유하는 원본의 RGBA 추정치다. 브라우저 RSS/실제 GPU 사용량·CSS 이미지·모드 fallback·추가 캐시나 보편적 로딩 속도 측정값이 아니다. 다양한 몸 모델이 함께 있는 지도는 더 많은 원본이 필요하다.

변경 범위 검증은 `tests/asset-lifecycle.test.ts`, `tests/atlas-plan.test.ts` 및 기존 동작/장비/모드/원본/포인터 검사다. 실제 검사는 `tools/inspect-assets-v343.ts`의 선언된 두 유한 지도에서 키·계단·타이틀/각인 재개·의도한 네트워크 실패 후 실제 재시도를 사용한다. 이전 불변 v340과 같은 초기 세계·같은 실제 행동의 전체 상태를 대조한다. 불러오기 뒤 세계/시간/RNG/장비를 주입하지 않는다. 최종 실행 결과는 `release-v343-proof.json`에 기록한다.

이 변경은 새 동작 프레임이나 NPC 종류를 완료 처리하지 않는다. 실제 착용 의복·절단/보철 외형, 남은 종과 촘촘한 보행, 장기 생태/노동, 전체 회귀·World·사람 평가가 계속 남아 있다.

실행 결과: 관련7파일44검사·타입·변경 파일 린트·프로덕션 빌드 통과. 불변 v340/r3과 v343/r1의 같은 초기 각인에서 두 화면×5시점의 전체 JSON/해시10쌍이 일치했다. 실제 계단 왕복으로 측량기/까마귀 모델을 교체하고, 타이틀 이탈 소유 시트0/재개 전체 상태 보존을 확인했다. 의도적으로 원본1개 요청을 차단한 뒤 실제 대기/이동 입력이 세계를 바꾸지 않고, 실제 재시도 뒤에도 같은 세계를 보존하며 그다음 실제 대기는 정상 진행했다. 정상 시나리오 콘솔/페이지 오류0이다. 강제 네트워크 오류는 별도로 기록했다. 실제 PNG5장을 직접 열어 두 원본 몸체/맵, 작은 화면, 실패·복구 화면을 검토했다. 전체 회귀·World·1,000판은 실행하지 않았다.
