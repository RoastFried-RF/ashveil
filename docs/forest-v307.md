# v0.307 수목 원화와 시야 경계

기존 고사목 한 실루엣의 반복을 줄이기 위해 갈라진 굵은 줄기·기운 가는 줄기·속 빈 낮은 밑동·높은 갈래 줄기 네 원화를 추가한다. 스팀 공식 숲 장면의 수목 높이/폭 차이와 길의 명암 구성을 분석하고, ASHVEIL의 잿빛·갈색 고사림 방향으로 독립 제작했다. 참고작 픽셀은 입력하거나 복제하지 않았다. [조사 기록](../tools/art/direction-v307/references.json) · [원본/방법](../tools/art/direction-v307/provenance.json) · [CC0](../tools/art/direction-v307/LICENSE.txt).

첫 생성본은 가지가 atlas 사분면을 넘어 반려했다. 이미지 생성 도구로 간격을 수정한 두 번째 원본을 바이트 그대로 사용한다. 희미한 배경 alpha 잡음은 PNG를 편집하지 않고 프레임 범위로 제외한다. 프레임·발밑 pivot·월드 높이는 [메타데이터](../tools/art/direction-v307/forest-frames.json)에 고정하며 `python3 tools/art/direction-v307/install.py --check`로 SHA256·실제 atlas·런타임 매핑을 대조한다.

실제 로드된 `Terrain.Tree`는 `original_dead_tree` 하나를 지정한다. 이 기본값에만 네 변주를 좌표 해시로 선택한다. 별도 살아 있는 소나무·검은잎나무와 사용자 모드의 명시 sprite 목록은 기존 표현을 유지한다. 옛 `tree_dead`/미지정 폴백의 생목1/4 선택도 유지한다. 최초 브라우저 검사에서는 새 PNG를 다운로드했지만 기존 기본 키가 사용자 모드처럼 분류돼 새 원화가 안 쓰였다. 실제 화면에서 발견해 로드된 Def를 사용하는 회귀 검사와 함께 수정했다. 다운로드 성공만으로 적용 성공을 판단하지 않는다.

시야 경계에서는 발밑이 보이는 불투명 물체의 실루엣만 발밑 조도로 합성한다. 가지가 미발견 타일 위로 뻗어도 잘리지 않으며 투명한 가지 사이는 원래 안개를 유지한다. 지형/생물의 가시성·지도 기억·Core FOV와 Y 정렬은 기존 경로를 사용한다. 반투명 가장자리의 안개를 두 번 지우지 않도록 alpha 보간을 적용했다. 소유한 캔버스 텍스처는 교체 때 이전 GPU 소스도 해제한다.

검증 장면은 유한한 초기 각인이다. 낮/어둠의 다섯 나무, 처음부터 장비한 꺼진 횃불, 나무 뒤 상자/물품과 행동 시각을 늦춘 적, 양쪽 눈이 없는 장면을 선언하고 실제 타이틀 불러오기 뒤 실제 입력으로 검사한다. 자연 수목 채집·적 조우·실명 획득 증거와 구분한다. 불러온 뒤 세계·몸·시간·난수를 주입하지 않는다. v0.306의 실제 일반 새 게임 저장도 그대로 불러오고 독립 Node 전체 상태 및 저장205 복원을 비교한다.

예비 실행은 보존한다. 최초 atlas 적용 누락, 적용 뒤 윗가지 잘림, 최종 합성 전 화면은 최종 통과 수에 합산하지 않는다. 독립 Canvas2D 검사 첫 실행은 tsx의 브라우저 함수 이름 보조자 누락으로 실패했고, 하네스 실행 환경을 수정한 별도 재실행에서 실제 프로덕션 합성 함수의 프레임/alpha/anchor/반전 경계14개를 통과했다. 전체 회귀와 두 화면 크기 검증 결과는 최종 검증 근거에 기록한다.

Core·콘텐츠·저장 형식·시야 수치·균형은 이번 묶음에서 바꾸지 않는다. 균형 회귀의 마지막 실측과 v1.0.0/X1–X4의 남은 완료 기준은 [출시 기준](v1-execution.md)에 유지한다.

## 최종 통합 검증

전체341파일 6,177개를 한 번의 전체 실행으로 통과했다(852.405초, 작업자2). 두 화면 크기 실제 수목/조명/숨김 검사24PNG·독립 전체상태30쌍·저장205 복원4회·실제입력1,000TU·오류0과 공통8PNG를 확인했다. 최종32PNG를 각각 열어 검토했다. 실제 발밑 조도·투명 가지 틈·낮/횃불·배율/저장 복원·숨은 상자/적·초기 실명 장면을 검토했다. 정적 고사목과 동적 소나무/검은잎나무 경로를 함께 검증했다. 독립 실제 Canvas2D14경계도 통과했다.
