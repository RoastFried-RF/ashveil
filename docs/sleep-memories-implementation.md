실제 needsTick에서 피로 회복에 사용한 것과 같은 수면 품질을 기록한다. 기록은 실제 수면 활동 중 잠든 턴에만 생기며 품질 백만분율의 평균·실제 맨땅 사용 여부·최대 내의 젖음을 보존한다. 품질 평균0.9 이상은 잘 잤다, 한 번이라도 맨땅을 썼으면 맨땅 기억, 내의 젖음50 이상이었으면 젖은 수면 기억이다. 임계와 기억 지속/효과는 Thought 데이터이며 모드 검증을 적용한다. 침구를 가방에 든 것만으로 침대가 되지 않는다.
