# 실제 깊은 물·호흡과 물가 구조

v0.93 / 각인v57의 구현 기록이며 전체95파일1,588개122.13초·관련5파일147개13.86초·타입/린트/Def86패치/Schema86/빌드를 통과했다. 실제 브라우저362~369/화면8장·네 차례 전체 각인v57 일치·콘솔0을 확인했다. 실제200TU 수영/같은 원본 사슬옷 탈의·원래 부상자/장비의3턴 구조·진행 중 구조 계속하기와 실제 숨 소진/의식 상실/익사 보고서를 검증했다. 부상자는 별도 초기 조건에서 실제 뇌 상처를 생성해 신체 계산으로 의식을 잃었으며, 구조 후에도 그 원래 부상/실신은 남는다. 별도370~371은 앞선 실제 완료 상태의 두 차례 시각 변화 없는 전체 계속하기를 확인했다. 미리보기 일부가 어둡게 보였으나 원본 PNG의 지형 픽셀과 실제 렌더링 데이터는 모두 정상이며 앱 렌더링 변경은 하지 않았다. 같은 원래 동결 빌드 월드30시드×최대3일265.405023938초·평균0.4219895833333334일·저체온19/치명상5/과다 출혈6으로30개 전체 행이v0.92와 같다.

설계01 §5.3과03 §7.3의 깊은 물 수영2턴/전신 젖음·착용 둔중 합2 이상 익사 위험을 연결했다. 기존 바다 깊은 물을 실제 수영할 수 있고 흐린 늪의 실제 깊은 누출수 웅덩이를 추가했다. 무게/과적을 판정에 쓰지 않는다(CANON D22). 지상 이동의 일반1턴 규칙은 유지하고 실제 얼지 않은 깊은 물만2턴이다. 물이 얼고 구멍이 없으면 기존 얼음 바닥이며, 실제 구멍은 수영이 필요하다.

수영은 작업 대사/열·실제 기력을 쓴다. 깊은 물에서 휴식으로 기력을 새로 얻지 않는다. 기력이 남고 움직임/호흡·의식이 유지된 가벼운 사람은 뜬다. 실제 착용 둔중이2 이상이면5턴마다35% 가라앉기 판정을 하며, 기력·움직임/호흡·의식이 부족하면 잠긴다. 기력이 남아 있는 동안 원래 무거운 장비를 벗으면 다시 뜰 수 있다. 배낭 속 짐을 무게로 변환하지 않는다.

잠기면 원래 호흡 기능에 따른20턴 숨을 먼저 사용하고, 숨이 바닥난 뒤 산소 부족이 쌓인다.20턴 산소 부족은 실제 익사 사망 원인이며, 의식 저하는 기존 신체 계산/실신과 실제 게임 스케줄러에 반영된다. 물가에 나가면 산소 부족은 턴당2씩 회복한다. 구조가 실제 뇌 손상이나 다른 상처를 치료하지 않는다. 이 추가 수치는 구현 제안값이며 CANON 상수를 바꾸지 않았다. 물을 삼킨 양/흡인성 질환·물살·침몰과 전체 물 생태를 구현한 것으로 집계하지 않는다.

플레이어와 NPC가 같은 규칙을 사용한다. 수중 호흡을 정의한 실제 환형동물은 이 공기 호흡 익사 모델에서 제외한다. 기계의 고장은 기존 별도 규칙이다. NPC의 자율적인 전체 구조 지휘/행동 계획은 별도 범위로 남는다.

구조자는 실제 물가에서 닿는 살아 있는 익수자를 기본3턴에 끌어낸다. 원래 환자·출발 위치와 원래 빈 인접 물가, 구조자의 위치를 묶는다. 환자/구조자가 이동하거나 원래 물가가 막히면 중단한다. 같은 사람/몸/장비를 옮기고 새 개체·물품·상처를 만들지 않는다. 실제 구조 중에도 환자의 호흡/신체 시간은 흐른다. F2와 신체 창에서 실제 잠김·남은 숨/산소 부족·현재 착용 둔중과 구조를 확인한다. 자동 행동은 새 잠김/숨 경고에서 멈춘다.

갑판 밖의 물에서 배를 원격으로 젓거나 항구 하선으로 빠져나갈 수 없다. 승선자는 같은 실제 갑판으로 돌아와야 해상 이동/하선을 시작할 수 있다. 원래 선체·화물·동행자 규칙은 유지한다.
