# 실제 식량 부족·충족의 공개 소식 — v0.298 작업 중

지난 완료일의 실제 공동 식량 소비가 부족해진 때와, 이후 실제 요청을 모두 충당한 때를 기존 주민 소문망에 공개 공고로 보낸다. 음식·돈·주민·정확한 부족 수량을 만들거나 플레이어 지식을 즉시 채우지 않는다. 마을의 실제 주민과 대화해야 현지 또는 실제로 도착한 소식을 듣는다. 기존 도로·봉쇄·거리·지연·왜곡·오래된 소식 만료를 그대로 따른다.

공고는 마을 이름·당시 날짜·배급 부족/충족 여부만 포함한다. 정확한 인구·재고·개별 주민의 병력은 공개하지 않는다. 계속 부족한 동안 매일 반복하지 않으며 처음 실제 부족과 다음 실제 충족을 별개 사건으로 기록한다. ‘충족’은 해당 날짜의 요청을 처리했다는 뜻이며 기근 해소나 미래 식량·건강을 보장하지 않는다. 사람이 없거나 식량 요구가 없는 마을은 회복됐다고 공고하지 않는다.

수급 정산과 모든 마을의 당일 봉쇄 처리가 끝난 뒤, 해당 완료일의 새 공고만 게시한다. 공고를 듣기 전후 원래 음식·UID·경제 수량은 기존 규칙을 따른다. `rumors.publicFoodSupply`는 별도 선택형 Def 패치다. 끈 모드에서는 게시 표식·전파 난수도 쓰지 않는다. 각인201→202는 버전만 바꾸고 과거 장부·공고·주민 지식을 소급하지 않는다.
