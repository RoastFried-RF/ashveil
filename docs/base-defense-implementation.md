# 실제 정찰 보고와 거점 습격·방어 — v0.70

거점이 생겼다고 적을 지도 가장자리에서 생성하지 않는다. 실제 현지 약탈자가 보관함을 보고 자기 집에 도착해 보고해야 출발 정보가 생긴다. 사망/실신·수면/포박/동료와 도주·항복 중인 사람은 정찰이나 준비 인원으로 쓰지 않는다. 보고 전에 플레이어에게 출발 계획/인원·좌표를 알리지 않는다. 새로운 `BaseDefense.Hearth`가 세력/출발지 경유점·범위, 첫 준비1일/이후1일·보고 후1시간, 확률35%, 실제2~3명, 제한2시간과 최대2묶음 약탈을 정의한다. 모드로 조정할 수 있는 후속 기본값이다.

같은 지도에 실제 집을 둔 살아 깨어 이동 가능한 인원만 모은다. 다른 작업/순찰·임무/동료/포로를 복제하거나 빼앗지 않는다. 기존 몸·배낭/장비·현금·소속/집과 출발 위치를 보존하고 보관함→원래 집의 실제 경로만 부여한다. 인원 부족/정찰 정보 없음은 난수/부대/물품을 만들지 않는다. 확률 실패도 다음 시도 시각만 정하고 반복 턴에 다시 추첨하지 않는다.

공격대는 실제로 한 칸씩 이동하며 기존 전투/신체·사기·항복/포박을 따른다. 실제 동료의 거점 방어가 공격대를 가로막고 같은 상처/기력·급료를 쓴다. 플레이어가 개입하지 않았다고 가상의 승리나 피해를 정산하지 않는다. 공격자가 실제 포로/동료가 되거나 항복/도주/사망하면 그 결과를 기록한다. 다른 지도의 인원을 죽거나 귀환한 것으로 세지 않는다. 원래 계단 추적은 유지하고 실제 다른 층으로 떠나는 사람은 원래 거점 임무에서 이탈한 것으로 기록해 그 지도에서 좌표를 따라 창고를 약탈하지 않는다.

보관함에 실제 도착해야1턴 약탈 행동을 수행한다. 최대2묶음을 가치순으로 살펴 실제10×6배낭에 들어가는 것만 옮긴다. 가득 차면 창고에서 빼거나 바닥 없는 보너스 수납을 주지 않는다. 원래 물품/상태·수량이 실제 배낭으로 옮겨지고 정상 쌓임 규칙을 쓴다. 한 번 약탈한 사람은 계속 같은 창고를 털지 않고 실제 집으로 돌아간다. 시간 안에 도착하지 못하면 실제 귀환으로 바꾸며 원격 약탈하지 않는다. 도난 기록은 이체 영수 기록이며 물품은 원래 인물에게 남아 회수할 수 있다.

출발·전투/귀환의 내부 결과와 플레이어가 실제로 본 소식은 따로 저장한다. 보이는 공격대/실제 창고 물품을 가져가는 장면·제압된 전원을 본 경우만 관측 기록과 로그를 만든다. 멀리서 실제로 약탈·귀환했어도 기존 관측 기록을 보이지 않는 결과로 덮어쓰지 않는다. F2의 거점 패널은 관측한 소식만 보여 준다.
