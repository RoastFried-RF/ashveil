# 마지막 실제 관찰을 그리는 월드 화면

v0.157은 기존에 저장하던 칸의 지형/관찰 시각을 세계 화면과 커서 설명에 연결한다. 닫힌 문 뒤에서 나무가 사라져도 마지막으로 직접 본 나무를 기억하며, 문을 실제로 열어 다시 관찰한 뒤 현재의 땅으로 바뀐다. 미탐색 칸은 실제 지형을 읽어 표시하지 않는다. 잠듦/실신/실명/사망 상태는 남아 있는 시야 배열로 현재 정보를 공개하지 않는다.

기억 속 지형은 그때 저장한 지형 종류만 보여준다. 과거 자료가 없는 상자 내용/개폐·바닥 물건·핏자국·화재·결빙·눈·수확 상태를 현재 값으로 채워 넣지 않는다. 현재 보이지 않는 불의 정확한 광원 위치와 화염도 표시하지 않는다. 구형 탐험 칸에 관찰 기록이 없으면 기존의 날짜 없는 표시를 유지하고, 과거 지형/시각을 추정하지 않는다. 화면과 커서 조회는 시간·난수·관찰·원본 물건을 변경하지 않는다.

저장 형식은120을 유지한다. v156의5개 고정 재생의 초기/최종 전체 상태·실패·해시가 모두 같아 기대값을 갱신하지 않았다. 전용15개/관련4파일65개 검사, 타입·린트·빌드가 통과했다. 브라우저777–782의6개 세계 캔버스/커서 설명을 모두 확인했다. 실제 오른쪽 입력2회로 이동1턴+문 열기1턴이 발생하고 같은 관찰 기록이 나무→땅으로 바뀌며,3개 전체 저장 복원과 휴식 저장 후 실제19턴의 전체 상태가 코어와 일치한다. 커서 조회 전후 전체 상태가 같고 콘솔 오류0이다. 초기 기억은 유효한 초기 탐험 기록이며 이전 탐험/나무 소실을 화면에서 실행한 것으로 쓰지 않는다.

전체 회귀와 월드는 v156 나무문 화재를 포함해 통합 검증한다. 전체 지도/함정 지도, 정지 지역의 과거 화재·건물 전체, 나머지 후속 확장은 계속 구현한다.


v0.156–157은 실제 생성된 집의 가연 나무문과 마지막 관찰을 그리는 월드 화면을 연결했다. 문을 열고 닫아도 같은 화재/부분 연료를 보존하고 실제 물500ml·1턴으로 끈다. 시야 밖 지형/상자/물건/화염은 현재 값으로 공개하지 않으며 다시 직접 보면 관찰을 갱신한다. 각인120·전용28/통합 전체161파일3,105개144.80초·타입/린트/Def224패치/Schema127·화면768–782의15개 해당 장면 전체 확인·11전체 복원/실제 재개19·16·19턴/콘솔0이다. 월드30판329.37853827199996초의30행 전체가v155와 같다. v156별도 전체검사/월드는 실행한 것으로 기록하지 않는다.
