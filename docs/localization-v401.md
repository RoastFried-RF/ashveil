# v0.401 개발 묶음 — 플레이 중 영어 표시

2026-10-28 KST. v400 뒤 Goal의 첫 구현 묶음이다. 현재 문서는 구현 중 기록이며 아래 클라우드·실제 화면 검증과 게시 근거가 채워지기 전에는 통과/배포로 보지 않는다.

## 변경 범위

- HUD의 체력/기력/경험치·반응·자세·전투·창 탐색·빠른 슬롯과 생존 막대의 수치/접근성 이름, 게임 화면의 조작 안내·도움말을 언어 선택에 연결한다.
- 캐릭터의 배경/특성·능력치·파생치/숙달과 능력 창의 갈래·학습 조건·도움말·공식·접근성 이름을 연결한다. 개인 이름은 원문을 보존한다.
- 콘텐츠는 `en-content.json`의 Def ID와 해당 필드의 정확한 원문이 일치할 때만 번역한다. 다른 모드의 같은 문구나 기존 ID의 바뀐 원문은 그대로 표시한다. 배경12/특성43/능력28의 label/description을 검토했다. 콘텐츠 개수는 전체 번역 완성률이 아니다.
- 기존 Shift 공식에서 분수 확률/효과 `0.5`를 `0.5%`로 오표시하던 것을 수정한다. 넘어뜨림50%/60%, 숨 고르기 기본 기력 회복50%·통증 감소50%로 표시한다. 실제 코어 판정과 저체온 조건은 바꾸지 않는다.
- 생존 막대와 캐릭터 파생치의 긴 영어 표시 공간을 조정한다. 물품/도감/기록 원문은 아직 전체 번역하지 않는다.

## 검증 계약

`tests/locale-gameplay.test.ts`는 ID/원문/모드 경계, 실제 로드 콘텐츠와의 대조, 언어 반응성, 백분율·모든 검토 능력 도움말, 실제 학습 거부, 표시 전후의 전체 저장 상태 보존을 검사한다.

`tools/inspect-locale-v401.ts`는 새 게임을 실제 타이틀에서 생성하고 1440×1080·1366×768·390×844에서 실제 창 열기·학습·초점·언어 전환·도움말·한 턴 대기·웅크림·자동 저장/복원을 실행한다. 각 단계의 브라우저 전체 World를 같은 설정으로 생성하고 같은 행동을 실행한 독립 Node 기대 World와 대조한다. 브라우저 세계/시각/난수를 불러온 뒤 바꾸지 않는다. 정상 렌더러가 소비한 FX만 대조에서 정규화한다.

`plan.py --locale --gameplay-locale`는 기존 v400과 새 v401 Native를 heavy로 순차 실행한다. 새 클라우드 브랜치 push의 기본 프로필은 release로 바꿔 앱 변경의 Full이 main보다 먼저 실행되게 한다. 수동 authoring 선택은 유지한다. Node24·pnpm9.15.9·frozen lockfile·설치된 Chromium, light 최대2/모든 heavy 단독 계약을 유지한다.

## 남은 범위

StatusStrip의 장소/상태 칩, 모든 다른 게임 창·물품 상세·동적 활동/판정/사건 로그·문헌·보고서 본문은 아직 한국어가 남는다. 번역하지 않은 원문을 감추거나 World/저장 로그를 덮어쓰지 않는다. Core/Def/이미지/모드/의존성·저장219는 이 묶음에서 수정하지 않는다. World30/원정1,000판·X1–X4의 실제 미완료 범위와 사람 평가 게이트는 [Goal](goal-v1.md)을 계속 따른다.
