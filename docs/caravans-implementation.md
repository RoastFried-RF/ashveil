# 실제 육로 교역단 — v0.94

정본 `design/09-world-and-simulation.md`의 교역 원칙에 따라, 이미 방문한 정착지에 실제로 존재하는 원래 상인과 최대 두 경비가 움직인다. 미방문 정착지에 교역용 인물을 새로 만들거나 독립적인 가상 화물을 만들지 않는다. 3일 주기의 출발 검사는 시간대별로 나눈다. 해당 상인이 자유롭고 깨어 있으며, 양쪽이 봉쇄되지 않고 적대 관계가 아니며, 실제 재고와 현금으로 양수의 예상 이익이 나는 육로가 있어야 출발한다.

예상 이익은 `(목적지 단가−출발지 단가)×수량−실제 경로 칸 수×2`다. 후보의 거리 하한을 이용해 불필요한 전체 경로 탐색을 줄인다. 가격은 현재 재고와 저장고를 반영한다. 예측은 거래 보장이 아니다. 실제 도착 시 물품 상태·신선도와 목적지의 당시 현금·가격·정치 상태로 다시 정산한다.

## 한 번만 존재하는 사람과 물품

출발 시 원래 시장에서 원본 물품과 유한 운전자금을 분리한다. 4×4 화물 격자와 개당 더미 상한을 적용한다. 온전한 더미는 기존 UID를 유지하고 일부만 나누는 경우에만 전역 물품 UID를 배정한다. 재질·품질·내구도·신선도·재 오염 등의 값은 보존한다. 이동 상점은 정기 재입고와 현금 보충을 하지 않는다. 거리 비용은 실제 동행 인물의 개인 현금으로 지급한다.

관찰 중인 도시는 원래 상인과 경비가 실제 출입구까지 걸어간 뒤 지도에서 빠진다. 관찰하지 않는 출발지의 보행은 저장된 지도에서 계산한 남은 경로 길이로 정산한다. 그 뒤 실제 월드 경로의 시간과 위치를 진행한다. 보관 중인 인물은 별도 인구로 생성하지 않으며, 주민 한도에 포함된다. 개인 음식과 화물 음식은 현재 무리의 월드 위치에 따른 기후에서 상한다. 화면 밖 생리 전체를 매 턴 처리하는 기능은 아니다.

같은 월드 칸의 바깥길을 지나면 원래 인물들을 현재 지도에 배치하고 보관 배열에서는 제거한다. 실제 시야에 들어온 무리만 지도 표식으로 표시한다. 인접한 실제 상인과 기존 거래 창으로 거래하며, 돈·물품·격자 한도를 적용한다. 재출발할 때는 남아 있던 이동 시간을 이어간다. 사망한 인물은 시체로 현장에 남고, 붙잡힌 인물은 실제 파티와 교역단에 중복 저장하지 않는다. 상인 사망·포획은 원래 화물과 이동 상점의 현금을 현장 시체/바닥·개인 현금으로 옮긴다.

## 귀환과 정산

목적지는 실제 시장의 유한 현금만 지급한다. 팔지 못한 화물과 받은 대금은 이동 상점에 남아 귀환한다. 출발지로 송금하지 않는다. 귀환한 원래 인물들은 도시 출입구에서 원래 상점·초소로 걸어간다. 모두 원래 자리 근처에 도착한 뒤에야 남은 화물과 현금을 원래 시장으로 반환하고 원래 업무를 회복한다. 관찰하지 않는 도시는 실제 지도 경로에 해당하는 시간이 지난 뒤 같은 인물의 위치와 정산을 처리한다. 출발지 봉쇄 중에는 입성을 기다린다.

각인 v58은 이동 경로·진척·대금·원래 거처·현재 단일 소유 인물과 화물·조우 중 남은 이동 시간을 저장한다. v57 이관은 버전만 바꾸며 과거 여행이나 인물을 만들어 내지 않는다.
