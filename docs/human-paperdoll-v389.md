# v389 실제 몸·착용 표현 작업

2026-10-26 KST. v388 감사의 QA-ART-01을 이어서 구현 중이다. 일반 인간형의 실제 몸·착용 표현을 연결하는 작업 기록이다. v1.0 출시 수락이나 모든 인체 변형 완료를 뜻하지 않는다.

## 원본과 소유

- v381 자체 인체 원본의 유효28영역, v386 자체 봉제 패널8영역을 재사용한다. 실패한 shorts-thigh4영역과 당시 보정 거절 기록은 그대로 보존하고 사용하지 않는다.
- 새 원화4PNG: torso16 + limb32 + accessory32 + 역할 머리20 =100원본 영역. 머리 첫 요청은 참조6개가 도구 상한5개를 넘겨 생성 전 입력 검증에서 거절됐고 PNG0이었다. 별도로 허용한5참조 요청1회만 성공했으며 자동 재시도는 하지 않았다. 원문 바이트와 정확 요청/참고/실패·alpha/방향 판정을 보존한다. 원본 PNG의 픽셀 편집·재인코딩은 하지 않는다.
- 25개 실제 의복 ID는20부품 종류와 명시한 재질 tint/형태 공유에 연결한다. 25개의 고유 의상이나 새 보행80프레임이 아니다.
- 6개 기존 의수족 물체 원문은 한 시점의 실제 물체를 공유한다. 네 방향의 숨은 면이나 독립 의수족 동작 원화를 제작한 것으로 세지 않는다.
- 손·전완, 발·정강이는 같은 원문을 실제 소유자별 런타임 반평면으로 나눈다. Chest/Abdomen/Pelvis도 원래 결합 원문의 분할 표현이며 독립 원화가 아니다. 기본 봉제 패널은 수치 효과 없는 내의이며 새 Item/방어구를 추가하지 않는다.

## 구현과 검토 중 발견

- 순수 표현 발 접지 제어 `human-gait.ts`와 집중11검사를 완료했다. 세계 root는 이미 보간된 좌표를 받으며 다시 보간하지 않는다. plantId/epoch로 접지 소유 구간을 구분한다. 실제3D 균형·충돌 검증이 아니다.
- `humanSurfaceState()`는 실제 의복·부분 내구/반착용/안감과 결손/보철을 읽고, 방어 그룹 없는 화살통·apparel없는 부적/반지도 실제 슬롯/UID로 별도 전달한다.
- 최초 실제 입력 검토는 기본 몸/코트 차림4방향씩8전체 상태 쌍·브라우저오류0이었다. 정지 팔의2-link 굽힘 방향이 몸 안쪽으로 향해 팔이 교차하는 것을 직접 발견했고, 화면 방향별 바깥 굽힘과 자연스럽게 늘어뜨린 목표로 수정했다. 첫 캡처는 보존한다.
- 새 원문의 옷 안쪽은 실제 어두운 안감으로 불투명하다. 투명 개구부라고 기록하지 않으며, 실제 목·팔·얼굴의 전후 가림으로 조립을 검토한다. 가짜 투명 PNG나 새 피부 픽셀을 만들지 않는다.
- 개발 서버의 hot reload가 수정 중 캡처를 다시 로드한 관찰은 통과로 세지 않는다. 최종 게임/저장/화면 수락은 변경을 동결한 빌드에서 다시 수행한다.

## 추가 발견과 보정

- 다리의 고정 길이 가상 관절은 접지 원문에 최대 약11px 오차를 만들었다. 화면의 발바닥을 보존하는2D cutout 관절 투영으로 바꿨다. 다리의 축 방향 길이는 변하며 고정 뼈 길이·물리적3D 접지가 아니다. 팔은 원문 길이의2-link 도달 제한을 사용한다.
- 전완 뿌리를 팔로 인식하지 못하던 대소문자 분기를 수정했다. Pioneer 손 전용·Articulated 발 전용은 기존 단일 물체의 말단 영역을 별도로 등록하며 새 의수족 원화로 세지 않는다. GlassEye의 전체 물체 지름을 기준으로 배율을 제한한다.
- 독립 검토에서 측면 후드의 얼굴 앞그림이 머리카락까지 복원하는 문제, 측면 화살통의 앞쪽 부착, 투구의 지나친 크기, 고글·마스크·허리띠의 잘못된 축 해석, 앞치마 밑단 잘림을 발견했다. 원문 부착점을 다시 측정하고 소유별 가림/등 위치/앞치마의 골반 소유 밑단으로 수정한다. 원본 PNG 픽셀을 바꾸지 않는다.
- 일반 인간형10개 등록은 실제 장비 UID/부위/내구/반착용/안감과 같은 renderer를 사용한다. 주민·치료사·상인·경비·약탈자의 새4방향 머리를 공유 몸 위에 조립한다.20개의 새 전신 모델이나 동작 프레임이 아니다. 머리 원문의 alpha1 잔상과 추정 목·얼굴 경계는 그대로 기록한다.
- 공개 `artbook/human/` 작업대는 실제 HumanView를 쓰되 합성 상태만 표시한다. 기존 도감의 결합 전신 그림에는 이전 원문 참고 표시와 작업대 링크를 붙인다. 초기 도구의 잘못된 directory URL·관찰 JSON 범위·얼굴 다각형 꼭짓점 개수 가정 실패는 원문을 보존하고 수정했다.
