# 실제 신체 변화의 유한 기억

v0.142 통합 검증 완료. 실제 손·발 등 팔다리 상실−20/30일/4×0.6와 손가락 상실−6/10일/5×0.5를 구분했다. 모두 선형 감쇠한다. 실제 새 절단면이 만들어진 부위만 기억하고 손 하나를 잃었을 때 다섯 손가락 사건을 꾸미지 않는다. 전투의 실제 절단과 완료한 의료 절단이 같은 규칙을 사용하며 기존 전투 중복 기록을 제거했다. 귀/코 등의 기존 일반 기억과 과거Maimed Def는 유지한다. 구형 기억의 실제 값/기간을 새 팔다리 기억으로 재작성하지 않는다.

새로 생성되거나 실제 더 심해진 치유 흉터는 몸−2/얼굴−5/허영 얼굴−10의5일 선형 기억이다. 모두 같은3×0.5 중첩을 공유한다. 얼굴 구분은 Thought의 faceEvent 그룹/값/특성 키로 수정할 수 있다. 아물기 전의 소작 예정 상처/원래 흉터/같은 옛 흉터의 재개방 후 같은 치유를 새 흉터로 세지 않는다. 기존 허영의 영구Temperament.Scar를 제거하여 같은 흉터에 중복 벌점을 주지 않는다. 실제 흉터의 신체 후유증과 첫인상 효과는 그대로 적용한다.

초기 장면은 실제 치유 마지막 단계의 상처로 만들고 공개 대기1턴이 흉터를 남긴다. 절단은 원래 칼UID70과 초기 실제 지혈대를 사용한 공개 시술이다. 기본60턴에 현재 신체의 시간 계수1.2가 적용되어 실제72턴이다. 마지막 시술은14471턴에 상실 기억을 만들고14472턴에 반환하므로 원래 선형 절삭 규칙에 따라 표시−19/남은863999턴이다. 미완료1턴에서 재개하면71턴만 남는다. 실제 칼 마모100→99/같은UID/새 절단면과 몸·난수·시간 전체를 비교한다. 이미 남아 있던 얼굴 흉터는 유효 초기 장면이며 과거 치유를 시뮬레이션했다고 주장하지 않는다.
