# v0.318 개발 미리보기 — 거점 완성품 최소 재고

거점 동료에게 기존 유한 제작 횟수에 더해, 같은 품목의 완성품 최소 재고 유지를 맡길 수 있다. F2의 현장·야영 → 거점에서 제작법/수량을 고르고 ‘완성품 최소 재고 유지’를 선택한다. 지시는 기존 곁의 대화·거점 소유권/안전·유급 동료 확인과1턴 비용을 쓴다. 새 선택을 요청한 작업에만 BaseTask.craftTarget을 기록한다.

실제 거점 보관함과 해당 작업자의 배낭에 있는 같은 완성품 개수를 합해 부족한 양을 계산한다. 배낭의 완성품을 먼저 같은UID/실제 공간 검사로 창고에 나른다. 부족하면 실제 창고 재료를 꺼내 원래 제작법·작업장·노동·급료·몸/식사/수면·품질·원재료 예약을 사용해 한 묶음씩 만든다. 재료·작업장·공간이 없으면 기존 방식으로 기다린다. 다른 지역 재고나 미래 완성품을 만들어 세지 않는다.

실제 재고를 목표 이상 채우면 새 제작을 시작하지 않고 대기한다. 플레이어가 꺼내 쓰거나 다른 실제 행동으로 줄어들면 동료의 다음 정상 작업 판단에서 부족분을 다시 계산한다. 이미 시작한 배치는 마치며, 한 배치의 출력 개수 때문에 목표를 넘을 수 있다. 여러 작업자가 같은 품목을 만들 때도 전역 예약으로 양을 나누지 않으므로 동시 배치만큼 초과할 수 있다. 목표는 개수 기준이고 품질·신선도를 구분하지 않는다. 자기 배낭의 해당 품목도 기존 납품 경로대로 창고로 옮긴다.

기존 즉시 제작법 중 동료가 알고 있고, 같은 물품을 입력으로 다시 소비하지 않는 개수 제작을 지원한다. 지연 숙성 제작은 포함하지 않는다. 목표는 기존 maxBatches 범위의1 이상 정수다. 잘못된 목표/원래 보관함/수량은 작업을 시작하지 않는다. 상태 조회는 목표나 재료를 수정하지 않으며, 실제 NPC 작업 판단에서만 파생된 남은 배치 수를 갱신한다. 목표 변경·유한 제작으로 전환·취소는 기존 같은 원본 작업 진행 보존/취소 규칙을 따른다. 별도 우선순위 작업 대기열·원격 주민 노동 전체는 남는다.

저장208을 추가했다.207→208은 헤더만 옮기며 기존 유한 제작을 반복 명령으로 추정하지 않는다. 원래 몸/가방/재고·UID·완성/미완료 작업은 유지한다. 새 필드가 없는 명령의 기존 경로는 동일하다.

타입/대상 린트·Def 로드를 확인했고 빌드를 준비했다. 새로운 목표의 실제 부족→인출→제작→납품→대기→재인출/재개, 조회 불변·원자적 실패·동시 작업/부분 진행·208/207 전체 복원·실제 UI·전체 회귀/월드는 후속 검증이다. 사용자 지시에 따라 구현을 우선한다.317 동료 의료와313–315의 새 경로 검증 대기도 유지하며, v1.0.0 완료를 뜻하지 않는다.
