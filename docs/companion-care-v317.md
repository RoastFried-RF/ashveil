# v0.317 개발 미리보기 — 동료의 현장 응급 처치

X1의 동료 간병 중, 플레이어가 곁의 동료에게 붕대·상처 세척·부목을 부탁하는 경로를 구현했다. 기존 `treat`/`careWait`와 원래 물품·신체·의료 시간·중단 규칙을 사용한다. 새 저장 필드를 추가하지 않아207을 유지한다. 이 문서는 구현 상태이며 실제 UI/완료/복원 검증은 후속이다.

N 주민·세력 → 해당 동료 → 동행·급료 → 응급 처치 부탁에서 자신의 외부 상처와 가능한 처치를 선택한다. 동료의 실제 물품 이름·예상 시간·현재 예상Q를 검토한 뒤 시작한다. 자기 배낭에 있는 관련 의료 물품을 기존1턴/한 묶음 전달 행동으로 먼저 건넬 수도 있다. 정보 조회/선택/취소는 시간이나 물품을 쓰지 않는다.

같은 현장의 살아 있고 깨어 있는 유급 동료·서로 보고 들을 수 있는 대각 차폐 없는 곁·처치할 조명/시력을 요구한다. 다른 활동/거점 작업/회수 임무나 교전 중에는 새 부탁을 받지 않는다. 동료 자신의 출혈·허기·갈증·피로·체온이 급하면 먼저 자기 몸을 돌봐야 한다. 임의의 주민/급료 대기자나 원격 인물에게 명령하지 않는다.

동료의 배낭과 접근 가능한 실제 주머니에서 같은 처치 종류의 깨끗하고 남은 사용량/내구가 있는 물품을 고른다. 도구 보정이 높은 것, 같으면 UID순이다. 빠진/오염된/반착용 물품을 대체 재료로 만들지 않는다. 조회는 시술자 활동과 로그의 사본에 기존 startTreatment를 적용하며 원래 물품/몸/시간/난수/기록을 변경하지 않는다. 시작 직전에 같은 원본UID·시간·예상Q를 다시 확인한다. UI가 오래됐으면 다시 선택해야 한다.

요청 성공은 즉시 시술자의 실제 `treat`와 플레이어의 `careWait`를 연결한다. 요청 자체는 기존 진료처럼0TU 활동 시작이고, 기다리는 동안 동료의 실제 차례와 다턴 작업·양쪽 대사/출혈/환경이 진행한다. 돈·의료 물품·치료된 상처를 새로 지급하지 않는다. 물품을 잃거나 환자가 대기를 그만두면 기존 외부 처치 규칙으로 중단한다. 완료에만 같은 실제 물품1회분을 쓰고 현재 시술자의 손·의료 숙달·빛/환경으로 품질과 효과를 계산한다. 미리 본 Q는 완료 보장이 아니다.

붕대/세척을 중단하면 완료 효과를 남기지 않는다. 부목은 기존 절반 진행 규칙을 따르므로 중단했어도 반쪽 부목과 실제 물품 소비가 남을 수 있다. 동맥 출혈은 붕대만으로 멈추지 않는다고 안내한다. 수술·약물·마취·지혈대 판단·무의식 구조/자동 간병·동료끼리의 원격 진료는 이번 경로에 포함되지 않는다. 완료된 기본 처치의 숙달·품질·환자 이력은 기존 의료 엔진이 기록하며 별도 성공 기록을 미리 만들지 않는다.

구현 중 타입/대상 린트·기존 Def 로드를 확인하고 게시용 빌드를 준비한다. 새로운 코어 행동의 전체 불변 조회·원자적 실패·물품/UID 보존·부분 부목/중단/새로운207각인 복원·실제 두 화면 크기·전체 회귀/월드는 아직 실행하지 않았다. 사용자 지시에 따라 기능을 먼저 연결하고 통합 검증은 뒤로 모은다.316의 제한된 실제 이동/광원 진단이나312의 전체 통과를317 새 기능의 검사 결과로 대신 쓰지 않는다. X1 전체 또는 v1.0.0 완료 주장이 아니다.
