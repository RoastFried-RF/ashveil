# 현재 실행 중 세계의 데이터 모드 재적용 — v0.270

설계11 §9의 개발 중 콘텐츠 재적재를 F3 설정의 ‘플레이 중 모드 검토·적용’에 연결했다. 실제 가져오기/설치와 현재 모드 선택·순서를 사용하고 기존 각인 불러오기와 같은 상세 검토 화면/이행 함수를 공유한다. 현재 실제 World의 원문 상태와 DB 객체/목표 내용 해시·사적으로 보관한 선택에 묶어 검토한다. 파일 설치/검토/취소는 현재 DB/세계/각인을 바꾸지 않는다. 제거한 파일이 선택 목록에서 사라져도 미설치 선택 체크박스로 명시 해제 후 제거 구성을 검토할 수 있다.

승인은 현재 World 객체/원래 DB 객체·원문 전체와 최신 패키지·스크립트 준비 뒤 실제 DB 해시/입력 가능 상태를 재검사한다. 디스크에서 오래된 각인을 읽지 않고 현재 상태의 소유 후보에 기존 Item/상태/사건/몸/생물 이름 이행·삭제 처리를 적용한다. 실제 현재 시각/몸/물품/개체/UID/난수와 과거 기록을 보존하며, 삭제가 필요한 값은 동일한 검토/명시 승인 정책을 따른다. 새 세계/과거 시뮬/정착지 주민 생성/이전 훅 재실행으로 데이터를 채우지 않는다. 현재 시야는 새 정의로 정상 갱신한다. 같은 구성은 원본/업적/저장을 다시 쓰지 않는다.

모든 후보 검사가 성공한 뒤 실제 DB/상태를 함께 적용하고 기존 구성 변경 이력·연대기/업적 비활성 상태와 한 번의 각인 저장을 수행한다. 저장 실패는 적용 사실과 저장 실패를 명확히 알리며, 같은 승인을 동시에 두 번 실행하지 못한다. 원래 헤더가 없는 생애는 현재 구성 기록 시작이 먼저 필요하다. 아직 지원하지 않는 이행/스크립트 소스 교체는 기존 안전한 거절을 유지한다. 이 버전은 데이터/스크립트 패키지의 현재 지원 범위이며 언어/텍스처 자산 HMR까지 완료했다고 주장하지 않는다. 새 Def/Item/각인 형식/API 변경은 없다.
