비활성/없는 loadAfter/loadBefore 대상은 무시하고 자동 활성화하지 않는다. 빠진 필수 의존성은 오류다. 같은 간선을 여러 필드에서 선언해도 한 번 계산한다. 혼합 순환·자기 순환·core보다 먼저 적용하라는 모순은 실제 순환 경로와 함께 거절한다. 오류 DB는 추가 정의 검사에만 쓰며 실제 시작/승인은 기존 report.errors 보호가 차단한다. 잘못된 네 종류 의존 목록은 문자열 분해나 예외 대신 명확한 로드 오류로 보고한다. 패키지 도구도 loadBefore를 확인한다.
