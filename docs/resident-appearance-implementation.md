# 주민 전용 표시와 실제 알약 외형

v0.288 작업 중. 주민과 플레이어가 공유하던 hero 원본은 보존하고 resident_worker의 새28포즈를 연결했다. CreatureDef.characterAliases는 저장된 sprite를 바꾸지 않고 현재 Def의 한 단계 표시 대응만 읽는다. Settler의 hero→resident_worker를 자손이 상속하고 정착한 옛 떠돌이의 hero→hero는 과거 플레이어 외형을 유지한다. 다른 저장된 외형·플레이어 Drifter·몸/장비/수량·이름/관계·인원/난수/시간은 바꾸지 않는다. 같은 개체의 표시 대응이 현재 데이터 재적용으로 바뀌면 렌더 뷰만 다시 만든다.

알약6종은 기존 pill_white/yellow/blue/black/green/magenta 키를 유지하면서 직접 그린 무광 정제/캡슐을 읽는다. 물약병·포장·효과별 표식·조건부 변질단서를 기본아이콘에 넣지 않았다. 실제 효과는 기존 시드 대응/더미 보존 상태를 따르고 아이콘으로 정답을 주지 않는다. 새 Item/Recipe는 없고 각인195를 유지한다.

Root가 주민/알약 접촉시트를 직접 열고 격리 원본을 그대로 복사했다. 원본/재현은 tools/art/draw-resident.py 및 tools/art/pills/draw-pills.py다. 현재 코드 작성 단계이며 관련·정적/골든/브라우저/전체 회귀는 아직 남아 있다.287검증 결과에 포함하지 않는다.

첫 전용7개는6통과/1실패였다. 기존 Def 상속의 null은 필드 삭제라는 정본 규약이므로 이를 잘못된 별칭 구조로 단정한 새 테스트를 고쳤다. 실제 null삭제/원래외형복귀를 별도 전체 상태 불변 검사로 추가하고 배열/숫자/빈키/빈값 거절은 유지했다. 제품 로더의 삭제 규약은 바꾸지 않았다.

의원 원본28포즈도 직접 검토·연결했다. SettlementDoctor의 hero→resident_healer를 두 간병인자손이 상속한다. 기존char선택은 세종 모두hero로 보존한다. 실제 새패치3개로300패치/정의884/물품206/제작법88이며CLI의합계단정만300/305로갱신했다.

두 번째 전용8개와 의원자손을 더한 관련2파일13개를 통과했고 첫 타입 검사도 통과했다. 실제 Native는6장/195전체복원2/400TU의 유한초기/실제입력 시나리오를 작성했으나 아직 실행하지 않았다. 경비/상인 원본도 같은묶음으로 준비해 전체/브라우저 검증을 한 번에 진행한다.287 전체5,863개 결과에288을 포함하지 않는다.

경비 네 종과 상인 세 종에도 원래 hero를 보존하는 별칭을 연결했다. 이제 주민·의원·경비·상인 네 역할이 다른 원본을 쓰며, 정착한 옛 떠돌이는 본래 외형을 유지한다. 총 패치302개이며 각인195/API1.4.0을 유지한다.

최종 관련2파일15개, 빌드/Vue타입, 린트0오류·기존원본도구 unused mirror 경고1개, Schema162파일·독립검사0오류, 실제Defs884/Items206/Recipes88/PATCH302를 확인했다. 골든5개 전체 초기/최종/오류는 두 콘텐츠해시 경로 외287과 완전히 같고287벡터를 한 번만 보관했다. 상인재현단독이동은 SOURCE 의존으로 실패하여 원래12파일 묶음을 tools/art/trader에 보존한 뒤9개 출력 재현을 통과했다. 석판 원본도 같은288 묶음에 포함했으며8파일 재현을 확인했다. 검증기 pnpm출력의 안내문구가 포함되어 첫 요약JSON파싱은 실패했고 실제 CLI본체 JSON을 분리해 재확인했다. 원래 검사 명령은 성공했다. 동결 v288-native의 실제 입력 검증은 진행 중이다.

실제6PNG를 Root가 모두 열었으며 전체195복원2/6전체단계 대조/400TU/오류0을 통과했다. 주민·의원·경비·상인 네 표시와 옛 떠돌이·플레이어 원래hero, 알약¼시음/¾섭취·원래6더미, 석판/Cd경계를 유한초기각인에서 검증했다. 공통 실제새게임은 두 크기11입력/4장씩/200TU/오류0이며 모든 게임snapshot 전체가 두 화면에서 같고 최종관찰도 전체상태를 바꾸지 않는다. 타이틀 시작버튼은 스크롤 없이 전체표시·클릭가능하다. 동결Native와 최종직전 제품src/dist/public/mods/tests/tools/.agents 바이트가 모두 같다. 독립14PNG 검토와 전체회귀는 별도 진행한다. 이번 변경은 표시 전용이며 실제 밸런스 변경이 없어 중복월드30판을 별도 실행하지 않고 기존월드포함5골든전체대조를 적용한다.
