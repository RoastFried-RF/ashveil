# 인간NPC의 사건형 정신 요약

v0.132. 정본04 §14에 따라 일반 인간NPC는 전체 사고와 시간당 기분을 저장/계산하는 대신 실제 사건마다 스트레스를 정산한다. 동물/기계의 직접 정신 호출에도 인간 사고/고양/붕괴를 만들지 않는다. 기계의 기존20턴 오류 루프는 유지한다. 플레이어 진영의 인간 동료는 기존 전체 정신 규칙을 쓴다.

NpcPsyche.Human의 모드 가능한 기본값은 부상5/위기15/아군 사망15/우두머리 사망30/인간 살인4/좋은 치료−2, 실제 유한 생활 사건의 특성 적용 기분×−1, 최근16건이다. 정본에 별도 NPC 수치표가 없어 이 기본값을 데이터로 분리했으며 새 확정 규칙으로 문서를 바꾸지 않는다. 신경과민/강철 의지·다정/냉혈 등 기존 특성을 적용한다. 같은 턴 부상은 중복하지 않고 서로 다른 사망은 각각 기록한다. 목격할 수 없는 사망에는 정신 사건을 넣지 않는다. 기존 즉시 사기와 병존한다.

사건에서 같은 붕괴 공식/BreakDef 가중치로 고른 뒤 선택된 반응만 보류한다. 들어오는 부상/치료 정산이 끝난 뒤 다음 NPC 처리에서 시작하고 기존 채널을 중단한다. 실신/수면 중에는 실제로 깬 뒤 시작한다. NPC별 body.npc.ID 난수 스트림을 사용한다. 같은 AI의 도주/식량 거부/자원 소비/해소를 실행하고 숨은 NPC 로그로 이름/상태를 누설하지 않는다. 화면에는 보이는 인간의 현재 불안정한 행동과 머리 위 보라색 표식만 보여 주며 비공개 스트레스 수치를 노출하지 않는다.

각인v96은 실제 기록된 요약/보류 반응/난수를 이어가며 구형에는 과거 사건을 채우지 않는다. 전용30개와 관련7파일214개 검사, 타입/린트/Def180패치+NpcPsyche1/Schema109/빌드 통과. 다섯 골든 초기 전체는 버전96 외에 같다. 최종3개 전체도 같으며 나머지2개는 실제NPC 스트레스/요약·전용난수와 해당NPC의 붕괴 기록/가시적 로그2건만 달라졌다. 플레이어 몸/기존body·ai 난수와 다른 전체 상태/오류는 같다. 실제 화면622~627 여섯 장 전체 확인·6전체 각인 복원·콘솔0이다. 초기 긴장30/85인 일반 상인이 실제 아군의 출혈 사망을 목격한 뒤45/100이 되고, 후자는 실제 단식으로 원래 포장을 먹지 않는다. 정상 NPC는 자기 배급 포장 UID85를 실제 먹어 같은 빈 포장을 남기고 스트레스20→11이다. NPC 환자는 자기1000에서8을 내고 같은 의사의 의료 가방 UID1099511628316의5회분 중1회분으로5턴/Q65 붕대를 받아 실제 부상25→치료23이다. 미완료 NPC치료는 타이틀/재시작으로20턴 재개한 전체 몸·현금·물품·요약이 순수 엔진과 같다. v0.132에서는 일반 인간형NPC의 실제 사건별 스트레스·같은 붕괴 규칙/AI·독립 난수·유한 자원/치료와 동물·기계의 인간 정신 제외를 연결했다. 각인v96·전용30/관련214개·전체134파일2,568개123.08초·타입/린트/Def180패치+NpcPsyche1/Schema109/빌드·화면622~627 여섯 장 전체 확인·6전체 복원/실제NPC20턴 재개/콘솔0이다. 월드30판281.773600432초 중21행 동일/9행 NPC 정신 연쇄 변경이며, NPC스트레스 설정만0으로돌린30판전체가이전과같다.
