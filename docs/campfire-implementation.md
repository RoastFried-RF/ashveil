# 직접 설치한 모닥불의 실제 점화·유한 연료와 동료 보급 — v0.74

돌3개·목재1개와 실제 제작 노동으로 야영 모닥불 꾸러미를 만든다. 빈 땅에 설치하면 같은 UID와 소유자를 가진 차가운 화덕만 생긴다. F2에서 배낭의 실제 땔감을 선택해 점화하거나 불을 끈다. `Campfire.Hearth` 기본은 목재1개당2400턴(2시간), 최대7200턴(6시간)이다. 꾸러미 재료를 땔감으로 중복 계산하지 않는다.

불씨가 없으면 마찰 점화 기본100턴, 불씨에 땔감 추가는 기본3턴이다. 점화와 거점 정비는 실제 작업 대사·체온 활동으로 계산한다. 몸·어둠 등 기존 다턴 배율을 쓰며, 젖음60% 이상 목재는 노동이3배다. 작업 완료에만 실제 목재1개를 소비하고 불빛/열과 연료 기한을 얻는다. 도중 중단·물품 유실·실제 불 교체·손 상태 변화는 열이나 땔감을 만들지 않는다. 짧은 땔감 추가 도중 불씨가 사라지면 실제 긴 점화를 다시 한다. 불을 직접 끄면 남은 연료를 돌려받지 않는다. 기존 토글로 새 모닥불을 무료 점화하지 못한다. 완료한 불 다루기는 기존 불 트라우마 극복 규칙에도 연결된다.

연료는 절대 소진 시각으로 보존한다. 활성 지도에서는 몸·수면/보온 계산 전에 만료를 처리한다. 떠난 지도는 재진입 시 경과한 기한을 처리하며 불씨 시간을 정지시키지 않는다. 소진된 불은 실제 빛/열을 주지 않는다. 새 설치와 소진을 동적 지도 그림에 반영했고, 꺼진 불에 불꽃/주황빛이 남지 않게 했다. 기본 지역에 원래 배치된 장면용 화덕은 기존 규칙을 유지하며, 이 버전의 유한 연료는 실제 꾸러미로 설치한 모닥불에 적용한다.

거점에서 곁의 동료와 실제 모닥불을 골라 관리를 맡긴다. 급료가 유효한 동료가 실제 창고로 걸어가 목재를 확인·인출하고, 실제 불 바로 곁으로 운반해 공통 점화/땔감 추가를 한다. 기본 최소2시간을 유지하려 하며 연료가 없으면 기다린다. 원격 공급이나 새 목재는 없다. 불 UID·소유권/반경·경로·모서리·몸·급료·위협과 명령 취소를 검증한다. 급료 만료/취소는 진행 중 목재를 소비하거나 열을 주지 않는다. 생존·피로와 기존 휴식은 계속 적용된다.
