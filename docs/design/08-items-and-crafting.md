## 0. 결론 요약

- 아이템 = **형태(ItemDef) × 재질(MaterialDef) × 품질 × 상태(내구·날·습기·부식)**. 같은 "손도끼"도 연철/강철/폐합금, 조악/명품, 녹슨/정비된 상태로 전부 다른 물건이다.
- 아이템은 소모되는 게 아니라 **늙는다**. 날이 무뎌지고, 활시위가 젖고, 재비에 녹슬고, 수리할수록 최대 내구가 줄어든다. 정비가 원정 루프의 일부다.
- 현재 세계는 원시~중세만 생산한다(CANON §3.3). 개척·정원사 물품은 **발굴만** 가능하고, 감정·수리에 지식과 희귀 부품이 든다. 이 격차가 경제와 욕망을 만든다.

## 1. 목적 / 설계 의도

| 의도 | 플레이어 결정 |
|---|---|
| 재질이 성능을 정한다 | "강철 칼 하나 vs 연철 칼 둘" — 가치·칸(둘이면 4칸)·정비 비용 비교 |
| 장비는 정비 대상 | 원정 배낭(13)에 숫돌·밀랍·기름·바늘 칸을 둘지, 그만큼 식량 칸을 뺄지 |
| 층(layer)이 생존을 정한다 | 망토를 갑옷 위에 걸칠지(부식 방지·단열·소음 −1) 벗을지(착탈 턴, 배낭에 넣으면 4칸) |
| 희소성이 가치를 만든다 | 탄 한 발을 쏠지, 팔아서 사흘 치 식량을 살지 |
| 제작은 운이 아니라 조건 | 좋은 도구·작업장·재료를 모아야 좋은 품질이 나온다 |

## 2. 아이템 Def 공통 구조

```json
{
  "defType": "ItemDef",
  "id": "Item.HandAxe",
  "parent": "Item.MeleeWeaponBase",
  "label": "손도끼",
  "category": "Weapon",
  "tags": ["Tool.Chopping", "Weapon.Axe"],
  "techLevel": "Medieval",
  "grid": { "w": 2, "h": 2, "rotatable": true },
  "volumeCm3": 420,
  "massFixedG": 350,
  "stuffSlots": [
    { "id": "head", "accepts": ["Metal", "Stone"], "volumeCm3": 70, "role": "Primary" },
    { "id": "haft", "accepts": ["Wood", "Bone"], "volumeCm3": 350, "role": "Secondary" }
  ],
  "durabilityBase": 80,
  "valueBase": 24,
  "stackLimit": 1,
  "comps": {
    "weapon": "Weapon.HandAxe",
    "edge": { "dullingPerHit": 1 },
    "corrosion": true
  },
  "craftedBy": ["Recipe.ForgeHandAxe"],
  "salvage": { "recoverable": ["head", "haft"] }
}
```

| 필드 | 설명 |
|---|---|
| `stuffSlots` | 재질 슬롯. `Primary`가 피해·관통을 결정, 모든 슬롯이 질량·내구에 기여 |
| `grid` | 칸 크기(가로×세로). **정본은 13 §4** — 08은 칸을 정하지 않고 13 표의 값을 옮겨 쓴다. 재질·품질·상태는 칸을 바꾸지 않는다(강철 손도끼도 연철 손도끼도 2×2) |
| `volumeCm3` / `massFixedG` | 슬롯 부피 × 밀도 + 고정 질량(끈·리벳) = 총 **질량**. 재질 계산 전용(타격 배율·분해 회수·재료 상속). 소지 제약·무게 표시에는 쓰지 않는다(D22, 13 §12) |
| `techLevel` | Primitive / Medieval / Industrial / Pioneer / Gardener. Pioneer·Gardener는 `craftedBy` 금지(검증 CLI가 차단) |
| `comps` | 기능 컴포넌트: weapon, apparel, edge, bowString, corrosion, firearm, container, food, relic, history |
| `valueBase` | 기준 재질·보통 품질의 기준가(표) |

인스턴스 상태(세이브에 저장): `defId, stuff{slot: materialId}, quality, durability, durabilityMax, edgePct, moisture, corrosion, fouling, partDurability{part: pct}, identified, historyId`.

- **폐합금**: 개척 시대 구조재 고철. 가볍고 단단하지만 **산업 작업장**(고열 단조) 없이는 가공 불가 → 재가공 가능한 유일한 개척 재질. 정원사 합성재는 가공 불가(발굴품 그대로만).

### 3.2 재질 → 무기 성능

```
베기·찌르기 피해 배율 = (날카로움 + 50) / (기준 재질 날카로움 + 50)       기준 = 무기 Def의 refStuff
타격 피해 배율       = clamp(0.7, 1.5, sqrt((밀도 + 1) / (기준 밀도 + 1)))
관통 보정            = floor((경도 − 50) / 5)                              (음수 내림)
질량(g)              = Σ(슬롯 부피 × 밀도) + 고정 질량                     (재질 계산 전용, 칸과 무관)
최대 내구            = floor(내구 기본 × 인성 / 50)
```

| 재질(칼날 기준 연철) | 피해 배율 | 관통 보정 | 비고 |
|---|---|---|---|
| 강철 | 125/105 = **1.19** | +4 | 정비 부담 적음(경도 높아 덜 무뎌짐) |
| 청동 | 1.00 | −1 | 녹 적음 |
| 부싯돌 | 130/105 = **1.24** | +4 | 인성 15 → 최대 내구 30% → 쉽게 이 빠짐 |
| 폐합금 | 115/105 = 1.10 | +5 | 가볍다(손도끼 머리 70cm³: 연철 539g → 폐합금 315g). 무게가 없으니(D22) 가벼움은 칸·둔중에 이득이 없고, 둔기로 쓰면 타격 배율만 sqrt(5.5 / 8.7) = **0.80**으로 낮아진다 |
| 뼈 | 85/105 = **0.81** | −3 | 원시 기술 대체재 |

검산 1 — 강철 손도끼: 기본 베기 14 × 1.19 = 16.66 → 16, 관통 15 + 4 = **19**. 질량 = 70×7.8 + 350×0.7 + 350 = 546 + 245 + 350 = **1,141g**(내부값 — 배낭에서는 재질과 상관없이 2×2 = 4칸, 13 §4). 최대 내구 = floor(80 × 70/50) = **112**. 고철 손도끼는 베기 14·관통 15·최대 내구 floor(80 × 50/50) = **80** — 07 §7.1 표의 값이 곧 고철 값이다.

### 3.3 재질 → 방어 성능

```
층 방어[날]  = floor(형태 날 기준치 × (경도 + 50) / 100)
층 방어[타격] = floor(형태 타격 기준치 × (인성 + 50) / 100)
층 방어[열]  = 형태 열 기준치 + 단열 × 2
```
| 형태 | 날 / 타격 / 열 기준치 | 고철 | 연철 | 강철 |
|---|---|---|---|---|
| 사슬옷(13 고철 사슬옷) | 45 / 15 / 2 | **45 / 15 / 2** | 45 / 17 / 2 | 54 / 18 / 2 |
| 비늘 갑옷 [후속] | 50 / 25 / 3 | 50 / 25 / 3 | 50 / 28 / 3 | 60 / 30 / 3 |

- 검산: 고철 사슬옷 날 = floor(45 × (50 + 50)/100) = **45**, 타격 = floor(15 × (50 + 50)/100) = **15** → 13 §6.2의 "45 / 15 / 2"와 07 §2.4 검산의 사슬옷(날 45)이 이 값이다. 연철로 다시 단조하면 타격 floor(15 × 115/100) = 17.
- 13 §6.2의 다른 장비 수치(누빔 재킷 20 / 25 / 4 등)도 이 공식의 **결과값**이다. 형태 기준치·재질은 장비 Def에, 결과값 표는 13 §6.2에 둔다.

## 4. 품질 6단계 [프로토타입: 조악·보통·좋음만 드롭]

| 품질 | 피해·방어 | 최대 내구 | 단열 | 가치 | 제작 Q 구간 |
|---|---|---|---|---|---|
| 조악 | ×0.85 | ×0.70 | ×0.9 | ×0.5 | Q < 20 |
| 보통 | ×1.00 | ×1.00 | ×1.0 | ×1.0 | 20–44 |
| 좋음 | ×1.10 | ×1.15 | ×1.05 | ×1.6 | 45–64 |
| 뛰어남 | ×1.20 | ×1.30 | ×1.1 | ×2.5 | 65–79 |
| 명품 | ×1.30 | ×1.50 | ×1.15 | ×4.0 | 80–94 |
| 전설 | ×1.45 | ×1.80 | ×1.2 | ×8.0 | ≥ 95, **고유 아이템 내력 부여** |

```
Q = 25 + 능력치 항 + 숙달 항 + 능력 항 + 배경 + 특성 + 도구 보정(−10~+10) + 작업장 보정(−10~+10) + 재료 보정(−5~+5)
      − 조작 감점 + (roll(0..30) − 15)
  능력치 항 = (레시피 주 능력치 − 10) × 2
              주 능력치: 대장·목공·무두질 = 근력 / 재단·바느질·화살·활 = 민첩 / 조리·약·붕대 = 지각
  숙달 항   = 생존 숙달 × 4 (조리·건조·훈제 레시피) 또는 의료 숙달 × 4 (붕대·습포·연고 레시피), 그 밖은 0   (15 §9.3)
  능력 항   = [후속] 비전투 제작 트리(15 §18) 1단 +10 · 2단 +20. 프로토타입은 0
  배경      = 대장간 도제 +10(대장 레시피) (04 §9)
  특성      = 손재주 +5 (04 §8)
  조작 감점 = 시술자 조작(02 §3.2) 1.0에서 −10%p마다 3
```
- 1차의 `Q = floor(제작 숙련 × 0.6) + …`는 폐지(D23). 골격은 02 §12.1 처치 품질 Q(기본값 + 지각 항 + 숙달 × 4 + 능력 + 도구 + 환경)와 같다. 처치와 달리 제작은 **±15 난수**가 있어 같은 사람·같은 도구라도 결과가 흔들린다.

검산 2 — 대장간 도제(배경 +10), 근력 13 → +6, 좋은 망치 +3(§7.2), 대장간 +5, 재료 0, roll 22 → +7: Q = 25 + 6 + 10 + 3 + 5 + 7 = **56 → 좋음**.
검산 3 — 배경 없는 떠돌이, 근력 10 → 0, 조악한 돌망치 −5, 작업장 없음(모닥불) −10, roll 3 → −12: Q = 25 − 5 − 10 − 12 = **−2 → 조악**. 능력치만으론 품질이 안 나온다 — 도구와 작업장이 먼저다.
검산 3a — 범위: 평범한 사람(능력치 10, 보통 도구 0, 작업대 0)은 Q 10~40 → 조악(roll 0~9) **32%**, 보통 68%. 프로토타입 최상(능력치 20 +20, 도제 +10, 손재주 +5, 뛰어남 도구 +10, 장인 작업장 +10, 재료 +5)은 Q = 85 + roll − 15 → 전설(≥ 95)은 roll ≥ 25뿐 = **19%**. [후속] 제작 능력 2단(+20)이 생기면 roll ≥ 5 = 84%.
검산 3b — 요리(03 §4.3, 주 능력치 지각): 지각 12(+4)·생존 숙달 2(+8)·모닥불(−10) → Q = 27 + roll − 15 = 12~42 → '좋음'(45) 불가. 여관 부엌(+5)·생존 숙달 5(+20) → Q = 54 + roll − 15 = 39~69 → 좋음 이상(roll ≥ 6) **81%**.

| 재비 부식 | 금속 | 노출 100턴마다 부식 += (100 − 내식성). 1,000점마다 내구 −1, 녹 단계 +1(최대 3). 기름칠 48시간 면제. 외투가 덮은 부위 ×0.2 | 녹 단계당 가치 −15%, 녹 3 = 날 최대 70% | [후속] |
| 총열 오염 | 화기 | `07` §10 | 불발·걸림 | [후속] |
| 부패·썩음 | 생가죽·목재·식품 | 03 신선도 규칙 공유 | 생가죽은 10일 내 무두질 안 하면 썩음 | [후속] |

검산 4 — 날 마모: 강철(경도 70) 칼로 살을 50번 → 50 × 1 × 80 = 4,000점 → 날 −40% → 60%. 피해 배율 (60 + 24)/100 = **0.84**. 연철(경도 50)은 50 × 100 = 5,000 → −50% → 0.80.
검산 5 — 재비 부식: 연철 사슬(내식 30)이 외투 없이 8시간(9,600턴) 재비 노출 → 96 × 70 = 6,720점 → **내구 −6, 녹 6단계 누적 → 상한 3**. 외투를 입었다면 덮인 부위 ×0.2 → 1,344점 → 내구 −1.

## 6. 의복 층 · 칸 · 꺼내기

### 6.1 층 규칙 [프로토타입: 슬롯 = 층 / 안감: 후속]

> 4층 구조(외투 → 갑옷 → 중간 → 내의)는 이 문서의 판정 모델로 남는다. 프로토타입에서 층을 정하는 것은 **13의 장비 슬롯**이고, 중간·내의층은 **13 §11.4 안감 [후속]**(몸 슬롯 '겉옷' 장비의 안감 칸 1개)으로 되살린다.

| 영역 | 층(바깥 → 안) | 프로토타입 슬롯(13 §6) | 예(13 §4) |
|---|---|---|---|
| 몸통·팔·다리 | 외투 → 갑옷 → 중간 → 내의 | 망토(외투층) → 몸(갑옷층) → 몸 슬롯 안감 칸 [후속](중간·내의) | 방수포 망토 → 고철 사슬옷 → (안감: 누빔 재킷 [후속]) |
| 머리 | 두건/모자 → 투구 → 안감 | 머리 슬롯 1개: 두건 **또는** 투구(13 §6.1 택일). 투구 안감 [후속] | 두건 / 고철 투구 |
| 손 | 장갑 1층(갑옷 장갑은 안감 일체형) | 장갑 슬롯 | 작업 장갑 |
| 발 | 신발 + 감발(발싸개) | 장화 슬롯. 감발 [후속] | 가죽 장화 |

- 한 영역·한 층에 하나만. 판정 순서는 `07` §2.4·13 §11.2와 동일하게 바깥부터.
- **망토가 갑옷 위**: 덮인 부위 재비 부식 ×0.2, 걷기 소음 −1(고철 사슬옷 5 → 4, 13 §6.2), 대신 망토가 먼저 베여 내구 손실.
- **중간층 없는 금속 갑옷**: 기온 −10°C 이하 접촉 동상 판정(03 §7.5) [프로토타입 — 안감이 없으니 사슬옷은 항상 '중간층 없음'] / 장거리 이동 1시간마다 쓸림(경미한 찰과상) 3% [후속, 안감과 함께].
- **단열 합산**(정본 03): `총 단열 = Σ 층 단열 × 품질 × (1 − 젖음% × 젖음 손실% / 10000)`. 체온에는 03 §7.1의 영역 가중 I를 쓴다.
- **방수**: 망토 방수%만큼 안쪽 층이 덜 젖는다(13 §11.3, 03 §7.3). **방풍**: 최외곽이 바람 냉각을 줄인다(값은 03 §7.1).
- **안감을 넣으면** 착탈 턴이 두 장비의 합이 된다(13 §11.4). 사슬옷 6/3 + 누빔 재킷 3/2 → 입기 9턴, 벗기 5턴.

검산 6 [후속: 안감 기준] — 가죽 코트(3, 젖음 손실 70) + 안감 누빔 재킷(4, 60), 둘 다 젖음 50%:
코트 3 × (1 − 50×70/10000) = 3 × 0.65 = 1.95, 안감 재킷 4 × (1 − 50×60/10000) = 4 × 0.70 = 2.8 → **4.75**(마른 상태 7). 안감을 누더기 셔츠(1, 70)로 바꾸면 1 × 0.65 = 0.65 → **2.6**. 양모 스웨터(4, 젖음 손실 50 — 13 §4 미등재)였다면 4 × 0.75 = 3.0 → 4.95: 양모는 젖어도 따뜻하다. 프로토타입(안감 없음)의 같은 계산은 13 §13 검산 3과 03 §7 검산 5다.

### 6.2 칸 · 꺼내기 [프로토타입] — 무게·운반 한계 폐지(D22)

| 규칙 | 값 |
|---|---|
| 단위 | **칸**(가로×세로). 정본 13 §4. 1차의 무게 g·부피 cm³ 표시(kg·L)는 폐지 — 질량·부피는 재질 계산 내부값(§2) |
| 운반 한계·과적 | **폐지**(D22, 05 §2.1). 1차의 '착용 갑옷 과적 계산 ×0.7(분산)'도 폐지. 착용 장비의 부담은 **둔중**(회피치 감점, 07 §2.1)·**걷기 소음**(07 §9.1)·**착탈 턴**(13 §6.1)으로만 |
| 용기 | 배낭 30L → **10×6 격자**(13 §2) · 허리 주머니 3L → 허리띠의 **2×2 허리 주머니** [후속](13 §3) · 화살통 20 → 화살은 1×2 칸에 **20발 쌓임**(13 §5), 화살통 [후속] · 물통 1L → **물병 1×2, 1,000ml**(13 §4) |
| 꺼내기 | 1차 TU(배낭 200·벨트 50·땅 50)는 폐지. **배낭 안 정리·빠른 슬롯 배치 0턴**, 소모품은 **빠른 슬롯에서 그 사용 행동의 턴**(먹기 1턴·붕대 5턴, 13 §7), **적대 인식 중 루팅 창 → 배낭, 배낭 → 장비 슬롯은 1회당 1턴**(13 §8.3), 허리 주머니 [후속]는 전투 중에도 0턴 연결 |
| 젖음 무게 | **폐지**. 젖음은 단열(03 §7)·부패(03 §4.2)·활시위 습기(§5)·붕대 오염(13 §5)으로만 벌한다 |
| 새 아이템 | 08에서 형태·재질을 만들 때 칸은 **13 §4 표에 먼저 등록**한다(검증 CLI: `grid` 없는 ItemDef 오류, 최소 1×1) |

- 검산 — 1차 "배낭에서 붕대 꺼내기 200TU(2턴), 허리 주머니 50TU" → 3차: 빠른 슬롯에 붕대를 두면 꺼내기 0턴 + 감기 5턴. 빠른 슬롯에 없으면 적대 인식 중 소지품 창에서 꺼내는 데 1턴(13 §8.3 옮기기 규칙 준용)을 더 써서 6턴. **붕대는 빠른 슬롯에** — 1차의 "붕대는 허리에"가 같은 교훈으로 남는다.

### 7.1 레시피 Def
```json

  "defType": "RecipeDef",
  "id": "Recipe.ForgeHandAxe",
  "label": "손도끼 단조",
  "workstation": ["Station.Forge"],

```

## 8. 수리 · 분해 · 유물

### 8.1 수리 [후속]
```
수리 점수 S = 능력치 항 + 능력 항 + 배경 + 특성 + 도구 보정 + 작업장 보정 − 조작 감점    (§4 Q에서 기본 25·재료·난수를 뺀 것)
1회 수리량 = clamp(10, 60, 30 + S) (% of 최대 내구)
수리 재료  = 원재료 질량의 5% per 10% 회복
최대 내구 영구 감소 = max(2, 10 − floor(S / 5)) %   (수리할 때마다. S가 음수면 10%를 넘는다)
현장 수리(작업장 없음) 상한 = 최대의 60%
```
검산 8: 대장간 도제(배경 +10), 근력 12(+4), 보통 망치(0), 대장간(+5) → S = **19** → 1회 49% 회복, 최대 내구 −7%(10 − 3). 같은 칼을 5번 고치면 최대 내구 약 0.93⁵ ≈ **70%**(곱셈 누적). 배경 없는 떠돌이(근력 10, 조악한 돌 −5, 모닥불 −10) → S = −15 → 1회 15%, 감소 10 − (−3) = **13%**. [후속] 제작 능력 2단(+20) + 근력 14(+8) + 도제 + 좋은 망치(+3) + 장인 작업장(+10) → S = 51 → 60%(상한), 감소 **2%**(하한).

### 8.2 분해 · 회수 [후속]
```
회수율 = clamp(10, 80, 35 + S) %          (S = §8.1 수리 점수)
회수 질량 = floor(원재료 g × 회수율 × (50 + 내구%/2) / 10000)
```
검산 9: 고철 사슬옷(3,000g), 대장간 도제 근력 12 작업대(0) 보통 도구(0) → S = 4 + 10 = 14 → 49%, 내구 60% → 3,000 × 49 × 80 / 10000 = **1,176g 고철**. 배경 없는 떠돌이(S 0) → 35% → 840g.

### 8.3 유물(개척·정원사) 감정 · 수리 [후속]

| 단계 | 아는 것 | 얻는 법 |
|---|---|---|
```
유물 감정치 = 지각 + 문해(06 §5, 0~3) × 3 + 배경(고물 발굴꾼 +8, 04 §9) + [후속] 유물학 능력(+10)
  1차 '유물학 숙련'은 폐지(D23, 06 §4 감별치와 같은 원칙: 지각 + 지식 단계)
```

| 단계 | 아는 것 | 얻는 법 |
|---|---|---|
| 미감정 | 외형 묘사, 크기·촉감("손바닥만 한 검은 판, 미세하게 따뜻하다", 칸은 13 §4) | — |
| 추정 | 용도 범주(무기/의료/도구/동력/기록) | 감정치 15, 또는 고물길드 감정(추정가 10%) |
| 감정 | 정확한 기능·잔여 전력·결함 | 감정치 25, 또는 길드 정밀 감정(추정가 25%, 3일) |

- **직접 조작**: 미감정 상태에서 사용하면 오작동 판정 `clamp(5, 30, 40 − 감정치)`%: 방전, 화상, 과열 폭발(드묾), 신호 발신(야생 정원사 유인 — 10 스토리텔러 연결).
- **동력**: 개척 유물은 전력 셀 충전량(0~100)을 쓴다. 재충전은 잔존 경비대 발전기·특정 유적에서만.
- **수리**: 희귀 부품(개척 회로판, 정원사 결정편 — 명칭은 lore 정합 필요) + 감정 완료 + 장인 작업장. 실패 시 `clamp(10, 60, 60 − 감정치)`%로 영구 파손.
- 검산: 지각 10·문해 0 → 감정치 10 → 추정 불가, 오작동 **30%**. 고물 발굴꾼(지각 11, 문해 1) → 11 + 3 + 8 = **22** → 추정 가능(감정은 길드에), 오작동 18%, 수리 실패 38%. 경비대 기록관(지각 12, 문해 3) → 12 + 9 = 21 → 추정. 감정치 25(감정)는 배경만으로는 닿지 않는다 — 책(06)·길드·[후속] 능력이 필요하다.

## 9. 경제 [후속, 프로토타입은 상인 없음 — 가치 표기만]

### 9.1 화폐
- **표(標, Tally)**: 고물길드가 각인한 금속 패(제안 — lore 정합 필요). 정착지 간 신용이 있어 통용되지만, 고원 촌락연합 외곽에선 물물교환이 기본.
- **기준 앵커**: 하루 식량(2,500kcal) ≈ **10표**, 공장 탄 1발 ≈ **10표**(CANON "탄 한 발 ≈ 하루치 식량").

### 9.2 가격
```
가격 = 기준가 × 재질 가치 × 품질 가치 × 상태 배율 × 지역 계수 × 세력 계수 × 흥정 계수
상태 배율 = (30 + 70 × 내구%/100) / 100
지역 계수 = clamp(0.5, 3.0, sqrt(목표 재고 / max(1, 현재 재고)))      (09 정착지 재고)
세력 계수: 우호 0.9 / 중립 1.0 / 경계 1.2 / 적대 거래 불가
상인 판매 = 가격 × 1.25, 상인 매입 = 가격 × 0.6 (고물길드는 유물 매입 0.75)
```
검산 10: 붕대(기준 4표), 역병 도는 정착지 재고 2 / 목표 18 → sqrt(9) = 3.0 → 12표, 상인 판매 **15표**. 평시 재고 18 → 1.0 → 4 × 1.25 = **5표**.

### 9.3 상인 재고 갱신
- 정착지 상인: 3일마다 `TraderStockDef` 풀에서 가중 추첨, 수량 × 정착지 재고 비율. 판 물건은 재고로 남아 다음 갱신 때 일부 소진.
- 방랑 상인·캐러밴: 출발지 재고에서 싣고 출발(09 캐러밴) → **약탈당하면 그 물건이 약탈단 손에 간다**.

### 9.4 흥정
```
흥정 항 = (지각 − 10) × 2 + (의지 − 10) + 배경(몰락한 길드 상인 +15 · 경비대 기록관·떠돌이 이야기꾼 +10, 04 §9) + [후속] 협상 능력
라운드(최대 3) 성공% = clamp(5, 90, 40 + (흥정 항 − 상인 흥정 항) + floor(평판/5))
  상인 흥정 항: 상인 NPC Def 값(마을 행상 5 · 정착지 상인 10 · 고물길드 감정상 15)
성공: 흥정 계수 −5%(구매) / +5%(판매) 누적. 실패: 상인 짜증 +1 → 2에서 가격 +10%, 3에서 24시간 거래 거부
```
- 1차의 '협상 숙련'은 폐지(D23, 05 §4: 협상 → 지각·평판으로 임시 대체). 지각은 상대 표정·장부를 읽는 눈, 의지는 물러서지 않는 버팀이다.

검산 11: 몰락한 길드 상인 배경(지각 11, 의지 11) → 2 + 1 + 15 = **18** vs 정착지 상인 10, 평판 10 → 40 + 8 + 2 = **50%**. 3라운드 모두 성공 확률 0.5³ = 12.5%. 배경 없는 떠돌이(지각 10, 의지 10 → 0) → 40 − 10 + 2 = **32%**, 0.32³ ≈ 3.3%.

## 11. 깊이 3층

| 층 | 내용 |
|---|---|
| L1 | 좋은 무기·갑옷을 입는다. 망가지면 고친다. 무엇이든 칸을 차지한다 |
| L2 | 재질 차이(강철 vs 연철), 외투로 부식 막기, 양모는 젖어도 따뜻하다, 활시위 밀랍칠 |
| L3 | 수리마다 최대 내구가 줄어 "언제 버릴지" 계산(대장간 도제는 7%, 모닥불의 떠돌이는 13%). 폐합금의 가벼움은 둔기에서는 손해다. 역병 정착지에 붕대를 3배로 판다. 혼합 재질 상속으로 단열 최적화. 고유 아이템을 원 소유 세력에 돌려 평판 작업 |

## 12. "이런 것까지?" 디테일

1. 양모는 젖어도 단열 손실이 50%뿐(리넨 70%) → 북부 원정 속옷은 양모.
2. 외투를 갑옷 위에 입으면 그 부위 재비 부식이 1/5.
3. 활시위를 건 채로 보관하면 활이 처진다(탄성 −1%/일) → 쉴 때 시위를 푼다(시위 걸기 6턴·풀기 3턴, 01 §4.2). 시위를 푼 채 습격당하면 첫 6턴은 활을 못 쓴다.
4. 전투 중 배낭에서 장비 슬롯으로 꺼내기 1턴, 빠른 슬롯의 붕대는 0턴(13 §7·§8.3) → 붕대는 빠른 슬롯에. 허리 주머니 [후속]가 생기면 그 칸의 소모품도 0턴.
5. 부싯돌 칼은 강철보다 날카롭지만 인성 15라 최대 내구가 30%.
6. 재질은 칸을 바꾸지 않는다: 폐합금 손도끼는 머리 쇠가 42% 가볍지만(539g → 315g) 배낭에서는 똑같이 2×2다. 무게가 없으니(D22) 젖은 옷도 무겁지 않다 — 대신 차갑다(03 §7).
7. 무두질 통은 3일 동안 냄새 4/턴을 뿜는다 → 야영지에서 하면 재늑대를 부른다.
8. 수리할 때마다 최대 내구가 영구히 깎인다 → 명품 칼은 대장간 도제 출신이나 [후속] 제작 능력을 가진 대장장이에게만 맡긴다(수리 점수 S가 높을수록 감소가 2%까지 준다).
9. 고물길드는 유물을 0.75에 사지만 일반 물건은 0.6 → 팔 곳을 고른다.
10. 미감정 유물을 만지작거리면 신호를 발신해 야생 정원사를 부를 수 있다.
11. 생가죽은 10일 안에 무두질하지 않으면 썩는다.
12. 젖은 화약은 불발률 ×2 → 탄약 주머니도 방수가 필요하다.
13. 고유 아이템의 원래 주인 세력은 그것을 알아본다(반환 요구 or 평판 보상).
14. 폐합금은 가볍고 단단하지만 산업 작업장 없이는 다듬을 수 없다.

## 13. 대칭 적용

- 약탈자 장비도 같은 내구·날·부식 상태를 가진다 → 드롭 장비는 대부분 "조악~보통, 내구 30~70%, 녹 1".
- NPC 상인도 같은 가격 공식을 쓰고, NPC 대장장이도 같은 Q 공식으로 만든다(정착지 대장장이 NPC Def의 근력·배경·능력과 그 마을 작업장이 상점 품질을 결정).
- 동물 가죽·뼈는 사냥 시 부위 피해에 따라 회수량이 줄어든다(몸통 심각 상처 → 가죽 회수 −50%).

## 14. UI 표현

- 아이템 이름에 품질·재질·상태 접두: "좋은 강철 손도끼 (날 84%, 녹 1)".
- 툴팁 L1: 피해·관통·칸(13 §19). Shift: 재질 배율·품질 배율·날 상태 공식 전개. 백과: 재질 속성 표 전체.
- 의복 패널: 13 소지품 창의 인물 도식 둘레 슬롯(망토/몸/(안감 [후속])/머리/장갑/장화), 슬롯마다 부위별 내구%·젖음% 막대.
- 경고: 날 50% 미만, 시위 습기 60↑, 녹 2↑는 아이콘 표시(`12` 경고 체계 저우선).

## 17. 열린 질문

1. 화폐 명칭 '표(Tally)'를 lore 문서와 합의 필요. 고물길드 발행이 맞는가?
2. 단열 단위: 03이 이 문서의 단열 값(리넨 1·양모 4·모피 7)과 젖음 공식을 채택해 `쾌적 하한 = 18 − 2.5 × 전신 단열`로 확정 → 단열 1점 ≈ 2.5°C. 재질 단열 값을 바꾸면 03의 계수 2.5도 함께 조정해야 한다.
3. 수리 최대 내구 감소가 너무 가혹한가? 명품 이상은 감소 ×1/2 옵션 검토.
4. 정원사 유물 부품의 고유명사(결정편 등)는 lore 확정 후 교체.
5. '고철' 재질(§3.1, 인성 50)은 07·13의 고철 장비 수치(사슬옷 45 / 15 / 2)를 08 공식으로 재현하려고 추가한 제안이다. 13 §6.2의 "고철 = 연철 기준 재질" 문구를 "고철 = §3.1 고철(인성 50)"로 고쳐야 한다.
6. 제작 Q의 기본값 25(평범한 사람 조악 32%)와 [후속] 제작 능력 +10/+20은 비전투 트리(15 §18)가 생길 때 다시 맞춘다. 그 전까지 전설 품질은 최상 조건에서 19%다(§4 검산 3a).
7. 레시피 지식(`requires.recipeKnown`)의 출처 — 06 책·소문, 04 배경, [후속] 능력 — 중 프로토타입(조리·붕대)은 모두 기본 지식으로 둔다.
