# 08 — 아이템 · 재질 · 제작 · 경제 (Items & Crafting)

> 기준: `CANON.md`. 전투 수치의 사용처는 `07-combat`, 체온 공식의 정본은 `03-survival`, 유물 지식은 `06-knowledge`, 정착지 재고는 `09-world-and-simulation`.
> 상태: 초안 v0.1 · 2026-10-13

## 0. 결론 요약

- 아이템 = **형태(ItemDef) × 재질(MaterialDef) × 품질 × 상태(내구·날·습기·부식)**. 같은 "손도끼"도 연철/강철/폐합금, 조악/명품, 녹슨/정비된 상태로 전부 다른 물건이다.
- 아이템은 소모되는 게 아니라 **늙는다**. 날이 무뎌지고, 활시위가 젖고, 재비에 녹슬고, 수리할수록 최대 내구가 줄어든다. 정비가 원정 루프의 일부다.
- 현재 세계는 원시~중세만 생산한다(CANON §3.3). 개척·정원사 물품은 **발굴만** 가능하고, 감정·수리에 지식과 희귀 부품이 든다. 이 격차가 경제와 욕망을 만든다.

## 1. 목적 / 설계 의도

| 의도 | 플레이어 결정 |
|---|---|
| 재질이 성능을 정한다 | "강철 칼 하나 vs 연철 칼 둘" — 가치·무게·정비 비용 비교 |
| 장비는 정비 대상 | 원정 짐에 숫돌·밀랍·기름·바늘을 넣을지, 그만큼 식량을 뺄지 |
| 층(layer)이 생존을 정한다 | 외투를 갑옷 위에 입을지(부식 방지·단열) 벗을지(무게·소음) |
| 희소성이 가치를 만든다 | 탄 한 발을 쏠지, 팔아서 사흘 치 식량을 살지 |
| 제작은 운이 아니라 조건 | 좋은 도구·작업장·재료를 모아야 좋은 품질이 나온다 |

## 2. 아이템 Def 공통 구조

```json
{
  "defType": "ItemDef",
  "id": "Item.HandAxe",
  "parent": "Item.MeleeWeaponBase",
  "label": "손도끼",
  "category": "Weapon",
  "tags": ["Tool.Chopping", "Weapon.Axe"],
  "techLevel": "Medieval",
  "volumeCm3": 420,
  "massFixedG": 350,
  "stuffSlots": [
    { "id": "head", "accepts": ["Metal", "Stone"], "volumeCm3": 70, "role": "Primary" },
    { "id": "haft", "accepts": ["Wood", "Bone"], "volumeCm3": 350, "role": "Secondary" }
  ],
  "durabilityBase": 80,
  "valueBase": 24,
  "stackLimit": 1,
  "comps": {
    "weapon": "Weapon.HandAxe",
    "edge": { "dullingPerHit": 1 },
    "corrosion": true
  },
  "craftedBy": ["Recipe.ForgeHandAxe"],
  "salvage": { "recoverable": ["head", "haft"] }
}
```

| 필드 | 설명 |
|---|---|
| `stuffSlots` | 재질 슬롯. `Primary`가 피해·관통을 결정, 모든 슬롯이 무게·내구에 기여 |
| `volumeCm3` / `massFixedG` | 슬롯 부피 × 밀도 + 고정 질량(끈·리벳) = 총 무게 |
| `techLevel` | Primitive / Medieval / Industrial / Pioneer / Gardener. Pioneer·Gardener는 `craftedBy` 금지(검증 CLI가 차단) |
| `comps` | 기능 컴포넌트: weapon, apparel, edge, bowString, corrosion, firearm, container, food, relic, history |
| `valueBase` | 기준 재질·보통 품질의 기준가(표) |

인스턴스 상태(세이브에 저장): `defId, stuff{slot: materialId}, quality, durability, durabilityMax, edgePct, moisture, corrosion, fouling, partDurability{part: pct}, identified, historyId`.

### 3.2 재질 → 무기 성능

```
베기·찌르기 피해 배율 = (날카로움 + 50) / (기준 재질 날카로움 + 50)       기준 = 무기 Def의 refStuff
타격 피해 배율       = clamp(0.7, 1.5, sqrt((밀도 + 1) / (기준 밀도 + 1)))
관통 보정            = floor((경도 − 50) / 5)                              (음수 내림)
무게(g)              = Σ(슬롯 부피 × 밀도) + 고정 질량
최대 내구            = floor(내구 기본 × 인성 / 50)
```

| 재질(칼날 기준 연철) | 피해 배율 | 관통 보정 | 비고 |
|---|---|---|---|
| 강철 | 125/105 = **1.19** | +4 | 정비 부담 적음(경도 높아 덜 무뎌짐) |
| 청동 | 1.00 | −1 | 녹 적음 |
| 부싯돌 | 130/105 = **1.24** | +4 | 인성 15 → 최대 내구 30% → 쉽게 이 빠짐 |
| 폐합금 | 115/105 = 1.10 | +5 | 가벼움(손도끼 머리 70cm³: 연철 539g → 폐합금 315g) |
| 뼈 | 85/105 = **0.81** | −3 | 원시 기술 대체재 |

검산 1 — 강철 손도끼: 기본 베기 14 × 1.19 = 16.66 → 16, 관통 15 + 4 = **19**. 무게 = 70×7.8 + 350×0.7 + 350 = 546 + 245 + 350 = **1,141g**. 최대 내구 = floor(80 × 70/50) = **112**.

### 3.3 재질 → 방어 성능

```
층 방어[날]  = floor(형태 날 기준치 × (경도 + 50) / 100)
층 방어[타격] = floor(형태 타격 기준치 × (인성 + 50) / 100)
층 방어[열]  = 형태 열 기준치 + 단열 × 2
```
| 형태 | 날 / 타격 / 열 기준치 | 연철 | 강철 |
|---|---|---|---|
| 사슬 셔츠 | 45 / 15 / 2 | 45 / 17 / 2 | 54 / 18 / 2 |
| 비늘 갑옷 [후속] | 50 / 25 / 3 | 50 / 28 / 3 | 60 / 30 / 3 |

`07` 예시 A의 사슬 셔츠(날 45)는 연철 기준이다.

## 4. 품질 6단계 [프로토타입: 조악·보통·좋음만 드롭]

| 품질 | 피해·방어 | 최대 내구 | 단열 | 가치 | 제작 Q 구간 |
|---|---|---|---|---|---|
| 조악 | ×0.85 | ×0.70 | ×0.9 | ×0.5 | Q < 20 |
| 보통 | ×1.00 | ×1.00 | ×1.0 | ×1.0 | 20–44 |
| 좋음 | ×1.10 | ×1.15 | ×1.05 | ×1.6 | 45–64 |
| 뛰어남 | ×1.20 | ×1.30 | ×1.1 | ×2.5 | 65–79 |
| 명품 | ×1.30 | ×1.50 | ×1.15 | ×4.0 | 80–94 |
| 전설 | ×1.45 | ×1.80 | ×1.2 | ×8.0 | ≥ 95, **고유 아이템 내력 부여** |

```
Q = floor(제작 숙련 × 0.6) + 도구 보정(−10~+10) + 작업장 보정(−10~+10) + 재료 보정(−5~+5) + 특성 + (roll(0..30) − 15)
```
검산 2: 숙련 50 → 30, 좋은 망치 +5, 대장간 +5, 재료 0, roll 22 → +7 → **Q 47 → 좋음**.
검산 3: 숙련 20 → 12, 조악한 돌망치 −5, 작업장 없음(모닥불) −10, roll 3 → −12 → **Q −15 → 조악**. 숙련만으론 품질이 안 나온다.

## 5. 내구 · 상태

| 상태 | 대상 | 규칙 | 효과 | 범위 |
|---|---|---|---|---|
| 구조 내구 | 모든 장비 | 무기: 명중 −1, 튕김 −2, 무기 막기 −floor(피해/4). 0 → 파손(성능 0, 수리 가능) | 0이면 사용 불가 | [프로토타입] |
| 부위별 방어구 내구 | 방어구 | 덮는 부위마다 0~100%. 그 부위 층이 막은 피해만큼 감소: `−floor(막은 피해 × 100 / 최대 내구)`% | 실효 방어 = 방어 × (50 + 내구%/2)/100 (`07` §2.4) | [프로토타입] |
| 날 상태 | 베기·찌르기 | 마모 점수 += 손실 × (150 − 경도). 100점마다 날 −1%. 손실: 살 1, 절반 2, 튕김 3, 뼈 2 | 피해 × (60 + 날% × 0.4)/100 | [프로토타입] |
| 활시위 습기 | 활 | 0~100. 비·재비 노출 10턴마다 +5, 습한 날 +1/시간. 밀랍칠(밀랍 1, 24시간) 증가량 ×0.3 | 30↑ 피해 −10%·사거리 −1, 60↑ −25%·−3, 발사마다 끊어짐 floor((습기−60)/2)% | [프로토타입] |
| 재비 부식 | 금속 | 노출 100턴마다 부식 += (100 − 내식성). 1,000점마다 내구 −1, 녹 단계 +1(최대 3). 기름칠 48시간 면제. 외투가 덮은 부위 ×0.2 | 녹 단계당 가치 −15%, 녹 3 = 날 최대 70% | [후속] |
| 총열 오염 | 화기 | `07` §10 | 불발·걸림 | [후속] |
| 부패·썩음 | 생가죽·목재·식품 | 03 신선도 규칙 공유 | 생가죽은 10일 내 무두질 안 하면 썩음 | [후속] |

검산 4 — 날 마모: 강철(경도 70) 칼로 살을 50번 → 50 × 1 × 80 = 4,000점 → 날 −40% → 60%. 피해 배율 (60 + 24)/100 = **0.84**. 연철(경도 50)은 50 × 100 = 5,000 → −50% → 0.80.
검산 5 — 재비 부식: 연철 사슬(내식 30)이 외투 없이 8시간(9,600턴) 재비 노출 → 96 × 70 = 6,720점 → **내구 −6, 녹 6단계 누적 → 상한 3**. 외투를 입었다면 덮인 부위 ×0.2 → 1,344점 → 내구 −1.

## 6. 의복 층 · 무게 · 부피

### 6.1 층 규칙 [프로토타입]

| 영역 | 층(바깥 → 안) | 예 |
|---|---|---|
| 몸통·팔·다리 | 외투 → 갑옷 → 중간 → 내의 | 우비 → 사슬 셔츠 → 누비 갬비슨 → 리넨 셔츠 |
| 머리 | 두건/모자 → 투구 → 안감 | 양모 두건 → 철모 → 펠트 안감 |
| 손 | 장갑 1층(갑옷 장갑은 안감 일체형) | 가죽 장갑 |
| 발 | 신발 + 감발(발싸개) | 장화 + 양모 감발 |

- 한 영역·한 층에 하나만. 판정 순서는 `07` §2.4와 동일하게 바깥부터.
- **외투가 갑옷 위**: 재비 부식 ×0.2, 갑옷 소음 −1, 대신 외투가 먼저 베여 내구 손실.
- **중간층 없는 금속 갑옷**: 장거리 이동 1시간마다 쓸림(경미한 찰과상) 3% / 기온 −10°C 이하 접촉 동상 판정(03).
- **단열 합산**(정본 03): `총 단열 = Σ 층 단열 × 품질 × (1 − 젖음% × 젖음 손실% / 10000)`.
- **방수**: 외투 방수%만큼 안쪽 층이 덜 젖는다. **방풍**: 외투가 바람 냉각을 줄인다(03).

검산 6 — 리넨 셔츠(1) + 양모 스웨터(4) + 무두질 가죽 코트(3), 외투·중간 모두 젖음 50%:
코트 3 × (1 − 50×70/10000) = 3 × 0.65 = 1.95, 스웨터 4 × (1 − 50×50/10000) = 4 × 0.75 = 3.0, 셔츠 1 → **5.95**(마른 상태 8). 양모를 리넨으로 바꿨다면 스웨터 자리가 1 × 0.65 → 총 3.6.

### 6.2 무게 · 부피 · 꺼내기 [프로토타입]

| 규칙 | 값 |
|---|---|
| 단위 | 무게 g, 부피 cm³ (UI는 kg·L) |
| 운반 한계 | 근력 기반(정본 03). 착용 갑옷은 과적 계산 시 ×0.7(분산), 둔중(`07`)은 전체 무게 |
| 용기 | 배낭 30L, 허리 주머니 3L, 화살통 화살 20, 물통 1L |
| 꺼내기 TU | 손에 듦 0, 벨트·허리 주머니 50, 화살통 0(발사 TU 포함), 배낭 200(내려놓기 포함), 땅 50 |
| 젖음 무게 | 젖은 의복 무게 + (부피 × 젖음% × 0.2)g |

## 7. 제작 [후속, 프로토타입은 모닥불 조리·붕대만]

### 7.1 레시피 Def
```json
{
  "defType": "RecipeDef",
  "id": "Recipe.ForgeHandAxe",
  "label": "손도끼 단조",
  "workstation": ["Station.Forge"],
  "tools": [{ "tag": "Tool.Hammer", "qualityWeight": 1 }, { "tag": "Tool.Tongs" }],
  "skill": "Skill.Smithing", "minSkill": 15,
  "workTU": 72000,
  "inputs": [
    { "filter": { "category": "Metal" }, "massG": 700, "stuffTo": "head" },
    { "filter": { "category": "Wood" }, "massG": 300, "stuffTo": "haft" },
    { "item": "Item.Charcoal", "count": 3 }
  ],
  "output": { "item": "Item.HandAxe", "count": 1 },
  "byproducts": [{ "item": "Item.Slag", "count": 1 }],
  "noise": 8, "smell": 0
}
```
| 필드 | 설명 |
|---|---|
| `filter` | 재질 범주·태그로 재료를 고른다(특정 재질 고정도 가능) |
| `stuffTo` | 이 재료가 결과물의 어느 슬롯 재질이 되는지 |
| `workTU` | 72,000TU = 36분(100TU=3초). 숙련 보정: × (150 − 숙련)/100, 최소 ×0.5 |
| `noise`·`smell` | 작업 중 발생(`07` §9) — 무두질은 냄새 4/턴 |

### 7.2 작업장 · 도구

| 작업장 | 기술 | 작업장 보정 | 할 수 있는 것 |
|---|---|---|---|
| 맨땅·모닥불 | 원시 | −10 | 조리, 붕대, 돌 도구, 화살대 |
| 작업대 | 중세 | 0 | 목공, 가죽 재단, 활 |
| 무두질 통 | 중세 | 0 | 생가죽 → 무두질 가죽(3일, 냄새) |
| 베틀 | 중세 | 0 | 직물 |
| 대장간(풀무) | 중세 | +5 | 연철·강철 단조, 사슬 수리 |
| 장인 작업장 | 산업 | +10 | 폐합금 가공, 탄약 재장전, 화기 수리 |

도구 보정: 조악 −5 / 보통 0 / 좋음 +3 / 뛰어남 이상 +5~+10. 도구 없음은 제작 불가(돌로 대체 가능한 레시피만 −10).

### 7.3 재료 속성 상속
```
같은 슬롯에 서로 다른 재질이 섞이면: 속성 = floor(Σ(질량ᵢ × 속성ᵢ) / Σ질량ᵢ),  Q −5(혼합 페널티)
```
검산 7: 갑옷 안감에 재늑대 가죽 2kg(단열 5) + 무두질 가죽 1kg(단열 3) → floor((10 + 3)/3) = **4**, Q −5.

## 8. 수리 · 분해 · 유물

### 8.1 수리 [후속]
```
1회 수리량 = 20 + floor(숙련/2) (% of 최대 내구)
수리 재료  = 원재료 질량의 5% per 10% 회복
최대 내구 영구 감소 = max(2, 10 − floor(숙련/12)) %   (수리할 때마다)
현장 수리(작업장 없음) 상한 = 최대의 60%
```
검산 8: 숙련 36 → 1회 38% 회복, 최대 내구 −7%(10 − 3). 숙련 96 → −2%. 같은 칼을 5번 고치면 숙련 36은 최대 내구 약 0.93⁵ ≈ 70%(곱셈 누적).

### 8.2 분해 · 회수 [후속]
```
회수율 = clamp(10, 80, 25 + floor(숙련/2)) %
회수 질량 = floor(원재료 g × 회수율 × (50 + 내구%/2) / 10000)
```
검산 9: 사슬 셔츠(연철 3,000g), 숙련 40 → 45%, 내구 60% → 3,000 × 45 × 80 / 10000 = **1,080g 연철**.

### 8.3 유물(개척·정원사) 감정 · 수리 [후속]

| 단계 | 아는 것 | 얻는 법 |
|---|---|---|
| 미감정 | 외형 묘사, 무게("손바닥만 한 검은 판, 미세하게 따뜻하다") | — |
| 추정 | 용도 범주(무기/의료/도구/동력/기록) | 유물학(06) 15, 또는 고물길드 감정(추정가 10%) |
| 감정 | 정확한 기능·잔여 전력·결함 | 유물학 40, 또는 길드 정밀 감정(추정가 25%, 3일) |

- **직접 조작**: 미감정 상태에서 사용하면 오작동 판정 `30 − floor(유물학/2)`% (최소 5%): 방전, 화상, 과열 폭발(드묾), 신호 발신(야생 정원사 유인 — 10 스토리텔러 연결).
- **동력**: 개척 유물은 전력 셀 충전량(0~100)을 쓴다. 재충전은 잔존 경비대 발전기·특정 유적에서만.
- **수리**: 희귀 부품(개척 회로판, 정원사 결정편 — 명칭은 lore 정합 필요) + 유물학 숙련 + 장인 작업장. 실패 시 `(60 − 유물학)%`로 영구 파손.

## 9. 경제 [후속, 프로토타입은 상인 없음 — 가치 표기만]

### 9.1 화폐
- **표(標, Tally)**: 고물길드가 각인한 금속 패(제안 — lore 정합 필요). 정착지 간 신용이 있어 통용되지만, 고원 촌락연합 외곽에선 물물교환이 기본.
- **기준 앵커**: 하루 식량(2,500kcal) ≈ **10표**, 공장 탄 1발 ≈ **10표**(CANON "탄 한 발 ≈ 하루치 식량").

### 9.2 가격
```
가격 = 기준가 × 재질 가치 × 품질 가치 × 상태 배율 × 지역 계수 × 세력 계수 × 흥정 계수
상태 배율 = (30 + 70 × 내구%/100) / 100
지역 계수 = clamp(0.5, 3.0, sqrt(목표 재고 / max(1, 현재 재고)))      (09 정착지 재고)
세력 계수: 우호 0.9 / 중립 1.0 / 경계 1.2 / 적대 거래 불가
상인 판매 = 가격 × 1.25, 상인 매입 = 가격 × 0.6 (고물길드는 유물 매입 0.75)
```
검산 10: 붕대(기준 4표), 역병 도는 정착지 재고 2 / 목표 18 → sqrt(9) = 3.0 → 12표, 상인 판매 **15표**. 평시 재고 18 → 1.0 → 4 × 1.25 = **5표**.

### 9.3 상인 재고 갱신
- 정착지 상인: 3일마다 `TraderStockDef` 풀에서 가중 추첨, 수량 × 정착지 재고 비율. 판 물건은 재고로 남아 다음 갱신 때 일부 소진.
- 방랑 상인·캐러밴: 출발지 재고에서 싣고 출발(09 캐러밴) → **약탈당하면 그 물건이 약탈단 손에 간다**.

### 9.4 흥정
```
라운드(최대 3) 성공% = clamp(5, 90, 40 + floor((협상 숙련 − 상인 협상)/2) + floor(평판/5))
성공: 흥정 계수 −5%(구매) / +5%(판매) 누적. 실패: 상인 짜증 +1 → 2에서 가격 +10%, 3에서 24시간 거래 거부
```
검산 11: 협상 35 vs 상인 20, 평판 10 → 40 + 7 + 2 = **49%**. 3라운드 모두 성공 확률 0.49³ ≈ 11.8%.

## 11. 깊이 3층

| 층 | 내용 |
|---|---|
| L1 | 좋은 무기·갑옷을 입는다. 망가지면 고친다 |
| L2 | 재질 차이(강철 vs 연철), 외투로 부식 막기, 양모는 젖어도 따뜻하다, 활시위 밀랍칠 |
| L3 | 수리마다 최대 내구가 줄어 "언제 버릴지" 계산. 역병 정착지에 붕대를 3배로 판다. 혼합 재질 상속으로 단열 최적화. 고유 아이템을 원 소유 세력에 돌려 평판 작업 |

## 12. "이런 것까지?" 디테일

1. 양모는 젖어도 단열 손실이 50%뿐(리넨 70%) → 북부 원정 속옷은 양모.
2. 외투를 갑옷 위에 입으면 그 부위 재비 부식이 1/5.
3. 활시위를 건 채로 보관하면 활이 처진다(탄성 −1%/일) → 쉴 때 시위를 푼다(시위 걸기 200TU).
4. 배낭에서 물건 꺼내기 200TU, 허리 주머니 50TU → 붕대는 허리에.
5. 부싯돌 칼은 강철보다 날카롭지만 인성 15라 최대 내구가 30%.
6. 젖은 옷은 무겁다(부피 × 젖음% × 0.2g 추가).
7. 무두질 통은 3일 동안 냄새 4/턴을 뿜는다 → 야영지에서 하면 재늑대를 부른다.
8. 수리할 때마다 최대 내구가 영구히 깎인다 → 명품 칼은 숙련 높은 대장장이에게만 맡긴다.
9. 고물길드는 유물을 0.75에 사지만 일반 물건은 0.6 → 팔 곳을 고른다.
10. 미감정 유물을 만지작거리면 신호를 발신해 야생 정원사를 부를 수 있다.
11. 생가죽은 10일 안에 무두질하지 않으면 썩는다.
12. 젖은 화약은 불발률 ×2 → 탄약 주머니도 방수가 필요하다.
13. 고유 아이템의 원래 주인 세력은 그것을 알아본다(반환 요구 or 평판 보상).
14. 폐합금은 가볍고 단단하지만 산업 작업장 없이는 다듬을 수 없다.

## 13. 대칭 적용

- 약탈자 장비도 같은 내구·날·부식 상태를 가진다 → 드롭 장비는 대부분 "조악~보통, 내구 30~70%, 녹 1".
- NPC 상인도 같은 가격 공식을 쓰고, NPC 대장장이도 같은 Q 공식으로 만든다(정착지 대장장이 숙련이 상점 품질을 결정).
- 동물 가죽·뼈는 사냥 시 부위 피해에 따라 회수량이 줄어든다(몸통 심각 상처 → 가죽 회수 −50%).
