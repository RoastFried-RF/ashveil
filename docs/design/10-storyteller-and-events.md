# 10 — 스토리텔러 · 장소 기반 사건 (Storyteller & Place Events)

> **2차 방향 반영(2026-10-13)**: CANON D8 — 지도 가장자리에서 적을 만들어 내는 출현 규칙을 **폐지**하고, 림월드식 사건 생성은 **장소 기반 사건**(약탈자 순찰대가 야영지에서 출발, 재비·날씨, 며칠 뒤 재점거, 소문)으로 축소·재구성했다. 모든 위협은 **출발지와 실제 인구**를 가진다. 위협 예산·긴장 곡선·성향은 [후속]으로 내리고, 프로토타입은 14 §10의 고정 규칙으로 돈다.
> 기준: `CANON.md` §7 D8. 장소·공급원·정산의 정본은 `14-locations-and-dungeons`, 날씨는 `09-world-and-simulation`, 적 능력치는 `07-combat`·`lore/bestiary`.
> 상태: 초안 v0.2 · 2026-10-13

## 0. 결론 요약

- 스토리텔러는 적을 **만들지 않는다**. 이미 세계에 사는 존재(약탈자 야영지 6명, 관로 하단의 그늘 사람 18명 …)가 **언제·얼마나 움직일지**만 정한다. 레벨 스케일링도 없다.
- 사건은 반드시 **출발지**(장소)와 **경로**를 가진다. 약탈자 순찰대는 야영지에서 걸어 나오고, 재점거하는 그늘 사람은 관로 균열에서 들어온다. 출발지의 인구를 줄이면 사건도 줄어든다.
- 사건의 결과는 **흔적**으로 남는다: 짓밟힌 야영지, 사라진 보관함 물건, 다시 불이 켜진 경비실 횃불. 플레이어가 없던 동안의 사건은 층 재진입 **정산**(14 §9.2)에서 처리한다.
- 프로토타입: 장소 사건 6종(순찰·수색·재비·재점거·소문·순례자 행렬)을 **고정 확률 규칙**으로 돌린다. 위협 예산·성향 4종은 지역이 여러 개가 되는 단계에서 이 규칙의 빈도·규모를 조절하는 층으로 다시 얹는다.

## 1. 목적 / 설계 의도

| 의도 | 플레이어 결정 |
|---|---|
| 위협에는 출처가 있다 | "순찰은 아침에 야영지에서 나온다" → 아침에는 숲을 피하고, 야영지 인원을 줄이면 순찰이 멈춘다 |
| 흔적이 사건을 알린다 | 진흙의 새 발자국, 꺼진 줄 알았던 횃불 → 다시 찬 방을 미리 의심한다 |
| 떠나 있는 시간에도 값이 있다 | 모닥불을 켠 채 지하로 내려가면 정산에서 순찰이 야영지를 찾을 수 있다 |
| 세계는 소모된다 | 공급원(14 §9.4)이 바닥나면 그 위협은 끝난다. 끝낸 것이 플레이어의 업적이 된다 |
| 사건이 사슬로 이어진다 [후속] | 약탈자 두목을 죽이면 복수가 **지역 출입구**로 온다 → 죽일지 쫓아낼지 |

## 2. 장소 사건의 원칙 [프로토타입]

| # | 원칙 | 규칙 |
|---|---|---|
| E1 | **출발지 필수** | 모든 위협 사건 Def는 `origin`(장소 또는 공급원)을 가진다. 출발지 인구가 0이면 사건이 열리지 않는다 |
| E2 | **걸어서 온다** | 개체는 출발지에서 생겨(이미 그곳에 살던 개체) 경로를 따라 이동한다. 시야 안·지도 가장자리·빈 공간에서 **새로 생성하지 않는다** |
| E3 | **편성은 실제 인원** | 순찰 2~3명은 야영지 6명 중에서 뽑는다. 순찰이 죽으면 야영지에 돌아오지 않는다 |
| E4 | **예고는 흔적으로** | 출발 전·이동 중 흔적(발자국·연기·소리·쪽지)을 남긴다. 예고 없는 매복은 없다 |
| E5 | **정지와 정산** | 플레이어가 없는 지도에서 일어날 사건은 재진입 정산(14 §9.2) 때 일 단위로 처리한다 |
| E6 | **바깥은 출입구로만** | 지역 밖에서 오는 존재(보충 약탈자, 상인, 복수자)는 **지역 출입구**로만 들어오고, 하루 전 소문으로 예고된다 [후속] |

|---|---|---|---|---|---|
| 1 | **약탈자 순찰** | 약탈자 야영지 | 매일 06:00, 야영지 인원 ≥ 4이면 50% | 2~3명(두목 제외, `story` 스트림)이 야영지 → 숲 개울 → 수도원 입구 → 야영지. 경유지마다 30분 대기 | 야영지 모닥불 연기 증가(05:30), 진흙 위 발자국(20시간) |

| 5 | **소문** | 서가·석관 쪽지, 포로, 시체 소지품 | 획득 시 | 06 §7 소문 개체: 아래층 방 위치, 보스 약점, 공급원 단서 | — |

### 3.1 순찰이 보는 플레이어 흔적

| 흔적 | 발견 조건 |
|---|---|
| 켜진 모닥불 불빛(밤) | 순찰 위치가 모닥불 반경 6 × 3 = 18칸 안(07 §5) |
| 모닥불 연기(낮) | 15칸 안, 순찰 위치가 바람 아래(±45°)면 × 1.5 = 22.5칸 |
| 마르지 않은 핏자국 | 경로 위 또는 3칸 안 |
| 약탈자 시체 | 시야 안(07 §4). 시체는 5일 뒤 뼈가 되어도 발견 대상 |
| 플레이어 본인 | 일반 인식 판정(07) → 교전 |

### 3.2 수색대의 보관함 약탈 (정산 포함)

```
수색대가 플레이어 야영지에 도착하면, 보관함(13 §2) 물건을 가치 내림차순으로
수색대 1명당 2개씩 가져간다. 가져간 물건은 그 약탈자의 배낭에 들어간다(13 §8.1)
→ 약탈자를 쓰러뜨리면 되찾을 수 있다
```

### 3.3 검산

**검산 1 — 순찰 빈도와 인원**
- 야영지 6명: 하루 순찰 확률 50% → 5일 기대 순찰 **2.5회**. 순찰 1회 인원 2~3명(균등) → 기대 2.5명.
- 플레이어가 순찰 2명을 숲에서 쓰러뜨리면 야영지 4명 → 여전히 50%. 1명 더 쓰러뜨리면 3명 → **순찰 중단**(인원 ≥ 4 조건). 두목을 죽이면 사기 붕괴(07 §8, 60%)로 남은 인원이 흩어질 수 있다.

**검산 2 — 모닥불을 켠 채 내려간 대가(정산)**
- 05:00 모닥불(연료 2시간, 07:00 소진)을 켠 채 1층으로 내려가 3일 뒤 돌아온다.
- 정산 1일째 06:00: 순찰 발생 50%. 순찰은 06:02(30턴) 숲 개울 도착, 06:32까지 대기 — 모닥불이 아직 탄다(낮 → 연기). 플레이어 야영지 → 숲 개울 22칸: 연기 기본 15칸으로는 부족, **바람 아래(× 1.5 = 22.5칸)일 때만** 보인다.
- 바람 방향(8방위 균등, 09)이 숲 개울 쪽 ±45° 안일 확률 = 3/8. → 발견 확률 = 0.5 × 3/8 = **18.75%**.
- 발견되면 수색대 3~4명 → 보관함에서 6~8개를 가져간다. 2·3일째에는 불이 꺼져 있어 발견 확률 0.
- 교훈(L3): 내려가기 전에 불을 끄면 위험 0이다. 끄는 데 1턴이다.

**검산 3 — 재점거와 공급원** (14 §9.3 공식 재사용)
- 1층 정리된 방 6개, 7일 뒤 재방문: 방마다 1 − 0.85⁴ = 47.8% → 기대 2.9개 방. 관로 하단 인원 18 → 충분.
- 같은 7일 동안 관로 하단 회복 = floor(7 / 4) = **+1명**. 1층을 두 번 정리하면(약 14명 소모) 공급원은 18 − 14 + 3 = 7명 수준으로 떨어진다.

## 4. 사건 예산 [후속 — 1차 '위협 예산'을 장소 사건 조절 층으로 축소]

> 지역이 여러 개가 되면, 고정 확률(§3) 위에 아래 예산이 **빈도·규모 배율**을 얹는다. 예산은 적을 만들지 않고, **출발지 인원을 넘는 편성은 불가능**하다(E3).

### 4.1 축적 · 스케일 (1차 공식 유지)
```
시간당 축적 = 4 × 스케일 × 성향 배율 × 신규 유예(첫 48시간 0.5)
스케일 = clamp(0.6, 3.0, 0.6 + sqrt(부 / 400) × 0.2 + 명성 / 100)
  부   = 소지품 + 보관함 가치(08 가격). 착용 장비 포함
  명성 = 0~100. 공급원 고갈·보스 처치·두목 처치로 증가, 매주 −2
예산 상한 = 30시간분 축적(= 120 × 스케일 × 성향 배율)
```
정수 구현: 예산은 ×10 고정소수점, sqrt는 정수 제곱근(`isqrt`).

| 부 | 명성 | 스케일 | 시간당 축적(성향 1.0) |
|---|---|---|---|
| 100 | 0 | 0.6 + 0.5×0.2 = **0.7** | 2.8 |
| 400 | 0 | 0.6 + 1×0.2 = **0.8** | 3.2 |
| 3,600 | 30 | 0.6 + 3×0.2 + 0.3 = **1.5** | 6.0 |

### 4.2 소비 — 장소 행동으로
```
판정 주기: 하루 06:00 (장소 사건 판정과 같은 시각), story 스트림
예산이 장소 사건의 '강화 비용' 이상이면 강화% = clamp(0, 80, 10 + (예산 − 30))
강화 종류: 순찰 확률 +25%p / 순찰 인원 +1 / 수색대 두목 동행 / 재점거 판정 +10%p
편성 단가는 1차 표 유지(약탈자 근접 25, 궁수 30, 부두목 60) — 단 출발지 인원 안에서만
```

**검산 4**: 예산 54, 강화% = 10 + 24 = **34%**. "순찰 인원 +1"(단가 25) 선택 → 순찰 3~4명, 예산 54 − 25 = 29. 야영지 인원이 4명뿐이면 최대 4명(두목 제외 3명) → 강화가 의미 없으면 예산을 쓰지 않는다.

## 5. 긴장 곡선 [후속]

```
긴장 T (0~100)
  + 적 인식 5, 피격 상처 경상 3 / 중상 8 / 심각 15, 혈액 손실 15% 10, 정신붕괴 20
  − 위협이 시야에 없을 때 시간당 3, 안전 수면(잠근 실내·야영지) 시간당 6
목표 긴장 = 성향의 곡선 함수(아래), 테이블 선형 보간
```
**검산 5**: T 20에서 적 인식 +5, 중상 +8, 혈액 15% +10, 경상 2회 +6 → **49**. 이후 6시간 위협 없음 → 49 − 18 = **31**.

## 7. 사건 Def 구조

```json
{
  "defType": "PlaceEventDef",
  "id": "Event.ReaverPatrol",
  "category": "Threat",
  "tags": ["Reaver", "Patrol"],
  "origin": { "place": "Place.GreyCloister.ReaverCamp", "population": "Pop.ReaverCamp" },
  "schedule": { "at": "06:00", "everyDays": 1 },
  "conditions": [ "pop('Pop.ReaverCamp').count >= 4" ],
  "chance": 500,
  "composition": { "fromPopulation": true, "count": [2, 3], "exclude": ["Role.Leader"] },
  "route": { "waypoints": ["Wp.ForestCreek", "Wp.CloisterGate", "Wp.ReaverCamp"], "waitMinutes": 30 },
  "onSee": [
    { "trace": "Trace.PlayerCampfireLight", "event": "Event.ReaverSearch" },
    { "trace": "Trace.PlayerCampfireSmoke", "event": "Event.ReaverSearch" },
    { "trace": "Trace.FreshBlood", "event": "Event.ReaverSearch" },
    { "trace": "Trace.ReaverCorpse", "event": "Event.ReaverSearch" }
  ],
  "traces": ["Trace.Footprints", "Trace.CampSmoke"],
  "resolveWhileFrozen": "Settlement",
  "text": { "title": "event.reaverPatrol.title" }
}
```

| 필드 | 설명 |
|---|---|
| `origin` | **필수**(E1). 장소 + 공급원. 공급원 인원이 조건을 못 채우면 열리지 않는다 |
| `composition.fromPopulation` | true만 허용(E3). 출발지 인원에서 실제 개체를 뽑는다 |
| `route` | 경유지 목록. 개체는 실제로 걷는다(E2) |
| `traces` | 남기는 흔적(E4) |
| `resolveWhileFrozen` | 지도가 정지 중일 때 처리 방식: `Settlement`(14 §9.2 정산) / `Skip` |
| `conditions` | 제한된 식 DSL(비교·논리·조회 함수만, 부작용 없음). 11-modding이 함수 목록 정의 |
| `chain` [후속] | 결과별 후속 사건(지연·확률). 지역 밖에서 오는 후속은 출입구 경유(E6) |

- 1차 설계의 `spawn.mode: "Ambush"`, `spawn.distance`(가장자리·시야 밖 거리)는 **삭제**한다. 검증 CLI는 `origin` 없는 위협 사건을 오류로 막는다.

## 13. "이런 것까지?" 디테일

1. **발자국의 나이**: 진흙 발자국은 20시간 남는다. 새벽에 새 발자국이 있으면 오늘 순찰이 이미 지나갔다.
2. **연기는 낮, 불빛은 밤**: 같은 모닥불이 낮에는 15칸, 밤에는 18칸에서 보인다. 바람 아래면 연기는 더 멀리 간다.
3. **되찾는 보관함**: 수색대가 가져간 물건은 그들의 배낭에 그대로 있다. 다음 순찰에서 그 약탈자를 쓰러뜨리면 내 물건이 루팅 창에 뜬다.
4. **재점거의 횃불**: 그늘 사람은 빛을 싫어하지만 재점거한 경비실의 횃불 받침 하나는 켜 둔다(요리용). 멀리서 그 빛이 보이면 방이 다시 찬 것이다.
5. **순찰의 대기**: 순찰은 수도원 입구에서 30분 머문다. 그때 수도원에서 나오면 정면으로 마주친다.
6. **수색대의 화살 표시**: 수색대는 흔적 지점에 화살을 꽂아 표시한다. 그 화살을 뽑아 가면(회수) 다음 수색대가 그 지점을 찾지 못한다.
7. **두목 없는 야영지**: 두목이 죽으면 남은 약탈자는 사기 판정 후 흩어지거나 남는다. 남은 자들은 순찰을 나가지 않고 야영지를 지킨다.
8. **사건 이유의 기록**: 연대기에 "약탈자 수색 — 순찰이 숲 개울에서 남서쪽 연기를 봄(바람 북동 2)"처럼 원인이 남는다.

## 14. 대칭 적용

- 약탈자 야영지도 같은 생존 압력을 받는다 [후속]: 식량이 떨어지면 순찰 확률 ×2.
- 장소 사건은 적에게 보너스를 주지 않는다. 순찰대는 같은 Def·같은 장비 규칙을 쓴다.
- 플레이어의 야영지도 하나의 "장소"다. 플레이어의 흔적이 순찰에게 보이듯, 약탈자 야영지의 연기도 플레이어에게 보인다.

## 15. UI 표현

- 흔적: 맵에 그려진다(발자국·연기·켜진 횃불·화살 표시). 툴팁: "약탈자 발자국 · 약 3시간 전 · 북동쪽으로".
- 정산 로그(재진입 한 줄): `[3일 지남] 모닥불이 꺼져 있다. 보관함이 열려 있다 — 3개가 없다.`
- 장소 정보(지도 `M`): 약탈자 야영지 "관찰한 인원 5 (2일 전)". 정확한 공급원 숫자는 표시하지 않는다.
- 연대기: 사건마다 원인 한 줄.
