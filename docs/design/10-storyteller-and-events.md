# 10 — 스토리텔러 · 사건 (Storyteller & Events)

> 기준: `CANON.md`. 세력·정착지·역병 상태는 `09-world-and-simulation`, 적 능력치는 `07-combat`, 부(소지품 가치)는 `08-items-and-crafting`.
> 상태: 초안 v0.1 · 2026-10-13

## 0. 결론 요약

- 스토리텔러는 적을 **강하게** 만들지 않는다(레벨 스케일링 없음). 사건의 **빈도·규모·종류**만 조절한다.
- 핵심은 **위협 예산**: 시간이 지나면 쌓이고, 사건이 생기면 쓴다. 쌓이는 속도는 플레이어의 **부와 명성**(=세상의 관심)에 비례한다.
- 성향 4종(기록관·주사위 점쟁이·은자·잿빛 추적자)이 같은 사건 풀을 다른 리듬으로 꺼낸다. 공정성 장치(최소 휴식, 연속 재앙 상한, 출현 예고)는 성향별로 켜고 끈다.
- 프로토타입은 **스토리텔러-라이트**: 위협 예산으로 재늑대·약탈자·굴쥐를 로컬 맵에 등장시키는 것만.

## 1. 목적 / 설계 의도

| 의도 | 플레이어 결정 |
|---|---|
| 부가 관심을 부른다 | 유물을 들고 다닐지, 은닉처에 둘지, 팔아서 흩을지 |
| 리듬이 있다 | "큰 습격 뒤 이틀은 조용하다(기록관)" → 그때 치료·정비 |
| 사건은 선택이다 | 구조 요청을 무시할지, 함정일 걸 알고 갈지 |
| 사건이 사슬로 이어진다 | 약탈단 두목을 죽이면 복수가 온다 → 죽일지 쫓아낼지 |

## 2. 위협 예산 모델

### 2.1 축적 · 스케일
```
시간당 축적 = 4 × 스케일 × 성향 배율 × 신규 유예(첫 48시간 0.5)
스케일 = clamp(0.6, 3.0, 0.6 + sqrt(부 / 400) × 0.2 + 명성 / 100)
  부   = 소지품 + 은닉처 가치(08 가격, 표). 착용 장비 포함
  명성 = 0~100. 큰 사건 해결·악명 행위로 증가, 매주 −2 자연 감소
예산 상한 = 30시간분 축적(= 120 × 스케일 × 성향 배율)
새 게임 초기 예산 = 40
```
정수 구현: 예산은 ×10 고정소수점, sqrt는 정수 제곱근(`isqrt`)으로 계산.

| 부(표) | 명성 | 스케일 | 시간당 축적(성향 1.0) |
|---|---|---|---|
| 100 | 0 | 0.6 + 0.5×0.2 = **0.7** | 2.8 |
| 400 | 0 | 0.6 + 1×0.2 = **0.8** | 3.2 |
| 3,600 | 30 | 0.6 + 3×0.2 + 0.3 = **1.5** | 6.0 |
| 40,000 | 80 | 0.6 + 10×0.2 + 0.8 = 3.4 → **3.0**(상한) | 12.0 |

### 2.2 소비 (사건 발생)
```
판정 주기: 1시간(1,200턴)마다, story 스트림
예산 ≥ 후보 사건 최소 비용일 때 발생% = clamp(0, 80, 10 + (예산 − 30) + floor((목표 긴장 − 현재 긴장)/2))
사건 선택: 조건 충족 사건들의 가중치 추첨
지출 = floor(예산 × 사용 비율),  사용 비율 = 성향 범위 내 추첨
편성: 사건의 편성 표에서 비싼 순으로 탐욕 구매, 남은 포인트는 예산으로 반환
```

| 적(편성 단가) | 포인트 | 적 | 포인트 |
|---|---|---|---|
| 굴쥐 | 4 | 약탈자(활) | 30 |
| 재늑대 | 18 | 약탈단 부두목 | 60 |
| 약탈자(곤봉·손도끼) | 25 | 수리 드론 [후속] | 45 |

**검산 1**: 예산 54, 긴장 20, 기록관 목표 긴장 50 → 10 + 24 + 15 = **49%** 발생. 사건 "재늑대 무리 출현"(편성: 재늑대만, 2~5마리) → 사용 비율 0.8 추첨 → 지출 floor(54 × 0.8) = 43 → 재늑대 2마리(36), 남은 7 반환 → 예산 54 − 36 = **18**.
**검산 2**: 예산 70, 비율 0.8 → 56 → 약탈자 정찰대(편성: 궁수 최대 1, 근접 나머지) → 궁수 30 + 근접 25 = 55, 남은 1 반환 → 예산 70 − 55 = **15**.

## 3. 긴장 곡선

```
긴장 T (0~100)
  + 적 조우(시야 진입) 5, 피격 상처 경상 3 / 중상 8 / 심각 15, 혈액 손실 15% 10, 정신붕괴 20
  − 위협이 시야에 없을 때 시간당 3,  안전 수면(잠근 실내·정착지) 시간당 6
목표 긴장 = 성향의 곡선 함수(아래), 테이블 선형 보간
```
**검산 3**: T 20에서 적 조우 +5, 중상 +8, 혈액 15% +10, 경상 2회 +6 → 20 + 29 = **49**. 이후 6시간 위협 없음 → 49 − 3×6 = **31**. 기록관 목표가 50이면 발생% 보정 floor((50−31)/2) = +9 → 아직 "더 몰아칠 여지"가 있다는 뜻. 목표가 20(골짜기)이면 floor((20−31)/2) = −6 → 휴식 쪽으로 기운다.

## 4. 성향 (Storyteller Persona)

| 파라미터 | 기록관 | 주사위 점쟁이 | 은자 | 잿빛 추적자 |
|---|---|---|---|---|
| 성격 | 점증 곡선, 숨 돌릴 틈 | 완전 무작위 | 생존·질병·탐험 중심 | 약할 때를 노림(고난도) |
| 축적 배율 | 1.0 | 1.0 | 0.5 | 1.5 |
| 사용 비율 | 0.6~1.0 | 0.2~1.5(초과분은 빚: 예산 음수 가능, 하한 −40) | 0.5~0.8 | 0.8~1.0 |
| 목표 긴장 곡선 | 8일 주기 삼각파 20→70→20, 주기마다 정점 +5 | 고정 40 | 고정 25 | 긴장 높을 때 목표 +20 |
| 범주 가중(위협/환경/질병/사회/거래/발견) | 30/15/10/15/15/15 | 균등 | 10/25/20/10/15/20 | 45/15/10/10/10/10 |
| 최소 휴식(큰 사건 후) | 36시간 | 0 | 48시간 | 12시간 |
| 연속 재앙 상한(48시간 내 위협 사건) | 2 | 없음(옵션) | 1 | 3 |
| 회복 감지(혈액 < 70% or 심각 상처) | 위협 보류 | 무시 | 위협 보류 | **발생% +15** |
| 출현 예고 | 항상 | 항상 | 항상 | 매복 계열 제외 |
| 업적·연대기 표기 | 기본 | 기본 | "은자" 표기 | "추적자" 표기 |

"큰 사건" = 지출 ≥ 50 또는 플레이어에게 심각 상처 발생.

## 5. 사건 Def 구조

```json
{
  "defType": "EventDef",
  "id": "Event.ReaverAmbushRoad",
  "category": "Threat",
  "tags": ["Combat", "Reaver", "Ambush"],
  "conditions": [
    "player.onRoad == true",
    "world.faction('Faction.AshenReavers').strength >= 20",
    "player.reputation('Faction.AshenReavers') < 0",
    "time.isNight == false || time.moon > 50"
  ],
  "weight": { "base": 20, "mods": [
    { "if": "player.wealth >= 2000", "mult": 1.5 },
    { "if": "world.reaverCamp.foodDays < 7", "mult": 2.0 }
  ]},
  "minCost": 50,
  "cooldownHours": { "self": 72, "categoryShared": 12 },
  "composition": { "pool": [
    { "def": "Actor.Reaver.Archer", "max": 2 },
    { "def": "Actor.Reaver.Melee" }
  ]},
  "spawn": { "mode": "Ambush", "hiddenUntil": "PerceptionCheck", "distance": [6, 10] },
  "warning": { "type": "Sound", "text": "event.reaverAmbush.warn", "perceptionDC": 12 },
  "choices": [],
  "chain": [
    { "onOutcome": "LeaderKilled", "event": "Event.ReaverRevenge", "delayHours": [48, 120], "chance": 0.6 },
    { "onOutcome": "PlayerFled", "event": "Event.ReaverTracking", "delayHours": [2, 6], "chance": 0.4 }
  ],
  "text": { "title": "event.reaverAmbush.title", "body": "event.reaverAmbush.body" }
}
```

| 필드 | 설명 |
|---|---|
| `conditions` | 제한된 식 DSL(비교·논리·조회 함수만, 부작용 없음). `11-modding`이 함수 목록 정의 |
| `weight` | 기본 × 조건부 배율(곱) |
| `minCost` | 이 사건을 열기 위한 최소 예산(비위협 사건은 0, 예산 안 씀) |
| `cooldownHours` | 자기 쿨다운 + 같은 범주 공유 쿨다운 |
| `composition` | 위협 사건의 편성 풀(§2.2 탐욕 구매) |
| `warning` | 출현 예고(소리·발자국·까마귀 등). 지각 판정 DC |
| `choices` | 선택지: 요구 조건·결과(아래) |
| `chain` | 결과별 후속 사건 대기열(지연·확률) |

선택지 예:
```json
"choices": [
  { "id": "help", "requires": "player.inventory.has('Tag.Medical')", "outcomes": [
      { "weight": 70, "effects": ["rep('Faction.Moorhold', +8)", "item.consume('Tag.Medical', 1)"] },
      { "weight": 30, "effects": ["spawnEvent('Event.FakeDistressAmbush')"] } ] },
  { "id": "ignore", "outcomes": [{ "weight": 100, "effects": ["thought('Thought.LeftThemToDie')"] }] }
]
```

## 7. 계약(퀘스트) 생성 템플릿 [후속]

| 템플릿 | 목표 | 반전(확률) |

| 호위 | 캐러밴·인물 목적지까지 | 매복 사건 강제 삽입(60%) |
| 회수 | 유적에서 지정 물품 | 경쟁 탐사대(25%), 물품이 유물이라 오작동(15%) |
| 전달 | 편지·약품을 다른 정착지로 | 수신 정착지 봉쇄(역병) |
| 구조 | 실종자 | 이미 사망 → 유품 회수로 전환(30%) |
| 조사 | 소문 확인 | 소문이 틀림(소문 신뢰도 역수) |
| 사냥 | 특정 동물 가죽 N장 | 무리가 예상보다 큼 |
| 정찰 | 지역 지도 작성 | 지도가 06 지식으로 판매 가능 |

```
보상(표) = (20 + 거리(월드 칸) × 8 + 예상 위협 포인트 × 0.8) × 의뢰 세력 부 배율(0.7~1.5)
기한 = 이동 예상 시간 × 2 + 24시간
실패: 기한 초과·대상 사망·호위 대상 사망 → 평판 −5, 연속 실패 시 그 정착지 게시판 이용 제한
```
**검산 4**: 거리 4칸, 예상 위협 54(재늑대 3), 촌락 부 배율 1.2 → (20 + 32 + floor(43.2)) × 1.2 = 95 × 1.2 = **114표** ≈ 하루 식량 11일치.

## 10. 깊이 3층

| 층 | 내용 |
|---|---|
| L1 | 가끔 적이 나타나고 상인이 온다 |
| L2 | 부가 늘면 더 자주 습격받는다 → 은닉처에 나눠 둔다. 큰 싸움 뒤엔 숨 돌릴 시간이 있다(기록관) |
| L3 | 예산 상한 30시간을 계산해 "언제 위험이 터질지" 예측. 두목을 죽이지 않고 쫓아내 복수 사슬을 피한다. 피를 흘린 채 바람 위로 이동해 추적 사건을 피한다 |

## 11. "이런 것까지?" 디테일

1. 착용 장비도 부에 포함 → 명품 갑옷을 입고 다니면 습격이 잦아진다.
2. 약탈단 야영지 식량이 7일분 미만이면 매복 가중 ×2(약탈단도 굶는다).
3. 피 냄새 추적 사건은 냄새 반경이 실제로 재늑대 서식 칸에 닿아야만 열린다.
4. 모닥불은 야간 습격 사건에서 위치를 노출한다(광원 ×3 거리, 07 §5).
5. 경비대 검문은 미감정 유물을 압수할 수 있다 → 유물은 숨겨서 운반(배낭 아래, 후속).
6. 부상당한 낯선 이의 30%는 미끼 → 의료 숙련이 높으면 "상처가 가짜" 판정 가능.
7. 암시장 탄약상에게 사면 경비대 평판 −5 위험.
8. 주사위 점쟁이는 예산을 빚질 수 있다(−40까지) → 대재앙 뒤 장기 평화.
9. 잿빛 추적자는 플레이어가 다쳤을 때 발생률이 오른다(+15%).
10. 두목 처치 시 60% 확률로 48~120시간 뒤 복수가 온다. 도망치게 두면 0%.
11. 계약 보상의 기준은 "하루 식량 10표" → 보상 114표는 식량 11일치로 체감.
12. 사건 발생 이유가 연대기에 남는다("부 3,600표 · 명성 30 → 스케일 1.5").

## 12. 대칭 적용

- NPC 정착지도 같은 사건을 겪는다(습격·역병·혹한) — 플레이어 근처가 아니면 L2에서 요약 처리(09 §10).
- 약탈단 야영지도 "식량 부족 → 습격 증가"라는 같은 생존 압력을 받는다.
- 스토리텔러는 적에게 보너스를 주지 않는다: 편성된 적은 같은 Def·같은 장비 규칙을 쓴다.

## 13. UI 표현

- 사건 창: 제목·본문·선택지(요구 조건 미충족은 회색 + 사유). 위협 사건은 창 없이 예고 로그만.
- 예고 로그: "북서쪽에서 재늑대 울음소리(12)" — 방향·소음 세기 표시.
- 스토리텔러 정보(설정 > 이번 판 정보): 성향·현재 스케일·예산 게이지(대략 5단계, 정확한 수치는 Shift).
- 연대기: 사건마다 원인 한 줄.
