# 05 — 성장 (Progression)

> **2차 방향 반영(2026-10-13)**: CANON D12 — 사용 기반 숙련·녹슬음·재능 트리를 **폐지**하고 **레벨·경험치 + 능력 트리**로 교체한다(상세는 [15-abilities](15-abilities.md)). 이 문서는 **능력치 5종과 파생치의 정본**, 나이·은퇴로 범위를 줄였다. 1차 설계의 재능은 부록 A에 "후속 능력 후보 풀"로 보존한다.
> 상위 기준: `CANON.md` §3.7, §7 D12·7.2(HP·기력·공격치·회피치·레벨). 충돌 시 CANON 우선.
> 관련: 01-time-and-turns, 02-body-and-health, 03-survival, 04-psyche, 06-knowledge, 07-combat, 08-items-and-crafting, 13-inventory, 15-abilities

## 0. 결론 요약

- **능력치 5종**(근력·민첩·지각·활력·의지)은 유지한다. 생성 시 정해지고, **레벨업마다 1점**을 원하는 곳에 더한다(상한 20). 극한 경험·노화로 깎이기도 한다.
- 능력치는 다른 시스템의 계수를 정하는 **파생치**로 쓰인다: 최대 HP(50 + 활력 × 5), 최대 기력(50 + 의지 × 5), 공격치·회피치(CANON 7.2) 등. 이 문서가 파생치 표의 정본이다(§2.1).
- 성장의 축은 **레벨·경험치·능력 트리**(스톤샤드 기본)다. 경험치 원천·레벨 곡선·능력 24개는 [15](15-abilities.md)가 정본이다.
- 사용 기반 성장은 **의료·생존 숙달**(0~5단계, 15 §9.3)에만 소폭 남는다(림월드 추가). 끝은 죽음 또는 **은퇴**다.

## 1. 목적 / 설계 의도

| 의도 | 플레이어 결정 변화 |
|---|---|
| 레벨업은 선택의 순간이다 | "민첩 +1(명중·회피·순서) vs 활력 +1(HP +5)" — 매 레벨 같은 질문이 다른 답을 낸다 |
| 능력치는 몸의 바탕이다 | 능력 트리가 "무엇을 할 수 있나"라면 능력치는 "얼마나 잘 버티나". 둘은 따로 고른다 |
| 반복은 손에 남는다 | 붕대를 수십 번 감은 손은 빠르다(의료 숙달). 그러나 칼질 횟수는 경험치가 아니다 |
| 끝을 고를 수 있다 | 다리를 잃은 40세 떠돌이는 은퇴 엔딩을 노릴 수 있다 [후속] |

## 2. 능력치 [프로토타입]

| 능력치 | 범위 | 의미 |
|---|---|---|
| 근력 | 1~20 (평균 10) | 근접 피해, 밀치기 체급, 막기 |
| 민첩 | 1~20 | 명중(공격치), 회피, 반응속도(행동 순서), 받아넘기기 |
| 지각 | 1~20 | 명중(공격치), 시야·인식, 감별, 처치 품질 |
| 활력 | 1~20 | **최대 HP**, HP 자연 회복, 기력 회복, 면역, 기절 저항 |
| 의지 | 1~20 | **최대 기력**, 통증 임계, 스트레스, 붕괴, 트라우마 |

**생성**: 모두 10에서 시작 → 시드(`world` 스트림)로 6점을 옮긴다(한 능력치에서 −1, 다른 곳에 +1을 6회, 각 7~13 범위) → 배경 보정(±1~2) 적용. 합계는 50 ± 배경 보정이다.
**레벨업**: 레벨이 오를 때마다 능력치 1점(15 §4). 상한 20. 되돌릴 수 없다.

### 2.2 검산

**검산 1 — 몸의 바탕** (활력 12, 의지 9)
- 최대 HP = 50 + 12 × 5 = **110**. HP 자연 회복 = floor(100 / 12) = **8턴마다 +1**.
- 최대 기력 = 50 + 9 × 5 = **95**. 기력 회복 = 2 + floor(12 / 5) = **4/턴**(몸통 멀쩡).
- 통증 기절 임계 = 80 + (9 − 10) × 2 = **78**.

**검산 2 — 레벨업 1점을 어디에?** (민첩 13, 지각 11, 마체테 정확도 +8, 사슬옷 둔중 2, 왼다리 중상)
- 현재 공격치 = 8 + floor(3 × 1.5) + 1 = 8 + 4 + 1 = **13**. 회피치 = (3 × 2 − 2) × (0.5 + 1.0) / 2 = 4 × 0.75 = **3**(내림).
- 민첩 +1(14): 공격치 = 8 + floor(4 × 1.5) + 1 = **15**(+2, 명중 +4%p), 회피치 = (8 − 2) × 0.75 = 4.5 → **4**(+1), initiative +2.
- 활력 +1(13): 최대 HP +5, 회복 주기 floor(100/13) = 7턴(−1), 기력 회복 2 + 2 = 4(변화 없음).
- `floor((민첩 − 10) × 1.5)` 때문에 **민첩은 짝수 단계(12·14·16)에서 공격치가 2씩, 홀수에서 1씩** 오른다 — L3.

## 5. 나이·노화 [후속]

- 1년 = 90일(01, CANON P1 결정 대기). 시작 나이는 배경(04)이 정한다(16~60).
- 생일(시작일 기준 90일마다) 노화 판정:

| 나이 | 상시 효과 | 생일 판정 |
|---|---|---|
| < 20 | 경험치 획득 ×1.1 | – |
| 20~39 | 기준 | – |
| 40~49 | 면역·치유 ×0.9(02) | 10%: 근력·민첩·활력 중 하나 −1 |
| 50~59 | 면역 ×0.8, 경험치 ×0.9 | 25%: 능력치 −1 / 10%: 관절통(만성 통증 +5, 02) |
| 60+ | 위 + 기력 회복 ×0.8 | 50%: 능력치 −1 / 20%: 시력·청력 상한 0.9 |

- **노련함**: 40세 이상은 숙달 문턱 −20%(빨리 익숙해진다), 의지 기반 판정 +2. 젊음과 경험의 교환이다.

## 6. 은퇴 엔딩 [후속]

### 6.1 조건 (정착지 여관에서 '은퇴' 선택)

| 조건 | 기준 |
|---|---|
| 거처 | 정착지 집 구매 또는 장기 임대(09 경제) |
| 저축 | 1년(90일) 생활비 × 남은 기대 수명 계수(40세 미만 5년, 40~59 3년, 60+ 1년) |
| 평판 | 그 정착지 세력 우호 이상 |
| 추적 없음 | 현상금·복수 사건(10) 미해결 0건 |
| 특례 | 사지 손실·영구 장애가 있으면 저축 기준 ×0.5('상처 입은 은퇴') |

### 6.2 결과

- 각인 모드에서도 **안전한 종료**다. 연대기에 '은퇴'로 기록되고 사망 보고서 대신 **은퇴 보고서**(생애 요약, 레벨·능력, 주요 사건, 흉터 목록)가 나온다.
- 유형: 평온한 은퇴 / 상처 입은 은퇴 / 전설의 은퇴(명성 상위, 고유 아이템 보유).
- **유산**: 다음 떠돌이가 같은 세계 시드로 시작하면 은퇴한 인물이 NPC로 존재할 수 있다(소문·여관 대화, 06). 게임 효과는 정보뿐이다(하드코어 유지).

| 층 | 내용 |

| L1 | 레벨이 오르면 능력치 하나를 올린다. 활력은 HP, 의지는 기력, 민첩은 맞히고 피한다 |

## 10. "이런 것까지?" 디테일

1. **짝수 민첩**: floor((민첩 − 10) × 1.5) 때문에 민첩 13 → 14는 공격치 +2, 14 → 15는 +1이다. 레벨업 화면이 "다음 1점 = 공격치 +2"를 미리 보여준다.
2. **회복 주기 계단**: HP 회복 주기 floor(100 / 활력)은 활력 13과 14가 같은 7턴이다. 14는 HP만 5 더 준다.
3. **의지와 숨 고르기**: 숨 고르기(15)는 최대 기력의 50%를 돌려준다 → 의지가 높을수록 같은 능력이 더 많이 돌려준다.
4. **노련함**: 40세 이상은 숙달 문턱 −20%. 늙은 약초꾼은 붕대에 빨리 익숙해진다.
5. **은퇴 특례**: 사지 손실·영구 장애가 있으면 은퇴 저축 기준이 절반이다. 크게 다친 판에도 '좋은 끝'의 길이 있다.
6. **능력치 상한 20**: 레벨 상한 20까지 19점을 얻지만 한 능력치는 20을 넘지 못한다. 생성 13에서 시작한 민첩은 7점만 받을 수 있다.

## 11. 적(NPC·동물)에 대한 대칭 적용

- NPC도 같은 능력치·파생치 공식을 쓴다. 약탈자의 공격치·회피치는 07 공식에 그대로 들어간다.
- NPC 능력치·능력은 생성 시 Def(약탈단 전사, 그늘 사람 우두머리 등)로 정해진다. 프로토타입에서 NPC는 성장하지 않는다.
- [후속] **복수자 성장**: 플레이어에게서 도망친 이름 있는 약탈자(10 '복수' 사건)는 같은 경험치 공식으로 레벨이 올라 돌아온다.
- 동물·비인간은 종족 고정 능력치(`RaceDef`)를 쓴다. 크기 보정(작음 +4 · 보통 0 · 큼 −4 · 거대 −8)이 회피치에 들어간다(07 §2.1).

## 15. 열린 질문

1. 민첩이 공격치·회피치·순서 세 곳에 들어가 "민첩 몰빵"이 최적이 되지 않는가? 봇으로 능력치 배분별 생존을 비교한다. 필요하면 근력을 막기·피해에 더 강하게 묶는다.
2. 근접·원거리 공격치가 같은 공식(민첩 ×1.5 + 지각)이다(CANON 7.2). 원거리에 지각 가중을 더 줄지는 CANON 확인이 필요하다.
3. 은퇴 '유산' NPC가 다음 판 정보 우위를 줘서 하드코어 원칙과 충돌하지 않는가?
4. 1차 숙련을 쓰던 문서(03 생존·요리, 04 배경 열정, 06 약초학·유물학 감별, 08 제작 품질 Q = 제작 숙련 × 0.6)가 아직 숙련을 참조한다. 각 문서의 2차 반영이 필요하다.
