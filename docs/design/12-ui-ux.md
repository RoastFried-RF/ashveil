# 12 — UI · UX

> 기준: `CANON.md` D3(DCSS 32×32 CC0 타일), §5 "규칙은 투명, 세계는 미지". 표시할 수치의 정본은 각 시스템 문서(01~11).
> 상태: 초안 v0.1 · 2026-10-13

## 0. 결론 요약

- UI는 "규칙은 투명"을 실제로 만드는 장치다. 모든 수치는 **3단 정보 계층**(기본 툴팁 → Shift 공식 → 백과)으로 끝까지 파고들 수 있어야 한다.
- 하드코어의 공정성은 **경고**와 **사망 보고서**에서 나온다. 죽기 전엔 "몇 턴 남았는지"를, 죽은 뒤엔 "무엇이 무엇을 불렀는지"를 보여준다.
- 키보드만으로 모든 걸 할 수 있고, 마우스는 보조. 색에만 의존하는 정보는 없다(색 + 모양 + 텍스트).
- 아트는 DCSS CC0 32×32로 시작하고, **방향(Facing)·젖음·상처**처럼 DCSS가 못 보여주는 정보는 렌더러 오버레이로 그린다. 교체 기준은 §10.

## 1. 목적 / 설계 의도

| 의도 | 플레이어 결정 |
|---|---|
| 판정을 예측 가능하게 | 공격 전 명중%·반응%·부위 분포를 보고 위치를 바꾼다 |
| 위험을 시간으로 표현 | "출혈 사망까지 8턴" → 지금 지혈대를 감을지 한 번 더 칠지 |
| 실패를 학습으로 | 사망 보고서의 원인 사슬을 보고 다음 판 습관을 바꾼다 |
| 정보 과부하 억제 | L1만 보면 플레이 가능, 원하면 L3까지 |

├──────────────────────────────────────────────────────────┤  (420px)      │
│                                                          │ ▣ 요약        │
│                                                          │  혈액 ███▒ 84%│
│                    맵 뷰포트                              │  스태 ██▒▒ 52 │

│                                                          │  상태 아이콘줄 │
│                                                          │ ▣ 탭          │

| 영역 | 크기(1080p 기준) | 내용 |
|---|---|---|
| 상단 바 | 36px | 시간·계절·날씨·조도 단계·바람(방향+풍속)·기온. 각 항목 툴팁 |
| 맵 | 나머지 | 타일·개체·오버레이(시야, 소음, 냄새, 조명, 방향) |
| 측면 패널 | 420px | 요약 게이지 + 탭(신체·소지품·숙련·지식·세계) |
| 하단 | 220px | 로그 + 퀵바 10칸 + 경고 배너 |

**검산 1 — 보이는 타일 수**: 1920×1080, 측면 420, 상단 36, 하단 220 → 맵 1,500×824px → 32px 타일 46.9 × 25.75 → **완전 타일 46×25**. 4K(3840×2160)에서 UI·타일 모두 2배(64px) → 3,000×1,648 / 64 → 같은 **46×25**. 정수 배율만 허용(1×·2×·3×), 1.5×는 픽셀이 뭉개져 금지.

## 3. 정보 계층 [프로토타입: L1·Shift / 후속: 백과]

| 계층 | 열기 | 내용 | 예(재늑대 공격 대상 호버) |
|---|---|---|---|
| L1 기본 툴팁 | 호버 300ms / `X` 보기 모드 | 결론 수치 | "명중 43% · 상대 회피 14% · 몸통 50%" |
| L2 Shift 상세 | 툴팁 위에서 Shift | 공식 전개, 항목별 출처 | `50 + (30−22)×2 −3(사거리) −15(어둠) −5(이동) = 43` |
| L3 백과 | 툴팁의 밑줄 용어 클릭 / F1 | 규칙 전문, 관련 시스템 링크 | "조명 단계" 항목: 4단계 표, 광원 반경, 장막 조도 공식 |

- **중첩 툴팁**: 툴팁 안 밑줄 용어에 호버하면 그 용어의 툴팁이 겹쳐 열린다(깊이 3까지). 마우스를 떼도 Shift를 누르고 있으면 고정.
- **지식 게이트**(06): 규칙은 항상 공개, 세계 지식은 미지. 재늑대 정보를 모르면 "회피 ??"로 표시되고 명중%는 "추정 30~50%" 범위로 나온다.

## 4. 신체 패널 [프로토타입]

```
 ┌ 부위 도식 ─────────┐  ┌ 상처 목록 (위험순) ───────────────────────┐
 │       (머리)        │  │ ⚠ 왼 대퇴  동맥 절단   150 ml/턴  [지혈대]  │
 │   [팔]─(몸통)─[팔]   │  │ ● 오른 상완 베임 중상   26 ml/턴  [붕대]    │
 │      [다]  [다]     │  │ ○ 몸통      타박 경상    0       —          │
 └────────────────────┘  └──────────────────────────────────────────┘
  총 출혈 176 ml/턴 · 혈액 4,200/5,000 · 쇼크까지 ~3턴 · 사망까지 ~9턴
  통증 2단계(명중 −10) · 체온 36.4 · 기능: 이동 60% 조작 90% 시야 100%
```
- 도식 칸은 상태로 채색 + **무늬**(색맹 대응): 정상 빈칸, 경상 점, 중상 사선, 심각 격자, 파괴 X.
- **위험 시간 표시**: `남은 턴 = floor((현재 혈액 − 임계 혈액) / 총 출혈)`, 임계 = 85%·70%·60%·50%(CANON 15/30/40/50%). 총 출혈은 **현재 행동 기준**(02 상황계수: 달리기·전투 ×1.3)이고 응고는 무시 → 실제보다 짧게(보수적으로) 나온다. 달리기 버튼 호버 시 "달리면 ~7턴"처럼 바뀐 값을 미리 보여준다.

**검산 2**: 혈액 4,200, 동맥 150 + 베임 26 = 176 ml/턴(위 그림). 쇼크(30% 손실 = 3,500): (4,200 − 3,500)/176 = 3.98 → **~3턴**. 사망(2,500): 1,700/176 = 9.66 → **~9턴**.
**검산 3**: 혈액 4,800, 베임 26 ml/턴만 → 어지러움(4,250): 550/26 = 21.2 → **~21턴**, 사망: 2,300/26 = 88.5 → **~88턴**. 같은 상처라도 동맥 유무가 3턴 vs 21턴을 가른다.

- 내출혈(`07` 찌르기)은 상처 목록에 "?"로만 표시되고 총 출혈에 포함되지 않는다 → 증상(창백·어지러움)으로 추론해야 한다(02). 의료 숙련·감별 후 공개.
- 상처 행의 버튼은 가진 처치 도구만 활성. 클릭 = 해당 처치 행동(TU 표시).

## 5. 전투 로그 포맷 [프로토타입]

**3단 상세도**: 간략 / 표준(기본) / 상세. 각 줄은 펼침(▸)으로 단계별 판정을 연다.

표준 한 줄:
```
[3일 14:20:06 · T48213] 약탈자(손도끼) → 나: 우측면 명중(79%), 오른 상완 — 사슬이 받아 타박(6). 경상.
```
펼침(상세, `07` 예시 A와 동일 수치):
```
 ▸ 1 명중   79% = 50 + (26 공격 − 14 회피)×2 + 10 측면 − 5 지침        roll 63 → 명중
 ▸ 2 반응   회피 3% (<10%, 반응 생략)  · 방패: 우측면 불가
 ▸ 3 부위   우측면 가중(‰): 오른쪽 ×1.5, 왼쪽 ×0.5 · roll 510/1000 → 오른 상완(480~539)
 ▸ 4 방어구 사슬 셔츠: 실효 40(내구 80%) − 관통 15 = 25 · roll 18 → 절반+타격 (13→6, 관통 7)
            누비 갬비슨: 25 − 7 = 18 · roll 72 → 관통 · 리넨: 생략
 ▸ 5 상처   타박 6 / 상완 HP 30 = 20% 경상 · 골절 임계 12 미달
 ▸ 6 2차    통증 +4 · 사슬 셔츠(오른 상완) 내구 −5% · 소음 8(금속 충돌)
```
- 색: 내가 준 피해 흰색, 받은 피해 주황, 치명 사건 빨강 + 굵게 + ⚠ 접두(색 없이도 구분).
- 필터: 전투/생존/사건/대화/시스템. 검색(Ctrl+F).
- **복사**(Ctrl+C on 줄): 시드·턴·로드 해시 포함 → 버그 리포트·커뮤니티 공유가 재현 가능.

## 6. 경고 체계 [프로토타입]

| 우선 | 조건(예) | 표현 | 자동 진행·휴식 |
|---|---|---|---|
| P0 치명 | 출혈 사망까지 < 30턴, 혈액 손실 ≥ 30%, 불붙음, 질식, 체온 < 32°C | 화면 가장자리 붉은 맥동(≤ 2Hz) + 배너 + 경고음 + **입력 1회 확인 요구** | 즉시 중단, 이동 키 1회 무시(실수 방지) |
| P1 위험 | 지속 출혈, 적 발견, 저체온 단계 진입, 통증 3단계 | 상단 배너(노랑) + 짧은 음 | 중단 |
| P2 주의 | 배고픔·갈증·피로 단계, 날 50% 미만, 시위 습기 60↑ | 상태 아이콘 깜빡 1회 | 휴식만 중단 옵션 |
| P3 정보 | 날씨 변화, 소문 도착 | 로그만 | 계속 |

- **중복 억제**: 같은 원인 경고는 상태가 악화될 때만 재발령(예: 사망까지 30 → 15 → 5턴 구간 진입 시).
- **우선순위 정렬**: 배너는 동시에 최대 3개, P0 > P1, 같은 등급은 남은 턴이 짧은 순.
- 모든 임계값은 설정에서 조정 가능(P0의 "30턴"도).

## 7. 사망 보고서 · 연대기 [프로토타입: 사망 보고서 / 후속: 연대기 화면]

### 7.1 사망 보고서
```
떠돌이, 3일차 14:29. 회색 고원 폐허 외곽.
왼쪽 대퇴 동맥 절단 후 9턴 만에 출혈로 사망.

[원인 사슬]
 피 흘리며 이동(오른 상완 26 ml/턴, 14:12~)
  └→ 피 냄새 반경 32칸(바람 아래, 풍속 2) ── 재늑대 서식지 도달
       └→ 사건 '피 냄새 추적'(예산 54 → 재늑대 3)
            └→ 후면 포위(측면 슬롯 2/후면 1)
                 └→ 왼 대퇴 물림 D11 → 동맥 절단(확률 22%, roll 11)
                      └→ 지혈대 없음 → 출혈 사망
[놓친 기회]
 · 붕대 2개 소지, 출혈 상처 14분(280턴) 방치
 · 출혈 중 바람 아래 방향으로 이동(냄새 반경 ×2 구간)
 · 포위 시점 3칸 거리에 좁은 통로(1칸 폭) 있었음
[마지막 50턴] 혈액·스태미나·사기 그래프  [소지품] … [마지막 식사] 훈제 고기
[공유] 시드 8F3A-21C7 · 기록관 · 로드 해시 9b04…  (복사)
```
- **원인 사슬 데이터**: 모든 상처·상태·사건에 `cause` 링크(이전 이벤트 ID)를 저장 → 사망 시 역추적. 사슬 깊이 최대 8, 분기 시 기여도(피해량·확률) 큰 쪽 우선.
- **놓친 기회**: 휴리스틱 규칙(Def로 확장 가능) — "치료 도구 소지 + 출혈 상처 N턴 방치", "좁은 통로 5칸 이내 + 포위당함", "횃불 켠 채 야간 원거리 피격" 등. 반사실 시뮬은 하지 않는다(난수 재현 비용·스포일러).

### 7.2 연대기
- 떠돌이 목록(영구, 각인 모드에서도 유지): 배경·특성·생존 일수·사인 한 줄·주요 사건 3개.
- 판별 타임라인: 사건·전투·발견을 날짜순, 스토리텔러 사건은 발생 이유 한 줄 포함(10 §11).
- 세계 역사(09 §11) 열람: 이번 판 세계에서 플레이어가 **알게 된** 부분만.
- 게임 내 효과 없음(하드코어 유지, GDD §6.7).

## 9. 접근성

| 항목 | 내용 | 범위 |
|---|---|---|
| 색맹 모드 | 적록(1·2형)·청황(3형) 팔레트 교체. 모든 정보는 색 + 모양(무늬·아이콘) + 텍스트 | [프로토타입: 무늬·아이콘 병행] |

| 애니메이션 속도 | 0(즉시)·0.5×·1×·2×, 전투 연출 끄기, 화면 흔들림 끄기 | [프로토타입: 즉시/1×] |

## 10. 픽셀 아트 가이드

### 10.1 규격
| 항목 | 규칙 |
|---|---|
| 타일 | 32×32, 3/4 오버헤드(위에서 내려다보되 벽·인물의 앞면이 보임) |
| 배율 | 정수 배율만(1×·2×·3×), 최근접 보간 |
| 광원 방향 | 좌상단 고정(그림자 우하단) |
| 조명 | 타일에 굽지 않는다. 렌더러가 조도 단계별 곱셈 레이어 + 광원 반경 그라데이션(정수 단계) |
| 팔레트 | 세계는 탈채도 회색·갈색(재의 장막), **정보색 예약**: 피 빨강, 경고 호박색, 냉기 파랑, 유물 청록. 일반 타일에 정보색 사용 금지 |
| 개체 | 장비 레이어(종이 인형): 몸 → 내의·중간 → 갑옷 → 외투 → 머리 → 손 무기 순 합성 |
| 오버레이 | 방향 화살표(발밑 8×8), 젖음(물방울 4×4), 출혈(바닥 핏자국 타일 3단계), 넘어짐(눕힌 스프라이트 대신 90° 회전 + 아이콘) |
| UI 아이콘 | 16×16·24×24, 1px 외곽선 |

### 10.2 프로토타입: DCSS 타일
- Dungeon Crawl Stone Soup 타일셋(32×32, CC0)을 사용. **파일별 라이선스를 확인**하고(후기 추가분 예외 가능) 크레딧 파일에 출처를 남긴다(CC0라도 표기).
- 판타지 던전 색이 강한 타일(마법 이펙트, 화려한 몬스터)은 쓰지 않고, 폐허·흙·돌·인간·개과 동물·기본 무기 위주로 고른다.
- DCSS 타일에는 방향이 없으므로 방향은 오버레이 화살표로 대체.

### 10.3 교체 기준 (하나라도 해당하면 교체 대상)
1. 플레이 정보를 못 담음: 방향(4·8방향 스프라이트 필요), 상처 부위, 젖음.
2. 세계관 불일치: 마법·판타지 종족 느낌, 장막 아래 탈채도 톤과 충돌.
3. 1× 1080p에서 3초 안에 식별 실패(플레이테스트 기준: 재늑대 vs 굴쥐 vs 약탈자 구분율 95% 미만).
4. 종이 인형 레이어 호환 불가.
5. Steam 출시 전 전량 자체 제작 또는 명확한 상업 라이선스로 교체.

교체 우선순위: 플레이어·적(방향 스프라이트) → 장비 종이 인형 → 지형·폐허 → 아이템 아이콘.

## 13. "이런 것까지?" 디테일

1. 위험 시간은 항상 내림(floor) → 표시된 턴보다 일찍 죽는 일이 없다.
2. P0 경고 직후 이동 키 1회는 무시된다(연타로 죽는 사고 방지).
3. 내출혈은 상처 목록에 "?"로만 → 총 출혈 합에 빠져 있어 "숫자는 괜찮은데 어지럽다"가 단서가 된다.
4. 로그 한 줄 복사에 시드·턴·로드 해시가 붙어 남이 그대로 재현할 수 있다.
5. 모르는 적은 명중%가 범위("30~50%")로 나온다 — 규칙은 공개, 적 수치는 지식.
6. 도식 상처는 색 + 무늬 → 색맹도 경상·중상을 구분.
7. 정보색(피 빨강 등)은 일반 타일에 쓰지 않는다 → 화면의 빨강은 항상 의미가 있다.
8. 조명은 타일에 굽지 않고 렌더러 레이어 → 같은 타일이 장막 농도에 따라 다르게 보인다.
9. 사망 보고서 "놓친 기회"는 반사실 시뮬 대신 휴리스틱 → 난수 결과를 스포일하지 않는다.
10. 타일 배율은 정수만 → 4K에서도 46×25 타일로 같은 시야(정보 공정성).
11. 툴팁 중첩 깊이 3, Shift 홀드로 고정 → 마우스 떨림에 닫히지 않는다.
12. 바람 표시가 상단 바에 항상 있다 → 냄새 규칙(07)을 매 순간 계산할 수 있게.

## 14. 대칭 적용

- 적 보기(`X`): 같은 신체 패널을 연다. 단 **보이는 것만**: 외부 상처·출혈 흔적·절뚝임. 내출혈·정확한 혈액량은 의료 숙련·지식(06)에 따라 "많이 흘림/조금" 수준으로.
- 적의 사기는 숫자 대신 행동 묘사("주춤거림", "도망칠 곳을 찾음") + 지식 단계에 따라 범위 수치.
