# 02 — 신체와 건강 (Body & Health)

> 상위 기준: `CANON.md` §4 (혈액 5,000ml, 15/30/40/50%, 체온 37/35/32). 충돌 시 CANON 우선.
> 관련: 01-time-and-turns, 03-survival, 04-psyche, 05-progression, 07-combat, 08-items-and-crafting, 11-modding, 12-ui-ux

## 0. 결론 요약

- 몸은 **부위 트리**다. 전체 HP는 없다. 죽음은 치명 부위 파괴, 혈액 50% 손실, 체온, 패혈·질병 같은 **구체적인 원인**으로만 일어난다.
- **상처는 개체다.** 상처마다 유형·심각도(sev)·출혈·통증·오염·감염 경주·처치 이력·치유 진행을 따로 갖는다.
- 부위 효율에서 **기능 능력치 7종**(의식·이동·조작·시야·청각·호흡·혈액순환)을 계산하고, 이 값이 TU·명중·처치 품질·체온 등 모든 시스템에 들어간다.
- 처치의 핵심 질문은 "무엇으로, 어디서, 어떤 손으로, 얼마나 빨리"다. 품질 공식이 전부 공개된다.

## 2. 신체 트리 [인간형·사족형: 프로토타입 / 기계형: 후속]

### 2.1 인간형 (`Body.Humanoid`)

- **외부 커버리지**는 무작위 피격 시 부위 가중치이고, 외부 부위의 합은 100이다. **내부** 부위는 부모 부위가 관통당했을 때 내부 분배표(§2.2)로 맞는다.
- HP는 체격 1.0 기준이다. 실제 HP는 `round(기본 HP × 체격)`이다.
- **상처 sev = 07-combat의 피해량 D**(부위에 들어간 최종 피해 포인트)다. 무기 한 방은 대개 D 3~20이다. 심각도 표기는 07과 같이 `D / 부위 최대HP`로 경상(<25%)·중상(<50%)·심각(<100%)·파괴(≥100%)를 쓴다.
- **뼈 강도**(골절 임계)는 기본값이 `round(HP × 0.4)`(07의 '부위HP 40%')이고, 갈비뼈(8)·골반(20)만 예외로 덮어쓴다.

## 3. 부위 효율과 기능 능력치 [프로토타입]

### 3.1 부위 효율

```
부위효율 e = clamp(0, 1, 남은HP / 최대HP) × Π(상처·상태의 효율 상한 적용 = min)
  골절 상한: 금 0.6 / 단순 미처치 0.1 / 단순 부목 0.2 / 복합 0.0 (치유 진행에 따라 1.0까지 선형 회복)
  지혈대 아래 부위: 0
  힘줄 절단: 0.5 (봉합 수복 전)
자식 의존: 손효율은 전완·상완 효율과 곱한다(능력치 공식 안에서 처리)
```

### 3.2 기능 능력치 (0~1, 각성제 등으로 1.2까지)

```
산소공급   = min(호흡, 혈액순환)
의식       = 뇌e × (1 − P통증 − P혈액 − P피로 − P체온 − P약물 − P쇼크) × (0.4 + 0.6 × 산소공급)
의식계수   = clamp(0, 1, (의식 − 0.3) / 0.4)          // 이동·조작에 곱한다. 의식 0.7 이상이면 1
다리효율   = 대퇴e × 정강이e × (0.6 + 0.4 × 발e)
  발e      = 발HP비 × (0.85 + 0.15 × 발가락 잔존비)
이동       = (0.5 × 다리L + 0.5 × 다리R) × 골반e × 의식계수
  예외: 한 다리 < 0.2 → 이동 = 다른 다리 × 0.3 (목발·지팡이 0.55)
손조작(h)  = 상완e × 전완e × 손e × Σ(손가락 가중 × 손가락e)
  손가락 가중: 엄지 .35 · 검지 .25 · 중지 .18 · 약지 .12 · 소지 .10
조작(표시) = (0.6 × 주손 + 0.4 × 비주손) × 의식계수
  한손 행동 = 사용 손 조작 / 양손 행동 = min(주,비) × 0.5 + (주+비) / 4
시야       = (max(눈L,눈R) × 0.75 + min(눈L,눈R) × 0.25) × 의식계수   // 한쪽만 남으면 원근 상실 플래그
청각       = max(귀L,귀R) × 0.7 + min(귀L,귀R) × 0.3
호흡       = (0.5 × 폐L + 0.5 × 폐R) × 기도e × 흉부상한(갈비뼈 골절 0.8)
혈액순환   = 심장e
```

| 패널티 항 | 공식 |
|---|---|
| P통증 | max(0, 통증 − 20) / 200 |
| P혈액 | 손실 L%: <15 → 0 / 15~30 → 0.05 + (L−15)×0.01 / 30~40 → 0.20 + (L−30)×0.02 / 40~50 → 0.40 + (L−40)×0.04 |
| P피로 | 피곤 0.03 / 지침 0.08 / 탈진 0.15 (03-survival) |
| P체온 | <35.0 → 0.05 / <34.0 → 0.15 / <32.0 → 0.40 / >39.5 → 0.10 / >41.0 → 0.40 |
| P쇼크 | 쇼크 상태 0.15 |
| P약물 | DrugDef 값 합 |

| 의식 | 상태 |
|---|---|
| ≥ 0.7 | 정상 |
| 0.5 ~ 0.7 | 둔함: 인식 판정 −10 |
| 0.3 ~ 0.5 | **혼미**: 매 이동마다 넘어짐 판정 10%, 복잡한 행동(봉합·자물쇠) 불가 |
| < 0.3 | **기절** |

### 3.3 검산 1 — 의식과 손 조작

- 부상: 대퇴 베임 sev 15(43%, 중상), 전완 물림 sev 8, 정강이 단순 골절. 혈액 손실 25%, 피로 '지침'.
- 통증 = 15 × 1.0(베임) × 0.9(사지) + 8 × 1.1(물림) × 0.9 = 13.5 + 7.92 = 21.42, 여기에 골절을 더한다
  - 부목 있음 +6 → **27.42**(경미) / 부목 없음 +15 → **36.42**(중간). 아래는 **부목 없는 경우**다.
- P통증 = (36.42 − 20)/200 = 0.0821, P혈액 = 0.05 + (25 − 15) × 0.01 = 0.15, P피로 = 0.08
- 의식 = 1.0 × (1 − 0.3121) × (0.4 + 0.6 × 1.0) = **0.688** → 둔함(인식 −10)
- 같은 상태에서 폐 하나를 찔려 호흡 0.5 → 0.688 × (0.4 + 0.3) = **0.482** → **혼미**(봉합·자물쇠 불가)
- 오른손(주손) 중지+약지 손실 → 손가락 합 = 1 − 0.18 − 0.12 = 0.70 → 조작 = 0.6 × 0.7 + 0.4 × 1.0 = **0.82**, 양손 행동 = 0.7 × 0.5 + 1.7/4 = **0.775**

## 4. 상처 개체 모델 [프로토타입]

```
Wound {
  id, partId, type: WoundDef id, sev: int(피해 포인트), depth: skin|muscle|bone|organ,
  source: {kind, actorId, itemId, damageType}, createdAt: TU,
  bleed: 0.1ml/턴 단위 정수, artery: ArteryDef id | null, internal: bool,
  contamination: 0~100, infection: {state: none|pending|active|cleared, I: 0~100, M: 0~100},
  treatments: [{kind, quality, at, byActorId}], tourniquetAt: TU|null,
  heal: 0~sev, foreignBody: ItemDef id|null, tendonCut: bool, fracture: FractureState|null,
  knownToOwner: none|symptom|diagnosed      // 내출혈·감염 초기 은닉용
}
```

- **부위 HP = 최대HP − Σ(미치유 sev)**. HP ≤ 0: 손가락·발가락·손·발·귀·코는 **절단(떨어져 나감)**, 사지 큰 부위는 **파괴**(효율 0, 절단 처치 대상), 뇌·심장은 사망.
- 같은 부위에 같은 유형 상처가 3개를 넘으면 가장 작은 둘을 합쳐 하나로 만든다(목록 폭발 방지, 합산 sev는 보존).

## 6. 혈액·출혈·응고 [프로토타입]

```
상처 출혈(ml/턴) = sev × 유형 출혈계수 × 부위 혈관계수 + 동맥 출혈
최종 출혈       = 상처 출혈 × 처치계수 × 혈액순환 × 상황계수
  상황계수: 달리기·전투 행동 1.3 / 누움 0.8 / 술 단계당 +0.15 / 체온<35 0.8 / 각성제 1.1
응고(비동맥): 10턴(1,000TU)마다 상처 출혈 × 응고계수

```

## 19. "이런 것까지?" 디테일

1. **옛 흉터가 다시 열린다**: 괴혈 40에 도달하면 치유된 흉터마다 sev 3짜리 베임이 다시 생긴다. 흉터가 많은 노련한 떠돌이일수록 괴혈병에 더 취약하다.
2. **더러운 손**: 피·흙 묻은 손으로 붕대를 감으면 Q −10, 오염 +5. 물 200ml로 손을 씻는 데 300TU가 든다.
3. **지혈대 시계**: 지혈대를 감은 시각이 상처에 기록된다. 2시간이 지나면 손이 저리다는 사고가 생기고, 4시간이면 괴사한다.
4. **한 손 압박 이동**: 압박하면서 걸을 수 있지만 그 손으로는 아무것도 들 수 없다. 방패를 놓아야 할 수도 있다.
5. **손가락 하나가 무기를 바꾼다**: 검지를 잃으면 활 당김 조작이 엄지·검지 의존(가중 0.6)이라 활 명중이 크게 떨어진다. 창은 영향이 적다(07-combat의 무기별 손가락 가중).
6. **소작은 화상으로 남는다**: 출혈은 멈추지만 화상 상처가 새로 생겨 감염 기본 25와 매일 붕대 교체가 따라온다.
7. **기절할 때 손을 놓는다**: 횃불을 들고 기절하면 횃불이 떨어진다. 마른 풀 위라면 불이 난다.
8. **물린 직후 지지기**: 거품병 확률이 절반으로 준다. 단, 잠복 10~40일 동안 확인할 방법이 없다.
9. **누우면 산다**: 내출혈 응고는 누워서 쉬면 0.92 → 0.85로 빨라진다. 같은 간 손상이 45% 대 24%로 갈린다.
10. **재관류**: 4시간 가까이 감았던 지혈대를 풀면 통증 +10과 함께 남은 상처가 다시 피를 흘린다.
11. **심장과 출혈**: 혈액순환이 낮으면(심장 손상) 출혈도 비례해서 줄어든다. 죽어가는 심장이 역설적으로 출혈을 늦춘다.
12. **말단 동상과 쇼크**: 쇼크 상태에서는 손발 혈류가 줄어 동상 위험이 ×1.5다. 겨울 전투 부상은 두 번 위험하다.
13. **술 소독 vs 음주**: 같은 곡주가 바르면 오염 ×0.4, 마시면 출혈 +15%다. 툴팁에 '바르기/마시기'가 따로 나온다.
14. **반대손 붕대**: 자기 오른손을 왼손으로 감으면 자가계수 0.7에 왼손(비주손) 조작이 적용된다.

## 20. 적(NPC·동물)에 대한 대칭 적용

- 모든 개체가 같은 BodyDef 계열, 같은 WoundDef, 같은 공식을 쓴다. 약탈자도 대퇴동맥이 잘리면 약 14~17턴 안에 죽는다(§6.2).
- AI 처치 행동: 적대 인식이 없을 때 '압박 → 붕대 → 도주' 우선순위를 따른다. 의료 숙련이 있는 약탈자는 지혈대를 쓴다.
- 출혈하는 적은 **핏자국**을 남긴다(추적 가능). 내출혈 적은 핏자국 없이 쓰러진다.
- 재늑대는 상처를 핥는다(오염 +5, 출혈 ×0.9). 굴쥐는 감염 저항이 높아(M ×1.5) 질병 매개체가 된다.
- 해부(06-knowledge)로 플레이어는 같은 트리를 확인한다. 늑대 대퇴동맥의 위치를 알면 조준 공격(07)의 가치가 생긴다.
- 기계형은 통증이 없으므로 통증 기반 명중 페널티가 없다. 대신 냉각액 누출과 과열로 같은 '시계'를 갖는다.

## 22. 엣지 케이스 & 악용 방지

| 사례 | 처리 |
|---|---|
| 지혈대를 몸통·목에 | validParts로 거부("목에 지혈대? 질식한다") |
| 지혈대를 감고 상처를 치료한 뒤 풀기를 반복해 시계 초기화 | 풀었다 다시 감으면 누적 시간이 이어진다(30분 이상 풀어야 리셋) |
| 소작으로 모든 상처 해결 | 통증 스파이크·기절, 화상 생성, 흉터 100%, 인두 가열 4,000TU로 억제 |
| 상처 병합 악용(작은 상처 쪼개기) | 병합은 sev 합 보존, 통증·출혈 공식은 선형이라 이득 없음 |
| 0ml 혈액 이하 | 혈액은 0~최대로 클램프, 50% 사망이 먼저 걸린다 |
| 기절 중 출혈 사망 | 정상. 사망 보고서에 '기절 → 무처치 출혈'로 사슬 기록 |
| 같은 TU 사망 원인 다중 | 원인 우선순위: 치명 부위 > 혈액 > 체온 > 질병, 나머지는 기여 원인으로 기록 |
| 진통제로 통증 0 → 골절 다리 무한 사용 | 진통은 통증만 줄인다. 골절 악화 판정은 하중 기준이라 그대로 남는다(오히려 무리하기 쉽다) |
| 알약 연타 | 과용 규칙, 같은 약은 지속 중 재투여 시 효과 중첩 없음(지속만 갱신, 내성은 누적) |
