# 01 — 시간과 턴 (Time & Turns)

> **2차 방향 반영(2026-10-13)**: CANON D9 — **1행동 = 1턴, 모든 생물 기본 속도 동일**, 치료·수색·수면 등 일부 행동만 여러 턴. 무기 무게·과적·지형에 따른 TU 배율과 대각 141 TU는 폐지하고, 몸 상태는 **비틀거림 확률**과 **다턴 행동의 턴 수**로 옮겼다.
> 상위 기준: `CANON.md` §4 (100 TU = 1턴 = 3초, 1시간 = 1,200턴), §7 D9. 충돌 시 CANON 우선.
> 관련: 02-body-and-health, 03-survival, 04-psyche, 05-progression, 07-combat, 09-world-and-simulation, 12-ui-ux, 13-inventory, 14-locations-and-dungeons, 15-abilities

## 0. 결론 요약

- **스톤샤드 기본**: 이동·공격·능력·아이템 사용 같은 기본 행동은 **모두 1턴(100 TU)** 이다. 사람·그늘 사람·말라붙은 자·융합체 모두 같은 속도로 움직인다. 대각 이동도 1턴이다.
- **림월드 추가**: 몸 상태는 "느려짐"이 아니라 **실패 확률**(이동 중 비틀거림)과 **다턴 행동의 턴 수**(다친 손으로 붕대 감기 5턴 → 7턴)로 나타난다. 치료·수색·수면·착탈·요리는 여러 턴 걸리는 **채널 행동**이고 중간에 끊길 수 있다.
- 내부 단위 TU(100 = 1턴)와 우선순위 큐 스케줄러는 유지한다. 반응(phase 1)·빈틈(+50 TU)처럼 "같은 턴 안의 순서"를 다루는 규칙에만 TU의 세밀함을 쓴다.
- 위협이 없으면 자동 진행, 위협을 감지하면 즉시 턴제로 돌아간다. 플레이어가 없는 층은 **정지**한다(14 §9).

## 1. 목적 / 설계 의도

| 의도 | 플레이어 결정에 미치는 영향 |
|---|---|
| 한 턴은 한 번의 선택이다 | 모든 기본 행동이 같은 값이라 "지금 무엇을 할까"에만 집중한다. 숫자 계산 대신 위치·순서를 고민한다 |
| 시간이 곧 자원이다 | "붕대(5턴)를 감을까, 손으로 누르고(1턴) 도망칠까?" — 다턴 처치가 생사를 가른다 |
| 다친 몸은 실수한다 | 다리를 다치면 느려지는 게 아니라 **휘청인다**. 도망치다 한 턴을 날리는 것이 무섭다 |
| 긴 행동은 끊긴다 | 야영지 선택, 불 위치, 문 닫고 석관 열기(14)가 의미를 갖는다. 아무 데서나 자면 습격을 당한다 |
| 낮·밤·계절이 있다 | 지하에서도 세계 시계는 흐른다. 그늘 사람은 낮에 더 잔다(14 §7) |

## 3. TU 스케줄러 [프로토타입]

### 3.1 자료구조

- 전역 **우선순위 큐**(이진 힙) 하나에 **현재 층**의 모든 행위자와 시스템 틱을 넣는다. 다른 층은 정지 상태로 저장된다(14 §9).
- 큐 항목: `{ readyAt: TU, phase: 0|1|2, initiative: int, seq: int, actorId }`
- 정렬 키(사전식 오름차순):

```
1. readyAt        오름차순  (먼저 준비된 쪽)
2. phase          오름차순  (0 시스템 틱 → 1 반응 → 2 일반 행동)
3. -initiative    오름차순  (반응속도가 높은 쪽 먼저)
4. seq            오름차순  (생성 순서. 플레이어 = 0)
```

- 모든 기본 행동이 100 TU라서 보통은 모든 개체의 `readyAt`이 같은 100 TU 격자 위에 놓인다. 격자를 어긋나게 만드는 것은 **빈틈**(받아넘기기 성공 시 상대 +50 TU, 07 §2.2)과 **잠기운**뿐이다.

### 3.2 phase 정의

| phase | 내용 | 예 |
|---|---|---|
| 0 시스템 틱 | 신체·환경 갱신 | 출혈·통증 틱(매 100TU 경계), 불 확산(100TU), 생존 대사(2,000TU) |
| 1 반응 | '자세' 상태에서 조건이 충족된 예약 행동 | 창벽 자세(15: 인접해 오는 적 선공), 받아넘기기 자세 반격 |
| 2 일반 | 보통 행동 | 이동, 공격, 능력, 아이템 사용 |

- **시스템 틱이 먼저**인 이유: 같은 시각에 출혈로 사망하는 개체는 행동하지 못하고 죽는다.
- 반응속도 `initiative = 민첩 × 2 + 지각` (05). 기절·수면 상태면 0.

### 3.3 실행 루프 (의사 코드)

```
loop:
  e = heap.popMin()
  worldTU = e.readyAt              // 시계는 뒤로 가지 않는다
  if e.phase == 0: runSystemTick(e); heap.push(next tick); continue
  if actor.dead or actor.unconscious: reschedule(+100); continue
  action = actor.isPlayer ? awaitInput() : ai.decide(actor)
  if action.isMove and rollStumble(actor): action = Stumble   // §5.2
  resolve(action)                                             // 후불형: 효과 먼저
  heap.push({readyAt: worldTU + 100 × action.turns, ...})     // 기본 1턴
```

### 3.4 행동 해결 방식

| 유형 | 규칙 | 적용 |
|---|---|---|
| **1턴 행동** | 효과가 즉시 발생하고, 행위자는 100 TU를 기다린다 | 이동·공격·능력·먹기·문·계단·무기 교체 |
| **채널형(다턴)** | 1턴 단위로 진행도가 쌓이고 완료 시점에 효과가 발생한다. 매 턴 사이 중단 검사 | §4.2 목록 |
| **자유 행동** | 0턴. 턴당 1회 제한 | 무기 떨구기, 토글 켜기·끄기(15), 한마디 외치기 |
| **선딜형** [후속] | 비용의 일부가 지난 뒤 효과 발생 | 양손 무기 내려치기. 07과 협의 |

### 3.5 동시성 충돌

- 같은 `readyAt`에 두 개체가 같은 칸으로 이동하려 하면 키 순서상 먼저 처리되는 쪽이 칸을 차지한다. 나중 개체는 행동이 무효가 되고, 같은 TU 안에서 **AI가 1회 재계획**한다(재계획 비용 0, 루프 방지를 위해 1회만).
- 동률 처리 결과는 전투 로그 디버그 모드(`Shift+D`)에서 정렬 키로 볼 수 있다.

### 3.6 검산 1 — 순서 결정

플레이어(민첩 12, 지각 10 → initiative 34, seq 0)와 그늘 사람 A(민첩 14, 지각 12 → 40, seq 5)가 둘 다 `readyAt = 10,200`이다. 같은 시각에 출혈 틱(phase 0)도 있다.

| 순서 | 항목 | 키 |
|---|---|---|
| 1 | 출혈 틱 | (10200, 0, –, –) |
| 2 | 그늘 사람 A | (10200, 2, −40, 5) |
| 3 | 플레이어 | (10200, 2, −34, 0) |

→ 그늘 사람이 먼저 벤다. 플레이어가 '창벽 자세'(phase 1)였다면 (10200, 1, …)로 그늘 사람보다 먼저 찌른다. 속도가 같은 세계에서 **민첩은 순서를 산다**.

## 5. 몸 상태가 시간에 주는 영향 [프로토타입]

### 5.1 다턴 행동의 턴 배율

- 모든 배율은 곱셈이고, 각 계수는 **천분율 정수**(permille)로 저장한다. 최종값에서만 올림한다.
- 전체 곱의 상한은 ×4.0이다. 넘으면 "할 수 없다"고 표시한다(예: "손이 떨려 붕대를 감을 수 없다").
- **1턴 행동에는 배율을 쓰지 않는다.** 1턴 행동의 불이익은 명중·피해·비틀거림으로 나타난다(02 §2.0, 07).

| 원천 | 조건 | 배율 | 정의 문서 |
|---|---|---|---|
| 조작 능력 | 조작 k(02 §3.2, 손가락·힘줄·지혈대 반영) | ×(1/k), k < 0.10이면 불가 | 02 |
| 팔 상태(쓰는 팔) | 타박 / 부상 / 중상 / 불구 | 1.0 / 1.1 / 1.25 / 그 팔 불가(한 손 행동만) | 02 §2.0 |
| 피로 | 피곤 / 지침 / 탈진 | 1.05 / 1.15 / 1.30 | 03 §6 |
| 통증 | 경미 / 중간 / 심각 / 극심 | 1.00 / 1.05 / 1.15 / 1.30 | 02 §7 |
| 혈액 손실 | ≥15% / ≥30% | 1.05 / 1.20 | CANON |
| 추위 손떨림 | 체온 < 36.0 / < 35.0 / < 34.0 | 1.10 / 1.25 / 1.50 | 03 §7 |
| 젖은 끈 | 착탈만 | 1.20 | |

### 5.2 이동 중 비틀거림

```
비틀거림% = clamp(0, 60, 왼다리 + 오른다리 + 지형 + 몸)
  다리(각, 02 §2.0): 멀쩡 0 · 타박 0 · 부상 5 · 중상 15 · 불구 30
  지형(§5.3): 진흙 +10 · 얕은 물 +10 · 잔해 +5 · 마르지 않은 핏자국 +5 · 포자 바닥 +5 · 얼음 +15 [후속]
  몸: 혈액 손실 15% +5 / 30% +10 · 통증 극심 +5 · 술 단계당 +5 · 의식 혼미(02 §3.2) +10 · 잠기운 +5
비틀거림 = 그 이동은 실패(제자리), 턴은 소모. 머리 위 "휘청"(12 D14)
양다리 불구 → 기어가기: 이동 1칸 = 2턴, 비틀거림 판정 없음
```

### 5.4 검산 2 — 다친 손으로 붕대 감기
- 오른손 중지+약지 손실 → 조작 0.82(02 §3.3), 통증 '중간'(×1.05), 사지 붕대 기본 5턴.
- 천분율: 1000 × 1000 / 820 = 1219.5(분수 유지) → × 1050 / 1000 = 1280.5 → 5 × 1.2805 = 6.40 → 올림 **7턴**.
- 같은 사람이 응급 처치(15)를 가졌다면 5 × 0.6 = 3 → 3 × 1.2805 = 3.84 → **4턴**.

### 5.5 검산 3 — 다친 다리로 진흙 건너 도망치기
- 왼다리 중상(15) + 오른다리 멀쩡(0) + 진흙(10) + 혈액 손실 15%(5) = **30%**.
- 한 칸 가는 데 드는 기대 턴 = 1 / (1 − 0.30) = **1.43턴**. 진흙 10칸 = 기대 **14.3턴**.
- 쫓는 그늘 사람(멀쩡, 비틀거림 10% = 진흙만): 10 / 0.9 = **11.1턴**. 10칸 동안 거리가 약 **3.2칸** 줄어든다. 속도가 같아도 **도망은 다리 상태로 결판난다**는 것이 숫자로 드러난다.

## 8. 수면 중 습격 / 각성 [프로토타입]

> 이 절은 플레이어와 **잠든 거주자**(14 §7)에 똑같이 쓰인다.

### 8.1 수면 주기

90분 주기로 반복한다: **얕은 잠 30분 → 깊은 잠 45분 → 얕은 잠 15분**. 수면 부채가 클수록 깊은 잠 구간이 15분씩 늘어난다(최대 +30). 던전 거주자는 생성·재진입 때 얕은/깊은 잠을 직접 배정한다(14 §7.1).

### 8.2 각성 판정

```
도달 세기 = 세기 − 경로 비용 − 주변 소음 + 청각 보정        (07 §9.1)
각성 임계 = (얕은 잠 3 | 깊은 잠 8) + 피로보정 + 특성보정 + 종 보정(14 §7.2)
  피로보정: 지침 +1, 탈진 +3
  특성보정: '얕은 잠' −2, '깊은 잠꾸러기' +3 (04)
도달 세기 ≥ 각성 임계 → 깨어남. 수면 중 1분 틱마다, 그리고 소음 이벤트마다 판정
추가 즉시 각성: 피해, 체온 < 35.0, 젖음, 불 접촉, 질식, 배고픔·갈증 단계 상승
```

### 8.3 잠기운

깨어난 직후 10턴 동안: 명중 −20, 다턴 행동 ×1.3, 비틀거림 +5, 인식 판정 −10. 깊은 잠에서 깼다면 20턴. 갑옷·신발을 벗고 잤다면 그 상태 그대로 깨어난다.

### 8.4 야간 기습

- 자는 대상을 공격하면 07 §2.8 '잠든 적 기습'이 적용된다(명중 +40, 반응 불가, 후면 부위 가중, 첫 타 피해 ×1.5).
- AI 약탈자는 수색대로 접근할 때 소음이 큰 장비를 피한다(대칭 규칙).

**검산 4** — 깊은 잠(8) + 지침(+1) → 임계 9. 실외, 맑은 밤(주변 소음 0).
- 약탈자의 외침(세기 12)이 4칸 밖: 12 − 4 = 8 < 9 → **못 깬다**. 3칸이면 9 ≥ 9 → 깨지만 약탈자는 이미 3턴 거리다.
- 같은 상황에서 얕은 잠(3 + 1 = 4)이면 8칸 밖(12 − 8 = 4)에서 깬다.
- 재비 오는 밤(주변 소음 3)이면 얕은 잠이어도 5칸에서야 깬다(12 − 5 − 3 = 4).
- 가죽 장화 약탈자의 발소리(세기 3)는 바로 옆(경로 1)이어도 3 − 1 = 2라서 얕은 잠(4)조차 깨우지 못한다. **보초·함정 없이 자는 것은 도박**이다.

## 14. "이런 것까지?" 디테일

1. **젖은 끈**: 젖은 장화·갑옷 끈은 착탈 턴 ×1.2. 비 오는 밤 습격에 장화 신는 데 3 × 1.2 = 3.6 → 4턴.
2. **추운 손**: 맨손으로 영하에서 붕대를 감으면 ×1.10 이상. 장갑을 낀 채 가능한 처치(지혈대)와 벗어야 하는 처치(봉합)가 나뉜다.
3. **활시위**: 비 올 때 걸어둔 시위는 습기를 먹어 위력 −15%. 풀었다 다시 거는 데 9턴.
4. **인두 식음**: 소작 인두는 불에서 꺼낸 뒤 1분(20턴)마다 25%씩 식어 3분이면 쓸 수 없다.
5. **반쯤 입은 갑옷**: 습격으로 사슬옷 착용(6턴)이 끊기면 '머리만 넣은' 상태로 남는다. 방어 50%, 회피치 −2.
6. **대각도 한 걸음**: 대각 이동이 1턴이라 기둥 둘레를 도는 추격전에서 쫓는 쪽도 도망치는 쪽도 손해가 없다. 대신 **문틀은 대각으로 지나갈 수 없다**(벽 모서리 끼임 금지).
7. **빗소리**: 재비는 주변 소음 3이라 발소리(가죽 3)가 사실상 지워진다. 습격자도 같은 혜택을 받는다.
8. **식사 중단**: 10턴 식사를 3턴에 끊으면 30%만 섭취하고, 남은 음식은 '먹다 남은' 상태가 되어 부패 속도가 ×1.5다.
9. **겨울 박명**: 겨울 일몰은 16:00, 박명은 17:00까지다. 오후 3시에 수도원에서 나오면 야영지 도착 전에 어둡다.
10. **잠기운 + 맨발**: 신발을 벗고 자다 깨면 발 방어 0, 잔해 위에서 비틀거림 +5(잔해) +5(잠기운).
11. **시스템 틱 우선**: 같은 TU에 출혈 사망과 마지막 공격이 겹치면 출혈 사망이 먼저다. 사망 보고서에 "마지막 공격 직전 사망".
12. **무기 떨구기는 자유 행동**: 활을 든 채 근접전이 시작되면 활을 떨구고(0턴) 사냥칼을 꺼내면(1턴) 한 턴, 활을 배낭에 넣고 꺼내면 두 턴이다. 떨군 활은 진흙에 빠질 수 있다.
13. **휘청과 핏자국**: 내가 흘린 피(마르지 않은 핏자국 +5)가 내 퇴로를 미끄럽게 만든다. 출혈 중 같은 길로 되돌아 도망치면 더 휘청인다.

## 15. 적(NPC·동물)에 대한 대칭 적용

- 모든 개체가 같은 스케줄러, 같은 ActionDef, 같은 비틀거림 규칙을 쓴다. **기본 속도는 모두 1행동 = 1턴**이다(D9). 종의 차이는 민첩(순서), 회피, 고유 능력(그늘 사람 '달려들기': 2칸 이동 + 공격, bestiary §17)에서 나온다.
- 다리를 베인 약탈자는 비틀거리며 도망친다. 추격할지는 플레이어가 비틀거림%를 보고 판단할 수 있다(적 툴팁에 관찰 가능한 절뚝임 표시, 12).
- 거주자도 잔다(14 §7). 같은 각성 판정을 쓴다.
- AI도 채널 행동이 끊긴다. 붕대를 감던 약탈자를 공격하면 처치가 무효가 된다.
- 기계형은 피로 대신 과열(02 §15)로 다턴 배율을 받는다 [후속].

## 17. 엣지 케이스 & 악용 방지

| 사례 | 처리 |
|---|---|
| 0턴 행동 무한 반복 | 자유 행동은 턴당 1회 |
| 채널 시작-취소로 정보 얻기 | 정보는 시작 전 툴팁에 이미 공개된다. 취소해도 소모 턴은 환급하지 않는다 |
| 문 열고 닫기로 적 AI 교란 | 문 조작은 소음. AI는 '최근 문 소리'를 기억해 수색한다 |
| 대기 연타로 적 접근 유도 | 정상 플레이로 인정 |
| 다턴 배율 상한 초과 | ×4.0에서 행동 불가 처리, 대체 행동 제안 |
| 비틀거림을 이용한 "의도적 제자리" | 이득 없음(대기와 같다, 기력 회복 ×2도 없음) |
| 시계 역행 | 스케줄러는 `readyAt < worldTU`를 거부하고 단언 오류 |
| 같은 seq 충돌(모드 스폰) | seq는 전역 증가 카운터, 저장 파일에 포함 |
| 층 왕복으로 재사용 대기 회복 | 대기는 "자기 턴"을 센다. 층 전환 1턴은 1턴으로만 친다 |
| 수면 중 굶어 죽기 | 수면 채널은 배고픔·갈증 단계 상승 시 강제로 깬다 |

## 19. 열린 질문

1. 1년 90일(겨울 35일)은 CANON P1 결정 대기다.
2. 장비 착탈 다턴(사슬옷 6턴)이 D9 "일부 행동만 여러 턴"의 범위에 드는지 확인 필요(13 §22-3).
3. 비틀거림 상한 60%가 너무 높으면 "다리 하나 중상 = 도망 불가"가 너무 쉽게 성립한다. 봇으로 도주 성공률을 잰다.
4. 대각 이동 1턴은 탐색을 빠르게 하지만 문틀·모서리 규칙(§14-6)이 없으면 벽 틈 통과가 생긴다. 맵 생성(14)과 함께 확정한다.
5. 프로토타입 코드(prototype.md)는 아직 TU 배율 모델이다. 이식 순서: 공격 TU 고정 → 이동 TU 고정 → 비틀거림 → 다턴 처치 턴 수.
6. 자동 모드 중 '수상한 소리'(T3)가 너무 자주 멈추게 하면 피로감이 생긴다. 지각 판정 임계 테스트가 필요하다.
