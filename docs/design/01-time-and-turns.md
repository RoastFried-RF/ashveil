# 01 — 시간과 턴 (Time & Turns)

> 상위 기준: `CANON.md` §4 (100 TU = 1턴 = 3초, 1시간 = 1,200턴). 충돌 시 CANON 우선.
> 관련: 02-body-and-health, 03-survival, 04-psyche, 05-progression, 07-combat, 09-world-and-simulation, 12-ui-ux

## 0. 결론 요약

- 세계의 모든 변화는 **정수 TU 시계 하나**로 진행된다. 행동마다 TU 비용이 있고, 비용은 몸 상태(부상·과적·피로·통증·추위)에 따라 **곱셈으로** 늘어난다.
- 다음 행동 시각이 가장 이른 개체가 먼저 움직인다(우선순위 큐). 동률은 **시스템 틱 → 반응 → 일반 행동**, 그다음 반응속도, 마지막으로 생성 순서로 정한다. 같은 시드와 같은 입력이면 항상 같은 순서가 나온다.
- 위협이 없으면 자동 진행, 위협을 감지하면 즉시 턴제로 돌아간다. 긴 행동(수면·요리·봉합)은 **채널형**이라 중간에 끊길 수 있고, 끊겼을 때 무엇이 남는지는 행동마다 정해져 있다.

## 1. 목적 / 설계 의도

| 의도 | 플레이어 결정에 미치는 영향 |
|---|---|
| 시간이 곧 자원이다 | "붕대(15턴)를 감을까, 일단 손으로 누르고(즉시) 도망칠까?" 같은 선택이 생긴다. 치료 행동의 TU가 생사를 가른다 |
| 몸 상태가 속도를 바꾼다 | 다리를 다치면 도망칠 수 없다. 그래서 싸움을 시작하기 전에 퇴로와 부상 위험을 따지게 된다 |
| 무기 무게가 템포다 | 무거운 무기는 한 방이 세지만 적이 그 사이에 두 번 움직일 수 있다. 상대 속도를 보고 무기를 고른다 |
| 긴 행동은 끊긴다 | 야영지 선택, 불 위치, 보초(함정)가 의미를 갖는다. 아무 데서나 자면 습격을 당한다 |
| 낮·밤·계절이 있다 | 겨울 낮은 8시간뿐이다. 원정 일정을 일조 시간에 맞춰 짜게 된다 |

## 2. 시간 단위

| 단위 | TU | 턴 | 비고 |
|---|---|---|---|
| 1 TU | 1 | 0.01 | 최소 단위(정수) |
| 1턴 | 100 | 1 | 3초. 기본 행동 1회 |
| 1분 | 2,000 | 20 | 생존 틱 단위 |
| 10분 | 20,000 | 200 | 압축 시뮬 틱 단위 |
| 1시간 | 120,000 | 1,200 | CANON |
| 1일 | 2,880,000 | 28,800 | |
| 1계절 | 일수 × 1일 | | 계절마다 길이가 다르다(§9) |
| 1년 | 90일 = 259,200,000 | | 봄 20 · 여름 15 · 가을 20 · 겨울 35 (09-world-and-simulation 제안 채택) |

- 전역 시계 `worldTU`는 64비트 정수다(JS에서는 `Number.MAX_SAFE_INTEGER` 이내라서 약 3×10⁹일까지 안전하다).
- 날짜 표기: `침묵 후 71년 · 늦가을 7일 · 14:32`. 1년이 90일이라서 나이는 '해(年)' 단위로 센다(05-progression §6).

## 3. TU 스케줄러 [프로토타입]

### 3.1 자료구조

- 전역 **우선순위 큐**(이진 힙) 하나에 모든 행위자와 시스템 틱을 넣는다.
- 큐 항목: `{ readyAt: TU, phase: 0|1|2, initiative: int, seq: int, actorId }`
- 정렬 키(사전식 오름차순):

```
1. readyAt        오름차순  (먼저 준비된 쪽)
2. phase          오름차순  (0 시스템 틱 → 1 반응 → 2 일반 행동)
3. -initiative    오름차순  (반응속도가 높은 쪽 먼저)
4. seq            오름차순  (생성 순서. 플레이어 = 0)
```

### 3.2 phase 정의

| phase | 내용 | 예 |
|---|---|---|
| 0 시스템 틱 | 신체·환경 갱신 | 출혈·통증 틱(매 100TU 경계), 불 확산(100TU), 생존 대사(2,000TU), 날씨(6시간) |
| 1 반응 | '대기/준비' 상태에서 조건이 충족된 예약 행동 | 창 세우기(접근하는 적 선공), 활 조준 유지 후 발사, 문 뒤 매복 |
| 2 일반 | 보통 행동 | 이동, 공격, 아이템 사용 |

- **시스템 틱이 먼저**인 이유: 같은 시각에 출혈로 사망하는 개체는 행동하지 못하고 죽는다. "마지막 일격"을 출혈 판정 뒤에 둬서 결과를 명확하게 한다.
- 반응속도 `initiative = 민첩 × 2 + 지각` (05-progression). 기절·수면 상태면 0.

### 3.3 실행 루프 (의사 코드)

```
loop:
  e = heap.popMin()
  worldTU = e.readyAt              // 시계는 뒤로 가지 않는다
  if e.phase == 0: runSystemTick(e); heap.push(next tick); continue
  if actor.dead or actor.unconscious: reschedule(+100); continue
  action = actor.isPlayer ? awaitInput() : ai.decide(actor)
  cost   = computeTU(action, actor)          // §5
  resolve(action)                            // 후불형: 효과 먼저, 대기 나중
  heap.push({readyAt: worldTU + cost, ...})
```

### 3.4 행동 해결 방식

| 유형 | 규칙 | 적용 |
|---|---|---|
| **후불형** | 효과가 즉시 발생하고, 행위자는 비용만큼 기다린다 | 비용 ≤ 300TU인 대부분의 행동(이동·공격·줍기) |
| **채널형** | 100TU(또는 정의된 덩어리) 단위로 진행도가 쌓이고, 완료 시점에 효과가 발생한다. 매 덩어리 사이에 중단 검사를 한다 | 비용 > 300TU 또는 Def에 `channel: true` (붕대·봉합·요리·수면·자물쇠) |
| **선딜형** [후속] | 비용의 `windup` 비율이 지난 뒤 효과가 발생한다. 그 사이 대상이 벗어나면 헛친다 | 양손 무기 내려치기, 석궁 조준. 07-combat과 협의 |
| **자유 행동** | 0TU. 턴당 1회 제한 | 무기 떨구기, 한마디 외치기, 자세 표시 변경 |

### 3.5 동시성 충돌

- 같은 `readyAt`에 두 개체가 같은 칸으로 이동하려 하면 키 순서상 먼저 처리되는 쪽이 칸을 차지한다. 나중 개체는 행동이 무효가 되고, 같은 TU 안에서 **AI가 1회 재계획**한다(재계획 비용 0, 루프 방지를 위해 1회만).
- 플레이어는 자기 차례에만 입력하므로 충돌하지 않는다.
- 동률 처리 결과는 전투 로그 디버그 모드(`Shift+D`)에서 정렬 키로 볼 수 있다.

### 3.6 검산 예시 — 순서 결정

플레이어(민첩 12, 지각 10 → initiative 34, seq 0)와 재늑대 A(민첩 14, 지각 12 → 40, seq 5)가 둘 다 `readyAt = 10,200`이다. 같은 시각에 출혈 틱(phase 0)도 있다.

| 순서 | 항목 | 키 |
|---|---|---|
| 1 | 출혈 틱 | (10200, 0, –, –) |
| 2 | 재늑대 A | (10200, 2, −40, 5) |
| 3 | 플레이어 | (10200, 2, −34, 0) |

→ 늑대가 먼저 문다. 플레이어가 '창 세우기'(phase 1)로 대기 중이었다면 (10200, 1, …)로 늑대보다 먼저 찌른다.

### 4.1 근접 공격 TU 공식

07-combat의 무기 계열 표가 **기준 무게에서의 기본 TU**를 정하고, 실제 무기(08의 재질·부피로 계산한 무게)와 몸 상태가 그것을 바꾼다.

```
무게보정 = 1 + (실제 무게 − 계열 기준 무게) × 0.25        // kg당 ±25%
근력초과 = max(0, 실제 무게 − 근력 × 0.3)                  // 근력이 감당하는 무게(kg)
근력계수 = 1 + 근력초과 × 0.10
숙련계수 = max(0.75, 1 − 숙련 × 0.0025)                    // 숙련 100이면 ×0.75
공격TU  = round(계열 기본 × 무게보정 × 근력계수 × 숙련계수 × Π상태수정치)   // 최소 50
```

| 계열(07) | 기본 TU | 기준 무게 | 예: 실제 무게 | 근력 10 | 근력 6 |
|---|---|---|---|---|---|
| 단검 | 70 | 0.4kg | 0.4 | 70 | 70 |
| 한손검 | 100 | 1.4kg | 1.4 | 100 | 100 |
| 창 | 100 | 1.8kg | 1.8 | 100 | 100 |
| 도끼 | 110 | 1.1kg | 1.141(08 강철 손도끼) | 110 × 1.010 = **111** | 111 |
| 둔기 | 110 | 1.5kg | 1.5 | 110 | 110 |
| 양손 | 150 | 3.0kg | 3.0 | 150 | 150 × 1.12 = **168** |

**검산 1** — 한손검(1.5kg, 기준보다 0.1kg 무거움), 근력 10, 숙련 40, 통증 '중간'(×1.05), 피로 '지침'(×1.15)
- 무게보정 = 1 + 0.1 × 0.25 = 1.025 → 100 × 1.025 = 102.5
- 근력초과 = max(0, 1.5 − 3.0) = 0 → ×1.00
- 숙련계수 = 1 − 40 × 0.0025 = 0.90 → 92.25
- 상태: 92.25 × 1.05 × 1.15 = 111.39 → **111 TU**
- 반올림은 마지막에 한 번만 한다. 중간값(102.5 → 103)을 반올림하면 111.94 → 112가 되어 1 TU가 어긋난다.

## 5. TU 수정치 [프로토타입]

### 5.1 적용 규칙

- 모든 수정치는 **곱셈**이고, 각 계수는 **천분율 정수**(permille)로 저장한다. 곱셈은 `a × b / 1000`이고 소수점 아래는 계산 중에 버리지 않는다(분수 누적은 `BigInt` 또는 분자/분모 쌍으로 처리). 최종값에서만 반올림(0.5는 올림)한다.
- 전체 곱의 상한은 ×4.0이다. 상한을 넘으면 행동이 불가능하다고 표시한다(예: "다리가 버티지 못한다").
- 행동마다 `affectedBy` 태그(이동/조작/정신/전신)로 어떤 수정치를 받는지 정한다.

### 5.4 검산 2 — 다친 몸으로 진흙 건너기

과적 r = 0.8(×1.25), 진흙(×1.5), 정강이 골절에 부목을 대서 이동능력 m = 0.6.

- 천분율: 진흙 1500 × 과적 1250 / 1000 = 1875
- 이동능력 역수: 1000 × 1000 / 600 = 1666.67(분수 유지)
- 1875 × 1666.67 / 1000 = 3125.0 → 전체 ×3.125(상한 4.0 이내)
- 100 × 3.125 = **312.5 → 313 TU/칸** (약 9.4초)
- 같은 시간 동안 재늑대(이동 60TU, lore/bestiary)는 5.2칸을 간다. 도망은 불가능하다는 결론이 숫자로 드러난다.

## 8. 수면 중 습격 / 각성 [프로토타입]

### 8.1 수면 주기

90분 주기로 반복한다: **얕은 잠 30분 → 깊은 잠 45분 → 얕은 잠 15분**. 수면 부채가 클수록 깊은 잠 구간이 15분씩 늘어난다(최대 +30).

### 8.2 각성 판정

소음은 07-combat §9.1의 '세기'와 전파 공식을 그대로 쓴다. 깨어 있을 때 기준은 `도달 세기 ≥ 0`이고, 자는 동안에는 이 기준이 각성 임계로 올라간다.

```
도달 세기 = 세기 − 경로 비용 − 주변 소음 + 청각 보정        (07 §9.1)
각성 임계 = (얕은 잠 3 | 깊은 잠 8) + 피로보정 + 특성보정
  피로보정: 지침 +1, 탈진 +3
  특성보정: '얕은 잠' −2, '깊은 잠꾸러기' +3 (04-psyche)
도달 세기 ≥ 각성 임계 → 깨어남. 수면 중 1분 틱마다, 그리고 소음 이벤트마다 판정
추가 즉시 각성: 피해, 체온 < 35.0, 젖음(빗물 유입), 불 접촉, 질식, 배고픔·갈증 단계 상승
```

### 8.3 잠기운

깨어난 직후 10턴 동안: 명중 −20, 모든 TU ×1.3, 인식 판정 −10. 깊은 잠에서 깼다면 20턴. 갑옷·신발을 벗고 잤다면 그 상태 그대로 깨어난다.

### 8.4 야간 기습

- 자는 대상을 공격하면 '무방비' 판정이 적용된다(방어 반응 불가, 후면 수정치, 07-combat).
- AI 약탈자는 접근할 때 '신중 이동'을 써서 소음을 줄인다(대칭 규칙).

**검산 3** — 깊은 잠(8) + 지침(+1) → 임계 9. 실외, 맑은 밤(주변 소음 0).
- 재늑대 울부짖음(세기 12)이 4칸 밖: 12 − 4 = 8 < 9 → **못 깬다**. 3칸이면 9 ≥ 9 → 깨지만 늑대는 이미 1턴 거리에 있다.
- 같은 상황에서 얕은 잠(3 + 1 = 4)이면 8칸 밖(12 − 8 = 4)에서 깬다.
- 재비가 오는 밤(주변 소음 3)이면 얕은 잠이어도 5칸에서야 깬다(12 − 5 − 3 = 4).
- 가죽 갑옷 약탈자의 발소리(세기 3)는 바로 옆(경로 1)이어도 3 − 1 = 2라서 얕은 잠(4)조차 깨우지 못한다. **보초·함정·개 없이 자는 것은 도박**이고, **수면 부채를 쌓지 않는 것이 곧 경계 능력**이라는 점이 수치로 드러난다.

## 14. "이런 것까지?" 디테일

1. **젖은 끈**: 젖은 신발·갑옷 끈은 착탈 TU ×1.2. 비 오는 밤 습격에 신발 신는 데 720TU가 걸린다.
2. **추운 손**: 맨손으로 영하에서 붕대를 감으면 조작 ×1.15. 장갑을 벗어야 하는 작업(봉합)과 장갑을 낀 채 가능한 작업(지혈대)이 나뉜다.
3. **활시위**: 비 올 때 걸어둔 시위는 습기를 먹어 위력 −15%. 풀었다 다시 거는 데 900TU.
4. **인두 식음**: 소작 인두는 불에서 꺼낸 뒤 1분마다 온도 25%가 내려가 3분이면 쓸 수 없다.
5. **반쯤 입은 갑옷**: 습격으로 착용이 끊기면 사슬 셔츠가 '머리만 넣은' 상태로 남는다. 방어 50%, 이동 ×1.2.
6. **대각 141**: 대각 이동은 정확히 √2배라서 대각 지그재그로 도망쳐도 이득이 없다.
7. **빗소리**: 재비는 주변 소음 3(07)이라 발소리(가죽 3)가 사실상 지워진다. 습격자도 같은 혜택을 받는다.
8. **식사 중단**: 10분 식사를 3분에 끊으면 30%만 섭취하고, 남은 음식은 '먹다 남은' 상태가 되어 부패 속도가 ×1.5가 된다.
9. **겨울 박명**: 겨울 일몰은 16:00, 박명은 17:00까지다. 오후 3시에 출발한 원정은 2시간 뒤 어둠 속에 있다.
10. **잠기운 + 맨발**: 신발을 벗고 자다 깨면 발 방어 0, 진흙·잔해 위에서 발 상처 판정을 한다.
11. **시스템 틱 우선**: 같은 TU에 출혈 사망과 마지막 공격이 겹치면 출혈 사망이 먼저다. 사망 보고서에 "마지막 공격 직전 사망"으로 기록된다.
12. **무기 떨구기는 자유 행동**: 활을 든 채 근접전이 시작되면 활을 떨구고(0TU) 단검을 꺼내면 50TU, 활을 등에 메고(150 × 0.8 = 120TU) 꺼내면 170TU다. 120TU 차이다. 떨군 활은 진흙에 빠질 수 있다.

## 15. 적(NPC·동물)에 대한 대칭 적용

- 모든 개체가 같은 스케줄러, 같은 ActionDef, 같은 수정치를 쓴다. 종족별 차이는 `RaceDef.baseMoveTU`(인간 100, 재늑대 60, 굴쥐 70, 수리 드론 80 — lore/bestiary 제안값)와 신체 능력치에서만 나온다.
- 다리를 베인 약탈자는 이동 TU가 올라가 절뚝이며 도망친다. 추격할지는 플레이어가 TU를 비교해 판단할 수 있다.
- 늑대도 잔다. 무리 중 보초 역할 한 마리는 얕은 잠을 유지한다(`AIRole.Sentry`).
- AI도 채널 행동이 끊긴다. 붕대를 감던 약탈자를 공격하면 처치가 무효가 된다.
- 기계형은 피로 대신 과열(02 §15)로 TU 수정치를 받는다.

## 17. 엣지 케이스 & 악용 방지

| 사례 | 처리 |
|---|---|
| 0TU 행동 무한 반복 | 자유 행동은 턴당 1회. 이후 입력은 최소 50TU 행동으로 취급 |
| 채널 시작-취소로 정보 얻기(예: 자물쇠 난이도) | 정보는 시작 전 툴팁에 이미 공개된다(규칙 투명 원칙). 취소해도 소모 TU는 환급하지 않는다 |
| 문 열고 닫기로 적 AI 교란 | 문 조작은 소음 발생. AI는 '최근 문 소리'를 기억해 수색한다 |
| 대기 연타로 적 접근 유도 | 정상 플레이로 인정. 대신 '대기'는 회피 −0, 반응 대기는 'Ready' 행동으로 따로 둔다 |
| TU 곱 상한 초과 | ×4.0에서 행동 불가 처리. 기어가기 등 대체 행동을 제안 |
| 시계 역행 | 스케줄러는 `readyAt < worldTU`를 거부하고 단언(assert) 오류를 낸다 |
| 같은 seq 충돌(모드 스폰) | seq는 전역 증가 카운터라서 저장 파일에 포함된다 |
| 압축 중 사망 | 10분 틱 안에서 사망 조건을 만나면 1분 단위로 되감아 정확한 시각을 기록(사망 보고서용) |
| 수면 중 굶어 죽기 | 수면 채널은 배고픔·갈증 단계 상승 시 강제로 깬다 |
