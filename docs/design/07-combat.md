## 0. 결론 요약

- **스톤샤드 기본**: 공격 1회 = 1턴. 명중은 `50 + (공격치 − 회피치) × 2 + Σ수정치`(5~95). 공격·능력·방어 반응은 **기력**을 쓰고, 액티브 능력(15)은 기존 판정의 특정 항을 바꾼다. 피해는 **HP**와 **6부위 상태**를 깎는다(02 §2.0).
- **림월드 추가**: 한 번의 공격은 **6단계 파이프라인**(명중 → 방어 반응 → 부위 → 방어구 층 → 상처 → 2차 효과)을 거친다. 상처는 개체로 남아 출혈·골절·감염을 만든다. 단계마다 난수 1회, 결과는 전부 로그·툴팁·**화면 위 문구와 숫자**(D14)로 공개된다.
- 승패는 숫자 크기보다 **위치(방향·고저·조명)·기력·사기·잠든 적**에서 갈린다. 정면 1:1은 손해, 측면·후면·어둠·잠든 대상을 만드는 게 이기는 법이다.
- 적은 플레이어와 **같은 규칙**을 쓴다. 다리를 베인 약탈자는 휘청이고, 사기가 꺾인 적은 도망치거나 항복한다. 적도 같은 능력 Def를 쓴다(15 §15).

## 1. 목적 / 설계 의도

| 의도 | 플레이어 결정이 어떻게 바뀌는가 |
|---|---|
| 위치가 숫자보다 크다 | 문간·좁은 복도로 끌어들이고, 등불을 끄고, 단차에 오른다 |
| 상처가 결과를 남긴다 | "이 싸움을 이겨도 출혈로 죽나?"를 매 교전 전에 계산한다 |
| 기력이 템포를 만든다 | 능력을 언제 쓸지, 언제 대기로 숨을 고를지 |
| 사기가 전투를 끝낸다 | 전멸이 아니라 **꺾기**가 목표가 된다. 우두머리를 먼저 노린다 |
| 잠든 적은 기회다 | 방 하나를 잠행으로 지나칠지, 하나씩 기습할지(14) |
| 소음·냄새가 다음 전투를 부른다 | 석관을 열지, 사슬옷을 벗고 지나갈지 |

## 2. 공격 판정 파이프라인 (6단계)

```
[1 명중] ─실패→ 빗나감(소음만 발생, 화면 "빗나감")
   │성공
[2 방어 반응] ─성공→ 막기/받아넘기기 결과
   │실패 또는 반응 불가
[3 부위 결정] → 대부위 → 세부 부위  (능력이 가중을 바꿀 수 있다)
[4 방어구 층] → 바깥층부터: 튕김 / 절반+타격 변환 / 관통
[5 상처 생성] → HP 감소 · 6부위 HP% · 유형·깊이·출혈·동맥·골절·장기
[6 2차 효과] → 통증·기절·무기 떨굼·넘어짐·사기·소음·냄새·내구 · 화면 표시
```

난수: 모든 판정은 `combat` 스트림에서 `roll = 0..99` 정수 1개를 뽑는다. 판정 순서가 고정이므로 같은 시드·같은 입력이면 같은 결과(결정론).

### 2.1 [1단계] 명중 [프로토타입]

```
명중% = clamp(5, 95, 50 + (공격치 − 회피치) × 2 + Σ수정치)                 (CANON 7.2)
성공: roll < 명중%
공격치 = 무기 정확도 + floor((민첩 − 10) × 1.5) + (지각 − 10) + 능력·장비 보너스     (05 §2.1)
회피치 = (민첩 − 10) × 2 + 장비·능력 보너스 − 둔중(13 §6.2) + 크기 보정,
         양수이면 × 다리 계수((왼 + 오른) / 2, 02 §2.0), 내림
크기 보정: 작음 +4 · 보통 0 · 큼 −4 · 거대 −8
```

**Σ수정치 표**

| 분류 | 조건 | 수정 |
|---|---|---|
| 방향 | 측면 / 후면 (§4) | +10 / +20 |
| 고저차 | 공격자가 1단 높음 / 낮음 | +10 / −10 |
| 조명(대상 칸) | 밝음 / 어스름 / 어둠 / 칠흑 | 0 / −5 / −15 / −30 |
| 기습 | 대상이 공격자를 인지 못함 | +20 (반응 불가) |
| 대상 상태 | 넘어짐: 근접 +20, 원거리 −15 / **잠듦·기절**(§2.8) | 표 값 / +40 |
| 공격자 머리·팔 | 머리 상태(02 §2.0: −3/−6/−10/−15), 무기를 쥔 팔 상태(−2/−5/−10) | 누적 |
| 공격자 몸 | 통증 단계당 −5, 혈액 손실 15%↑ −10 / 30%↑ −20, 기력 < 25 −5 / 0 −15, 넘어짐 −20, 잠기운 −20(01 §8.3) | 누적 |
| 협공 | 같은 대상에 인접한 다른 아군 1명당 | +5 (최대 +15) |
| 원거리 | 유효 사거리 초과 1칸당 −3(침착함 절반, 15), 인접 사격(활) −10, 대상 이동 중(직전 행동이 이동) −5 | |
| 엄폐 | 반 엄폐 / 전 엄폐 (원거리만) | −15 / −30 |
| 연기·포자 구름 | 사선상 칸당 | −10 |
| 공간 | 좁은 복도에서 도끼 휘두르기 / 리치 2 무기로 인접 공격 | −15 / −10 |
| 지형(대상) | 대상이 진흙·얕은 물 위 | 회피치 −2 (01 §5.3) |
| 능력 | 칼끝 감각 +8(공격치), 거리 유지 +10, 조준 사격 +25 등(15) | |

### 2.2 [2단계] 방어 반응 [프로토타입]

명중이 확정되면 방어자는 **반응 1회**를 시도할 수 있다. 플레이어는 "반응 정책"(막기 우선 / 받아넘기기 우선 / 반응 안 함)을 설정한다. AI는 성향 Def의 정책을 쓴다.

| 반응 | 성공률 | 방향 제한 | 기력 | 성공 시 |
|---|---|---|---|---|
| 막기(방패) | clamp(0, 85, 방패 막기치 + (근력 − 10) × 2 + 능력 − 방패 팔 상태 불이익) | 정면, 방패쪽 측면(−20) | 4 + floor(피해/2) | 피해가 방패로. 방패 흡수 초과분은 방패 든 팔에 타격 |
| 막기(무기) | clamp(0, 50, 무기 막기치 + (근력 − 10) − 무기 팔 상태 불이익) | 정면만 | 6 + 피해 | 피해 0, 무기 내구 −피해/4 |
| 받아넘기기 | clamp(0, 50, 15 + (방어자 민첩 − 공격자 민첩) × 2 + 무기 받아넘기기치) — 받아넘기기 자세(15) 중 +40, 상한 90 | 정면만, 원거리 불가 | 6 | 피해 0 + 공격자 다음 행동 +50TU(빈틈). 자세 중이면 즉시 반격 1회 |

- **회피 반응은 폐지**: 회피는 명중 공식의 회피치로만 반영한다(1차 설계의 이중 적용 문제 해소).
- **연속 반응 피로**: 같은 100TU 창 안에서 두 번째 반응부터 기력 비용 ×1.5, 세 번째 ×2.
- **반응 불가 조건**: 기력 0, 기절·잠듦·넘어짐(막기만 −20으로 가능), 공격자가 보이지 않음, 기습, 그 팔이 불구.
- **무의미 반응 생략**(옵션, 기본 켬): 최선 반응 성공률이 10% 미만이면 반응하지 않고 기력을 아낀다. 로그·화면에 "반응 생략(3%)".

### 2.3 [3단계] 부위 결정 [프로토타입]

외부 말단 부위의 커버리지(02 정본, ‰, 합 1000)에 보정을 곱한 뒤 `roll 0..(합−1)` 1회로 고른다. 내부 장기는 5단계 장기 판정으로만 맞는다.

| 인간 대부위(02) | 머리 | 몸통(목 20·흉부 200·복부 150·골반 30) | 팔 1개(상완 40·전완 30·손 20) | 다리 1개(대퇴 80·정강이 60·발 30) | 합 |
|---|---|---|---|---|---|
| ‰ | 80 | 400 | 90 ×2 | 170 ×2 | 1000 |

**가중치 보정**(말단 부위별 곱셈 → 정수 ‰ 유지, 순서: 머리 → 몸통 → 오른팔 → 왼팔 → 오른다리 → 왼다리로 누적 구간 생성)

| 조건 | 보정 |
|---|---|
| 공격자가 대상의 우측면 | 오른쪽 부위 ×1.5, 왼쪽 ×0.5 (좌측면은 반대) |
| 공격자가 작음(체고 차 2단↑) | 다리 ×3, 팔 ×0.5, 머리 ×0 |
| 공격자가 고지대 / 대상이 넘어짐 | 머리 ×1.5 / 머리·몸통 ×1.5, 다리 ×0.5 |
| 대상이 잠듦·후면 기습(§2.8) | 목 ×2(경동맥이 드러남) |
| 방패 막기 실패 | 방패 든 팔 ×2 |
| **능력**(15) | 급소 찌르기: 머리·목 ×4 / 머리 강타: 머리 ×4 / 다리 찍기·다리 쏘기: 다리 ×5 |

보정 후 합이 1000이 아니면 실제 합을 상한으로 쓴다(예: 머리 강타 → 1,000 − 80 + 320 = 1,240).

### 2.4 [4단계] 방어구 층 [프로토타입]

부위를 덮는 장비를 **바깥부터** 판정한다: 망토(외투층) → 몸 슬롯(갑옷층) → [안감, 후속] → 자연 방어(털·가죽·외피). 머리·장갑·장화는 단일층(13 §6).

```
실효 방어 = floor(층 방어[피해 범주] × (50 + 내구% / 2) / 100)   ← 내구 0%여도 50% 남음
유효      = 실효 방어 − 현재 관통
유효 ≤ 0           → 판정 생략, 그대로 통과
2 × roll < 유효     → 튕김: 피해 0, 이후 층 판정 중단        (= roll < 유효/2, 정수화)
                      [갑옷 우그러뜨리기(15): 4 × roll < 유효]
roll < 유효         → 피해 floor(D/2), 날 계열은 타격으로 변환, 관통 floor(관통/2)
그 외              → 관통: D·유형·관통 유지, 다음 층으로
```
- 피해 범주: **날**(베기·찌르기·파편·총상) / **타격** / **열**(화염·냉기). 층마다 3개 값.
- 정수 판정이므로 튕김 확률은 ⌈유효/2⌉%, 절반 확률은 유효 − ⌈유효/2⌉%.
- 층이 막은 만큼 그 층·그 부위의 내구가 깎인다(08 §5). 쪼개기(15)는 −10%p 추가.
- 관통 척도는 0~100 정수다. CANON §4·15의 소수 표기(0.2, 0.25)는 ×100(+20, +25)으로 읽는다.

**기대 피해 배율 검산**(1층, 변환 무시)

| 실효 방어 | 관통 | 유효 | 튕김 | 절반 | 관통 | 기대 배율 |
|---|---|---|---|---|---|---|
| 60 | 20 | 40 | 20% | 20% | 60% | 0.2×0.5 + 0.6 = **0.70** |
| 45 (사슬옷) | 8 (녹슨 칼) | 37 | 19% | 18% | 63% | 0.18×0.5 + 0.63 = **0.72** |
| 25 (누빔 재킷 타격) | 10 (파이프 곤봉) | 15 | 8% | 7% | 85% | 0.035 + 0.85 = **0.885** |

### 2.5 [5단계] 상처 생성 [프로토타입]

```
피해 원값 D0 = floor(무기 기본 × 품질 배율 × 날 상태 × 근력 보정 × 팔 상태 피해 배율 × (80 + r)/100),  r = roll 0..40
  날 상태 = (60 + 날% × 0.4) / 100     (베기·찌르기만)
  근력 보정 = (100 + (근력 − 10) × 5) / 100   (근접만. 활은 당김 무게 충족 여부)
  팔 상태 피해 배율 = 02 §2.0 (타박 0.95 / 부상 0.85 / 중상 0.70)
  능력 배율: 흉포 ×1.2(출혈 중 대상), 휘둘러 베기 ×0.7, 기습 첫 타 ×1.5 등
D(방어구 후) → HP −D, 그 6부위 HP% 재계산(02 §2.0)
심각도 = D / 세부 부위 체력 → <25% 경상 / <50% 중상 / <100% 심각 / ≥100% 파괴(절단·분쇄)
```

| 피해 유형 | 상처 | 외부 출혈 ml/턴 (× 부위 혈관계수, 02) | 통증 계수 | 특수 |
|---|---|---|---|---|
| 베기 | 베임 | D × 2.0 | 1.0 | 동맥 확률 D×2%(동맥 부위이고 D ≥ 부위HP 30%일 때만 — D33, 깊게 베기 +15%p), 손·전완·발에서 D ≥ 부위HP 40%면 힘줄 절단 판정 |
| 찌르기 | 찔림 | D × 1.5 | 1.2 | 장기 관통 판정 `clamp(0,80,(D−4)×6)%`(몸통·머리), 내출혈(외부 표시 없음) |
| 타격 | 타박 | 0 | 0.8 | 골절: `(D − 뼈 강도)×8%`(뼈 부수기 ×1.5, 다리 찍기 ×2, 상한 90), 머리면 뇌진탕 판정 |
| 화염 | 화상 | 0 | 1.5 | 감염 기본률 ×2, 의복 착화 판정. 포자 인간·융합체에 ×1.5 |
| 냉기 | 동상 | 0 | 0.6 | 03과 공유 |
| 총상 [후속] | 총창 | D × 2.5 | 1.5 | 장기 판정 ×1.5, 탄 잔류, 사출구 50% |
| 파편 [후속] | 열상 다발 | 조각당 D′×1.5 | 1.0 | 1~3조각 분할 |

- **물기**(동물 턱)는 방어 범주 '날'로 판정하고 상처는 **물림**(02 정본). 프로토타입 출현 종에는 물기 공격자가 없다.
- 동맥 상처는 D와 무관하게 동맥별 고정값(대퇴 150, 02 §2.1). 능력의 "출혈 ×2"는 상처 출혈 항에만 곱한다.
- 화살이 박힌 채면 출혈 ×1/2, 대신 이동·공격마다 통증 +1. 뽑으면 원래 출혈 + 즉시 D×5 ml.

### 2.6 [6단계] 2차 효과 [프로토타입]

| 효과 | 판정 | 비고 |
|---|---|---|
| 출혈 시작 | 5단계 값 | 핏자국·냄새 생성(§9) |
| 통증 | floor(D × 통증 계수) 누적 | 통증 단계는 02 정본 |
| 기절 | 머리 타격·총상: `clamp(0,90,(D − 4)×6 − (의지 − 10)×3 + 능력)%` (둔기는 D+4로 계산, 머리 강타 +40%p) | 기절 시간 = **ceil(D/2) 턴**(D는 실제 피해, 둔기 D+4는 확률에만) |
| 무기 떨굼 | 손·전완 피해: `D × 3%`, 힘줄 절단 시 100% | 무기는 인접 칸으로 |
| 넘어짐 | 다리 피해 D ≥ 세부 부위HP 30%: `D × 4%` / 타격 D ≥ 15: `(D − 10) × 5%` / 능력: 밀쳐내기 50%, 다리 걸기 60% | 4족은 ×1/2. 넘어지면 일어나기 1턴 |
| 사기 | §8 | 큰 상처는 즉시 판정 |
| 소음 | 금속 충돌 8, 비명(통증 급증) 12 | §9 |
| 내구 | 방어구 층·무기 날 | 08 |
| 화면 표시 | §2.9 | D14 |

- 검산(기절 시간): 파이프 곤봉 머리 D 12 → ceil(12/2) = **6턴**(옛 식 600TU와 같다). 마체테 D 11 → ceil(5.5) = **6턴**(옛 식 550TU = 5.5턴은 격자를 벗어났다). D 5 → **3턴**. 기절한 대상은 남은 턴 동안 §2.8 기습 대상이다.

### 2.7 능력 사용 공격 [프로토타입]

- 공격형 액티브(15 §6)는 **같은 6단계 파이프라인**을 쓴다. 능력 Def의 `attackMods`가 지정한 항만 바뀐다.

| 단계 | 능력이 바꾸는 항(예) |
|---|---|
| 1 명중 | 조준 사격 +25(2턴 채널), 거리 유지 +10, 칼끝 감각 공격치 +8 |
| 2 반응 | 받아넘기기 자세 +40%p·반격, 창벽 자세(phase 1 반응 공격) |
| 3 부위 | 가중 배율(머리 ×4, 다리 ×5, 머리·목 ×4) |
| 4 방어구 | 관통 +20/+25, 튕김 구간 절반(우그러뜨리기), 내구 −10%p |
| 5 상처 | 출혈 ×2, 동맥 +15%p, 골절 ×1.5/×2, 피해 ×1.2/×0.7 |
| 6 2차 | 기절 +40%p, 넘어짐 50/60%, 밀림 1칸 |
| 대상 수 | 휘둘러 베기(인접 8칸 각각), 꿰뚫기(일직선 2칸 각각) — 대상마다 1~6단계를 따로, 정해진 순서(시계 방향 북쪽부터 / 가까운 칸부터)로 |

- 능력의 기력은 기본 공격 기력을 **대체**한다. 재사용 대기는 자기 턴을 센다(15 §5).
- 툴팁(L2)은 바뀐 항을 공식 그대로 보여준다: "부위: 머리 80‰ × 4 = 320 / 1,240 → 25.8%".

### 2.8 잠든 적 기습 [프로토타입]

| 항목 | 규칙 |
|---|---|
| 대상 | 잠든 개체(14 §7) 또는 기절한 개체 |
| 명중 | **+40** (기습 +20과 중첩하지 않는다) |
| 반응 | 불가 |
| 방향 | **후면 판정**(방향과 무관하게), 부위 가중 목 ×2 |
| 피해 | 첫 타 ×1.5. 짧은 날 도검(녹슨 칼·사냥칼)은 ×2 |
| 결과 | 맞은 대상은 즉시 깨어나 **잠기운**(01 §8.3: 10턴 명중 −20, 깊은 잠이면 20턴). 비명(소음 12)이 같은 방 잠든 개체의 각성 판정을 부른다 |

**검산 C — 납골실 말라붙은 자 기습** (플레이어: 사냥칼 정확도 12, 민첩 12, 지각 11 → 공격치 12 + 3 + 1 = 16)
- 대상 말라붙은 자(민첩 9, 보통 체구): 회피치 = (9 − 10) × 2 = −2(음수라 다리 계수 생략).
- 명중 = 50 + (16 − (−2)) × 2 + 40 = 50 + 36 + 40 = 126 → **95%**(상한).
- 부위: 목 20 × 2 = 40 → 합 1,020, 목 확률 40 / 1,020 = **3.9%**(평소 2%). 찌르기 D0 = floor(8 × 1.0 × 1.0 × (80 + 20)/100) = 8 → 기습 ×2(짧은 날) = **16**.
- 흉부(HP 40 × 체격 0.8 = 32)에 맞으면 16/32 = 50% → **심각**, 장기 판정 (16 − 4) × 6 = **72%**.
- 교훈(L2): 잠든 적의 첫 타는 거의 확실하고 강하다. 그러나 비명이 방 전체를 깨운다 — 한 방에 셋이면 첫 타 뒤 두 번째 개체는 대개 깨어 있다(14 §7.3).

## 3. 검산 예시

### 예시 A — 약탈자의 손도끼가 플레이어의 우측면을 친다 (낮, 흐림)

| 단계 | 계산 | 결과 |
|---|---|---|
| 공격치 | 손도끼 정확도 4 + floor((13 − 10) × 1.5) = 4 + (지각 10 − 10) = 0 | **8** |
| 회피치 | (민첩 11 − 10) × 2 = 2 − 둔중(고철 사슬옷) 2 + 크기 0 = 0 | **0** |
| Σ수정 | 우측면 +10, 약탈자 기력 22(<25) −5 | +5 |
| 명중% | 50 + (8 − 0) × 2 + 5 | **71%**, roll 63 → 명중 |
| 반응 | 방패는 왼팔 → 우측면 막기 불가. 받아넘기기는 정면만 | **반응 없음** |
| 부위 | 우측면(‰): 머리 80 / 몸통 400 / 오른팔 60·45·30 / 왼팔 20·15·10 / 오른다리 120·90·45 / 왼다리 40·30·15 (합 1000). 오른 상완 구간 480~539 | roll 510 → **오른 상완** |
| 피해 원값 | 14 × 1.05(근력 11) = 14.7 → × (80 + 15)/100 = 13.97 | **D = 13 베기**, 관통 15 |
| 층1 방수포 망토 | 실효 4 − 15 < 0 | 판정 생략 |
| 층2 고철 사슬옷(내구 80%) | 실효 floor(45 × (50 + 40)/100) = 40, 유효 40 − 15 = 25. roll 18: 2×18 = 36 ≥ 25, 18 < 25 | **절반+변환**: D 6 타격, 관통 7 |
| 상처 | 타박 D 6 / 상완 HP 30 = 20% | **경상**, 골절 임계 12 미달, 통증 floor(4.8) = 4 |
| HP·6부위 | HP 100 → 94. 오른팔 Σ 6 → floor(100 − 6 × 100 / 35) = 82 | **오른팔 타박**(명중 −2, 피해 ×0.95, 막기 −5) |

교훈(툴팁 노출): 사슬옷이 없었다면 망토만 남아 **D 13 베기**가 그대로 관통한다 → 13/30 = 43% 중상, 출혈 26 ml/턴, 동맥 확률 26%, 오른팔 62% 타박. 그 대신 사슬옷은 회피치 −2와 걷기 소음 5를 받는다(13).

### 예시 B — 지하 1층, 등불을 든 플레이어가 7칸 밖 그늘 사람에게 활을 쏜다

| 단계 | 계산 | 결과 |
|---|---|---|
| 공격치 | 사냥 활 정확도 10 + floor((11 − 10) × 1.5) = 1 + (지각 14 − 10) = 4 | **15** |
| 회피치 | (민첩 14 − 10) × 2 = 8 + 작은 체구 4 | **12** |
| Σ수정 | 사거리 7 − 유효 6 = 1칸 → −3, 대상 칸 어둠(등불 반경 5 밖) −15, 이동 중 −5 | −23 |
| 명중% | 50 + (15 − 12) × 2 − 23 | **33%**, roll 12 → 명중 |
| 반응 | 방패 없음, 받아넘기기는 원거리 불가 | 반응 없음 |
| 부위 | 인간형(‰) 머리 0~79 / 목 80~99 / 흉부 100~299 / … | roll 250 → **흉부** |
| 피해 | 10 × (80 + 22)/100 = 10.2 | D 10 찌르기, 관통 20 |
| 누더기 셔츠 | 날 3 − 20 < 0 | 판정 생략 |

교훈: 조준 사격(15)이었다면 58%(침착함 60%)였다. 등불을 끄면 그늘 사람의 빛 회피 성향(bestiary §17)은 사라지지만 내 명중도 칠흑 −30이 된다.

| 항목 | 값 |

**검산 D — 손도끼로 1:1 교전**(의지 10 → 최대 100, 활력 12 → 회복 2 + 2 = 4, 적이 매 턴 공격해 오고 내가 매번 방패로 막음, 피해 10)

- 턴당 소모: 도끼 공격 8 + 막기 (4 + 10/2) = 9 → 17, 회복 4 → **순 −13/턴**.

- 대기 턴을 섞으면? 대기 회복 4 × 2 = 8, 그 턴에도 막기 9 소모 → 순 −1. → **맞으면서는 회복할 수 없다.**
- 정답은 접촉 끊기: 문을 닫고(1턴) 대기 3턴(+24), 또는 숨 고르기(15: 최대의 50% = +50). 좁은 통로·문이 기력 경제의 일부가 된다.

### 7.2 밀치기(기본 행동) [프로토타입]
```
성공% = clamp(5, 95, 50 + (공격 체급 − 방어 체급) × 3 + 수정)
체급 = 근력 + floor(체중kg / 10)
수정: 방패 +10, 맨손 +10, 대상 진흙·얕은 물 위 +15, 대상 자세 능력 중 −20
1턴, 기력 10. 성공: 1칸 밀림. 밀린 칸이 벽 → 타격 5(몸통) + 넘어짐 25%. 불·물·포자 바닥이면 해당 환경 효과
밀쳐내기(15 둔기 ③)는 이 판정을 생략하고 명중만 하면 밀어낸다
```
검산: 플레이어 근력 12·72kg → 19, 약탈자 근력 11·68kg → 17, 대상 진흙 위 → 50 + 6 + 15 = **71%**.

### 7.3 넘어뜨리기 · 무장해제 [후속]
```
넘어뜨리기% = clamp(5, 95, 50 + (걸기치 − 균형) × 3)
  걸기치 = 민첩 + floor(레벨 / 2) + 무기 보정(창 +5, 도끼 +10)
  균형   = 민첩 + floor(체중kg/10) + 다리 보정(2족 0, 4족 +8)
  1턴, 기력 12
무장해제% = clamp(5, 75, 30 + (공격자 민첩 − 대상 민첩) × 2 + 보정(도끼 +10, 짧은 날 −10, 대상 양손 −15))
```
- 프로토타입에서 넘어뜨리기는 능력(다리 걸기 60%, 밀쳐내기 50%)으로만 한다.

### 7.4 조준 공격(부위 지정) — 능력으로 대체
- 1차 설계의 범용 조준 공격(부위 지정 −10~−40)은 프로토타입에서 **폐지**한다. 부위를 노리는 것은 **능력의 가중 배율**(머리 강타·급소 찌르기·다리 찍기·다리 쏘기)로만 한다. 이유: 매 턴 부위를 고르는 조작 부담을 없애고, 노리기를 기력·대기라는 자원으로 묶는다.
- [후속 검토] 기력 소모형 범용 조준을 다시 넣을지는 플레이테스트 후 결정.

## 8. 사기 (Morale) [프로토타입: 도주·항복까지 / 포로 처리 후속]

```
사기 = 기본 사기(성향 Def) + Σ사건 수정(감쇠) + 전력비 수정
전력비 = 적 위협 합 / 아군 위협 합 (위협 = HP% × 무기 등급, 시야 내만)
전력비 수정 = clamp(−20, +10, (1 − 전력비) × 10) 정수 내림
판정 시점: 사건 즉시 + 매 5턴
```

| 사건 | 수정 | 감쇠 |
|---|---|---|
| 시야 내 아군 사망 | −15 | 30턴에 절반 |
| 우두머리 사망·도주 | −30 | 없음(교전 끝까지) |
| 자신 6부위 중 하나 중상 / 불구 | −10 / −20 | 상태 유지 동안 |
| 혈액 손실 15% / 30% | −10 / −20 | 상태 유지 동안 |
| 시야 내 아군 도주 | −5 | 20턴 |
| 적 사망(내가 처치) | +5 | 30턴 |

| 구간 | 효과 |
|---|---|
| 40 이상 | 정상 |
| 25~39 흔들림 | 명중 −5, 후퇴 행동 가중 |
| 10~24 도주 | 매 판정 `(25 − 사기) × 4%`로 도주 |
| 10 미만 | 확정 도주 |
| 도주가 결정됐는데 도주 불가(포위·다리 중상 이상·막다른 방) | 인간: 항복 `max(20, (25 − 사기) × 3)%`, 실패하면 "궁지"(명중 +5, 반응 안 함) |

- **사기가 없는 종**: 말라붙은 자(통증·공포를 못 느낌), 융합체, 포자 인간은 사기 판정을 하지 않는다(bestiary §18~20). 그늘 사람은 무리 절반 손실 시 도주.

**검산 E — 약탈자 4인조**(기본 사기 50): 1명 사망 → 35(흔들림). 본인 다리 중상 → 25. 2번째 사망 → 10 → 도주 확률 (25 − 10) × 4 = **60%**. 도주가 결정됐지만 다리 중상이라 비틀거림 15% + 쫓기는 중 → 도주 불가 판정 → 항복 max(20, 15 × 3) = **45%**, 실패 55%는 궁지에 몰린 반격.

**항복 이후 선택** [후속, 프로토타입은 '놓아주기·처형'만]

| 선택 | 조건 | 결과 |
|---|---|---|
| 놓아주기 | — | 해당 세력 평판 +3, "빚진 자"로 재등장 가능. 경험치는 처치와 같다(15 §3) |
| 포박 | 밧줄 1, 2턴 | 끌고 다니면 [후속] |
| 심문 | 포박 상태 | 소문 1개(14 §10) |

**대칭**: 플레이어도 같은 사기 수치를 갖지만 조작권을 빼앗지 않는다. 25 미만이면 "공포"(명중 −10, 04), 10 미만은 04의 정신붕괴 판정으로 넘긴다.

### 12.4 협동 포위 (빛 회피 무리)
1. 대상 주변 8칸 중 정면 1, 측면 2, 후면 1~2 슬롯을 배정.
2. 슬롯이 2개 이상 채워질 때까지 **광원 반경 밖**에서 선회 대기.
3. 채워지면 측면·후면 슬롯부터 공격. 대상이 등을 벽에 대면 후면 슬롯 무효 → 정면 몰림 → 좁은 복도 전술이 성립.

## 16. 깊이 3층

| 층 | 내용 |
|---|---|
| L1 | 때리고 막는다. 측면·후면이 더 잘 맞는다. 피 나면 붕대. 능력은 기력을 쓴다. 잠든 적은 거의 확실히 맞는다 |
| L2 | 사슬옷엔 둔기·쪼개기, 그늘 사람은 좁은 복도로. 지친 적을 노린다. 등불은 양날의 검. 우두머리를 먼저 꺾는다. 잠든 적의 첫 타는 방 전체를 깨운다. 다리가 다친 적은 휘청인다 |
| L3 | 갑옷 우그러뜨리기는 둔기에서 사실상 피해 증가다. 박힌 화살을 일부러 안 뽑는다. 반응 생략 임계로 기력을 짠다. 회피치가 음수인 적에게 다리 쏘기는 회피 이득이 없다(계수가 안 곱해진다) — 다리는 비틀거림을 위해 쏜다. 3층에서 피를 흘리면 융합체가 16칸 밖에서 냄새를 맡는다 |

## 17. "이런 것까지?" 디테일

1. 방패는 방패 든 팔 쪽 측면만 막는다 → 왼손잡이 약탈자는 반대편이 약점.
2. 박힌 화살은 출혈을 절반으로 줄이지만 움직일 때마다 통증 +1.
3. 피격 후 자동으로 돌아서지 않는다 → 두 명에게 끼면 한 명은 계속 후면.
4. 등불을 든 자는 어둠 속 관찰자에게 15칸 밖에서도 보인다(반경 5 × 3).
5. 반응 성공률 10% 미만이면 반응을 생략해 기력을 아낀다(설정 가능).
6. 파이프 곤봉은 무뎌지지 않는다 → 던전 장기 탐험에서 날붙이 대비 정비 비용 0.
7. 도주하는 출혈 적은 핏자국을 남기고, 그 핏자국은 아직 마르지 않아 **추격자를 휘청이게** 한다(+5).
8. 고철 사슬옷 내구가 0%여도 방어의 절반은 남는다(구멍 난 사슬도 사슬).
9. 리치 2 창으로 인접한 적을 찌르면 −10 → 창병은 반 발짝 물러서는 게 이득. 감방 문틀 밖에서 찌르면 안의 적은 닿지 않는다.
10. 받아넘기기 성공은 피해 0에 더해 상대 다음 행동을 50TU 늦춘다 — 같은 속도 세계에서 유일하게 "반 턴"을 버는 방법.
11. 잠든 적 목 가중 ×2 — 잠든 사람은 고개가 젖혀져 있다.
12. 휘둘러 베기는 인접 8칸을 **시계 방향 북쪽부터** 친다. 같은 방향에 있는 순례자(중립)도 맞는다.
13. 말라붙은 자는 사기가 없어 동료가 쓰러져도 물러서지 않는다. 대신 통증 기절도 없다 — 피를 빼거나 HP로 쓰러뜨려야 한다.
14. 고철 투구는 청각 −1 → 뒤에서 오는 그늘 사람 발소리를 한 칸 늦게 듣는다.

## 18. UI 표현

- 공격 대상 호버: 명중% 큰 글씨 + 반응 예상(상대의 최선 반응 %) + 부위 분포 막대. 능력 키를 누르고 있으면 **바뀐 분포**를 보여준다.
- Shift: Σ수정치 전 항목, 방어구 층별 유효·튕김/절반/관통 %(예시 A 표와 동일 형식).
- 방향: 개체 발밑에 작은 화살표, 내 측면·후면 칸은 피격 시 붉은 테두리.
- 맵 위 표시: §2.9 표(정본 12 §2.5).
- 냄새·소음: 토글 오버레이(소음 원 파문, 냄새는 바람 방향 쐐기형 음영).
- 로그 포맷은 12 §5.

## 21. 열린 질문

1. 공격치에 민첩 ×1.5 + 지각, 회피치에 민첩 ×2가 들어가 민첩이 양쪽을 다 가져간다. 같은 민첩끼리는 상쇄되지만 민첩 차이가 4면 명중 차이가 (6 + 8) × 2 = 28%p다. 봇으로 확인.
2. 기본 명중 50%(능력치 10·정확도 0 대 회피 0)가 1행동 = 1턴 리듬에 비해 너무 낮지 않은가? 무기 정확도(+4~+12)로 보정했지만, 근접 기본 60% 근처가 목표라면 정확도를 +5 올린다.
3. 잠든 적 기습 +40과 첫 타 ×1.5(짧은 날 ×2)가 "잠행 → 기습"을 지배 전략으로 만들지 않는가? 비명 각성(12)과 잠행 이동 2턴이 견제 장치다.
4. 사기 없는 종(말라붙은 자·포자 인간·융합체)이 프로토타입 적의 절반 이상이다. 사기 시스템이 약탈자·그늘 사람에서만 보이는데 충분한가?
5. 프로토타입 코드의 숙련 기반 회피(prototype.md §5 #5)는 이 문서 공식으로 교체가 필요하다.
