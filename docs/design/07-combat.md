# 07 — 전투 (Combat)

> 기준: `CANON.md` §4 규칙 상수. 신체 부위 체력·커버리지·장기 구조의 정본은 `02-body-and-health`, 시간 비용의 정본은 `01-time-and-turns`, 숙련 수치의 정본은 `05-progression`이다. 이 문서의 해당 수치는 **예시값**이며 정본과 다르면 정본을 따른다.
> 상태: 초안 v0.1 · 2026-10-13

## 0. 결론 요약

- 한 번의 공격은 **6단계 파이프라인**(명중 → 방어 반응 → 부위 → 방어구 층 → 상처 → 2차 효과)을 거친다. 단계마다 난수 1회, 결과는 전부 로그와 Shift 툴팁에 공개된다.
- 전투의 승패는 숫자 크기가 아니라 **위치(방향·고저·조명)·스태미나·사기**에서 갈린다. 정면 1:1은 손해, 측면·후면·어둠·지친 상대를 만드는 게 이기는 법이다.
- 적은 플레이어와 **같은 규칙**을 쓴다. 다리를 베인 약탈자는 느려지고, 피 흘리는 재늑대는 무리를 부르고, 사기가 꺾인 적은 도망치거나 항복한다.

## 1. 목적 / 설계 의도

| 의도 | 플레이어 결정이 어떻게 바뀌는가 |
|---|---|
| 위치가 숫자보다 크다 | 문간·좁은 통로로 끌어들이고, 횃불을 끄고, 언덕에 오른다 |
| 상처가 결과를 남긴다 | "이 싸움을 이겨도 출혈로 죽나?"를 매 교전 전에 계산한다 |
| 스태미나가 템포를 만든다 | 무작정 연타하지 않고 "숨 고르기"로 템포를 조절한다 |
| 사기가 전투를 끝낸다 | 전멸이 아니라 **꺾기**가 목표가 된다. 우두머리를 먼저 노리거나, 첫 피를 크게 낸다 |
| 소음·냄새가 다음 전투를 부른다 | 총을 쏠지, 활로 조용히 끝낼지, 피를 흘린 채 이동할지 판단한다 |

## 2. 공격 판정 파이프라인 (6단계)

```
[1 명중] ─실패→ 빗나감(소음만 발생)
   │성공
[2 방어 반응] ─성공→ 회피/막기/받아넘기기 결과
   │실패 또는 반응 불가
[3 부위 결정] → 대부위 → 세부 부위
[4 방어구 층] → 바깥층부터: 튕김 / 절반+타격 변환 / 관통
[5 상처 생성] → 유형·깊이·출혈·동맥·골절·장기
[6 2차 효과] → 통증·기절·무기 떨굼·넘어짐·사기·소음·냄새·내구
```

난수: 모든 판정은 `combat` 스트림에서 `roll = 0..99` 정수 1개를 뽑는다. 판정 순서가 고정이므로 같은 시드·같은 입력이면 같은 결과(결정론).

### 2.1 [1단계] 명중 [프로토타입]

```
명중% = clamp(5, 95, 50 + (공격치 − 회피치) × 2 + Σ수정치)
성공: roll < 명중%
공격치 = floor(무기 숙련 / 2) + 능력 보정 + 무기 정확도
         능력 보정: 근접 (민첩 − 10), 원거리 (지각 − 10)
회피치 = floor(회피 숙련 / 2) + (민첩 − 10) − 둔중
         둔중 = floor(착용 갑옷 총무게 kg / 4)   (내의·중간층 제외)
```
CANON의 "공격 숙련"은 공격치, "방어자 회피"는 회피치에 해당한다(숙련 0~100, 능력치 기준 10 가정 — 05와 정합 필요).

**Σ수정치 표**

| 분류 | 조건 | 수정 |
|---|---|---|
| 방향 | 측면 / 후면 (§4) | +10 / +20 |
| 고저차 | 공격자가 1단 높음 / 낮음 | +10 / −10 |
| 조명(대상 칸) | 밝음 / 어스름 / 어둠 / 칠흑 | 0 / −5 / −15 / −30 |
| 기습 | 대상이 공격자를 인지 못함 | +20 (반응 불가) |
| 대상 자세 | 넘어짐: 근접 +20, 원거리 −15 / 웅크림: 원거리 −15 / 기절·수면 | 표 값 / +40 |
| 공격자 상태 | 통증 단계당 −5, 혈액 손실 15%↑ −10 / 30%↑ −20, 스태미나 <25 −5 / 0 −15, 넘어짐 −20 | 누적 |
| 협공 | 같은 대상에 인접한 다른 아군 1명당 | +5 (최대 +15) |
| 원거리 | 유효 사거리 초과 1칸당 −3, 인접 사격(활·석궁) −10, 대상 이동 중(직전 행동 2칸↑) −5 | |
| 엄폐 | 반 엄폐 / 전 엄폐 (원거리만) | −15 / −30 |
| 연기 | 사선상 연기 칸당 (농도 5↑) | −10 |
| 공간 | 좁은 통로에서 양손·도끼 휘두르기 / 리치 2 무기로 인접 공격 | −15 / −10 |
| 조준 | 부위 지정 (§7.4) | −0 ~ −40 |

### 2.2 [2단계] 방어 반응 [프로토타입]

명중이 확정되면 방어자는 **반응 1회**를 시도할 수 있다. 플레이어는 "반응 정책"(막기 우선 / 회피 우선 / 받아넘기기 우선 / 반응 안 함)을 설정한다. AI는 성향 Def의 정책을 쓴다.

| 반응 | 성공률 | 방향 제한 | 스태미나 | 성공 시 |
|---|---|---|---|---|
| 회피 | clamp(0,75, floor(회피 숙련/2) + (민첩−10)×2 − 둔중×2 + 방향보정) | 정면 0, 측면 −10, 후면 불가 | 8 + 둔중 | 피해 0. 원거리엔 −15 |
| 막기(방패) | clamp(0,85, floor(방패 숙련/2) + 방패 막기치) | 정면, 방패쪽 측면(−20) | 4 + floor(피해/2) | 피해가 방패로. 방패 흡수 초과분은 방패 든 팔에 타격 |
| 막기(무기) | clamp(0,50, floor(무기 숙련/4) + 무기 막기치) | 정면만 | 6 + 피해 | 피해 0, 무기 내구 −피해/4 |
| 받아넘기기 | clamp(0,50, 15 + (방어자 무기 숙련 − 공격자 무기 숙련)/2 + 무기 받아넘기기치) | 정면만, 원거리 불가 | 6 | 피해 0 + 공격자 다음 행동 +50TU (빈틈) |

- **연속 반응 피로**: 같은 100TU 창 안에서 두 번째 반응부터 스태미나 비용 ×1.5, 세 번째 ×2.
- **반응 불가 조건**: 스태미나 0, 기절·넘어짐(막기만 −20으로 가능), 공격자가 보이지 않음, 기습.
- **무의미 반응 생략**(옵션, 기본 켬): 계산된 최선 반응 성공률이 10% 미만이면 반응하지 않고 스태미나를 아낀다. 로그에 "반응 생략(3%)"으로 표시.

### 2.3 [3단계] 부위 결정 [프로토타입]

외부 말단 부위의 커버리지(02 정본, 0.1% 단위 = ‰, 합 1000)에 보정을 곱한 뒤 `roll 0..(합−1)` 1회로 고른다. 내부 장기는 5단계 장기 판정으로만 맞는다.

| 인간 대부위(02) | 머리 | 몸통(목 20·흉부 200·복부 150·골반 30) | 팔 1개(상완 40·전완 30·손 20) | 다리 1개(대퇴 80·정강이 60·발 30) | 합 |
|---|---|---|---|---|---|
| ‰ | 80 | 400 | 90 ×2 | 170 ×2 | 1000 |

**가중치 보정**(말단 부위별 곱셈 → 정수 ‰ 유지, 순서: 머리 → 몸통 → 오른팔 → 왼팔 → 오른다리 → 왼다리로 누적 구간 생성)

| 조건 | 보정 |
|---|---|
| 공격자가 대상의 우측면 | 오른쪽 부위 ×1.5, 왼쪽 ×0.5 (좌측면은 반대) |
| 공격자가 작음(체고 차 2단↑, 예: 굴쥐) | 다리 ×3, 팔 ×0.5, 머리 ×0 |
| 공격자가 고지대 / 대상이 넘어짐 | 머리 ×1.5 / 머리·몸통 ×1.5, 다리 ×0.5 |
| 방패 막기 실패 | 방패 든 팔 ×2 |
| 조준 공격 | §7.4 |

보정 후 합이 1000이 아니면 실제 합을 상한으로 쓴다(예: 굴쥐 보정 후 합 = 0 + 400 + 90 + 1020 = 1510).

### 2.4 [4단계] 방어구 층 [프로토타입]

부위를 덮는 층을 **바깥부터** 순서대로 판정한다: 외투 → 갑옷 → 중간 → 내의 → 자연 방어(털·가죽·외피).

```
실효 방어 = floor(층 방어[피해 범주] × (50 + 내구% / 2) / 100)   ← 내구 0%여도 50% 남음
유효      = 실효 방어 − 현재 관통
유효 ≤ 0           → 판정 생략, 그대로 통과
2 × roll < 유효     → 튕김: 피해 0, 이후 층 판정 중단        (= roll < 유효/2, 정수화)
roll < 유효         → 피해 floor(D/2), 날 계열은 타격으로 변환, 관통 floor(관통/2)
그 외              → 관통: D·유형·관통 유지, 다음 층으로
```
- 피해 범주: **날**(베기·찌르기·파편·총상) / **타격** / **열**(화염·냉기). 층마다 3개 값.
- 정수 판정이므로 튕김 확률은 ⌈유효/2⌉%, 절반 확률은 유효 − ⌈유효/2⌉%.
- 층이 막은 만큼 그 층·그 부위의 내구가 깎인다(`08-items-and-crafting` §5).

**기대 피해 배율 검산**(1층, 변환 무시)

| 실효 방어 | 관통 | 유효 | 튕김 | 절반 | 관통 | 기대 배율 |
|---|---|---|---|---|---|---|
| 60 | 20 | 40 | 20% | 20% | 60% | 0.2×0.5 + 0.6 = **0.70** |
| 40 | 15 | 25 | 13% | 12% | 75% | 0.12×0.5 + 0.75 = **0.81** |
| 25 (갬비슨 타격) | 10 (곤봉) | 15 | 8% | 7% | 85% | 0.035 + 0.85 = **0.885** |

### 2.5 [5단계] 상처 생성 [프로토타입]

```
피해 원값 D0 = floor(무기 기본 × 품질 배율 × 날 상태 × 근력 보정 × (80 + r)/100),  r = roll 0..40
  날 상태 = (60 + 날% × 0.4) / 100     (베기·찌르기만)
  근력 보정 = (100 + (근력 − 10) × 5) / 100   (근접·투척만. 활은 당김 무게 충족 여부)
심각도 = D / 부위 체력 → <25% 경상 / <50% 중상 / <100% 심각 / ≥100% 파괴(절단·분쇄)
```

| 피해 유형 | 상처 | 외부 출혈 ml/턴 (× 부위 혈관계수, 02) | 통증 계수 | 특수 |
|---|---|---|---|---|
| 베기 | 베임 | D × 2.0 | 1.0 | 동맥 확률 D×2%(동맥 부위), 손·전완·발에서 D ≥ 부위HP 40%면 힘줄 절단 판정 |
| 찌르기 | 찔림 | D × 1.5 | 1.2 | 장기 관통 판정 `clamp(0,80,(D−4)×6)%`(몸통·머리), 내출혈(외부 표시 없음) |
| 타격 | 타박 | 0 | 0.8 | 골절: D ≥ 부위HP 40%면 `(D − 임계)×8%`, 머리면 뇌진탕 판정 |
| 화염 | 화상 | 0 | 1.5 | 감염 기본률 ×2, 의복 착화 판정 |
| 냉기 | 동상 | 0 | 0.6 | 손가락·발가락 괴사 진행 (`03-survival`과 공유) |
| 총상 | 총창 | D × 2.5 | 1.5 | 장기 판정 ×1.5, 탄 잔류(제거 전 감염 +), 사출구 50% |
| 파편 | 열상 다발 | 조각당 D′×1.5 | 1.0 | 1~3조각으로 분할(D′ = D/n), 이물 잔류 |

- **물기**(동물 턱 공격)는 방어 범주 '날'로 판정하고 상처는 **물림**(02 정본: 출혈 D×1.6, 통증 1.1, 기본 오염 40). 동맥 판정은 베기와 같은 D×2%를 제안(02와 정합 필요). 굴쥐 물림은 질병 전파 판정 ×3.
- 동맥 상처는 D와 무관하게 **150 ml/턴**(GDD 부록 A). 깊은 베임(D 20 베기) = 40 ml/턴 → 기존 초안 값과 일치.
- 화살·볼트가 박힌 채면 출혈 ×1/2, 대신 이동·공격마다 통증 +1. 뽑으면 원래 출혈 + 즉시 D×5 ml.

### 2.6 [6단계] 2차 효과 [프로토타입]

| 효과 | 판정 | 비고 |
|---|---|---|
| 출혈 시작 | 5단계 값 | 피 웅덩이·냄새 생성(§9) |
| 통증 | floor(D × 통증 계수) 누적 | 통증 단계는 02 정본 |
| 기절 | 머리 타격·총상: `clamp(0,90,(D − 4)×6 − (의지 − 10)×3)%` | 기절 시간 = D × 50TU |
| 무기 떨굼 | 손·전완 피해: `D × 3%`, 힘줄 절단 시 100% | 무기는 인접 칸으로 |
| 넘어짐 | 다리 피해 D ≥ 부위HP 30%: `D × 4%` / 타격 D ≥ 15: `(D − 10) × 5%` | 4족은 ×1/2 |
| 사기 | §8 | 큰 상처는 즉시 판정 |
| 소음 | 금속 충돌 8, 비명(통증 급증) 12 | §9 |
| 내구 | 방어구 층·무기 날 | 08 |

## 3. 검산 예시

### 예시 A — 약탈자의 손도끼가 플레이어의 우측면을 친다 (낮, 흐림)

| 단계 | 계산 | 결과 |
|---|---|---|
| 공격치 | 손도끼 숙련 46 → 23, 민첩 13 → +3, 정확도 0 | 26 |
| 회피치 | 회피 숙련 30 → 15, 민첩 11 → +1, 둔중(사슬 셔츠 9kg → 2) −2 | 14 |
| Σ수정 | 우측면 +10, 약탈자 스태미나 22 → −5 | +5 |
| 명중% | 50 + (26−14)×2 + 5 = 50 + 24 + 5 | **79%**, roll 63 → 명중 |
| 반응 | 방패는 왼팔 → 우측면 막기 불가. 회피 15 + 2 − 4 − 10 = 3% < 10% | **반응 생략**(스태미나 보존) |
| 부위 | 우측면(‰): 머리 80 / 몸통 400 / 오른팔 60·45·30 / 왼팔 20·15·10 / 오른다리 120·90·45 / 왼다리 40·30·15 (합 1000). 오른 상완 구간 480~539 | roll 510 → **오른 상완** |
| 피해 원값 | 14 × 1.05(근력 11) = 14.7 → × (80+15)/100 = 13.97 | **D = 13 베기**, 관통 15 |
| 층1 사슬 셔츠 | 실효 floor(45 × (50+40)/100) = 40, 유효 40−15 = 25. roll 18: 2×18=36 ≥ 25, 18 < 25 | **절반+변환**: D 6 타격, 관통 7 |
| 층2 누비 갬비슨 | 타격 25 × 100/100 = 25, 유효 25−7 = 18. roll 72 ≥ 18 | 관통, D 6 |
| 층3 리넨 내의 | 타격 1 − 7 < 0 | 판정 생략 |
| 상처 | 타박 D6 / 상완 HP 30 = 20% | **경상**, 골절 임계 12 미달, 통증 floor(4.8) = 4 |

교훈(로그 툴팁에 노출): 사슬이 없었다면 갬비슨(날 20 − 15 = 유효 5)만 남아 95% 확률로 **D 13 베기**가 관통한다 → 13/30 = 43% 중상, 출혈 26 ml/턴, 동맥 확률 26%.

### 예시 B — 밤, 횃불을 든 플레이어가 7칸 밖 재늑대에게 활을 쏜다

| 단계 | 계산 | 결과 |
|---|---|---|
| 공격치 | 활 숙련 44 → 22, 지각 14 → +4, 단궁 정확도 +4 | 30 |

### 7.3 넘어뜨리기 · 무장해제 [후속]
```
넘어뜨리기% = clamp(5, 95, 50 + (걸기치 − 균형) × 3)
  걸기치 = 민첩 + floor(무기 숙련/10) + 무기 보정(창 +5, 도끼 +10)
  균형   = 민첩 + floor(체중kg/10) + 다리 보정(2족 0, 4족 +8)
  TU 120, 스태미나 12
무장해제% = clamp(5, 75, 30 + (공격 무기 숙련 − 대상 무기 숙련)/2 + 보정(도끼 +10, 단검 −10, 대상 양손 −15))
  실패 시 공격자의 다음 반응 −15
```
검산: 창 숙련 30·민첩 12 → 걸기치 12+3+5 = 20. 약탈자 균형 10+6+0 = 16 → 50+12 = **62%**. 재늑대 균형 14+3+8 = 25 → 50−15 = **35%**. → "늑대는 넘어뜨리기 어렵다"를 숫자로 배운다.

## 8. 사기 (Morale) [프로토타입: 도주까지 / 항복·포로 후속]

```
사기 = 기본 사기(성향 Def) + Σ사건 수정(감쇠) + 전력비 수정
전력비 = 적 위협 합 / 아군 위협 합 (위협 = 체력% × 무기 등급, 시야 내만)
전력비 수정 = clamp(−20, +10, (1 − 전력비) × 10) 정수 내림
판정 시점: 사건 즉시 + 매 5턴
```

| 사건 | 수정 | 감쇠 |
|---|---|---|
| 시야 내 아군 사망 | −15 | 30턴에 절반 |
| 우두머리 사망·도주 | −30 | 없음(교전 끝까지) |
| 자신 중상 / 심각 | −10 / −20 | 상처 유지 동안 |

| 구간 | 효과 |
|---|---|

### 9.2 냄새 (피·시체·조리)
```
누적 냄새: 매 턴 + floor(흘린 피 ml / 10)(소수부는 이월), 시체는 +2/턴, 조리 +3/턴
감쇠: 10턴마다 누적 = floor(누적 × 9/10). 재비·비: 생성량 ×1/2
기본 반경 R = isqrt(누적)
방향 배율: 바람 아래(±45°) × (1 + 풍속/2), 측면 ×1, 바람 위 ×1/2   (풍속 0~4)
감지: 거리 ≤ floor(R × 방향 배율 × 후각 배율)   후각: 인간 1/2, 재늑대 2, 굴쥐 1, 기계 0
실내(닫힌 방): 외부로 나가는 R ×1/2
```
검산 F: 깊은 베임 40 ml/턴 → +4/턴. 10턴 40 → 36, 20턴 76 → 68. R = isqrt(68) = 8. 풍속 2 바람 아래 → 8 × 2 = 16, 재늑대 후각 ×2 → **32칸**. 바람 위에서는 8 × 1/2 × 2 = **8칸**. → "바람을 등지고 이동하라"가 숫자로 성립.

## 10. 화기 · 탄약 [후속, 프로토타입은 Def만]

| 항목 | 부싯돌 장총(중세 말) | 회전식 권총(산업) | 볼트식 소총(산업) |
|---|---|---|---|
| 피해 / 관통 | 총상 22 / 45 | 총상 14 / 30 | 총상 24 / 50 |
| 장전 | 1발 700TU(화약·탄·꽂을대) | 6발, 1발당 150TU | 5발 클립 300TU |
| 사용 탄 | 납탄+흑색화약 | 공장 실탄 / 재생탄 | 공장 실탄 / 재생탄 |

- **탄약 가치**: 1발 ≈ 하루 식량(≈10표, `08` §9). 재생탄은 고물길드·잔존 경비대 정착지에서만.
- **불발률** = 탄 기본(공장 2%, 재생 8%, 수제 흑색 12%) × 젖음(젖은 탄 ×2) + floor(오염/10)%.
- **총열 오염** 0~100: 발사당 무연 +1, 흑색 +4. 걸림 확률 = max(0, 오염 − 40)/2 %. 걸림 해소 200TU, 청소 600TU + 총기 기름 1.
- **재비 부식**: 노출 10턴마다 오염 +1, 기름칠 상태면 무시(08 부식).

검산 G: 흑색화약 장총 10발 → 오염 40 → 불발 12 + 4 = **16%**, 걸림 0%. 15발 → 오염 60 → 불발 18%, 걸림 (60−40)/2 = **10%**.

## 17. "이런 것까지?" 디테일

1. 방패는 방패 든 팔 쪽 측면만 막는다 → 왼손잡이 약탈자는 반대편이 약점.
2. 박힌 화살은 출혈을 절반으로 줄이지만 움직일 때마다 통증 +1.
3. 피격 후 자동으로 돌아서지 않는다 → 두 명에게 끼면 한 명은 계속 후면.
4. 횃불을 든 자는 어둠 속 관찰자에게 12칸 밖에서도 보인다.
5. 반응 성공률 10% 미만이면 반응을 생략해 스태미나를 아낀다(설정 가능).
6. 4족 동물은 넘어뜨리기 균형 +8 → 늑대 다리 걸기는 잘 안 된다.
7. 곤봉은 무뎌지지 않는다 → 장기 원정에서 날붙이 대비 정비 비용 0.
8. 도주하는 출혈 적은 핏자국을 남기고, 그 피가 다른 포식자를 부른다.
9. 재비가 오면 냄새 생성이 절반 → 비 오는 날 사냥감 추적은 어렵지만 내 피 냄새도 덜 퍼진다.
10. 첫 총성은 중세 이하 세력과 동물의 사기를 −10 깎는다(두 번째부터는 없음).
11. 사슬 셔츠 내구가 0%여도 방어의 절반은 남는다(구멍 난 사슬도 사슬).
12. 리치 2 창으로 인접한 적을 찌르면 −10 → 창병은 반 발짝 물러서는 게 이득.
13. 받아넘기기 성공은 피해 0에 더해 상대 다음 행동을 50TU 늦춘다.
14. 진흙 위 발자국은 20시간 남아, 약탈자가 내 야영지를 역추적한다.
