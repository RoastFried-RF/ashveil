# v0.402 개발 묶음 — 상태와 경고 표시

2026-10-28 KST. v401의 별도 후속 작업본에서 작성했다. 이 문서는 구현 중 범위이며 실제 검사·화면 검토·게시 영수증이 기록되기 전에는 완료로 세지 않는다.

상단 시각·계절/날씨·깊이, 여섯 부위 상태/설명, 효과/부상·생존/동료 진료 칩과 경고 띠를 언어 선택에 연결한다. 질병·붕괴·계절·날씨·자세의 검토한 Def label은 ID+원문을 확인한다. 장소의 저장된 이름, 다른 창/로그/문헌/보고서 전체는 이 묶음의 영어 완료 범위가 아니다. 개인 이름이나 저장 원문은 덮어쓰지 않는다.

치명 경고의 확인 장벽은 GameScreen이 읽는 기본 `computeBanners(w)`의 기존 한국어 메시지를 유지한다. 보이는 Banners만 명시적인 언어 인수로 계산한다. 정렬/우선도/남은 턴/대상 관찰은 공유하며 언어 전환을 새 치명 사건으로 취급하지 않는다. 코어/정의/저장219를 변경하지 않는다. 신체·등불·수면 설명의 키는 현재 저장된 실제 키 설정을 표시한다.

`tests/locale-status.test.ts`는 같은 위독 상태의 우선도/턴과 한국어 경고 식별/전체 세계 보존, 실제 현재 조건의 체온 경고를 검사한다. 기존 v401 카탈로그 검사도 새 검토 필드가 최종 로드된 정의와 일치하는지 계속 검사한다.

`tools/inspect-status-v402.ts`의 초기 조건은 실제 생성한 새 세계에서 플레이어 HP만10으로 선언한 유한 fixture다. 과거에 다친 플레이 근거로 사용하지 않는다. 불러온 뒤에는 세계/시각/난수를 수정하지 않는다. 실제 첫 이동 키로 경고만 확인하고, 실제 설정의 영어 전환 뒤 두 번째 키가 한 번 이동하는지 독립 Node 전체 상태와 비교한다. 두 데스크톱과390px 화면의 정상 저장/복원을 포함한다. 별도 v401의 실제 생성·학습·대기·웅크림 시나리오도 현재 빌드에서 함께 실행한다.

`plan.py --status-locale`는 대상 검사와 기존 체온 검사를 Full보다 먼저 실행하고, 실제 상태 Native는 다른 Native 뒤의 heavy 단독 슬롯을 쓴다. 상호 배제·frozen 의존성·Chromium 계약과 전체 X1–X4/원정1,000판·사람 평가 게이트는 유지한다.
