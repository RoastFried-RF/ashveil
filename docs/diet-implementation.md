# 실제 최근 식사·살코기 굶주림과 영양 흡수

v0.101. 설계03 §3.3의 ‘최근3일 섭취 칼로리 중 단백질 비중45% 초과 → 설사/칼로리 흡수×0.7’을 원래 음식·실제 섭취·수분/열량·일지/상태 표시·각인에 연결한다.

먹은 음식의 원래 열량과 단백질을 실제 섭취 시각에 기록한다. 단백질1g을4kcal로 환산하고 음식 전체 열량을 넘지 않게 제한한다. 실제 현재 식사까지 포함한 비중이45%를 넘을 때 그 식사의 흡수부터 줄인다. 원래 음식 열량140kcal/단백22g인 육포만 먹으면88/140이므로 실제 흡수는98kcal다. 원래 식품의 Def 열량이나 단백 상태/수분 함량을 바꿔 낮은 열량으로 속이지 않는다.

처음부터 ‘과거3일 동안 고기를 먹었다’고 가정하지 않는다. 실제 기록이 있는 식사만 사용하고, 72시간이 된 원래 식사만 정확한 턴에 제외한다. 곡물 식사가 먼저 오래되면 그 뒤 고기만 남아 비중이 높아질 수 있고, 마지막 고기도 오래되면 불균형이 사라진다. 배고픈 정도나 단백 상태100/100을 최근 식사의 구성으로 잘못 사용하지 않는다.

같은 턴에 여러 끼를 먹어도 전체 열량을 보존하면서 기록을 합친다. 마지막 실제 식사의 정확한 기여량·원래 UID/종류를 별도로 보존해 실제 구토는 그 식사만 한 번 뺀다. 물/0열량 단백 보충은 존재하지 않는 열량 식사를 만들지 않는다. 실제 부분 음료는 마신 분량만 기록한다. NPC에게 먹일 때도 원래 물건은 제공자의 배낭에서 한 번 줄고, 영양/영수증은 먹은 같은 NPC에게만 남는다.

설사 중 수분 손실은 같은 대사율과 ml 잔여량으로 실제 몸에 반영한다. 별도의 감염·이질·발열이나 가짜 치료 이벤트를 만들지 않는다. 재 체기·실제 이질이 있으면 각각의 흡수 배율과 함께 적용한다. 식단을 바꾸거나 원래 식사가 기간을 벗어날 때 비중을 다시 계산한다. 등잔 기름을 식용 지방으로 바꾸거나 정본에 없는 체지방 저장량을 만들지 않았다.

일지의 영양 설명과 상태 칩은 실제 기간·단백 열량 비중·현재 흡수 배율을 읽는다. 조회로 영양 장부나 난수를 바꾸지 않는다. 생물학적 식단 규칙은 기계 몸에 적용하지 않는다. 각인v65는 원래 기록과 마지막 식사/구토 기여량을 보존하고, 구형64에는 과거 식사를 만들어 넣지 않는다.

3일·45%·흡수0.7은 설계 기준이다. 단백 열량 환산4와 설사 수분 손실1,500ml/일은 변경 가능한 Def 기본값이며, 특히 추가 수분 손실은 정본의 확정 수치가 아니다. 식사 기간/비중/배율/수분 설정은 Def 검증과 Schema를 통과해야 한다.

전용18개와 관련189개 검사·타입/린트·Def96패치·Schema90파일을 확인했다. 기존 검사3개가 육포의 흡수를 원래140kcal 전부로 기대한 부분은 새 규칙의98kcal와 실제 돌봄 기록98로 고쳤고, 원래 Def140/단백22/수분5와 식중독 난수 불사용 검사는 보존했다. 기존 다섯 재현의 전체 초기/최종 상태·오류는 버전64→65 외에는 같았다. 이 고정 재현에는 새 음식 섭취 경로가 없으므로 전용 실제 섭취 검사를 별도로 사용한다. 전체103파일1,749개95.79초 검사가 통과했다. v0.101에서는 원래 음식/분량·실제 섭취자의 최근72시간 단백질 열량 비중·45% 초과 흡수×0.7/실제 설사 수분 손실·원본 마지막 식사의 한 번 구토·시간 경계/식단 변화·일지/상태 칩·각인v65를 연결했다. 전체103파일1,749개95.79초·전용18개/관련189개·타입/린트/Def96패치/Schema90/빌드·화면428~433/6장·네 차례 전체 복원·콘솔 오류0이다. 같은 검증용 사본의 월드30시드×최대3일294.91805527900004초·30개 전체 행을 대조해 15개가 같고 15개의 실제 변경을 검토했다. 월드 평균0.4804675925925926일·원인{'저체온': 20, '치명상': 4, '과다 출혈': 6}이다. 최종 검증은 변경하지 않는 v101 사본에서 실행했다. 실제 원본 건빵/육포5끼43.1% → 다음 원본 육포45.7%/98kcal → 원본 건빵37.1%/350kcal와 두 원본 식사의 연속72시간 경계/4전체 각인을 확인했다.

월드30개 중15개는 전체 상태가 같고,11개는 실제 식사 기록만 추가됐다. 나머지4개는 같은 원본 육포를 먹기 직전 상태와 선택이 같았고, 첫 차이는 실제 흡수140→98kcal와 설사 수분 잔여량이었다. 이후 실제 선택/전투/생존이 달라졌다. sim-21은 지하 치명상0.2803819일에서 지상 저체온1.6666667일로,sim-14는 저체온1.25일에서1.6388889일/레벨3→2로 바뀌었다. 전체 차이는 [월드 감사](sim-v101-diff.json)에 보존했다.
