# 실제 보관함의 거점·동료 제작과 방어 — v0.69

실제 본인 야영지 보관함 곁에서 기본200턴 정비를 마쳐야 이 지도의 거점이 생긴다. 기존 야영지 보관함 또는 본인이 실제로 설치한 보관함만 사용할 수 있다. 새 목제 보관함은 실제 목재4개/천1장·120턴 제작 후 같은 물품을 I창에서 설치한다. 저장고를 만들었다고 식량/재료/돈을 채워 주지 않는다. 다른 사람의 보관함·주민이 사는 정착지·주변에 아직 살아 저항하는 적이 있는 곳은 점유할 수 없다. `BaseCamp.Hearth`가 실제 저장고 지형·정비 시간/범위6칸·최대20회 배정을 정의한다.

거점의 실제 보관함/소유자와 UID를 보존한다. 곁에서 창고와 배낭 사이에 묶음당1턴으로 옮기며, 필요한 일부 재료만 나눌 때만 새 조각 UID를 만든다. 전체 묶음과 상태/품질·오염은 유지한다. 옮기기 전에 전체 공간을 검사하고 실패하면 일부 이전·수량/UID 소비가 없다. 원격·손 손상·없어지거나 바뀐 보관함은 물품을 움직이지 않는다. 원래 인벤토리 창으로도 실제 창고를 열 수 있다.

급료가 유효하고 곁에서 말을 주고받을 수 있는 실제 동료에게 알고 있는 즉시 제작법과 횟수 또는 거점 방어를 맡긴다. 작업자는 실제 창고로 한 칸씩 걷고 필요한 실물 재료만 배낭으로 꺼낸다. 도구/능력/작업장·실제 손과 몸/품질·작업 시간이 기존 제작 규칙을 따른다. 작업장이 필요하면 실제 사용 가능한 곳으로 이동한다. 각 제작이 끝나야 남은 배정 횟수가 줄고 결과물을 직접 창고로 나른다. 재료·공간/도구가 없으면 기다리며 공짜 재료나 결과를 만들지 않는다. 손·칼로리/물·수면과 급료도 계속 필요하다. 장기 창고 생산의 균형을 완료했다고 주장하지 않는다.

급료 만료·위협·없어진 창고/바뀐 명령은 진행 중 배정 제작도 소비 없이 멈춘다. 실제 급료 지급 후 같은 작업을 재개하면 같은 재료와 부분 진행을 이어 간다. 명시적인 취소/다른 작업/일반 동행 지시는 해당 배정을 끝내고 노동 진행만 초기화한다. 방어는 기존 실제 동료의 방어 범위/전투·몸·급료를 쓰며 국가 관계를 바꾸거나 가상의 병력을 추가하지 않는다. 다른 층으로 떠나도 방어 동료·거점·재고는 원래 지도에 남는다. 미활성 지도의 실제 작업을 원격으로 완료시키지 않는다.

F2의 거점 패널에 실제 정비/창고 입출고·곁의 동료 제작 선택/횟수·배정/재개/취소·방어·작업 상태/대기 이유를 연결했다. 손님이나 먼 주민의 몸 수치를 공개하지 않는다. 각인v34는 기존 지도/물품·몸/계약을 보존하는 순수 이관이며 새로운 거점을 과거 각인에 만들어 주지 않는다. 실제 거점/정비·배정과 부분 제작/재료·횟수/창고를 중간 저장한다.
