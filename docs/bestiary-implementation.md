# 관찰·사체 해부·문헌 — v0.39

현재 생물의 도감을 처치 수 기반 표시에서 실제 관찰/전투 생존/해부/문헌으로 바꿨다. Bestiary1종과 Entry7종(재늑대/굴쥐/인간/그늘 사람/말라붙은 자/포자 인간/융합체)을 Def로 정의하며 변종은 종 지식을 공유한다. 정착민/상인/경비와 약탈자는 인간 몸 지식을 공유한다. 과거 전투 기록은 S2로 유지하고 처치만으로 S3를 주지 않는다.

처음 보이면 S0, 시야 안 누적20턴 또는3회 조우로 S1이다. 같은 턴의 반복 계산이나 같은 무리 여러 마리로 관찰 시간이 빨라지지 않는다. 벽·어둠·수면·의식상실 동안 관찰하지 않고 사체의 외형은 관찰할 수 있다. 현재의 재조우 구분60턴은 임시 기본값이다. 아직 만나지 않은 종을 목록에 공개하지 않는다.

공격 한 번으로 S2를 주지 않는다. 처치/항복/도주시킴을 마치거나, 교전 상대와 떨어져 보이지 않고 추격도 끊겨10턴을 넘기면 전투 생존 S2다. 다른 지역으로 벗어나도 교전 종료를 기록한다. 추격 종료10턴은 임시 기본값이다. 관찰·지식 조회 자체는 상태나 난수를 바꾸지 않는다.

S1 혈액/부위 HP는±30%, S2는±10%에서 지각 보정 `1−(지각−10)×0.05`를 적용하고 매의 눈은 폭에서0.05를 더 뺀다. 혈액은100ml, 작은 부위 HP는1단위로 반올림한다. 2400ml/지각12의 S1은1800~3000, S2는2200~2600이다. S3는 실제 표본의 부위/내부 장기·동맥·정확값을 보여준다. S4는 관찰한 기록이나 문헌 기준값과 실제 동작에 관한 사실을 연다. 알고 있던 표본을 새 Def 값으로 덮지 않는다.

S0의 생물은 실루엣과 정체를 모르는 이름으로 표시하며 보지 못한 공격자는 정체 모를 존재로 기록한다. 상대의 정확한 HP·내부 출혈/뼈 강도·내부 장기 상세와 부위 추첨 가중치는 지식에 맞춰 공개한다. 자기 상태와 일반 명중/판정 공식은 유지한다. CANON D14의 적 체력 막대·피해 숫자·상태 표시는 단계와 무관하게 유지한다. 이름/기록 공개가 실제 피해·몸·난수를 바꾸지 않는 회귀를 추가했다.

해부는 인접 사체·밝기·손 기능과 실제 날붙이가 필요하며 기본200턴(10분)에 몸/특성의 채널 배율을 적용한다. 선택한 도구 UID와 접근/밝기/신체 조건을 진행 중/완료 때 재검사한다. 대각선 벽 모서리를 넘어 작업하지 못한다. 중단·실패한 조건에서는 도구를 바꿔 끼워 판정하지 않는다. 소지품 없는 동물 시체도 S수색으로 열고 인벤토리에서 해부한다. 봇의 전리품 탐색은 기존처럼 빈 사체를 건너뛴다.

해부 확률은 `40+max(의료,생존 숙달)×6+(지각−10)×2−종 난이도`를10~95%로 제한한다. 생존3/의료0/지각12/난이도20의 재늑대는42%다. 같은 종3회 성공 뒤에는 자동 성공하며 판정 난수를 소비하지 않는다. 사체1구는 한 번만 시도한다. 실패 시 다른 사체에서 다시 시도한다. 성공은 생존 숙달의 실제 성공1회이며 같은 대상/시간당3회 제한을 유지하고 경험치·능력 포인트는 주지 않는다. NPC는 같은 판정·재료를 쓰되 자기 기억에 배우며 플레이어 대신 지식을 얻어 주지 않는다.

재늑대는 추가 생가죽3/뼈2, 굴쥐는1/1, 융합체는뼈4를 실제 사체 곁 바닥에 남긴다. 실패는70%로 줄이고 정수 단위에서 버린다(재늑대2/1). 새 재료가 있으면 바닥 루팅을 열어 바로 줍게 한다. 이 수량은 임시 기본값이다. 기존 사망 시 생고기 드롭은 유지하며 이 해부 수율과 별개다. 완전한 도살·무게별 고기/가죽/지방/힘줄·위 내용물은 아직 연결하지 않았다.

사람/그늘 사람/포자 인간의 해부 시도는 기분−8을 남긴다. 깨어 있는 인간 세력의 목격자가 실제로 보면 인간5세력에 평판−5 소식을 보내며 기존 거리에 따른 지연/지역 도착 규칙을 쓴다. 평판 수치−5는 임시 기본값이다. 목격자가 없으면 소식을 만들지 않는다. 말라붙은 자는 lore에 따라 해부를 거부한다. 기계 분해의 도구 품질 판정도 공통 규칙으로 지원하지만 실제 정원사 기계 생물은 아직 없다.

고원 생물지는 서가의 책 추첨 몫 안에서 나오며 문해2/120쪽이다. 온전한 완독은 현재7종의 S4와 생존 책 숙달5회를 주며 기존 책 누계 상한15를 유지한다. 오독/번진 책으로 S4를 주지 않는다. NPC 강의와 나머지 문헌/종은 남아 있다.

새 개체의 혈액량은02의 기준에 맞춰 재늑대2400ml/굴쥐60ml로 보정했다. 우두머리는 기존의 재늑대 대비1.3배인3120ml다. 임계 비율15/30/40/50%는 그대로다. 각인 형식7의 해부 활동을 추가했지만, 구형2~6의 기존 몸/혈액/영양/약물/도감 기록을 재조립하거나 회복시키지 않는다. 구형 재늑대2500ml의 손상된 몸도 그대로 보존한다.
