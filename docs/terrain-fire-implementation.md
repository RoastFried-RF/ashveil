# 실제 모닥불의 불씨와 마른 나무 화재

v0.155는 실제 목재를 써서 점화한 원래 모닥불에서 마른 나무로 옮겨 붙는 불씨를 연결한다. 차가운 꾸러미·무한 배경 조명·불가능한 원격 조회로 화재나 새 난수를 만들지 않는다. 실제 타기 시작한 나무의 불씨는 인접한 원래 나무로 번질 수 있고 부모 화재ID를 출처로 남긴다. 새 불이 같은 시각 중복 틱만으로 연쇄 확산하지 않는다.

나무마다 실제 남은 연료를 보존하고 소진하면 그 자리의 바닥으로 바꾼다. 불을 꺼도 이미 탄 연료를600으로 복원하지 않는다. 수확되어 재생을 기다리는 원래 나무에서 온전한 목재와 불 연료를 이중으로 얻지 못하며, 불붙거나 탄 재료를 원래 양으로 채집하지 못한다. 진행 중 채집도 실제 불붙은 재료에서 멈춘다. 새 목재나 소화 용기를 생성하지 않는다.

같은 몸이 화재에 인접한 실제 피해 시각에는 화상/체력 피해를 받고 기존 몸의 통증/의식/사망을 사용한다. 열과 빛은 원래 실제 광원/체온 경로를 사용한다. 실제 물500ml를 원래 물병/물 공급에서 써서 끌 수 있으며 같은 원래 병과 남은 물을 보존한다. 물을 끼얹은 재료는 일정 시간 새 불씨가 붙지 않고, 실제 노출된 재비는 점화를 막거나 현재 불을 꺼뜨릴 수 있다.

기본 불씨 검사10턴/확률0.02, 인접1칸/연료600턴/화상20턴마다1/물500ml·젖음600턴/재비 소화0.25/빛5는 Campfire.Hearth.wildfire와 Terrain.Tree.combustion PATCH의 조정 가능한 콘텐츠 기본값이다. 새 아이템을 추가하지 않았다. 현재는 마른 나무만 가연 대상으로 정의한다. 건물 전체·들판 화재·방화 범죄/모든NPC 회피·정지 지역의 과거 확산/날씨 정산 전체는 다음 범위다. 이미 알려진 한 지역의 실제 현재 물리 틱만 처리하고 시간 공백의 과거 화상/확산 난수는 추정하지 않는다.

제작 창에서 보이는 주변 화재의 실제 소화 조건을 확인하고 같은 물로 끈다. 실제 화염은 기존 불꽃 애니메이션으로 그린다. 각인118→119는 버전만 이관하며 과거 산불/연소/젖음을 추정하지 않는다. 전용 검사에서는 명시적으로 확률1 조건을 사용한다. 기본 확률 장면은 별도 모드 없이 원래 콘텐츠DB를 쓰며 그 동일성을 회귀 검사한다. 실제 기본 확률0.02의 고정 시드terrain-fire-proof-1은 공개 점화 작업100턴과 실제 대기140턴 뒤 첫 나무가 발화하고,230턴 더 지나 인접 나무로 번지며, 첫 발화 뒤600턴에 원래 나무가 소진된다. 초기 검사 도우미에서undefined가 기본 인수1로 치환되던 오류를 고쳐 검사 전용 조건과 실제 기본 콘텐츠를 분리했다.

브라우저와v153–155 통합 전체 회귀/월드 검증을 완료했다. v153/v154 별도 전체회귀/월드를 실행한 것으로 기록하지 않는다.


v0.153–155는 원래 지도 원본/예치금의 정찰 납품·실제 탐험/읽은 문서의 층 의뢰·실제 유한 모닥불에서 나무로 옮겨 붙는 화재를 연결했다. 각인117→119·전용44개·통합 전체158파일3,072개146.43초·타입/린트/Def222패치/Schema126·실제 UI창/세계 캔버스20장면 전체 확인·17전체 복원/실제 재개59·19·19턴/콘솔0이다. 기본 확률0.02의 화재는 실제100턴 작업+140턴 대기 뒤 발화/230턴 더 지나 번짐/600턴 연소 뒤 소진과 실제 물500ml·소화 버튼1턴을 확인했다. 월드30판319.63681798199997초의30행 전체가v152와 같다. v153/v154별도 전체검사·월드30판은 실행한 것으로 기록하지 않는다.
