# 주민의 실제 몸 씻기와 관찰한 개인 침구 세탁

v0.122. 각인86. 주민도 실제 위생/몸의 이와 개인 침구의 이를 따로 관리한다. ResidentWater.Hearth의 선택 정책은 위생40 미만/실제 이, 체온35 이상, 개인 침구 관리를 기본으로 한다. 기존 몸 씻기200턴/2L/+60과 침구 세탁200턴/2L 규칙을 그대로 쓴다.

주민은 우물까지 실제로 걷고 배낭의 원래 물 용기를 채운다. 실제1L 물병 두 개도 합산해2L를 준비한다. 몸을 씻고 나면 다른2L를 다시 준비해 같은 개인 침구를 씻는다. 마지막 노동 턴에만 물을 쓰며 같은 빈 용기UID를 남긴다. 목욕용 물을 끓이거나 마신 것으로 처리하지 않는다. 술/눈과 부족한 물을 대신 쓰지 않는다. 자기 침구만 다루고, 점유자/원래 침구/실제 거리·시야/손/깨어 있음과 물을 기존 공통 행동에서 다시 확인한다.

침구의 이는 직접 보았을 때만 기억한다. 관찰한 물리 지도/좌표/지형/원래 물품UID/출처 시각을 각인에 보존한다. 우물로 가는 동안 그 기억을 유지하지만 보이지 않는 침구의 청소/변경을 원격으로 알아채지 않는다. 돌아와 확인한 깨끗한 침구/소유권 상실은 잊는다. 조회는 관찰/난수/시간/물/UID를 만들지 않는다. 위협 대응·식수/식량·보온을 우선하고 위생 관리 뒤 개인 수면으로 돌아간다.

적설/얼음 우물, 길막, 손 결손·실신·잠·포박·추위, 위생 설정 꺼짐, 부족한 물/용기와 타인의 침구는 세탁을 만들지 않는다. 실제 용량이2L에 못 미치면 무한히 같은1L를 덮어 채우지 않고 재시도를 미룬다. 주민에게 새 물통/공짜 물을 소급하지 않는다. 실제 상점 용기 조달은 다음 작업으로 남아 있다.

전용25개/관련6파일129개와 전체 상태를 비교한5개 고정 재현을 확인했다. 고정 재현은 버전86 외 전체 초기/최종 상태와 오류가 같다. 유효한 초기 보균자가 개인 침구에서 실제1턴 쉬어 출처14401을 만든 후, 같은 주민이 실제 우물/원래 두 병으로 몸과 침구를 따로 씻는 공개 스케줄러 검사를 포함한다. 실제500턴 미완료 상태도 전체 각인을 복원해 똑같이 진행한다.

최종 브라우저6화면558~563을 모두 실제로 확인했고6전체 각인 복원/콘솔 오류0을 확인했다. 미완료500턴의 헤드리스/브라우저 전체 상태가 같은 렌더 시점에서 정확히 같다. v0.122에서는 주민의 실제 몸/개인 침구 세탁·직접 관찰한 침구 기억·우물 걸음/원래 두 물병과 별도2L씩 총4L·같은 빈UID·각인v86을 구현했다. 최종 전체124파일2,241개115.32초·전용25/관련129개·타입/린트/Def132패치/Schema102/빌드·화면558~563/6장 전체 확인·6전체 복원/콘솔 오류0이다. 미완료500턴의 실제 규칙 상태는 렌더가 소비한 이동7/경험치1 연출을 기록한 뒤 전체가 헤드리스와 같다. 같은 최종 검사본의 월드30시드×최대3일284.599233549초·30개 전체 행이 이전과 같다.
