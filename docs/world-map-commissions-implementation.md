# 새 월드 정찰과 원래 종이 지도 납품

v0.175. 실제 현지 상인이 자기 장부에서24표를 예치하고 현재 정착지 주변 반경3칸의 새 월드 정찰 지도 원본을 의뢰한다. 수락/납품/취소는 각각1턴이며, 공용 계약 장부의 기한/사망/환급 경로를 사용한다. 새 계약 종류를 따로 소급하지 않고 기존 지도 계약에 명시적 월드 조사 범위를 추가한다. 기존 지역/층 계약은 별도 원본 조건을 유지한다.

수락 뒤 주변 살피기/여행 도착으로 직접 본 지형을 실제60턴/원래 종이·잉크에 작성한다. 원래 작성자ID/이름/세계 시드·의뢰ID·관찰/작성 시각·신뢰도40 이상·대상 범위의 새 주장12개 이상을 확인한다. 같은 좌표를 반복해 칸 수를 채울 수 없다. 현재 숨은 지형으로 진위를 채점하거나 잘못된 좌표의 정답을 공개하지 않는다. 작성 오차/누락은 기존 월드 규칙대로 남아 있어서 납품 기준을 충족하지 못할 수 있다. 보수가 바뀌거나 기한/예치금/지갑이 잘못되면 원본/현금/난수를 옮기지 않는다.

성공하면 배낭의 같은 원본UID를 상인 실제 시장 재고로 옮기고 예치금만 플레이어에게 지급한다. 완료 장부에는 전달한 원본/그때 내용의 사본이 남고 N/일지에서 완료와 요구 범위를 확인한다. 원본이 없어져도 작성자가 이미 아는 내용은 잊지 않는다. 취소/기한 만료/사망은 같은 예치금을 한 번 시장으로 돌려준다. 장부에 보수가 부족하면 의뢰를 게시하지 않는다. 전용 PATCH234이며 새 Item은 추가하지 않는다.
