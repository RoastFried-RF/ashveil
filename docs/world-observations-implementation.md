# 세계 지도의 당시 지리 기록

v0.173. 세계 지도 색/선택 지형/육로 예상은 저장된 당시 지리 기록을 사용한다. 현재 원격 칸이 달라져도 옛 바이옴·도로·기온·기저 장막을 다시 읽지 않는다. 자원량·현재 강수/날씨는 이 기록에 넣지 않는다. 알려진 고정 지명의 설명과 기존 배의 날씨 경로 예상은 별도 기존 동작을 유지한다.

새 세계는 도로/확장 배치를 마친 시작 주변49칸의 지리 기록과 시작 시각을 갖고, 화면은 이를 처음 지니고 있던 기록이라고 명시한다. 실제 여행으로 도착한 뒤 깨어 주변을 볼 수 있을 때만 도착 시각의 주변 기록을 갱신한다. 시력이 없으면 여행 흔적은 남아도 본 지리 기록을 만들지 않는다. 출입구 곁이나 바깥길에서 주변을 직접 살펴보는 행동은1턴이며 정상 몸/빛/의식 조건을 따른다. 갱신 범위 바깥의 옛 기록은 그대로 둔다.

각인126→127은 버전만 이관한다. 옛 방문 목록만으로 당시 지형/날짜를 소급하지 않고 회색/기록 없음으로 보인다. 실제 새로운 관찰 입력으로 기록을 회복할 수 있다. 경로 예상은 기록 없는 칸을 현재 원격 지형으로 채우지 않으며 실제 여행 요청은 기존 물리 규칙으로 처리한다.
