# 월드 원본 지도의 실제 시장 거래

v0.176. 원래 월드 지도의 공개된 신뢰도/중복 없는 기록 칸 수만으로 지도 기준가를 계산한다. 별도 PATCH235의 기본10 + 유일한 기록 칸 수×1×신뢰도/100을 사용하고, 실제 거래가는 기존 물품 상태·재질·품질·평판·흥정·시장/매매 차이를 그대로 적용한다. 빈 종이/잘못된 문서/다른 세계·미래의 문서는 월드 지도 가치를 붙이지 않는다. 숨은 현재 지형·진위·실제 읽었는지를 가격으로 알아낼 수 없다. 같은 좌표 복제로 가격을 올릴 수 없다.

일반 N 거래창에서 월드 지도 신뢰도/기록량·기준가를 표시한다. 실제 판매/구매는 기존1턴·유한 장부/개인 현금·전체 배낭/UID 원자성을 사용한다. 같은 원본/작성자/시각/의뢰 서명은 시장을 오가도 유지하고, 소지만으로 새 지도 지식을 만들지 않는다. 작성자가 이미 아는 내용은 원본을 팔아도 유지한다. 되산 원본이 새 직접 정찰의 원래 조건을 만족하면 기존 계약에 납품할 수 있다. 새로운 Item이나 각인 필드는 추가하지 않고129를 유지한다.
