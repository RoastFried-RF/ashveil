# 현장 목격 소식과 도착한 마을의 첫 반응

v0.166 작업은 현재 정착지에서 새로 목격된 공격/살해·소유권 침해·석방/처형(실제 구조 확인의 석방 보상 포함)을 공개 소식 전파망에 연결한다. 원래 목격 판정과 실제 새 사건 생성 지점에서만 게시한다. 주체는 같은 각인의 실제 인물ID/이름이며 깨어 있는 실제 사람 목격자가 현재 행위자를 보아야 한다. 과거 평판 목록을 훑거나 주체 없는 옛 사건을 플레이어의 일로 바꾸지 않는다. 정착지 밖의 사건을 새 마을로 즉시 옮겨 게시하지 않는다.

플레이어가 공격1턴을 했다고 자신의 소식을 자동 학습하지 않는다. 같은 마을의 공개 목격 이야기에서 실제 거리/수다 지연과 당시 명시 주장 왜곡을 거쳐 다른 정착지로 전한다. 기존 평판/범죄의 판정이나 값은 유지하며 일반 소식 전파에 별도의 전역 평판 보상을 주지 않는다.

새로운 주민과 실제로 처음 만날 때, 그 마을에 이미 도착한 유효한 공개 이름 소식만 첫 인상에 더한다. 인물ID·이름·각인 시드가 모두 일치해야 한다. 그 마을 주민이 아니거나 미도착/30일 경과/정확도20미만 소식은 쓰지 않는다. 의견은 정확도에 비례하며 별도 PATCH의 `firstImpressionCap:10`으로 제한한다. 견적/조회는 기억·시간·난수를 만들지 않는다. 실제 대화/거래 등 기존 첫 만남 지점에서만 기억하고 이미 만난 사람의 과거 인상을 덮어쓰지 않는다.

N창의 실제 첫 인사 기록은 소식을 먼저 들은 눈치라는 설명과 원래 우호/경계 반응을 함께 보여 준다. 정확한 숨은 정확도나 원래 참값을 표시하지 않는다. 소문이 명성 전체/세력의 절대 사실로 판정된다고 주장하지 않는다.

각인123→124는 버전만 이관하며 과거 첫 만남에 새 `rumor` 항목을 넣지 않는다. `publicNames`를 설정으로 끌 수 있다. 사람 없는 옛 사건·외부 원정의 목격자 귀환 경로 전체·모든 이름 소식 원천/첫 반응은 아직 전체 완료 범위가 아니다.
