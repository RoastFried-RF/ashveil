# 실제 귀환한 동료의 방 정찰 이야기

v0.163은 동료가 실제 그 자리에 서서 기록한 방을 실제N대화로 전하도록 연결한다. 떨어져 있거나 아직 직접 기록한 방이 없는 사람의 위치/현재 원격 방·주민·물품을 조회해 소식을 만들지 않는다. 같은 지역의 실제 개인 기록만 전하고 목격자 출처/당시 기록 시각을 보존한다. 이미 들은 같은 기록은 다시 만들거나 현재 사실로 덮어쓰지 않는다.

소식을 들었다고 칸을 보거나 방을 직접 발견한 상태가 되지 않는다. 종이·잉크·지도 문서를 만들거나 소비하지 않으며, 플레이어의 직접 탐험 지도 초안에도 복사하지 않는다. 구술 보고는 실제 원본 지도의 정찰 납품 증빙이 아니다. 글로 적힌 지도와 들은 방 위치가 같은 방을 다르게 가리키면 두 주장을 함께 충돌 표시한다. 직접 발견한 방이 우선하며 현재 원격 지형을 읽어 어느 출처가 맞는지 판정하지 않는다. 같은 방 식별자의 이름만 다른 경우도 충돌로 남긴다.

M창은 문서의 파란 점선·들은 위치의 호박색 점선·서로 다른 주장의 붉은 점선과 출처/기록 시각을 구분한다. 명시적인 층 수/크기를 실제로 전해 들었으면 그 층의 의뢰를 알 수 있지만 실제 층을 생성하지 않는다. 기록 없는 층 수는 의뢰에 추정하지 않는다.

기본 동행 거리는2칸이며 대화는1칸이다. 유효한 초기 원래 수도원에 떨어져 있던 동료가 실제 정상 차례로 귀환하고 플레이어가 한 칸 더 접근하는 입력을 사용한다. 출발을 실행했거나 먼 사람과 바로 대화했다고 주장하지 않는다. 기존 상충 지도는 처음부터 읽어 둔 유효 초기 기록이며 이동 중 지식을 주입하지 않는다. 기존 두 지도 충돌 독서 검사도 두 원본 쪽지를 첫 행동 전 초기 소지품으로 준비했다.

각인121과 콘텐츠 수치는 유지하고5개 골든 전체 초기/최종 상태·오류·해시가v162와 같다. 기존 명령/기대값을 바꾸지 않았다. 전용20개/관련5파일85개와 타입·린트·빌드를 확인했다.

브라우저806–809의4개 M창 장면을 모두 확인했다. 원래 수도원에서의 관찰·정상 귀환과 실제 플레이어 접근을 포함한36턴 뒤에도 소식이 자동으로 공개되지 않으며, 실제N버튼 대화1턴 뒤에만 당시 출처/시각과 미확인 위치를 표시한다. 기존 지도와 다른 위치는 두 미확인 주장으로 함께 남는다. 플레이어가 직접 발견한 방이 되지 않고 종이/잉크를 만들거나 쓰지 않는다.3전체 저장 복원과 남은19턴 전체 상태가 렌더러 연출 큐를 반영한 코어와 일치하고 콘솔 오류0이다. 초기 동료의 먼 위치/이전 지도는 유효한 초기 조건이며 출발/이전 독서 입력까지 실행했다고 주장하지 않는다. 전체166파일3,220개152.46초를 통과했다. 월드30판299.482416361초의 전체30행이v162와 같으며 이전 원문은 한 번 보관했다.
