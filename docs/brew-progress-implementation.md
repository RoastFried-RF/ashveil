# 같은 원래 물병의 차 끓이기 진행 보존

v0.115. 01 §7의 조리·물 끓이기 진행 보존에 맞춰 솔잎차 중단 후 재개를 연결했다. 기존 v0.108의 중단 후 진행을 잃는 처리는 이 기능으로 대체한다.

차 작업은 실제 원래 물병 UID/물량·수질·원래 솔잎 더미별 UID/수량·같은 유한 모닥불 UID/위치·조리 규칙과 총/남은 시간을 보존한다. 실제80턴 뒤 멈추면 같은 자원으로 남은120턴만 진행한다. 멈춘 동안 새 영양이나 정수를 만들지 않고 원래 물/솔잎을 소비하지 않는다. 불이 꺼져 실패한 틱은 남은 시간을 줄이지 않는다. 같은 원래 불에 실제 목재를 넣어 다시 피운 뒤 이어 갈 수 있다. 다른 물병/새 솔잎 UID/다른 불로 지난 진행을 옮길 수 없다.

도중에 물량이나 수질이 바뀌면 이전 진행을 거절한다. 실제1000ml 중200ml를 다른 원래 병으로 옮긴 재현은800ml+200ml를 보존하고 과거 열을 재사용하지 못한다. 명시적으로 차 작업을 취소하면 같은800ml/솔잎은 남고 새200턴 작업을 시작한다. 그때 물량에 맞는 솔잎3개만 소비하고, 다른 병의200ml는 그대로 남는다. 취소 자체는 물/솔잎/시간/난수를 바꾸지 않는다.

마지막 턴의 원래 솔잎 소비/같은 차 물병·기존 병원체0/재×1.1/소금 보존·부분 섭취 규칙은 유지한다. 별도 진행 난수를 추가하지 않는다. 제작 창은 원래 작업의 남은 시간·중단 이유·취소를 보여 주며 조회만으로 시간을 정산하지 않는다.

각인v79는 원래 자원과 중단/재개를 보존한다. 구형78에 실제 진행 중인 차 활동이 저장되어 있으면 그 활동의 실제 남은 시간만 작업 기록으로 옮긴다. 차 활동이 없으면 과거 끓임이나 진행을 지어내지 않는다. 다른 지도와 원래 이동 무리의 실제 저장된 차 활동도 같은 원칙을 쓴다.

전용16개·기존 솔잎차25개와 관련6파일92개·타입/린트를 확인했다. 일반 스케줄러 재현은 실제80턴/중단 뒤120턴만 추가해 같은 원래1L 차/솔잎4개 소비를 확인했고, 진행 중 저장 재개도 전체 상태가 같다. [5개 재현 전체 상태 감사](golden-v115-diff.json)는 버전79 외 모든 초기/최종 상태와 오류가 같다. v0.115에서는 원래 물병/솔잎/유한 불의 차 끓이기80턴 중단·남은120턴 재개·원래 수질/양/UID 변경 거절·실제200ml 분배와 취소/새200턴·각인v79를 연결했다. 전체117파일2,063개127.10초·전용16/기존 솔잎차25/관련92개·타입/린트/Def120패치/Schema101/빌드·최종 화면517~522/6장 전체 확인·6전체 복원·콘솔 오류0이다. 같은 검증 코어의 월드30시드×최대3일348.253983678초·30개 전체 행이 이전과 같다. 최종 파일 manifest가 일치한다.
