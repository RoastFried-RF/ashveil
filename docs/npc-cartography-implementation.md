# 일반NPC의 개인 지도 생산과 원본 판매

v0.169 작업은 고용하지 않은 사람도 자기 개인 관찰과 실제 소지한 빈 종이/잉크로 지도를 쓰도록 연결한다. 안전하고 한가하며 글을 읽고 손/시력/빛 조건을 만족할 때 기존60턴 작성 행동을 사용한다. 음식/물/보온/위생/휴식과 전투 등 기존 우선순위 뒤에 둔다. 진행 중 순찰·캐러밴·포박·동료에게 강제로 일을 맡기지 않는다.

플레이어의 발견 기록을 복사하지 않고 실제NPC 차례에 관찰한 자기 방/계단만 옮긴다. 같은 관찰로 이미 작성한 자신의 지도 지식이 있으면 다시 그리지 않는다. 새 관찰이 있거나 중단된 실제 작업은 기존 재료/진행 조건으로 처리한다. 종이/잉크를 새로 주거나 상점에서 몰래 빼오지 않는다. 일반 주민의 자동 재료 구매/조달 전체는 별도 후속이다.

N창은 실제 보이는 작성 작업과 정상 대화/거래 가능한 사람의 직접 작성 원본만 표시한다. 벽 너머/잠든 사람의 소지품으로 판매 내용을 공개하지 않는다. 원본 구매는1턴이며 같은 종이UID를 플레이어 배낭으로 옮기고 플레이어 돈을NPC 지갑에 준다. 배낭/돈/가격/저자를 먼저 검증하고 실패하면 전체를 보존한다. 실패/조회에는 첫 만남을 만들지 않고 성공한 실제 거래에서만 기존 첫 만남을 기록한다. 같은 원본을 두 번 팔거나 다른 인물/각인의 문서를 자기 지도라고 팔 수 없다. 고용한 동료는 원래 건네받기 경로를 사용한다.

구입만으로 내용이나 지형을 배우지 않는다. 직접 독서1턴이 당시 작성자·관찰 기록·오차/누락의 문서를 배우며 종이 원본은 남는다. 현재 원격 지형/주민을 확인해 지도 품질을 보정하지 않는다. 보이지 않는NPC의 작성 중단/개인 몸 상태는 플레이어 로그에 공개하지 않는다.

`Cartography.Hearth`의 PATCH에 최소 특징1·기본가격10·특징당5를 둔다. 기존 지도 작성/각인125 구조를 사용하고 옛 NPC에게 재료/문해/과거 작업을 소급하지 않는다. 기본 전체5골든의 초기/최종 상태·오류·해시는v168과 같아 원래 기대값을 변경하지 않았다.

전용22개·관련5파일102개(첫 만남 보강1개 전)·최종 골든 포함2파일32개·타입/린트·Def230패치·Schema127파일 오류0·빌드BNheUtzS1.43초를 확인했다. 미완료 검사는 NPC 차례의30TU까지 실제로 진행한 뒤 저장하며 남은7970TU(79.7턴)를 보존한다. 이 부분을80턴 정수로 반올림해 주장하지 않는다.

준비한 브라우저 검사는 처음부터 비고용 우호 인물/원래 개인 재료가 있는 유효 초기 조건을 사용한다. 과거 영입/해고/선물을 실행했다고 주장하지 않는다. 실제 대기1턴에 자신의 관찰/작성 시작·실제59번 추가 대기/총60턴의 작업·원본 구매1턴·I문맥 메뉴 독서1턴·미완료 복원을 확인한다. 브라우저831–835의5개 장면을 모두 직접 확인했다. 실제 대기1턴의 독립 관찰/자동 작성·59번 실제 추가 대기/총60턴·같은UID65 원본의 구매1턴/15표(P100→85/NPC7→22)·실제I문맥 메뉴 독서1턴·남은잉크2/추가종이77 미사용·내용 자동 학습 없음·4전체 각인125 복원(미완료 포함)/남은7970TU(79.7턴) 전체 일치·콘솔0을 확인했다. 통합 전체 회귀를 진행한다.
