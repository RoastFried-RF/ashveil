# 육로로 연결되는 정착지 소식

v0.167 작업은 정착지 간 소식의 간선을 실제 `worldRoute` 육로로 연결한다. 바다로 끊긴 마을은 월드 직선 거리만으로 연결하지 않는다. 실제 갈 수 있는 길의 칸 수로 가까운 세 정착지를 정하고 거리/6.4일+수다 지연을 적용한다. 기존 길 선택은 도로/지형의 원래 월드 이동 규칙을 사용하며, 소문은 기존6.4칸/일 수치를 유지한다.

조회는 플레이어의 지도·탐험·시간·난수·지역 생성에 영향을 주지 않는다. 경로 정보나 미도착 소식을 UI에 공개하지 않는다. 섬의 현지 게시 자체는 가능하지만 가상 배나 캐러밴을 만들어 바다를 건너지 않는다. 해상 전령/선박 신호망 전체는 후속이다.

별도 PATCH의 `landRoutes` 설정이며 각인124와 이미 대기 중인 소식의 원래 예정시각/내용을 보존한다. 전송 중 경로 변경을 따라 실제 전령 개체가 이동하는 모델이라고 주장하지 않는다. 새로 다음 정착지로 보낼 때만 그때의 육로를 확인한다.

새 전용5개/관련4파일64개6.08초·타입/Def229패치·빌드DZcBrXR32.65초를 확인했다. 합성7×5 단위 검사에서는 해협의 단절·4칸 직선 거리와10칸 우회로·섬의 현지 게시를 구분했다. 이 합성 지형을 원래 생성된 세계나 실제 여행으로 주장하지 않는다. 기존5골든의 전체 초기/최종 상태·오류·해시는v166과 같아 원래 기대값을 변경하지 않았다. 브라우저823–826의4개 주민 창 장면을 모두 직접 확인했다. 기본 원래 세계의 실제 게시1턴·예정된 육로 거리/기본 지연 경계·도착 전 실제대화1턴/대기1턴/도착 후대화1턴·3전체 각인124 복원/남은19턴 전체 일치·콘솔0을 확인했다. v167별도 전체검사/월드는 실행한 것으로 기록하지 않으며168과 통합 검증을 진행한다.

준비한 브라우저 검사는 원래 기본 세계의 게시 버튼1턴과 실제 육로/전파 지연의 일치를 검증한다. 근접 도착은 명시적인 유효 초기 소식이며 기본 지연을 줄이지 않고 도착 전 대화/도착 후 대화/미완료 저장 후19턴을 확인한다.
