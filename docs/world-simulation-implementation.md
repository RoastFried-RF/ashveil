# 전역 인구·저장고·회색열 — v0.36

28개 인간 정착지의 인구·저장고와 실제 시장 재고를 게임 시작부터 각인에 담는다. 구형 각인에서는 방문한 시장과 물품을 보존하며 전역 저장고를 연결한다. NPC를 모든 지역에 미리 생성하지 않으며, 기존 지역 진입 때의 주민 실체화를 유지한다.

저장고의 식량·연료·금속·약품·탄약·소금은09§5의180명 예시를 기본값으로 삼는다. 시작 식량2400/연료600/약품18/소금90, 목표 식량3600/약품18/소금60, 생산 식량160/연료25, 소비 인당 식량1/연료0.15/소금0.05다. 인구에 비례해 초기값과 생산을 조정한다. 고정 정착지의 인구와 길드/경비대의 탄약 생산은 Def의 임시 기본값이다. 식량1은2500kcal 분량이며 건빵350kcal는0.14다. 시장의 초기 배치·3일 보충은 저장고에서 실제 수량을 뺀다. 저장고가 고갈되면 주민 소비가 실제 시장 재고에서도 빠진다. 생산은 아직 작업자·원료·작업장별 제조 공정과 연결되지 않았다.

가격의 지역 계수는 분류 물자의 저장고+시장 합계와 목표의 제곱근 비율을 쓴다. 같은 약품 분류의 붕대·회복약을 함께 센다. 비분류 장비는 기존 공급표 가격/생산을 유지한다. 재고 일괄 정산과 하루씩 정산은 물품 생성시각·UID·인구·이월·RNG를 포함해 같다. 현재의 공급표·추상 저장고는 완전한 개별 제조·상류 자원 경제의 대체가 아니다. 현금은3일 공급표 보충을 유지한다.

회색열의 월드 전파·회복·사망 계수는 `Disease.GreyFever.population`의300/100/30‰다. 감염은 백만분율, 회복·사망은 천분율 나머지를 각인해 일별로 이월한다. **N은09 검산4의 고정 조사 인구**이며 S+I+R+누적 사망=N을 보존한다. 실제 물자 소비는 살아 있는 S+I+R로 계산한다. 400명/감염20명에서3일 후 S361/I30/R7/사망2가 된다.

가까운3정착지 사이의 일상 왕래를 하루6명으로 두고 `왕래×I/N×0.5`로 감염 씨앗을 판정한다. 양쪽의 전날 상태를 사용해 같은 날 계산 순서로 연쇄 감염이 빨라지지 않는다. 각 쌍은 별도 월드 RNG를 쓴다. 출발지/목적지 봉쇄는 각각 왕래×0.2다. 왕래 연결과6명은 설정 가능한 기본값이며, 실제 캐러밴 무리는 아직 없다. 월드 조우를 임의로 생성하지 않는다.

감염률5%에서 봉쇄를 결정하고 약품 목표가3배가 되어 실제 거래 가격이 오른다. 지역 안의 봉쇄/해제 표시는 진입 시 또는06시의 장소 변화 적용에서만 바뀐다. 밖으로 떠날 수 있으나 봉쇄 중에는 월드 지도에서 재진입할 수 없다. 저장·복원으로 봉쇄를 초기화하거나06시 전의 변화를 미리 적용하지 않는다. 멀리 있는 모든 정착지의 감염 수치를 지도에 공개하지 않는다.

현재의 자연 전파 시작점은 **실제로 임상 회색열이 있는 플레이어의 방문**이다. 방문객 전파0.5, 감염 지역 방문 시 I/N×0.5로 플레이어의 실제2~4일 잠복 회색열로 연결한다. 하루에 같은 정착지를 반복 출입해 판정을 반복하지 못한다. 처음 실체화하는 주민은 요약 감염 비율로 질병에 노출될 수 있다. 월드 SIR가 비활성 지역의 NPC를 즉석 생성하거나 매일 교체하지 않는다. 역사 시뮬의 초기 역병, 다른 전염병의 지역 전파, 의사·간병·검역 외곽 거래, 기근 사망/이주, NPC 임상과 요약 인구의 개별 대응은 남아 있다.

검증: 월드 시뮬15개·모드 오류1개를 더해37파일512테스트, Schema37파일과 코어/샘플 Def·타입·빌드를 통과했다. 기존3골든은 전체 초기/최종 상태가 그대로이며, 월드28/30입력은 저장고/시장·인구·UID와 상점 식량의 날씨 기록만 추가됨을 전체 상태 비교로 확인했다. 기존 명령·오류·플레이어 시간/신체·NPC·경로·기존 RNG는 보존했다. `golden-v036-diff.json`에 감사를 남겼다. 전용 브라우저(world-health-v036)는 실제 자정의 S375/I23/R2·약품값 상승,06시 봉쇄 표시/진입 거부·저장 복원·재개방/주민 중복 방지를 통과했고 콘솔 오류0이다. 화면47~51과 설정을 확인했다. 전역 시장 물품이 로컬 NPC의 생성 순서/AI 경로 판정에 영향을 주지 않도록 별도 안전 정수 UID 공간을 사용한다. 이 분리의 회귀를 추가했다. 최종 전체 브라우저(full-final-v036)도 화면01~51·설정을 통과했고 콘솔 오류0이다. 시뮬레이션 결과는 아래와 같다.
