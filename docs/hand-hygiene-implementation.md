# 손 씻기와 접촉 오염 — v0.45

02 §12.1/시나리오2의 손 씻기200ml·3턴, 씻음 Q +5 / 보통0 / 피·흙 −10, 더러운 손으로 열린 상처를 만질 때 오염 +5를 연결했다. 손 상태는 전신 위생과 별개이며, 청결 습관 특성과 장갑 −5(봉합 −15)는 기존대로 더한다. 따라서 특성 없는 지각13·의료4·의료가방15·실내5·씻은 손5는 검산B의 Q87이다. 청결 특성까지 있는 기본 의사는 같은 조건에서 Q92가 된다.

`HandHygiene.Human`에 수량/시간/보정을 정의한다. 씻음은 다음 접촉 오염 또는1시간까지 유지된다. 1시간은 문서에 없는 임시 조정값이며 만료 후 보통으로 돌아간다. 피·흙 묻은 손은 기다리는 것만으로 깨끗해지지 않는다. 기존 각인은 보통 손으로 시작하고 원래 특성·몸·재고를 유지한다.

J의 생존 탭에서 손 상태와 씻기 버튼을 확인한다. 행동을 완료할 때 실제 물을 다시 확인하고200ml를 소모한다. 중단하거나 물이 사라지면 깨끗함을 주지 않는다. 술과 얼어붙은 물은 사용할 수 없고, 물가의 얼음 구멍도 기존 규칙으로 확인한다. 손 씻기로 전신 위생·갈증·체온을 즉시 회복시키지 않는다. 전신 목욕을 완료하면 손도 씻긴다. 물가에서 몸을 씻을 때의 젖음/냉각은 기존 규칙을 따른다.

실제 물병은1000ml/5회이고200ml가1회다. 음료의 실제 `drink.water`와 잔량으로 ml를 정산하므로 다른 용량의 모드 병이나 일부 잔량도 지원한다. 여러 병의 물을 합산하고 필요한 양만 쓰며 빈 재사용 병의 UID를 유지한다. 마지막100ml를 마시면100ml만 흡수하고 오염 노출도 같은 양으로 계산한다. 물 나누기도 실제200ml를 요구/소비한다. 남은 양은 ml로 표시한다. 음수·비정수·NaN 물 소비 요청은 거부한다.

`Wound.handContact`는 베임·찔림·화상·물림의 접촉을 정의한다. 열린 상처의 실제 붕대/외과/세척/외용약 접촉, 출혈 압박, 실제 채집/해부 작업은 손을 더럽힌다. 상처 처치의 Q는 그 효과를 적용하기 전 손 상태로 계산하고 접촉 뒤 다음 처치에 반영한다. 더러운 손으로 봉합하면 오염 +5를 더한 뒤 미세척 상처의 기존1.5배 규칙을 적용한다. 닫힌 타박·폐쇄 골절·내부 상처를 만났다는 이유로 열린 상처 오염을 만들지 않는다. 채집/해부 첫 유효 작업 뒤 중단해도 손의 오염은 남고 재료는 만들지 않는다. 음식 위험은 기존 위생 위험 수치를 손의 실제 오염에도 적용하며 두 조건이 겹쳐도 같은 위험을 중복 가산하지 않는다.

의사는 환자 사이에 자신의 물로 더러운 손을 씻는다. 적 피하기·갈증·음식이 먼저이며 활동 중 새 진료를 받지 않는다. N에서 손 상태/씻는 중 표시와1턴 대기 버튼을 제공한다. 기본 의사의 진료 물3병(3L)은 기존 정착민의 개인 물2병과 별도로 지급해 총5L다. 재보급 최소1/목표3회분·병 가격 상한12전은 임시값이다. 시장에서 물을 살 때도 기존 실제 재고/현금/용량 규칙을 사용한다. 무한한 물이나 무료 세척을 부여하지 않는다.

각인v12는 진행 중 손 씻기/손 상태/실제 잔량을 보존하고 v2~11의 몸·활동·물품을 유지한다. 기존5고정 입력의 원본 명령·오류는 유지했고 물리 상태/시간/난수도 같다. 차이는 버전 번호와 freeze-reentry의 실제 접촉으로 기록된 손 오염뿐이다(`golden-v045-diff.json`).
