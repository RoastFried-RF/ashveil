# 주민의 유한 상점 재고와 실제 물 용기 조달

v0.123. 각인87. 위생 관리에 실제2L가 필요하지만 가진 용량이 부족한 주민은 아는 상점까지 걸어가 자기 돈으로 물 용기를 구한다. 이동 계획은 원격 상품/가격을 읽지 않는다. 도착한 뒤 실제 재고·거리/시야·손·자금·배낭과 물품당 지불 상한20을 확인한다. 빈 물병과2L 양동이도 원래 물품 그대로 다룬다. 실제 부족 용량에 대한 가격으로 고르고 필요한 용량을 확보하면 추가 구매를 멈춘다.

구매는 기존 거래의 원자적 배낭/상점/지갑 이전을 쓴다. 한 개짜리 물품은 원래UID, 묶음 재고의 일부를 나누면 실제 한 조각에만 새UID를 쓴다. 구매가 물이나 용기를 생성하지 않는다. 실제 상점 재고가 줄고 주민 돈이 상점 금고로 간다. 그 물통을 우물에서 채우고 씻은 뒤에도 구매한 물품UID를 유지한다.

상인은 자기 상점 곁으로 실제로 돌아와 이미 소유한 유한 재고 한 개를 개인 배낭으로 옮긴다. 자기 자신과 거래하는 가짜 상대를 만들지 않는다. 개인 지갑/상점 금고는 그대로이고 전역 비축에서 두 번 공제하지 않는다. 공간이 없으면 물품/지갑/UID를 먼저 바꾸지 않는다.

배낭 용량이 충분하면 물이 비어 있어도 새 용기를 사지 않는다.2L 양동이와 빈1L 병을 함께 갖고 있다면 실제 부족량을 한 번에 채울 양동이를 우선해 불필요하게3L를 뜨지 않는다.1L 두 병은 기존대로 준비한다. 부족한 돈/재고/공간·가격 상한·잠/죽음/적대·손/추위/포박/위생 설정을 확인하며 실패는 현지 재시도만 미룬다. 조회가 돈/물품/UID/난수를 쓰지 않는다. 주민 조달은 플레이어의 기록/세계 지식을 대신 공개하지 않는다.

초기 부족 상태 검사에서는 원래 주민의 용기 하나를 먼 바닥에 남겨 보존하고, 원래 빈1L 한 개와 소지금100으로 시작했다. 실제 경비는 상점까지 걸어 재고8→7, 지갑100→90, 상점 금고300→310을 만든 뒤 원래 빈 병73과 실제 구매로 나뉜 병85를 채워2L/200턴 몸 씻기를 끝냈다. 같은 빈73/85가 남고 추가 구매는 없다. 상인은 원래 개인 병54와 자기 재고에서 옮긴85로 씻으며 두 현금 장부가 그대로다. 기본 주민이 항상 용기 하나나 현금100을 받는다는 뜻이 아니다.
