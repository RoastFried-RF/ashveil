# 좋은 치료와 현물 유물 복원

v0.134. 정본04 §3.4#52의 붕대·봉합 Q50 이상을 실제로 완료한 환자에게 +2/1일 기억(최대2회, 두 번째×0.5)을 연결했다. 시작/취소/반완료/낮은 품질에는 생기지 않는다. 기존 일반NPC의 좋은치료 사건−2는 유지하며 별도 사고를 중복 변환하지 않는다. 기계·동물에게 인간 사고를 만들지 않는다.

04 §3.6#69의 고물 발굴꾼은 실제 부품으로 기계 손상 또는 유물을 복구했을 때 +4/1일 기억을 받는다. 전원/냉각액 보충·누출 밀봉은 복원 사건이 아니다. 같은 생활사건 메타데이터로 품질 경계와 배경을 검증한다.

08 §8.3의 가방 유물 수리를 실제 경로로 연결했다. 기존 개척 의수/정원사 팔다리 두 품목에 패치로 내구와 수리 규칙을 추가했다. 새 Item/이름/이미지는 추가하지 않았다. 기존 소형 구동기·망치·장인 작업장을 사용한다. 감정2를 요구하고 기존 공개 감정30턴 뒤 수리200턴을 진행한다. 부품량은 기존 수리량 견적에 따라1~2개다. 실패율은 clamp(10,60,60−실제 감정치)%이고, 시작 때 확률과 결과/원래 부품UID를 같은 작업에 저장한다. 완료 때만 전용 items.relicRepair.원래UID 난수를 한 번 사용한다. 실패는 실제 부품을 쓰고 같은 유물의 내구0/영구파손을 남기며 재시도를 막는다. 성공에는 기존 최대내구 영구감소/복구 공식을 사용한다. 부품/작업장/도구/몸 상태가 나빠지면 재료와 난수를 쓰지 않고 진행을 보존한다.

기존 유물 품목에 있는 실제 소형 구동기를 희귀 부품으로 사용하는 것,1~2개/200턴은 모드 가능한 구현 기본값이며 새로운 CANON 수치로 확정하지 않았다. 미감정 유물의 실제 이름/수리 부품/확률은 숨긴다. 수리 화면에는 실패율과 영구파손 경고를 표시한다. 구형 가방 유물에 새 내구/파손/과거 기억을 소급하지 않으며, 이미 저장된 작업에 실패율을 새로 붙이지 않는다. 각인97→98은 버전만 이관한다.

전용25개/관련6파일129개 검사가 통과했다. 다섯 골든 전체 초기/최종/오류는 버전98을 제외하면v133과 같다. v0.134에서는 완료한 좋은 붕대/봉합의 기억과 고물 발굴꾼의 실제 기계·가방 유물 복원을 연결했다. 원래 구동기/망치·정밀 감정/장인 작업장·200턴 수리·실패 영구파손/부품 소모를 구현했다. 각인v98·전용25/관련129개·전체136파일2,623개127.55초·타입/린트/Def187패치/Schema110/빌드·화면634~640 일곱 장 전체 확인·7전체 복원/실제199턴 재개/콘솔0이다. 월드30판304.51232693699995초의 전체 기록이v133과 같다.
