# v1.0.0 자율 개발·출시 기준

2026-10-23 KST. 사용자가 프로토타입에 더해 후속 확장 X1–X4까지 포함하고 v1.0.0까지 자율 진행하도록 지시했다. Eslabong의 정확한 참고작은 [사용자가 제공한 Steam 페이지](https://store.steampowered.com/app/4560660/Eslabong/?l=koreana)다. 큰 구현 묶음으로 개발 미리보기를 push/Pages에 갱신하고, 최신 지시에 따라 통합 테스트는 후속 단계로 모은다.

`expansion-roadmap.md`의 첫 표는 오래된 단계별 계획을 포함한다. 예를 들어 화재·계약·사건 성향·영향권·주민 농업·재장전은 후속 버전에서 일부 구현됐다. 그 표의 단어 하나를 완성으로 보거나 과거 체크박스 수로 완성률을 계산하지 않는다. 현재 코드/실제 검증 근거와 대조해 아래의 남은 범위를 닫는다. **v0.305 시야 구현은 v1.0 완성을 뜻하지 않는다.**

기존 엔진은 웹 배포·결정론·순수 코어와 현재 원화를 지원한다. 현재 병목을 해결한다는 근거 없이 이전하지 않는다. 먼저 실제 프로파일/검증으로 병목을 확인하며, 이전이 유리하다는 근거가 생기면 사용자가 이미 허용한 범위에서 판단한다.

## 기능을 닫는 조건

실제 입력→행동 비용→원래 몸/물품/인원/돈의 변화→보이는 화면→저장 복원을 연결한다. 원래 UID·수량·난수/기억을 지키며, 숨은 정보를 UI에 유출하지 않는다. 의미 있는 경계 검사와 고정 입력/전체 상태 감사를 포함한다. 리소스는 개별 구조를 검토하고 실제 장면에서 읽히는지 확인하며 생성 원본·매핑·출처와 검토 결과를 남긴다. 참고 이미지를 게임에 복제하지 않는다.

## 출시 게이트

- 타입·린트·Def/Schema·스프라이트·고정 입력·저장 호환·전체 회귀 통과. 시간 초과 재검은 최초 실행과 구분한다.
- 두 화면 크기의 실제 키/마우스·UI·로드/저장·치명/은퇴/다른 결말을 확인한다. fixture와 자연 플레이 결과를 구분한다.
- 동일 시드30판/최대3일 균형 회귀와 GDD의1,000판 탐험 기준을 별도로 충족한다. v0.305 World30은 저체온13/치명상11/과다출혈6, 평균0.37777일로 기존0.48862일보다 짧다. 실제 사람 평가와 함께 전투/생존 편중 및 안내·봇 전술을 점검해야 한다.
- GDD의 실제 사람30분 플레이/사망 보고서 평가와 외부 테스터5명 중4명 재플레이 기준은 사람의 증거가 필요하다. 봇·자동 브라우저로 충족했다고 쓰지 않는다. 구현/자동 검증을 먼저 완료한 뒤 검토 가능한 빌드와 재현 정보를 제공한다.
- 위 범위의 남은 필수 항목을 근거 없이 삭제하거나 버전만1.0.0으로 바꾸지 않는다. 코드 완료·자동 검증 완료·외부 평가 완료를 구분한다.

루틴 수치/구현 판단은 현재 CANON 기본값과 근거를 사용해 자율 진행한다. 옛 문서의 확인 대기 문구만으로 작업을 중단하지 않는다. 인간 평가가 필요한 출시 게이트는 남아 있음을 정확히 기록한다.

C10 대체 저장 방식은 v0.306에서 실제 새 원정 선택/저장/취소/사망/복원/204호환·분리 메타를 통합 검증했다. [검증 근거](release-v306-proof.json). 다른 범위와 외부 사람 평가 게이트는 유지한다.

## 현재 작업 순서 — 사용자 최신 지시

2026-10-23: 구현을 우선하고 테스트는 나중에 하며, v1.0.0을 목표로 기능·UI를 큰 묶음으로 개발한다. 매 기능마다 전체 회귀/월드/브라우저를 반복하지 않는다. 게시에 필요한 컴파일 오류는 구현 중 정리하고, 묶음 뒤 회귀·저장 호환·실제 화면을 검증한다. 미실행 검사는 통과로 기록하지 않으며 v1.0.0 출시 조건은 유지한다. 이미 검증된312는 게시를 완료했다.

현재316은 이동/광원 사용자 결함과 인간형 원화·실제 손 장비 표시를 개선했다. [범위](movement-people-v316.md). 두 화면 크기의 제한된 실제 이동 진단은 전체 통합 검증을 대신하지 않는다. 다음 기능 구현은 아래 미완료 범위를 계속 다루고, 기존 멈춘310 기준1,000판은 자동 재개하지 않는다.
