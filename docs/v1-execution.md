## 기능을 닫는 조건

실제 입력→행동 비용→원래 몸/물품/인원/돈의 변화→보이는 화면→저장 복원을 연결한다. 원래 UID·수량·난수/기억을 지키며, 숨은 정보를 UI에 유출하지 않는다. 의미 있는 경계 검사와 고정 입력/전체 상태 감사를 포함한다. 리소스는 개별 구조를 검토하고 실제 장면에서 읽히는지 확인하며 생성 원본·매핑·출처와 검토 결과를 남긴다. 참고 이미지를 게임에 복제하지 않는다.
