# v393 보온 판단과 행동별 체온 안내

v388의 실제 월드30판에서 저체온13판이 있었다. 최종 저장을 조사하니 봇이 불 가까이에 있다는 이유로60턴 휴식을 반복하는 경우가 있었다. 실제로는 강풍·젖은 옷·낮은 기온 때문에 불 곁에서도 계속 식었다. `03-survival.md` §7.3의 의도된 환경 위험을 유지하면서 잘못된 보온 판단과 안내 부족을 수정한다.

## 실제 몸과 날씨를 쓰는 비교

`projectThermalState()`는 현재 옷·품질·부위별 젖음·체질·열원·바람·침구·약물/발열로 다른 행동이나 자리를 비교한다. 기존 `thermalState()`와 같은 측정을 사용한다. 세계·몸·물품·난수·열 적산은 바꾸지 않는다. 직전 걷기/전투·건조 활동의 냉각을 다음 휴식에 이월하지 않으며, 깊은 물에서 떠 있기 위한 작업 대사는 휴식/수면 예상에서도 유지한다.

예측은 현재 조건이 유지될 때의10분당 변화율이다. 미래의 날씨·젖음 변화·연료 소진을 미리 읽거나 성공을 보장하지 않는다. 체온은 기존 실제 턴 적산으로만 움직인다. 열량·피로·부상·탈수·연료·옷의 수치와 저장219는 바꾸지 않았다.

## 봇의 보온

- 불/지붕 곁에서 휴식으로 실제 회복할 수 있으면 쉰다. 휴식으로 식는데 몸 풀기는 회복시키면 기존 `warmByFire` 행동을 수행한다.
- 몸 풀기로도 부족하면 알려진 지붕/불의 열수지를 비교한다. 미탐색·보이지 않는 목적지, 물·피해야 할 방·통과할 수 없는 길을 피하고 실제 한 칸 이동을 사용한다.
- 더 나은 알려진 피난처가 없으면 실제 몸 풀기로 손실을 줄일 수 있다. 이를 회복이나 생존 보장으로 세지 않는다.
- 꺼진 설치형 모닥불을 `toggleFire`로 무료 점화하려던 반복을 막았다. 실제 땔감이 필요한 기존 규칙을 유지한다.
- 전투·출혈 처치·음식/물 판단의 기존 우선순위를 유지한다. 봇의 판단 개선과 생존 수치 조정은 구분한다.

## 화면

상태 칩에서 `불 곁에서도 체온 하락`, `멈추면 체온 하락`, `체온 회복 정체`를 구분한다. 클릭 또는 키보드 초점→Enter로 일지의 생존 탭에 도달한다. 위독 경고가 우선하며 새 확인창이나 행동 차단을 넣지 않는다.

생존 탭은 같은 자리의 휴식·수면/현재 침구·실제 몸 풀기를 비교한다. 몸 풀기 불가 사유와 조건 유지의 한계를 표시한다. 회복 불가/변화 없음은 중립색이며 냉각/가열은 부호와 수치로도 구분한다. 기본 `j`는 남쪽 이동이므로 일지는 실제 `Shift+J`를 검사하며, 경고에 고정 단축키를 쓰지 않는다.

## 검증 기록

최종 실제 입력 불변본은 `v393-validation-r5`, 월드 검사는 `v393-thermal-r3`이다. 둘의 Core336파일은 모두 바이트가 같다. 국소5파일47검사, 타입·전체 린트(오류0/기존 미사용 함수 경고1), 기존5골든의 전체 초기/최종/명령 오류 동일을 확인했다. 기존 기대값은 바꾸지 않았다.

실제 입력 검사는 유한 초기 각인을 타이틀에서 불러와 휴식/몸 풀기·예측 조회·저장 복원을 독립 Node 전체 상태와 비교한다. 불러오기 뒤 세계/수치/난수 주입을 하지 않으며 소비된 표현FX만 정규화한다. 첫 검사의 일지 키 실수와 실패를 보존했다. 최종8조건×3화면(1440/1366/390)의24장면90전체 상태 쌍이 같았고 브라우저 오류0, 문서 가로 넘침0이었다. 실제 Tab3회→경고 초점→Enter로 일지를 열고 실제 버튼/키로 진행했다. 직접 연 선택5화면과 집계는 [검증 기록](release-v393-proof.json)에 연결한다.

같은30시드/최대3일의 새 월드 검사는 저체온13→3, 3일 시간 종료 생존0→7, 평균0.315230324→0.963060185일이다. 치명상13→14, 과다 출혈4→6도 그대로 보고한다. 전체 초기30개가 같고, 새 봇 판단에 따라 최종13개가 달라졌으며17개는 그대로다. 원래 초기/최종60저장을 모두 전체 복원/원래 해시와 대조했다. 실시간 실행 시간은 하드웨어 성능 비교가 아니다.

남은 저체온은 sim-9/18/19다. 세 최종 상태 모두 피로100이며, 두 몸은 열량−6,000kcal 아래/젖음100%, 한 몸은 발열 상태였다. 최종 저장만으로 전체 사망 인과를 재구성했다고 주장하지 않는다. 몸 풀기는 음식·수면·마른 옷을 대체하지 않으며 새 판단이 생존을 보장하지 않는다.

전체 디버그 세계/시뮬레이션 저장은 로컬 검증 자료로만 유지한다. 공개 문서에는 집계·선택 화면·SHA만 넣는다. 봇의30판이나 자동 브라우저는 사람 플레이 평가가 아니다.
