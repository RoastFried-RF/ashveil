# 첫 만남의 인상과 실제 주민의 기억

v0.104.

설계03의 위생20미만→연합 주민 첫 인상−5, 설계04의 냉혈−5, 기존 탈주 노예 배경−5, 설계02의 얼굴 흉터−5와 유리 눈+3을 실제 대화·거래·흥정·진료·수업·숙박·고용에 연결한다. 같은 사람의 실제 최초 접촉을 한 번 기억한다. 기존 기억은 목욕·외형 변화·지역 이동 뒤에도 보존한다. 견적·화면 선택·실패한 행동은 접촉을 기록하거나 난수/UID/현금을 소비하지 않는다.

인상은 관찰자별 실제 인물 ID를 키로 저장한다. 서로 깨어 있고 의식이 있으며 바로 곁에서 실제로 만날 때만 형성된다. 얼굴의 눈·코·턱 흉터는 실제 아문 상처에서 읽고 여러 개여도 한 번 감점한다. 내부 장기·두피·없어진 부위·의수족으로 대체한 부위는 얼굴 흉터로 세지 않는다. 유리 눈은 같은 원본 물건이 실제 설치되어 정상 내구도를 가질 때만 가산한다. 보이지 않는 외형을 알아내거나 후각도 없는 주민에게 악취 정보를 주지 않는다. 위생 기능을 껐을 때 남아 있는 낮은 수치를 감점하지 않는다.

현재 상대의 실제 기억은 흥정 성공 확률과 새 동료의 최초 관계에 반영한다. 기존 동료 관계를 덮어쓰지 않는다. 고용료·상점 기본 가격·의료/수업/숙박 요금·세력 평판을 이 값으로 변경하지 않는다. 원래 이야기 난수와 거래 수량·현금 보존 규칙을 사용한다. 관계 한도에서 실제 적용된 변화만 관계 기록에 남긴다.

Economy.Hearth.firstImpressions의 hagglePerPoint=1과 태도 구간(warmAt=10, waryBelow=0)은 수정 가능한 구현 기본값이다. CANON에서 결정 대기인 전역 경제/평판 수치를 확정한 것으로 취급하지 않는다. 화면에는 실제 접촉 당시 전달된 반응만 한국어로 표시한다.

각인v68은 원래 첫 기억·몸·물병·현금·진료 예약·관계와 난수를 보존한다. 구형67은 버전만 올린다. 이미 만났지만 과거 인상이 없는 주민에게 현재 외형을 과거 기억으로 만들어 넣지 않는다. 아직 만나지 않은 주민은 이후 실제 접촉에서 기억을 만든다.

전용21개와 관련262개 검사는 실제 정착지 입력/원래 주민과 재고·위생 문턱/설정 해제·첫1턴 대화·원래 두 병의2L/200턴 목욕·다른 원래 경비까지 실제 걸음·동일 인물 기억 보존·아문 얼굴 상처/원래 유리 눈의 실제 설치·실제 흥정의 동일 난수·구매 수량/현금·최초 고용 관계·실패한 진료/수업/숙박의 원자성·전체 각인/구형 과거 기억 생성 없음을 확인했다. 테스트 초안의 지역 지도 이름 가정, 설치 숙달 준비 누락, 목욕 뒤 이동한 경비에 대한 접근을 수정했고 저장 비교는 JSON의 전체 영속 필드를 대상으로 확인했다.

v0.104에서는 실제 주민별 첫 만남의 인상·위생/냉혈/배경/아문 얼굴 흉터/원본 유리 눈·동일 기억의 흥정/새 고용 관계·원래2L 목욕 뒤 기존/새 주민 구별·각인v68을 연결했다. 전체106파일1,806개106.04초·전용21개/관련262개·타입/린트/Def99패치/Schema91/빌드·화면446~451/6장·네 차례 전체 복원·콘솔 오류0이다. 같은 검증용 사본의 월드30시드×최대3일316.770193908초·30개 전체 행이 이전과 같다. 검증 소스/테스트/도구가 고정 사본과 같은 동안 전체 검사를 완료했고, 동일 사본의 빌드로 브라우저와 월드를 검증했다. 접힌 동행 메뉴를 열지 않은 첫 브라우저 검증을 실제 summary 클릭으로 고쳐 같은 빌드에서 재실행했다. 모든6장 화면을 직접 확인했다. 과거 사본은 전체 파일 SHA-256 manifest와 같다.
