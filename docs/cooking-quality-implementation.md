# 직접 굽기의 실제 음식 품질과 원본 치즈·열매 표시

v0.117. 03 §4.3의 지각/생존 숙달 음식Q를 기존 직접 굽기에도 연결했다. 불 위에 올리는 조리와 같은 기초식25+실제 작업 점수+생존 단계×4를 사용한다. 직접 굽기 시작 때 실제 지각·조작 상태/모닥불 보정을 기록하며, 마지막 실제 조리 턴에만 독립 음식 난수0~30−15를 적용하고0~100으로 제한한다. 시작/199턴 중간에 음식 결과나 품질 판정·영양을 만들지 않는다. 중단 후 재개는 기존 진행 보존 규칙을 쓰고 다시 시작한 실제 조리자의 조건을 기록한다.

같은 원래 한 개를 실제200턴에 한 구운 음식으로 만들고 기존 영양·신선도·재·해동/탄 상태를 보존한다. 음식Q는 기존 좋은 음식 사고와 표시를 사용하며 영양을 추가로 생성하지 않는다. 높은 실제 지각/숙달로 만든 한 회분을 실제 먹어야 그 당사자가 좋은 음식 사고를 얻는다. 예전 날고기 검사의 질병 난수 불변 조건은 그대로 확인하며, 새 음식 품질 전용 스트림 하나만 별도로 사용한다.

기존에 버섯 그림으로 표시하던 치즈와 잿딸기는 서로 다른 원본32×32 치즈/딸기 타일로 바꿨다. 원본을 수정하지 않았고 커밋/URL/SHA-256·라이선스 파일은 [원본 명세](../tools/art/food-sources.json)에 기록했다. [재현 도구](../tools/art/fetch-food-icons.py)는 기본 동작으로 파일 해시·PNG 크기·라이선스를 확인하고 --fetch로 고정 원본을 다시 받는다. 나머지 음식의 임시 그림은 별도 후속 범위다.

각인v81은 진행 중 실제 조리의 품질 기초와 마지막 판정/결과Q를 보존한다. 구형80의 완성 음식에 과거 품질을 소급하지 않는다. 품질 기초가 없는 구형 실제 미완성 조리는 저장된 남은 시간을 마친 뒤 현재 실제 조리 조건으로만 판정한다.
