# 배열 합성과 상속 값 삭제

v0.193 구현. 정본design/11 §3.3의기본배열교체·앞뒤추가/삭제·null키삭제·`$inherit:false`객체교체를 같은순수병합규칙에연결했다. 배열합성은기존값삭제→앞추가→뒤추가순서이며객체값삭제는키순서와무관하고`{id:값}`은같은원래ID를찾는다. 새배열원소/객체는사본이라부모나패치원본을바꾸지않는다.

잘못된지시/배열이아닌대상/혼합필드는오류다. 실패한패치는원본을보존하고실패한상속과그자손은실행용DB에넣지않는다. 원본JSONSchema는상속자식의부분객체·삭제·배열지시를허용하면서잘못된배열/원소타입과기존책의잘못된pages타입을계속거절한다. 해석된필수값/실제참조/범위는로더도검사한다.

기존검사중상속자의선택필드null을항상손상으로보던경우는정본의실제삭제로구별했다. 생고기의rawDisease/면포respirator는제거됨을검사하고, 열매seasons/소나무needles를지워연결이깨지면실제forage/pines참조오류를검사한다. 잘못된형태검사는유지하고방진필수수치누락검사를보강했다. 단순히오류검사를생략하지않았다.

선택형`sample-merge`는기존네성향배열에‘긴휴식’1개를추가한다. 기본quiet는48시간을유지하고추가성향은72시간쉰다. 선택자예제와함께켜면quiet60/추가성향72가각각유지된다. 기능적이름의실행가능한모드예제이며미확정된정식스토리텔러명칭을확정하지않는다. 기존사건의현재인원/유한예산/회복규칙을사용하고새Def/Item을추가하지않는다.
