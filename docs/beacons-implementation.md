# 실제 해안 봉화와 원래 소식의 전달

v0.92 / 각인v56의 구현 기록이며 전체94파일1,571개114.29초·관련5파일144개8.90초·타입/린트/Def80패치/Schema85/빌드를 통과했다. 실제 브라우저356~361/화면6장을 검토했고, 원래 땔감 점화/유한 빛과 열·20턴 부호화/실제10턴 전송·수신 직후 모르는 지식/직접 읽기·날짜/출처/전달 단계와 실제 한 턴 진행한 점화의 계속하기를 확인했다. 네 차례 전체 각인v56가 정확히 일치하고 콘솔 오류는0이다. 원래 NPC의 사전 지식/실제 규칙 부호화와 수신 지역 진입은 별도 초기 조건이며 브라우저는 남은 전송과 읽기를 직접 수행했다.360 화면에서 켜진 실제 봉화도 확인했다. 같은 동결 소스 월드30시드×최대3일267.122824391초·평균0.4219895833333334일·저체온19/치명상5/과다 출혈6으로30개 전체 행이v0.91과 같다.

장부소의 실제 봉화와 가까운 실제 해안 중계소/부두 지도를 연결했다. 인근 지역은 먼저 생성한 장부소의16칸 안에 실제로 닿는 해안으로 고르며 원래 지역·도로 추첨은 유지한다. 중계소에는 인구나 시장을 만들어 넣지 않는다. 실제 방문한 지도에만 원래 봉화 UID와 수신 기록이 있다. 보지 않은 곳의 기구나 주민을 원격으로 만들지 않는다.

원래 나무 한 단위와20기본턴 작업으로 불을 살려2,400턴 연료를 더한다.28,800턴이 실제 저장 한도다. 원래 물품 UID/수량을 완료 때 한 번 소비하며 교체 물품으로 대신하지 않는다. 같은 불이 실제 빛과 열을 내고 떠나 있어도 연료 시각이 흐른다. 현재 자동으로 무한 연료를 공급하는 관리자는 없다.

실제로 아는 소식만20기본턴 동안 부호화한다. 원래 소식의 ID/내용/출처·날짜와 원본 송수신 봉화/양쪽 규약을 묶는다. 손·의식·시야와 문해1이 필요하다. 같은 신호망/거리16칸과 실제 지형 고도를 확인하며40m 높이의 봉화 사이를 산이 가리면 거부한다. 신호 기본 처리량은 월드 한 칸당20이며 실제 양쪽 불이 살아 있을 때 턴당2씩 진행한다. 소문 속도×2 규칙을 이 명시적 전송에 적용한다. 기존 외부 소문·평판·친족의7일 소식을 일괄 절반으로 바꾸지 않는다. 일반 캐러밴/전령 전체를 구현한 것으로 집계하지 않는다.

불이 꺼진 구간은 전송을 멈춘다. 다시 불을 넣기 전에 이전 시각까지 정산하므로 어두웠던 시간을 진행으로 받을 수 없다. 원래 기구가 사라지거나 양쪽 규약/실제 경로가 달라지면 실패한다. 다른 UID의 새 봉화로 넘어가지 않는다. 전송은 소식의 복사이며 물품을 순간 이동시키지 않는다.

수신 뒤에도 플레이어가 내용을 자동으로 알지 않는다. 실제 봉화에 닿아 기록을1턴 읽어야 원래 소식의 내용·작성일·출처와 전달 단계+1이 개인 지식으로 들어온다. NPC도 같은 수신 규칙을 쓰지만, 현재 UI는 플레이어의 실제 인접 봉화를 표시한다. 중복 전송/중복 읽기로 기록을 복제하지 않는다.

F2에서 남은 연료/원본 땔감·직접 아는 소식/방문한 수신소·부호화/수신 기록을 확인한다. 진행 중 연료 작업과 전송 패킷을 각인v56에 함께 보관한다. 월드 전체 소문 재생산·일반 전령·날씨에 따른 광학 통신 전체와 소금 경제/나머지 후속 구현은 계속 진행한다.
