# NPC가 실제 읽은 쪽지와 대화로 전한 지도

v0.161은 NPC의 같은 쪽지 읽기 행동이 개인 지식에 내용을 남기도록 고쳤다. 원래 소유한 물리 쪽지/문해/시야·빛/깨어 있는 몸을 검사하고 정상1턴을 쓴다. 책의 다턴 학습은 기존 경로를 유지한다. 한가한NPC는 자기가 아직 읽지 않은 쪽지를 한 번 읽고, 순찰/긴급 화재/욕구 대응을 위해 경로를 중단하지 않는다. 플레이어도 보이지 않거나 읽을 밝기가 없는 쪽지를 원격 독서할 수 없다.

NPC가 읽어도 플레이어 지식이 자동으로 늘지 않는다. 실제 목격한 독서는 행위자/쪽지 제목만 보이고 비공개 내용은 알림으로 공개하지 않는다. 이후 곁의 깨어 있는 두 사람이 실제1턴 대화하면 화자가 이미 읽거나 전해 들은 유효한 당시 지도만 전한다. 출처와 전달 단계를 더하고 작성자·작성 시각·원래 방/계단 주장을 보존한다. 원래 종이를 옮기거나 현재 원격 층을 생성해 진위를 확인하지 않는다. 다시 들은 같은 주장은 중복/갱신하지 않는다.

기존 어두운 지붕 아래 초기 지도 독서 검사는 새 공통 독서 조건에 맞춰 초기 플레이어 칸만 실제 낮 바깥으로 설정했다. 턴 중 빛을 주입한 것으로 쓰지 않는다. 같은5골든 전체 초기/최종 상태·오류·해시가v160과 같아 기대값/명령/각인120을 바꾸지 않았다. 전용25개/관련5파일95개와 기존 독서/소문 영향5파일101개, 타입·린트·빌드가 통과했다.

브라우저795–798의4개 M창/세계 화면을 모두 확인했다. 실제 대기 키1턴에 같은NPC가 원래 소유 쪽지를 읽고 개인 지식만 얻으며, 실제N창 이야기 버튼1턴 뒤에만 플레이어 지도에 출처/전달1단계와 원래 작성자/작성 시각의 주장이 나타난다. 같은 쪽지UID는NPC에게 남고 지하2층을 실제 생성하지 않는다.4전체 저장 복원과 남은20턴의 전체 상태가 렌더러 연출 큐를 반영한 코어와 일치하고 콘솔 오류0이다. 초기NPC 소유 쪽지는 유효한 초기 소지품이며 과거 전달/독서 턴을 실행했다고 쓰지 않는다. v160 지도 표시와 통합 전체 회귀/월드를 진행한다.

NPC의 전역 문해/연구·지도 제작 직업, 오인 지도/세계 지도, 전체 일반 소문 전달망과 나머지 후속 확장은 남아 있다.


v0.160–161은 M지도 창의 실제 관찰/시각·현재와 다른 층의 시야 분리·숨은 층 탭 차단과NPC의 실제 쪽지 독서/개인 지도 지식·실제 대화 전달을 연결했다. 현재 보이지 않는 피는 지도 색으로 공개하지 않으며, NPC의 독서를 봤다고 비공개 내용을 자동으로 배우지 않는다. 실제 대화는 원래 작성자/시각/주장과 물리 쪽지를 보존하고 출처/전달 단계만 더한다. 각인120·통합 전체164파일3,174개150.32초·타입/린트·화면791–798의8개 장면 전체 확인/7전체 복원/저장 후19·20턴 전체 일치/콘솔0이다. 월드30판296.413703524초의30행 전체가v159와 같다. v160별도 전체 회귀/월드는 실행한 것으로 기록하지 않는다.
