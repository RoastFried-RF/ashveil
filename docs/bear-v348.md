배부른 잿곰은 굴에서7칸 안의 실제 감지한 침입자에게2회의 연속 경고 행동을 한다. 경고는 각각100TU를 쓰고 실제 소리·포효 로그·머리 위 표시·커서 정보를 남긴다. 같은 차례의 중복 요청이나 감지가 끊긴 시간은 경고를 완성하지 않는다. 상대가 영역 밖으로 물러나면 추적을 해제한다. 실제 허기가 심하거나 해빙기 초반에 열량이 부족한 경우, 또는 공격받은 경우에는 경고 없이 추적하며 굴에서12칸의 경계를 지킨다. 실혈30%와 사용할 공격 부위를 모두 잃은 몸은 보통 이동/후퇴를 시도한다.

앞발 후려치기와 물기는 실제 앞발의 `claw`·턱의 `bite` 기능을 따른다. 앞발을 모두 잃으면 물기를 사용하고, 턱도 없으면 가짜 맨손을 만들지 않는다. 앞발 붙들기는 기존 명중/붙잡힘/탈출·기력/재사용 규칙을 사용한다. 실제 해결된 공격 event의 mode를 보존해 각 공격의 원본을 재생하며, 나중의 공격 선택을 보고 이전 타격의 모습을 추측하지 않는다. 몸체별 피격·쓰러짐·수면·기상 시간을 실제 렌더러에 적용하고, 기상 중 피격이 서 있는 자세로 덮이지 않게 했다.

동물 사체의 원래 재고에서 고기 한 단위를 분리해 실제 바닥 UID로 만들고 기존 입 섭취로 먹는다. 이후 해부와 같은 재고를 사용하므로 고기를 재발행하지 않는다. 새 잿곰의 해부 재고는 고기80단위·생가죽6kg·지방15kg·발톱4개·담즙1개다. 가죽은 소금/무두질틀의 기존 작업으로1kg 단위의 잿곰 가죽이 되고, 실제3kg를 재질 선택 코트의 겉감으로 사용하면 단열8을 갖는다. 지방은 실제 한 덩이와 화덕 작업으로 등잔 기름이 된다. 가죽/발톱의 Def 무게와 원재료 질량을 맞췄다. 담즙은 현재 해부/교역 물품이며 새 약물 효과를 구현했다는 뜻은 아니다.
