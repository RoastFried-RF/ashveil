# 모드의16×16 원본 PNG

v0.293 검증 중. `docs/design/11-modding.md` §2·§7·§11의 정적 텍스처를 웹 모드 가져오기와 CLI 배포에 연결한다. 설치된 게임 하네스와 리소스 검사기를 재사용하며 새 엔진·의존 패키지를 추가하지 않는다. Item.sprite와 Ability.icon에 `mod:<manifest.id>/textures/소문자파일.png`를 지정한다. 실제 파일명은 소문자 영문·숫자·밑줄·하이픈과 하위 디렉터리만 허용한다.

PNG는16×16 정적 이미지, 파일당64KiB, 모드 전체8MiB/512파일 제한이다. 경로 이탈·SVG·실행 파일·APNG와 손상된 청크/CRC를 거절한다. 청크 구조 검사는 픽셀 압축 해제 검사가 아니며, 브라우저 설치 검토는 별도로 실제 이미지 디코더를 실행해 실패를 설치 전에 표시한다. 원본 PNG는 UTF-8로 변환하지 않고 정규 base64로 별도 모드 저장소에 기록하며, ZIP/tar.gz에는 원본 바이트를 그대로 넣는다.

이미지 원문도 모드 패키지와 로드 해시에 들어간다. PNG만 바꿔도 기존 각인의 구성 변경 검토를 거친다. DefDatabase에는 선택한 이미지의 불변 사본이 있으며, 설치 후보/다른 탭의 설치/제거가 현재 세계의 그림을 바꾸지 않는다. 승인한 World가 실제 교체될 때 Vue 아이콘과 지도 렌더러를 같은 DB에 맞춰 갱신한다. 맵을 다시 만드는 동안 이전 비동기 렌더러가 뒤늦게 살아나지 않게 정리한다.

`mods/sample-original-textures`는 기본 비활성 예제다. 소금 봉지의 새16×16 CC0 원본을 포함하며 Item.Salt의 sprite만 바꾼다. 수치·수량·음식/거머리 제거 규칙은 그대로다. 원본 PNG/SVG·새 픽셀 좌표·재현/독립 검사기·라이선스는 `tools/art/mod-texture/`에 있다. 원본 이전 Salt 이미지의 복사·크롭·재색칠이 아니다.

첫 관련6파일67개 검사와 확장 후68개 검사가 모두 통과했다. PNG 바이트/독립 Buffer base64, 손상CRC·IHDR·크기·청크·경로, ZIP/tar.gz 동일 패키지 해시, 설치/재시작/제거, 불변 DB/진행 중 세계 보존, 실제 브라우저 디코더 실패 전달과 비트맵 정리, 리소스 검사기를 확인했다. 초기 Native 검사 코드의 잘못된 dx/dy 이동 인자는 타입 검사에서 발견해 기존 Action.dir=2로 고쳤다. 첫 린트의 caught error cause 요구도 원인을 보존하도록 고쳤다.

[골든 전체 상태 대조](golden-v293-diff.json): 다섯 시나리오의 전체 초기/최종/오류/해시는292와 정확히 같다. Save198과 기본 콘텐츠 해시는 변하지 않았으므로 기대 벡터를 갱신하거나 과거 벡터를 다시 보관하지 않았다. 실제 브라우저·전체 회귀 결과는 완료 후 기록한다. 이 기능은 캐릭터/시트 애니메이션·지형 대체·폰트·오디오·실제 Steam 창작마당 전체 지원을 뜻하지 않는다.


실제 Native 첫 실행에서9장·전체198복원2·전체상태6단계·100TU·오류0을 확인했다. 유효CRC/손상IDAT의 ZIP은 실제 브라우저 디코더가 설치 전에 거절했으며, 정상ZIP은 실제파일선택·설치·재시작·미선택을 거쳤다. 이후 유한 초기소금 배낭2+바닥1을 실제동쪽1T/무료줍기로 보존하고, 실제 구성제거 검토/적용으로 기본그림을 복원했다. 제작/전리품 과거이력은 주장하지 않는다. [Native근거](mod-textures-v293-native-audit.json).

Native 동결 뒤에는 Pages 입력경로에 mods/** 하나를 추가했다. 모드 PNG/JSON만 바뀌어도 새 웹 빌드가 필요하기 때문이다. Native와 최종 동결의 게임·배포이미지·검사코드는 같고, 워크플로 파일의 이 한 줄 차이는 별도로 기록한다. 원격Actions292는39536728279/build119014964439에서 계정결제/사용한도로 시작 전 거절됐으며 배포는 skipped였다. 자금/한도/저장소공개설정을 바꾸지 않았다.
