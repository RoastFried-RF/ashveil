# 주민의 개인 침대와 취침 — v0.47

정착지 주민은 자신의 침대로 실제 이동해 자고, 충분히 쉬거나 깨어난 뒤 원래 업무 자리로 걸어 돌아간다. 기본4명은 각자 고정 짚 침대 하나를 받으며 손님용 대여 침대2개와 소유권을 구분한다. 순간이동하거나 피로를 즉시 없애지 않는다. 기존 침구/체온/영양·피로/수면 부채·소리/피격 기상 규칙으로 회복한다.

`NpcRest.Hearth`에 피로70 또는 수면 부채1시간에서 취침, 피로20 이하·부채0에서 기상, 재시도1시간, 거처 주변3칸 내 짚 침대를 정의했다. 문서에 없는 문턱/거리/재시도는 임시 조정값이다. 플레이어의 수면 회복 문턱2는 유지하고 주민 활동에만 별도 기상 문턱을 저장한다. 실제 약물 수면은 이 일과의 문턱으로 조기에 끝내지 않는다.

상인·의사 같은 주민은 보이는 적을 피하고, 자기 먹을 것/물·식사 전 손 씻기를 먼저 처리한다. 의사는 처치 사이 손을 씻고 휴식한 뒤 재보급한다. 경비도 보이는 적이 없을 때 자기 침대를 찾는다. 정상 취침은 몸이 너무 차거나 통증이 극심하면 시작하지 않는다. 진료나 거래를 받는 동안 새 취침을 예약하지 않으며 자는 의사는 기존 규칙으로 진료를 받지 않는다.

먼 침대가 비었는지 미리 읽지 않고 아는 위치로 간다. 곁에서 사라졌거나 점유된 것을 확인하거나 경로를 찾지 못하면 즉시 계속 왕복하지 않고 재시도를 미룬다. 깨어난 뒤 업무 복귀 상태/경로도 저장한다. 주민의 현재 이동·잠든 모습은 기존 시야 규칙으로 관찰한다.

개인 침대는 주민의 거처 가까운 빈 지형에 한 번 설치한다. 기존 생물·물건·건축·물·계단·작업장·침구를 덮어쓰지 않는다. 공간이 없으면 만들지 않으며 죽은 주민을 부활시키지 않는다. 고정 침대는 접거나 다른 설치물로 덮어쓸 수 없다. 플레이어와 다른 주민은 그 자리에서 자발적으로 잠들 수 없으며 손님은 여관 침대를 빌린다. 지형이 사라지면 빈 땅에 소유 제한만 남기지 않는다.

현재는 별도 주택 지형 대신 침대 자리의 지붕 표시를 사용한다. 이는 초기 정착지 자산이며 밤마다 새로 만들지 않는다. 구형 지역은 원래 몸/주민을 유지하며 안전한 자리만 한 번 추가한다. 각인v14는 개인 침대/소속 정착지·기상 문턱·재시도/복귀를 보존하고 v2~13의 몸·물품·수면을 유지한다. 기존5고정 입력의 전체 상태 차이는 버전13→14뿐이고 명령·오류는 유지했다(`golden-v047-diff.json`).

주민 휴식10개와 Def1개를 추가했다. 검증은 실제 이동/수면/귀환, 소유/대여 구분, 안전 배치/중복 방지, 경비/보이는 위협 우선, 원격 점유 조회 배제/실제 막힘 재시도, 이동/수면 중 각인을 포함한다. 전체46파일721개가27.58초에 통과했고 lint·타입/빌드·Def·44파일 JSON Schema 검사도 통과했다. 최종 브라우저87~89/설정은 콘솔 오류0이다. 실제 의사가 침대로 이동해 잠들고 진료를 거절한 뒤, 플레이어도 실제 시간/수분을 쓰면서 기다려5시간 넘게 회복한 의사의 업무 복귀/진료 가능/각인 복원을 확인했다. 88화면도 직접 확인했다. 격리된 장면에서 다른 NPC 행동/습격만 억제했고 의사의 피로를 중간에 바꾸지 않았다. 첫 테스트의 수면 거절 문구와 진료비 미지급 fixture를 고쳐 실제 안내와 소지금을 검사한다. 30시드×최대3일은197.76729305900002초, 평균0.42021412037037037일·생존0/저체온19/치명상5/실혈6이다. v0.46과30시드의 원인·시간·레벨·지도가 같다. 봇은 정착지 주민을 직접 이용하지 않으므로 일과는 별도 검증으로 판단한다.

주민 개인 주택/전체 근무표·공공 배급/우물·주민 소비와 전역 인구 소비의 전체 연결·교사는 남는다. 유한한 개인 음식과 물만으로 장기 생존이 보장된 것으로 세지 않는다.
