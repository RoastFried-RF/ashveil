# 실제 최초 지역 지도 생성 워커 · v0.229 / 각인166

RegionLayoutDef.genWorker가 선택한 단계2 모듈의 MapGenStepWorker.execute를 가리킨다. 원래 코어가 만든 최초 지도 후보를 전달하고, 검증한 지형 변경만 적용한 뒤 원래 주민 배치를 진행한다. 예제는 기존 검은 숲 정비구의 시작점 옆 길 한 칸만 진흙으로 바꾼다. 새 물품·주민을 생성하는 명령은 없다.

입력은 지형 팔레트, 두 자리36진법 지형 행, 지붕 행과 보호 좌표로 압축한다. 최대128×128 지도와 기존64KiB 입출력/상태·격리 실행 예산을 적용한다. 출력은 최대256개의 setTerrain 목록이며 정확한 키/정수 좌표/실제 TerrainDef/지붕 불리언/중복을 검사한다. 시작·출구·링크·주민 등장·원래 배치물·문·부두·물품·용기·설비·불은 보호한다. 수로 변경과 새 계단/장치/비콘은 거절한다. 원래 시작점에서 닿던 보호 좌표의 보행 연결이 끊기면 전체 출력을 거절한다. 일반 지형이 기존 코어에서 만드는 효과와 전리품은 기존 규칙을 따른다.

실패하면 원래 후보를 유지하고 자기 데이터와 난수 변경을 버리며 해당 메서드만 중단한다. 성공한 실제 생성만 자기 JSON데이터와 모드·지역·레이아웃·워커별 난수 스트림을 반영한다. 미리보기는 코어 지도 난수와 UID도 복제하여 전체 세계 상태를 보존한다. 선박 도착의 사전 공간 검사는 목적 지역의 동일한 후보를 미리 보고 실제 생성은 입장 때 한 번만 수행한다. 캐시된 지역과 구형 저장 지도를 다시 생성하지 않는다. 각인165는 버전만166으로 옮긴다.
