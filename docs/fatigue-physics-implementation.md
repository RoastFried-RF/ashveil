# 휴식과 부채에 따른 몸의 피로 단계

v0.126. 각인90. design/03 §6·01 §5/§8·02 §3의 휴식R=100−fatigue 경계를 의식·다턴 행동·각성·깊은 잠·비틀거림에 통일했다. 정상R≥60/피곤30≤R<60/지침10≤R<30/탈진R<10이다. 수면 부채>0은 탈진을 우선한다.

새Fatigue.Survival Def에서 경계/이름과 각 대역의 행동 배율1/1.05/1.15/1.3, 의식 벌점0/.03/.08/.15, 각성 보정0/0/1/3, 깊은 잠 연장0/0/15/30분, 비틀거림0/0/0/5%를 읽는다. 같은 턴에 경계를 넘나들어도 의식 캐시가 즉시 바뀐다. 플레이어와 주민은 같은 물리이고, 기계는 기존 가동/과열 규칙을 우선한다. 봇/주민이 스스로 잠을 선택하는 목표치는 별도 정책이다.

실제 수면 시작 때만 시작 피로/부채를 기록한다. 구형 미완료 수면의 누락된 시작 부채는 현재 관찰 부채를 계산의 대체값으로 사용하고 과거 시작 기록을 채우지 않는다. 각인89→90은 버전만 이행한다. 단계 조회는 시간/UID/난수/기억을 바꾸지 않는다. 일지는 현재 휴식·배율·의식/각성·깊은 잠·비틀거림 보정을 표시한다.

전용40개/관련7파일145개, 타입·린트·Def153패치/Fatigue1종/Schema105파일·빌드를 확인했다. 새Item은 없다. 5골든은 버전90 외 전체 초기/최종 상태와 오류가 같다. 기존 수면 검사 하나는 플레이어 초기 피로60의 새 정당한 피로 경고가 섞였으므로, 보이지 않는NPC 정보 유출이라는 검사 목적에 맞춰 해당 초기 플레이어만 피로20으로 설정했다.

실제 초기 상처67에 실제 붕대68을 사용한 정상6/피곤7/지침7/탈진8/낮은 피로+실제 부채8턴을 확인했다. 피곤/지침은 서로 다른 배율이지만 이 작업의 올림 결과는7턴으로 같다. 시작0TU 후 마지막 작업 턴에만 원래 붕대가 소비되고 같은 상처에 품질26의 붕대를 남긴다. 미완료 시 원래 붕대가 남아 있으며 실제7턴TU 재개 뒤 브라우저와 헤드리스 전체 상태가 렌더 연출 큐 소비를 기록한 후 같다. 화면582~587 여섯 장 전체 확인·6전체 각인 복원/콘솔 오류0이다.

v0.126에서는 휴식/부채에 따른 의식·다턴 시간·각성·깊은 잠·비틀거림의 물리와 캐시/실제 수면 시작 기록·현재 단계 표시를 정본에 통일했다. 각인v90·전용40/관련145개·전체128파일2,377개117.41초·타입/린트/Def153패치/Schema105/빌드·실제 붕대6/7/7/8/8턴과 미완료7턴 재개·화면582~587 여섯 장 전체 확인/6전체 복원/콘솔0이다. 월드30판264.275629217초·13행 동일/17행 물리 연쇄 변경·3생존 시각 변화가 있고, 피로 물리만 이전으로 되돌린30판 전체가 이전과 같아 원인을 확인했다.
