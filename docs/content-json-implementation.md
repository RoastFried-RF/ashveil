# 원문 콘텐츠 JSON 파싱과 파일 오류 격리

v0.244 작업 중. 각인177/API1.4.0 유지. 브라우저 Vite와 Node 콘텐츠 로더 모두 JSON을 원문으로 읽고 같은 엔진 독립 검사기를 거친다. 중복 객체 키가 덮어써지기 전에 거절하고, Unicode 이스케이프 표기가 달라도 같은 키로 판단한다. BOM·잘못된 JSON 문법·제어/이스케이프·유한 범위를 넘은 숫자·512단계 초과 중첩은 실제 파일/줄/열 오류로 보고한다. 문자열 안의 BOM·일반 Unicode와 음수0 등 정상 JSON 값은 보존한다. 줄/열은 원문의 문자 위치이며 JSON 배열 항목과 다르다.

파일 전체를 원자적으로 검사하므로 앞의 유효 Def도 실패 파일에서 부분 추가하지 않는다. Def/패치 원문은 객체 배열이어야 하며 잘못된 manifest는 폴더 이름의 기본 패키지와 파일 오류로 남긴다. 다른 유효 파일의 읽기는 계속한다. 파일 오류는 ModPackage 바깥 WeakMap에 저장하며 실제 켠 모드만 loadReport에 포함한다. 꺼진 모드의 오류는 코어 게임 시작을 막지 않는다. 활성 코어/모드 오류는 타이틀/Def 조회·validate CLI의 기존 오류 경로로 전달된다.

스크립트 원문은 JSON으로 파싱하거나 이 단계에서 실행하지 않는다. 이미 파싱된 객체를 받는 프로그램/테스트 API는 유지하지만 원문에서 이미 사라진 중복 키를 복원해 검사한다고 주장하지 않는다. 유효 콘텐츠의 패키지 직렬화·소스 파일 항목·스크립트 해시·DB/전체 게임·저장을 바꾸지 않는다. 각인 파일의 파싱/형식에는 이 검사를 소급하지 않는다.

Def 조회의 ‘JSON 원문 문법 검사’는 붙여 넣은 원문과 표시 파일 이름을 사용해 같은 문법 오류를 보여 준다. 수정하면 이전 결과를 지우며, 정상 결과는 읽기 전용으로 표시한다. 파일/Def/선택 모드/게임에 적용하지 않는다. 스키마/참조 검증이라고 표시하지 않는다. Tab 이동에 textarea도 포함한다.

전용43개(유효 임의 JSON250개를 표준 파서와 대조 포함)·실제 임시 파일/CLI4개가 첫 시도 통과했다. 기존 Def/조회/출처/패치 검사5파일187개와 최종 관련8파일121개도 통과했다. 정상 전체 파일/패키지 직렬화와 실제 전체 월드 초기 상태를 기존 읽기와 대조했다. 기존 골든5개의 전체 초기·최종·오류·해시는 저장177까지243과 완전히 같고 벡터·해시를 갱신하지 않았다.

최종 정적 검사·실제 브라우저·전체 회귀는 준비 중이다. 부분/완전 스키마 통합·불변 콘텐츠 동결/일반 로드 해시·나머지 전체 확장은 계속 남는다.

실제 최종246 빌드의1225–1227 세 장 전체 확인/전체177복원1·실제 중복3:3/BOM·정상 구문/게임·스크립트 전체 동일/콘솔0을 통과했다. 통합 전체·월드 회귀 검증은 실행 중이다.244/245 단독 전체·월드 실행은 주장하지 않는다.
