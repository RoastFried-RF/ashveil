# 모드에서 사라진 층 생물 제거 — v0.266 작업 중

설계11 §8의 생물 제거를 명시적인 각인 모드 구성 검토/승인에 연결했다. 실제 이전 정의 목록의 Creature가 현재 DB에 없고 기록된 구성이 다를 때만 적용한다. 현재/정지/방문한 다른 지역의 층 개체 배열에서 해당 기록과 소지품을 제거하고 방의 미래 배치 참조·해당 개체를 향한 AI 대상/경로를 정리한다. 플레이어는 제거하지 않으며 동료/구금/운송/기생 관계와 진행 중 작업/계약/불투명 스크립트의 현재 참조는 원본을 바꾸기 전에 차단한다. 현재 공포 등 지원하지 않는 Def 참조도 별도 복원이 필요하다. 모든 종류의 NPC 관계를 자동 종료하는 기능은 아니다.

killCreature/사망·상처·전리품·경험치·보상 함수는 호출하지 않는다. 공급원 인원/원래 명단/재생 시계와 나머지 실제 개체·몸/물품/UID/시각/난수·과거 개인/상처 원인은 보존한다. 없는 종 또는 생존 전제의 공급원은 조회/배치/재생/인원 정산을 멈추며 다른 생물로 바꾸거나 사람을 채우지 않는다. 원래 정의를 다시 설치하면 현재 규칙에 따른 공급원 처리가 재개되지만 이미 제거한 개체/소지품을 복원하거나 과거 출생으로 만들지 않는다. 실제 제거가 있을 때 한 개의 콘텐츠 변경 로그를 남기고, 기존 승인 흐름이 현재 구성/이력·업적 비활성 상태를 저장한다. 새 저장 형식/Def/Item은 추가하지 않았다.

시험은 실제 이전 모드의 Creature.BurrowRat 자식을 먼저 로드한 정상 새 게임에서 실제 생성자로 한 초기 개체를 선언해 배치한다. 과거 전투/출생/사망/경과 턴을 꾸미지 않는다. 공급원 시험의 배치 명단은 실제 한 개체/인원1과 같으며, 미배치 재점거 시험은 별도의 유한 예비 인원7과 실제 generateDungeon 결과를 사용한다.
