## 제작·현장·정비

F2의 긴 패널을 제작법/현장·야영/수리·분해로 나눴다. 제작법 검색은 이름·완성품·재료·작업장을 찾는다. 배운 제작법/현재 제작 가능/찜 필터와 이번 창의 찜 기능을 제공하고, 재료의 선행 제작법으로 이동할 수 있다. 찜은 제작 규칙·해금·물품·시간을 바꾸지 않는다. 기존 현장 행동은 현장·야영 탭에 그대로 남는다. 현재 작업 진행·재개·취소는 같은 코어 행동을 쓴다.

재배 패널은 작물 원화·성장 막대·현재 물량·햇빛·온도를 먼저 표시한다. 상세 조건·증발/수분 이동·배지 설명은 펼쳐 읽고, 같은 실물 물병/목재·실제 수확 행동을 사용한다.

## 원정 수첩·계약·소지품

수첩은 현재 실제 출혈/체온/갈증/허기/눈에 보이는 적과 지닌 물·음식·광원·능력 포인트를 바탕으로 다음에 확인할 창을 안내한다. 처음10턴 이내에는 펼쳐 시작한다. 준비 표시는 현재 상태이며 과거 행동 완료·업적을 만들어 내지 않는다. 클릭은 해당 창만 열며 시간/행동을 대신 진행하지 않는다.

계약 탭에 진행 중/마친 계약/전체·이름/의뢰인 검색을 추가했다. 기한순 정렬과 계약 하나의 수첩 고정을 제공한다. 고정·찜·창의 메모는 화면 세션의 편의 상태이며 각인 복원으로 이어지는 세계 기록이 아니다. 계약의 실제 수락·원본·예치·보고 조건은 유지한다. 사건 성향 패널은 사건 탭에서 연다.

소지품은 이름 검색·분야 선택으로 맞는 물건을 강조한다. 격자에서 나머지를 지우거나 위치·드롭 대상을 바꾸지 않아 가려진 물품 위에 잘못 놓지 않는다. 미확인 물품은 기존 표시 이름으로만 검색한다. 열린 전리품의 검색도 실제 열린 항목을 대상으로 한다.
