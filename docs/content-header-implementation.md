# 실제 각인의 콘텐츠 구성 기록과 불일치 중단

v0.247 작업 중. 각인178/API1.4.0. 실제 새 게임은 db.loadHash를 저장한다. 같은 실제 구성을 읽으면 정상 이어가고, 기록과 현재 내용이 다르면 스크립트 등록/게임 초기화/세계 진입 전에 중단해 기존 세계·화면·원본 각인을 보존한다. 아직 다른 구성으로 계속하는 승인/차이 검토·제거 복구 흐름은 별도 후속이다. 자동으로 다른 구성을 승인하거나 저장을 덮어쓰지 않는다.

구형177은 버전178만 올리고 기록되지 않은 과거 해시를 추정하지 않는다. 기록 없음은 unknown으로 기존 방식의 로드를 허용한다. 유효한 기록이 있으면 그대로 보존하며, 존재하지만 형식이 잘못된 해시는 구형으로 취급하지 않고 오류를 보고한다. 실제 스크립트 구성 검사는 기존 규칙을 유지한다. 해당 기존 검사 준비는 명시된 raw177/해시 없음 조건으로 바꾸어 원래 스크립트 불일치 검사를 계속 실행한다.

설정의 ‘각인 콘텐츠 구성’은 실제 각인 기록/현재 해시와 같음 또는 구형 기록 없음을 구분해 표시한다. 조회는 턴·난수·몸·물품·역사를 바꾸지 않는다. 호환성 판정 함수도 전체 상태를 수정하지 않는다. 이미 기록한 구성은 실제 행동/미완료 행동 재개·저장 후 복원에서 보존한다.

전용13개와 실제 저장 시작 보호3개·기존6개가 통과했다. 골든10개를 더한4파일32개와 저장 어댑터 검사를 별도로 통과했다. 초기 명령의 존재하지 않는 imprint.test.ts는 실행 검사로 세지 않으며 실제 imprint-storage.test.ts를 따로 실행했다. 기존5개 전체 골든 초기·최종·오류는177→178과 실제 새 게임의 loadHash 헤더 외 모두 같음을 감사했다. 원래246 벡터를 한 번 보관하고 기대 초기/최종 해시 두 필드만 갱신했다. 고정 입력/오류/명령을 바꾸지 않았다.

브라우저 장면은 실제 새 게임의 헤더와 전체178복원, 실제 원본 구성에 석판 label 패치 한 개를 넣고 실제 newGame으로 생성한 다른 해시의 초기 각인, 로드 전 선언한 raw177/해시 없음 조건을 사용한다. 과거 게임을 실행했다고 주장하지 않으며 원래 몸·NPC·물품을 변경하지 않는다. 다른 해시는 제목 화면에서 원문 각인을 보존하고 진입을 중단해야 한다. 구형은 버전만 올린 전체 상태와 동일해야 한다. 최종 UI/정적 검사·통합 회귀는 준비 중이다.

명시적인 다른 구성 검토/계속·제거된 Def 복원/플레이스홀더·일반 모드 버전 목록/defSchemaVersion 헤더와 나머지 전체 확장은 계속 남는다.

247의 실제1234–1236 세 장을 모두 확인했고 전체178복원2회/다른 실제 구성의 진입 중단과 원문 보존/구형177의 버전만 이동·원래 인물 보존/콘솔0을 통과했다. 248의 명시 검토는 별도 구현이며 통합 회귀는 최종248에서 진행한다.247단독 전체·월드 실행은 주장하지 않는다.
