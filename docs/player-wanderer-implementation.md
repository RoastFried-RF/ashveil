# 플레이어 원본과 거래 우선 화면 — v0.295 통합 완료

이 버전은 표시와 창 배치만 바꾼다. 각인199, 기존884정의/206물품/88제작법/329패치와 콘텐츠 로드 해시를 유지한다. 코어290파일·콘텐츠271파일·모드86파일이 동결294와 바이트 단위로 같고, 대표 재생5개의 전체 초기/최종 상태·오류·해시도 모두 같다. 골든 기대값 갱신이나 과거 파일 보관, 추가 월드30판 재실행은 하지 않는다. 월드의 최신 실측은294다.

## 플레이어 표시

새 CC0-1.0 원본은 걷기12·공격16포즈다. 기존 시트와 NPC의 픽셀은 보존한다. 새72×128/128×160 시트, 24×32/32×40 셀, 발 앵커31/39, 표시 배율1과 머리 높이30은 기존 표시 계약에 맞춘다. 원본 제작과 재현은 [제작 기록](art-player-wanderer-original.md)에 있다.

`creatureSprite`는 Def가 명시한 한 단계 별칭을 먼저 읽는다. 별칭이 없으면 실제 `playerId` 개체의 저장된 선택이 `hero`일 때에만 새 `original_wanderer_hero`를 반환한다. 다른 외형을 직접 선택한 플레이어·기존 NPC·은퇴한 떠돌이를 전역 교체하지 않는다. 저장된 `Creature.sprite`, 몸, 장비, 난수와 UID는 조회로 바뀌지 않는다. 모드가 명시한 자기대응 `hero:hero`도 우선한다.

HUD와 생성 화면은 기존 초상 아래의 대체 도트를 새 idle0으로 읽고, 캐릭터 창의 항상 표시되는 도트 미니어처도 새 idle0을 읽는다. 이미지 실패를 인위적으로 일으켜 확인했다고 주장하지 않는다. 정식 장비별 겹침 그림·성별/피부 선택·상처 표현은 이 고정 원본 범위에 포함하지 않는다.

## 거래 우선 배치

주민의 기존 증거·소문·지도·관계·위생·진료·의뢰 패널을 상인 물품/판매 목록과 거래 합계 뒤로 옮긴다. 같은 컴포넌트·인물·조건·행동을 유지한다. 대화 버튼 옆에서 도움·의뢰로 이동할 수 있고, 해당 제목에서 거래로 돌아올 수 있다. 두 버튼은 창 안에서 스크롤만 이동하며 세계 행동/턴을 호출하지 않는다. 작은 화면에서 모든 서비스와 거래 목록 전체가 한 화면에 들어간다는 뜻은 아니다.
