# v0.316 개발 미리보기 — 이동·광원 동기화와 인물

사용자가 보고한 먼 거리/대각선 이동의 순간 이동과 뒤따라오는 광원, 부족한 인물 디테일을 조사했다. Core·콘텐츠·모드는315 불변본과 파일별 SHA-256이 같으며 저장207을 유지한다. 실제 이동 비용·시야/시선·아이템·난수 규칙은 바꾸지 않는다.

## 이동 경로와 자동 이동

기존 자동 이동은95ms마다 다음 행동을 실행하지만 화면 보간은150ms였다. 매 행동마다 현재 화면 위치에서 보간을 다시 시작하고, 화면과 목적지의 맨해튼 거리가2.5를 넘으면 즉시 목적지로 붙였다. 느린 연출·대각선의 누적 지연이 이 조건을 넘길 수 있었다.

새 walk-motion은 실제 인접 칸과 move FX의 순서를 보존한다. 여러 행동이 한 번에 관찰돼도 중간 꺾임을 생략하지 않으며, 보간 중인 위치의 거리로 정상 대각 이동을 순간 이동으로 처리하지 않는다. 숨은 개체가 다시 나타나거나 지도/실제 위치가 불연속이면 현재 관찰 위치에서 표시를 시작한다. 밀린 수동 입력은 경로를 보존하면서 따라잡고, 한 프레임의 전진량을 제한한다.

자동 이동은 플레이어의 현재 화면 걸음과 비동기 시뮬레이션이 끝난 뒤 다음 행동을 실행한다. 키를 길게 누른 반복 이동도 현재 걸음을 기다린다. 개별 새 입력은 순서를 유지한다. 문 열기만 수행한 행동에서 아직 건너지 않은 경로 칸을 소모하지 않는다. 위협 중단과 실제 행동 비용은 기존 경로를 사용한다. 연출0은 인접 칸마다 즉시 표시하는 접근성 설정을 유지한다.

캐릭터의 보간 뒤에 카메라를 다시 지수 보간하던 지연을 없앴다. 카메라는 같은 발 위치를 따라가며 기존 지도 경계/하단 HUD 여백과 화면 흔들림 설정을 유지한다. 보행 프레임은 걸음 진행도에 연결해 칸마다 사이클을 처음으로 돌리지 않는다.

## 고정 광원과 휴대 광원

고정 조명·환경 조도는 행동 동기화 때 샘플링하고, 실제 살아 있는 개체가 지닌 광원은 매 프레임 캐릭터와 같은 표시 좌표에서 계산한다. 공격/피격의 작은 몸 이동도 같은 좌표를 쓴다. 바닥의 불/봉화/기계 조명은 지도 좌표에 남는다. 캔버스/텍스처를 매 프레임 파괴하지 않고 재사용한다.

그림자와 따뜻한 빛은 현재 공개 시야 안에만 적용한다. 이동 중의 시선 마스크는 실제 논리 위치와 구간 양 끝의 정수 칸 LOS를 모두 요구하며, 미관찰 개체의 이동 경로를 표시하지 않는다. 실제 Core FOV·빛 반경·벽의 차폐·적의 인지 판정은 변경하지 않는다. 경계의 빛은 보수적으로 처리하므로 모든 벽 모서리의 시각 점검은 후속 통합 검증에 남는다.

## 19종의 새 인물과 실제 장비

플레이어·옛 떠돌이·주민4종·약탈자4종·그늘 사람5종·쇠약자2종·감염자2종의 독립 SVG 원화를 작성했다. 걷기48×64를.5배로 표시해 기존24×32 월드 크기와 발 위치를 지킨다. 얼굴의 눈썹/눈/코/볼/턱, 천의 주름·봉제선·가죽 끈·금속 재질, 직업별 옷과 비대칭 소품을 보강했다. 방향별 걷기6/정지2/공격4프레임,38PNG·912새 프레임·21등록(별칭2포함)이다. 비인간형7등록과 이전 프레임/출처를 보존한다.

새 몸에는 고정 무기를 그리지 않는다. 현재 보이는 식별된 인물의 실제 main/off 물품을 같은 몸에 표시한다. 장착 해제/반착용/부재 물품·숨은 인물·시체에는 표시하지 않으며 실제 세계의 장비를 추가하지 않는다. 인물 창과 타이틀의 도트 미리보기도 새 원본을 사용한다. 기존 별도 회화 초상화는 이번 원화 범위에 포함되지 않는다.

## 이번 묶음의 확인

타입·대상 린트·Def 로드·스프라이트 파일·빌드를 확인했다. 스프라이트 등록은122시트/2,218프레임/28캐릭터/148고유PNG가 유효하다. 저장 필드·정의·스키마를 바꾸지 않아 Schema 재생성이나 새 골든 갱신을 하지 않았다.

`tools/inspect-movement-v316.ts`는 별도 유한 초기 방(실제 생성 몸/칼/횃불·정지된 외부 세계·기억된 바닥·고정 지도 광원)을 실제 타이틀의 이어하기로 불러오고 실제 마우스로7칸 경로를 이동했다. 로드 뒤 세계/시각/난수·좌표를 주입하지 않는다. 읽기 전용 `?debug` 플레이어 표현 관찰로 두 화면 크기1440×1080/1366×768에서 연출1/.5/2/0을 확인했다. 연출이 있는 세 실행의 최대 프레임 전진은.32/.16/.64칸, 휴대 광원과 발 위치 차이0, 자동 이동 대기열0, 목적지 도착과 고정 광원 제자리, 콘솔 오류0이었다. 연출0은 인접1칸씩 즉시 진행했다. 소프트웨어 Chromium 결과이며 GPU 성능 보장은 아니다.

최종9PNG를 생성했고 그 중 작은 지도 도착과 인물 창2장을 직접 열었다. 앞선 동일 묶음의 큰 지도 시작1장과 contact도 열었다. 전체 회귀·World30/1000·새 전체 저장/골든·자연 플레이/공개 브라우저·모든 문/다중 경로/숨김 조합은 아직 실행하지 않았다.313–315의 통합 검증 대기도 유지한다. 기능 구현 우선 지시에 따른 개발 미리보기이며 v1.0.0 출시 완료가 아니다.
