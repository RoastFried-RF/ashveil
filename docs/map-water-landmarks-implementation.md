# 직접 본 지상 물 지형/시설의 당시 지도

v0.171 작업은 지상에서 실제 관찰한 물 지형/시설의 당시 위치도 원래 종이/잉크의 지도에 남긴다. 지하 문서는 정본의 방/계단 범위를 유지한다. 플레이어는 자기 `observed`의 과거 지형/시각만 사용하며, NPC는 실제 자기 차례에 서서 관찰한 물 칸만 개인 기록에 남긴다. NPC가 플레이어의 물 관찰을 복사하거나 원격 물 지형을 조사하지 않는다. 같은 장소/지형의 기억 시각을 조회마다 갱신하지 않는다.

물 기록만 실제로 보았어도 지상 지도 초안을 작성할 수 있다. 기존60턴·몸/문해/빛·원래 종이UID/잉크1회분·누락/오차·중단/재개 규칙을 사용한다. 이전 관찰 뒤 실제 지형이 바뀌어도 현재 숨은 지형으로 초안을 고치지 않는다. 미래/잘못된 시각의 플레이어 관찰이나NPC 방/계단/물 기억은 직접 작성의 근거에서 제외하며 원래 기억을 수정하지 않는다.

M창은 문서의 물 지형/시설 이름·당시 출처/작성 시각·미확인/직접 본 기록과 일치 또는 다름을 표시한다. 같은 자리의 다른 시설 이름은 충돌로 남는다. 비교에는 플레이어의 실제 과거 관찰만 사용한다. 현재 숨은 수질·물량·마실 수 있는지를 확인하지 않으며 직접 확인해야 한다고 표시한다. 자기 작성자는 내용을 이미 알고, 다른 사람에게서 원본을 얻은 경우는 기존 독서 경로로 배우게 된다.

물 기록도 실제 작성 문서의 특징 수/원본 가격·정찰 납품 조건에 포함한다. 원래 저자/각인/의뢰 후 직접 관찰/원본 검증 조건은 유지한다. 각인125→126은 버전만 이관하며 옛 문서/개인 기억/지도 관찰에 물 표식을 소급하지 않는다.
