# 산업 화기·실제 탄창·탄피 재장전

v0.281의 실제 화면/전체/월드 통합 검증을 완료했다. 별도282 이후 작업은 이 결과에 포함하지 않는다.

정본07 §10의 권총14/30·6발·한 발당2턴, 소총24/50·5발 클립3턴을 적용한다. 공장 실탄 기본 불발2%, 재생8%, 젖음×2+floor(오염/10), 무연 오염+1/흑색+4, 걸림·청소·기름/해소 시간은 기존 단발 화기와 같은 정본이다.

13 전체를 읽고6물품 칸을 먼저 등록했다. 새 총은 비어 있고 탄창에는 실제 개별 ItemInst를 순서대로 옮긴다. 한 발 완료/클립 완료에서 원래 UID의 재료만 사용한다. 권총은 완료한 탄만 남고 소총은 선택한 최대5개가 함께 유효해야 한다. 소총의 부분 클립 허용, 공통 호환 탄종, 장전/정비 두 손 필요와 한손 권총 오른손 사격은 구현 기본값이다. 선택한 재생탄이 없다고 공장탄을 자동 쓰지 않는다.

발사/불발로 쓴 실탄은 같은 UID의 빈 탄피로 사수 발밑에 남긴다. 불발의 잃은 탄두·화약과 회수 탄피, 걸림의 원래 탄 보존은 구현 기본값이며 원래 납탄이나 완성 실탄을 새로 만들지 않는다. 공장 실탄은 무연, 이번 실제 재생법은 흑색화약을 쓰므로 오염+4다. 두 실탄 모두43표의 한 발 가치 기본값이며 구경을 추정하지 않는다.

장인 작업장+쇠집게·빈 탄피1/납탄1/흑색화약1회분/뇌관1을 쓰는60기본 작업턴 재장전은 콘텐츠 기본값이다. 원래 한 개 탄피 UID·품질/오염을 보존하고 실제 화약 젖음을 완성탄에 넘긴다. 원래 탄피 더미가 남으면 정상 분할처럼 별도 UID를 쓰며 더미와 중복하지 않는다. 새 무연 화약을 제조했다고 처리하지 않는다. 새 유한 경비대 시장 기본 재고는 권총1/소총1/공장10/재생6/뇌관6이며 일일 생산·소비0이다. 과거 각인은 채우지 않는다.

각인189는188의 버전만 옮긴다. 탄창 실물은 직접 공급에서 제외하되 전체 저장·UID/중첩 검사·가치·정의 제거 검토·환경 정산에 포함한다. 실제 젖음/정산 시각이 다른 탄은 병합하지 않는다. 원본 아이콘6종의 제작 기록과 재현 도구는 [아트 기록](art-industrial-items-original.md)에 있다.

산업 화약/뇌관 제조, 실제 납 주조와 화약 인화·폭발·연기 등 나머지 전체 확장은 계속 구현한다. 이 묶음의 추가만으로 모든 후속 구현을 완료 표시하지 않는다.
