# v0.315 개발 미리보기 — 밭 정리·원래 바닥·잔재

사용자의 구현 우선/회귀 테스트 후순위 지시에 따른 세 번째 기능 묶음이다. 저장207을 추가했다.206→207은 헤더만 옮기며 예전 밭의 심기 전 지형이나 과거 잔재를 추정하지 않는다.313–314의 실제 UI/회귀 검증 대기도 유지한다.

## 새로 심을 때 원래 바닥을 기록

실제 place 행동에서 파종 직전의 지형ID와 현재 턴을 선택적인 CultivationState.origin에 보관한다. 원래 물품UID/주인/물/오염/성장을 유지한다. 원래 바닥은 실제 통행 가능한 흙(배양목은 허용한 바닥)이면서 물/시설/계단/다른 채집물이 아니어야 한다. 추후 기본 지형이 사라지거나 물리 조건이 바뀌었으면 다른 바닥으로 추정 복원하지 않는다. 직접 helper로 만든 유한 초기 장면이나 과거 저장에 origin이 없으면 정리 기능을 허용하지 않는다.

새 파종에만 적용하며, 기존 타이머 밭과 원래 바닥 기록 없는 물리 밭의 수확·성장을 유지한다. 원래 지형의 variant/지붕/물건·피·방과 다른 타일 필드는 정리 과정에서 덮어쓰지 않는다.

## 자기 밭의 실제 정리

uprootCrop은 깨어 있는 같은 지도 본인·실제 시야/시선/대각 접근·손과 의식·곁의 유효한 원래 작물·소유자와 원래 바닥을 확인한다. 다른 사람이 심은 밭은 정리하지 않는다. 선택한 종자UID를 다시 대조한다. 작업은 WorldGen.cropUprootTurns12에 같은 신체·피로·빛의 channelTurns 배율을 적용한다. 원래 즉시 작업 규약대로 정리 결과를 적용하고 그만큼TU를 진행하며, 별도 중단 가능한 다턴 활동은 아니다.

정리하면 작물과 수확 대기를 없애고 기록한 원래 지형을 드러낸다. 종자·음식·목재·배지나 남은 관수는 환급하지 않는다. 정리 함수는 원래 몸/가방/물병/통화·물건/인원/다른 지형을 직접 지우거나 지급하지 않는다. 비용TU 동안의 대사·날씨·AI와 난수는 정상 진행한다. 숙성한 작물도 버릴 수 있어 UI에서 미수확 여부와 포기할 물량을 확인하고 두 번 선택한다. 행동이 진행되면 오래된 확인 선택을 닫는다.

## 버린 작물의 오염은 다음 작물로

미수확 작물에 이미 옮은 관수/배양 재료의 오염 몫이 있으면, 그 ml·병원체×ml·재량을 같은 원래 바닥의 cropResidue.dose로 옮긴다. 원래 작물 상태를 삭제하며 같은 오염을 양쪽에 중복 기록하지 않는다. 이 ml는 모든 관수물의 잔량이 아니라 기존 오염 노출의 운반량이다. 남은 성장용 물은 되돌려 받지 않는다.

새 파종은 같은 실제 바닥에 남은 잔재와 종자 자체 오염을 합산해 한 번 인계하고 기존 잔재를 지운다. 넘치는/잘못된 수치와 바닥 불일치는 종자 소비 전에 실패한다. 심었다 뽑는 반복으로 오염을 씻거나 종자/작물을 복제하지 않는다. 실제 수확으로 오염을 수확물에 이미 옮겼으면 기존 reset 규칙대로 그 몫은 남기지 않는다.

활성/지상 이탈 정산과 일반 주민·동료 파종은 기존 같은 helper/상태를 재사용한다. 토양 확산의 실제 물량·증발/비·다른 밭의 기존 오염 규칙은 바꾸지 않는다. 일반 관수의 토양 흡착/전역 오염·염분 잔류·빗물에 의한 잔재 세척/분해·폐기물의 운반 품목은 이 기능에 포함되지 않는다. 무기한 잔재는 같은 위치에서 다음 파종으로 인계하는 현재 기본값이다.

## UI·직접 그린 바닥 잔재

F2 → 현장·야영 → 작물의 ‘밭 정리·다른 작물로 바꾸기’에서 원래 바닥/노동 시간/수확/물 포기를 검토한다. 기록이 없거나 타인의 밭이면 이유를 표시한다. 맵 커서에는 직접 보이는 잔재를 안내하고, 시야 밖/기억 지형에는 새 cropResidue를 제거한 표시 타일만 전달한다.

직접 작성한64px SVG/PNG1프레임을 잔재에16px 높이로 표시한다. 생성 원본·CC0·SHA/검토 상태는 tools/art/direction-v315에 있다. 제작 PNG를 직접 열었으며 실제 게임 조명/배율/숨김/독립 재생성은 대기한다. 원래313 성장 아틀라스와 출처는 수정하지 않았다.

## 확인 상태

타입·대상 린트·Def/생성 Schema/스프라이트 파일·게시용 빌드를 먼저 확인한다. 원래 바닥 전체 보존·환급/복제 방지·가득 찬 배낭/같은 UID·오염 전량 인계·잘못된 상태의 원자적 실패·207/206 전체 복원·실제 두 화면 크기/정리 취소·원화 숨김·전체 회귀/골든/월드는 아직 실행하지 않았다. 새로운 필드를 포함하므로 다음 통합 검증에서 전체 저장과 기존 Native 초기 장면/기대 버전을 함께 점검해야 한다. v1.0.0과 전체 생태/장기 농업의 완료 주장은 아니다.
