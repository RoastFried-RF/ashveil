# 원정 계산 최적화와 자연 탐험 관찰 — v0.309

v0.308의 자연 수도원 원정 `sim-0`을 프로파일링했다. 수정치 generator·나이 구간의 filter/sort, 영양 구간의 filter, 동상 사전 전체 열거와 의수족 없는 몸의 조상 탐색이 반복됐다. 엔진 이전으로 해결할 문제가 아니므로 순수 TypeScript 코어를 유지한다.

수정치의 원천 순서(나이/감각 저하→특성→종→배경→조건에 맞는 패시브→장비)와 부동소수점 연산 순서를 보존한 직접 누산으로 바꿨다. 중복 나이 경계는 기존 안정 정렬과 같이 첫 항목을 선택한다. 영양 구간은 원래 배열의 마지막 일치를 찾으며 재정렬하지 않는다. 의수족이 없으면 부위 탐색을 생략하고, 동상은 불변 BodyDef의 손가락 ID만 재사용한다. 실제 동상 등급은 매번 원래 몸에서 읽는다. 기존 신체 상태 지문의 유효성 검사는 축약하거나 턴 단위로 캐시하지 않는다.

짧은 프로파일 비교는 동일223결정/0.1일에서 초기·최종 전체 serialize SHA256과 나머지 관찰 행이 정확히 같다. 15.480397401초→10.389057195초는 단일 프로파일 진단이며 일반적인 프레임 성능이나 다중 표본 평균으로 주장하지 않는다. 별도 무프로파일3일 원정은 같은1,749결정·거절0·최대1층·레벨1·시간 종료이며, 초기/최종 SHA256과 전체 관찰 행(벽시계 제외)이 같다. 기존189.071581838초→115.93041944초(이 한 표본에서38.684% 감소)다. 최초0.1일 프로파일은 산출물 경로 오류로 실패했으며 통과 수에 넣지 않는다.

원정 보고 도구 `pnpm sim:expedition <새 출력 경로> [판 수=1000] [최대 일수=3] [시드 시작=0]`는 먼저 `game:freeze`로 고정한 소스에서 실행한다. 입력 전후에 불변 명세의 모든 원본 바이트를 확인하고, 기본4개 이하 프로세스가 실제 newGame/botDecide/playerAct로 `sim-N`을 진행한다. 몸·시각·난수 주입이나 초기 fixture는 없다. 매 결정 뒤 방문 맵/최초 시각·최대 도달 층/레벨·거절과 실제 대기 대체를 기록한다. 각 완료 행은 NDJSON에 즉시 보존하며 작업자 실패는 다른 작업자를 종료하고 성공 집계를 만들지 않는다.

집계는 누락/중복·종료 TU·방문 층·거절 횟수·해시 형식을 검사한다. 지상으로 돌아온 마지막 위치와 최대 도달 층을 구분한다. 사망 원인의 전체 원정 비율과 사망자 중 비율을 별도 제공하며 GDD의 ‘전체40% 초과’를 표시한다. 시간 제한 생존·탈출·은퇴를 사망으로 세지 않는다. 최대3일은 명시적인 측정 지평이며 GDD가 지정하지 않은 제한을 숨기지 않는다. 사람 플레이/외부 평가, 월드30판과 별도 기준이다.

예비 측정·경계 검사와 최종 Full·월드30·브라우저 검사를 완료했다. 1,000판은 아직 완료하지 않았다. v1.0 출시 게이트 완료로 기록하지 않는다. 원문은 `test-results/expedition-v309-*`, `perf-v309-*`에 실패와 함께 보존한다.

## 최종 통합 검증

전체344파일 6,201개를 한 번의 전체 실행으로 통과했다(810.121초, 작업자2). 두 화면 크기 실제24PNG·독립 전체상태30쌍·저장205 복원4회·실제입력1,000TU·오류0과 공통8PNG를 확인했다. 최종32PNG를 각각 열어 검토했다. 월드30판 252.62638592599998초의 전체 결과 행은305와 같다. 1,000판은 별도 진행한다. 최초 도구 정수 경계 검사1건 실패는 덧셈 중간 반올림을 배제하는 안전한 배타 끝 검사로 수정했고 원문을 보존했다. [전체 근거](release-v309-proof.json).

첫 Native 실행은 구형 각인 경로 인수를 빠뜨려 추가 호환 장면이 제외됐다. 이를 포함한 두 최종 실행만 위 수치에 넣는다. 복원 화면이 어둡다는 최초 시각적 판단은 원본 PNG의 지면/수목 픽셀 대조로 오판임을 확인했다. 작은 캐릭터 연출/빠른 슬롯 안내 이외의 차이는 없었다. 불필요한 렌더러 실험은 폐기하고 src/public/dist/tests/tools/mods 전체가 검증본과 바이트 동일함을 확인했다. 정정·원문은 [화면 검토](performance-v309-screen-review.json)에 남긴다.
