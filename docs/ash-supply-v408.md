이 경로가 닫혀도 전체 T2 공개/결말·장기 생태·X1–X4·영어/출시/사람 게이트는 별도다. v407의30회분·실제30일·위험×0.7·폐 부담10과 개인 근거 경계는 유지한다.

## 구현한 기본 규칙

`AshDeposit.Pilgrim`은 실제 `Region.ChimneySeven` 탑을 공급원으로 쓴다. 침묵원 바깥의 두 곳과 칠번 굴뚝의 한 곳을 지정하며, 허용한 빈 흙바닥에만 도입한다. 플레이어가 깐 바닥·문·용기·침구·작물·설치물·물건·몸을 덮어쓰지 않는다. 새 풍경의 초기 잔량은 각4회분, 한 곳의 용량12회분, 출력100에서 하루6회분이다. 실제 기본 출력80이면 하루4.8회분이며 200턴 작업마다 한 회분을 채집한다. 이 수치는 기존 정경에 없는 구현 기본값이며 자연 수송 전체의 재현을 뜻하지 않는다.

출력은 천분 단위 고정소수로 적분하고 분수 이월을 저장한다. 큰 정수 곱셈은 일시적인 BigInt만 사용하며 저장 데이터에는 안전한 정수만 둔다. `초기+누적 유입=현재 잔량+누적 채집+넘침 손실`을 유지한다. 지붕/지형 변경 전에 경과 구간을 닫고 변경 후 노출 여부를 기록한다. 덮여 있던 과거 구간을 다시 연 시점에 소급하지 않는다. 대기 중 잔류 재의 기후 효과와 새 분출은 구분하므로 정지 뒤 새 분출은0이다. 휴면 지도도 같은 탑의 단일 장부를 정산한다.

기존 순례회 상인이 현역 작업자다. 새 인물·매일 생기는 재떡을 만들지 않는다. 자기 상점에서 신선한 완성품3개 미만을 확인하면 작업 지시를 남긴다. 개인의 남길 먹을거리600kcal, 몸에 남은 열량500 이상, 피로60 미만과 기존 조리 안전 조건을 요구한다. 알려진 현지 채집처의 주소로 이동하되 현재 잔량·지형은 직접 보이는 때에만 확인한다. 자기 상점의 곡물·그릇·키트·장작을 실제 배낭으로 옮기고 자기 우물/물병과 유한 장작불로 정상400턴 제작을 한다. 같은 그릇 UID를 완성품·판매·섭취 뒤 빈 그릇까지 유지한다. 식량/물·수면·보온·위험 대응이 생산보다 먼저다.

작업용 곡물을 개인의 남길 식량으로 이중 계산하지 않는다. 판매 수요가 있을 때 실제 자기 상점의 배급식 한 개를 옮겨 개인 비축을 채우고, 열량500 미만이면 실제 식사를 한다. 피로60부터 원래 자기 침대로 가서 정상 수면을 한다. 기존 위기 수면 기준70까지 아무 일 없이 기다리는 간격을 줄였다. 외투를 가방에 가진 채 추운 작업·수면을 반복하는 경계를 확인해, 같은 공개 체감 온도 예측으로 자기 옷의 실제 교체를 고른다. 작업 중 옷/몸을 즉시 바꾸거나 새 의류를 만들지 않는다. 잠자리의 현재 지형은 직접 보일 때 확인한다.

새/옛 순례회 상점에는 `ash-workshop-v408` 표식으로 귀리8·그릇4·장작8·키트1의 유한 초기 설비를 한 번 도입한다. 같은 표식을 재로드·재방문·날짜 변경으로 다시 지급하지 않는다. 노동의 원재료는 재고에서 빠지고 생산자의 자기 상점으로 옮기는 동안 돈은 생기지 않는다. 손님의 실제 구매·되팔기만 정상 거래의 현금을 옮긴다. 제작자 표시는 실제 완료한 작업에만 붙이고 섭취 뒤 같은 빈 그릇에서는 지운다. 썩은 음식은 신선한 공급 목표나 작업자의 남길 식량으로 세지 않는다.

저장221은 장부·작업 지시·완성품 출처를 보존한다. 저장220에는 없는 과거 유입·작업·생산을 만들지 않는다. 이전에 방문한 바닥에 새 채집처를 도입할 때 초기 재고는0이다. 원래 장부는 현재 Def가 없어져도 그 자체의 수량과 손실 기록을 검증한다.
