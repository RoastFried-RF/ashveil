# v0.322 동작 확장과 연결

걷기와 공격만으로 표현하던 몸체를 정지·걷기·근접 공격·방어·피격·웅크리기·웅크려 걷기·서기·작업·물품 사용·쓰러짐·기상·수면·사격·던지기·상호작용의16동작 계열로 연결했다. 사람·동물·기계·소형 생물13모델을 기존28캐릭터 등록에 적용한다. 같은 역할의 외형 변형은 모델을 공유하며 정지된 드론은 가동 동작을 재생하지 않는다. [동작 비교와 프레임 재생](https://roastfried-rf.github.io/ashveil/artbook/motion/) · [게임](https://roastfried-rf.github.io/ashveil/).

방향당 걷기12/정지4/공격8/방어4/피격4/웅크려 걷기8/작업4/사용4/쓰러짐6/수면2프레임을 등록했다. 사람8모델에는 사격4/던지기2/상호작용2를 추가한다. 기상6은 쓰러짐의 역순이고, 웅크리기3/서기3은 쓰러짐 앞부분을 재사용한다. 모든 행동마다 독립적인 그림을 만들었다는 뜻은 아니다. 현재221종Action과 지속 활동은 의미에 맞는 계열을 선택한다.

OpenAI 이미지 생성 도구로 자체 v321모델을 참고한99PNG를 만들었다. 프레임키는3,168개가 추가되며 실제 고유 원본 영역은2,904개이며264슬롯은 검토한 반대쪽 포즈와 반전 메타데이터를 공유한다. 생성 시도가 겹친 실루엣을 만들면 거절하고, 화면에서 방향 배치가 섞인 경우 이동 시트의 행 구성을 바꿔 다시 만들었다. 방향별 실제 등록 보정은 `semantic_registration.py`에 명시한다. 원본을 보관하고 알파/영역/몸 높이/발과 골반 기준/손의 위치만 읽는다. PNG 픽셀 편집·리샘플링은 하지 않았다. [프롬프트·시도별 해시·등록 방법](../tools/art/direction-v322/README.md).

정지·이동·행동·넘어짐의 우선순위를 연결하고 서로 다른 사용/상호작용을 연달아 입력해도 새 포즈를 생략하지 않으며 자세가 바뀔 때65ms로 짧게 겹쳐 전환한다. 한 걸음150ms, 두 발의 한 주기300ms와 실제 TU는 유지한다. 더 많은 포즈 때문에 이동이 느려지지 않는다. 피격/방어는 진행 중 공격보다 우선하며, 공격 대기열을 최대2개로 제한하고 움직이기 시작하면 지난 작업 동작을 취소한다. 웅크리다 다시 서면 현재 진행률에서 역방향으로 이어진다. 애니메이션0배는 포즈·대기열을 즉시 정리한다.

손의 실제 물품은 방향·행동을 따라 표시하고, 옆모습의 주 손 부착점을 알파 실루엣에서 추정한다. 이는 관절 전체의 뼈대/역운동학이나 모든 방어구의 개별 착용 애니메이션을 구현한 것은 아니다. 사용 중 실제 소모품을 표시하고, 던지기와 먹기에서 적절한 시점에 숨기며, 넘어짐에서는 장비를 낮추고 지운다. 넘어짐·수면은 누운 전용 그림을 쓰고 상태 표시 위치도 몸 높이를 따른다.

플레이어 입력뿐 아니라 눈앞 NPC의 성공한 단발 행동을 전달하기 위해 Core에 선택적·최대64개 도메인 관찰 채널을 추가했다. 관찰자가 없으면 행동 기록을 할당하지 않고 GameState/저장에 채널을 넣지 않는다. `perform`의 기존 규칙 본체를 감쌌으며, 기존 실제 공격FX에 원거리/투척의 선택적 구분만 추가했다. 빈 무기의 장전이나 불발을 발사 포즈로 오인하지 않는다. Core의 actions/combat/types와 새 action-observations 모듈이 바뀌었으므로 v321과 Core 바이트가 같다는 주장은 하지 않는다. 저장 헤더208을 유지하지만 원거리FX의 선택적 필드는 직렬화 상태에 나타날 수 있다.

이전 정적 장면 비교는 그대로 보존하고 별도 동작 비교 페이지를 추가했다.13모델·4방향·16계열과 여섯 연결 예제, 속도·일시 정지·앞/뒤 한 프레임·진행 위치를 조절한다. 사람 외 모델에는 원거리 메뉴를 제공하지 않는다. 이전 전용 포즈가 없는 계열은 그 사실을 표시하고 이전 정지 그림을 보여 준다. 미리보기에는 실제 게임의 조명·장비·FX가 포함되지 않는다.

타입·대상 린트·PNG/CRC/프레임 참조·프로덕션 빌드와 짧은 타이밍/관찰/석궁/자산 검사를 수행한다. 실제 브라우저는 유한 초기 각인을 타이틀에서 불러온 뒤 키 입력만 사용한다. 두 화면 크기에서 걷기·웅크리기·낮춰 걷기·서기·좌우 공격·음식 사용·줍기를 관찰했다. 실제 맵 클릭7걸음은1/.5/2/0배에서 목적지에 도달했고 이동 구간은 한 칸 이하, 몸과 광원의 위치 오차0·고정 모닥불 위치 유지·대기열0이었다. 전체 회귀·World30/1,000·출시 저장 호환 검사는 사용자 지시에 따라 후속이며 v1.0.0 완료로 선언하지 않는다.
