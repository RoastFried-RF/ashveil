# v0.326 동료 진찰과 특정 약 1회 투여

주민·세력 → 동료 → 동행·급료 → 돌봄 부탁 → ‘진찰·특정 약 부탁’에서 진찰 또는 동료 배낭의 실제 약 1회 투여를 직접 선택한다. 기존 상호 응급 처치/창고 허락과 구분하며 자동 투약이나 반복 처방을 추정하지 않는다. 별도 진료비를 지급하지 않고, 고용한 동료의 실제 의료 숙달·손·시야·물품과 시간을 쓴다.

현재 진료 대상은 직접 부탁하는 주인공이다. 같은 현장의 살아 있는 유급 동료 곁에서 서로 보고 들을 수 있어야 한다. 다른 작업/회수 임무는 먼저 끝내거나 중단해야 한다. 위협이 있거나 동료 자신의 출혈·허기·갈증·피로·체온을 먼저 돌봐야 하면 이유를 표시한다.

진찰은 기존 임상 검사의 숙달·시간·품질을 사용한다. 실제 완료했을 때 외부 상처, 숙달에 따른 복부/맥 소견과 기존 영양·질병·호흡 소견을 기록한다. 마지막 소견은 돌봄 창과 기존 일지에서 읽을 수 있다. 보고서는 당시 결과이며 현재 숨은 신체 값을 다시 조회하지 않는다. 실제 검사 전에는 보고서를 생성하지 않는다.

투약은 기존 처방 규칙의 알려진 약만 다룬다. 전신 약은 깨어서 받을 수 있어야 하고, 외용 약은 선택한 실제 외부 상처에 바른다. 규격1회분과 현재 내성·중복 복용·의존·호흡 억제·과용 등의 기존 약물 설명을 검토하고 시작한다. 원래 UID·종류·소모 횟수를 묶고 완료 때 한 번만 소비한다. 시작/미리보기에는 약효나 소비가 없으며, 원본이 없어져도 다른 더미로 대체하지 않는다. 얼음·오염·반쪽·소실 물품이나1회분 미만인 약은 사용할 수 없다.

검토 내용의 서명을 다시 비교해 약·시간·품질·위험 설명이 달라진 오래된 요청을 거절한다. 그 뒤 실제 진료 동안에는 완료 시점의 몸/환경을 따른다. 환자가 중단하거나 서로 떨어지고, 급료·계약·원래 진료 규칙·안전이 달라지면 기존 양쪽 진료 중단/해제 경로를 쓴다. 중단한 진찰의 보고서나 미완료 투약 효과를 만들지 않는다. 기존 정착지 의사의 유료 진료는 유지한다.

`Companion.Hearth.clinical`을 JSON 패치로 기존 `Clinic.Hearth`에 연결했다. 공유하는 것은 임상 검사/허용 처방 기준이며 동료에게 정착지 공급/진료비를 지급하지 않는다. 저장211에는 시작한 진료의 원래 정책ID를 기록한다.210→211은 헤더만 이행하고 과거 진료 요청을 추정하지 않는다. 진찰/투약 동안 든 무기는 숨기고 기존 신체 동작을 사용한다. PNG 리소스는 바꾸지 않았다.

타입·대상 린트·Def/생성Schema·대상90개와 유한 초기 몸/물품을 불러온 실제 키/마우스2해상도 진찰→외용약→기록 확인을 수행했다. 초기 검사 한 개는 실제 상처 명칭 ‘베임’을 일반 단어 ‘상처’로 기대해 실패했고 기대 문구를 수정했다. [정확한 검증 기록](release-v326-proof.json)에 범위를 남긴다. 모든 약/몸/부위·중단 조합과 자연 발생 빈도, 전체 회귀·World/1,000판·출시 저장/사람 평가는 후속이다.

반복 돌봄/수술 지시·다른 동료 환자 선택·들것/지도 경계, 나머지 X1–X4와 영어 전환 등은 [자율 구현 추적](autonomous-implementation.md)에 남는다. 이 기능만으로 v1.0.0 완료를 선언하지 않는다.
