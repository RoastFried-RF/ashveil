# 실제 굴쥐 고기·날것 쥐열과 원래 개척 배급 팩

v0.111. 03 §4.1의 구운 굴쥐 고기90kcal/단백18/비타민0.5/수분40ml·신선24시간/날것 쥐열10%, 개척 배급 팩1200kcal/단백40/비타민30/수분0·밀봉 무기한/개봉7일을 연결한다. 13 §4.11에 굴쥐 고기1×1/쌓임3, 배급 팩/개봉 팩/빈 포장1×2/쌓임1을 먼저 등록했다. 생고기 열량90÷1.1/비타민1/수분80·원래 한 마리당 고기1과 유한 길드 배급 팩1은 조정 가능한 콘텐츠 기본 제안값이다.

실제 굴쥐가 죽은 같은 위치에 원래 고기1개만 생긴다. 사망의 중복 정산은 새 고기를 만들지 않는다. 생물별 고기 종류/수량은 Creature의 meatDrop으로 정의하고, 원래 플레이어의 실제 종 공포 극복 수확 잔여량 규칙을 유지한다. 다른 짐승의 기존 생고기3개는 바꾸지 않는다. 원래 바닥 고기를 실제로 주운 배낭의 물품으로 조리/섭취한다. 실제200턴 마지막에 원래 고기1개가 구운 고기1개로 바뀌며 신선도·재·해동 기록은 유지한다. 구워서 몸에 영양을 미리 주거나 날것 노출을 만들지 않는다.

날것 질병은 실제 섭취 때 기존 질병 노출/면역·기계 신체 거절·1~3일 잠복과 임상 진행을 사용한다. 원인에는 실제 먹은 음식 UID/Def/시각만 남기며 물린 상처나 보지 못한 동물을 지어내지 않는다. 다른 사람에게 먹였으면 그 실제 섭취자에게만 생긴다. 구운 고기·확률0·이미 면역/같은 질병이 있는 몸은 새 음식 노출 난수를 쓰지 않는다. 손 위생/부패로 생기는 기존 식중독과 원래 생식 쥐열은 구별한다.

기본10%를 바꾸지 않은 실제 재현 시드 actual-raw-rat-food-2에서 원래 굴쥐41/음식42를 실제로 먹고14401턴 음식 노출·52464턴 잠복 종료를 확인했다. 가짜 물린 상처를 만들지 않았고, 해당 생식 이전에는 질병이 없다. 단위 검사의 확률1/0 모드는 실제로 켜서 경계를 확인하며 배포 콘텐츠의 기본10%는 유지한다. 설명은 먹기 전 실제 날것 쥐열10% 위험을 보여 준다. 잠복 질병을 즉시 발병한 것처럼 표시하지 않는다.

원래 길드 상인의 유한 배급 팩은 실제 현금과 같은 재고를 교환한다. 실제 사냥칼/녹슨 칼/손도끼로2턴 개봉한 뒤 별도1턴 먹는다. 개봉만 선택하면 같은 원래 UID의 한 회분 팩이 남고, 실제 개봉 시각부터168시간 부패한다. 마지막 실제 섭취 후 같은 UID/품질/내구의 빈 포장만 남는다. 원래 도구를 잃은 진행에 새 칼을 대입하거나 같은 빈 포장을 다시 먹을 수 없다. 메뉴 문구는 콘텐츠 openFoodLabel에서 통조림/배급 팩을 구별하며, 문구는 개봉 진행의 규칙 서명에 들어가지 않는다.

각인v75는 실제 음식 원인과 잠복 시각·원래 팩 개봉/식사 경계를 보존한다. 구형74의 생고기에 과거 종이나 질병을 소급 생성하지 않는다. 전용21개·관련6파일214개가 통과했다. 일반 스케줄러 재현은 원래 배급 팩의 실제3턴 개봉/식사 재개와1200kcal/비타민30/같은 빈 포장까지 영속 전체 상태가 같음을 확인했다. [5개 재현 전체 상태 감사](golden-v111-diff.json)는 버전75와 유한 길드 팩1/이후 원래 UID 이동 외 모든 초기/최종 상태와 오류가 같다. 해당 다섯 재현은 굴쥐 고기 섭취를 포함하지 않으므로 실제 고기/노출은 별도 검사로 확인했다.

타입/린트/Def117패치/Schema98파일 오류0·빌드를 확인했다. v0.111에서는 실제 굴쥐의 원래 고기1/200턴 조리·기본10% 날것 쥐열의 실제 음식 원인과 잠복·원래 칼2턴 배급 팩 개봉/별도1턴 식사·같은 UID 빈 포장과 각인v75를 연결했다. 전체113파일1,973개119.21초·전용21/관련214개·타입/린트/Def117패치/Schema98/빌드·최종 화면492~499/8장 전체 확인·7전체 복원·콘솔 오류0이다. 같은 검증 코어의 월드30시드×최대3일339.95653572초·30개 전체 행이 이전과 같다. 최종 화면의 음식 열량을 소수1자리까지 표시했고, 최종 모든 코어/단위 검사/도구는 전체 검사 사본과 SHA-256이 같다. 최종 파일 manifest도 일치한다. [30개 전체 행 감사](sim-v111-diff.json). 기존 원본 그림을 사용하는 임시 음식 표시는 정식 신규 에셋 전체 완료를 뜻하지 않는다.
