# 거점 운반·채집과 실제 창고 목표/작업자 보급 — v0.71

실제 동료에게 주변 바닥 물품 운반 또는 자원 채집과 창고 목표 수량을 배정한다. 현재 창고 재고를 포함한 목표다. 창고에2개가 있고3개를 목표로 맡기면1개를 더 채운다. 같은 창고에서 꺼냈다 되넣어도 재고가 순증하지 않아 추가 작업으로 세지 않는다. 재료가 소비/반출되면 실제 재고를 다시 확인해 보충한다. 창고 수량과 몸·품질/상태를 바꾸거나 보이지 않는 물품을 만들지 않는다.

운반자는 거점 반경 안에서 자기 눈으로 볼 수 있고 실제로 걸어갈 수 있는 바닥 물품만 찾는다. 보관함/시체·다른 사람의 고정 물품은 직접 뒤지지 않는다. 같은 인물/배낭으로 한 칸씩 걷고 발밑의 정확한 UID를 기본1턴에 주운다. 목표에 필요한 일부만 나누면 실제 새 조각 UID가 생기고 원래 남은 묶음은 바닥에 남는다. 전체 묶음은 같은 UID, 품질·내구/오염·잔량 등 상태를 보존한다. 전체 공간을 먼저 검사해 실패한 줍기로 일부 물품/UID를 쓰지 않는다. 가져왔어도 실제 창고에 들어가지 않으면 재고가 늘지 않는다.

채집자는 실제 지형 자원/반경·시야/경로를 확인해 곁으로 걷는다. 기존 실제20턴 나무·30턴 바위·20턴 모래 채집과 자원 회복 기한을 쓴다. 완료 전에는 산물이 없으며, 다른 사람이 먼저 채집했다면 완료 때 같은 회복 기한을 다시 검사해 중복 생성하지 않는다. 채집물을 받을 배낭 공간도 시작 전에 검사한다. 닫힌 모서리는 공통 채집 탐색/작업에서 막는다. 수면/실신·새 상처/위협/급료 만료·배정 취소는 작업과 실제 자원 소모를 건너뛰지 않는다. 중단한 채집은 그 회차의 노동을 다시 해야 하며 산물이나 납품을 만들어 주지 않는다. 원래 지형과 물품은 유지한다.

동료가 배고프거나 목마르면 실제 창고의 조리된 신선한 음식·얼지 않은 비알코올 식수를 꺼내 자기 몸에 섭취한다. 기존 개인 식수/음식 우선·열량/갈증/수면·섭취 시간·손 위생과 수질 위험을 쓴다. 실제 음식이 줄고 같은 물병의 모금/잔량이 남는다. 썩음/날것·빈/얼어 있는 병이나 창고 재고 없음은 무료 보급으로 대체하지 않는다. 개인 창고 보급을 공공 정착지 배급이나 플레이어의 포로 회유 실적으로 세지 않는다. `BaseLogistics.Hearth`가 줍는 시간1턴과 자동 보급 음식의 최소 신선도50을 정의한다.

완료한 작업자와 방어자는 비어 있는 창고 곁에서 대기한다. 막힌 보관함 칸으로 계속 걸어 들어가려던 동작도 고쳤다. 일반 동행 지시나 명시적인 취소는 배정을 끝내고 이미 운반한 실물을 배낭에 남긴다. F2의 실제 동료 패널에서 물품 종류/창고 목표 수량·운반/채집 배정과 상태를 표시한다.
