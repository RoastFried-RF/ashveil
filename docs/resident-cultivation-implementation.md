# X2 주민의 실제 개인 재배와 유한 종자 전달

v0.235 / 각인172. 새 `ResidentCultivation.Hearth` Def로 역할·집 반경6칸·관수200ml/기준300ml·남길 개인 물500ml와 몸 상태를 분리한다. 모든188종 물품과 원래 주민을 재사용한다. 주민/종자/물/식량을 새로 만들어 공급하지 않는다.

N의 주민 대화에서 자기 배낭의 실제 종자 한 개를 건넬 수 있다. 같은 실제 제공자·수령자/지도·곁·상호 시야·손·각성·비적대 관계·배낭 공간을 검사한다. 이미 종자나 돌보는 밭이 있으면 반복해서 받지 않는다. 두 배낭/원래 쌓음 분할UID를 별도 계산해 전부 들어갈 때만 함께 반영한다. 실패나 견적은 몸·수량·UID·시계·난수를 바꾸지 않는다. 건네기는1턴이며 이후 농사는 주민의 몸/시간/물을 쓴다. 플레이어 종자를 받는 것은 정상 플레이에서 자원을 확보하는 경로이고, 초기 농부에게 공짜 종자를 주는 전역 초기화는 하지 않는다.

여유가 있는 실제 거주 인간형 주민은 집 주변에서 현재 보이고 비어 있는 흙을 찾고 곁으로 걸어간 뒤 같은 `place` 행동으로 자기 종자를 심는다. 현재 햇빛·기온·토양 비옥도가 맞는 곳만 고른다. 원래 종자UID/주민ID/실제 지도·지역·위치를 그때 기록한다. 자기 물병에서 부족량만 관수하고 남길 개인 물을 보존한다. 얼거나 음수에 부적합한 염수는 물 예산에서 제외한다. 동결/염분/수질·원래 관수 규칙을 다시 검증하며 오염 전이도 같은 규칙이다.

한 번 실제 심은 자기 밭만 돌보고 실제로 자란 뒤 같은 수확 작업을 마쳐 자기 배낭에 받는다. 남은 종자로 다른 밭을 복제하지 않는다. 식사·급수·보온·위생·휴식·위협/돌봄이 먼저다. 교역/순찰/호송/포획·기계/적대 인식/심한 몸 상태는 농사를 시작하지 않는다. 미확인 조사는 유지하며, 이미 곁에서 본 비적대 기척이나 실제 도착한 조사 지점은 확인한 것으로 취급할 수 있다. 일반 조사 AI의 경로/상태는 덮어쓰지 않는다.

보이지 않는 밭은 현재 성장/물/철거 여부를 읽지 않고 자기 기억 좌표로 간다. 곁에서 다른 작물/주인이나 소멸을 확인하면 자기 옛 위치 기록만 지우는1턴을 쓴다. 남의 밭을 자기 것으로 등록하지 않는다. 구형171 각인은 버전172만 올리고 주인 미상의 밭에 주인이나 파종 이력을 채우지 않는다. F2/현재 보이는 밭 커서는 타인이 심은 밭을 구분한다. 소유 기록의 현재 역할은 주민의 재배 선택이며, 별도의 절도 처벌/분쟁 제도까지 구현했다고 주장하지 않는다.

전용47개와 기존 재배·동료 관수·관수 오염·NPC돌봄·급수6파일178개가 통과했다. 원래 주민의 실제3턴 파종1회/관수200ml 두 번, 실제 물600ml 중100ml만 사용한 뒤500ml 보존, 같은 수확을 두 사람이 시작했을 때 중복 음식 방지, 다른 주인/숨은 밭·시야·몸·거래 실패·가득 찬 배낭과 두 실제 배낭/UID 보존을 검사한다. 초기 정적 오류는 검사에서 기계 상태의 필수 초기 필드를 빠뜨린 것이어서 유효한 선언 상태로 고쳤다.

브라우저 초기 장면은 실제 정착지의 원래 주민95/모든 현재5명·기존 장비와 개인 물병103/104를 유지한다. 원래 집37,20에서 실제 기존 흙40,20으로의 초기 거주 위치/쉬는 AI와 다음 날 한낮/모든 주민의 활성 순서를 명시한다. 주민이 실제로 이사하거나 앞선12시간을 기다렸다고 주장하지 않는다. 플레이어는 원래 지도에서 실제12턴 걸어 접근했고 자기 종자2개만 추가 초기 키트로 받는다. 다른 주민을 멈춘 채 농사만 진행하지 않는다. 실제 종자 전달/파종/두 관수·관찰 이동/성장/수확과 미완료 휴식 전체172 저장 복원을 검사한다. 마지막3성장턴은 선언한 초기 성장 조건이며 앞선28797턴을 실행했다고 주장하지 않는다.

토양 수분 확산·장기 오염/염분, 정지 지역의 일 단위 작물 정산, 종자 상거래의 자율 공급 확대/장기 잉여 생산·판매와 나머지X2 생태는 남는다. 각 기능의 최종 정적/골든·브라우저·전체/월드 결과는 완료 후 기록한다.
