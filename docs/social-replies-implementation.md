# 실제 환대·모욕과 명령 뒤 지역 이탈

v0.145 검증 중. 실제 지역 주민과 대화하고 우호 평판20 이상이며 목소리를 들었을 때 환대+5/3일 선형 기억을 준다. 원래 주민이 누구를 환대했는지 저장해 같은 사람에게 반복 대화하여 기억을 갱신하지 않는다. 현재 정착지/주민의 실제 소속을 사용하고 먼 마을이나 과거 만남으로 소급하지 않는다.

실제 짜증 붕괴 중인 인간형NPC에게 말을 걸면1턴의 모욕 발언으로 응답한다. 들었을 때에만−5/2일/3×0.5 선형 기억을 준다. 실제 붕괴 인스턴스 안의 청자를 저장해 반복 발언으로 쌓지 않는다. 못 들었을 때는 표식을 만들지 않아 나중의 실제 청취를 막지 않는다. 이 응답을 긍정적인 잡담/소문 전달로도 중복 처리하지 않는다. 경계하는 인사 자체를 모욕으로 세지 않는다.

현재 정착지의 원래 세력 경비에게 경계 최저 평판−20 이하에서 실제로 들은 떠나라는 명령을 받으면 당사자/지역/세력/시각을 기록한다. 기존 적대 대화 거절 규칙은 유지한다. 명령만으로 추방 기억을 주지 않고, 실제 출구까지 이동하여 정상적으로 지역 이탈을 완료한 뒤에만−8/5일 선형 기억과 완료시각을 기록한다. 다른 지역/일반 상인/명령 없는 출발/실패한 출발/이미 완료한 명령에서는 추방을 꾸미지 않는다. 경비의 강제 이동·자동 재입장 금지·추가 AI집행을 전부 구현했다고 주장하지 않는다. 두 평판 문턱은Economy.socialReplies로 수정하는 구현 기본값이다.

주민 창에는 이 마을에서 떠나라는 경비의 명령을 실제 받은 동안만 표시한다. 선택적 명령이 없거나 이미 지역을 떠났을 때 잘못된 배너가 뜨지 않는다. 새로운 물품이나 이미지는 없다.

검증 초기 장면은 실제 생성/진입한목자골Region.ShepherdDale의 원래 주민63/경비81을 원래 출구32,47 근처의 유효 초기 경비 장면으로 배치한다. 실제 대화1턴, 원래 출구로 이동1턴, 정상 지역 이탈1턴을 사용한다. 과거에 그 길을 걸었다고 주장하거나 턴 중에 위치를 순간 이동시키지 않는다. 명령은14400턴/완료14402턴, 입력 복귀14403턴의 기존 선형 절삭으로 표시−7/남은143999턴이다. 대화 직후 환대+4/86399턴과 모욕−4/57599턴도 같은 기존 선형 규칙이다. 길 장면은원래MapState.kind=surface를 사용하며 별도road종류를 만들지 않는다. 실제 지역 포인터와 보관된 원래 장면을 검증한다.
