# 저체온 혼란과 실제 착탈 — v0.59

03 §7.4에 따라 체온33°C 미만·의식0.6 미만인 인물은10분(200턴) 경계마다5%로 겉옷을 벗으려 한다. `ColdConfusion.Human`에 조건·간격·확률·대상 슬롯을 두며 모드 검증/Schema에 포함한다. 가장 바깥 의복을 고르고 같은 인물의 `body.coldConfusion.<id>` 난수 스트림을 쓴다. 조건 미달·옷 없음·손 사용 불가·동일 옷 탈의 중이면 난수를 소비하지 않는다.

몸 갱신 후 요청을 남기고, 실제 준비 차례에서 정상 착탈 행동으로 처리한다. 수면/기존 활동은 공통 중단 경로를 따른다. 기절·심한 몸 불이익으로 정상 착탈이 불가능하면 강제로 장비를 지우지 않는다. 재가온/의식 회복·옷 UID 변경·기한 만료는 낡은 요청을 취소한다. 반복 대기는 판정 기회를 추가하지 않는다. NPC도 같은 처리를 받되 사적인 이력이 전역 로그로 드러나지 않는다.

탈의가 끝나면 원래 물품을 바닥에 놓는다. 배낭이 가득 차도 새 물품/UID를 생성하지 않으며 품질·내구·젖음 상태를 보존한다. 실제 시간 동안 몸과 젖음의 자연 변화는 계속된다. 장착한 의복의 일반 떨구기도 같은 탈의 시간을 쓰며, 장착 의복을 직접 컨테이너로 옮겨 시간을 생략하는 경로는 거부한다. 배낭 물품/손에 든 무기의 기존 자유 행동 떨구기는 유지한다. I창 장착품 메뉴와 바닥으로 끌기도 이 경로를 쓴다.

착용·탈의 중단은 반착용(방어/단열50%)과 남은 기준 작업량을 물품에 저장한다. 재개 때 현재 몸의 다턴 배율을 적용하므로 중단을 반복해 시간이 짧아지지 않고, 몸이 회복하면 남은 시간도 줄어든다. 반쯤 입은 같은 장착품을 다시 마저 입을 수 있으며, 반탈의한 옷을 다시 여미는 역방향 진행도 처리한다. 구형 반착용 물품은 진행 정보가 없으므로 기준 작업의 절반으로 호환한다. 배낭으로 완전히 벗거나 다른 인물이 입을 때 이전 반착용 진행을 시간 할인으로 쓰지 않는다.

각인v25는24에서 몸·장비·원장을 그대로 보존하는 순수 이관이다. 대기 요청/착탈 중 진행과 인물별 난수 상태를 저장한다. 기존5개 고정 입력은 명령과 오류를 유지했고, 전체 초기/최종 상태 차이는 버전24→25뿐이다(`golden-v059-diff.json`).

집중 검사90개(저체온/착탈20·Def40·기존RPG30)가 통과했다. 정상/가득 찬 배낭의 동일 UID, 플레이어/NPC, 실제 작업 시간, 회복/낡은 요청 취소, 장비 교체 중단, 느린 몸의 취소/회복, 반착용 재개/역방향, 중간 저장/난수 보존을 검사한다. 전체59파일912개는33.29초에 통과했고, 린트/타입/빌드/Def/Schema54파일 오류0이다. 브라우저135~138/설정은 콘솔 오류0으로 통과했으며137을 시각 확인했다. 원래 월드 없는 준비 상태는 불러오기 때 월드 RNG4개가 초기화되어 비교 실패했다. 실제 월드를 포함한 준비 상태로 수정한 뒤 몸/물품/지도/난수/시간 전체의 저장 복원이 동일함을 확인했다.
