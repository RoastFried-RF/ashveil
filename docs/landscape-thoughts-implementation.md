# 현재 고향 풍경과 보이는 새 유적

v0.138.04 #28의 고향 풍경+3을 현재 실제 지도의 월드 칸에 연결했다. 정본 예시인 촌락 사냥꾼의 고원은 기존 Biome.Greymoor(회색 고원), 뱃사공의 강변은 실제 WorldCell.river 표식을 사용한다. 존재하지 않는 강/고원 바이옴을 새로 만들지 않았다. 나머지 배경의 고향 바이옴은 정본에 정의되지 않아 임의로 확정하거나 전부 매핑했다고 주장하지 않는다. 모드는 배경의 바이옴/강 조건을 설정할 수 있다.

야외·지상에서 깨어 볼 수 있고 칠흑이 아닌 현재 풍경만 반영한다. 지붕 아래/눈 손상/수면·실신/지하/월드가 없는 옛 지도/다른 배경에서는 원격 고향을 추측하지 않는다. 실내에서 바깥 풍경을 보는 추가 경로는 구현하지 않았으며 현재의 야외 관찰 정책은 정본의 새로운 확정 조건으로 쓰지 않았다. 현재 지도에 묶인 실제 칸을 사용하고 여행 지도 포인터로 원격 풍경을 읽지 않는다. 조회는 상태/기억/난수/시간/UID를 바꾸지 않는다.

04 #24의 경이로운 광경+4/1일/3×0.5는 실제 처음 발견한 보이는 유적 구역에 연결했다. 기존 방 타일의50%를 봤다는 발견 기준/기존 경험치5와 발견 플래그는 유지하고, 새 기억은 현재도 그 구역을 볼 수 있을 때만 준다. 이미 발견한 유적/일반 방/보지 못한 과거 기록을 기억으로 소급하지 않는다. 모드의 실제 구역 종류를 메타데이터로 고를 수 있다. 별도 전망대/그 밖의 발견 지식은 아직 전부 구현했다고 주장하지 않는다.

각인101→102는 버전만 이관한다. 새 Item/이미지는 없다. 전용28/관련3파일75개 검사 통과. 생성된 실제 시작 회색고원과 원래 지역의 유효 초기 작은 유적 구역을 공개 행동으로 발견하는 검증을 사용한다. 골든5개 초기 전체는 버전102 외 같고, 최종3개 전체도 같다. surface/동결 재진입은 기존 발견 로그의21647/21640턴에 생긴 유적 기억1개만 추가되며 나머지 전체 필드와 오류는 같다. v0.138에서는 실제 현재 고향 풍경과 처음 보이는 유적 발견의 심리 반응을 연결했다. 각인v102·전용28/관련75개·전체140파일2,727개128.20초·화면660~665 여섯 장 전체 확인·6전체 복원/20턴 재개/콘솔0이다. 월드30판299.278011672초에서11행은 새 기억만,17행은 새 기억과 스트레스,2행은 신체·시간 연쇄가 달랐다. 풍경 사고 두 설정만 끈30판 전체가v137과 같아 원인을 확인했다.
