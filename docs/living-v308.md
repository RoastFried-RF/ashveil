# v0.308 생목 원화

혼합 수목 장면에서 기존 소나무가 지나치게 크고 거친 픽셀 계단으로 보이는 것을 확인했다. 소나무 두 실루엣·검은잎나무 두 실루엣을 새 SVG로 제작하고 기존 고사목과 함께 검토한다. [편집 가능한 원본과 재현](../tools/art/direction-v308/README.md) · [방법과 실패 기록](../tools/art/direction-v308/provenance.json) · [CC0](../tools/art/direction-v308/LICENSE.txt).

이미지 생성 도구 두 번의 호출은 도구 매개변수 오류로 이미지를 만들지 못했다. 새 SVG 경로·가지 좌표·솔잎·잎 무리와 수피를 구성하고 로컬 Inkscape로 PNG를 생성했다. 첫 안의 반복적인 솔잎 띠/둥근 잎 무리와 줄기 밖 수피 선을 반려하고, 줄기 내부 클리핑·개별 솔잎·잎 질감과 먹빛 색을 다듬었다. 다른 게임 이미지나 기존 PNG를 입력·편집하지 않았다.

현재 두 기본 생목의 `visual.sprite/scale/tint`가 원래 기본값과 모두 같을 때만 새 원화를 선택한다. 사용자 모드가 종·원화·크기·색 중 하나를 바꾸면 기존 경로를 따른다. 기본 소나무는 월드 높이56/58, 검은잎나무는44/41로 맞추고 원화의 접지점을 사용한다. 성장/채집 뒤 축소는 기존 배율을 그대로 곱한다. 이전 프레임·시트·UI·애니메이션 키는 덮지 않는다.

Core·Def·모드·시야 수치·저장205는 그대로다. 실제 낮/어둠·횃불·배율·가림/실명·이전307 저장 및 독립 Node 전체 상태/복원을 비교한다. 검증 장면의 두 소나무/두 검은잎나무/고사목과 꺼진 횃불은 유한한 초기 각인으로 선언하며 자연 획득 증거와 구분한다. 불러온 뒤 세계/몸/시간/난수를 주입하지 않는다.

최종 통합 검증 결과는 완료 후 근거에 기록한다. [v1.0.0/X1–X4 출시 기준](v1-execution.md)은 계속 남는다.

## 최종 통합 검증

전체342파일 6,181개를 한 번의 전체 실행으로 통과했다(824.757초, 작업자2). 두 화면 크기 실제 생목/조명/숨김 검사24PNG·독립 전체상태30쌍·저장205 복원4회·실제입력1,000TU·오류0과 공통8PNG를 확인했다. 최종32PNG를 각각 열어 검토했다. 실제 발밑 조도·투명 가지 틈·낮/횃불·배율/저장 복원·숨은 상자/적·초기 실명 장면을 검토했다. 정적 고사목과 동적 소나무/검은잎나무 경로를 함께 검증했다. 안개 합성은307과 같고 기존 실제 Canvas2D14경계 근거를 유지한다.
