# 항복 이후 선택과 실제 밧줄 — v0.62

07 §8의 포박/석방/심문/처형을 실제 인물·물품·시간에 연결했다. `Prisoner.Hearth`는 밧줄/시간·평판·소문 오차를 정의한다. 포박 기본2턴/밧줄1개, 처형 기본3턴과 평판±값은 정본을 따른다. 석방1턴/심문20턴·안전 귀환 유예1200턴과 밧줄 제작20턴/천2개/가치는 추가 조정값이다. 포로 돌봄·수면/깨우기·감시/밧줄 탈출은[v0.63](prisoner-care-implementation.md)에 연결했다. 장거리 호송/회유와 자연 발생 구출 사건 전체는 후속이다.

F2에서 천2개로 밧줄을 엮고, N창의 실제 항복자에서 선택한다. 곁의 살아 있는 인간형·시야/모서리·조작/의식과 항복 상태를 검사한다. 포박은 깨어 다른 일을 하지 않는 항복자만 대상으로 삼는다. 중단/이동/밧줄 UID 교체는 소비 없이 멈춘다. 완료 때 배낭의 실제 한 개를 포로에게 옮긴다. 쌓임 분리일 때만 새 UID 하나를 배정하고, 한 개짜리는 같은 UID를 유지한다. 포박은 손과 이동을 막고 NPC AI/직접 행동에도 적용한다. 경비/약탈자는 실제 밧줄을 가진 경우에만 안전한 곁의 항복자를 포박할 수 있다. 신규 밧줄을 NPC에게 무료 지급하지 않는다.

풀거나 사망하면 같은 밧줄이 그 자리 바닥에 남는다. 석방한 사람은 같은 몸과 소지금/장비를 지니고 원래 자리로 걸어 돌아간다. 잠시 놓아준 편을 공격하지 않고, 다시 공격받으면 공통 반격 판정을 쓴다. 같은 사람의 석방 평판/수용 기억은 같은 고용주에게 한 번뿐이며, 이미 받은 격퇴 경험치도 중복하지 않는다. 기존의 ‘AI가 항복했을 때 다정 기억 자동 생성’은 실제 석방 선택으로 옮겼다. 수용 기억은 정본대로+3/2일/2중첩·0.5, 다정은+6이며 기존 Def는 패치로 고친다.

심문은 포박된 상대와 말을 주고받아야 한다. 그 인물이 속한 세력의 현재 지도 공급원만 대략±30%로 전하며, 겁먹은 경우30%로 수량을 더 부풀릴 수 있다. 다른 지역/층을 생성하거나 숨은 NPC 능력치를 읽지 않는다. 소문은 전해 들음(hop1)·작성 시점을 갖는다. 같은 인물의 말은 한 기억으로 저장하고 청자마다 한 번만 듣는다. NPC가 먼저 들었다고 플레이어 지식에 자동 추가하지 않으며, 이후 플레이어가 물으면 같은 기억을 듣고 난수를 다시 굴리지 않는다. NPC의 사적 소문도 저장한다.

석방+3/처형−5는 기존 목격·거리별 소식 도착을 적용한다. 석방한 생존자는 자신의 석방을 알릴 수 있지만 처형된 시체는 목격자로 세지 않는다. 살아 깨어서 실제로 본 같은 세력 인물이 있을 때 처형 소식을 보낸다. 일반 살해 평판과 중복 부과하지 않는다. 실제 국가 NPC의 처분은 국가 간 석방/처형 사건으로, 플레이어/고용 동료는 개인 평판 소식으로 처리한다. 물리적 전령 이동 전체는 기존 소식 모델과 마찬가지로 후속이다.

처형은 실제 사망/시체·혈액·공통 격퇴/기억을 처리한다. ‘처형했다’ 기억은−8/7일/선형 감쇠/3중첩·0.5, 냉혈은0이다. 일반 사람 죽임/첫 살인 기억도 각 조건을 따른다. 완료 다음 턴의 표시−7은 기존 정수 선형 감쇠의 절삭에 따른 값이며 정의값은−8이다. 전역 정수화 정책은 바꾸지 않는다.

각인v28은27의 몸/장비/관계/기억을 바꾸지 않는 순수 이관이다. 포박 중 진행·밧줄 소유·개별 소문/청자·석방 보상/유예를 저장한다. 기존5골든은 버전27→28 외 전체 초기/최종 상태와 원래 명령/오류를 유지했다(`golden-v062-diff.json`).
