# 생성 선택과 콘텐츠 해시를 포함한 시드 공유 — v0.267 작업 중

설계11 §5의 시드/성향/로드 해시 공유를 타이틀에 연결했다. ASHVEIL1 형식은 현재 실제 게임/정의 계약 버전, 원래 시드·선택한 배경 또는 원래 무작위 선택, 특성 재굴림0/1, 사건 흐름, 실제 적용 순서의 모드 ID/버전/내용 SHA256과 전체 로드 SHA256을 담는다. 원래 선택을 canonical JSON/URI 문자열과 SHA256 체크섬으로 표현한다. 현재 세계의 몸/돈/물품/시간/난수 상태를 가져오는 저장 파일 기능은 아니다. 체크섬은 손상 검사용이며 작성자 인증은 아니다.

배경 무작위를 실제 결과 배경 ID로 바꾸면 원래 추첨의 RNG 소비가 사라져 다른 세계가 된다. 따라서 원래 background 미선택을 그대로 보존하고 실제 원래 선택/재굴림·사건 흐름으로 새 게임을 만든다. 같은 시드의 은퇴 인물 초기 메타 기록도 결과에 영향을 주므로 실제 정상 preview 생성에서 허용된 정보 전용 초기 인물 기록만 포함한다. 생성된 개체 번호/이미 들음/몸/소지품은 코드에 넣지 않는다. 수신자의 로컬 연대기를 다시 합치지 않고 코드의 초기 정보만 사용한다. 생성/복사 화면은 인물 이름과 이야기 기록 포함 사실을 표시한다.

코드는 크기/필드/형식·중복 JSON 키/체크섬과 인물 초기 필드를 엄격하게 검사한다. 모드를 자동 내려받거나 core로 대체하지 않으며, 현재 설치된 실제 로더 결과의 버전/원문/순서/전체 해시와 게임·정의 계약/배경/사건 흐름을 비교한다. 검토와 생성 선택 적용은 새 세계/각인을 쓰지 않는다. 실제 시작 시 새로 검증하고 스크립트 준비 뒤 실제 DB 해시도 재확인한다. 생성 선택을 편집하면 공유 코드 고정을 풀며, 공유 코드를 적용할 때는 가져온 재굴림1을 배경 변경 감시자가0으로 되돌리지 않는다.
