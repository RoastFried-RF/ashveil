# 기존 각인의 명시적 모드 목록 변경

v0.250 작업 중. 각인180/API1.4.0을 유지한다. 기존 각인의 실제 모드 목록을 별도 조회하고 타이틀에서 설치된 모드를 선택해 검토한다. 새 게임의 선택과 분리한다. core는 항상 켜며 현재 설치되지 않은 원래 모드는 이름을 표시한다. 원래 모드가 없어 기본 불러오기가 실패한 각인도 다른 선택의 검토에 들어갈 수 있다.

목록 열기·체크박스 변경·검토만으로 세계나 각인을 쓰지 않는다. 검토는 추가/제거할 실제 모드와 정의/물품 복구 수·기존 오류를 보여 준다. 계속 토큰은 원문 각인과 선택 DB의 실제 해시에 묶이며 승인할 때 저장을 다시 읽고 그 선택으로 DB를 다시 만든다. 원문/콘텐츠/선택 변경은 새 검토가 필요하다. 체크박스 변경·취소는 이전 토큰을 무효화한다. 선택 배열은 소유 사본으로 보관한다.

같은 구성을 선택해도 검토만으로 진입하지 않는다. 같은 실제 해시의 승인에는 변경 이력·업적 비활성·불필요한 저장을 만들지 않는다. 실제 바뀐 구성의 승인만 현재 목록/해시/정의/크기·같은 시각의 변경 이력·연대기와 업적 비활성을 저장한다. 기존 지도·몸·인물·물품·시간·UID·난수는 재생성하지 않는다. 원래 물품 모드 제거는249의 같은 UID 보관으로 이어지고, 실제 패키지를 다시 설치·선택하면 원래 상태로 복원한다.

아직 복구하지 못하는 다른 종류 정의 제거와 설치된 의수족/선체·진행 중 물품 참조는 차단한다. 스크립트 지속 상태의 원래 해시 목록과 현재 실제 스크립트 소스가 다르면 검토에서 차단한다. 특히 스크립트를 전부 제거해 초기화 함수가 일찍 끝나던 경우도 오래된 지속 상태를 조용히 남기지 않는다. 스크립트 구성 변경의 마이그레이션은 후속 작업이다.
