# v0.333 숲의 실제 동물과 수렵 산물

도감에만 있던 재뿔사슴과 엄니돼지를 독자 몸체·4방향/동작·신체·행동·먹이·실제 수렵 산물로 연결한다. 새 숲 지도에만 사슴3/돼지2, 총5마리를 유한하게 배치한다. 이미 방문한 지도에 소급해 새 개체를 만들지 않는다. 기존 지역 진입과 하위 지도 왕복에서 같은 원래 개체 ID를 보존한다. 해당 버전은 개발 미리보기이며 전체 동물 생태나 v1.0.0 출시 완료를 뜻하지 않는다.

사슴은 쥐의 ‘쓰러지거나 피 흘리는 사람을 사냥’하는 분기를 재사용하지 않는다. 실제 시야/바람·냄새로 감지한 위험에서 도주하고, 닿는 적 앞에서 도주로가 막히면 실제 뿔/발굽으로 방어한다. 볕철에는 실제 조우마다 한 번만30%의 공격성 판정을 하고50턴의 조우 기억을 보존한다. 표시나 도감 조회는 그 판정을 하지 않는다. 돼지는 현재 상처의 심각도로 사기가 올라가며 상처가 있다고 도망치지 않는다. 공용 직선 접근/기력/재사용 대기 규칙을 따르는 들이받기와 엄니의 다리 선호 가중2를 연결했다. 공격 자체의 부위 가중은 기존 부위/방향/능력 가중과 곱하며 강제로 다리를 맞히지 않는다. S2 이전 도감에 숫자를 공개하지 않는다.

두 동물은 사냥개와 다른 비정치적 `foragers` 무리에 속한다. 단지 같은 ‘짐승’ 문자열 때문에 늑대와 초식 동물이 같은 우호 무리로 취급되지 않는다. 종별 AI는 Def의 `wildlife` 설정을 읽고 실제 몸·경로·위험을 사용한다. 몸에 조작 기관이 없으면 기본값으로 가상의 손을 받던 공용 계산도0으로 고쳤다. 자연 공격이 요구하는 실제 신체 기능을 생물/기계 모두 확인하며, 뿔 기능이 사라진 사슴은 실제 움직일 발굽 공격으로 바뀐다. 네 다리도 모두 잃으면 가상의 주먹을 만들어 공격하지 않는다.

식물/바닥 먹이/물을 실제로 먹는다. 배낭/현재 바닥의 허용된 원래 먹이 UID 한 단위를 입으로 소비하고 실제 칼로리·단백질·비타민·수분·오염·신선도/식중독·해당 날먹이 질병을 적용한다. 사람의 손을 우회하는 새 인간 섭취 경로를 열지 않는다. 살아 있는 입/의식이 필요하며 턱이 불능이어도 의식과 움직일 다리가 남으면 도주·방어 판단은 계속한다.

성숙한 실제 식물을 뜯을 때는 기존 채집 활동/시간·계절·토양·관수 오염·재성장을 사용한다. 완료한 양만 삼키고 원래 군락을 소진하며, 재성장 전 같은 산물을 다시 지급하지 않는다. 위험·불·식물 변경·입 손상은 완료 전에 중단한다. 실제 식수는 인접 물/얼음 구멍·염분·오염을 따른다. 피곤한 개체는 기존 수면 규칙을 사용한다. 무한 재료·즉석 회복/날짜 보상이나 시간만 보는 렌더 치료를 추가하지 않는다.

돼지는 실제 진흙 지형에서 뒹굴어 진흙 방어를 얻고, 지붕 없는 지상에서 실제 재비를 맞은60턴 동안 씻긴다. 방어는 공용 갑옷 판정의 별도 층이다. 단단한 피부의 기본 방어3/2와 진흙8/5를 구분한다. 진흙을 아이템으로 생성해 교역하는 경로가 아니다. 전용 뒹굴기 원화는 낮춤→접기→굴림/비빔→복귀→일어서기의6포즈로2.4초 재생하고 이동/피격/공격에 중단된다. 몸 굴림이 core facing을 돌리지 않는다.

수렵은 실제 사체를 기존 해부 절차로 한 번만 처리한다. 사슴의 생가죽/뿔/힘줄·골수, 돼지의 생가죽/엄니/비계를 각각 정의하고 원본7영역을 새로 그렸다. 사슴 생가죽의 무두질→일반 가죽, 돼지 생가죽의 무두질→질긴 엄니돼지 가죽, 힘줄→실, 비계→등잔기름 제작법을 수첩에 연결했다. 실제 준비·재료/소금·도구/무두질 시설·가공 대기를 보존한다. 생가죽을 곧바로 가공 가죽 재질로 쓰던 초안을 고쳤고 가공 가죽의 회수 재료도 같은 재질을 가리킨다. 무두질한 돼지 가죽은 원래 접힌 가죽 아이콘을 공유하며 별도 신규 그림으로 세지 않는다.

각 동물은 정지/걷기/공격/피격/쓰러짐/수면/기상/섭식의4방향×4원본 영역을 갖는다. 여기에 돼지 뒹굴기24영역을 더해 두 몸체의 실제 등록은280고유 영역이다. 반전/역순 재생으로 새 고유 영역을 늘린 수치가 아니다. 기존 원본도 보존하고 잘못된 방향·이웃 실루엣·경계 문제가 있던 후보는 제외했다. 섭식 원화는 입이 낮아져도 실제 발을 지면 기준으로 쓰며, 식물/물/음식 소품을 몸에 굽지 않았다. 지속 섭식 주기는 사슴1.8초/돼지1.9초, 공격은0.7초/0.68초이며 게임 TU는 바꾸지 않는다. [제작 기록](../tools/art/direction-v333/wildlife/README.md), [수렵 산물 원문](../tools/art/direction-v333/harvest-materials-provenance.json).

새 몸체의 보행은 아직 방향당4원본 포즈이며 기존 인간12보행과 같은 촘촘함을 완료했다고 쓰지 않는다. 새로운 군락의 성숙/소진 그림, 사체·잘린 뿔/엄니와 진흙이 씻긴 외형, 암컷/새끼/번식·무리 관계, 긴 계절의 먹이/수분 수지와 야생 개체 수 순환은 계속 구현/평가할 항목이다. 의복·보철/절단 외형, 나머지 확장7종과 행동도 남는다. 재까마귀 원화와 잿곰 부분 원화, 중립 관절형 의복 시제품은 별도 준비 자료이며 이 버전의 활성 개체로 세지 않는다.

이동이 논리적으로 끝났지만 화면의 보행 보간이 남아 있는 동안 시작한 작업/물품 사용/상호작용/뒹굴기는 실제 도착 뒤 재생한다. 기존에는 보행 중 정지 동작을 지우며 새 뒹굴기도 사라졌다. 대기한 동작은 새 이동·지도 변경·공격/피격·받아넘김·사망/의식 상실에 폐기하며, 계속 작업인 경우 원래 활동이 실제로 유지될 때만 연결한다. 즉시 표시 설정도 대기 동작을 제거한다. 실제 화면 관찰에서 원래6프레임과 정지한 전체 세계 해시를 대조했다. 빈 전투 기록도 고정 높이를 차지하지 않게 줄여 작은 화면에서 동물과 바닥을 가리지 않도록 했다.

저장212의 선택 필드와 원래 활동/지도 보존 경로를 사용한다. 개체별 AI 난수도 각인에 보존한다. 파일/대상 검사와 실제 초기 각인 입력의 근거는 [v333 검사 기록](release-v333-proof.json)에 분리한다. 전체 회귀·World/1,000판·장기 균형·기기 성능/외부 사람 평가는 미실행이며, 원화/파일 검사만으로 출시 승인으로 바꾸지 않는다.
