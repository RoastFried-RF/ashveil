# 실제 상처 감염의 국소 증상과 전신 부담

v0.128. 각인92. design/02 §10의 감염I0/20/40/60/80 단계에 맞춰 국소 추가 통증0/5/10/10/10, 체온 목표37/37/37.8/38.5/39.5°C, 전신 의식 벌점0/0/0/5/15%, 수면 질 배율1/1/1/1/0.6, I40부터 해당 상처의 치유 정지, I60부터 발열 대사를 적용했다. 값은 Recovery.Wounds.infectionStages 패치에서 읽는다.

여러 상처의 국소 통증은 각각 더하고, 전신 온도/의식/수면/발열 대사는 가장 심한 한 단계만 적용한다. 질병의 열과 감염의 열 중 높은 목표를 현재 ThermalState에 담고, 체온 계산은 이 파생 상태를 읽는다. 추위·더위의 실제 열평형과 해열제의 목표 감소를 보존한다. 체온을 목표로 즉시 옮기지 않는다.

발열 수분은 기존 Nutrition.feverWaterPerDay500ml/일, 열량은 기존 feverKcalMult를 재사용한다. 감염 발열과 질병 발열/현재 고열을 OR로 묶어 추가 물을 중복 차감하지 않는다. 수면 감소는 약의 수면 보정을 포함한 전체 질에 적용하며 기존 최저/최고 한계와 극한 통증 수면 불가를 보존한다. 면역 경주·항생제·괴저/패혈증의 나머지 처리는 같다.

같은 턴의 경계나 모드 단계 변경에도 통증/의식 캐시가 즉시 바뀐다. 현재 상태를 읽는 조회는 상처·면역·몸·기억/난수/UID/시간을 바꾸지 않는다. 구형91에는 과거의 발열/물 소비/치유를 소급하지 않고 버전만 이행한다. 새Item은 없다.

일지에는 눈에 보이는 국소 증상 또는 실제 전신 발열 단계의 치유·의식·수면·추가 수분 부담을 표시한다. 아직 증상 없는 상처를 곪음으로 부르지 않고, 숨겨진 내부 감염의 고름을 표시하지 않는다. 기존 의료 숙달에 따른 상세 수치/내부 진찰 정책을 유지한다.

전용42개/관련11파일225개·타입/린트·Def159패치/Schema106파일·빌드를 확인했다. 5골든은 버전92 외 전체 초기/최종 상태와 오류가 같다. 실제400턴 휴식에서 미열37.8 유지, 원래 버드나무차68의 실제 소비/201턴으로 같은 몸39.4→39.3°C 냉각, 미완료 원래 감염 상처67의399턴TU 재개를 확인했다. 정상 렌더 연출 큐 소비를 기록한 뒤 브라우저와 헤드리스 전체가 같다. 화면598~603 여섯 장을 모두 확인했고6전체 각인 복원/콘솔 오류0이다.

전체 검사와 월드 회귀는 진행 중이다. 나머지 정신 사건·일반NPC 정신과 전체 후속 확장도 남는다.
