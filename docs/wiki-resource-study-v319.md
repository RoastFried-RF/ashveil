# v0.319 위키 리소스 조사와 자체 원화 적용

사용자가 지정한 [Stoneshard Wiki](https://stoneshard.com/wiki/Stoneshard_Wiki)와 [Enemies](https://stoneshard.com/wiki/Enemies)를2026-10-23UTC에 조사했다. 전체 파일 목록과 프로젝트의 모든 사용처를 대조하고, 역할·실루엣·재질·화면 비율을 참고해 자체 원화를 제작했다. [공개 원화 도감](https://roastfried-rf.github.io/ashveil/artbook/)에서 방향/동작/프레임·분류/검색·확대를 바꿔 볼 수 있다.

## 전수 목록과 시각 검토 범위

공개 MediaWiki API를 continuation 끝까지 조회했다. 현재 업로드3,937파일, 비리다이렉트 본문4,372문서,288분류와 파일 사용22,977기록이다. 본문ID와 결합한 사용은21,981건이며 파일이 들어 있는86분류의 구성원도 모두 수집했다. 본문4,372개의 분류도 모두 조회했다. 번역/관리 문서가 포함되어 있으므로 문서 수를 독립 리소스 수로 해석하지 않는다.

직접 파일 분류가 없는1,592파일도 전체 목록에 보존했다. 본문 사용/분류를 결합한 비배타적 분류 힌트를 추가했으며, 힌트가 없는976파일도 버리지 않았다. 자동 힌트는 정확한 의미 분류를 보장하지 않는다. [전체 파일/사용/분류 결합](../tools/research/stoneshard-v319/joined-resource-inventory.json) · [API 완료 기록](../tools/research/stoneshard-v319/inventory-audit.json) · [파일 분류](../tools/research/stoneshard-v319/file-category-catalog.json).

실제 픽셀 검토는 **601개 참고 이미지**다. Enemies 페이지에 쓰인305개 고유 파일을 모두 포함하고, Enemy NPC 이미지 분류와 합친317개를11contact 화면에서 확인했다. NPC80개, PC18개와 다른73개 시각 분류의 크기별 대표도 검토했다. 최초449개17화면과 확장 적 목록11화면의 파일 목록/해시를 [검토 기록](../tools/research/stoneshard-v319/visual-study.json)에 남겼다. GIF는 브라우저의 한 시점이며 모든 애니메이션 프레임을 보았다는 뜻은 아니다. **3,937개 전체의 목록 조사와601개 시각 검토는 구분한다.** 다른 분류는 대표 검토이며 모든 이미지/환경 장면을 확대 검토한 것은 아니다.

참고 래스터는 로컬 `test-results/wiki-resource-survey-v319/`에만 있다. 게임/public/게시 파일에 옮기지 않는다. 게임 이미지에 대한 위키의 권리 표시는 [NOTICE](../tools/research/stoneshard-v319/NOTICE.md)에 보존했다.

## 조사에서 그림·UI로 옮긴 것

적은 머리장식/무장/자세로 역할을 구분하고, 동물은 몸통·주둥이·다리의 비율로 크기를 읽게 한다. 작은 밝은 재질 덩어리와 어두운 틈으로 천·가죽·금속·털을 구분한다. 긴 무기는 정사각형에 압축하지 않고 실제 가방 칸의 세로 비율을 쓴다. 얼굴은 몸체 확대 대신 눈썹·코·볼·턱·머리카락/나이 표현을 별도로 그린다. 게임의 고유 인물·픽셀·팔레트 샘플·트레이싱은 사용하지 않았다. ASHVEIL의 성인 비율, 잿빛 재질, 살아 있는 환자와 기계 설정을 따른다.

총47새PNG,1,267새 프레임과 기존 물품 프레임30개의 대체다. 중복 별칭을 제외한26몸체가28CharDef에 연결되고,33Creature Def의 기본/별칭/휴면/이전sprite 경로를 모두 대조했다. 모든206물품·85지형·28능력·26UI의 매핑을 [프로젝트 전수 매핑](../tools/research/stoneshard-v319/ashveil-resource-mapping.json)에 남겼다. 나머지176물품과 기존 지형·능력·UI는 자체 원화를 유지한다. 이번 버전에서 이들 전부를 새로 그렸다고 주장하지 않는다. 지형 도감은 조합 렌더러의 대표 프레임이며 계절/성장/벽 조합 전체 장면과 다르다.

새 큰 몸체를 누르면 실제 표시된 불투명 픽셀에서 해당 개체의 논리 칸을 선택한다. 투명 여백은 선택하지 않으며 앞의 불투명 사물은 개체를 가린다. 현재 보이는 개체만 조회하고 숨은 개체를 누출하지 않는다. 동물의 그림 폭이 여러 칸에 걸쳐도 규칙상 충돌 크기를 바꾸지는 않는다.

가방의 세로/가로 칸과 회전은 원래 크기 규칙을 유지하고 아이콘만 그 칸 안에 비율대로 표시한다. 땅에 떨어진 물품도 정사각형 강제 확대를 제거했다. `heldItems`와 `portrait`은 클라이언트 CharDef의 표시 메타데이터다.319의 코어/콘텐츠는318과 같고 저장208을 유지한다.

## 원본·재현·확인

[그리기 코드/SVG/개별 디자인](../tools/art/direction-v319/) · [CC0](../tools/art/direction-v319/LICENSE.txt). 외부 이미지를 입력하지 않고 직접 SVG 좌표를 작성해 Inkscape로 PNG를 만들었다. `node tools/art/direction-v319/build.mjs --install` 뒤 `node --import tsx tools/art/export-public-artbook.ts`로 재현한다. 큰 DPI의 구성용 contact와 실제 native PNG 확대를 구분한다.

타입·대상 린트·Def·스프라이트·빌드를 확인했다. 실제 파일 계약은169시트/3,485프레임/28캐릭터/26UI/195고유PNG다. 원화 도감의4방향 정지·뒤쪽 걷기/공격 특정 프레임·초상·무기·첫 지형/능력/UI 페이지·모바일12PNG를 직접 열었다. 새 리소스의 모든 애니메이션 프레임과 모든 장비 조합을 전수 재생 검증한 것은 아니다.

`tools/inspect-art-scene-v319.ts`는 유한한 초기 각인(평평한 방·플레이어/경비·동물/기계/융합체·실제 무기/횃불/가방)을 실제 타이틀에서 불러왔다.1440×1080/1366×768 각각에서 I와 실제 마우스로 가방/머리 호버/투명 여백/머리 클릭을 확인했다. 불투명 머리는 경비를 선택하고 투명 여백은 석판을 표시했으며, 머리 클릭은 실제 대화100TU/플레이어 제자리·주민 창으로 이어졌다. 콘솔 오류0,12PNG를 생성했다. 이 중 최종 큰 타이틀·작은 가방/주민 창3장을 직접 열었으며, 앞선 동일 원화 큰 장면/가방2장도 열었다. 도감12장과 구분한다. 첫 시도는 던전 경비의 기본 적대 관계를 그대로 둬 공격이 발생했으며 진단 초기값에 명시적 calm을 설정한 뒤 다시 실행했다. 불러오기 뒤 세계/시각/좌표·난수를 주입하지 않았고 이 배치를 자연 플레이/사회 발생 빈도의 증거로 삼지 않는다.

사용자 지시에 따라 전체 회귀·World30/1000·새208/207 저장 전체 비교는 후속이다.318 최소 재고와317 동료 처치의 검증 대기도 유지한다. 개발 미리보기이며 v1.0.0 출시 완료가 아니다.
