# 같은 주민의 나이와 생일

v0.148은 새 인간형 NPC에게 조정 가능한 `CreatureDef.ageRange`를 적용한다. 인간 기본20~39세는 콘텐츠 기본값이며 정본의 새 수치 확정이 아니다. 플레이어는 기존 배경의 나이와 생성 난수를 유지한다. 동물/기계에 인간 노화 규칙을 붙이지 않는다. 구형 저장의 나이 없는 사람에게 현재 시점의 나이를 지어 넣지 않는다. 각인111→112는 버전만 이관한다.

이미 태어난 같은 생물의 나이·다음 생일·개인 기록을 보존하고, 실제 달력 생일을 지날 때 같은 Growth.Human의 면역/회복·노련함·능력치 감소·관절/감각 규칙을 적용한다. 플레이어의 기존 몸 난수와 별개인 `body.age.ID`를 사용하므로 NPC를 고용해 소속이 바뀌어도 나이 판정 흐름이 바뀌지 않는다. 생일 전 조회는 난수나 기록을 만들지 않는다. 활력이 줄면 현재HP도 새 상한으로 즉시 제한한다. 이미 모든 신체 능력치가1인 경우 빈 후보를 뽑지 않는다.

지역이 비활성인 동안 지나간 달력 생일은 다시 활성화된 몸을 실제로 처리할 때 각 날짜의 개인 기록으로 정산한다. 이를 과거의 신체 틱 전체를 실행한 것으로 주장하지 않는다. NPC의 개인 생일을 플레이어가 들은 말이나 로그로 꾸미지 않는다. 주민 창은 보이는 사람의 연령대만 표시한다. 원래 생물ID·소지품·시장 장부는 유지된다.

전용13/관련7파일126개·타입/린트·Def208패치/Schema124/오류0·빌드2.75초를 통과했다. 고정5개 초기와 최종 전체를 비교한 각12개 차이는 원래 NPC6명의 새 나이와 독립 난수6개뿐이며 기존 모든 필드/오류/플레이어 난수/물품/행동은 같다. [골든 전체 비교](golden-v148-diff.json).

브라우저 네 장면은 실제 생성한 원래 상인64의 생일이 임박한 유효 초기 장면이다. 과거 수십 년을 실제로 실행했다는 뜻이 아니다. 기본 난수 시드`npc-aging-proof-0`에서는 실제60세 생일에 활력10→9가 나와 같은 몸의HP95 상한을 확인하도록 준비했다. 화면720~723 네 장 모두 확인했고 생일 전/후·실제 활력10→9/HP95·미완료19턴 전체 재개 일치·4전체112 복원/콘솔0을 확인했다. 전체 회귀/월드는v149와 통합 검증했으며 v148 별도 전체 검사나 별도30판을 수행한 것으로 기록하지 않는다. 다른 영구 능력치 변화와 전체 후속 확장도 계속 진행한다.


v0.148–149에서는 같은 인간 주민의 생성 나이/실제 생일/노화와 기아7일 초과·회색열 실제 회복 후의 영구 능력치 변화를 연결했다. 각인112→113·전용28·통합 전체152파일2,972개142.97초·Def209패치/Schema124·화면720~728 아홉 장 전체 확인·9전체 복원/실제19턴과 회복 시 자연 중단되는9턴 재개 전체 일치/콘솔0이다. 통합 월드30판310.654449348초의 전체 결과가v147과 같다. v148 별도 전체 검사나 별도 월드30판은 실행한 것으로 기록하지 않는다.
