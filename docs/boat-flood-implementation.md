# 선체 침수·같은 승객 구조·원래 선체 복구

v0.97. X4의 침몰을 기존 실제 선체·수영·구조·현물 수리와 연결한다. 수치는 Coracle의 추가 Def 패치이며 정본의 확정 수치로 간주하지 않는다. 엔진 독립 코어와 기존 Pixi 화면을 유지한다.

바다 칸에서 실제 시간 경계를 넘으면 폭풍과 최소 내구 미만의 누수가 원래 선체를 마모시킨다. 기존 노 젓기 마모는 그대로다. 항구에 정박한 배에는 바다의 추가 마모를 적용하지 않는다. 원래 선체 내구가 정확히 0이 되면 같은 지도에서 갑판이 잠기고 실제 항해/자동 작업이 중단된다. 선체 UID, 승객, 몸, 위치를 새로 만들거나 바꾸지 않는다. 고정 조명은 꺼지며 설치 가구와 화물은 원래 물건 그대로 같은 칸의 바닥에 남는다. 손상된 선체는 별도의 물건으로 복제하지 않는다.

원래 선체의 네 지지 칸은 얕은 바닷물 위의 뼈대로 남는다. 나머지 갑판은 실제 깊은 바닷물이며 기존 젖음·에너지·호흡·착용 둔중·익사가 진행된다. CANON D22에 따라 가방 속 질량을 별도의 침강 수치로 쓰지 않는다. 깨어 있고 발을 움직일 수 있는 동료는 잠기거나 기력이 떨어지면 보이는 빈 뼈대까지 실제 경로를 걷는다. 두 칸 이상 떨어진 지지대도 찾으며, 포박·의식 상실·점유를 무시하지 않는다. 의식을 잃은 승객은 기존 구조 행동으로 빈 지지대로 끌어낼 수 있다. 부상·장비·몸을 교체하거나 치료하지 않는다.

소유자가 원래 지지대 위에서 손을 쓸 수 있으면 원래 목재를 예약하고 실제 시간 동안 선체를 기운다. 작업 중 위치·몸·원래 선체·수리 설정·목재 예약을 다시 확인한다. 완료할 때만 목재를 한 번 소비하고 같은 선체 내구를 복구한다. 항해 가능한 최소 내구가 되면 같은 갑판이 다시 떠오른다. 바닥 화물을 자동으로 선창에 되돌리지 않으며 부상·저산소증을 지우지 않는다. 실제 사망한 승객의 시신은 남고 산 승객의 출발만 검사한다. 살아 있지만 물속이나 다른 곳에 있는 승객을 원격으로 데려가지는 않는다. 복구된 원래 선창 칸도 승선 위치에 포함한다. 구조된 환자가 원래 선창 위치의 뼈대에 있던 경우에 출발이 막히지 않는다.

각인v61은 v60의 기존 데이터를 그대로 보존한다. 침수/재부상 시각과 실제 수리 예약은 기존 지도/활동에 저장한다. 구형 각인에 과거 침몰을 만들어 넣지 않는다.

20개 전용 코어 검사는 실제 폭풍 시간 경계·항구 보호·원본 몸/물건/화물 보존·실제 동료 이동/부상자 구조·목재 예약/소비·중간 각인 복원·생존/사망 승객 출발·바닷물 염도·착용 둔중·잘못된 선체 값·구형 변환을 확인했다. 실제 폭풍 경계부터 부상 승객 구조와 수리가 끝날 때까지 네 원래 인물이 모두 살아 있는 통합 흐름도 포함한다. 전체99파일1,660개86.50초의 최종 검사가 통과했다. 브라우저에서 드러난 정적 지형 층의 미갱신을 고쳤으며, 같은 지도의 실제 지형 ID가 바뀌면 바닥·고정물 층을 다시 만든다. 생물 화면 객체는 보존한다. 초기 수정에서 생물 화면 객체를 함께 지워 발생한 오류 기록은 보존했다. 실제 화면의 목재 바닥 수가 침수 중4칸·복구 후29칸(선창1칸 제외)으로 코어와 일치함을 검사한다. v0.97에서는 실제 폭풍/누수로 같은 선체와 갑판이 침수되고, 원래 승객 구조·빈 뼈대까지 실제 이동·예약 목재 수리/재부상·각인v61로 이어지게 했다. 전체99파일1,660개86.50초·관련48개·타입/린트/Def89패치/Schema87/빌드·화면392~399/8장·네 차례 전체 복원·실제 목재 화면4/29칸 일치·콘솔 오류0을 확인했다. 같은 최종 사본의 월드30시드×최대3일275.601949513초·30개 전체 행이v0.96과 같다. 월드 평균0.4219895833333334일·원인{'저체온': 19, '치명상': 5, '과다 출혈': 6}이다. 최종 검증은 변경하지 않는 v097-final 사본에서 실행했다. 최초 정적 층 갱신 누락과 중간 수정의 생물 화면 객체 삭제 오류는 최종 상태에서 해결했으며 실패 원자료도 남겼다.

해상 교역단, 월드 칸을 넘는 수영, 전역 해난 구조와 물·늪 생태 전체는 별도 후속 작업이다.
