# 실제로 알게 된 지역과 던전 층의 정찰 의뢰

v0.154는 정찰 지도 의뢰의 대상 목록을 실제 방문한 지상 지역·직접 탐험한 층·실제 읽은 지도 문서로 확장한다. 캐시에 미리 생성되어 있어도 보지 못한 층, 아직 읽지 않은 소지품 문서, 알려지지 않은 지역/층은 목록에 넣지 않는다. 목록 조회와 의뢰 생성은 실제 미방문 지형을 생성하거나 원격 방·거주자를 조회하지 않는다.

원래 탐험 장면/현재 층과 플레이어의 읽은 문서만 사용하는 읽기 전용 목록이다. 같은 지역/지도ID는 한 번만 게시한다. 알려진 층의 깊이 보수는 기본10×깊이이며 조정 가능한 PATCH다. 왕복 경로/예치금/시장 재고/원본 납품 규칙은 기존 정찰 계약과 같다. 읽은 문서가 현재 진실인지를 미리 판정하지 않는다. 실제 의뢰 결과물은 수락 뒤 그 지역/층에서 새로 시작하여 직접 그려야 하며, 원래 읽었던 남의 문서를 다시 팔아 정산하지 못한다.

각인117→118은 버전만 이관한다. 구형 각인에 과거 층 지식이나 정찰 의뢰를 추정하지 않는다. 전용12/관련3파일48개를 통과했고 실제 계단 입력의 탐험 층, 실제1턴 읽기/수락, 미생성crypt2/원본 보존과 저장 후19턴의 전체 일치를 확인했다.

브라우저와 전체 회귀·월드는v153–155 통합 검증으로 확인했다. v153별도 전체 회귀/월드30판을 실행한 것으로 기록하지 않는다. 함정 지도·전역 지도와 나머지 후속 확장은 계속 남는다.


v0.153–155는 원래 지도 원본/예치금의 정찰 납품·실제 탐험/읽은 문서의 층 의뢰·실제 유한 모닥불에서 나무로 옮겨 붙는 화재를 연결했다. 각인117→119·전용44개·통합 전체158파일3,072개146.43초·타입/린트/Def222패치/Schema126·실제 UI창/세계 캔버스20장면 전체 확인·17전체 복원/실제 재개59·19·19턴/콘솔0이다. 기본 확률0.02의 화재는 실제100턴 작업+140턴 대기 뒤 발화/230턴 더 지나 번짐/600턴 연소 뒤 소진과 실제 물500ml·소화 버튼1턴을 확인했다. 월드30판319.63681798199997초의30행 전체가v152와 같다. v153/v154별도 전체검사·월드30판은 실행한 것으로 기록하지 않는다. [통합 원문 비교](sim-v155-diff.json). 전체 뷰포트 캡처의 부분 합성 현상은 시각 근거에서 제외하고 실제 창 단위/게임 캔버스의 완전한 해당 장면을 확인했다. 원본 정적 제품과 검사 전용 캡처 변형의코어/빌드는 같으며, 실제 버튼/저장/재개는 전체 상태로 비교했다.
