매시간 실제 조종한 선체에 날씨에 따른 마모가 쌓인다. 최소 내구 아래에서는 더 이동하지 않고 실제 나무와 시간을 들여 수리한다. 원래 재료 UID와 수리 지침을 보존하고 완료 때 한 번만 소비한다. 잘못된 선체 상태로 출항하거나 수리해 유효한 상태를 만드는 것을 막는다. 침몰/익사·해전 전체를 구현한 것으로 집계하지 않는다.
