# 소금 해안 형제단과 실제 소금·염장

v0.89 / 각인v53. X4의 서부 소금 해안·형제단과03-survival §4.4 염장 규칙을 연결한다. 관련4파일124개와 수첩/기존 지역 순서 보완 뒤3파일109개·전체91파일1,517개116.92초·타입/린트/Def71패치·Schema82/빌드를 통과했고 고정5개 입력의 전체 상태 차이를 검토했다. 브라우저329~339의 화면11장과 세 차례 전체 각인v53 복원·콘솔 오류0을 확인했다. 실제 해안 걸음/급수·추위 보정480턴 증발(기본400)/24턴 준비(기본20)·염장 배치/마지막 한 턴의 회수 경계·원본 수첩25전 구매와240턴 완독을 검증했다. 이틀 경계 사례는 만료 직전 초기 조건으로 시작하며 브라우저가 이틀을 기다린 것으로 집계하지 않는다. 같은 월드30시드×최대3일263.285586239초·평균0.4219895833333334일·저체온19/치명상5/과다 출혈6이며30개 전체 최종 행이v0.88과 같다. 전체 첫 검사의 실패1곳은 기존 후속 지역4곳의 맨 끝 위치 기대값으로, 원래4곳의 순서와 새 해안의 마지막 위치를 함께 확인하도록 고쳤다.

소금 해안 장부소는 기존 지형과 시장 생성 뒤 세대4로 추가한다. 현재 서부 육지 중 바다와 실제로 인접하고 원래 출발지에서 도보로 닿는 칸을 고른다. 현지 지도에 이어진 깊은 바다/얕은 바다·갯벌/육지와 소금솥·형제단 주민/장부지기·파수꾼/간병인이 있다. 살아 있는 요약 인구120명 중 기존 시민 절차로 실체화하며 재방문/사망 뒤 복제하지 않는다. 기존 시장들의 UID 순서를 보존하고 새8개 재고 묶음만 뒤에 추가한다.

공용 소금솥의 제작은 실제35g/L 물1L·장작2개와400턴을 요구한다. 이 기본 제작법은35g 결과에 맞춰진 가열법이며 임의 농도의 모든 물을 자동 변환하지 않는다. 정량/염도·시간·연료·소금35g은 Def 설정이다. 현물 수첩을 읽어 배운다. 같은 물병의 UID·잔량·전체 수질·제작 규칙을 예약해 중단/저장/재개한다. 완료 때만 실제 물을 증발시키고 원래 빈 병을 남긴다. 물이 바뀌거나 얼거나 없어지면 남은 연료와 물을 소비하지 않는다. 증류수나 추가 병을 생성하지 않는다.

물에 있던 재의 실제 노출량은 소금에 남는다. 소금/고기 등 입력 조각의 양에 따라 다음 음식과 가공 배치에 분배되며, 조리하거나 저장해도 사라지지 않는다. 한 조각을 먹으면 그 노출량이 실제 신장의 재 축적에 더해진다. 같은 수치의 오염만 쌓을 수 있고 소금 질량/재 노출이 설명에 나온다. 가열은 병원체를 제거하지만 재를 제거하지 않는다.

기존 '생고기1+소금1→즉시 육포' 제작법은 정본대로 실제 생고기3회분+소금1→이틀 뒤 염장육3회분으로 바꾼다. 준비20턴 후 실제2일의 완료 시각을 갖는 유한 배치를 만든다. 이전 고기는 사라지고 회수 전에 완성품이 생기지 않는다. 이른/먼/중복 회수를 막고 중간 저장을 보존한다. 염장육은 한 칸/쌓임3·회분당300kcal/단백50g/비타민0/갈증400ml·실온 기본 부패 시간60일이다. 가장 나쁜 원재료 신선도와 해동/젖음·재를 보존해 상한 고기를 신선하게 되돌리지 않는다.

형제단 초기 시장의 소금20단위와 수첩1권은 실제 원래 UID 재고다. 소금은 기존 요약 저장고의 Salt 품목으로 한 번 인출하며 음식 가격/수요와 연결한다. 해상 운송/봉화 정보망·실제 정착지 염부의 자동 생산 전체·흐린 늪과 나머지 후속 전체는 이어서 구현한다.
