# 실제 전달된 역병 소식과 회색열 고아의 기억

v0.136.04 #70의 회색열 고아가 회색열 역병 소식을 처음 알게 되면−6/3일 기억을 받도록 연결했다. 소식은 질병/작성일을 명시하며 원래 글·출처 단계·지역·작성 시각을 보존한다. 일반 한국어 글에 회색열이라는 낱말이 있는 것만으로 종류나 진위를 추측하지 않는다. 다른 배경/다른 질병/같은 소식의 재탕은 새 기억이나 만료 갱신을 만들지 않는다. 만료 후 재탕도 같다. 다른 날의 새 유행은 다른 소식으로 받을 수 있다.

성공한 실제 대화에서 양쪽의 청각이 충분할 때만 전달한다. 현재 지도의 실제 현지 주민이, 전역 SIR에서 유행 중이며 현장에도 실제 봉쇄가 적용된 것을 보고 말할 수 있다. 적용 전 감염 수치, 다른 지역의 원격 SIR, 외지인의 고향 상황을 현지 목격으로 만들지 않는다. 현재 인원/정확한 감염률은 공개하지 않는다. 사람이 이미 알고 있던 이전 역병 소식은 현재의 진실로 덮어쓰지 않고 당시 출처와 날짜로 전달한다.

같은 수신 함수에 실제 쪽지 읽기와 실제 봉화 기록 읽기를 연결했다. NPC의 지식은 그 NPC에게만 남고 플레이어 지식에 몰래 복사하지 않는다. 봉화에 도착한 기록도 실제 읽기 전에는 지식/기억이 아니다. 원래 기록은 깊은 복사로 보존하며, 중복은 기존 id/지역 기준을 유지한다. 각인99→100은 버전만 이관하고 옛 글에서 과거 유행·인지·기억을 지어내지 않는다.

전용24/관련5파일104개 검사 통과. 봉화 검사에는 실제 전송/원래 게시판/별도 NPC 읽기/원본 질병 정보 보존도 포함한다. 화면용 봉화 장면은 명시적인 유효 초기 수신기록을 실제1턴 읽는 장면이며, 그 장면이 과거 전송을 실제 실행했다고 주장하지 않는다. 다섯 골든은 전체 초기/최종/오류 전부 버전100 외v135와 같다. v0.136에서는 실제 현지 봉쇄 소식의 대화/쪽지·봉화 읽기와 회색열 고아의−6/3일 기억을 연결했다. 같은 소식의 재탕·다른 배경/질병·원격SIR/읽기 전 인지를 막고 원래 출처/단계/작성 시각을 보존한다. 각인v100·전용24/관련104개·전체138파일2,675개135.97초·타입/린트/Def189패치/Schema112/빌드·화면647~652 여섯 장 전체 확인·6전체 복원/실제19턴 재개/콘솔0이다. 월드30판292.31735848999995초의 전체 기록이v135와 같다.
