# 실제 도구·개봉과 원래 통조림 용기

v0.107. 13 §4/엣지7의 사냥칼·녹슨 칼·손도끼와01 §4의2턴 개봉/중단 시 진행 손실을 연결한다. 이전의 맨손으로12턴 두드려 먹는 경로는 정본에 없으므로 제거했다. 새 개봉 상태와 빈 용기는13 §4.7에 등록했다.

밀봉 음식의 견적은 배낭의 실제 원본과 같은 실제 도구를 확인한다. 맨손/파손 도구/손을 쓸 수 없는 상태는 음식·몸·UID·난수를 소비하지 않고 거절한다. 실제2턴의 개봉을 마치기 전에는 영양을 주거나 내용물을 소비하지 않는다. 원래 도구를 잃은 진행에 다른 칼을 대입하지 않는다. 중단하면 같은 밀봉 음식이 남고 개봉 진행은 사라진다.

개봉 완료는 같은 원래 UID의 열린 음식으로 바꾼다. 도구/용기·원래 품질/내구·재 노출을 보존한다. 밀봉 동안 무기한이던 음식은 실제 개봉 시각부터24시간의 신선 기간을 사용한다. 바로 전체 식사가 이루어진 것으로 만들지 않는다. ‘통조림 따기’는2턴 뒤 열린 음식만 남기고, ‘먹기’는 실제2턴 개봉과 별도1턴 식사를 자동으로 잇는다. 개봉 뒤 식사 전에 중단하거나 저장할 수도 있다. 이후에는 남은 한 턴 식사만 한다.

실제 마지막 식사는 원래 한 회분의450kcal/단백25g/비타민2/물150ml를 기존 식단·흡수·식중독 규칙으로 실제 섭취자에게 전달하고 같은 UID의 빈 통을 남긴다. 다른 사람에게 먹이던 중 그 사람이 떠났다면 열린 음식은 그대로 남고 멀리 영양을 전달하지 않는다. 일반 음식과 다른 회분 용기는 기존 소비 방식을 쓴다. 자동 식사는 열 수 없는 밀봉 음식을 건너뛰며, 주민 식량 집계는 실제 남은 회분과 사용할 수 있는 도구를 함께 확인한다.

각인v71은 같은 음식/도구·진행 중 개봉·개봉 완료/식사 대기의 경계·몸·난수를 보존한다. 구형70의 과거 개봉/먹고 없어진 용기를 소급 생성하지 않는다. 기존5재현의 전체 초기/최종/오류는 버전70→71 외 동일하다. [골든 감사](golden-v107-diff.json).
