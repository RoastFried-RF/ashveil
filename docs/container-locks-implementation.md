# 원래 상자의 실제 잠금과 도구 작업 — v0.274 작업 중

설계13 §8/§21의 잠긴 상자를 기존 경비실 상자에 연결했다. 새 아이템/상자/전리품 표를 추가하지 않는다. 새로 생성하는 던전의 원래 `Terrain.GuardChest`에만 실제 잠금을 기록한다. 기존 지도나 이미 연 상자는 소급해 잠그지 않는다. 잠금 수치30작업턴/도구 내구5/10작업턴마다 소음6과 칼·도끼/망치 도구 태그는 조정 가능한 콘텐츠 기본 제안값이며 한 PATCH에 둔다. 정밀 자물쇠 따기/열쇠와 잠긴 문은 별도 후속이다.

수색(S)은 잠겨 있으면 실제 도구로 잠금쇠 벌리기를 시작한다. F2에는 실제 보이는 인접 상자/도구/필요 작업·마모를 표시하고 같은 작업을 실행한다. 거리/시야/모서리·몸/손·원래 지도/지역·같은 도구UID/남은 내구·원래 잠금 정의를 검사한다. 도구를 잃거나 다른 UID로 바꾸거나 상자 곁을 떠나거나 정의가 바뀌면 완료하지 않는다. 큰 소음은 실제 곁의 자는 인물을 깨울 수 있고 노동은 실제 대사/체온의 작업으로 분류한다.

마지막 작업 턴에만 원래 도구 내구를5 줄이고 같은 상자의 잠금만 푼다. 이 동작으로 물품/UID/내용물/수색 숙달/발견 보상은 만들지 않는다. 이후 별도 정상 수색에서 원래 상자의 전리품을 한 번만 결정한다. 이미 실제 물품이 든 잠긴 상자도 내용물을 교체하지 않는다. 잠긴 채 저수준 열기/낡은 루팅 선택으로 꺼내거나 넣을 수 없으며 실패가 배낭 물품을 바닥으로 버리지 않는다. 봇은 자기 도구로 열 수 없는 잠긴 상자를 반복 수색하지 않고, 실제 접근 가능한 목표를 좌표로 지정한다. 상자 내부 물품을 미리 읽어 접근을 결정하지 않는다.

각인185는 잠금과 진행 중 작업을 저장한다.184이하는 버전만 이행하며 구형 상자에 과거 잠금/물품/작업을 채우지 않는다. 원래 잠금 정의가 사라져도 실제 잠긴 상자를 조용히 열지 않고 정의 복원을 요구한다.
