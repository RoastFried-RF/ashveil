## 1. 재늑대 (Ash Hound) — CANON · 이번 프로토타입 출현 제외(Def 유지)

| 항목 | 값 |
|---|---|
| 분류 | 변이 야생동물 / 사족보행 |
| 체중·혈액량 | 28~36kg · 약 2,400ml (임계 15/30/40/50% 동일 적용) |
| 서식 | 고원 전역, 폐촌, 양치기 골 외곽. 긴겨울엔 정착지 가까이 |
| 무리 | 3~7마리, 우두머리 1 |
| 이동/공격 TU | 이동 60 / 물기 100 |
| 감각 | 후각 매우 높음(피 냄새 바람방향 최대 40칸), 청각 높음, 시야 보통 |

**행동 패턴**
- **배고픔**: 굶주림 → 사람에게도 정면 공격, 사기 손실 무시하고 2마리 남을 때까지 싸움. 배부름 → 시야에 들어와도 거리 유지, 소음에 회피(CANON).
- **사기**: 우두머리 사망 시 사기 −40. 무리 절반 손실 시 도주 판정.
- **무리 전술**: 1~2마리가 정면에서 짖어 주의를 끌고 나머지가 측면·후면으로 우회(방향 시스템의 측면/후면 보너스 활용). 출혈 중인 대상을 끝까지 추적.
- **피 냄새·소음 반응**(CANON): 출혈 중인 생물, 고음(휘파람·비명) 쪽으로 이동.

**공격**: 물기(찢김: 베기+찌르기 혼합, 출혈 높음, 다리 부위 가중), 넘어뜨리기(기력 낮은 대상에게 넘어짐 판정 → 넘어진 대상은 목 부위 가중)

**약점**

| 단계 | 약점 |
|---|---|
| L1 | 털이 두껍지 않음 → 베기·찌르기 모두 잘 통한다. 불을 꺼린다(횃불 든 상대에게 정면 접근 지연) |
| L2 | 우두머리(몸집 가장 큰 개체, 목에 흉터)를 먼저 쓰러뜨리면 무리가 흩어진다. 좁은 통로에 서면 우회 전술이 막힌다 |
| L3 | 재비 속에선 후각 −80% → 비 오는 날 이동하면 추적당하지 않는다. 고기를 바람 위쪽에 던져 무리를 갈라놓을 수 있다(배고픈 무리만) |

**전리품·해부**: 재늑대 가죽(회색, 재 털어냄 특성 — 외투 재때 누적 −30%), 고기 2~3kg(촌락 금기), 송곳니(장신구·화살촉), 힘줄(활시위 재료), 지방(장비 기름칠)

## 2. 굴쥐 (Burrow Rat) — CANON · 이번 프로토타입 출현 제외(Def 유지)

| 항목 | 값 |
|---|---|
| 분류 | 야생동물 / 사족보행(소형) |
| 체중·혈액량 | 0.6~1.0kg · 약 60ml |
| 서식 | 관로, 폐가 지하, 곡식 창고, 굴쥐 굴(퇴적물 층) |
| 무리 | 단독~군집 10+ (굴 안) |
| 이동/공격 TU | 이동 70 / 물기 80 |
| 감각 | 후각 높음(음식), 시야 낮음, 어둠 적응 |

**행동 패턴**
- 단독으로는 겁이 많아 사람을 피한다. **굴 안에서 막히면** 집단 공격.
- 음식 냄새에 끌린다 → 야영지의 열린 식량 자루를 밤에 턴다(식량 손실 사건).
- 잠든 대상, 의식 없는 대상을 문다.

**공격**: 물기(찌르기, 피해 낮음, **감염 위험 높음**(CANON) — 상처 청결도 기본값 "오염", 회색열 벼룩 전파 판정)

**약점**

| 단계 | 약점 |
|---|---|
| L1 | 한 대만 맞아도 죽는다. 진짜 위험은 상처 감염 |
| L2 | 물린 상처를 즉시 술·끓인 물로 씻으면 감염 확률 크게 하락. 식량은 매달아 보관하면 털리지 않는다 |
| L3 | 굴 바닥 퇴적물(굴쥐 똥)에서 **초석**을 얻는다(흑색화약 재료). 연기를 굴에 피우면 반대편 출구로 쏟아져 나온다 |

**전리품·해부**: 꼬리(유행기 포상 2고리), 작은 가죽(조각), 고기 0.2kg(기생충 위험), 퇴적물(초석 원료, 굴에서 채취)

## 17. 그늘 사람 (Shade-folk) — CANON 7.3 · **프로토타입 출현**

## 19. 말라붙은 자 (The Withered) — CANON 7.3 · **프로토타입 출현**

> ### 언데드가 아니다. **회색열 말기 환자**이고, **아직 살아 있다.**
> 숨을 쉬고, 피가 흐르고, 혈액 50%를 잃으면 죽고, 굶으면 약해진다. 플레이어와 같은 인간형 신체 규칙을 따른다. 연출에서도 언데드 표현(눈의 빛, 녹색 기운, 되살아남)을 쓰지 않는다(12 §10.2). 톤: 공포가 아니라 **비극**(world-bible §8).

| 항목 | 값 |
|---|---|
| 분류 | 인간 / 인간형(체격 0.8) — 회색열 **'정체' 경과** |
| 체중·혈액량 | 30~40kg · 2,500ml (피가 진하고 적다: 출혈 ×0.6) |
| 체온 | 34.5°C 상시(저체온 1단계, 03) |
| 서식 | 지하 2층 납골당(옛 병동)·3층 납골실. 공급원 **납골당 병동**(14 §9.4: 융합체가 살아 있으면 10일마다 +1) |
| 무리 | 단독~2(같은 방) |
| 속도 | 1행동 = 1턴 |
| 능력치 | 민첩 9 · 근력 9 · 지각 8 · 활력 7 · 의지 —(사기 없음) → 최대 HP (50 + 35) × 0.8 = **68**, 회피치 **−2** |
| 감각 | 시야 흐림, 소리, **물 냄새**(물병·물 끓이는 냄비를 가진 대상에게 끌린다) |

**의학적 설정**
- world-bible §5.2의 회색열은 잠복 → 발열 → 위기 → 결말(사망·회복)로 진행한다. 말라붙은 자는 **위기 단계에서 결말에 이르지 못하고 멈춘** 드문 경과(**정체**)다. 보통 환경에서는 위기 환자의 0.5% 미만이지만, 재의 겨울 때 수도사들이 쓴 **회색 가루** 처치에서는 약 30%, 융합체가 살아 있는 수도원 지하에서는 약 50%다. 정본은 world-bible §5.4(작가 메모: T2·T11).
- 살이 말라 뼈에 붙었고, 신경이 죽어 **통증을 느끼지 못한다** → 통증 기절 없음, 통증 명중 감점 없음, 사기 없음(도주·항복 없음).
- 그러나 몸은 살아 있다: 출혈·골절·장기 손상·혈액 임계가 그대로 적용된다. 쓰러뜨리면 **죽는다**(일어나지 않는다).

**행동 패턴**
- 소리 나는 쪽으로 천천히 배회한다. 잠듦이 많다(납골실 50%).
- **붙잡기**: 인접 대상의 팔을 붙잡는다(명중 판정 후 탈출 판정 = 근력·민첩 대결). 붙잡힌 동안 이동 불가, 기침 노출로 회색열 노출 판정 ×3.
- 물을 가진 대상을 우선 쫓는다.

**공격**: 맨손 타격 5, 붙잡기.

**방어**: 없음(마른 피부 타격 3).

**약점**

| 단계 | 약점 |
|---|---|
| L1 | 약하고 둔하다. 그러나 아파하지 않는다 — 쓰러질 때까지 온다 |
| L2 | 붙잡히지 마라(회색열 노출). 기절하지 않으므로 머리 강타보다 출혈(깊게 베기)·HP로 쓰러뜨린다. 다리를 노려 휘청이게 하면 다가오지 못한다 |
| L3 | **물을 주면 멈출 수 있다**: 인접해서 "물 주기"(1턴, 물 200ml) → 30% 확률로 적대를 풀고 주저앉는다(비적대 '휴식'). 목마름이 남은 유일한 감각이다. 융합체를 죽이면 더는 생기지 않는다. 납골실 석관의 이름패로 그가 누구였는지 알 수 있다 |

**처치의 무게**: 말라붙은 자를 죽이면 사고 "회색열 환자를 죽였다"(기분 −6, 냉혈 0, GDD §8.4). 물을 줘서 멈춘 경우에는 사고 "물을 나눴다"(+2).

**전리품**: 거의 없다 — 환자복 조각(천 조각), 이름 새긴 나무패(유품, 소문 단서). **인간 해부 금기**.

**도감 텍스트**
- S0 ???: "마른 사람이 벽에 기대 서 있다. 숨소리가 난다."
- S1 관찰: "말라붙은 자. 뼈에 가죽만 남았다. 그래도 숨을 쉰다."
- S2 전투: "베어도 소리를 내지 않았다. 피는 검고 진했다. 그리고 쓰러졌다 — 죽었다. 살아 있었다는 뜻이다."
- S3 해부: (해부 대신) "환자였다. 손목에 병동 번호가 새겨져 있다." — 기분 −8
- S4 문헌: "『잿빛 수도원 병동 기록』: 셋째 날에도 열이 내리지 않는 자들에게 회색 가루를 썼다. 열은 내렸다. 그들은 먹지 않고, 울지 않고, 죽지도 않았다."

## 20. 융합체 (The Amalgam) — CANON 7.3 · **프로토타입 출현(보스)**

> 수도원 지하에서 회색열 치료를 시도하다 생긴 **살덩이**. 대성소에 모인 환자 여럿이 회색 가루와 포자 속에서 하나로 엉겼다. 괴물이라기보다 **실패한 치료의 결과**다. 여러 사람의 몸이므로 출혈·장기·혈액 규칙이 그대로 적용된다.

| 항목 | 값 |
|---|---|
| 분류 | 인간 기원 / 융합형(§0.2) |
| 체중·혈액량 | 약 400kg · 18,000ml (임계 15/30/40/50% 동일) |
| 서식 | 지하 3층 **대성소**(13×11). 대성소를 떠나지 않는다 |
| 속도 | 1행동 = 1턴. 기저 살덩이로 끌며 이동 |
| 능력치 | 민첩 6 · 근력 18 · 지각 8 → 최대 HP **400**(고정), 회피치 (6 − 10) × 2 − 8(거대) = **−16** |
| 신체 | 머리 3(각 HP 30), 팔 4(각 HP 40), 몸덩이(내부: 심장 3·폐 다수). 6부위 대응: 머리 → 머리 3 묶음, 팔 → 팔 4 묶음, 다리 없음(비틀거림·넘어짐 면역, 밀쳐내기 면역) |
| 감각 | 머리 3개의 시야 → **등 뒤가 없다**(모든 방향이 정면: 측면·후면 명중 보정 없음), 후각 2, 진동 |
| 사기·통증 | 없음 |

**행동 패턴**
- **휩쓸기**(매 턴, 기력 없음): 인접 8칸 중 대상이 가장 많은 연속 3칸을 타격 16, 넘어짐 판정(07 §2.6). 남은 팔이 2개 이하면 연속 2칸.
- **붙잡기**: 팔 1개로 인접 대상을 붙잡아 매 턴 타격 8. 탈출 판정 근력·민첩 대결.
- **포자 분출**: 6턴마다 반경 3 포자 구름(농도 8, 4턴). 머리 하나가 부서질 때마다 주기 +2턴.
- 출혈한다: 살덩이 출혈(동맥 없음, 출혈 ×1.0). 피 냄새로 16칸 밖 출혈 대상을 감지(07 §9.2).

**사망 조건**: HP 0 · 혈액 50%(9,000ml) · **머리 3개 모두 파괴** 중 하나.

**방어**: 살덩이(날 5 / 타격 15 / 열 0). **화염 피해 ×1.5**.

**약점**

| 단계 | 약점 |
|---|---|
| L1 | 크고 세다. 등 뒤가 없어 돌아 들어가도 이득이 없다. 기둥을 사이에 두고 싸워라 |
| L2 | 포자 분출은 6턴 주기 — 턴을 세고 분출 직전에 물러나라. 출혈이 통한다(깊게 베기·흉포·다리 찍기 대신 **몸덩이**). 머리 셋(각 HP 30)을 부수는 것이 HP 400보다 빠르다: 급소 찌르기·머리 강타의 머리 가중이 여기서 빛난다 |
| L3 | 불에 ×1.5. 머리를 하나 부술 때마다 분출 주기가 늦어진다(6 → 8 → 10). 융합체를 죽이면 납골당 병동 공급원이 끊겨 말라붙은 자가 더는 생기지 않는다. 피를 흘리며 3층을 걸으면 16칸 밖에서 냄새를 맡는다 |

**전리품**: 수도원장 반지(13 §4 제안 아이템), 회색 가루가 묻은 정원사 캡슐 잔해(유물, 작가 진실 T2 단서), 수도원장의 마지막 기록(소문·도감 S4).
