> **결론 먼저**: 모든 생물·기계는 **플레이어와 같은 규칙**(신체 트리, 혈액량 비율, 스태미나, 사기, 배고픔, 체온)을 따른다. 약점은 숨겨진 보너스가 아니라 **그 몸의 구조에서 나오는 결과**다. 도감은 그 구조를 단계적으로 알려줄 뿐이다.
>
> 수치는 **제안값**이다. 최종 밸런스는 02·07 문서와 밸런스 봇이 정한다. 단, 혈액량 임계 비율(15/30/40/50%)은 CANON 상수로 모든 종에 동일 적용한다.

| **군체형** | 개체 수 = 체력. 부위 없음. 밀도·흩어짐 상태 | — | 재나방 떼 |

### 0.3 기계형 공통 규칙 (대칭성 번역표)

| 생물 개념 | 기계 대응 | 설명 |
|---|---|---|
| 출혈 | **유압액 누설** | 구동부·도구팔 손상 시 턴당 누설. 누설량 50%에서 해당 부위 정지. **바닥에 유막 흔적** → 추적 가능 |
| 통증·쇼크 | 없음 | 대신 **과열** |
| 스태미나 | **열량(0~100)** | 행동마다 열 상승, 대기 시 냉각. 100이면 강제 정지 2~4턴. 냉각핀 손상 시 냉각 −50% |
| 배고픔 | **동력 잔량** | 동력이 30% 미만이면 둥지·마디로 복귀 행동 |
| 사기 | 없음 | 도주 대신 "수리 복귀" 판정(손상 60% 이상) |
| 감염 | **부식** | 재비 노출로 장갑 내구 저하(장기) |
| 시야 | 센서 | 광학 센서 파괴 → 음향 센서만 사용(소리에만 반응) |

- 피해 유형 대응: 타격 → 장갑 변형·내부 충격, 찌르기 → 틈새 관통(관절·냉각핀), 베기 → 대부분 튕김, 화상 → 열량 직접 상승, 물(침수) → 동력핵 단락 판정.

### 0.4 행동 공통 변수

| 변수 | 범위 | 영향 |
|---|---|---|
| 배고픔 | 배부름 / 보통 / 배고픔 / 굶주림 | 교전 개시 임계, 도주 임계, 사냥 대상 크기 |
| 사기 | 0~100 | 무리 손실, 부상, 수적 열세로 하락. 임계 이하 도주 |
| 무리 결속 | 낮음/중간/높음 | 우두머리 사망 시 사기 하락폭 |
| 감각 | 시야·청각·후각 반경 | 은신·바람·소음 시스템과 대응 |

## 1. 재늑대 (Ash Hound) — CANON

| 항목 | 값 |
|---|---|
| 분류 | 변이 야생동물 / 사족보행 |
| 체중·혈액량 | 28~36kg · 약 2,400ml (임계 15/30/40/50% 동일 적용) |
| 서식 | 고원 전역, 폐촌, 양치기 골 외곽. 긴겨울엔 정착지 가까이 |
| 무리 | 3~7마리, 우두머리 1 |
| 이동/공격 TU | 이동 60 / 물기 100 |
| 감각 | 후각 매우 높음(피 냄새 바람방향 최대 40칸), 청각 높음, 시야 보통 |

**행동 패턴**
- **배고픔**: 굶주림 → 사람에게도 정면 공격, 사기 손실 무시하고 2마리 남을 때까지 싸움. 배부름 → 시야에 들어와도 거리 유지, 소음에 회피(CANON).
- **사기**: 우두머리 사망 시 사기 −40. 무리 절반 손실 시 도주 판정.
- **무리 전술**: 1~2마리가 정면에서 짖어 주의를 끌고 나머지가 측면·후면으로 우회(방향 시스템의 측면/후면 보너스 활용). 출혈 중인 대상을 끝까지 추적.
- **피 냄새·소음 반응**(CANON): 출혈 중인 생물, 고음(휘파람·비명) 쪽으로 이동.

**공격**: 물기(찢김: 베기+찌르기 혼합, 출혈 높음, 다리 부위 가중), 넘어뜨리기(스태미나 낮은 대상에게 넘어짐 판정 → 넘어진 대상은 목 부위 가중)

**약점**

| 단계 | 약점 |
|---|---|
| L1 | 털이 두껍지 않음 → 베기·찌르기 모두 잘 통한다. 불을 꺼린다(횃불 든 상대에게 정면 접근 지연) |
| L2 | 우두머리(몸집 가장 큰 개체, 목에 흉터)를 먼저 쓰러뜨리면 무리가 흩어진다. 좁은 통로에 서면 우회 전술이 막힌다 |
| L3 | 재비 속에선 후각 −80% → 비 오는 날 이동하면 추적당하지 않는다. 고기를 바람 위쪽에 던져 무리를 갈라놓을 수 있다(배고픈 무리만) |

**전리품·해부**: 재늑대 가죽(회색, 재 털어냄 특성 — 외투 재때 누적 −30%), 고기 2~3kg(촌락 금기), 송곳니(장신구·화살촉), 힘줄(활시위 재료), 지방(장비 기름칠)

**도감 텍스트**
- S0 ???: "회색 털의 네발짐승. 무리 지어 있다."
- S1 관찰: "재늑대. 개였던 것들의 후손. 다섯 마리가 서로 냄새를 맡으며 바람을 읽는다."
- S2 전투: "물면 놓지 않는다. 다리를 노린다. 우두머리가 쓰러지자 나머지가 머뭇거렸다."
- S3 해부: "비강이 사람 손바닥만큼 넓다. 털은 재를 거르는 촘촘한 속털과 기름진 겉털 두 겹이다."
- S4 문헌: "『양치기의 겨울 수첩』: 비 오는 날엔 늑대가 양을 찾지 못한다. 우리 할아버지는 재비가 오면 양을 바깥에 풀었다."

## 2. 굴쥐 (Burrow Rat) — CANON

| 항목 | 값 |
|---|---|
| 분류 | 야생동물 / 사족보행(소형) |
| 체중·혈액량 | 0.6~1.0kg · 약 60ml |
| 서식 | 관로, 폐가 지하, 곡식 창고, 굴쥐 굴(퇴적물 층) |
| 무리 | 단독~군집 10+ (굴 안) |
| 이동/공격 TU | 이동 70 / 물기 80 |
| 감각 | 후각 높음(음식), 시야 낮음, 어둠 적응 |

**행동 패턴**
- 단독으로는 겁이 많아 사람을 피한다. **굴 안에서 막히면** 집단 공격.
- 음식 냄새에 끌린다 → 야영지의 열린 식량 자루를 밤에 턴다(식량 손실 사건).
- 잠든 대상, 의식 없는 대상을 문다.

**공격**: 물기(찌르기, 피해 낮음, **감염 위험 높음**(CANON) — 상처 청결도 기본값 "오염", 회색열 벼룩 전파 판정)

**약점**

| 단계 | 약점 |
|---|---|
| L1 | 한 대만 맞아도 죽는다. 진짜 위험은 상처 감염 |
| L2 | 물린 상처를 즉시 술·끓인 물로 씻으면 감염 확률 크게 하락. 식량은 매달아 보관하면 털리지 않는다 |
| L3 | 굴 바닥 퇴적물(굴쥐 똥)에서 **초석**을 얻는다(흑색화약 재료). 연기를 굴에 피우면 반대편 출구로 쏟아져 나온다 |

**전리품·해부**: 꼬리(유행기 포상 2고리), 작은 가죽(조각), 고기 0.2kg(기생충 위험), 퇴적물(초석 원료, 굴에서 채취)

**도감 텍스트**
- S0 ???: "발치에서 무언가가 빠르게 움직였다."
- S1 관찰: "굴쥐. 사람 팔뚝만 한 쥐. 줄지어 관로 틈으로 사라진다."
- S2 전투: "약하다. 하지만 이빨 자국 주변이 벌써 붉게 부어오른다."
- S3 해부: "털 속에 벼룩이 들끓는다. 이빨 사이에 회색 가루가 끼어 있다."
- S4 문헌: "『제3 초소 총포공 수기』: 굴쥐 굴 바닥 흙을 걸러 끓이면 하얀 결정이 남는다. 화약의 3/4이 이것이다."

## 3. 약탈자 (Reaver) — 인간 템플릿 — CANON

> 모든 인간 NPC(촌민, 경비병, 길드원, 순례자)는 이 템플릿을 공유한다. 차이는 **장비·숙련·사기·AI 성향**뿐이다. 플레이어와 같은 신체 규칙(CANON).

| 항목 | 값 |
|---|---|
| 분류 | 인간 / 인간형 |
| 체중·혈액량 | 55~90kg · **5,000ml** (CANON) |
| 서식 | 검은 입(거점), 고개·다리(통행세), 폐촌, 도로변 매복지 |
| 무리 | 3~12명 (두목 1, 이빨 1~2) |
| 이동/공격 TU | 플레이어와 동일 공식(장비 무게·부상 반영) |
| 감각 | 인간 기준. 재 바른 얼굴 = 재 자극 면역(맛) |

**변종**

| 변종 | 장비 | 숙련 | 사기 | 역할 |
|---|---|---|---|---|
| 졸개 | 도끼/몽둥이, 누비옷 일부 | 낮음(10~20) | 낮음 | 수적 압박 |
| 투석꾼 | 투석구, 단검 | 원거리 20 | 낮음 | 후방 견제 |
| 이빨 | 갈고리창, 잡동사니 갑옷 | 중간(30~40) | 중간 | 측면 돌파 |
| 두목 | 좋은 무기 1개, 부분 금속 갑옷, 화기 1정(탄 1~3) | 높음(40~55) | 높음 | 지휘. 사망 시 무리 붕괴 판정 |

**행동 패턴**
- **배고픔**: 긴겨울엔 배고픈 무리 → 사기 낮지만 자포자기 돌격 확률.
- **사기**(CANON: 낮으면 쉽게 흩어짐): 두목 사망 → 60% 무리 붕괴. 다리를 다친 약탈자는 절뚝이며 도주 → 출혈로 쓰러질 수 있음(추격 판단).
- **항복**: 사기 0 + 부상 시 무기를 버리고 항복 → 포로/몸값/처형/석방(평판·기분 영향).
- **매복**: 병목·덤불·폐가에서 대기. 플레이어가 횃불을 들면 먼저 발견한다.

**공격**: 장비 따름. 베기(도끼), 타격(몽둥이·투석), 찌르기(갈고리창). 갈고리창은 **끌어당기기**(대상 1칸 이동 + 넘어짐 판정).

**약점**

| 단계 | 약점 |
|---|---|
| L1 | 갑옷이 부위마다 다르다 → 맨살 부위가 보이면 그곳을 노린다 |
| L2 | 두목을 먼저. 투석꾼은 근접하면 무력. 항복을 받아주면 정보를 얻는다 |
| L3 | 장물(다른 세력 표식)을 가진 약탈자를 죽이고 그 물건을 원래 세력에 돌려주면 평판 이득. 긴겨울 배고픈 무리에게 식량을 던지면 일부가 교전을 포기 |

**전리품·해부**: 잡동사니 갑옷 조각, 무기, 장물(표식), 이빨 목걸이(두목), 소량 식량, 탄 1~3발(두목). **인간 해부는 금기**(의료 숙련 경험치는 큼, 목격 시 모든 인간 세력 평판 −, 기분 −).

**도감 텍스트**
- S0 ???: "사람이다. 얼굴이 잿빛이다."
- S1 관찰: "잿빛 약탈단. 재를 바른 얼굴, 짝이 맞지 않는 갑옷."
