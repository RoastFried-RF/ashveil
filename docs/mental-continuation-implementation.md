# 실제 조명과 대화 관찰의 정신 효과

v0.131. 실제 위치의 조명 단계3(칠흑)일 때만−3이며, 야행성은 같은 조건에서+2이다. 밤+3/낮−2는 별도 조건이다. 밤의 실제 모닥불/등불은 칠흑 기분을 없애고, 한낮의 칠흑 던전에서는 기분이 적용된다. 조건 사고의 특성 수정치는 데이터와 검증으로 분리했다.

인간형 플레이어 진영의 실제 첫 생존 턴부터 무대화 관찰을 시작한다. 실제 성공한 대화만 양쪽 인간형의 마지막 대화 시각을 기록한다. 원격/수면/실신/죽음/적대의 실패나 조회는 기록하지 않는다. 관찰된3일 초과 이후 하루마다−1, 기본 최대−8이며 외톨이0/수다쟁이×2다. 매일 단계는 유예를 넘은 구간의 올림으로 센다: 정확히3일은0,3일+1턴은−1,4일은−1,4일+1턴은−2다. 구형 각인v94에는 과거 침묵/대화를 채우지 않고v95로 버전만 올린다. 일반NPC에게 플레이어 전체 정신 기록을 추가하지 않는다.

기도 기억은 정본12시간이며, 파문된 순례자뿐 아니라 신앙심 특성의 재비 노출200턴 기도 완료도+5를 준다. 기존 스트레스 완화는 보존한다. 도주 기억은1일/최대2회×0.5이고 겁쟁이0/무모−6이다. 항복 수용은 기존 패치가 이미+3/2일/2회×0.5여서 재변경하지 않았다.
