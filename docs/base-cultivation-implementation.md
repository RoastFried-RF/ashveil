# 거점 채집 동료의 실제 작물 관리

v0.182 구현·181–182 통합 검증 완료. 기존 거점의 실제 보관함/같은 유급 동료/채집 목표 배정을 사용한다. 새 종류의 추상 농부나 저장고 생산량을 만들지 않는다. 덜 자란 새 밭은gatherAt이 없다는 이유로 수확 대상으로 고르지 않는다. 같은 실제 품목의 다 자란 자원을 먼저 수확한다. 없는 과거 성장이나 관수를 만들어 넣지 않는다.

채집 목표가 남아 있고 실제로 보이는 거점 반경의 밭만 돌본다. 같은 몸으로 직접 걸어간 뒤 원래 개인 물 용기에서250ml씩 주며 본인 식수500ml를 남기는 제안 기본값을Def 옵션에 분리했다. 동료 자신의 식사·갈증·수면·전투 대응이 우선한다. 적을 보면 작업하지 않고 급료 만료/명령 변경/취소·실신/포로/손/다른 지도 조건도 따른다. 자기 물이 부족하면 원래 창고의 실제 용기 한 개를 꺼내 운반한다. 존재하지 않는 물을 원격으로 공급하거나 플레이어 개인 물병을 가져오지 않는다. 자신이 마실 수 있으나 작물에는 너무 짠 물만 있을 때도 실제 창고 담수로 해결한다. 물이나 공간이 없으면 대기한다.
