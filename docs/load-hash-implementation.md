# 불변 정의와 콘텐츠 로드 해시

v0.246 작업 중. 각인177/API1.4.0 유지. 실제 선택된 위상 정렬 패키지의 manifest·원본 Def·패치 순서·스크립트 원문을 정규화해 SHA-256 콘텐츠 로드 해시를 만든다. 객체 키 순서는 정규화하고 배열/패치 순서는 유지한다. 꺼진 모드와 실행 경로/조회용 WeakMap 메타데이터는 포함하지 않는다. 같은 실제 구성은 Node와 브라우저에서 같은 식별자를 사용한다. 엔진 버전·시드·입력까지 같을 때의 재현 구성을 식별하며 엔진 코드 전체 해시라고 부르지 않는다.

최종 Def는 DB가 소유한 깊은 사본을 재귀 고정한다. get/tryGet/종류별 조회는 같은 불변 값을 읽는다. all이 반환한 목록을 정렬/삭제해도 내부 목록은 바뀌지 않는다. 로드 순서/스크립트 원문 메타데이터와 해시 속성도 재할당·수정할 수 없게 한다. 실행기/등록 모듈의 정상 준비는 이 고정 데이터와 별도로 동작한다. 호출자 원본 패키지/정의를 고정하거나 보관하지 않는다. GameState의 mods는 DB 배열과 분리된 일반 저장 배열로 복사한다.

해시는 타이틀의 실제 선택 구성, Def 조회 보고서, resolve/validate CLI 결과에 제공한다. 오류가 있는 타이틀/조회 후보에는 유효 해시로 표시하지 않는다. 이 단계에서는 해시를 각인에 기록하거나 구형 각인의 과거 구성에 소급하지 않는다. 저장 헤더와 변경 감지 연결은 다음 후속 범위다. 물품/Def/신체/시간/규칙 수치·각인 버전을 바꾸지 않는다.

SHA-256은 엔진 독립 UTF-8/정수 연산을 사용하며 빈 문자열·abc·장문 표준 벡터와55/56/63/64/65/127/128바이트·백만 바이트 경계, 한국어/비BMP/고립 surrogate·임의 문자열250개를 Node crypto와 대조한다. 실제 전체 선택 패키지의 정규화 내용도 Node SHA-256으로 독립 대조한다. 규칙 난수를 소비하지 않는다.

최초17개 중15개가 통과했고 둘은 검사 준비 문제였다: fast-check 콜백이 assertion 값을 반환하던 형식과 존재하지 않는 db.recipe 편의 호출을 수정했다. SHA 알고리즘을 바꾸지 않았다. 이후17개+기존 관련101개가 모두 통과했다. 기존 의족 검사 한 곳은 DB의 icy를 직접 바꾸던 준비를 같은 실제 false 패치 구성 재로드로 바꾸어 불변 정책을 유지했다. 실제 이동/미끄러짐 배율 검사는 그대로다. 최종 전체 패키지 독립 대조 한 개를 추가한 전용18개와 실제 CLI/모드 패키지/로딩까지 관련11파일146개가 모두 통과했다.

기존5개 전체 골든 초기·최종·오류·해시는 저장177까지245와 완전히 같고 벡터·해시를 갱신하지 않았다. 최종 정적 검사·실제 화면과244–246 통합 회귀는 준비 중이다. 범용 로드 변경/세이브 호환 UI·나머지 전체 확장은 계속 남는다.

실제 최종246 빌드의1231–1233 세 장 전체 확인/전체177복원1·Node/브라우저 실제 전체 패키지 SHA-256 동일/정의·해시 변경 차단/all목록 격리/게임·스크립트 전체 동일/콘솔0을 통과했다. 통합 전체·월드 회귀 검증은 실행 중이다.244/245 단독 전체·월드 실행은 주장하지 않는다.
