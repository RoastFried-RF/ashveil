# 자율 구현 추적

현재 사용자 지시는 프로토타입/X1–X4를 포함한 v1.0.0까지 구현을 계속하는 것이다. 구현을 우선하고 전체 회귀·World·1,000판은 뒤로 모으며 큰 묶음으로 push/Pages에 반영한다. 오래된 ‘남음’ 문구는 현재 코드와 대조하고, 구현/자동 검증/사람 평가를 구분한다. 정본과 전체 출시 조건은 [CANON](CANON.md), [실행 기준](v1-execution.md)에 유지한다.

| 항목 | 현재 작업/근거 | 이어서 닫을 범위 |
|---|---|---|
| X1 응급 처치·구조 | v324 구조/처치 + v325 실물 의료 보급 + v326/328 환자 선택·진찰/1회 투약·외과 처치·중단/당시 소견 | 반복 돌봄/수술 계획, 실신자 들것/지도 경계 |
