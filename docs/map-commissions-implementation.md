# 직접 작성한 원본 지도의 정찰 계약

v0.153은 정본06의 지도 작성 결과물을 정찰 계약에 납품하는 경로를 연결한다. 실제 방문한 지역의 지상 지도만 게시하고 미방문 지형을 만들거나 현장의 현재 정답을 조회하지 않는다. 기존 공급/현장 조사 계약과 같은 정착지당 진행1개 제한, 실제 장부/몸/위협/거리 조건을 공유한다.

수락1턴에서 원래 시장 지갑의 보수를 예치한다. 수락 뒤 해당 지역에서 새로 시작한 지도 작업만 의뢰ID와 작성자의 몸ID/이름/세계 시드를 붙인다. 수락 전 중단 초안은 나중에 재개해도 새 계약으로 바꾸지 않는다. 종이/잉크와60턴 작업은 원래 지도 작성 경로를 그대로 사용한다. 이미 적힌 남의 지도나 옛 문서/다른 지역/다른 의뢰/기준 미달 지도는 거절한다. 몸과 원래 종이가 실제로 없어지면 예치금은 그대로 남는다.

납품1턴에 같은 원본 종이UID와 문서를 원래 시장 재고로 옮기고, 예치한 보수만 플레이어 지갑으로 정산한다. 장부에는 당시 수신 문서의 사본과 원본UID를 남긴다. 다시 납품하지 못하며 같은 정착지의 완료된 같은 지역 정찰 보수를 반복 청구하지 못한다. 문서를 받았다고 NPC에게 읽은 지식을 자동 부여하지 않는다. 취소/기한/사망의 예치금 반환은 기존 공통 원장을 쓴다. 납품으로 새 경험치나 숙달을 주지 않는다.

기본 보수20+거리×2, 왕복 실제 경로 시간+7일 여유, 신뢰도40/방 또는 계단1곳/평판2는 Cartography.Hearth.commission PATCH의 조정 가능한 기본값이다. 일부가 누락된 지도는 실제 그려진 내용으로 자격을 확인하며 원격 진실로 오차를 채점하지 않는다. 후속의 전역 지도/모든 던전 정찰 계약/함정 지도 경제 전체를 완성한 것으로 쓰지 않는다.

정착지 장부와 일지에 조건/예치금/납품/취소/불가 이유를 표시한다. 각인116→117은 버전만 이관하며 과거 의뢰나 지도 작성자를 추정하지 않는다.

전용16/관련4파일66개가 통과했다. 유효 초기의 실제 생성 정착지 탐험 기록을 두고 실제 공개 수락1+지도 작성60+납품1=62턴, 원본 종이110/잉크111의3→2, 소지금1000→1020/금고300→280과 예치금0을 확인했다. 과거 탐험까지 실행했다는 뜻은 아니다. 미완료 첫1턴 뒤59턴과 납품의 전체 저장 복원이 같다. 브라우저와v153–155 통합 전체회귀/월드 검증을 완료했다.


v0.153–155는 원래 지도 원본/예치금의 정찰 납품·실제 탐험/읽은 문서의 층 의뢰·실제 유한 모닥불에서 나무로 옮겨 붙는 화재를 연결했다. 각인117→119·전용44개·통합 전체158파일3,072개146.43초·타입/린트/Def222패치/Schema126·실제 UI창/세계 캔버스20장면 전체 확인·17전체 복원/실제 재개59·19·19턴/콘솔0이다. 기본 확률0.02의 화재는 실제100턴 작업+140턴 대기 뒤 발화/230턴 더 지나 번짐/600턴 연소 뒤 소진과 실제 물500ml·소화 버튼1턴을 확인했다. 월드30판319.63681798199997초의30행 전체가v152와 같다. v153/v154별도 전체검사·월드30판은 실행한 것으로 기록하지 않는다. [통합 원문 비교](sim-v155-diff.json). 전체 뷰포트 캡처의 부분 합성 현상은 시각 근거에서 제외하고 실제 창 단위/게임 캔버스의 완전한 해당 장면을 확인했다. 원본 정적 제품과 검사 전용 캡처 변형의코어/빌드는 같으며, 실제 버튼/저장/재개는 전체 상태로 비교했다.
