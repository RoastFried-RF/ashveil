# 실제 물림·거품병의 숨은 잠복과 원래 상처의 응급 처치

v0.100. 설계02 §11·§12와 거품병 JSON 예시·§632/643의 전파10/80%, 잠복10~40일, 1시간 안 세척 후 소작의 확률 절반, 발병7일 사망을 실제 공격·처치·몸·화면·각인에 연결한다.

실제 재늑대/우두머리의 물림 상처가 생겨야 한 번 판정한다. 옆에 서 있는 것만으로 전파되지 않는다. 원래 공격자·상처 UID/부위·노출 시각·예방 기한·한 번 뽑은 판정·잠복 시계를 피해자에 보존한다. 상처가 아물거나 절단되어 사라져도 전파 시계가 지워지지 않는다. 작은 물림끼리 합쳐질 때 원래 상처 별칭과 예방 기한을 이어 간다.

실제 원래 밀주를 사용해 해당 상처를 씻은 뒤, 같은 상처를 실제로 소작하는 데 성공해야 예방한다. 다른 상처의 세척, 과거에 남은 washedAt, 소작 후 세척, 실패/중단/열원 소실, 1시간을 넘긴 처치는 이 예방을 만들지 않는다. 완료 시 새 판정을 뽑지 않고 원래 확률을 절반으로 줄인다. 여전히 감염될 수 있고, 화상·흉터/통증이라는 실제 소작의 대가도 그대로 생긴다. 1시간 경계의 처치는 유효하고, 다음 턴부터 원래 판정을 확정한다. 이미 잠복한 병은 뒤늦은 처치로 지우지 않는다.

잠복 중에는 질병 창·상태 칩·진찰에 거품병을 표시하지 않는다. 아문 원래 물린 자리가 쑤신다는 일반 단서만 신체에 나타난다. 병명을 확정하는 검사나 잠복 종료일까지의 카운트다운을 주지 않는다. 실제 발병 턴에 같은 질병이 드러나고, 매 턴 발병 후 시각으로 진행을 계산한다. 부동소수점 누적이나 시간 단위 반올림으로 일찍 죽이지 않으며, 정확한 발병7일 시각에 실제 코어 사망과 생애 보고서로 이어진다. 일반 항생제와 턱굳음 혈청으로 치료하거나 자연 면역을 만들지 않는다. 정원사 유물 치료는 정본에서 결정되지 않았으므로 새 완치법을 발명하지 않았다.

기존 종의 실제 생성 때 독립된 시드 스트림으로 드물게 거품 개체를 정한다. 같은 종/개체/몸을 유지해 개체 수를 늘리지 않고, 입에 거품 문 외양은 종을 모르는 플레이어도 실제로 볼 때 알 수 있다. 거품 개체의 물림 전파율80%와 일반10%는 설계 수치다. 거품 개체 생성률5%·아문 자리 통증1은 변경 가능한 Def 기본값이며 정본 확정 수치가 아니다. 정본 CANON7.3의 현재 기본 재늑대 출현 제외는 유지한다. 다른 미완성 에셋을 대신 끼워 기본 출현을 강제하지 않는다. 실제 생성/공격 경로와 모드로 활성화된 개체에도 같은 규칙을 쓴다.

각인v64는 진행 중 실제 소작과 원본 도구/세척 잔량·원래 판정·기한·잠복/발병 시계를 보존한다. 구형63은 버전만 올리고 과거 물림이나 감염·거품 개체를 만들어 넣지 않는다. 기존 다섯 재현의 전체 초기/최종 상태·오류를 대조했으며 버전63→64 외에는 같다.

22개 전용 검사와 관련176개를 통과했다. 타입·린트·Def95패치·Schema90파일·빌드를 확인했다. 전체102파일1,729개97.25초 검사가 통과했다. v0.100에서는 실제 재늑대 물림의 원래 공격자/상처·단 한 번의 판정·10~40일 숨은 잠복·1시간 안 원본 밀주/소작의 확률 절반·아문 자리의 일반 단서·실제 발병/정확한7일 사망과 보고서·각인v64를 연결했다. 전체102파일1,729개97.25초·전용22개/관련176개·타입/린트/Def95패치/Schema90/빌드·화면418~427/10장·여섯 차례 전체 복원·콘솔 오류0이다. 같은 검증용 사본의 월드30시드×최대3일285.08838797600004초·30개 전체 행을 대조해 30개가 같고 0개의 실제 변경을 검토했다. 월드 평균0.4219895833333334일·원인{'저체온': 19, '치명상': 5, '과다 출혈': 6}이다. 최종 브라우저와 월드 검증은 변경하지 않는 v100-ui 사본에서 실행했다. 최초 v100 사본의 규칙/타입스크립트 소스는 최종 사본과 바이트 단위로 같고 CSS의 탭 분할만 다르다. 원래 투명 위10/아래7픽셀 여백을 테두리 영역으로 잘라 글 위로 장식선이 늘어나는 화면 오류를 수정했다. 첫 브라우저도 실제 경로가 통과했고 최종 수정 화면을 모두 다시 확인했다. 첫 추가 검사에서 테스트가 기계 몸에 존재하지 않는 Frame 부위를 지정한 오류를 실제 Body의 첫 부위로 수정했다. 브라우저 준비용 시나리오에서는 초기화로 바뀐 HP 상한 정산을 실제 첫 대기 턴으로 마친 뒤 소작을 시작한다. 앱의 ‘다쳤다’ 중단 규칙을 우회하지 않는다.

이 작업에서 골절 후 눕기 판정에 실제 ‘누워 있기’ 붕괴를 포함하고, 여러 발열 질병이 있으면 가장 높은 현재 목표 체온을 사용하도록 보완했다. 높은 발열이 치료된 뒤 오래된 effect의 목표를 계속 재사용하지 않는다. 기존 질병의 즉시 발열 방식과 새 질병의 점진적 열 교환 구분은 보존한다.

나머지 장기 질병·위생/영양·사회 및 전체 후속 확장 기능은 계속 구현한다.
