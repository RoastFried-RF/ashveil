# 실제로 들은 자기 이름 소문

v0.146은 새 평판 사건에 실제 행위자의 생물ID·이름·월드 시드와 사건 지역을 저장한다. 재산 침해·공격·포로 석방/처형·증거 제출·친족 목격의 기존 실제 사건 경로에만 붙인다. 친족 소식은 전달 지역이 아니라 처음 목격한 지역을 보존한다. 과거 각인의 주체 없는 사건에서 현재 플레이어를 추측하지 않는다.

대화 상대는 같은 세력의 직접 목격 사건 또는 이미 현지에 도착한 사건을 실제 거주 지역에서 말할 수 있다. 직접 목격자는 전역 평판 반영을 앞당기지 않고 자기가 본 일을 전할 수 있다. 개인적으로 이미 들은 소식은 당시 내용·출처·작성일을 유지하여 재전달한다. 전역 평판의 조회/적용만으로 플레이어의 지식이나 기억이 생기지 않는다.

공통 소식 습득 경로는 대화·원래 쪽지의 실제 읽기·봉화 기록의 실제 읽기를 처리한다. 명시적인 소문의 당사자ID·이름·시드가 현재 인물과 모두 맞고 사건ID/부호가 유효할 때 `Thought.NameRumor`를 만든다. 좋은 소문은+4, 나쁜 소문은−4, 5일 고정·최대2중첩/다음 중첩×0.5다. 두 부호가 같은 슬롯을 공유한다. 같은 소식은 기억이 만료한 뒤에도 다시 보상하지 않는다. 단순히 이름이 들어간 글이나 다른 생애의 소식에는 적용하지 않는다.
