# v356 유한 파종 정책과 정면 관절 시제품

개발 묶음이다. 기본 게임의 활성 종 수는 v348과 같고, 파종기를 실제 새 개체로 배치하지 않았다. [공개 정면 시제품](https://roastfried-rf.github.io/ashveil/artbook/rig/)과 규칙 엔진의 정책을 각각 구현했다. 다른 방향·실제 지도·행동별 손상 외형까지 연결한 완료 기록이나 v1.0.0 출시 승인이 아니다.

파종 정책은 CreatureDef.sower와 실제 기계 몸/신호부/공구/파종팔을 요구한다. 순수 Core에서 기존 제어 회로 고장 분기를 거친 뒤 일반 수리 드론의 잔해 운반·공격 판단보다 먼저 실행한다. 종 ID를 분기하거나 새 기계를 생성하지 않는다. 경유지는 보통 이동으로 가며 실제 도착 행동이 대기 비용을 쓴다. 벽·물·문 열기·실패한 걸음은 파종 이동 횟수가 아니다. 경로를 막은 곁의 대상은 기존 밀치기 확률과 두 칸 이동/충돌 규칙으로 밀고, 이 행동만으로 구역 경계를 높이지 않는다.

네 번의 실제 이동 뒤에는 배낭의 원래 캡슐 한 개를 공유 설치/재배 경로로 소비한다. 판단과 실행이 같은 읽기 전용 placementQuote를 사용한다. 바닥이 적합하지 않으면 남은 재고와 대기를 유지하며 경로를 계속 간다. 작물은 원래 종자 UID/소유자/심기 전 바닥과 성장·물 상태를 남긴다. 여덟 개를 모두 쓰면 더 심지 않는다. 저장·지도 이동·반복 사망/해체는 종자를 재발행하지 않는다. 돌바닥에 떨어진 캡슐이 계절 뒤 자동 군락으로 바뀌는 생태는 아직 추가하지 않았다.

관찰한 실제 새 상처의 공격자에게 경보 행동을 한 번 수행한다. 같은 상처의 재요청은 무료 경보가 되지 않는다. 원래 전원·신호 부위가 기능해야 하며, 실제 구역 경계 원장과 반경 안의 살아 있고 전원이 켜진 같은 세력 측량기의 안테나를 사용한다. 호출은 당시 파종기 위치를 기록하며 숨은 공격자의 현재 위치를 측량기에 알려주지 않는다. 측량기는 자기 감지/관찰 정책으로 판단하고, 관찰할 대상이 없으면 기록된 호출 지점 쪽을 조사한다. 호출은 전역 시각의 유한 기한이 지나면 만료한다. 빗나가 상처를 만들지 않은 공격의 전용 경보 기억은 후속이다.

곁의 실제 공격자에게 균 분사를 할 때도 별도의 원래 균 캡슐 하나를 소모한다. 기존 포자 구름과 턴별 기침/기력·질병 노출을 사용하며, 새 분사는 실제 시선이 통하는 칸에 한정한다. 열용접이나 직접 약물 피해로 꾸미지 않는다. 원래 UID/소모 시각과 재사용 기한을 저장한다. 경유지 노동과 분사 재사용은 지도와 함께 정지하는 전투 시계에 맞추고, 실제 원문 소모 시각은 바꾸지 않는다. 기존 포자 노출의 보호구/농도 모델을 새로 완성한 것은 아니다.

저장 형식213은 원래 경로 계약·작업·캡슐·호출 기록을 보존한다. 구형 각인에 종자/기계/과거 행동을 채우지 않는다. 진행 중 정책이 바뀌면 이전 계약을 임의 해석하지 않고 해당 작업을 보류한다. 실제 기본 콘텐츠 활성 전에 지역별 경로/회수 부품/재배 토양과 관찰 UI, 실제 입력·전체 상태 비교를 연결해야 한다.

정면 관절은 image_gen 원문 PNG1장의 차체/upper/lower/foot4영역을 사용한다. 원문 바이트·프롬프트·참고·관측 핀과 가려진 힙 추정은 tools/art/direction-v356에 구분해 보존했다. 네 다리에 세 부품을 공유하며 authored 보행 프레임은0개다. 원화를 수정하거나 새 PNG로 잘라 다시 그리지 않았다. 실제 source축이 기울어져 있어 두 금속 핀을 투영 hip/knee/ankle에 정확히 맞춘다. 고정17.5+17.5 길이의 물리 링크를 투영하고, 그 화면 길이만 바뀐다. 진짜 가변 피스톤 stroke를 제작했다는 뜻이 아니다.

거리20당 네 발이 LH→LF→RH→RF로 회복한다. 각 발은 지지 중 world 접촉점을 유지한다. 회복 전에 몸을 지지 다각형으로 옮기고, 발을 다시 둔 뒤 몸을 돌아오게 한다. 내부 접촉점을 포함하는 오목한 각도 정렬 대신 실제 convex hull을 사용했다. 정지하면 진행 중인 한 발만 마저 내려놓고 세계 위치를 유지한다. 긴 표현 프레임을 작은 거리로 분할하며 순간 이동/지도 교체에는 새 소유자가 필요하다. 가정한 무게중심/기하의 지지 여유이며 실제 동역학이나 최종 시각 품질 보증이 아니다.
