# 모드 오류를 시작 전에 표시하고 각인을 보존하기

v0.190 구현. 정본design/11의 ‘실패를 먼저 보여준다’와 중복/상속 검증을 연결했다. 선택한 모드가 없어도 조용히core만 불러오거나, 의미 오류를 경고만 하고 세계를 생성하던 경로를 막는다.

검사용`inspectDb`는 리포트와DB를 반환한다. 실행용`buildDb`는 오류가 있으면 새 게임/각인 복원의 세계 대입 전에 거절한다. 시작 화면은 오류 내용을 표시하고 미리보기/시작을 막으며, 잘못된 모드를 끄면 정상 구성으로 다시 검사한다. 실패한 새 게임은 현재 세계·화면·기존 각인을 바꾸지 않는다. 필요한 저장 모드가 없으면 이어서 하기에 해당ID를 표시하고 원래 각인을 보존한다.

로더는 선택된 모드 누락, 활성manifest ID 중복, Def ID 중복, 알 수 없는 타입, 다른 타입 부모, 다른 모드 부모의 의존성 미선언을 오류로 보고한다. 전체 교체는`override: true`를 명시하고 리포트에 남겨야 한다. 보통 변경에는 패치를 사용한다. 상속 의존성은 마지막 패치 모드가 아니라 원래 정의 모드로 판정한다. 같은 타입의 정상 상속·명시한 의존성·선택하지 않은 모드는 기존대로 동작한다.
