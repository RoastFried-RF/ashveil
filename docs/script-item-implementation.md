# 실제 원래 물품을 소비한 뒤의 컴포넌트 · v0.228 / 각인165

ItemCompWorker.onConsume의 첫 연결은 기존 consumeFor의 음식·음료·약·기름·알약 사용 경로이다. 실제 원래 물품의 사용 전/후 수량·회분·물량을 비교해 감소한 성공만 전달한다. 실패·빈/얼어 있는/없는 물품·사본/개봉 시작은 실제 콜백을 호출하지 않는다. 개봉한 음식의 실제 결과 Def에는 자기 worker 참조가 필요하다.

제공자와 소비자/원래 쌓음 UID·Def/감소량을 읽기 전용으로 전달한다. 자기 JSON데이터·모드 하위 난수·추가 명령은 기존 격리 예산과 원자적 목록 검사에 따른다. 실패한 콜백은 자기 효과를 적용하지 않고 원래 완료된 소비/영양/빈 용기를 유지한다. 배우는 실제 현재 객체만 허용한다. NPC에 적용한 생각은 기존 NPC 정신 이력에 남고 플레이어 생각 목록을 대신 쓰지 않는다.

구형 여러 회분 음식의 uses생략은 실제 Def 회분 수로 읽는다. 마지막 회분은 같은 UID의 원래 빈 용기로 변환한다. 쌓음을 나눠 소비할 때 기존 코어가 소비 단위 UID를 할당하는 동작도 보존한다. 콜백의 uid는 원래 쌓음/용기의 출처 UID이다. 예제는 원래 육포 참조만 패치하고 새 Def·사람·아이템을 추가하지 않는다.164각인에는 버전165만 올린다.
