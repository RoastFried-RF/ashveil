# 키 반복 지연·속도 · v0.212 / 각인153 유지

접근성 정본의 키 반복 설정을 실제 게임 키 입력에 연결했다. F3에서 운영체제 기본/지연·속도 제한/한 번만 실행을 선택한다. 기본은 기존 입력 방식이다. 제한 방식은 최초 반복 지연0–2000ms와 반복 간격50–1000ms를 설정하며, 한 번 방식은 실제 키 해제 후 다시 눌러야 다음 게임 행동이 가능하다. 기본 지연500ms/간격125ms는 사용자 화면 설정이며 코어 시간이나 게임 균형의 정본 수치가 아니다.

실제 브라우저 keydown만 통과/거절한다. 타이머로 행동을 생성하거나 늦은 입력을 여러 턴으로 보충하지 않는다. 방향뿐 아니라 실제 배정된 게임 키에 적용하고 키 배정/왼손 배치를 보존한다. 키별 시계를 따로 관리하며 키 해제/포커스 상실/가시성·설정 전환/화면 제거 때 눌림 상태를 정리한다. 설정에서 누른 채 돌아온 반복 입력은 새 최초 입력 전까지 실행하지 않는다. 설정 조작은 턴을 쓰지 않는다.

각인과 별도인 기존 환경 설정 키에 저장하며 구형 설정은 기존 방식으로 읽는다. 잘못된 열거/무한값은 기본값, 범위 밖 지연/간격은 유효 범위로 읽는다. 코어/콘텐츠/각인153은211과 동일하다. 새 Def/Item/패치/각인 이관은 없다.

반복 경계·키별 시계·해제/설정 전환·시각 역행/손상·밀린 행동 미생성과 구형/손상 설정·기존 재배정/왼손 배치 관련24개가 통과했다. 최종 타입/린트/빌드3.25초가 완료됐다. 최신213/각인153의 실제 화면1044–1047 네 장을 모두 확인했다. 전체153복원4/실제 대기7턴(한 번2·제한2·왼손1·기본2)/설정 조작의 전체 코어 불변/콘솔0이다. 실제 keyboard.down 반복과 해제/재입력·최대지연2000ms/간격1000ms·왼손S·설정 지속/기본 복원을 검사했다. 최신 통합 전체/월드 회귀는 진행 중이다.
