# 실제 수면 상태와 공통 기상 — v0.46

일반 수면 활동을 시작해도 `asleep`을 켜지 않아 `canSee`와 대화 판정에서 깨어 있는 것으로 취급하던 문제를 고쳤다. 플레이어와 NPC 모두 잠든 순간 눈을 감는다. 자발적 수면도 약물 수면/처음부터 잠든 생물과 같은 상태를 사용한다. 일반 수면을 취소하면 즉시 시야를 되찾고 기존 잠기운을 받는다. 긴 활동 진행 표시에 공통 중단 버튼을 제공하고, 다른 창/표적/전리품 처리를 마친 Esc도 현재 활동을 중단한다. 약기운으로 스스로 깰 수 없으면 기존 규칙의 이유를 표시하며 강제로 우회하지 않는다.

NPC의 수면 활동도 소리/피격, 허기·갈증 단계 악화, 위험한 체온·통증·젖음, 완전 회복과 예정 시간 종료를 처리한다. 깨어난 NPC가 수면 활동을 계속해 다시 회복하지 않으며, 마지막 실제 수면 시간은 기존 피로/체온/대사 규칙으로 정산한다. 소리·피격으로 깊은 잠에서 이미 받은20턴 잠기운을 활동 정리 때10턴으로 덮어쓰지 않는다. 정상 수면의 침대 대여 만료도 기존 공통 검사로 적용한다. 실제 약물 강제 수면의 자연 만료도 공통 기상으로 연결해 시야/기상 시각과10/20턴 잠기운을 남긴다. 약효·용량·신체 규칙은 유지한다.

보이지 않는 NPC의 수면 종료는 플레이어 기록/지식을 새로 만들지 않는다. 보이는 주민의 현재 모습과 대답할 수 있는 상태는 기존 관찰/대화 규칙을 따른다. 주민의 정해진 취침 일과·개인 침대/주거·공공 배급·교사는 별도로 남아 있다.

각인v13은 v2~12를 변환하며 이전 수면 활동에서 실제 수면 상태만 맞춘다. 몸·현금·물·물품·수면 경과는 유지하고 이미 소리/피격으로 깨어나기로 한 활동의 표시는 덮어쓰지 않는다. 활성/비활성 지도와 저장된 지역 장면을 모두 처리하며 재변환하지 않는다. 기존5고정 입력의 초기/최종 차이는 버전12→13뿐이고 명령·오류·물리 상태는 같다(`golden-v046-diff.json`).

검증9개는 즉시 닫히는 시야/취소 복구, NPC 수면 회복/종료, 소리 기상과20턴 잠기운, 상처 수 증가 없는 기상, 내부 신호/회복, 비공개 종료, 약물 수면 자연 만료의 기상/잠기운, 중간 각인의 동일 결과, 구형 수면만 보정하는 변환을 다룬다. 전체45파일710개가27.91초에 통과했고 lint·타입/빌드도 통과했다. 숙박 브라우저77~80/85~86과 설정은 콘솔 오류0이다. 실제 Z수면→시야0·중단 버튼으로 즉시 시야 복구→재수면·자연 기상·각인 복원을 확인했다. 잠든86화면도 직접 확인했다. 30시드×최대3일은240.023764569초, 평균0.42021412037037037일·생존0/저체온19/치명상5/실혈6이며 v0.45와30시드의 원인·시간·레벨·지도가 같다. 봇이 이용하지 않은 NPC 수면/약물 기상은 별도 단위로 검증한다.
