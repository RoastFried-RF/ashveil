## 무엇이 디테일한가 (일부)

- 상처는 하나하나가 개체다. 왼쪽 대퇴 동맥이 베이면 붕대로는 안 멎는다. 지혈대는 두 시간 넘기면 아래가 썩는다. 켜진 등불에 칼을 달궈 지지면 출혈은 멎지만 화상과 비명이 남는다.
- 손가락을 잃으면 조작 능력이 떨어지고, 손을 다치면 붕대 감는 데도 오래 걸린다.
- 젖은 옷은 단열의 70%를 잃는다. 방수포 망토 아래 옷은 훨씬 천천히 젖는다. 고철 사슬옷을 내피 없이 입으면 냉기가 스민다.
- 적은 정해진 방에 산다. 잠든 그늘 사람에게 잠행으로 다가가면 명중 +40, 첫 타 피해 1.5배. 그늘 사람은 등불 빛 안에서 겁을 먹는다. 약탈자 야영지의 경비는 14칸 넘게 쫓아오지 않는다.
- 다리를 다치면 회피가 떨어지고 걸음마다 비틀거릴 수 있다. 화면 좌상단 인형의 색이 부위 상태다.
- 적도 같은 규칙으로 피 흘리고, 절뚝이고, 겁먹고 도망친다. 궁지에 몰린 약탈자는 무기를 버리고 항복한다.
- 알약의 색과 효과는 시드마다 섞인다. 먹어보거나, 의료 숙달로 감별하거나.
- 죽으면 사망 보고서가 원인 사슬을 보여주고, 연대기에 남는다.

## 실행

```bash
pnpm install
pnpm dev            # 브라우저에서 플레이
pnpm test           # 단위·속성·결정론 테스트 (105파일 1783개)
pnpm sim 30 3       # 헤드리스 봇 밸런스 리포트 → docs/sim-latest.txt
pnpm validate-defs  # 콘텐츠 Def 검증 (모드 id를 인자로)
```

조작: 방향키/hjklyubn/숫자패드 이동·공격, 맵 클릭 자동 이동, `1~0` 빠른 슬롯, `F3` 화면 설정, `F2` 제작·정비, `C` 캐릭터, `I` 소지품, `Shift+K/B/J` 능력·신체·일지, `s` 뒤지기, `e` 모두 가져가기, `g` 줍기, `t` 등불, `>` 계단, `.` 대기, `r` 휴식, `z` 수면, `?` 도움말.
