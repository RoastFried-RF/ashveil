# 같은 물병의 실제 급수·정수와 창고 식수 보급 — v0.72

거점 동료에게 식수 재고 목표를 맡긴다. `BaseWater.Hearth` 기본은 입력1단위1000ml, 병원체0·재 오염10 이하의 얼지 않은 실제 물이다. 기준은 모드로 조정할 수 있다. 단순 병 개수로 식수 재고를 세거나 한 병으로 여러 병 분량을 채운 것으로 보지 않는다. 기존 거점 재고와 남은 실제ml를 합산한다. 끓였어도 재가 높다면 목표에 포함하지 않는다.

동료는 실제 빈/오염된 병을 자기 배낭이나 창고에서 찾아 운반한다. 물병이 없으면 기다리며 병을 만들지 않는다. 자기 눈으로 볼 수 있고 실제로 접근할 수 있는 반경 안의 수원으로 걸어가 공통1.5턴 급수 행동을 쓴다. 같은 UID의 병이 실제 수원 품질과1000ml로 채워진다. 원격/닫힌 모서리·얼음 구멍이 없는 언 물·수원 없음은 급수를 대신하지 않는다. 덜 찬 병을 꺼냈다 되넣는 반복도 실제 보충 없이 목표가 늘지 않는다.

원래 물병을 실제로 여과하고 끓이거나 정수정으로 처리한다. 재가 높으면 실제 숯/천 여과 도구가 있어야 낮추며, 병원체 제거는 끓이기/정수정을 쓴다. 갖고 있지 않은 도구나 연료는 직접 창고에 돌아와 확인해 꺼낸다. 도구·연료가 없으면 대기하며, 아직 오염된 작업 물을 갈증 때문에 먼저 마시지 않는다. 실제 도구 사용/잔량과 완료 시 연료 소비·처리 시간·물 품질은 기존 공통 정수 규칙이다. 침전은 이 능동 작업에 포함하지 않는다.

끓이려면 실제 열이 있는 장소로 이동해야 한다. 꺼진 화덕/막힌 경로는 물을 끓이지 않는다. 얼어 있는 같은 병도 실제 끓이기로 녹인다. 처리 중 같은 물병의 잔량/오염이나 도구가 달라지면 공통 조건으로 중단한다. 급료 만료/취소·위협은 작업을 건너뛰거나 연료/물품을 무료로 바꾸지 않는다. 중단한 정수는 그 회차의 노동을 다시 해야 한다.

기준을 채운 실제 병을 창고에 돌려놓아야 목표가 줄어든다. 같은 병/물 잔량과 실제 재고를 보존하며 물병·연료·도구와 현금/인물을 추가하지 않는다. 다른 작업자의 실제 식수 소비나 반출로 줄어든 재고는 다시 보충한다. F2에서 입력 단위/식수 보급 배정과 실제 목표ml·상태를 보여 준다. 개인 식수 목표를 공공 정착지 배급으로 세지 않는다.
