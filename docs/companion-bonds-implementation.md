# 동료 관계·성향 충돌과 들은 태도 — v0.61

X1의 고용한 사람과 함께 살아가는 관계를 실제 시간/행동에 연결했다. `CompanionBond.Hearth`가 초기 관계·상하한/종료·공유 시간·일일 긍정 한도·급료·성향 쌍과 사기 계수를 정의한다. 수치는 임시 조정값이며 CANON의 미확정 평판 단계나 NPC 정신 전반을 확정하지 않는다.

깨어서 의식이 있고 가까이서 서로 볼 수 있었던1200턴(1시간)을 채워야 관계가 누적된다. 매 실행 틱을 세므로 원격/비활성 지역의 달력을 건너뛴 시간을 무료로 보상하지 않는다. 중간 공유 시간은 저장한다. 기본+1/같은 성향+1·성향 충돌 합계를 적용하고, 긍정은 하루3점까지다. 냉혈/다정·피 냄새에 취함/다정은−3, 외톨이/수다쟁이는−2라 실제 조합에 따라 누적 결과가 다르다. 양쪽 방향에 같은 쌍을 적용한다. 시간 호출을 반복하거나 해고/재고용해서 점수/일일 한도를 초기화할 수 없다.

새로 생성한 정착지 주민에게만 인물별 `body.personality.<id>` 스트림으로 성향 하나를 배정한다. 기존 특성이 있으면 보존하며 이미 살아온 구형 주민을 방문 때 다시 굴리지 않는다. 공통 TraitDef이므로 해당 성향의 기존 몸/전투 효과도 그대로다. 초기 인물 생성/전리품의 다른 난수 스트림을 섞지 않는다. 동료 간 모든 관계나 일반 NPC 정신 요약 전체는 후속이다.

실제 급료를 직접 받으면+1, 선불 만료 시 한 번−5다. 거절한 지급은 관계도 바꾸지 않는다. 관계의20점마다 사기±1(상한±5)을 적용한다.−25 이하가 되면 같은 인물/물품/현금을 남기고 고용을 끝낸다. 선불은 환불하지 않으며, 이런 관계를 새 고용료로 초기화할 수 없다. 고용주의 유효한 공격 시도는 맞고 빗나감과 관계없이 계약을 끝내고 실제 반격/목격 평판 규칙으로 넘어간다. 동료의 아군 판정을 악용해 안전하게 공격할 수 없다.

N창에는 내부 점수나 이후 변화를 바로 보여 주지 않는다. 실제 대화 때 청각/의식/각성/접근을 검사하고 그때 들은 태도와 날짜만 남긴다. 이후 사적인 변화가 생겨도 다시 이야기하기 전의 기록은 과거 그대로다. 관계 사건 이력은 NPC 소유이며 모든 사건을 전역 로그로 알리지 않는다. 플레이어의 공격이나 눈앞에서 계약을 끝내는 결과는 알린다.

각인v27은26의 몸/성향/계약/착탈을 보존하는 순수 이관이다. 구형 계약에 과거 친밀도를 지어내지 않고 새 누적을 시작한다. 관계·공유 시간/상한·들은 태도·배신/이별 기록을 저장한다. 기존5골든의 전체 초기/최종 상태 차이는 버전26→27뿐이며, 원래 명령/오류는 유지한다(`golden-v061-diff.json`).

새 관계18개·Def1개를 추가했다. 성향 스트림·실제1200턴·중복 틱/달력 건너뛰기·원격/벽/수면·대칭 충돌/같은 성향·일일 상한·급료/만료·동일 몸으로 이별·사적인 변화/대화·실제 공격/목격·읽기 전용 사기·중간 저장·재고용/구형 각인과 실제 한 시간 공통 스케줄러를 검사한다. 집중82개와 전체62파일961개(36.33초)가 통과했다. 린트/타입/빌드·Def/Schema56파일 오류0이며 기존5골든의 전체 상태는 버전 외 동일하다. 고정 코드의 브라우저139~145/설정은 콘솔 오류0으로 통과했고144를 시각 확인했다. 실제 한 시간 휴식 동안 내부 관계−2/실제120000TU와 과거 태도 유지, 실제 대화1턴 후 새로운 태도, 전체 인물/난수/시간/UID 저장 복원의 일치를 확인했다. 성향만 충돌 쌍으로 준비했으며 몸/식수/시간은 실제로 진행한다. 원래 고용/물품/지역 왕복 검증도 함께 통과했다. 같은 고정 코드의30판×최대3일은178.115029166초에 완료했다. 평균0.419056712962963일·3일 생존0·저체온19/치명상5/과다 출혈6이며 v0.60의30개 결과는 최종 세부 상태까지 모두 같다. 봇은 동료를 고용하지 않으므로 기존 규칙 회귀이며 관계의 실제 동작은 별도 단위/브라우저로 검증한다.
