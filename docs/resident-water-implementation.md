# 주민의 실제 우물·급수 — v0.49

갈증 난 주민은 가진 비알코올 음료를 먼저 마신다. 쓸 물이 없으면 아는 공용 우물까지 걸어가 기존 빈 병을 채우고 실제로 마신 뒤 업무 자리로 돌아간다. 물병이 없으면 우물에서300ml를 직접 떠 마신다. 더러운 손을 씻을200ml가 부족해도 급수한다. 경비는 보이는 적에 먼저 대응하고 민간인은 먼저 피한다. 의사의 의료용 술을 식수로 쓰지 않는다.

우물은 거처 주변의 안전한 빈 자리에 한 번 설치한다. 덮개로 비·눈·얼음을 막지만 물 자체를 멸균하지 않는다. 기존 WaterSafety의 우물 수질(병원체10/재5)을 적용하며 인접 시체의 오염도 반영한다. 끓이기·여과·음수 노출·이질/재 축적은 기존 공통 규칙이다. 주민의 자동 끓이기·연료 보급은 다음 작업으로 남는다. 장기 안전한 식수 확보가 끝났다고 세지 않는다.

실제 병 UID/1000ml 용량·200ml 사용량·수질을 보존한다. 채우기는150TU이며 기존 내용물을 버리고 새 물을 담는다. 직접300ml 음수는200TU다. 새 병·돈·공공 물품을 생성하지 않는다. 빈 병과 손이 없거나 길/수원에 접근하지 못하면 무료 물을 얻지 않는다. 현재 부족 판단500ml·손 씻기 보충·배치 반경3·실패 후1시간은 임시 Def 값이다.

먼 우물의 현재 지형·얼음 상태를 미리 읽지 않는다. 아는 위치로 실제 접근한 뒤 인접 거리/시선/막힌 대각 모퉁이/실제 수원을 재확인한다. 선택 수원 좌표를 기존 채우기/음수 행동에 선택적으로 전달하므로 우물 옆에 웅덩이가 있어도 선택한 우물 물을 담는다. 기존 좌표 없는 행동도 유지한다. 양손 기능이 부족하면 물을 뜰 수 없다.

N의 우물 창은 실제 우물 곁에서만 열리며 직접 음수와 각 소유 병의 채우기를 제공한다. 현재 잔량과 기존 물 폐기를 알리고, 수질 설명은 기존 지식 공개 규칙을 쓴다. NPC가 물을 뜨더라도 플레이어 기록이나 비밀 지식을 대신 얻지 않는다. 각인v16은 병·수질·급수 경로/재시도와 몸·기존 식량 원장을 보존한다. 구형 몸이나 병에 새 물을 부여하지 않는다.
