# 실제 침구 화재·그을음과 유한 물 소화

v0.119. 실제 설치한 유한 모닥불의 연료가 남아 있는 동안 인접한 마른 침구에만 불씨를 판정한다. 출처 없는 옛 빛·꺼진 불·교체된 꾸러미·연료 만료·벽 뒤/막힌 대각선·두 칸 간격·젖음50% 이상은 발화하지 않는다. 재질은 원래 설치 물품의 실제 주재질을 우선하고 원래 지형 침대는 등록한 재질을 쓴다. 새 수치는 [13 등록](design/13-inventory.md)의 콘텐츠 제안값이다.

200턴마다 가연성3 기준2%를 독립 fire 지도/칸 스트림으로 판정한다. 실제 나무의 기본 확률은2%×2/3다. 같은 턴 재처리/각인 재개로 실패 판정을 다시 굴리지 않는다. 발화 때만 전역 사건UID 하나를 만들며 고정 지형 침대에 가짜 물품을 만들지 않는다. 같은 침구/실제 물품UID·원래 불UID·발화/마지막 관찰 시각을 보존한다. 실제 화염의 빛과 기존 불꽃 애니메이션이 표시된다.

실제 연속 관찰된 턴만 같은 침구를 태운다. 기본 가연성3 침구는400턴, 나무는600턴이고 기름천은 같은 가연성 아마포보다1.5배 빠르다. 타는 동안 원래 모닥불이 꺼져도 침구 자체가 탄다. 그을음은 수면 질/단열을 낮추고 실제 포장·재설치에도 남는다. 타는 침구는 접거나 포장할 수 없다. 전소하면 원래 실제 바닥으로 돌아가며 원래 물품과 주민의 침대 소유 기록을 잃고 새 물품/전리품을 주지 않는다.

불 위에 실제 있는 몸만20턴마다 기존 해부학적 화상 규칙을 적용한다. 기계형은 기존 기계 열손상 변환을 사용한다. 새로운 가까운 가시 화재는T5, 실제 화상은T2로 자동 행동을 중단한다. 정상적인 안전한 모닥불은 이 위협이 아니다. 다른 생성 지도에서도 같은 실제 침구/사람이 타며 상처/화재의 전역UID를 한 번씩 반영한다.

F2에 실제 가연성·그을음·불붙음과 물200ml 소화 견적이 나온다. 깨어 있는 손·시야/인접 조건과 실제 얼지 않은 비알코올 물이 있어야 한 턴에 쓴다. 물가에 실제 서 있으면 수원을 쓴다. 음수/영양/정수 노출을 만들지 않고 같은 침구를 젖음100%로 만들며 그을음은 남긴다. 실패는 시간·물·물품·난수를 바꾸지 않는다. 빈 물병은 같은UID로 남는다.

각인v83은 실제 화염/같은 침구/그을음·불씨 판정 시각을 보존한다. 구형82에 과거의 화재나 새 물품/사건UID를 소급하지 않는다. 기본 콘텐츠/기본 확률 actual-bedding-fire-1에서 실제120턴 점화 노동과79턴 휴식 뒤14600턴에 발화·실제20턴 뒤 화상1·물200ml 소화/800ml·그을음3.3333333333333313 보존과 전체 복원을 확인했다.
