# 흑색화약 단발 화기 구현 기록

v0.280 단발 화기의 전체314파일5,706개와 실제 화면5장/전체188복원2·공통 하네스8장 검증을 통과했다. 월드30판429.17192325초도 통과했으며279와30개 전체 결과 행·평균·사인이 같다. 별도281 산업 화기 작업은 이 결과에 포함하지 않는다.

## 정본과 기본값

CANON의 탄1발≈하루 식량, 07 §7.1/§10의 부싯돌 장총 총상22/관통45/7턴/소음30, 수제 흑색 불발12%×젖음배율2+floor(오염/10), 발사 오염+4/최대100, 걸림max(0,오염−40)/2%, 해소2턴, 청소6턴+총기 기름1개를 따른다. 02 §5의 총상 출혈2.5/통증1.5/오염25/치유1.2/흉터40%, 사출구50%·잔류 탄두·장기×1.5·골절×2를 연결한다. 방어는 기존 날 방어이며 절반 방어는 타격으로 바뀐다. CANON D33의 동맥 문턱은 유지한다.

13 전체708행을 읽고 새 장총/납탄/화약1회분/총기 기름4종의 칸을 먼저 등록했다. 납탄과 화약은 별도 실물이며 납을 연철 재질로 바꾸거나 숯만으로 화약을 만든 것으로 처리하지 않는다. 원본 아이콘은 독립 제작 패키지에서 가져온다.

정본에 없는 콘텐츠 기본값: 유효8/최대18칸, 정확도8, 기력8, 무기 가치240·내구100, 납탄 가치18+화약25=한 발43표, 기름18표. 실제 건빵350kcal/6표에 비례하면2500kcal는42.857…표다. 정수8개2800kcal의48표와 구분한다. 사기 충격은 실제 총성을 들은 적대자에게−10/30턴으로 제안한다. 가격/사거리/충격은 정본 확정값이 아니다.

불발/걸림의 정본 미정 경계는 다음 구현 기본값으로 명시한다. 조회는 순수하다. 실제 발사 입력에서 현재 오염의 걸림을 먼저 판정하며 걸리면 장전탄은 남고2턴 해소가 필요하다. 걸리지 않았으면 불발을 판정한다. 불발은 장전된 화약을 태운 실패로 두 재료를 잃고 오염+4, 기력8/행동1턴을 쓴다. 정상 발사만 소음30/총상 전투를 수행한다. 걸림 입력도 기력8/1턴을 쓰되 오염·탄은 보존한다. 기본 청소는 오염을0으로 만들고 걸림 해소를 대신하지 않으며 장전된 실물을 지우지 않는다.

새 화약은 건조하고 장전 완료 때 실제 젖음 값을 함께 보존한다. 보호된 배낭/닫힌 용기에는 비 노출을 추정하지 않는다. 표면의 실제 재비·물 노출과 건조만 양의 경과 시간에 정산한다. 젖음30 이상을 젖은 화약 기본값으로 삼는다. 구형 각인에는 탄/화약/오염 이력을 채우지 않는다.

총상 사출구는 같은 명중부위에 추가 외부 총상을 남기되 원래 피해를 두 상처에 분배해 HP/심각도를 복제하지 않는 기본값이다. 장기 판정은 기존80% 상한을 곱셈 전에 적용한 뒤 최대100%; 골절은 기존 최종90% 상한을 유지한다. 사출구가 없으면 탄두 이물질을 남기며 추출해도 완성 납탄을 생성하지 않는다. 기계는 기존 관통 손상으로 변환하고 인간 출혈/탄두를 생성하지 않는다.

## 남은 범위

현재 단위는 단발 장총의 운용을 먼저 완결한다. 회전식 권총/볼트식 소총, 공장 실탄/재생탄, 실제 납 주조/화약 제조, 화약 인화·폭발·연기와 산업 작업장 탄약 생산/수리 전체는 후속 구현 대상이다. 이 파일의 작성이나 새 Def만으로 완료 표시하지 않는다.

경비대 시장의 새 유한 재고 기본값은 장총1/납탄6/화약6/총기 기름2이며 일일 생산·소비0이다. 기존 시장에 없는 물품을 불러오기로 채우지 않고 새 실제 재고 생성에만 적용한다. 장전된 탄두와 화약은 단순 Def ID가 아니라 원래 한 개의 전체 ItemInst를 loadedRound에 보존한다. 공급 검색에는 노출하지 않고 거래 가격/정의 제거 검토/UID 검사/저장에는 실제 내부 실물로 센다. 전체/실제 브라우저 검증 근거는 [280 검사 기록](release-v280-proof.json)에 있다.

첫 정의 검사에서 기존 Item 스키마의 필수 legacy `weight` 메타데이터3곳이 누락된 것을 확인했다. 장총3.5/납탄0.025/화약0.005/기름0.1kg는 조정 가능한 자료 기본값으로 채웠으며, CANON D22대로 운반/과적/행동 시간 제한에는 사용하지 않는다. 첫 실패 로그는 보존한다.
