# 실제 패치 미리보기와 validate 보고서

v0.243 작업 중. 각인177/API1.4.0 유지. Def 조회의 ‘패치 적용 미리보기’와 `pnpm --silent defs validate [modId ...] --json`은 실제 로더의 원본 사본에 적용된 패치 순서/결과를 보여 준다. 원본 파일·현재 게임·모드 선택·저장을 쓰지 않는다. CLI validate는 기존 격리 실행기로 선택 스크립트 등록까지 검사하며, 조회 화면은 스크립트 실행 검증을 포함하지 않는다.

각 패치는 실제 적용/조건 건너뜀/실패와 모드·파일·JSON 배열 항목·연산·이유, 상속 전 원시 정의의 실제 값 차이를 제공한다. 세 조건 ifModLoaded/ifModNotLoaded/ifDefExists의 건너뜀을 성공으로 세지 않는다. 누락 대상·실패한 경로·부분 병합 실패는 실제 오류를 유지한다. 실패한 원본 사본은 값과 출처를 남기지 않는다. 같은 값으로 성공한 적용은 상태 applied와 차이0을 함께 표시한다. 합성 _mod만의 변화는 실제 콘텐츠 차이로 내보내지 않는다.

참고 경고는 실제 성공한 replace가 같은 경로에 서로 다른 JSON 값을 쓰는 경우(앞뒤 실제 패치 항목 포함), 숫자 인덱스형 경로, 최종 자식에서 다른 출처/삭제로 가려진 부모 스칼라 replace다. 객체 키 순서만 다른 값은 충돌로 보지 않는다. 배열 이동을 자식 가림으로 추정하지 않는다. 선택자·숫자 배열 경로와 객체/배열 전체 replace의 가림은 경고 범위 밖이다. 경고는 적용 실패가 아니며 로드 결과를 바꾸지 않는다. 전체 구조적 의미 충돌 탐지라고 주장하지 않는다.

실제 원시 사본은 audit 옵션을 요청했을 때만 복사한다. 기본 로더·DB·GameState·스크립트 설정 해시에는 붙이지 않는다. 화면은 모드/대상/경로·상태로 검색하고 처음100개를 표시한다. ‘상속·패치 적용값’과 필드별 출처는 최종 해석값이므로 원시 미리보기와 구분한다.

CLI는 실제 로더의 상속·참조·수치/의미 검증 오류와 실제 스크립트 등록 오류에 종료1을 반환한다. 누락 모드 같은 데이터 오류가 있으면 VM 등록 전에 실패한다. 본 작업은 현재 로더 검사의 구조화 출력이며 문서의8단계 전체를 새로 완성했다고 주장하지 않는다. 중복 JSON 키/BOM의 엄격한 파싱·원본 부분/최종 완전 스키마의 통합·불변 콘텐츠 동결/일반 로드 해시와 나머지 전체 확장은 계속 남는다.
