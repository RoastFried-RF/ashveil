# v0.330 지속 처치의 손·도구

지속되는 진찰·투약·외과 처치가 음료를 마시는 자세를 반복하던 경로를 작업 자세로 바꿨다. 실제 환자에게 하는 작업 턴에서만 시술자가 환자를 바라본다. 견적 조회나 렌더링으로 방향·세계 시간·난수를 바꾸지 않는다. 동료에게 간병을 부탁하는 인물의 순간 동작은 상호작용으로 남긴다.

처치에 처음 묶인 `toolUid/uid/supplies`의 실물만 표시한다. 봉합은 바늘과 원래 실타래를 각각 실제로 쓸 수 있는 손에 붙이며 손상/상실한 손에 새 손을 만들지 않는다. 도구가 없어졌다고 같은 종류의 다른 UID로 바꾸지 않는다. 무의식·사망·환자 이탈·취소·완료 때 도구를 숨기며, 표현 대기는 재료를 소모하거나 치료를 진행하지 않는다. 실제 치료 결과와 재료 소모는 기존 코어에 남긴다.

고유 인물 원화8종의4방향 작업4프레임, 총128원본 크롭을 직접 대조해 오른손106·왼손91접점을 등록했다. 가려진59손 슬롯은 명시적으로 비웠다. 원본 크롭의 좌표를 anchor/scale/flipX와 웅크림에 따라 바꾸고, 원래 피부/장갑 색을 샘플링한 작은 손가락 가림만 덧그린다. 새로운 팔이나 새 픽셀 원화를 생성한 작업은 아니다. [원본별 해시·수동 대조 범위](../tools/art/direction-v330/README.md).

도구를 손에서 떨어뜨리는 병진 효과 없이 회전만 작게 넣고 처치 종류마다1.2–1.8초의 표현 주기를 쓴다. 바늘과 실타래는 첫 확대 화면에서 크기가 과해5월드픽셀로 줄였다. 부목·칼·병은 각 원래 크기를 따른다. 의료 동작에는 몸만 따로 기울이는 효과를 꺼 접점이 분리되지 않게 했다. [공개 검토 페이지](https://roastfried-rf.github.io/ashveil/artbook/medical/)는 게임과 같은 기하 계산, 원본 PNG·128접점을 사용하며8인물·4방향·9처치·쓰는 손과 프레임 이동을 제공한다. 진찰/관절 정복에 없는 도구를 임의로 추가하지 않는다.

실제 입력 검토는 유한 초기 팀3명·상처1개·바늘1개/실3개를 선언했다. 두 화면 크기에서 동료 환자를 선택해 봉합을 부탁하고 실제 작업 자세를 관찰한 뒤 취소, 재시작, 실제 휴식 턴으로 완료했다. 표현만 관찰한1.7초 동안 전체 상태 해시가 같고, 취소는 실3개 유지, 완료는 실2개/같은 바늘/환자 봉합으로 끝난다. 가방·몸·시간을 불러온 뒤 수정하지 않았다. 전체 의료 행위의 자연 획득/모든 손 손상/모든 자세 조합을 검증한 것으로 세지 않는다. [검사 기록](release-v330-proof.json).

현재 인물 작업 원화는 프레임마다 몸과 손의 포즈가 변하지만 환자의 실제 신체 부위까지 팔을 뻗는 전용 수술 원화/관절 IK는 아니다. 전용 바늘/칼 팔 모션, 다른 자세의 모든 손목, 실제 착용 의복/보철/절단 외형은 후속 출시 항목이다. 확장 생물9종·사제 향로·기본 장비4종의 재획득 누락은 별도 준비 중이며 이 버전에서 활성화했다고 쓰지 않는다. 전체 회귀·World/1,000판과 외부 사람 평가도 미실행이다. 저장212 유지.
