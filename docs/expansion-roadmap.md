2026-10-17 사용자가 프로토타입뿐 아니라 후속 확장 전체를 포함하도록 요청했고, 이득이 있으면 엔진 교체도 허용했다. 이 문서는 **요청 범위**를 추적한다. v0.262까지 주민 재배·지하 성장·격리 스크립트·모드 조회/검사·구성/버전/순서 검토와 없어진 물품/상태/정신/사건 이행을 통합 검증했다. v0.264까지 몸/생물 ID도 통합 검증했다. v0.265–270의 브라우저 가져오기/설치·사라진 층 생물 제거·시드 공유/ZIP 배포·헤드리스 도구/현재 세계 데이터 재적용까지 통합 검증했다. v0.271의 자루는 전체5,532개/실제 UI/각인183 복원/월드30판을 통합 검증했으며, v0.272의 허리 주머니는 실제 UI/각인184 복원을 확인했다. v0.273 음식 병합은 관련139개와 전체 골든 감사를 통과했다. 구현된 게임의 범위는 `prototype.md`다. 전체 장기 로드맵이 완료된 상태는 아니다.

정본은 CANON → design → GDD → lore다. CANON의 ‘사용자 확정 필요’ 항목을 임의로 확정하지 않는다. 수치 기본값은 설정으로 분리하고, 독립 구현은 계속 진행한다.

## 검증 기준

각 기능은 데이터 정의만 넣은 것으로 완료하지 않는다. 입력 → 턴/행동 → 실제 상태 변화 → 화면 → 저장 복원까지 연결하고 검증한다. 밸런스 변경은 동일 시드 30판 × 최대 3일을 기본 회귀로 삼는다. 작업 상한으로 조기 종료한 판을 생존으로 집계하지 않는다. 긴 자동 활동도 종료 TU에서 잘라 지정 일수를 초과한 사망을 집계하지 않는다.

GDD §14의 통과 기준(1,000판 탐험 보고서, 실제 사람의 30분 플레이·사망 보고서 평가, 외부 테스터 5명 중 4명 재플레이 등)은 별도로 남는다. 30판 봇 회귀나 브라우저 스모크로 사람 평가를 대체하지 않는다.

## 자율 진행 기준과 기존 결정 대기

사용자의 최신 지시에 따라 목표는 X1–X4를 포함한 v1.0.0이다. [현재 실행·출시 기준](v1-execution.md)을 사용하며 아래의 과거 확인 대기 문구만으로 루틴 구현을 멈추지 않는다. 기존 기본값은 근거를 갖춰 변경하기 전까지 유지한다. 첫 표의 오래된 남음 항목은 이후 구현 기록과 대조해야 한다.

- P1 달력: 시스템 문서 기본은 90일(20·15·20·35), lore 제안은 120일. 확인 요청 중이며 아직 CANON을 바꾸지 않았다.
- P3~P7·P9: 명칭·경제·평판·스토리텔러·반올림의 기존 기본값을 유지한다. P10/C10 저장 방식은 사용자 자율 구현 범위에 따라 D39와 표석/탐구로 구현한다.
