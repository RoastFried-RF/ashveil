# 원래 그릇과 실제 물의400턴 끓임

v0.114. 13 §4.14를 먼저 등록하고 같은 빈 그릇·귀리1·원래 물220ml를 모닥불 위 한 회분으로 담는 방법을 추가했다. 기존 직접400턴 제작도 유지한다. 새 덜 익은 귀리죽의 원래 그릇1×1/쌓임1·300÷1.1kcal/단백10/비타민0/수분220ml·신선12시간/추가 생식독0은 조정 가능한 Def 제안값이다. 아직 끓지 않은 원래 물의 병원체는 별도로 그대로 남는다.

준비의 실제1턴에 원래 병에서220ml를 덜고 귀리1만 사용한다. 원래 물병/남은780ml와 같은 수질, 귀리의 실제 나머지2개를 보존한다. 그릇은 동일 UID/품질3/내구81의 혼합물로 불 위에만 존재한다. 덜 익었을 때 내려도 실제 진행과 물의 병원체·재·소금이 남는다. 실제 배낭에서 그 혼합물을 먹으면 기존500ml 물 노출에220ml/병원체176ml가 더해지고, 그릇은 같은 빈 그릇으로 돌아온다. 조리나 회수만으로 물 노출/영양을 주지 않는다.

400번째 실제 뜨거운 턴에만 원래 물의 끓임을 적용한다. 병원체를 없애되 소금0.66g은 남기고 원래 물의 재에 기존 끓임×1.1을 적용한다. 원래 곡물의 재에는 물의 끓임 배율을 덧씌우지 않는다. 같은 그릇이 완성된 귀리죽으로 바뀌고 실제 완성 시각부터 보온을 센다. 그 뒤 불 위에 남기면 기존 실제200턴 간격 방치/탐을 사용한다.

실제 먹은 한 그릇만300kcal/수분220ml/보온+0.2°C와 소금·재를 전달하고 같은 UID/품질/내구의 빈 그릇을 남긴다. 빈 그릇은 남은 귀리와 물로 재사용할 수 있다. 마지막220ml를 쓰면 같은 물병은 빈 채로 남는다. 기존 손 굽기로 미완성 그릇을 바꿔 다른 그릇을 생성하는 경로는 거절한다. 실제 칸/거리·시야/불 소유·동시 자리·예약한 기존 작업을 확인하며 실패는 자원을 바꾸지 않는다.

각인v78은 원래 혼합물과 실제 물의 수질·물량·조리 진행/방치와 원래 그릇을 보존한다. 구형77에 혼합물이나 과거 물 노출을 소급하지 않는다. 전용20개·관련7파일230개가 통과했다. 타입/린트/Def120패치/Schema101파일 오류0을 확인했고 [5개 재현의 전체 상태 감사](golden-v114-diff.json)는 버전78 외 모든 초기/최종 상태와 오류가 같다. v0.114에서는 원래 귀리1/물220ml/동일 그릇을 불 위에 담고 실제400턴에만 끓이기·미완성 병원체/원래 소금·곡물과 물의 재/실제 보온·300kcal와 같은 빈 그릇/각인v78을 연결했다. 전체116파일2,047개140.61초·전용20/관련230개·타입/린트/Def120패치/Schema101/빌드·최종 화면511~516/6장 전체 확인·6전체 복원·콘솔 오류0이다. 같은 검증 코어의 월드30시드×최대3일322.546977907초·30개 전체 행이 이전과 같다. 최종 화면의 미완성 그릇 설명을 실제 모닥불 바로 곁 조건으로 고쳤다. 최종 모든 코어/단위 검사/도구는 전체 검사 사본과 SHA-256이 같고 파일 manifest도 일치한다. [30개 전체 행 감사](sim-v114-diff.json). 솔잎차/물 끓이기 중단 보존과 나머지 생존·새 그림/생물 생산·후속 확장 전체는 계속 구현한다.
