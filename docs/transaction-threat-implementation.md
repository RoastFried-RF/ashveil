v0.139.04 #57의 좋은 거래+3/2일/2×0.5를 실제 성사된 흥정 거래에 연결했다. 같은 물품/수량/재질·품질/현재 지역가격/평판/불쾌감/신선도/도구 상태를 유지하고, 흥정 성공 보정만 뺀 가격과 실제 확정 가격을 비교한다. 최소1표를 실제 아낀 구매·실제 더 받은 판매만 완료 사건으로 기억한다. 최소가격 반올림 때문에 실제 값이 같으면 성공한 흥정이 있어도 기억을 주지 않는다.1표 기준은 모드 가능한 구현 기본값이며 정본의 새 정의로 확정하지 않았다.
