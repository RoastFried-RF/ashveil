# 실제 화살통과 구형 내부 격자 — v0.275 검증 중

설계13 전체를 다시 읽고 새 물품을 먼저 등록한 뒤 Item.Quiver/Recipe.Quiver를 추가했다. 바깥2×2/안쪽1×6이며 기존 등 슬롯을 망토와 공유한다. 완전히 착용한 정상 화살통만 원래 화살을 바로 꺼내 쓸 수 있다. 화살20발의1×2 더미 세 개로 최대60발이며 화살 외 물품/가방 중첩은 거절한다. 원래 UID/품질/상태/배치를 보존한다. 부서짐·반착용·탈의/망토 교체는 접근만 닫으며 내용물을 만들거나 없애지 않는다. 단열/방수는 제공하지 않는다.

가죽2/실1/실제 바늘로300작업턴에 빈 화살통을 만든다. 기존 arrow sprite를 재사용하며 시작 장비/상인 재고/탄약을 늘리지 않는다. 무게0.5/가격14/내구40/착탈1턴과 슬롯은 콘텐츠 기본값이다. 실제 사격과 다턴 장전은 배낭/허리 주머니/착용 화살통의 실제 탄약을 검색하고 한 발만 차감한다. 장전은 원래 탄약UID에 묶이고 완료 때만 옮기며 도중 탈의하면 장전하지 않는다. 닫힌 자루 내용물은 사용 가능한 탄약이 아니다. 기존 화살 회수 규칙을 바꾸거나 새 깃 손상을 구현했다고 주장하지 않는다.

각인186은185이하를 버전만 이행하며 화살통/화살을 소급하지 않는다. 실제 내부 격자는 기존 저장·보관물·ID 이행 검사와 같은 경로에 연결했다.

272–273 통합 전체 회귀에서는 기록 없는 구형 허리 주머니를 잘못 차단하는 실제 제품 회귀 세 건이 발견됐다. 원본273 보고서는 보관했고 월드 회귀는 실행하지 않았다.275에서 기록 없는 빈 내부 격자는 그대로 허용하고, 실제 내용물이 있으면 현재 정의의 실제 크기/물품 크기·위치/겹침을 검사하도록 수정했다. 기록된 과거 내부 크기가 다르면 비어 있어도 차단한다. 같은 실제 해시의 모양 기록 보강은 기존 공통 경로만 사용하고, 모르는 해시의 생애는 실제 주머니 사용 후 재저장해도 과거 해시/크기 기록을 꾸미지 않는다. 없어진 바깥 물품 정의의 원래 크기/정의 기록 요구는 유지한다.
