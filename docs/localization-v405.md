# v0.405 작업 초안 — 물품 상세와 공개 관찰

2026-10-28 KST. v404 검증 중 별도 작업본이다. 타입/린트/대상/Full·실제 입력/개별 PNG 검토와 main/Pages는 아직 통과하지 않았다. v403의 공개 이름 경계를 이어 물품의 수치/상태/조건·약 추정·제작/재질·장비·물/음식·독서/설치/정비 설명을 표시 경계에 연결한다.

기존 물품160개 description·감정 전3개 unknownDescription, 알약 효과6개 description 및 관련 Material/Disease/설치 Terrain label을 ID+최종 원문으로 검토했다. 정적 조사와 실제 최종 DB 검증은 구분한다. 변경한 모드 원문과 없어진 물품 기록, 계약/사람 이름·저장한 물 출처는 원문 인수로 보존한다. 미감정 유물은 기능 설명/수치를 보이지 않으며 빈 참조가 다른 실물의 감정을 빌리지 않는다. 알약은 실제 추정/확신·기존 외관 관찰만 사용하고 숨은 pillMap/실제 효력을 새로 공개하지 않는다.

원래 재료 조각의 실질 label이 런타임에서 합성돼 기존 Def label guard에 걸리지 않는 경우는 실제 재질 Def를 별도 표시하고 기존 질량/UID를 유지한다. 물 관찰은 한국어에서 원래 core waterLines를 그대로 쓰고 영어에서 같은 공개 단계만 표시한다. 저장 출처를 이름 치환으로 번역하지 않는다.

새 Native 초안은 유한 초기 소지품8개와 잘못된 공개 알약 추정만 선언한다. 실제 한국어/영어 tooltip·Tab/Enter 메뉴·원래 그릇 음식 한 회분 섭취·같은 빈 그릇·저장/계속을 독립 Node 전체 상태로 대조할 예정이다. 획득/조리/감별·자연 장기 플레이나 사람 평가 근거로 세지 않는다. 다른 창·동적 로그/문헌/도감·보고서와 전체 v1/X1–X4는 계속 미완료다.

2026-10-30 새 환경의 첫 light 계획은 Node/pnpm/Chromium/lock 환경과 린트를 통과했지만 약물 의식/호흡의 선택적 수치를 메시지 인수에 넘긴 두 타입 오류를 발견했다. 없는 감점은0으로 표시해 undefined 문자열이 나타나던 경계도 수정했다. 대상/Def/스프라이트는 의존성 실패로 차단됐고 Full/빌드/Native는 이 light 계획에 포함하지 않았다. 실패 원문은 test-results/v405-authoring-light에 남긴다.

v404의 실제 타이틀 World 보존에 맞춘 복원 도구와 짧은 순차 Native 검증 경로를 병합 중이다. 물품 상세 도구도 화면별 선택을 지원하며 전체 상태를 boolean으로 단정해 실패 시 거대한 숨은 World diff를 로그로 출력하지 않는다. 앱의 정보 공개 경계나 기대 세계는 줄이지 않는다.
