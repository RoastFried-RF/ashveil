# v405 로컬 개발 — 물품 공통·장비 상세 표시

2026-10-30 KST. 이 PC의 [Windows 하네스](windows-development.md)에서 공통/장비 범위를 로컬 구현·검증했다. 공개 기준은 v0.404-dev/저장219이며, 게시나 전체 v1 수락은 별도다. [최종 로컬 검증 영수증](pc-harness-v405-proof.json).

## 구현 경계

- 물품의 분류/슬롯·품질·내구·크기, 보관 격자/화살통/주머니, 깃 상태와 실제 동일 상태 탄약 규칙.
- 실제 무기 공격 수치·계열/출혈/리치/머리 판정·날/방패, 방어구 부위·단열/방수/방풍·실제 젖음/수리 상한·혼합 재질과 질량.
- 의수족 효율·전력/정비·장착 안내, 계약 원본 표지. 계약/인물의 고유 이름은 그대로 둔다.
- 미감정 유물의 외형과 감정 안내. 같은 종류의 다른 감정된 물품이나 빈 참조가 미감정 실물의 기능을 공개하지 않는다.
- 검토한 기본 물품 설명8개, 미확인 외형3개, 재질20개와 현재 물품 공격 이름. 수는 번역 완성률이 아니다.

`en-item-details.json`은 기존 UI 메시지와 분리하며 기존 키를 덮어쓰지 않는다. `en-item-content.json`은 기존 Def 번역과 필드 단위로 합치고 ID+정확한 원문을 검사한다. 중첩 공격은 물품ID+공격ID+원문이 모두 맞아야 번역한다. ID 없는 공격, 바뀐 모드의 원문과 미검토 설명은 그대로 표시한다. Core·공식 콘텐츠·물품 상태·저장219의 계약은 바꾸지 않았다.

대상 검사는 모든 생성 가능한 기본 물품을 ko→en→ko로 표시한 뒤 전체 저장·물품·난수를 비교한다. 미감정/부분 감정/감정 완료와 빈 참조, 틀린 숨은 알약 매핑, 변경/외부 모드 원문, 혼합 재질·실제 수치를 별도 확인한다.

## 실제 입력과 검증

`tools/inspect-item-details-v405.ts`는 선언된 초기 탐구 각인에 원래 칼·유한 혼합/젖음/수리 가죽옷·감정 상태가 다른 의수 두 개만 준비한다. 이것을 자연 획득으로 보고하지 않는다. 타이틀에서 불러온 뒤 마우스/Tab·Enter, 언어 전환, 실제 버리기, 저장/계속하기만 사용한다. 매 단계의 전체 세계를 독립 Node 세계와 비교하고 실제/기대 원문을 로컬에 보존한다. 불러온 뒤 브라우저 세계나 난수는 쓰지 않는다.

```powershell
./tools/windows/ashveil.ps1 release --item-details-locale
```

초기 검사에서 타입 누락과 장비 비교의 `기력` 번역 누락을 확인·수정했다. 데스크톱 이후390px에서 검사 포인터가 창 뒤의 설정 버튼을 찾는 잘못된 가정도 수정했다. 이전 실패/재검을 지우지 않고 최종14단계에서 Full414파일6,771검사(642.18초/작업자2), 타입/린트·Def/스프라이트/독립 Schema·빌드·공통 스모크를 통과했다.

최종 Native는 기존 언어12쌍/14PNG, 기존 물품45쌍/33PNG, 새 상세30쌍/30PNG다. 모든 전체 상태 비교와 콘솔 오류0을 확인했다. 이미지 생성 수와 개별 시각 검토 수를 구분하며, 세 화면 크기의 타이틀/소지품/상세 대표 화면과 최종 작은 화면/복원 화면을 직접 열어 확인했다. 앱·테스트·하네스27파일의 실제 검사 바이트가 바뀌지 않은 것도 확인했다. 원시 세계 JSON은 로컬에만 남긴다.

## 계속할 범위

음식/물/약·책/조리/설치, 화기·시위/부식과 나머지 기본 물품 설명은 [v406 후속](localization-v406.md)에서 로컬 구현·검증했다. 알약의 현재 지식/외형·숨은 실제 효력, 물의 공개된 관찰 경계는 기존 규칙을 유지한다. 다른 창·동적 로그/문헌·결말, X1–X4의 기능 결손과 전체 World/원정/사람 출시 게이트도 [v1 장부](goal-code-audit-v1.md)에 남는다.
