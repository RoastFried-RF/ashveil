# v394 방향별 의수족과 실제 관절

기존6의수족은 한 시점의 물체 원문을 여러 방향에 공유했다. 새 자체 원화5PNG/52고유 원문 영역을 등록하고 실제 장착 뿌리에서 손·발까지의 관절을 연결했다. 일반 인간과 그늘 사람·말라붙은 자·포자 인간의 기존 크기/몸을 사용하며 Core·콘텐츠·저장219는 유지한다.

## 원문과 소유

- 막대 의족·갈고리 손·유리 눈은 네 방향의 실제 물체 면을 사용한다. 발만 바꾼 막대 의족은 같은 원문 아래쪽을 소유하며 별도의 새 원문으로 세지 않는다.
- 관절 의족은 정강이/발, 개척 의수는 전완/손, 정원사 이식지는 상완/전완/손·대퇴/정강이/발의 별도 부품을 사용한다. 설치한 뿌리의 자손만 그리며, 위쪽의 없는 사지를 만들지 않는다.
- 관절 여러 개를 그려도 기존 실물 UID 하나다. 손의 원문 잡는 점을 실제 손잡이에, 발바닥 기준점을 기존 보행 접지에 맞춘다. 작은 몸도 실제 원래 발 크기를 기준으로 맞추며 부츠 착탈이 의족 크기를 바꾸지 않는다.
- 앞/뒷면의 반대쪽 공유는 명시적인 반사이며, 좌/우 프로필은 각각 새로 그린 방향을 사용한다. 발목·발바닥·실제 표시 행렬이 같은 반사를 사용한다.
- 실제 금속 부품도 열린 의복 소매의 안쪽을 가린다. 그림의 피부나 가짜 사지를 추가하지 않는다.

생성5회/원본5장을 바이트 그대로 보존했다. 첫 혼합 시트의 갈고리4칸은 프로필/뒤쪽의 모양이 일관되지 않아 등록하지 않았고 전용4방향 원문으로 대체했다. 유리 눈의 혼합 시트 좌/우 열은 실제 홍채 방향에 맞춰 정규화했다. 등록52영역 중 눈의 뒤쪽1영역은 실제 뒤통수에서 보이지 않으므로 현재 몸이 조건부로 선택하는 신규 원문은51영역이다. 원문·정확 프롬프트·SHA·크롭·부착점은 [제작 기록](../tools/art/direction-v394/source-audit.json)에 남긴다. PNG 픽셀 수정/리샘플링은 하지 않았다.

이는2D 원문 부품 조립이며 새 완전 보행/공격 프레임은0개다. 관절 기준점/접지 검사와 실제3D 골격·동역학 인증은 구분한다. 기존6개 물품의 아이콘과 실물/설치 규칙은 유지한다.

## 필요한 원화만 로딩

첫 추가 뒤 대표 지도의 기본 디코딩 추정치가 기존300MiB 검사 예산을 넘었다. 예산을 올리지 않고 선택한 몸과 실제 설치한 의수족을 분리했다. `worldAssets()`가 실제 설치 Def의 원문을 요청하며, 설치/분리 때 요청 키가 바뀐다. 같은 장비의 내구/전원 변화로 불필요한 재로딩을 하지 않는다. 모든 원문을 보는 진단 작업대는 명시적으로 전체 원문을 요청한다.

메모리 검사는 대표 지도의 기본 예산과 원래 PNG의 RGBA 크기 추정이다. 모든 지도/기기의 실제 GPU 메모리나 프레임 속도 보장은 아니다. 실제 UI 설치·분리에서도 한 장의 원화만 추가되고, 분리 뒤 원래 로드 수/디코딩 추정치로 돌아왔다.

## 검증

기능 불변본 `v394-prosthetic-r2`: 국소7파일47검사, 타입/린트,401시트/8,469프레임/36캐릭터/427고유PNG 검사를 확인했다. 기존5골든의 전체 초기·최종·명령 오류가 v393과 같고, Core/콘텐츠/모드/기대 fixture1,072파일은 바이트가 같다. 기존 v393 월드30판을 재실행했다고 세지 않는다.

- 합성 확대: 일반 인간28장착점×4방향112개, 변형3계열의 대표7장착 조합×4방향84개로196개 관측. Core 세계를 만들지 않는다.
- 실제 Native:16유한 장면에서28장착 규칙을 네 방향에 나누고 일반 인간과 실제 변형 NPC3종을 함께 확인했다. 실제 이동/회전·부츠 착탈·왼/오른손 무기 공격·두 대각선 요청·저장 복원의176전체 상태 쌍이 독립 Node와 같았다. 의족 소스 접지388회를 대조했고 브라우저 오류0이었다. 초기 설치된7기기는 fixture이며 수술 수행으로 세지 않는다.
- 초기 검사에서 미확인 NPC가 정상적으로 숨겨지는 조건, 잘못된 검사 동작 이름, 결손 오른팔의 주 손 슬롯에 둔 잘못된 초기 무기를 발견했다. 실패를 유지하고 이미 만난 NPC·실제 동작 이름·기능하는 손의 올바른 슬롯을 초기 fixture에 명시했다. 현재의 실제 무기 선택을 초기 검사에서도 확인하며, 숨은 정보/무기 숨김 규칙은 바꾸지 않았다.
