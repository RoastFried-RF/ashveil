# 모드 제거의 실제 상처·상태 정리

v0.256 작업 중, 각인182/API1.4.0. 설계11§8에 따라 실제 이전 정의 목록에 기록된 Wound/Disease/Thought/Trait가 현재 구성에서 사라진 경우, 명시적 구성 변경 검토와 승인 뒤에만 해당 상태를 제거한다. 같은 ID의 종류 변경은 여전히 차단한다. 과거 구성이 없는 저장이나 같은 해시와 모순되는 정의 목록으로 자동 삭제하지 않는다.

활성 인물·다른 층·정지 지역의 실제 몸/배낭/정신 구조를 찾아 상처 기록·질병 상태·생각 묶음·특성을 따로 집계한다. 사라진 질병의 물림 대기/상처 위험/보균 표시도 별도로 집계하고 제거한다. 검토는 사본에서 모든 참조를 먼저 검사하며 원본·시각·난수·UID·각인을 쓰지 않는다. 승인 시 기존 후보에 같은 턴의 집계 로그 한 개를 남긴다. 반복 실행은 추가 로그를 만들지 않는다.

제거한 상처의 현재 피해/출혈과 상태의 현재 효과는 사라진다. 이를 HP 불변으로 설명하지 않는다. 혈액량·절단/영구 손상·독립 흉터·과거 면역/노출/진료와 남은 질병의 노출 원인은 보존하고 죽은 인물을 되살리지 않는다. 진행 중 치료/다른 인물의 치료·압박·뇌 회복·동상·현재 다른 질병의 물림 위험이 제거될 상처를 참조하면 전체 승인을 차단하고 원래 정의 복원을 요구한다. 그 밖의 살아 있는 값/사전 키 및 임의 스크립트 지속 상태 참조도 추정해서 지우지 않는다.

물품 rename→상태 정리→원래 크기 물품 보관 순서로 같은 실제 구성/원문 토큰 승인에 연결한다. 원본 물품이 보관된 뒤 다른 종류의 정의로 돌아오면 보관 복원을 승인하지 않는 검사도 추가했다. 아직 Break/다른 상태의 개별 종료 절차·개체/사건 제거·스크립트 소유 상태 이행은 별도 구현 대상이다.

전용16개와 실제 저장 시작3개 및 기존 검토/물품 보관·rename/현재 기록·골든을 포함해10파일106개를 통과했다. 첫 전용12개와 추가 시작3개도 각각 처음 통과했다. 전체 상태 독립 대조, 과거 기록 보존, 실제 다른 층/정지 지역의 같은 인물, 치료/알 수 없는 값·키의 원자적 거절, 실제 승인 한 번 저장/연대기, 취소·원문 변경 토큰 검사를 포함한다. 고정5개 전체 초기/최종/오류/해시가255와 정확히 같아 각인 형식·기대 벡터·보관 벡터는 바꾸지 않았다.

최종 타입·린트·Def277패치/191물품·빌드2.37초가 통과했다. 고정한 원본256에서 실제 화면1267–1269 세 장을 모두 확인했고 검토/취소 원문 보존·실제 승인한 네 상태/한 로그 외 전체 일치·전체182복원1/반복 로그 없음·진행 중 압박의 승인 차단/원문 유지·콘솔0을 첫 실행에 통과했다.256–258 통합 전체/월드 회귀는 진행 중이다. 전체 후속 확장은 계속 구현한다.
