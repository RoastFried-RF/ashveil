# v0.328 환자 선택과 동료 외과 처치

돌봄 부탁의 진료 창에서 직접 보이는 시술자 곁의 주인공 또는 동료를 환자로 선택한다. 진찰·약 바르기/투약에 더해 붕대·세척·지혈대·부목·봉합·동맥 결찰·힘줄 수복·이물질 제거·관절 맞추기·절단의 기존 처치 규칙을 사용할 수 있다. 자동 반복 처방이나 의료품 지급을 추가하지 않는다.

시술자는 곁에서 부탁받는 실제 유급 동료이며 기존 안전·몸·급료·작업 조건을 따른다. 환자는 같은 현장의 깨어 있는 살아 있는 주인공/동행자여야 하고, 직접 관찰하며 시술자 곁에 있어야 한다. 선택한 환자가 사라지거나 시야를 벗어나도 다른 사람으로 몰래 바꾸지 않는다. 부위·외부 상처와 현재 시술 조건을 다시 검토한다. 원래 처치의 숙달·도구·소모품·손·진행/중단·완료 품질/위험을 사용한다.

주인공이 환자면 기존 진료 대기로 실제 노동을 기다린다. 다른 동료에게 진료를 맡기는 지시는1턴이며, 정한 환자만 진료 대기에 들어간다. 주인공은 이후 직접 기다리거나 다른 일을 할 수 있다. 진찰 소견은 정한 환자에게 기록하며 주인공의 몸/보고서에 복사하지 않는다. 창에는 해당 동료의 당시 소견을 표시하고 현재 숨은 수치를 다시 검사하지 않는다.

다른 동료에게 부탁한 진료는 같은 창의 ‘부탁한 진료 중단’으로1턴에 중단할 수 있다. 원래 시술자/환자 쌍을 다시 확인하며, 오래된 중단 지시로 새 환자의 진료를 취소하지 않는다. 기존 정상 중단 경로가 양쪽 대기를 해제하고, 미완료 투약/진찰/봉합에는 새 효과나 완성 기록을 남기지 않는다. 이미 반 이상 묶은 부목 등의 기존 부분 효과와 실제 소비는 되돌리지 않는다. 곁에서 중단을 전할 수 있어야 하며, 주인공 자신의 진료 중단은 기존 행동 중단 경로를 유지한다.

절단은 원래 지혈대·칼날·숙달 조건을 먼저 충족해야 한다. 환자와 부위를 고른 뒤 영구 상실/출혈/실신/사망 위험을 직접 확인해야 시작 버튼을 누를 수 있다. 코어도 명시적 동의가 없는 요청을 원자적으로 거절한다. 단순히 버튼을 고르거나 검토/취소한 것으로 부위를 제거하지 않는다. 이물질 제거의 추가 출혈·실패 악화, 봉합의 원래 바늘/실 한 몫·품질도 유지한다.

정착지 의사와 동료가 동일한 읽기 전용 임상 계획을 사용하도록 분리했다. 기존 의사는 평판/진료비를 계속 적용하며 동료에게는 별도 진료비나 상점 재고를 지급하지 않는다. 서명에는 원래 환자·처치/부위·도구/소모품UID·시간/품질·설명을 묶는다. 도구가 사라지거나 환자가 중단하고 급료/계약/정책·안전이 달라지면 기존 양쪽 중단 경로를 따른다. 든 무기는 진료 중 숨기고 기존 신체 동작을 사용한다.

저장212의 기존 진료 표식/환자ID/고정 소모품 구조를 그대로 사용한다. 새 각인 버전이나 과거 진료 추정은 필요하지 않다. PNG·코어 콘텐츠/모드 정의는 바꾸지 않았다.

대상95개·타입/린트·Def/Schema·빌드와 유한 초기 몸/도구를 불러온 실제 UI를 확인했다. 실제 입력은 주인공 봉합, 두 해상도의 다른 동료 진찰→봉합, 동료 진찰 중단/재의뢰, 절단 위험 확인/취소를 포함한다. 초기 절단 견적 검사는 필수 지혈대가 없는 초기 자료로 실패했으며 원래 규칙을 완화하지 않고 유효한 초기 지혈대 자료로 수정했다. [검증 근거](release-v328-proof.json)에 실제 범위와 제약을 남긴다.

모든 부위/시술·오염/기후·동료 조합이나 자연 발생 빈도, 반복 간병/수술 계획·실신자 들것/지도 경계는 아직 전체 검증/구현 범위가 아니다. 전체 회귀·World/1,000판·출시 각인/사람 평가와 나머지 v1 항목은 [추적 문서](autonomous-implementation.md)에 남는다.
