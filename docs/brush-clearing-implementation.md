# 마체테로 야생 덤불 베기 — v0.296 통합 완료

D13의 후속 항목인 마체테의 덤불 제거를 별도 행동으로 구현한다. 대상은 실제 `Terrain.AshBerryBush`이며, 영구 제거한 흙에 원래 종자를 심을 수 있다. 계절 열매 채집을 그대로 유지하면서, 반복 채집원을 남길지 다른 작물을 재배할지 고른다. **전체 숲/벌목/생태/기근/이주가 완성됐다는 뜻은 아니다.**

## 실제 규칙

Def의 선택형 `clearing`은 도구 ID 목록·기본 작업 턴·결과 지형·날 마모·소음을 가진다. 기본 제안값은 손에 든 실제 철판 마체테,10턴/기존 몸·조명 배율, 빈 흙, 기존 재질 기반 날 마모1, 매 작업턴 소음4다. 수치는 정본에서 확정한 숫자로 주장하지 않는다. 배낭에만 든 도구나 사냥칼, 날·내구가0인 마체테는 쓸 수 없다. 보이는 인접 지형/시야/대각선 막힘/깨어 있는 몸과 손을 검사한다.

작업이 끝나면 같은 타일의 덤불 지형만 빈 흙으로 바꾸고 과거 열매 재생 시각을 지운다. 원래 지면 물품·UID를 유지하고 열매나 장작·돈·아이템을 만들지 않는다. 원래 마체테에 재질 경도를 반영한 기존 `edgeLoss`를 한 번 적용한다. 씨앗이 설치된 재배 작물·설치물·보관함·설비·불타는/부분 연소한 덤불은 이 행동으로 지우지 않는다. 기존 남은 물/토양/세계 생산·계절 채집량을 소급 정산하지 않는다.

실제 매 작업턴의 소음은 정상 청각/AI 규칙을 따른다. 시작한 지도/지역·원래 도구 UID·지형/제거 정의가 바뀌면 중단한다. 취소하면 덤불과 날은 보존되며 다시 시작할 때 전체 시간이 필요하다. 진행 중 전체 각인은 남은 시간/같은 도구를 보존한다. 형식199→200은 버전만 바꾸고 과거 덤불 제거·재료·작업을 지급하지 않는다.
