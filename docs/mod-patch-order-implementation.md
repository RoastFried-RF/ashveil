# 원본 수집과 모드 패치 순서

v0.191 구현. 정본design/11 §4.2에 따라 모든 활성 모드의 원본을 먼저 모으고, 확정된 모드 순서·파일 경로 사전순·파일 내 배열 순서로 패치한 뒤 상속을 해석한다. 이전에는 모드 하나의 원본과 패치를 바로 처리해 뒤 모드에서 정의한 대상을 찾지 못했다.

앞 모드의 패치도 뒤 모드의 실제 원본을 찾는다. 명시적인 전체 교체 원본을 모은 뒤 패치하므로 앞선 변경이 뒤 원본 수집에 묻히지 않는다. 추상 부모 패치는 자식에 전파하고 자식 자체 값은 보존한다. 파일 입력 객체의 삽입 순서가 달라도 같은 경로 순서로 처리한다.

새`ifDefExists`조건은 활성 모드에서 수집한 실제 원본만 검사한다. 뒤 모드의 원본도 인식하고, 조건 Def가 없거나 해당 모드가 비활성이면 패치를 건너뛴다. 기존 모드 유무 조건과 함께 사용할 수 있다. 조건이 없는 잘못된 대상은 계속 오류다.
