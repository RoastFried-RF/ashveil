## 1. 한 줄 요약

> **"규칙은 투명하게, 세계는 끝없이 낯설게."**
> Stoneshard처럼 한 번의 실수가 죽음으로 이어지는 턴제 RPG를, RimWorld처럼 매번 다른 세계·사건·인물로 생성하고, 모든 콘텐츠를 모드로 갈아끼울 수 있게 만든다.

플레이어는 무너진 제국의 변경 지대에서 살아남으려는 한 명의 떠돌이다. 왼쪽 대퇴부 동맥이 베였을 때 13턴 안에 지혈하지 못하면 죽고, 젖은 옷으로 밤을 넘기면 저체온이 오고, 3주 동안 염장육만 먹으면 잇몸에서 피가 난다. 그리고 이 모든 게 **같은 규칙으로 적에게도 적용**된다.

## 2. 디자인 기둥

### 2.1 기둥 (지킬 것)

| # | 기둥 | 의미 | 출처 |
|---|---|---|---|
| P1 | **결과가 남는 하드코어** | 부상·손실·죽음이 되돌릴 수 없고, 다음 선택을 바꾼다 | Stoneshard |
| P2 | **이야기 생성기** | 세계·인물·사건이 시드마다 다르고, 시스템 충돌이 이야기를 만든다 | RimWorld |
| P3 | **파면 팔수록 나오는 깊이** | 모든 시스템이 3층(표면/중간/심층) 구조를 갖는다 (§4) | 공통 |
| P4 | **데이터 우선 · 모드 우선** | 기본 게임도 하나의 '코어 모드'다. 개발자가 쓰는 도구 = 모더가 쓰는 도구 | RimWorld |

### 2.2 안티 기둥 (하지 않을 것)

- **레벨 스케일링 없음**: 세계는 플레이어에게 맞춰주지 않는다. 북쪽 늪의 괴물은 1일차에도 30일차에도 똑같이 세다. (스토리텔러는 사건의 *빈도와 종류*만 조절, §6.9)
- **불투명한 규칙 없음**: 하드코어 ≠ 불친절. 공식과 확률은 툴팁으로 전부 공개한다. 숨기는 건 *규칙*이 아니라 *세계에 대한 지식*이다(어떤 약초가 독인지, 저 괴물의 약점이 뭔지).
- **실시간·멀티플레이·3D 없음**: 범위 통제.
- **복잡함을 위한 복잡함 없음**: 모든 디테일은 "플레이어 결정을 바꾸는가?"를 통과해야 한다. 바꾸지 않는 디테일은 로그·툴팁의 맛으로만 남긴다.

| 정신 | 정신력(Sanity), 사기(Morale) | 기분 = 사고(Thought) 합산, 정신붕괴 | **사고 스택 + 정신력 + 트라우마** |
| 성장 | 레벨 + 능력 트리 | 사용 기반 숙련 + 열정 | **사용 기반 숙련 + 숙련 임계로 해금되는 재능** |
| 세계 | 고정 지도 + 랜덤 던전 | 절차적 행성 + 세력 | **절차적 대륙 + 역사 시뮬 + 세력** |
| 사건 | 계약(퀘스트) | 스토리텔러 AI | **스토리텔러 + 계약 + 소문** |
| 확장 | 비공식(MSL 패치) | XML Def + XPath 패치 + C#/Harmony | **JSON Def + 경로 패치 + 샌드박스 스크립트 훅** |
| 저장 | 제한 저장(초기) | 자유 저장 / 커밋 모드 | **3가지 저장 정책 선택** (§6.11) |

버리는 것: Stoneshard의 "고정된 메인 스토리 지도", RimWorld의 "실시간 다중 유닛 관리"(MVP 범위 밖).

## 4. "파고들기" 설계 원칙

두 게임의 공통점은 **처음엔 단순해 보이지만 100시간 뒤에도 새로운 걸 발견한다**는 점이다. 이걸 우연에 맡기지 않고 구조로 만든다.

### 4.1 깊이 3층 규칙

모든 시스템은 기획 단계에서 3층을 명시해야 한다. 어느 층이 비어 있으면 그 시스템은 미완성이다.

| 층 | 대상 | 발견 시점 | 예 (출혈) |
|---|---|---|---|
| **L1 표면** | 모든 플레이어 | 첫 1시간 | 피 흘리면 붕대를 감는다 |
| **L2 중간** | 몇 번 죽어본 플레이어 | 10~50시간 | 동맥 상처는 붕대로 안 멈춘다 → 지혈대. 지혈대는 오래 두면 팔다리가 괴사한다 |
| **L3 심층** | 파고드는 플레이어 | 50시간+ / 위키 | 술을 마시면 혈관이 확장돼 출혈량↑. 피 냄새는 바람을 타고 늑대를 부른다. 추운 날씨는 출혈을 줄이지만 저체온을 부른다 |

### 4.2 규칙 대칭성

플레이어에게 적용되는 규칙은 적·NPC·동물에게도 똑같이 적용된다.
- 다리를 베인 도적은 절뚝이며 도망가고, 출혈로 쓰러진다 → 추격할지 말지 판단이 생긴다.
- 굶주린 늑대 무리는 사기가 낮아 쉽게 흩어진다. 배부른 늑대는 덤비지 않는다.
- 상인도 병에 걸리고, 마을도 굶는다 → 가격이 오른다.

대칭성이 깊이를 공짜로 만든다. 플레이어가 자기 몸에서 배운 걸 적에게 써먹을 수 있기 때문이다.

### 4.3 상호작용 매트릭스

재질·원소·상태가 서로 반응하는 규칙을 **데이터 테이블 하나**로 관리한다(모드로 확장 가능).

| 조합 | 결과 |
|---|---|
| 불 + 마른 풀 | 바람 방향으로 확산 |
| 불 + 비 | 화염 약화, 연기 발생(시야 차단) |
| 물 + 추위 | 젖은 옷 단열 -70%, 저체온 가속 |
| 기름 + 불 | 폭발적 연소, 주변 인화 |
| 피 + 바람 | 냄새 확산 → 육식 동물 유인 |
| 독 + 술(내복) | 해독 지연, 독 흡수 가속 |
| 금속 갑옷 + 추위 | 접촉 동상 위험(내피 없을 때) |
| 금속 갑옷 + 번개 | 피격 확률↑ |

### 4.4 정보 공개 정책: "규칙은 투명, 세계는 미지"

- **투명**: 명중률·피해 공식·출혈량 같은 규칙은 Shift 툴팁에서 수식까지 공개한다.
- **미지**: 몬스터 약점, 약초 효과, 지역 정보 같은 지식은 관찰·실험·구매로 얻는다(§6.7).
- **사후 공개**: 죽으면 "사망 보고서"가 원인 사슬을 보여준다. 다음 판에서 배울 수 있어야 하드코어가 공정해진다.

### 4.5 실패가 이야기가 된다

죽음은 **연대기**(영구 기록)에 남는다.
> *"떠돌이 에다, 32일차. 검은 늪 남쪽에서 늑대 3마리에게 쫓기던 중, 왼쪽 대퇴 동맥 절단 후 13턴 만에 출혈로 사망. 마지막으로 먹은 것: 상한 염장육. 소지품: 미확인 물약 2병."*

## 5. 게임 구조

### 5.1 루프 3단

| 루프 | 주기 | 내용 |
|---|---|---|
| **턴 루프** | 초~분 | 이동·공격·치료·아이템 사용. 위치·자세·무게·부상이 행동 비용을 바꾼다 |
| **원정 루프** | 시간~일 | 계약 수주 → 준비(식량·의약품·장비) → 이동 → 탐험/전투 → 귀환 → 치료·정비·판매 |
| **생애 루프** | 주~계절 | 숙련 성장, 평판, 세력 관계, 계절 변화, 세계 사건(전쟁·역병)에 휘말림 → 은퇴 또는 사망 |

### 5.2 시간 체계 (TU, Time Unit)

- 모든 행동은 **TU 비용**을 갖는다. 기본 행동 = 100TU = 게임 시간 3초.
- TU 비용은 상태에 따라 곱셈으로 변한다. 예: 과적 ×1.25, 다리 골절 ×1.5 → 이동 1칸 = 100 × 1.25 × 1.5 ≈ **188TU**.
- 행동 순서는 "다음 행동 가능 시각"이 가장 이른 개체부터 처리한다(우선순위 큐). 빠른 적은 내 한 번 행동 동안 두 번 움직일 수 있다.
- 전투가 없을 때는 자동 진행(빠른 이동)하고, 위협을 감지하면 즉시 턴제로 전환한다.
- 월드맵 이동은 시간 단위로 압축해 시뮬레이션한다(이동 중에도 배고픔·체온·상처 진행).

## 6. 시스템 상세

### 6.1 신체 & 부상

**신체 트리** (데이터 정의, 종족별로 다름)
```
몸통 ─ 심장*, 폐(좌/우), 간*, 위, 신장(좌/우), 갈비뼈
머리 ─ 두개골 ─ 뇌*
     ├ 눈(좌/우), 귀(좌/우), 턱
팔(좌/우) ─ 상완 ─ 전완 ─ 손 ─ 손가락×5
다리(좌/우) ─ 대퇴(대퇴동맥) ─ 정강이 ─ 발 ─ 발가락×5
(* = 치명 부위)
```
- 부위마다 체력, 피격 커버리지(%), 기능 기여도가 있다.
- **기능 능력치**(RimWorld식)를 부위 상태에서 계산한다: 의식, 이동, 조작, 시야, 청각, 호흡, 혈액순환.
  - 예: 오른손 손가락 2개 손실 → 조작 -12% → 양손무기 명중 하락, 자물쇠 따기 불가 단계 진입.
  - 예: 왼눈 손실 → 시야 -25%, 원거리 명중 하락, 왼쪽 측면 기습 감지 하락.

**상처는 개체다.** 같은 부위에 상처 여러 개가 각각 자기 상태로 존재한다.

| 상처 유형 | 출혈 | 특수 |
|---|---|---|
| 베임 | 높음 | 깊으면 힘줄 절단(조작/이동 영구 저하 가능) |
| 찔림 | 중간 | 장기 관통 확률, 내출혈(겉으로 안 보임!) |
| 타박 | 낮음 | 골절, 뇌진탕(머리) |
| 화상 | 없음 | 감염 위험 높음, 치유 느림, 흉터 |
| 물림 | 중간 | 감염·광견병 계열 질병 |
| 동상 | 없음 | 손가락·발가락 괴사 → 절단 필요 |

**상처의 일생**
1. 생성 → 출혈 시작
2. 처치: 지혈(손으로 압박, 행동 불가) / 붕대 / 지혈대(동맥) / 봉합 / 소작(인두질: 출혈 즉시 정지, 통증 극심, 흉터 확정)
3. 감염 판정: 상처 청결도(오염된 손, 진흙, 소독 여부)
4. 감염 진행 vs 면역 진행 **경주**: 둘 중 먼저 100%에 도달하는 쪽이 이긴다. 휴식·영양·약이 면역 속도를 올린다.
5. 치유 → 흉터 / 만성 통증 / 영구 기능 저하

**혈액량**: 성인 5,000ml.

| 손실 | 상태 |
|---|---|
| 15% | 어지러움, 명중 하락 |
| 30% | 쇼크 위험, 행동 TU 증가 |
| 40% | 의식 저하, 기절 판정 |
| 50% | 사망 |

**통증**: 상처별 통증의 합. 통증은 행동 페널티를 주고, 임계를 넘으면 쇼크로 기절한다. 진통제는 통증을 줄이지만 내성과 중독이 있다. 술은 통증↓ + 출혈↑ + 판단력↓.

| 깊이 | 내용 |
|---|---|
| L1 | 피 흘리면 붕대. 체력 0이면 죽음 |
| L2 | 동맥 출혈은 지혈대. 내출혈은 겉으로 안 보이니 증상(창백·어지러움)으로 추론. 감염과 면역의 경주 |
| L3 | 지혈대 장시간 → 괴사. 소작 vs 봉합 트레이드오프. 손가락 손실이 무기 선택을 바꿈. 추위는 출혈↓·저체온↑ |

### 6.2 생존

| 요소 | 규칙 | 디테일 |
|---|---|---|
| 칼로리 | 기본 소모량에 활동량(전투·무게·추위)이 더해짐 | 굶주림 단계별 근력·회복 저하 |
| 단백질 | 부족 시 근손실(근력 숙련 성장 저하), 상처 회복 저하 | 고기·콩·치즈 |
| 비타민 | 0~100 저장, 하루 -2 소모. 0이 되면 괴혈병 진행 | 염장·건조 식품만 먹으면 50일 후 발병. 신선 채소·과일로 회복 |
| 수분 | 기온·활동량에 따라 소모 | 오염된 물 → 이질 → 탈수 가속. 끓이면 안전(연료와 시간 소모) |
| 부패 | 음식마다 신선도. 온도가 높을수록 빨리 상함 | 염장·훈제·건조로 보존. 상한 음식은 식중독 확률 |
| 수면 | 수면 부채 누적 | 수면의 질: 땅바닥 < 침낭 < 여관 침대. 비·추위·소음이 질을 깎음. 야간 기습 위험 |
| 체온 | 의복 단열 + 바람 + 젖음 + 불 | 의복 **층** 시스템: 내의·중간·외투·갑옷. 젖은 옷 단열 -70% |
| 무게 | 근력 기반 한계 | 과적 → 이동 TU 증가, 스태미나 회복 저하, 피로 가속 |

| 깊이 | 내용 |
|---|---|
| L1 | 먹고 마시고 잔다 |
| L2 | 장기 원정엔 비타민·물 정화를 계획해야 함. 겨울엔 옷 층 관리 |
| L3 | 강 건너기 전에 옷을 벗어 짐에 넣으면 젖지 않음. 금속 갑옷 아래 내피 없으면 동상. 훈제 고기는 냄새로 곰을 부름 |

### 6.3 정신

- **기분 = 사고(Thought)의 합.** 사고마다 수치와 지속 시간이 있다.
  - 예: "배부르게 먹음 +5 (6시간)", "동료가 눈앞에서 죽음 -20 (10일)", "생고기를 먹음 -4", "비 오는 날 노숙 -6", "적을 처음 죽임 -8 (특성 '냉혈'이면 0)".
- **정신력(스트레스)**: 기분이 낮으면 누적, 높으면 회복.
- **정신붕괴** (임계 초과 시 확률 판정)

| 단계 | 예시 |
|---|---|
| 경미 | 짜증(협상 불리), 폭식, 혼잣말(은신 실패) |
| 중간 | 폭음, 무단 휴식, 전투 중 도주 시도 |
| 극심 | 광란(통제 불가 공격), 긴장증(행동 불가), 자해 |

- **트라우마**: 특정 경험이 영구 기억이 된다. 늑대에게 거의 죽을 뻔함 → "늑대 공포증"(늑대가 시야에 들어오면 사기 하락). 같은 상황을 이겨내면 극복할 수 있고, 드물게 긍정 특성("짐승 사냥꾼")으로 바뀐다.
- **특성**: 캐릭터 생성 시 2~3개 + 사건으로 획득·상실. 특성끼리, 그리고 다른 시스템과 상호작용한다.
  - 예: "알코올 의존" → 술 없으면 금단(손떨림 → 조작 하락) / "야행성" → 밤 시야 보너스, 낮 기분 하락 / "피를 보면 흥분" → 출혈 중인 적 근처에서 공격력↑, 정신력 회복.

| 깊이 | 내용 |
|---|---|
| L1 | 기분이 나쁘면 위험하다 |
| L2 | 원정 전에 여관에서 기분을 채워두는 운영. 특성에 맞는 플레이 스타일 |
| L3 | 트라우마 극복을 일부러 설계하기. 특성 조합 시너지(예: "냉혈" + "피를 보면 흥분") |

### 6.4 전투

**공격 판정 파이프라인** (각 단계가 툴팁과 전투 로그에 노출됨)
```
1. 명중 판정   ── 숙련, 무기, 시야/조명, 고저차, 방향(측면/후면), 자세, 통증
2. 방어 반응   ── 회피 / 막기(방패) / 받아넘기기 — 스태미나 소모
3. 부위 결정   ── 커버리지 가중 랜덤 + 공격 방향·신장 차이·조준 보정
4. 방어구 층   ── 바깥 층부터 판정: 판금 → 사슬 → 누비옷 → 피부
5. 상처 생성   ── 피해 유형(베기/찌르기/타격)·잔여 피해로 상처 유형·깊이 결정
6. 2차 효과    ── 출혈, 골절, 기절, 무기 떨굼, 넘어짐, 사기 판정
```

**명중 공식 (초안)**
```
명중률 = clamp(5, 95, 50 + (공격 숙련 - 방어 회피) × 2 + Σ수정치)
수정치 예: 야간 무조명 -15, 측면 +10, 후면 +20, 고지대 +10, 통증 단계당 -5
```

**방어구 판정 (RimWorld 방식 참고)**
```
유효 방어 = 방어구 수치 - 무기 관통
roll < 유효/2        → 튕겨냄 (피해 0)
roll < 유효          → 피해 절반, 베기/찌르기가 타격으로 변환 (멍·골절 위험)
그 외                → 관통 (전량)
```

**기타 시스템**
- **방향(Facing)**: 캐릭터는 바라보는 방향이 있다. 측면·후면 공격 보너스, 방패는 정면만 막는다.
- **스태미나(기력)**: 공격·막기·회피로 소모된다. 고갈되면 방어 반응이 불가능하다.
- **사기**: 아군·적 모두. 동료의 죽음, 수적 열세, 큰 부상으로 하락 → 도주·항복. 항복한 적은 포로로 잡거나 몸값을 받거나 처형할 수 있다(사고·평판에 영향).
- **소음·냄새**: 행동마다 소음 반경이 있다. 판금 갑옷은 은신을 거의 불가능하게 만든다. 피 냄새는 바람을 타고 퍼진다.
- **조명·시야**: 밤엔 횃불 반경만 보인다. 횃불을 든 쪽은 멀리서도 보인다(양날의 검).
- **환경**: 불 확산, 진흙(이동 TU ×1.5), 얼음(미끄러짐 판정), 문 닫기/잠그기, 좁은 통로 병목, 높이.
- **장비 상태**: 날 무뎌짐(숫돌로 관리), 활시위 습기, 방어구 부위별 내구도(구멍 난 사슬은 그 부위만 약해짐).

| 깊이 | 내용 |
|---|---|
| L1 | 때리고 막고 물약 마신다 |
| L2 | 방향·지형·조명을 이용한 포지셔닝. 피해 유형별로 무기 바꾸기(판금엔 둔기) |
| L3 | 도주하는 적을 출혈로 말려 죽이기. 바람 반대편에서 접근해 냄새 숨기기. 적 방어구의 구멍 난 부위를 노리기 |

### 6.5 장비 · 재질 · 제작

- **재질이 속성을 결정한다**: 같은 "장검"이라도 청동·철·강철·운철로 무게·날카로움·내구도가 다르다. 가죽도 종류별로 단열·방어가 다르다.
- **품질 단계**: 조악 / 보통 / 좋음 / 뛰어남 / 명품 / 전설. 제작 숙련과 도구·작업장이 결정한다.
- **의복 층**: 내의 · 중간 · 외투 · 갑옷(상/하체) · 머리 · 손 · 발. 층마다 단열·방어·소음·무게가 있다.
- **제작**: 레시피 + 작업장 + 숙련 + 재료 속성 상속. 수리도 제작의 일부다.
- **고유 아이템**: 세계 역사 시뮬에서 생성된 전설 무기에는 "누가 만들고 누가 쓰다 어디서 잃어버렸는지" 내력이 붙는다.

### 6.6 캐릭터 성장

- **능력치 5종**: 근력 · 민첩 · 지각 · 활력 · 의지. 거의 고정이고, 극한 경험이나 노화로만 변한다.
- **숙련(사용 기반)**: 한손검, 양손무기, 창, 도끼, 둔기, 활, 석궁, 방패, 맨손, 의료, 생존, 요리, 제작, 사냥, 협상, 은신, 자물쇠 등.
  - 쓰면 오른다. **열정**(없음/관심/열정)이 학습 배율을 정한다.
  - 높은 숙련은 오래 안 쓰면 천천히 녹슨다.
- **재능**: 숙련이 임계값(예: 20/40/60)에 도달하면 갈래 선택형 재능이 해금된다.
  - 예: 의료 40 → "야전 외과의(소작 통증 -50%)" vs "약초학자(미확인 약초 1회 안전 감별)".
- **나이**: 계절이 지나면 나이를 먹는다. 장기 플레이에선 노화가 오고, 은퇴가 하나의 엔딩이 된다.

### 6.7 지식 · 발견 ("파고들기"의 엔진)

- **도감**: 몬스터 정보는 단계적으로 열린다.
  - `???` → 관찰(대략적 체력·공격 유형) → 전투 경험(약점 피해 유형) → 해부(장기 구조·재료) → 문헌(습성·출몰 계절).
- **미확인 아이템**: 물약·약초·버섯은 처음에 효과를 모른다. 확인 방법은 맛보기(위험), 감별 숙련, 책, 상인에게 묻기(돈)가 있다. 효과는 **시드마다 섞인다**(일부 핵심 아이템 제외).
- **문해력**: 글을 못 읽는 배경의 캐릭터는 책·두루마리를 쓰지 못한다. 배울 수는 있다(시간 투자).
- **지도와 소문**: 지도는 직접 탐험하거나 산다. 산 지도는 **틀릴 수 있다**(지도 제작자의 신뢰도). 소문은 거리에 따라 늦게 도착하고, 왜곡된다.
- **지식의 영속성**: 지식은 캐릭터에 귀속된다(죽으면 사라짐). 연대기에는 "이전 캐릭터가 발견한 것"이 기록으로 남지만, 게임 내 효과는 없다(하드코어 유지).

### 6.8 월드 생성 & 시뮬레이션

**생성 파이프라인**
```
높이맵 → 강·호수 → 기후(위도·고도·바람) → 바이옴 → 자원 분포
→ 정착지 → 도로 → 세력 배치 → 역사 시뮬(N년) → 유적·전설 아이템·원한 관계 배치
```
- **역사 시뮬**: 세력 간 전쟁·동맹·몰락을 수십 년 돌리고 결과를 지형에 남긴다(폐허가 된 성, 버려진 광산, 세력 간 원한).

**런타임 시뮬레이션** (플레이어가 없어도 세계가 굴러감)
- 세력 관계 매트릭스(호감·적대·전쟁·동맹), 영토 변화
- 캐러밴 이동과 지역별 수요·공급 기반 가격
- 역병 확산(단순 감염 모델: 감염·회복 비율로 정착지 간 전파)
- 계절·날씨(비·눈·폭풍·안개)가 이동·전투·생존에 영향
- **LOD 시뮬레이션**: 플레이어 근처는 정밀하게, 먼 곳은 요약 시뮬레이션으로 처리(성능)

### 6.9 스토리텔러

RimWorld 스토리텔러를 참고한 사건 생성 AI.

- **위협 예산**: 시간이 지날수록 쌓이고, 사건이 발생하면 소비된다. 예산 규모는 플레이어의 *부와 명성*에 비례한다(적의 *강함*이 아니라 *관심*이 커진다).
- **사건 Def**: 발생 조건, 가중치, 쿨다운, 후속 사건 사슬. 예: "도적 습격" → (승리 시) "도적 두목의 복수" 대기열 추가.
- **성향 (가칭)**

| 성향 | 성격 |
|---|---|
| 연대기 작가 | 긴장이 점점 올라가는 곡선. 큰 사건 뒤엔 숨 돌릴 틈 |
| 광대 | 완전 랜덤. 사흘 연속 재앙도, 한 달 평화도 가능 |
| 은둔자 | 전투 사건 적음. 생존·탐험·질병 중심 |

- **사건 종류**: 습격, 매복, 상인 방문, 구조 요청, 역병, 혹한, 세력 전쟁 휘말림, 기묘한 방랑자, 유적 발견 소문, 계약(퀘스트).

### 6.10 동료 & 거점 (확장 단계 — MVP 밖)

- **동료**: 고용·구출·포로 회유로 합류한다. 관계(호감·불화), 특성 충돌, 급여·식량을 요구한다. 전투에선 명령(공격/방어/후퇴/따라오기)으로 간접 지휘한다.
- **거점**: 버려진 요새·농장을 점유한다. 방어 시설, 작업 배정(RimWorld 간소화판), 저장고, 습격 방어전.
- MVP 이후 크레딧 여유 또는 후속 개발로 진행한다.

### 6.11 하드코어 · 저장 정책

| 모드 | 규칙 | 업적 |
|---|---|---|
| **각인** (기본) | 단일 슬롯, 종료 시 저장, 자동저장 덮어쓰기. 죽으면 끝 | O |
| **순례** | 여관·야영지에서만 수동 저장 | O |
| **탐구** | 자유 저장/불러오기. 연대기에 "탐구" 표시 | X |

## 7. 랜덤성 설계

- **시드 기반 결정론**: 같은 시드 + 같은 입력 = 같은 결과. 리플레이, 버그 재현, 밸런스 봇이 모두 이 위에서 돈다.
- **RNG 스트림 분리**: 월드 생성 / 전투 / 전리품 / 스토리텔러 / AI가 각각 독립 난수 스트림을 쓴다. UI 조작이 전투 결과를 바꾸는 나비효과를 막는다.
- **정수 연산**: 핵심 수치(혈액 ml, TU, 무게 g, 확률 ‱)는 정수·고정소수점으로 처리한다. 플랫폼 간 부동소수점 차이로 결정론이 깨지는 걸 막기 위해서다.
- **공유 가능한 시드**: "시드 + 스토리텔러 + 모드 목록"을 문자열로 공유하면 같은 세계를 만들 수 있다.

## 8. 모드 / 확장성 아키텍처

### 8.1 원칙

- 기본 게임 콘텐츠 전체가 `core` 모드다. 엔진 코드에 콘텐츠를 하드코딩하지 않는다.
- 모더가 쓰는 도구(스키마 검증기, Def 뷰어, 시뮬 러너)는 개발자가 쓰는 도구와 같다.

### 8.2 Def (데이터 정의)

- JSON 기반. 스키마(zod)로 검증한다.
- **상속**: `parent`로 추상 Def를 상속한다(RimWorld의 ParentName과 같은 개념).
```json
{
  "defType": "WoundDef",
  "id": "Wound.DeepCut",
  "parent": "Wound.CutBase",
  "label": "깊은 베임",
  "bleedPerTurnMl": 40,
  "infectionChance": 0.08,
  "painPerSeverity": 0.12,
  "healDaysBase": 9,
  "scarChance": 0.35
}
```

### 8.3 패치 (다른 모드의 Def 수정)

- 경로 기반 연산: `add` / `replace` / `remove` / `merge`, 조건부 적용(`ifModLoaded`).
```json
[
  { "op": "replace", "target": "Wound.DeepCut", "path": "/bleedPerTurnMl", "value": 55 },
  { "op": "add", "target": "Race.Human", "path": "/traits/-", "value": "Trait.Nightwalker",
    "ifModLoaded": "someone.nightmod" }
]
```

### 8.4 스크립트 훅 (단계적 도입)

- 1단계(MVP): **데이터 모드만** 지원한다.
- 2단계: 타입이 정해진 훅 포인트 + 워커(Worker) 등록으로 동작을 확장한다.
```ts
export default defineMod({
  hooks: {
    onWoundInflicted(ctx, wound) {
      if (wound.part === 'Hand.Left' && ctx.rng.chance(0.1)) ctx.addThought('Thought.Maimed')
    },
  },
})
```
- 스크립트는 샌드박스(Web Worker + 허용 API만 노출)에서 실행한다. 난수는 `ctx.rng`만 쓸 수 있다(결정론 보장).

### 8.5 매니페스트 & 로드 순서
```json
{
  "id": "someone.nightmod",
  "version": "1.2.0",
  "gameVersion": ">=0.3 <0.5",
  "dependencies": ["core"],
  "loadAfter": ["core"],
  "incompatibleWith": []
}
```
- 의존성 그래프를 위상 정렬하고, 순환이나 충돌이 있으면 로드 전에 리포트한다.
- **배포**: 웹 버전은 폴더·zip을 불러온다. Steam 버전은 Steam 창작마당(UGC)으로 구독·업로드한다.

| 언어 | TypeScript (strict) | 코어부터 UI까지 단일 언어 |
| 시뮬 코어 | 순수 TS, DOM 의존 0 | 헤드리스 테스트·봇·워커 실행 |
| UI | Vue 3 (Composition API) + Tailwind v4 | 인벤토리·캐릭터 시트·툴팁처럼 복잡한 UI |
| 맵 렌더링 | PixiJS | 타일맵 + 조명·시야 레이어, WebGL |
| 빌드 | Vite, pnpm workspace | |
| 품질 | ESLint Flat, Vitest, fast-check(속성 테스트), Playwright | |
| 데스크톱 | **Electron + steamworks.js** | Steam 오버레이 헬퍼 제공. Tauri는 WebView2 위에서 Steam 오버레이가 표시되지 않는 문제가 보고돼 제외 |

※ Nuxt는 쓰지 않는다. 게임 클라이언트엔 SSR·파일 라우팅이 필요 없다.

### 9.2 모노레포 구조
```
ashmarch/
├─ packages/
│  ├─ core/          # 시뮬레이션 (턴 스케줄러, 신체, 전투, 생존, 월드, 스토리텔러)
│  ├─ defs/          # Def 스키마 · 로더 · 상속 · 패치 엔진 · 모드 매니페스트
│  ├─ content-core/  # 기본 게임 = core 모드 (JSON)
│  ├─ client/        # Vue3 + PixiJS + Tailwind v4
│  ├─ desktop/       # Electron 셸 + steamworks.js + 플랫폼 어댑터
│  └─ sim-cli/       # 헤드리스 시뮬 · 밸런스 봇 · Def 검증 CLI
└─ docs/             # GDD, 모딩 가이드, 수식 문서
```

### 9.3 핵심 결정

- **상태 = 직렬화 가능한 순수 데이터.** 세이브는 상태 스냅샷 + 버전, 버전 간 마이그레이션 함수를 둔다.
- **`Math.random` 금지**: ESLint 규칙으로 차단한다.
- **월드 시뮬은 Web Worker**에서, 렌더링은 메인 스레드에서 돌린다.
- **플랫폼 어댑터**: `Platform` 인터페이스(저장소, 업적, 클라우드 세이브, 창작마당)로 웹과 Steam의 차이를 숨긴다.

## 10. 검증 전략

"제가 직접 돌려서 확인할 수 있는가"가 이 프로젝트의 핵심 조건이다.

| 계층 | 방법 | 예 |
|---|---|---|
| 공식 | 단위 테스트 + 문서화된 검산 | 출혈 시간, 방어구 기대 피해 |
| 불변식 | 속성 기반 테스트(fast-check) | 혈액량 0~5000, TU ≥ 1, 무게 ≥ 0, 상처 수 ≥ 0 |
| 결정론 | 같은 시드 + 입력 → 상태 해시 일치 | 1,000턴 리플레이 해시 비교 |
| 밸런스 | 헤드리스 봇 N판 자동 플레이 | 사망 원인 분포, 평균 생존 일수. 한 원인이 50%를 넘으면 경고 |
| 모드 | Def 검증 CLI | 스키마 오류, 존재하지 않는 참조, 순환 상속 |
| UI | Playwright 스모크 + 스크린샷 | 새 게임 → 10턴 진행 → 저장/불러오기 |

## 11. 세계관 가안 (교체 가능 — 이것도 core 모드의 데이터일 뿐)

- 몰락한 제국의 북쪽 변경. 20년 전 **"재의 겨울"**(화산 겨울 + 역병) 이후 중앙의 통제가 사라졌다.
- 소영주·용병단·교단·도적이 난립한다. 교역로는 끊겼다 이어지기를 반복한다.
- **로우 판타지**: 마법은 드물고 대가가 크다(사용할 때마다 정신력이나 신체가 소모됨). 괴물은 대부분 변이된 짐승과 역병의 산물이다.
- 플레이어는 이름 없는 떠돌이다. 배경(탈영병, 파계승, 사냥꾼, 몰락 귀족 등)이 초기 숙련·특성·문해력을 정한다.

## 12. 범위 & 마일스톤 (크레딧 250달러 기준)

### 12.1 목표 정의

크레딧 250달러로 **상업 출시 가능한 완성작은 불가능**하다. 목표는 아래 세 가지다.
1. **1개 지역 버티컬 슬라이스**: 30분~2시간 플레이 가능, 죽고 다시 하고 싶은 수준
2. **확장 가능한 엔진**: 모든 시스템이 Def로 확장 가능
3. **모드 파이프라인**: 샘플 모드 1개가 실제로 동작함

Steam 출시에는 별도로 Steam Direct 등록비(앱당, 2026-10 기준 금액 재확인 필요), 아트·사운드, 외부 플레이테스트가 필요하다.

## 부록 A. 수식 검산

| 항목 | 계산 | 결과 |
|---|---|---|
| 깊은 베임(40ml/턴) 위험 단계 도달 | 5000 × {0.3, 0.4, 0.5} / 40 | 쇼크 37.5턴 · 기절 50턴 · 사망 62.5턴 |
| 동맥 절단(150ml/턴) | 5000 × {0.3, 0.4, 0.5} / 150 | 쇼크 10턴 · 기절 13.3턴 · 사망 16.7턴 → **약 10턴 안에 지혈대** |
| 방어구 0.8 vs 관통 0.2 | 유효 0.6 → 튕김 0.3 / 절반 0.3 / 관통 0.4 | 기대 피해 배율 = 0.3×0 + 0.3×0.5 + 0.4×1 = **0.55** |
| 명중 (숙련 30 vs 회피 20, 야간 -15, 측면 +10) | 50 + (30−20)×2 − 15 + 10 | **65%** |
| 비타민 고갈 | 100 / 2(일) | **50일** |
| 이동 TU (과적 + 다리 골절) | 100 × 1.25 × 1.5 | 187.5 → **188TU** |

※ 모든 수치는 초안이며, M2~M3에서 밸런스 봇 결과로 조정한다.
