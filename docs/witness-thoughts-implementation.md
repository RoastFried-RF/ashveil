# 직접 들은 기계음과 목격한 동료 상실

v0.135.04 #26의 야생 정원사 기계음−4/신앙심+4를 실제 소음 전파에 연결했다. 살아 있는 현재 지도의 기계형 정원사가 실제 낸 소리를 기존 거리/벽/닫힌 문/환경 소음/청각 계산을 통과해 깨어 들었을 때만 조건 인지가 생긴다. 눈으로 본 기계의 존재만으로 만들지 않는다. 같은 정의의 소리는 중첩하지 않고 마지막 실제 소리에서 갱신한다. 고용된 기계는 야생 출처에서 제외한다. 자거나 실신한 사람에게 의식 있는 인지를 소급하지 않으며 기존 각성 규칙은 유지한다. 동물/기계는 인간 사고를 갖지 않는다.

소리가 멈춘 뒤20턴(1분)의 인지 유지, 동료 상실의5일째50% 경감은 원문에 없는 모드 가능한 구현 기본값이다. 정본의 새로운 확정 수치로 쓰지 않았다. 기록은 사고ID/만료만 저장하고 보지 못한 출처 위치를 저장하거나 화면에 노출하지 않는다. 조회는 만료/UID/난수/물품을 바꾸지 않는다.

04 #39의 동료 상실−20/10일/3×0.5는 고용/급료 대기 중 실제 동료가 처음 죽을 때, 살아 깨어 있고 그 사망을 볼 수 있는 고용주와 현지 동료에게만 적용한다. 해고/배신/떠남·숨은/다른 지도·수면/실신/눈 손상·반복 사망에는 새 상실을 만들지 않는다. 냉혈의 면제는 정본에 없어 새로 만들지 않았다. 같은 진영 전체로 원격 전파하지 않는다. 일반NPC 동료는 기존 개인 스트레스 요약으로 받아 본래 세력을 유지한다. 나중에 실제 전령/시체 확인을 통해 알게 되는 원격 사망 보고 경로는 아직 구현하지 않았으며 기존 일반 사망 로그/사고의 시야 정책까지 이 작업에서 바꾸었다고 주장하지 않는다.

각인98→99는 버전만 바꾸며 과거의 들은 소리나 동료 사망을 추측해 넣지 않는다. 전용28/관련4파일98개, 타입/린트/Def189패치/Schema111개를 검증한다. 전체 골든5개는 초기/최종/오류 전부 버전99 외v134와 같다. v0.135에서는 실제 전달된 야생 정원사 기계음/신앙심 반전과 직접 목격한 동료 상실을 연결했다. 원래 초기 고용 계약에서40표를 실제 이전한 같은 동료의 출혈 사망을 검증했다. 각인v99·전용28/관련98개·전체137파일2,651개125.76초·타입/린트/Def189패치/Schema111/빌드·화면641~646 여섯 장 전체 확인·6전체 복원/실제19턴 재개/콘솔0이다. 월드30판307.760037416초의 전체 기록이v134와 같다.
