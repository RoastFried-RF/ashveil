# 젖은 침구와 새 야영불의 실제 흔적 — v0.75

침구 위에서 실제로 자거나 쉬거나 실신한 몸과 맞닿은 옷/맨살 사이에 젖음이 천천히 옮겨 간다. 서 있거나 옆 칸에 있는 사람에게 즉시 전이하지 않는다. 최외곽 옷이 있다면 그 옷부터 닿고 안쪽 옷·맨살을 건너뛰지 않는다. 마른 침구도 젖은 몸에서 수분을 받는다. `BeddingContact.Hearth` 기본 교환율은 젖음 차이×0.6/시간(1200턴)이며 설정할 수 있다. 부위 가중합만큼 실제 침구에서 공제/수취하며, 이 상태 교환을 음용수ml로 만들거나 몸의 수분 결손을 지우지 않는다. 비·불·바람의 기존 건조, 단열·수면 질·몸이 젖어 깨는 규칙은 계속 적용된다.

같은 실제 침구 물품 UID/젖음과 같은 몸·옷을 보존한다. 포장·재설치로 젖음을 지우지 않는다. 미리보기는 젖음을 진행시키지 않는다. F2의 실제 침구 행에 현재 젖음을 표시한다. 별도 설치 물품이 없는 원래 지형 침대의 축축함 상태와 곰팡이/질병·화재 전체는 남는다.

순찰의 기존 불빛/연기 감지를 실제로 설치한 야영불 위치에도 적용한다. 실제 물품 UID·소유권·켜짐·남은 연료를 확인한다. 낮 연기15칸/바람 아래22.5칸, 밤 실제 빛 반경×3의 기존 감지 규칙을 공유한다. 먼 첫 불 때문에 가까운 다른 실제 불을 놓치지 않는다. 차가운 꾸러미·끄거나 소진된 불·다른 사람의 불·사라진 물품은 플레이어 야영 흔적으로 보지 않는다. 기존 순찰자가 흔적을 감지해 실제 귀환 경로와 보고를 맡는다. 이 감지에서 새 사람이나 수색대를 생성하지 않는다.

새 저장 필드가 필요 없어 각인v39와 기존 해시를 유지한다. 기존5개 전체 초기/최종 골든 상태와 원래 명령/오류가 v0.74와 정확히 동일하다(`golden-v075-diff.json`). 전용15·Def1을 추가했고 관련4파일107개/전체77파일1,228개 검사55.12초에 통과했다. 타입·린트·빌드·Def/JSON Schema70파일 오류0이다.
