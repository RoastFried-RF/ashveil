# 실제 상점 재료로 준비하는 상인의 지도

v0.170 작업은 곁의 상인에게 자기 기록을 그려 달라고 부탁하면 원래 자기 상점에서 빈 종이1장/잉크1회분을 작업용으로 챙기는1턴 행동을 연결한다. 이미 가진 재료가 있으면 빠진 종류만 가져온다. 재료를 새로 만들거나 원격 상점/다른 사람의 돈을 쓰지 않는다. 완성 원본을 실제로 살 때만 플레이어가 대금을 낸다. 예약 보수/완료 보장을 가진 정찰 계약이라고 주장하지 않는다.

상인은 실제 현재 정착지의 자기 상점 곁에 있고 대화/문해/몸/빛/개인 기록 조건을 만족해야 한다. 진행 중 작업/같은 기록의 완성본이 있으면 재료를 반복해서 챙기지 않는다. 현재 자기 재고/배낭을 복사해 두 재료가 모두 실제로 들어가는지 검증한 뒤 한 번에 반영한다. 원래 묶음에서 한 개를 분리할 때만 새로운 UID를 배정하며 원래 수량과 속성은 보존한다. 부족/가득 찬 배낭/불가능한 작성은 원래 개인·상점 재고/UID/돈/난수를 모두 보존한다.

준비 뒤에는v169의 일반NPC 생활/안전 우선순위와60턴 자기 지도 작성·동일 원본 판매를 사용한다. 부탁만으로 내용을 알게 되지 않으며 완성 원본 구매/직접 독서는 별도1턴씩이다. 상점 금고나 재고를 자동 보충하지 않는다.

실제 지역 생성기의 방 칸에 `room` 인덱스가 없는 경우에도 NPC가 물리적으로 그 방 안에 서 있으면 자기 실제 차례에 기록할 수 있도록 보강했다. 유효한 칸 인덱스를 우선하고 실제 경계 안의 방을 찾으며, 실제로 방 밖에 있는 옛 인덱스/인물의 출생 방은 증거로 쓰지 않는다. 깨어 있음/시력/빛 조건은 유지한다. 플레이어의 숨은 원격 방 기록을 복사하지 않는다.

별도 PATCH의 `independent.shopSupplies` 설정이며 각인125를 유지한다. 기존5골든의 전체 초기/최종 상태·오류·해시는v169와 같아 원래 기대값은 변경하지 않았다. 전용16개/관련3파일64개·최종골든 포함2파일26개·타입/린트·빌드3duLyCpk1.62초를 확인했다.

브라우저 검사는 실제 지역 생성기의 원래 상인/금고/종이6장·잉크8회분을 가진 유효 초기 스냅샷에서 시작한다. 초기 시각은 원래 입장 시각보다 이르게 되돌리지 않고 처음 기록할 인물의 과거 관찰은 준비하지 않는다. 과거 입장/여행/생활 입력까지 이 검사에서 실행했다고 주장하지 않는다. 실제 대기1턴의 관찰·준비1턴/작업60턴·동일 원본 구매/독서·미완료 저장을 확인한다. 브라우저836–841의6개 장면을 모두 직접 확인했다. 실제 관찰1턴/준비1턴·NPC60턴 작업(59번 추가대기)·원본UID90/잉크91·원래 상점 종이6→5/잉크8→7·금고300 보존·구매15표(P200→185/NPC0→15)/직접I독서 각각1턴·4전체 각인125 복원/남은7970TU(79.7턴) 전체 일치·콘솔0을 확인했다. 전체 회귀를 진행한다.
