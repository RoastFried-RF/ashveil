# 약탈단 작성자의 의도적 거짓 물 시설

v0.172 작업은 실제 약탈단 작성자의 지상 지도에30% 확률로 없는 물 시설1~2개를 적는 경로를 연결한다. 별도 PATCH의 세력/확률/수량/시설 이름/신뢰도20을 사용한다. NPC의 기존 실제60턴·원래 종이/잉크·저자/시각을 유지하며 완료할 때 독립적인 종이UID 난수로 판정한다. 견적/작업 중/일반 작성자/플레이어 자기 지도는 이 거짓말 난수를 쓰지 않는다. 지하 지도에는 넣지 않는다.

작성자는 자기 현재 시야 안의 실제 마른 통행 칸만 골라 물 시설이 있다고 적는다. 플레이어 시야/관찰이나 숨은 원격 지형을 조사하지 않고 실제 물·우물·지형·아이템을 만들지 않는다. 이미 기록한 위치는 중복하지 않고 최대128개 표식을 넘기지 않는다. 공간/후보가 부족하면 그 범위 안에서만 적는다. 원래 실제 물 기록/방/계단도 기존 누락/오차 규칙을 사용한다.

문서/화면에 가짜 여부·참 위치 같은 정답을 넣지 않는다. 신뢰도와 원래 저자/가격을 보고 같은 유한 원본을 구입할 수 있다. 구입은1턴과 실제 현금이며 내용을 자동 학습하지 않는다. 실제 독서 후 지도 주장을 배우고, 자신의 과거 직접 관찰이 있는 칸만 그 기록과의 불일치로 표시한다. 본 적 없는 칸은 숨은 실제 바닥이 물이 아니더라도 미확인 주장으로 둔다.

이 작업은 의도적 거짓 **물 시설**을 다룬다. 실제 매복 계획/매복지를 ‘안전한 길’로 파는 전체 함정 지도 경로는 아직 남는다. 거짓 시설을 표시했다고 실제 매복단/안전한 길이 생성되었다고 주장하지 않는다.
