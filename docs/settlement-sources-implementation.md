# 실제 현지 배치 인원의 소속 명단

v0.196 통합 검증 완료. 새로 정착지를 실체화할 때 그 호출에서 실제 생성된 현지 인물만 원래 ID로 등록한다. 정착지 소유 세력을 명시하며 대표 인물 종의 기본 세력으로 바꾸지 않는다. 현재 정착지/실제 객체/생존/소속/지도/중복을 확인한다. 추상 SIR 총인구가 아닌 현재 처음 배치한 집단의 명단이다. 나중 출생/이주/증원을 자동으로 포함했다고 주장하지 않는다.

기존 초기화된 정착지에는 명단을 소급해서 만들지 않는다. 같은 등록을 반복해도 명단/시간/난수/UID를 바꾸지 않는다. 현재·정지·이동 보관의 원래 ID를 추적하고 동료로 영입된 인물은 가용 수에서 제외한다. 해산하면 같은 몸을 다시 센다. 현지 주민 집단 소멸은 적 야영지 고갈 명성을 주지 않는다.

각인137→138은 버전만 이관한다. 기존 다섯 골든의 전체 초기/최종 상태와 오류는 버전 외에 같고, 이전195 기준을 한 번 보관한 후 두 기대 해시만 갱신했다. [전체 비교](golden-v196-diff.json). 새 Item/Def는 없다. 명단을 화면에 숨은 인구 총계로 노출하지 않는다.
