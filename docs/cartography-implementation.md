# 당시의 쪽지 지도와 직접 탐험 기록

v0.151은 원래 서가/석관 쪽지의 아래층 방 단서에 당시의 지도 조각을 붙인다. 원래 story 난수/단서는 유지하며 실제 새 쪽지 작성 경로에서만 독립`items.cartography.UID`로 누락/위치 오차를 판정한다. 기본 신뢰도40/오차2는 Cartography.Hearth의 조정 가능한 콘텐츠 기본값이다. 정본06의 누락률`(100−신뢰도)/2%`를 사용하고, 지도에는 방의 기하와 이름만 남긴다. 현재 생물/재고/재점거 상태를 넣지 않는다.

쪽지를 가지고만 있으면 지도 지식을 얻지 않는다. 실제 읽은 뒤에는 저자·작성 시점·출처·신뢰도·오차·그려진 위치를 보존한다. 봉화 전달도 원본 중첩 정보를 보존한다. 이후 지형이나 원본 쪽지가 바뀌어도 배운 지도를 현재 진실로 갱신하지 않는다. 지도 조회와 미방문층의 지도 표시는 실제 미방문 지형을 생성하지 않는다.

지도 창은 직접 본 방/지도 주장/옛 소문을 구분한다. 서로 다른 위치를 그린 두 문서는 덮어쓰지 않고 함께 보여 준다. 실제 발견한 방과 같은 식별 기록이 있으면 직접 본 기하를 우선하고 잘못된 옛 위치도 출처가 남는다. 방 식별 기록이 없는 옛 지도는 동명 방 하나만 보고 거짓이라고 단정하지 않는다. 실제로 보지 않은 방/다른 지역의 현재 상태를 조회하여 지도를 판별하지 않는다.

실제 깨어 있는 플레이어 시야는 지형과 관찰 시점을 기록한다. 보이지 않는 곳의 현재 지형이 바뀌어도 지도에는 마지막으로 직접 본 값을 쓴다. 맹인/수면/실신 상태의 갱신으로 새 시각 기록을 만들지 않는다. 구형114 각인에는 과거 관찰 시점이나 지도 저자를 추정하지 않으며 버전115만 이관한다. 옛 미기록 탐험 정보는 기존의 날짜 없는 표시로 유지한다.

전용22/관련2파일48개·타입/린트·Def210패치/Cartography1/Schema125/오류0·빌드를 통과했다. 골든5개 초기/최종 전체를 비교했고 새 관찰/쪽지 지도/깊이/독립 난수 외 기존 필드와 오류는 모두 같다. 모든 새 관찰의 실제 본 칸/유효 지형/미래가 아닌 시각, 지도2개의 원래 방 식별/크기·±2 오차를 확인했다. [전체 비교](golden-v151-diff.json).

브라우저의 검증/반박 장면은 실제 생성한 원래 방의 유효 초기 탐험 기록과 원래 지도 쪽지를 사용한다. 그 과거 탐험을 브라우저에서 실행했다고 주장하지 않는다. 실제 화면/전체 각인 복원/19턴 재개와 전체 회귀·월드 검증을 완료했다. 종이·잉크를 쓰는 직접 지도 작성/유한 거래·함정 지도, 월드 범위 지도는 다음 후속에 포함된다. 새 아이템은 추가하지 않았다.


v0.151은 당시 쪽지 지도와 실제 본 지형/시각을 연결했다. 지도 저자·시점·신뢰도·오차와 두 주장 충돌을 보존하고 직접 탐험을 우선한다. 각인115·전용22/관련48·전체154파일3,008개150.23초·Def210패치/Schema125·화면734~739 여섯 장 전체 확인·6전체 복원/실제19턴 재개 전체 일치/콘솔0이다. 시야 기록의 공통 몸 상태 계산을 한 번으로 줄여 같은 골든 상태를 유지했다. 월드30판359.60706046999996초의30행 전체가v150과 같다. [전체 비교](sim-v151-diff.json). 최초 넓어진 창 버전의 전체검사에서는 한 긴 휴식 검사가 시간 제한을 넘었고, 나머지3,007개는 통과했다. 한 칸마다 반복하던 공통 시야 몸 상태 계산을 밖으로 옮긴 최종 불변 소스로 전체3,008개와 동일 골든을 다시 확인했다. 제한 시간을 늘리지 않았다.
