# 실제 인원과 흔적을 요구하는 장소 사건 계약

v0.189 구현. 정본design/11 §3.2.1·3.4에 맞춰 실행 중인 네 사건의 타입을`PlaceEvent`로 전환했다. 기존`Event.*`ID·각인135와 실제 순찰/수색/재점유/보관함 습격의 기본 동작은 유지한다. TypeScript의`EventDef`는 기존 호출부의 타입 별칭으로만 남으며 JSON의폐지된`Event`/`EventDef`형식은 오류다.

출발지`origin`은 실제 세력/야영지 또는 실제 방 공급원, 후속 사건이면 원래 파견 사건을 가리킨다. `composition.fromPopulation`은true만 허용하고, 원래 인원 범위는`composition.count`다. 모든 사건에 비어 있지 않은`traces`를 요구한다. `place`는 실제 경유·확률·두목·대기 행동을 담당한다. 원래 몸의 이동/경로/개인 물품을 사용하며 새 적을 생성하지 않는다.

기존 원본은 스키마 판별용`defType`헤더만 바꿨다. 실제 설정은 새`place-event-types.json`패치20개로 추가/이전한다. 기존`place.origin`/`place.count`를 최상위 계약으로 옮기고 샘플 모드도`composition.count`경로를 사용한다. 기본268패치, 예제272패치다. 새Item은 없다.

로더는 폐지 타입/`spawn`필드, 없는 출발 참조·잘못된 세력/인원/두목, 잘못된 편성/흔적을 오류로 보고한다. 후속 사건의 자기 참조도 거절한다. 타입/원본Schema와 실제 상속/패치 뒤 의미 검증을 함께 사용한다. 모딩 가이드의 예제도 현재 경로로 바꿨다.
