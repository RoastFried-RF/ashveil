# 새 뇌 손상에서 회복한 뒤의 영구 변화

v0.150은 정본05 §2.3의 뇌 손상 회복을 실제 새 상처와 연결한다. 새 손상이 발생했을 때 인간형의 내부 의식 기관에 남은HP가50% 이하이면서0보다 크면 그 손상의 실제 상처ID·부위·시각·최저HP를 기록한다. 그 부위의 모든 상처가 실제로 치유 완료한 뒤 지각/의지 중 하나가 영구적으로1 줄어든다. 즉사한 뇌를 미래 회복 대상으로 만들지 않는다. 심각도 임계값과 후보 능력치는 Growth.Human의 PATCH다.

같은 뇌의 반복 손상은 하나의 치유 사건으로 합치고 최저HP만 갱신한다. 물리 상처가 합쳐지거나 먼저 상처 하나가 아물어도 나머지가 남아 있으면 정산하지 않는다. 실제 완료한 사건은 한 번만 처리하고 최솟값1을 지킨다. 일반 뇌진탕의 기존 의식 상한/건망 규칙과 구분하며, 해당 물리는 그대로 사용한다. NPC도 같은 자기 몸·개인 기록·독립 난수에 적용한다.

구형113에 새 손상 당시 기록이 없으면 과거 최저HP를 현재 상처에서 추측하지 않는다. 각인113→114는 버전만 이관한다. 실제 새 상처가 발생하기 전의 원격 조회나 화면은 기록/난수를 만들지 않는다. 기존 기아/회색열의 부분 규칙 PATCH와 파일 순서가 달라도 서로의 설정을 지우지 않도록 병합하며, 순서를 바꾼 검사로 확인했다.
