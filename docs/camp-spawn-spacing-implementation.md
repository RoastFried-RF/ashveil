# 새 야영지의 겹친 시작 칸 수정

v0.210 작업 중. 잿빛 수도원 야영지의 네 번째 약탈자와 마지막 약탈자가 같은 고정 칸으로 지정돼 있었다. 마지막 인물의 시작 칸만 옆의 실제 빈 바닥으로 한 칸 옮겼다. 기존 여섯 인물/명단/소지품·UID/방/집/개별 생성 순서와 모든 난수 호출은 유지한다. 임의로 다른 지형을 지우거나 인물을 새로 만들지 않는다.

새 생성에만 적용한다.151각인의 이미 살아온 인물의 현재 위치/몸/물품/난수를 바꾸지 않고152버전만 이관한다. 이미 진행한 이동이나 의도된 같은 위치의 다른 상황을 추정해 과거 인물을 재배치하지 않는다.

고정 벡터는 단순히 새 해시를 승인하지 않았다. 동결한209 엔진에서 원래 세계를 만든 뒤 마지막 실제 야영지 약탈자의 최초 위치만 x+1/버전152로 바꾸고 같은 명령을 이전 엔진으로 재생한 독립 대조 자료를 만들었다. 새210의 다섯 전체 초기/최종/오류/해시가 이 대조와 정확히 같다. 초기 차이는 한 인물의 한 칸과 버전뿐이다. 최종의 NPC 이동/체온·열량/수분 나머지와 이동 효과 차이도 이 최초 위치 보정만으로 재현됐다. 최종 상태를 정규화하거나 가리지 않았다.

기존209와도 모든 난수 스트림·다음ID·플레이어 전체 객체·오류는 초기/최종 모두 같다. [전체 비교](golden-v210-diff.json)에 각 벡터의 원래/새 해시·최초 위치 보정과 최종 차이 경로를 남겼다.209 기준은 한 번 보관했고 두 기대 해시 항목만 갱신해 명령/시드/오류 목록을 보존했다. 새 Item/Def/패치 없이 Item188/269패치/Schema136을 유지한다.

서로 다른8시드의 실제 생성에서 여섯 기존 인원/공급원 명단과 통과 가능한 서로 다른 시작 칸을 검사했다. 실제20회 대기 동안의 인물 겹침·추가 태생/ID 없음과151전체 복원 보존도 검사했다. 전용10개를 포함한 관련4파일102개6.65초와 골든 포함6파일113개9.38초가 통과했다. 최종 타입/린트/빌드1.61초가 완료됐다. 실제 화면1035–1037 세 장을 모두 확인했다. 전체152복원3/실제 대기6턴·미완료20턴2000TU의 전체 상태 일치/콘솔 오류0이다. 기존 여섯 NPC와 플레이어가 서로 다른 칸에서 시작하고 추가 인물 없이 자기 차례에 이동했다.최신210에서208–210 통합 전체214파일4210개214.34초/월드30판367.052241853초를 완료했다.207과20개 전체 행이 같고10개가 다르며 동결209 최초 배치 한 칸만 보정한 독립 대조30판355.8109032070001초의 전체 행과210이 모두 같다.

화면 장면의 플레이어 초기 관찰 위치/중립 평판/자기 몸의 필요와 사건 예산은 제어 조건이며 이동/외교/자연 조우 빈도를 완료했다고 주장하지 않는다. 원래 NPC 자체의 생성·자기 이동/몸·물품/난수를 사용한다.
