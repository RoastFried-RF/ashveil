## 1. 한 줄 요약과 판타지

> **"규칙은 투명하게, 세계는 끝없이 낯설게."**

무너진 개척 행성 **하스**. 71년째 하늘은 재로 덮여 있고, 명령을 잃은 테라포밍 기계들이 아직도 정원을 가꾼다. 플레이어는 이름 없는 **떠돌이** 한 명으로, 회색 고원의 폐허를 걸으며 살아남는다.

왼쪽 허벅지 동맥이 찢기면 10턴 안에 지혈대를 감아야 하고, 젖은 외투로 긴겨울 밤을 넘기면 저체온이 오고, 재보리빵만 50일 먹으면 잇몸에서 피가 난다. 총은 강하지만 **한 발 쏠 때마다 하루치 식량을 태운다.** 그리고 이 모든 규칙은 **재늑대에게도, 약탈자에게도, 기계에게도 똑같이** 적용된다.

### 1.1 플레이어 판타지 3가지

| 판타지 | 플레이어가 느끼는 순간 |
|---|---|
| **아는 자의 생존** | "비 오는 날 이동하면 재늑대가 냄새를 못 맡는다"를 알고, 실제로 써먹어 살아남았을 때 |
| **결과를 짊어진 삶** | 손가락 두 개를 잃은 뒤 양손 도끼를 내려놓고 창을 배우기 시작할 때 |
| **나만의 이야기** | 사망 보고서를 읽고 "그때 그 돼지만 피했어도"라고 친구에게 이야기할 때 |

### 2.1 기둥 (지킬 것)

| # | 기둥 | 의미 | 검증 질문 |
|---|---|---|---|

| P2 | **이야기 생성기** | 세계·인물·사건이 시드마다 다르고, 시스템 충돌이 이야기를 만든다 | 이 기능이 로그·연대기에 한 줄 남길 만한 사건을 만드는가? |

### 2.2 안티 기둥 (하지 않을 것)

| 금지 | 설명 |
|---|---|
| **레벨 스케일링** | 세계는 플레이어에게 맞추지 않는다. 구제기는 1일차에도 100일차에도 똑같이 세다. 스토리텔러는 사건의 *빈도·종류*만 조절한다 |
| **불투명한 규칙** | 하드코어 ≠ 불친절. 공식과 확률은 툴팁에 전부 공개. 숨기는 건 **세계 지식**(약점, 약초 효과, 지역 정보)뿐이다 |
| **복잡함을 위한 복잡함** | 모든 디테일은 §4.6 "디테일 채택 테스트"를 통과해야 한다 |
| **선택받은 자 서사** | 떠돌이는 특별하지 않다. 특별해지는 건 플레이의 결과다 |
| **마법·외계인** | 모든 이상 현상은 정원사망·변이·인간으로 설명된다 |
| **실시간·멀티플레이·3D** | 범위 통제 |
| **타 IP 고유명사** | CANON §2. 용어집과 금지어 린트로 관리(§13) |

## 3. 레퍼런스 분해 (구조만)

| 요소 | Stoneshard 구조 | RimWorld 구조 | ASHVEIL |
|---|---|---|---|
| 조작 | 단일 캐릭터, 턴제 그리드 | 다수 정착민, 실시간+일시정지 | **단일 캐릭터 턴제**. 동료는 확장 |
| 부상 | 부위별 체력, 출혈·골절 | 신체 부위 트리 + 상태 스택 | **신체 트리 + 상처 개체**(상처 하나하나가 객체) |
| 정신 | 정신력·사기 수치 | 기분 = 요인 합산, 붕괴 | **기분 요인 합산 + 스트레스 + 트라우마** |
| 성장 | 레벨 + 능력 트리 | 사용 기반 숙련 | **사용 기반 숙련 + 임계 재능** (레벨 없음) |
| 세계 | 고정 지도 + 랜덤 던전 | 절차적 행성 + 세력 | **고정 앵커 + 절차적 지형 + 역사 시뮬** |
| 사건 | 계약(퀘스트) | 사건 생성 AI | **사건 생성기 + 계약 + 소문** |
| 정보 | 몬스터 정보 미공개 | 수치 대부분 공개 | **규칙은 공개, 지식은 발견** |
| 확장 | 비공식 | 데이터 정의 + 패치 + 코드 주입 | **JSON Def + 경로 패치 + 샌드박스 훅** |
| 저장 | 제한 저장 | 자유 저장 / 단일 저장 선택 | **각인 기본**(D4) |

**버리는 것**: Stoneshard의 고정 메인 스토리 지도, RimWorld의 다수 유닛 실시간 관리.
**더하는 것**: 기계형 생물의 대칭 규칙(출혈 ↔ 유압 누설), 지역 환경 변수(재 농도·일조 지수), 탄약 = 식량 경제.

## 4. "파고들기" 설계 원칙

사용자 핵심 욕구: **"파면 팔수록 파고들 게 많다"**, **"이런 것까지 신경 써야 돼?"**. 이것을 우연에 맡기지 않고 구조로 만든다.

### 4.1 깊이 3층 (CANON §5)

| 층 | 대상 | 발견 시점 | 예 (출혈) |
|---|---|---|---|
| **L1 표면** | 모든 플레이어 | 첫 1시간 | 피 흘리면 붕대를 감는다 |
| **L2 중간** | 몇 번 죽어본 플레이어 | 10~50시간 | 동맥 상처는 붕대로 안 멈춘다 → 지혈대. 지혈대를 오래 두면 괴사 |
| **L3 심층** | 파고드는 플레이어 | 50시간+ / 위키 | 술은 혈관을 넓혀 출혈↑. 피 냄새는 바람을 타고 재늑대를 부른다. 재비는 냄새를 지운다 |

**규칙**: 시스템 문서는 L1/L2/L3 표가 없으면 미완성이다. L3 항목 중 최소 1개는 **다른 시스템과의 교차**여야 한다.

### 4.2 규칙 대칭성

| 플레이어에게 | 적에게도 |
|---|---|
| 다리를 베이면 이동 TU 증가 | 다리 베인 약탈자는 절뚝이며 도주 → 출혈로 쓰러질 수 있다 |
| 배고프면 판단이 무모해짐 | 굶주린 재늑대는 사람에게 정면으로 덤빈다 |
| 젖으면 활시위가 처진다 | 재비 속 약탈단 궁수도 명중이 떨어진다 |
| 기절하면 재까마귀가 눈을 쫀다 | 기절한 적도 마찬가지 |
| 과열되면 행동 불가 (기계) | 플레이어의 스태미나 고갈과 같은 구조 |
| 병에 걸리면 약해진다 | 상인도 병에 걸리고, 마을도 굶는다 → 가격이 오른다 |

기계형은 [bestiary §0.3 대칭성 번역표](lore/bestiary.md)로 같은 규칙을 다른 이름으로 적용한다(출혈 → 유압액 누설, 스태미나 → 열량).

### 4.3 상호작용 매트릭스

재질·원소·환경·상태의 반응을 **데이터 테이블 하나**로 관리한다(모드로 확장 가능). 소유: [08](design/08-items-and-crafting.md)·[09](design/09-world-and-simulation.md).

| 조합 | 결과 | 깊이 |
|---|---|---|
| 재비 + 의복 | 젖음 + 재때 누적 → 단열 저하 | L1 |
| 재비 + 금속 | 부식 진행. 기름칠 시 1/5 | L2 |
| 재비 + 냄새 | 냄새 확산 −50~80% → 추적 회피 | L3 |
| 밤 + 횃불 | 시야 확보 = 멀리서 보임 + 재나방 유인 | L2 |
| 피 + 바람 | 냄새 확산 → 재늑대·잿곰 유인 | L2 |
| 재 농도 + 호흡 | 재폐 누적 → 회색열 위험 증가 | L2 |
| 불 + 정원 구역 | 경계 단계 +2 | L2 |
| 불 + 과열 중인 기계 | 열량 100 → 강제 정지 | L3 |
| 물 + 기계 | 동력핵 단락 판정 | L3 |
| 훈제 + 바람 | 잿곰 유인 | L3 |
| 굴쥐 굴 퇴적물 + 끓이기 | 초석 → 흑색화약 | L3 |
| 젖은 외투 + 열 감지 | 측량기 감지 회피 | L3 |
| 종 "세 줄" + 정원사 기계 | 일시 정지 | L3 |

### 4.4 정보 공개 정책: "규칙은 투명, 세계는 미지"

| 공개 | 미지 |
|---|---|
| 명중률·피해 공식·출혈량·방어구 판정 (Shift 툴팁에서 수식까지) | 몬스터 약점·장기 위치 (도감 단계) |
| 내 상태의 모든 수치 | 약초·물약·버섯 효과 (시드마다 섞임) |
| 날씨 효과 수치 | 정원 구역 경계 상승 요인 |
| 평판 단계별 효과 | 세력의 숨은 사정, 작가 전용 진실 |

- **사후 공개**: 사망 시 **사망 보고서**가 원인 사슬을 보여준다. 하드코어는 다음 판에 배울 수 있어야 공정하다.

### 4.5 실패가 이야기가 된다 — 연대기

죽음은 **연대기**(캐릭터 간 영구 기록)에 남는다.

> *"떠돌이 이름 없음(촌락 사냥꾼 출신), 재내림 9일. 양치기 골 북쪽 개울가. 재늑대 5마리에게 쫓기던 중 왼쪽 대퇴부 물림 → 동맥 손상. 붕대 2회 시도 실패. 11턴 뒤 출혈 쇼크, 16턴 뒤 사망. 마지막으로 먹은 것: 재보리빵 반 덩이. 소지품: 미확인 버섯 3개. 하늘: 흐림."*

- 연대기는 지식을 이월하지 않는다(게임 효과 없음, 하드코어 유지). 플레이어 머릿속 지식만 이월된다.

### 4.6 디테일 채택 테스트 — "이런 것까지?"

새 디테일은 아래 **A·B·C 중 하나 이상**을 만족해야 하고, **D**를 확인한다.

| 기준 | 질문 |
|---|---|
| A. 결정 | 플레이어의 선택을 바꾸는가? |
| B. 이야기 | 로그·연대기에 남을 사건을 만드는가? |
| C. 세계 | 세계가 "진짜로 굴러간다"는 증거가 되는가? |
| D. 비용 | 데이터(Def)만으로 추가 가능한가? 코드가 필요하면 범용 훅으로 만들 수 있는가? |

**채택 예시 (이 수준을 목표로 한다)**

| 디테일 | 시스템 | 통과 기준 | 층 |
|---|---|---|---|
| 총을 쏜 뒤 **탄피를 주워야** 경비대에 재장전을 맡길 수 있다 | 08·07 | A | L2 |
| 촌락은 개 대신 **거위**로 경보를 울린다 → 밤에 몰래 들어가면 거위가 운다 | 07·세력 | A·C | L2 |
| 엄니돼지 귀에 **녹슨 공사 꼬리표 "CALD-LS-0"** | 06 | C | L3 |

## 7. 게임 구조

### 7.1 루프 3단

| 루프 | 주기 | 내용 | 핵심 긴장 |
|---|---|---|---|
| **턴 루프** | 초~분 | 이동·공격·치료·아이템. 위치·자세·무게·부상·빛·바람이 행동 비용과 결과를 바꾼다 | 지금 이 상처를 처치할까, 먼저 도망칠까 |
| **원정 루프** | 시간~일 | 계약 수주 → 준비(식량·의약품·기름·마스크) → 이동 → 탐험·전투 → 귀환 → 치료·정비·판매 | 짐 무게 vs 대비, 시간 vs 날씨 |
| **생애 루프** | 계절~해 | 숙련 성장, 평판, 세력 관계, 계절 순환, 회색열 유행, 노화 → 은퇴 또는 사망 | 긴겨울을 어디서 날 것인가 |

### 7.2 세션 구조 예시 (실플레이 1시간)
- 정착지에서 준비 10분 → 원정 이동 10분(빠른 이동 + 조우) → 탐험·전투 25분 → 귀환·정비 15분.
- 한 원정은 게임 시간 1~4일. 1계절(18~42일)에 원정 5~10회.

### 7.3 시간 체계 요약 (CANON §4)
- **100 TU = 1턴 = 게임 시간 3초. 1시간 = 1,200턴.**
- 행동 순서는 "다음 행동 가능 시각"이 가장 이른 개체부터(우선순위 큐). 재늑대(이동 60 TU)는 플레이어 한 걸음에 거의 두 걸음.
- 위협이 없으면 자동 진행, 위협 감지 시 즉시 턴제. 월드맵 이동은 시간 단위 압축 시뮬(배고픔·체온·상처는 계속 진행).

### 8.7 전투 → [07-combat](design/07-combat.md)
- **요약**: 6단계 판정 파이프라인(명중 → 방어 반응 → 부위 → 방어구 층 → 상처 생성 → 2차 효과). 모든 단계를 툴팁·로그에 노출.

  - 방어구: 유효 = 방어 − 관통. `roll < 유효/2` 튕김, `roll < 유효` 절반+타격 변환, 그 외 관통. 층은 바깥부터.

- **3층**: L1 때리고 막는다 / L2 방향·지형·조명 포지셔닝, 피해 유형별 무기 / L3 도주하는 적을 출혈로 말려 죽이기, 바람 반대편 접근, 갑옷 구멍 노리기, 기계 과열 유도.
- **요구 연결**: 사기(약탈단 두목 붕괴 60%), 화기 = 탄약 경제, 불발(수제 뇌관 8%), 횃불 = 표적, 세 줄 종.

### 8.8 아이템과 제작 → [08-items-and-crafting](design/08-items-and-crafting.md)

- **3층**: L1 좋은 걸 입는다 / L2 기름칠·숫돌·시위 관리, 재질별 상성 / L3 장물 표식, 탄피 회수, 초석 → 화약, 정원사 부품 대체 사용.

## 11. 랜덤성 설계

| 원칙 | 규칙 |
|---|---|
| 시드 결정론 | 같은 시드 + 같은 입력 = 같은 결과. 리플레이, 버그 재현, 밸런스 봇의 기반 |
| 스트림 분리 (CANON) | **world / combat / loot / story / ai** 독립 스트림. UI 조작이 전투 결과를 바꾸는 나비효과 차단 |
| `Math.random` 금지 (CANON) | 린트로 차단 |
| 초월함수 금지 (CANON) | 코어에서 `Math.sin/exp/log` 등 금지. **사칙연산·sqrt만** |
| 정수 연산 | 혈액 ml, TU, 무게 g, 확률 ‱(만분율)은 정수·고정소수점 |
| 순회 순서 | 결과에 영향을 주는 순회는 명시적 ID 정렬(엔진 간 해시맵 순서 차이 방지) |
| 공유 시드 | `시드 + 스토리텔러 + 모드 목록 해시` 문자열로 같은 세계 재현 |
| 랜덤의 정직성 | 확률은 툴팁 표시값 그대로. "보정된 랜덤"(연속 실패 보호 등)을 쓰면 툴팁에 명시 |

**랜덤이 만드는 것 / 고정인 것**

| 시드마다 다름 | 항상 같음 |
|---|---|
| 지형, 소규모 정착지, 유적 배치 | 고정 앵커(칠번 굴뚝, 양치기 골 등) |

| 미확인 약초·물약 효과 배정 | 핵심 아이템(붕대, 지혈대, 바늘잎 차) |

| 정원 구역 기계 구성 비율 | 생물 종의 신체 구조·약점 |

## 12. 엔진 독립 원칙 (D6)

> 프로토타입 후 Godot/Unity 등으로 이전할 수 있다. **규칙과 데이터는 엔진을 갈아타도 살아남아야 한다.**

### 12.1 계층

```
┌─────────────────────────────────────────────┐
│ 표현 계층 (교체 대상)                        │
│  렌더러 · 입력 · 오디오 · UI · 플랫폼(저장소) │
├──────────── 어댑터 인터페이스 ──────────────┤
│ 코어 (순수 TS, 엔진 무관)                     │
│  스케줄러 · 규칙 · 시뮬 · RNG · 상태 · 직렬화 │
├─────────────────────────────────────────────┤
│ 데이터 (JSON Def, 엔진 무관)                  │
│  core 모드 · 사용자 모드 · 타일 매핑 Def      │
└─────────────────────────────────────────────┘
```

### 12.2 규칙 12개

| # | 규칙 | 이유 |
|---|---|---|
| E1 | 코어는 DOM·렌더러·타이머·`Date.now`·파일 API를 import하지 않는다 | 헤드리스 실행, 포팅 |
| E2 | 시간은 **TU만**. 실시간은 표현 계층의 일 | 결정론 |
| E3 | 상태는 **직렬화 가능한 평문 데이터**(JSON 호환). 클래스 인스턴스·클로저·순환 참조 금지. 참조는 ID로 | 세이브, 포팅, 디버깅 |
| E4 | 입력은 **커맨드 객체**(`{ "type": "Move", "dir": "N" }`), 출력은 **이벤트 로그** + 상태. UI는 이벤트를 소비만 | 리플레이, 엔진 교체 시 입력 매핑만 다시 |
| E5 | 수학은 정수·고정소수점, `sqrt`만 허용(CANON) | 플랫폼 간 동일 결과 |
| E6 | PRNG는 **32비트 정수 연산만 쓰는 공개 알고리즘**을 자체 구현 | C#·GDScript로 비트 단위 재현 |
| E7 | 콘텐츠의 에셋 참조는 **논리 ID**(`sprite:ash_hound`). 실제 파일(DCSS 타일)은 별도 **타일 매핑 Def**에서 연결 | 아트 교체 시 매핑만 변경 |
| E8 | 사용자 텍스트는 **로컬라이제이션 키**. 코어는 문자열을 조립하지 않고 키 + 인자를 이벤트로 낸다 | 다국어, 엔진 무관 |
| E9 | 순회 순서·정렬은 명시적(ID 정렬, 코드포인트 비교). 로케일 의존 비교 금지 | 결정론 |
| E10 | 부동소수점은 표현 계층에서만(애니메이션·보간) | 결정론 |
| E11 | **골든 테스트 벡터**: `시드 + 커맨드 로그 → N턴 후 상태 해시`를 저장소에 보관 | 포팅 적합성 검증 |
| E12 | Def 스키마는 **JSON Schema로도 내보낸다**(TS 전용 검증기 의존 금지) | 다른 언어에서 같은 검증 |

### 12.3 이전 경로

| 경로 | 방법 | 장점 | 단점 | 판단 시점 |
|---|---|---|---|---|
| A. 코어 임베드 | 새 엔진에 JS 런타임을 넣고 TS 코어를 그대로 실행 | 규칙 재작성 0 | 런타임 성능·디버깅 | 버티컬 슬라이스 후 |

## 13. 플레이 경험 시나리오

> 시스템이 실제로 만들어 낼 경험의 목표 예시. 각 장면 옆 괄호는 동작하는 시스템.

### 13.1 첫 1시간 — "붕대로는 안 되는 상처"

**캐릭터**: 촌락 사냥꾼. 특성: 대식가, 밤눈. 재내림 3일, 양치기 골 외곽.

1. **0~10분**. 높은울 촌장 헤사가 계약을 준다: "북쪽 개울에 재늑대 세 마리. 양을 두 마리 잃었어. 꼬리 셋 가져오면 18고리." 툴팁에서 처음으로 명중률 공식을 본다: `50 + (25 − 15) × 2 + 측면 10 = 80%`. (10 계약, 07, 12)
2. **10~20분**. 개울로 가는 길에 재비가 내린다. 외투가 젖고, 체온 표시가 36.8°C로 내려간다. 활시위 아이콘에 습기 경고. 헛간에서 비를 피하다 굴쥐에게 손을 물린다. 피해는 작지만 상처 상태가 "오염". (03, 08, 02)
3. **20~35분**. 재늑대는 세 마리가 아니라 다섯이다(소문 왜곡). 두 마리가 정면에서 짖고, 한 마리가 왼쪽으로 돈다. 왼쪽 대퇴부 물림 — **동맥 손상**. 로그: "왼쪽 허벅지. 피가 뿜어진다." 붕대를 감지만 출혈량 표시가 거의 줄지 않는다. 혈액량 30%에서 화면 가장자리가 어두워진다. 16턴째 쓰러진다. (07, 02)
4. **사망 보고서**: "왼쪽 대퇴동맥 물림 → 붕대 2회(동맥 출혈에 효과 낮음) → 11턴 쇼크 → 16턴 사망. 참고: 지혈대는 동맥 출혈을 멈춥니다. 소지품에 없었음." (12, 06)
5. **35~60분 (두 번째 캐릭터)**. 같은 배경. 이번엔 촌락 상점에서 지혈대(가죽끈 + 막대)를 산다. 늙은 약초할멈 노른이 굴쥐 상처는 술로 씻으라고 알려준다. 재늑대 무리 중 **목에 흉터 있는 가장 큰 놈**을 화살로 먼저 쓰러뜨리자 나머지가 머뭇거리다 흩어진다. 꼬리는 하나뿐이지만 살아서 돌아온다. 헤사: "하나라. 그래도 살아 왔군." 6고리. (04 기분 +, 06 지식, 07 사기)

**이 1시간이 가르친 것**: 상처마다 다른 처치가 필요하다(L1→L2), 적의 사기는 우두머리에 달렸다(L2), 정보(소문)는 틀릴 수 있다.

### 13.2 30시간 차 — "렌즈 하나의 값"

**캐릭터**: 고물 발굴꾼, 생존 41일. 특성: 울림 듣는 자, 추위에 강함. 볕철 5일.

1. **계약**: 갈래길 장부관의 톨렌 "반고리"가 측량 렌즈 1개에 220고리를 건다. 측량기는 칠번 굴뚝 정원 구역 외곽에 있다. 재 농도 65 구역. (10, 09)
2. **준비 (게임 시간 하루)**:
   - 귀환 보증 20고리 — 죽으면 촌락 친구에게 60고리. (세력: 길드)
   - 재 마스크와 보호안경. 재폐가 이미 18이다. (02, 03)
   - 장비 전부 기름칠. 지난번 재비에 녹슨 쇠지레가 부러진 기억. (08)
   - 바늘잎 차 10회분. 비타민 41 — 원정 중 떨어지면 안 된다. (03)
   - 활시위 여분과 밀랍. (08)
3. **접근**: 정원 구역 경계에 들어서자 UI에 경계 단계 0. "울림 듣는 자" 특성 덕에 12칸 밖의 기계 웅웅거림이 들린다 — 수리 드론 2, 측량기 1. 두통으로 기분 −3. (06, 04)
4. **교전**: 측량기의 **안테나를 먼저** 쏜다(지난 캐릭터가 죽으며 배운 것). 두 발째 명중, 신호 차단. 섬광에 눈이 멀어 2턴 허비. 렌즈를 떼어내는 데 600 TU. 그 사이 식물을 채집한 게 다섯 번째가 되며 경계 단계 1 → 수리 드론이 접근. (07, 09)
5. **도주 판단**: 수리 드론이 물에 들어가지 않는다는 걸 이 캐릭터는 모른다(도감 S2). 대신 **둔기**가 통한다는 건 안다. 망치로 한 대의 냉각핀을 부수고 개울 쪽으로 물러난다. 드론이 개울가에서 멈춘다 — 도감에 관찰 메모가 붙는다: "물가에서 멈췄다." 문헌 없이 **체험으로 L3 지식을 얻는 경로**다. (06, 07)
6. **귀환 길의 딜레마**: 순례회 행렬과 마주친다. 종지기 "꺼진 등"이 렌즈를 알아보고 말한다. "그것은 천사의 눈이다. 돌려주면 침묵원이 그대의 병을 돌봐줄 것이다." 회색열 유행 소문이 도는 중이다. 220고리냐, 순례회 우호와 간병이냐. (04, 세력, 10)
7. 길드에 판다. 220고리 중 40을 빚 상환에 쓰고, 경비대 화기 허가증(30고리)을 산다. 그날 밤 장부관 여관에서 기분 +10 "큰 거래". (세력, 04)

**이 시점의 플레이어**: 원정을 숫자로 준비한다. 도감을 채우는 것이 생존 확률을 올린다는 걸 체감한다. 세력 선택이 상점 목록을 바꾼다.

### 13.3 100시간 차 — "긴겨울, 회색 깃발 아래서"

**캐릭터**: 탈영 경비병, 다섯 번째 각인. 생존 163일(두 번째 긴겨울). 특성: 재표지자(첫 긴겨울에 회색열에서 살아남음), 냉혈, 알코올 의존.

1. **배경의 무게**: 경비대 현상금 때문에 제3 초소에 갈 수 없다. 탄약은 약탈단 장물아비에게서만 산다 — 한 발 15고리, 경비대 표식이 찍혀 있어 들고 다니면 위험하다. (세력, 08)
2. **L3 경제**: 굴쥐 굴 바닥을 긁어 초석을 끓인다. 숯과 유황(관로 누출 지대)을 더해 흑색화약을 만든다. 뇌관이 없어 총엔 못 쓰지만, 경비대 총포공 렌카가 **도른 하사를 통해** 뒷거래로 사준다. 도른은 현상금을 눈감아 주는 대가로 3할을 뗀다. (08, 세력, 06)
3. **유행**: 긴겨울 28일, 양치기 골에 회색 깃발이 걸린다. 촌락이 성문을 닫는다. 식량값 ×1.5. 재표지자인 이 캐릭터는 간병 계약을 받을 수 있는 몇 안 되는 사람이다. 검역 초막에서 이틀 밤을 지낸다. 환자 하나가 섬망 속에 그를 "아버지"라 부르며 붙잡는다. 회복한 그 양치기는 이후 고유 NPC가 되어 매번 염장 양고기를 싸준다. (02, 04, 09, 10)
4. **재비의 장막**: 구제기가 지키는 정원 구역 안쪽에 공사 문서 상자가 있다는 소문. 재비가 오는 날을 기다렸다가 들어간다 — 젖은 외투로 측량기의 열 감지를 피하고(L3), 비 때문에 소리도 묻힌다. 구제기가 깨어나자 냉각 틈을 세고, 네 번째 공격 뒤 **순례 종으로 세 줄**을 울린다. 4턴의 정지. 구역 경계 +200m 밖으로 빠져나온다. (06, 07, 09)
5. **발견**: 상자 속 문서는 반쯤 타 있다. "…토양 개량균은 인체에 무해하다. 단, 호흡기 질환자는…" 이 캐릭터는 문해력이 있다. 도감의 파종기 S4와 이 문서를 교차하면 **"회색열 = 파종기 분사"** 라는 가설 메모가 지식 탭에 생긴다(작가 전용 진실 T2의 P2 단서). (06)
6. **끝**: 긴겨울 39일, 술이 떨어져 금단으로 손이 떨린다. 약탈단 매복. 조작 −15%에 석궁 재장전이 두 번 실패한다. 오른쪽 폐 관통. 사망 보고서는 이렇게 끝난다: "…마지막으로 마신 것: 없음(금단 3일차). 연대기: 다섯 번째 떠돌이. 처음으로 회색열 가설을 기록함." 플레이어는 다음 캐릭터로 **파문된 순례자**를 고른다 — 침묵원 안에서 그 가설을 확인하고 싶어서. (02, 04, 12)

**이 시점의 플레이어**: 시스템 간 교차를 의도적으로 설계한다. 세력의 뒷사정을 이용한다. 연대기가 다음 판의 동기가 된다. 세계의 진실 일부를 "스스로 조립"했다.

| 재늑대 동맥 손상(혈액 2,400 ml, 같은 비율) 72 ml/턴 | 2,400 × 0.50 / 72 | 사망 16.7턴 — 체급이 달라도 비율 규칙이 같으면 시간 구조가 같다 |
| 방어구 0.8 vs 관통 0.2 | 유효 0.6 → 튕김 0.3 / 절반 0.3 / 관통 0.4 | 기대 피해 배율 = 0×0.3 + 0.5×0.3 + 1×0.4 = **0.55** |
| 명중 (숙련 30 vs 회피 20, 야간 −15, 측면 +10) | 50 + (30 − 20) × 2 − 15 + 10 | **65%** |
| 비타민 고갈 | 100 / 2 | **50일** (재보리빵만 먹을 때) |
| 이동 TU (과적 ×1.25, 다리 골절 ×1.5) | 100 × 1.25 × 1.5 | 187.5 → **188 TU** |
| 1시간 행군 | 1,200턴 = 120,000 TU | 이동 188 TU면 시간당 약 638칸 |
| 탄약 가치 | 1발 ≈ 하루치 식량(CANON) ≈ 12고리 | 소총 탄 10발 = 120고리 ≈ 측량 렌즈 계약 보수의 절반 |

※ CANON 상수 외 모든 수치는 초안이며 밸런스 봇 결과로 조정한다.
