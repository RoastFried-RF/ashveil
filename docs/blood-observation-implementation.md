# 실제 출혈 목격

v0.141 통합 검증 완료. 04 #35의 피를 보았다−2/2시간/중첩1을 실제 외부 출혈에 연결한다. 피 냄새에 취함은 PATCH로+4이며 기존의 가까운 출혈 적 기분+3과 별도다. 냉혈 면제는 추가하지 않는다.

현재 지도에 살아 있는 생물의 실제 흐르는 외부 상처만 원천이다. 깨어 볼 수 있는 인간형 관찰자에게 기존 시야·직선/막힌 대각선 규칙을 적용한다. 전투에서 새 상처가 만들어진 뒤2차 효과 전에, 실제 세계 턴의 신체 갱신 전에 관찰한다. 초기 상처 생성 함수/상태 조회는 기억을 만들지 않는다.

상처의 bloodSeenBy는 이 출혈을 이미 본 인물만 저장한다. 같은 상처의 계속되는 출혈/숨었다 돌아오기/각인 재개가 기억을 갱신하거나 NPC스트레스를 매 턴 만들지 않는다. 한 원천의 여러 상처를 처음 보는 같은 시점은 한 번 반응한다. 실제 관찰 턴에 출혈이0이 되면 표식을 지워 재출혈은 새 목격이 된다. 새로 생긴 다른 상처의 실제 목격도 별도 사건이다. 일반NPC는 기존 사건별 스트레스 변환을 사용하고 전체 사고 기억을 저장하지 않는다.

내출혈/장기 상처/기계 파손/죽은 뒤 처음 본 시체/바닥 혈흔은 이 경로에서 제외한다. 출혈 사망 직전에 실제 보았던 기억은 사망 후에도 유한하게 남는다. 바닥 피와 늦게 본 시체의 피를 처리했다고 주장하지 않는다.
