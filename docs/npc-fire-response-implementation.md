# 원래 자기 물로 주변 불을 끄는 NPC

v0.159는 깨어서 실제 주변 화재를 본 인간형NPC가 기존 소화 조건을 만족할 때 자기 물로 불을 끄도록 연결한다. 지형 화재500ml/침구200ml는 기존 콘텐츠의 실제 물량이다. 같은 원래 물병에서 소모하고, 여러 병이면 실제 합계를 쓰며 같은 빈 용기UID를 남긴다. 플레이어의 배낭이나 멀리 있는 재고에서 물을 꺼내지 않는다. 실제 열린 물 위에 서 있는 경우는 기존 공통 세척/소화 수원을 따른다.

소화도 원래 다음 차례의1턴이다. 진행 중 작업은 기존 중단 경로로 멈추고 물이 부족하거나 얼었거나 손/의식/포박 조건이 안 되면 소화하지 않는다. 불의 피해 범위에 있으면 기존 대피를 시도한다. 나무가 불붙은 바로 그 시각에 끄면 아직 타지 않은 연료를 탄 것으로 꾸미지 않는다. 이미 탄 재료·침구의 그을음은 기존 소화 경로대로 보존한다.

플레이어는 직접 본 NPC소화만 행위자와 물량을 알림으로 받는다. 현재 보이지 않는 다른 이의 화재/소화로 전역 지식을 얻지 않는다. 자동 소화는 바로 곁에서 할 수 있는 실제 대응이며 원격 소방 경보/직업·수송을 추가한 것으로 집계하지 않는다.

저장 형식120과 콘텐츠 수치는 유지한다. v158의5개 고정 재생 전체 초기/최종 상태·실패·해시가 같아 기대값을 갱신하지 않았다. 전용17개와 대피21개/골든 등을 포함한6파일106개가 통과했다. 타입·린트·Def224패치/Item188/Terrain80·빌드도 확인했다. 침구 검사는 실제 남은20턴을 진행해 생긴 그을음과NPC의 명시적인 원래 물병만 남긴 초기 소지품을 사용한다. NPC의 다른 기본 지급 물병이 먼저 소비되는 경우를 선택한 병 소비로 오인하지 않는다.

브라우저787–790의4개 세계 화면을 모두 확인했다. 실제 대기 키2회 중 첫 입력에 원래 기본 확률0.02의 불씨가 생기고, 다음NPC차례의1턴 소화로 같은 원래 병1L→500ml/플레이어 병1L 보존을 전체 상태로 확인했다.3개 전체 저장 복원과 실제20턴 재개도 코어 전체 상태와 같고 콘솔 오류0이다. 물 없는NPC 대피는v158의 실제 화면4장/3전체 복원과20턴 재개로 별도 확인했다. 전체 회귀/월드는v158–159통합 검사 중이며 v158별도 전체 회귀/월드는 실행한 것으로 기록하지 않는다.


v0.158–159는 실제로 본 화재의NPC 대피/순찰 경로 재계획과 원래 자기 물병의 주변 소화를 연결했다. 사람·동물·기계의 기존 몸/포박/동력·정상 이동 시간을 유지하고, 조건이 되는 사람은 지형500ml/침구200ml를 실제로 쓴다. 관찰하지 않은 소화는 플레이어 로그로 공개하지 않는다. 각인120·전용38/관련6파일106·통합 전체163파일3,143개147.67초·타입/린트/Def224패치·화면783–790의8개 장면 전체 확인/6전체 복원/저장 후20·20턴 전체 일치/콘솔0이다. 월드30판327.26855848초의30행 전체가v157과 같다. v158별도 전체 회귀/월드는 실행한 것으로 기록하지 않는다.
