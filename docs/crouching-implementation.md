# 웅크림 자세와 두 번째 원본 약탈자

v0.284 통합 검증 완료. 검증한283 원본과 분리한다. 아직 타입/관련/골든/실제 화면/전체/월드 검사를 실행하지 않았다.

정본07 §5의 웅크림은 이동2턴/자기 근접명중−10/상대 원거리명중−15/발소음×0.5다. Posture.Crouch 정의에서 읽으며 NPC도 같은 규칙이다. 기본 자세 전환은01의 토글과 같은0턴/턴당1자유행동이며 에너지/무기/몸을 새로 만들지 않는다. 깨어 있는 실제 인간형/지탱할 다리·현재 상태를 검사하고 포박/기절/넘어짐/진행중 작업은 먼저 해결해야 한다.

잠행과 겹치는 이동 시간은 더 느린 값 하나, 발소음은 더 조용한 값 하나를 쓴다. 두 배로 턴을 늘리거나0.15배로 곱하지 않는 것은 구현 기본값이다. 기존 깊은 물/기어가기의2턴 규칙은 우선한다. 문·총성 같은 별도 환경/공격 소음을 웅크림으로 지우지 않는다. 잠행의 기존 시야거리0.6 규칙은 바꾸지 않는다.

실제 넘어지거나 잠들 때 낮은 자세를 끝낸다. 의식 없는/넘어진 몸에는 웅크림 회피를 중첩하지 않는다. 캐릭터의 발 앵커는 유지하면서 낮아진 몸과 머리 표식 위치로 표현하고 HUD 현재 자세/상태 칩/읽기 전용 관찰에도 같은 유효 상태를 표시한다. Alt+C는 재지정 가능하며 한손 배치와 충돌하지 않는다.

각인192는191의 버전만 옮기며 과거 자세를 소급하지 않는다. 비활성 자세 필드는 만들지 않고 실제 선택한 상태만 저장한다.

하네스 관찰의 빠른 슬롯이 손에 든 투창을0개로 보고하던 연결도 찾았다. 실제 HUD처럼 투척물에 한해서만 손의 원본 수량을 포함하며 일반 음식/닫힌 가방의 공급 규칙을 바꾸지 않는다. 반복 관찰의 전체 상태 불변/숨은 정보 보호를 함께 검증한다.
