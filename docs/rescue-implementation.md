# 실신 포박·실제 해방과 동료 구조 — v0.66

살아 있는 항복자와 실제 의식을 잃은 인간형에게 밧줄1개/기본2턴 포박을 연결했다. 자연 수면 중 저항할 수 있는 사람과 플레이어는 대상이 아니다. 작업 중 깨어 저항하면 밧줄을 쓰지 않고 취소한다. 실신한 몸의 기존 착탈/의료·대화 활동은 공통 중단 경로로 정리해 부분 장비/치료 진행을 보존한다. 실제 몸/실신·혈액/소지품·지갑을 바꾸지 않는다. NPC도 다른 깨어 싸울 적이 없고 실제 밧줄이 있을 때 같은 견적/행동을 쓴다. 적의 기본 재고에 공짜 밧줄을 추가하거나 버튼으로 포로를 생성하지 않는다.

원래 고용한 동료도 적에게 붙잡힐 수 있다. 계약/원소속·급료/몸은 유지하되 실제 결박된 동료는 자발적 이동 명단에서 제외한다. 남겨진 동료 때문에 출입이 막히거나 다른 지도에 복제되지 않으며, 기존 명부의 정원에는 남는다. 실제로 돌아와 같은 인물·밧줄을 해방하면 기존 계약을 보존한다. 급료가 밀렸다면 기존 규칙으로 직접 지급해야 한다.

실제 다른 적대 포박자(죽은 몸의 신원도 포함)에게서 해방된 인물에 구조 기록을 남긴다. 원래 동료를 구한 경우도 같은 경로다. `Rescue.Hearth`는 보호28800턴(1일), 처음 깨어 안전할 때 휴식20턴, 실제 동료 구조 관계+5를 정의한다. 후속 조정값이며 국가 전체의 동맹으로 바꾸지 않는다. 같은 밧줄은 해방 위치에 남고, 실신/혈액 손실/상처는 해방으로 치료하지 않는다. 실신한 사람에게 음식이나 깨우기를 써서 의식을 되돌리지 못한다.

구조는 항복 격퇴 경험치나 ‘항복을 받아 줌’ 윤리 보상으로 세지 않는다. 자신이 실신자를 묶었다 푸는 행동도 항복 보상/평판을 만들지 않는다. 실제 항복으로 시작한 기존 포로의 보상은 유지한다. 보상이 없는 해방이 미래의 실제 항복 보상까지 소비하지도 않는다.

실신한 사람이 자기 구출 소식을 즉시 전하지 않는다. 살아 깨어 의식이 충분하고 실제 구조자/그 동료가 곁에서 보이며 대화/돌봄으로 도움을 알아볼 때만 인식 기록을 만든다. 그 뒤 살아 있는 당사자가 목격자로 기존 거리/도착 지연을 따라 소식을 전한다. 실제 고용 동료 관계+5는 구조자 한 명당 한 번, 실제 도움을 알아본 뒤에만 기록하며 기존 급료나 사기를 초기화하지 않는다. NPC가 구한 NPC의 공을 플레이어에게 주지 않는다. 구조자에게 공격당하면 보호가 끝난다.

해방된 사람에게도 곁에서 실제 음식/필요 식수를 제공할 수 있고 당일 수취 기록이 이어진다. 안전하면 처음 깨어20턴 쉬고 실제 배낭의 식량·물/수면과 원래 자리 귀환을 진행한다. 해당 정착지의 실제 급수/배급·보온/침대 일과도 이어 쓴다. 다른 적이 보이면 기존 도주 판단을 따르며, 잠든 경비나 구조 기록만으로 무적이 되지 않는다. 구조 후 새 동료 영입과 자연 발생 납치/구출 사건 전체는 다음 작업이다.

계약 창은 시험 동행 기한과 실제로 지급한 이후 선불 급료를 나눠 표시한다. 새 계약은 `trialUntil`을 저장하며 구형 각인에 없던 시험 기한을 만들어 주지 않는다. 원소속 국가의 관계와 현재 개인 동료 상태를 함께 표시한다. 이미 사용한 급료 기한이나 지갑은 변하지 않는다.

급식 수취량의 국소 정밀도도 수정했다. 실제350kcal가 신체의 소수점 감산 때문에349.999999999로 기록되어 조건을 놓치던 경우를 재현했다. 영수 기록만 소수점6자리로 누적하고 이전 각인의 미세 오차를 같은 정밀도로 비교한다. 신체의 실제 칼로리/수분이나 전역 정수화 정책을 바꾸지 않는다. 깨운 자유 구조자와 동료가 바로 다시 잠들던 경우도 검사로 재현해 기존 잠기운 기한 동안은 다시 잠들지 않고 돌볼 시간을 준다.

각인v32는31의 몸/포박/호송·동의/급료를 보존하는 순수 이관이다. 실제 항복 여부·구조/인식/소식·같은 밧줄·시험 기한·돌봄 기록을 보존한다. 기존5개 리플레이의 전체 초기/최종 상태는 버전31→32 외 동일하며 원래 명령/오류를 유지했다(`golden-v066-diff.json`).
