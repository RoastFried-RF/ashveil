# 실제 노출로 손상되는 화살 깃과 탄약 선택 — v0.277 구현 중

기존 화살(기존 상속 정의인 석궁 볼트 포함)에 콘텐츠 패치로 깃 손상 명중 불이익3을 연결했다. 새 물품·새 전리품·추가 난수는 만들지 않는다. 실제 양의 경과 시간이 있고 재비에 노출된 착용 화살통의 화살·손에 든 화살·지붕 없는 바닥 화살만 손상된다. 일반 배낭과 닫힌 마대 자루의 화살은 보호한다. 기록이 없는 구형 바닥 화살은 현재 시각부터 기록하며 과거 노출을 추정하지 않는다.

정상과 손상 화살은 다른 더미로 유지한다. 소지품/화살통 메뉴와 빠른 슬롯에서 실제 상태를 선택하며, 선택은0턴이다. 선택한 정상 탄약이 떨어져도 손상 탄약으로 몰래 바꾸지 않는다. 사용자가 다른 상태 또는 자동 선택을 명시적으로 고를 수 있다. 빠른 슬롯 개수는 연결된 상태만 세고 닫힌 자루의 화살은 세지 않는다.

발사 전에 실제 한 발의 상태를 묶어 마지막 화살이 소모되어도−3을 유지한다. 조준 능력과 일반 사격, 장전 완료·중단, 회수·몸에 박힘·치료 추출·사망 반환까지 같은 상태를 유지한다. 이미 장전한 손상 화살을 다른 선택으로 정상화하지 않는다. 최종 명중 확률의5~95 제한은 그대로다. 손상 깃 수리와 새로운 탄종은 이 구현에 포함되지 않는다.

각인187은186에서 버전만 이행한다. 과거의 손상이나 선택 이력은 채우지 않는다. 실제 선택·빠른 슬롯·장전 표시·박힌 화살의 상태를 보존하며 잘못된 타입/탄약 없는 장전 표시는 거절한다. Item193/최종 Def861/제작법84/패치281이며 새 Item 등록은 없다.

관련8파일116개가 통과했다. 최초 검사에서는 명중 상한95에 걸린 비교용 능력 fixture와 존재하지 않는 Wound.Puncture fixture가 실패했다. 비교용 민첩을 상한 아래로 두고 실제 addWound/Wound.Stab으로 상처를 생성하도록 고친 뒤 통과했다. 원본 실패 보고서를 보존했으며 해당 실패를 제품 수정으로 숨기지 않았다. 실제 화면·전체 회귀·월드30판 결과는 동결본 검증 뒤 별도로 기록한다.
