# 동료가 실제 본 월드 지형과 직접 구두 보고

v0.178. NPC는 플레이어와 같은 현재 바깥길/갑판의 물리적 월드 칸에서 자기 차례에 실제로 볼 수 있을 때만 주변 지리 기록을 자기 기억에 남긴다. 지역 안/다른 지도/잠듦·의식·시력·포박·몸 조건이 맞지 않으면 기록하지 않는다. 플레이어의 방문/옛 지도/관찰을 복사하지 않고 실제 현재 주변 반경3칸의 지리만 남긴다. 자원·생물·현재 강수는 기록하지 않는다. 바뀌지 않은 지형은 최초 관찰 시각을 유지하고 바뀐 지형만 새 시각으로 갱신한다. 기본 기억 최대256칸은 오래된 것부터 한정한다.

실제 동료가 자기 고용주 곁에서 깨어 듣고 말할 수 있는 대화1턴에, 이미 자기 기억에 있는 현재 세계의 당시 지형만 전한다. 종이/잉크를 만들거나 소비하지 않고 플레이어의 직접 관찰/방문 기록으로 바꾸지 않는다. 같은 원래 기록의 반복 보고는 중복하지 않는다. 다른 세계/미래 기억은 보고로 만들지 않는다. 큰 보고도 요약 로그 한 줄만 남긴다.

M의 세계 지도는 구두 보고를 황색의 미확인 주장/원래 관찰 시각/출처로 표시하며 종이 문서의 신뢰도/오차를 지어내지 않는다. 자기 직접 관찰이 있는 칸만 그 기록과 일치/다름을 표시한다. 오래된 종이/다른 보고와 충돌하면 양쪽을 남긴다. 육로 예상은 직접 기록>종이의 기존 우선순위를 유지하고 구두 지형만으로 자동 경로를 고르지 않는다. 현재 숨은 지형으로 보고를 고치거나 진위를 판정하지 않는다.

각인129→130은 버전만 이관하며 옛NPC의 과거 월드 관찰/보고를 소급하지 않는다. 별도 PATCH237이며 새 Item은 없다. 기존5골든 전체 초기/최종/오류는129→130 외에는 같음을 검토하고 원래v177 기대값을 한 번 보관했다. 두 기대 해시만 바꾸고 원래 시드/명령/오류/형식은 보존했다. [전체 검토](golden-v178-diff.json).

전용21개/관련3파일56개14.07초를 확인한 뒤 실제 한 시간 동행 이동을 추가해 최종 전용22개4.91초를 통과했다. 실제 이동 검사는 처음부터 따뜻한 유효 초기 구간을 준비한 뒤 정상 출입/1200턴 이동/다음 자기 차례를 실행한다. 이전49칸의 원래 시각과 새7칸의 실제 도착 뒤 시각을 별개로 보존한다. 게임의 체온/동행 규칙을 검사 편의로 바꾸지 않았다. 타입/린트·Def237/Item188·127스키마 오류0·빌드CRWjrcI21.60초를 확인했다.

준비한 브라우저 검사는 처음부터 동의한 동료/원래 재료/실제 출입구·처음 받은 옛 지도와 달라진 현재 지형의 유효 초기 조건을 사용한다. 과거 영입/지도 변화/장거리 이동 입력을 브라우저에서 실행했다고 주장하지 않는다. 실제 출입1턴은 아직NPC차례 이전이므로 기억이 없다. 실제 대기1턴에NPC가49칸을 보고, 대화1턴에만 보고가 생기며 자기 관찰1턴 뒤 같은 원 보고가 확인된다. 반복 대화1턴의 중복 방지·원래NPC시각14401·3전체 각인130 복원/미완료 남은19턴을 검증할 준비를 했다. 최종 실제 화면877–881의5장 전체를 직접 확인했다. 실제UI출입1턴/다음 대기1턴/NPC자기 관찰49칸/직접 대화1턴의49개 보고/직접 관찰1턴의49개 확인/반복 대화1턴 중복 없음·NPC 원래 관찰14401/P옛 기록13800 보존·3전체 각인130 복원/미완료1900TU(19턴) 전체 일치/콘솔0이다.177–178 통합 전체 회귀를 진행한다.

NPC 자유 월드 정찰/자기 월드 종이 지도 생산·다른 거짓/실제 매복 경로와 나머지 후속은 남는다.

최초 화면 검사는 실제 출입/대기/보고의 전체 상태와 화면까지 같았지만 준비한 월드에 기후/시장 초기화가 빠져 전체 복원에서 차이가 났다. 검사 장면을 실제 새 게임과 같은 enableOverworld→initializeClimate→initializeWorldSimulation 순서로 준비하도록 고쳤다. 코어의 저장/복원·경제·관찰 규칙을 완화하지 않고 재초기화가 전체 상태를 바꾸지 않는 통합 검사도 추가했다.

월드 초기화/복원 무변경 검사를 포함한 최종 전용23개+기존월드25개+골든10개=3파일58개9.36초를 통과했다. 실제1200턴 동행 이동도 이 최종 검사에 포함된다.
