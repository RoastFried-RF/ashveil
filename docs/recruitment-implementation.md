# 여러 날의 돌봄·대화와 포로 영입 — v0.65

X1의 포로 회유를 기존 몸/시간·실제 급식과 고용 동료 계약에 연결했다. `Recruitment.Hearth`의 기본값은 서로 다른3일, 매일 실제로 받은350kcal/필요 수분200ml, 각 대화1200턴, 불안 판단25, 시험 동행1일·마지막 밧줄 풀기1턴이다. 확장용 조정값이며 사용자 결정 대기인 세력/경제 정본을 확정하지 않는다. 자연 발생 납치/구출과 구출 후 영입 전체는 다음 작업이다.

같은 편이 돌보는 실제 포로가 깨어 말을 듣고 이해할 수 있고 다른 적의 위협이 없을 때 N창에서 대화를 시작한다. 양쪽 의식.5/청각.25, 곁/시선·모서리와 기존 사기·이전 동료 관계를 검사한다. 급식 기록은 실제 음식·필요 수분의 당일 수취량을 쓴다. 하루 대화는 한 번이며 날짜를 건너뛰거나 중단한 대화는 진도가 아니다. 급식/수면·물병/체질은 기존 돌봄 규칙을 쓴다. 예를 들어 육포1개는140kcal이므로350kcal 기준을 만족하지 않는다. 건빵350kcal와 실제 식수를 쓰는 검사 자료를 보관한다.

대화는 양쪽 실제 활동으로 진행한다. 말하는 사람의 활동만 진도를 소모하고 상대 대기는 별도 몸/시간을 진행하며 중복 진도를 만들지 않는다. 양쪽 의식/청각의 낮은 쪽과 상대의 실제 다음 행동 시각을 반영한다. 손이 없어도 대화는 할 수 있고, 빛·손 조작을 회화 속도로 오인하지 않는다. 매 틱 같은 인물/밧줄UID·거리/신체·새 상처와 활동 짝을 재검사하며 중단하면 양쪽 활동을 해제한다. 자정을 넘긴 대화는 시작한 날짜를 한 번 기록한다. 완료한 대화 뒤 그 인물의 이름을 들은 상태로 바꾸며, 비공개 몸/정신 수치를 UI에 표시하지 않는다.

세 날짜를 마치면 그 인물의 동행 동의가 기록된다. 아직 몸과 밧줄/소속은 바뀌지 않는다. 실제로 ‘함께 가자’를 제안하면 전체 동료 정원3과 직접 걸을 수 있는 몸/밧줄을 풀 손을 검사한다. 기존 다턴 몸 배율을 적용한 밧줄 풀기 작업을 끝내야 같은 밧줄을 바닥에 돌려주고 같은 인물이 동행한다. 동행 제안 전 다른 활동/밧줄 교체·상황 변경은 완료를 취소한다. 포박을 일반 고용으로 우회할 수 없다.

새 인물/장비/지갑이나 지급하지 않은 돈을 생성하지 않는다. 원래 세력·몸·소지품·기억/기존 관계를 보존하고 유효한 계약 동안 기존 전투 편/물품 전달·생활/호송·계단/지역 이동·관계 규칙을 쓴다. 관계를 초기 호감으로 부풀리지 않으며 최초 관계는 기존 기본값0이다. 첫1일은 합의한 시험 기간이며 이후 기존 하루 급료6표를 직접 받아야 동행한다. 원래 적 공급원의 현지 배치 인원은 실제 동료를 제외하고, 그 인물이 동료인 상태로 죽으면 다시 차감하지 않는다. 국가 평판이나 항복 격퇴/석방 경험치를 영입 보상으로 만들지 않는다.

동의 뒤 실제 공격 시도는 빗나가도 대화/동의를 철회하고 시각을 기록한다. 평화롭게 헤어지는 경우 기존 귀환 유예를 주어 그 자리에서 즉시 원소속 적대로 돌아가지는 않으며, 추가 석방 보상/평판은 없다. 배신 공격으로 끝낸 계약에는 이 유예를 부여하지 않는다. 국가 전체의 관계는 별개다.

각인v31은30의 몸/밧줄·손 점유·돌봄/호송을 보존하고 과거 대화를 만들어 주지 않는 순수 이관이다. 진행 중 양쪽 활동과 완료 날짜·동의/공격 기억은 전체 직렬화에 포함한다.
