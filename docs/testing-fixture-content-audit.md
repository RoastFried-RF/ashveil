# 기본 콘텐츠를 사용하는 실제 검증 장면

검사 도우미의 기본 인수chance=1에undefined를 전달하면 기본 인수가 다시 적용되는 오류를 확인했다. 확률1 단위 검사와 실제 기본 콘텐츠 장면을 명시적으로 분리했다. 기본 장면은null로 원래 DB를 사용하고, 침구 화재/침구 접촉/물 용기의 실제 장면에서 브라우저와 같은 원래 DB 객체를 쓰는지 회귀 검사한다. 게임 코어/콘텐츠의 확률이나 저장 형식은 바꾸지 않았다.

실제 기본 침구 화재는 원래 시드actual-bedding-fire-1에서14600턴에 발화하고14620턴에 실제 화상과 기존 휴식 중단을 재현했다. 기본 침구 접촉은actual-bedding-lice-1377에서28801턴의 원래 보균자 흔적과 실제 몸 씻기 뒤200턴 접촉의29502턴 재감염/기존T4중단을 재현했다. 두 경로 모두 전체 저장 복원 후 같은 결과였다. 이전 사건 시각을 억지로 유지하도록 제품 확률을 바꾸지 않았다.

검사용 초기 시계를 낮으로 바꾸는 공용 장면에서는 생성 시각의 미래 관찰을 삭제하고 현재 능력치에 맞는 유효 최대 체력을 둔다. 이후의 실제 턴 중에는 수치나 결과를 주입하지 않는다. 검사 도우미와 관련5파일121개/타입/린트가 통과했다. 이 추가 검사는v153–155제품의 전체158파일3072개와 구분한다. 새 장면과 기존 원본 화면의 UI 상태/전체 복원은 동일 제품의 브라우저 검증으로 계속 확인한다.
