# NPC의 실제 밧줄 제작·포박·해방·돌봄 — v0.68

현지 경비와 약탈자가 같은 물품·몸·제작/포박·해방·급식 행동을 사용한다. 살아 깨어 손을 쓸 수 있고 도주/항복 중이 아니며, 다른 깨어 싸울 적이 없을 때만 곁의 실제 항복자/실신자를 처리한다. 플레이어와 자연 수면자는 자동 포박 대상이 아니다. 기존의 실제 밧줄 포박을 유지하고, 밧줄이 없을 때는 개인 배낭에 실제 천2장이 있어야 기본20턴 제작을 시작한다. `NpcCustody.Hearth`의 역할/제작법·열량/갈증/신선도 임계는 모드로 조정할 수 있다. 시작 재고나 포로를 추가하지 않는다.

같은 제작 시스템이 정확한 재료 UID와 남은 작업을 보존한다. 완료 때만 천이 소비되고 품질 판정을 거쳐 밧줄1개가 생긴다. 그 뒤에도 곁의 상대가 계속 항복/실신 상태일 때만 실제2턴 포박을 완료한다. 제작 중 자연히 깨어 저항한 사람을 강제 포박하지 않는다. 실제 검사에서는 깨어난 사람이 반격해 작업자를 다치게 했다. 새 상처로 NPC 제작을 중단하도록 제작 시작의 상처 수를 기록했고, 같은 천과 부분 작업이 남는다. 기존 다른 제작의 남은 작업을 임의로 덮어쓰지 않는다.

다른 적대 포박자에게 붙잡힌 자기 편 인물이 실제 곁에 있으면 경비가 같은 해방 행동을 고른다. 원래 몸·실신·계약을 보존하고 같은 밧줄을 바닥에 돌려준다. NPC의 공을 플레이어 평판/관계/경험치로 바꾸지 않는다. 중립인 타인의 포로를 훔치거나 보이는 다른 적을 무시하지 않는다.

자기 편이 포박한 사람이 깨어 삼킬 수 있고 열량500kcal 미만/갈증500ml 이상이면 개인 배낭의 조리된 신선도50 이상 음식·얼지 않은 비알코올 식수를 실제로 제공한다. 시술자가 같은 생존 한계에 있다면 자기 보급을 남긴다. 같은 물병의 한 모금과 실제 음식이 소비되고 받은 사람의 몸/당일 돌봄 기록에 반영된다. NPC의 돌봄을 플레이어의 회유 실적으로 세지 않는다. 실신/수면 중 강제 급식이나 썩은 음식·날고기 투여를 택하지 않는다. 손 위생/수질·섭취 위험은 공통 규칙을 따른다.

새 저장 구조 없이 기존 제작 작업/포박/돌봄/구조 기록을 쓰므로 각인v33을 유지한다. 새로운 상태를 과거 각인에 만들어 넣지 않는다. 자연 발생 납치 사건 전체·멀리 있는 포로를 향한 작전·거점 작업/보급·간병 의료 전체는 다음 작업이다.
