# 명시된 물품 ID 이행

v0.253 작업 중, 각인180/API1.4.0 유지. 실제 활성 패키지의 migrations/rename.json을 엄격한 원문 JSON으로 읽어 기존 ID→현재 ID 사전을 구성한다. 같은 원본의 다른 목적지·순환/자기 순환·현재 정의도 남아 있는 원본·부재 목적지·잘못된 ID/사전은 실행 전에 거절한다. 여러 단계 사슬은 최종 목적지로 평탄화하며 만 단계 사슬도 재귀 스택 없이 검사한다. 사전은 최종 DB의 별도 읽기 전용 속성이고 실제 패키지 내용/순서 해시에 포함한다. 꺼진 모드의 이행은 적용하지 않는다.

현재 저장 이행은 Item에 연결한다. 원래 정의 종류/칸 크기 기록과 현재 목적지의 Item/같은 크기를 확인한 뒤 원래 UID·개수·상태·배치·회전을 유지하고 def만 새 ID로 바꾼다. 이미 보관 중인 원본도 같은 UID/현재 배치로 복원해 새 ID를 사용한다. 빠른 슬롯/제작 입력 등의 현재 def 참조도 함께 이행한다. 한 물품이라도 잘못되면 아무 물품도 부분 이행하지 않는다. 시간/난수/새 UID를 쓰거나 병합/분할하지 않는다.

일반 지식/로그/과거 보고서는 새 ID로 소급하지 않는다. 물품 내부의 쪽지/수확 출처도 임의로 다시 쓰지 않으며 별도 처리가 필요한 참조가 남으면 차단한다. 스크립트 지속 상태의 기존 ID 문자열/키와 설치 의수족/선체는 개별 이행을 요구한다. 다른 종류 정의의 rename과 지원하지 않는 현재 ID 참조도 추정해서 처리하지 않는다. 로더가 일반 ID 사전을 읽는 것과 각 종류의 저장 복구를 모두 구현한 것은 구분한다.

타이틀 검토는 실제 원래/새 ID와 물품 더미 수를 보여 준다. 검토는 사본에만 이행해 후속 보관/참조 검사 결과를 계산한다. 기존 토큰 보호를 통과한 승인 후보에서만 rename을 보관 변환보다 먼저 적용하고, 기존 현재 해시/정의/크기 목록·같은 시각의 변경 이력/연대기·업적 비활성/한 번 저장을 연결한다. 세계/지도/몸/인물을 재생성하지 않는다.

sample-item-renames는 이전 예제의 SampleMigration.Item.OldKnife를 실제 코어 Item.RustyKnife로 옮기는 사전만 제공한다. 새 실제 Item Def/생성/보상을 만들지 않는다. 이전 버전 fixture는 새 게임 전에 메모리 패키지에 옛 칼을 실제 현재 코어 칼의 자식으로 선언하고 makeItem/addToBag를 실행한다. 품질2/내구도67/빠른 슬롯8은 선언한 초기 조건이며 원래 인물/몸을 편집하거나 과거 플레이로 주장하지 않는다. 크기 불일치 fixture도 이전 정의를 실제2×2로 선언한 뒤 생성한다.

전용28개(사전11·물품14·실제 저장 시작3)·실제 배포1개와 기존 물품/승인/선택/해시/골든을 포함한11파일124개가 통과했다. 최초 예제의 목적지 Item.Knife는 실제 코어에 없어 실제 로더 확인에서 발견했고, 현재 등록된 Item.RustyKnife로 수정했다. 잘못된 예제를 고정/배포하지 않았다. 타입 검사의 시험용 순환 사전 배열 추론도 명시적 문자열 사전으로 수정했다. 골든5개 전체 초기·최종·오류·해시는252와180까지 같으며 벡터/기대 해시를 바꾸지 않는다.

배포 도구는 migrations/rename.json만 허용하고 원문을 그대로 넣는다. 실제 브라우저 검토/승인·같은 칼과 빠른 슬롯의 새 ID/원래 품질/내구도/배치·전체180복원1·실제 이전2×2 정의의 이행 차단을 준비했다. 최종 정적 검사·화면·252–253 통합 회귀는 진행 중이다. 다른 종류/설치 상태·스크립트 지속 상태/비 def 참조·스키마 이행/헤더·가져오기/창작마당과 나머지 전체 확장은 계속 남는다.

최종 타입·린트·Def277패치/Item191·Vite1.84초 빌드를 통과해253을 고정했다. 실제 배포 파일1017바이트의 SHA-256은ce02e287f78825146d8f8083e6df2d529b45dc66c3617810a5a50cb4439d5cc4이며 대상 모드의3개 원본 파일만 포함한다. 실제1257–1259 세 장/전체180복원1을 실행 중이며 아직 통과를 주장하지 않는다.

실제1257–1259 세 장을 모두 확인했다. 이전0.9.0 실제 정의/현재 원문 사전의 검토 전 원문 보존·명시 승인 뒤 같은 칼/빠른 슬롯의 새 ID/원래 UID·개수·품질2·내구67·배치·전체180복원1·실제 이전2×2 크기와 현재1×2 목적지의 이행 차단/콘솔0이 첫 실행에서 통과했다.252의3장/2복원과 함께253 전체·월드 회귀를 시작했다.
