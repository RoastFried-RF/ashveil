# 실제 이웃의 자기 물품을 쓰는 출혈 돌봄 · v0.221 / 각인159

실제로 대화해 서로 알게 된 같은 세력의 두 주민 사이에, 자기 의료 물품과 기존 의료 규칙을 쓰는 돌봄 행동을 추가했다. `NpcCare.Hearth`는 기존 주민 대화 규칙의 대상 역할과 실제 관계 기록을 참조한다. 플레이어·고용 동료·포로·구조 보호 중 인물을 이 행동의 대상으로 삼지 않는다. 기존 유료 진료/동료 돌봄은 별도로 유지한다.

원래 NPC 자기 차례에 생존 필요·위협 대응·맡은 일을 우선하고, 한가한 의료 능력1단계 이상 제공자가 곁의 실제 이웃 외부 출혈을 확인한다. 같은 현장의 실제 두 원본·양쪽 의식/시청각·거리1/식별할 밝기/시야·서로의 실제 대화 사건과 양수 관계가 필요하다. 자기 몸의 출혈/기아·갈증·피로·체온과 손, 활동/업무/순찰/호송을 확인한다. 현재 원격 사람이나 플레이어 지식을 조회하지 않는다.

조회는 제공자의 활동만 사본으로 만들어 기존 `startTreatment`에 묻는다. 물품·몸·돈·난수·로그를 변경하지 않는다. 자기 배낭의 실제 깨끗한 붕대 물품 UID를 예약하고 시술자 처치/환자 대기를 연결한다. 기존 다턴 의료가 양쪽 몸과 물품을 매 작업 때 검사하며, 실제 완료에만 원래 물품1회분을 소비하고 품질·붕대·출혈 감소를 남긴다. 기존 규칙대로 중단/도구 상실은 양쪽 예약을 풀며, 다른 더미로 자동 대체하거나 미완료 붕대를 만들지 않는다.

완료 기록은 두 당사자의 개인 이력에 실제 제공자/환자/상처/재료UID·시각·품질로 보관한다. 완료 전에는 성공 이력을 만들지 않는다. 실제로 깨어 보고 들을 수 있는 플레이어만 두 사람이 곁에서 처치하는 모습을 공개 로그로 관찰한다. 역할/알고 있는 이름을 쓰고 사적인 관계/이름/의료 품질을 원격으로 알려 주지 않는다. 숨은 돌봄은 개인 기록으로 남으며 플레이어 소식을 자동 생성하지 않는다. 타인의 현재 몸을 원격 치료하거나 체력/자원을 새로 만들지 않는다.
