# 실제 귀환 동료가 본 계단의 구술 보고

v0.168 작업은 실제 동료가 그 칸에 서서 기록한 계단도 실제 대화로 전한다. 동료의 원래 지역/지도·계단 지형/이름·좌표·관찰 시각만 사용하며, 숨은 현재 계단/연결 목적지·다른 층을 조회해 소식을 만들지 않는다. 동일한 가까운 동료·깨어 있음/의식·청각·시선·고용주 조건을 사용한다. 미래 관찰은 방/계단별로 거절한다.

구술 보고는 종이·잉크·지도 원본을 만들거나 쓰지 않는다. 플레이어의 직접 관찰 칸이나 방 발견으로 바꾸지 않는다. 원래 계단이 현재 변했는지 멀리서 확인하지 않는다. 대화 재탕으로 같은 보고의 시각/내용을 덮어쓰거나 난수를 쓰지 않는다.

M창은 읽은 지도의 계단/구술 계단을 파란/호박색 점선으로 표시하고 이름·출처·기록 시각을 보여 준다. 같은 자리에 서로 다른 계단을 주장하면 둘 다 충돌로 남는다. 같은 이름이 다른 자리에 있다는 이유만으로 동일한 계단이라고 추정하지 않는다. 실제 과거 직접 관찰이 있는 칸만 그 관찰과 비교하며 현재 숨은 지형을 쓰지 않는다. 표시도 ‘직접 본 기록과 다름’으로 구분한다. 명시적인 층/크기를 들었으면 의뢰할 층을 알 수 있지만 그 층을 생성하지 않는다.
