# 거점의 실제 침구 사용 허가와 동료 휴식 — v0.73

F2에서 바로 곁에 설치한 실제 침구와 곁의 동료를 골라 사용을 허락하거나 해제한다. `BaseRest.Hearth` 기본 배정 시간은1턴이다. 실제 거점 반경 안의 본인 소유 고정 침구 또는 소유자 없는 휴대 침구만 선택할 수 있다. 주민 침대·다른 사람의 침구·침구 없는 바닥·원격·닫힌 모서리는 배정할 수 없다. 소유권, 원래 물품 UID, 동료 몸·계약·현금은 보존한다. 한 동료에게 새 침구를 허락하면 이전 사용 허가를 옮긴다.

피로85 또는 수면 부채10 이상인 동료는 위협이 없고 깨어서 움직일 수 있을 때 허가받은 실제 침구로 걸어간다. 추운 몸은 실제 불로 이동해 기존 보온 행동을 먼저 한다. 열이 없으면 체온을 올려 주지 않는다. 식사350kcal·수분 결손300ml 기준으로 개인 물품과 실제 창고의 준비 가능한 신선한 조리 음식·안전한 물을 인출하고 실제로 먹거나 마신다. 음식을 만들거나 병을 복제하지 않는다. 창고가 비었거나 손을 쓸 수 없다면 준비 불가를 확인한 뒤 잠을 무한히 미루지 않는다. 창고 확인 기억은 실제 기상 시각별로 보존한다.

침구에 도착해야 기존 수면 활동을 시작한다. 침구·몸/옷의 젖음·체온·영양·통증에 따른 실제 수면 회복과 갈증·추위·소음 등 자연 기상을 공유한다. 동료의 회복 목표는 기존25이며, 회복 전에 갈증 등으로 깰 수 있다. 깨어난 직후의 잠기운도 보존한다. 급료 대기 중에도 이미 허가받은 침구는 쓸 수 있지만 노동 계약을 무료 재개하지 않는다. 동행 중 플레이어가 거점을 떠났다면 원정자를 침구로 강제로 돌려보내지 않는다.

사용 중인 침구의 허가 해제·포장은 차단한다. 빈 침구를 실제 포장하면 같은 UID가 배낭에 남고, 설치되지 않은 유령 침구를 목표로 삼지 않는다. 같은 침구를 재설치해야 새 위치를 따른다. 허가 중에는 원래 소유자도 해제 후에 잠을 자야 한다. 계약 종료는 현재/보관 지도의 사용 허가를 지우며 이 과정에서 날씨·시계·난수를 정산하지 않는다.

각인v38은37에서 버전만 바꾸는 순수 이관이다. 실제 침구 UID별 사용 허가·준비 확인 시각·중간 수면과 같은 몸을 저장한다. 또한 공통 급수의 고정5모금을 실제 Def 용량으로 바꾸고, 깨끗한 병/오염된 병의 용량·한 모금 단위가 일치하는지 검증한다. 기본5모금/1000ml는 그대로다.
