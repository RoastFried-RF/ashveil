# v0.404 작업 중 — 저장 지점과 콘텐츠 복원 검토

2026-10-28 KST. v403 고정 작업본 뒤의 별도 초안이다. 현재 구현/타입·전체 검사·실제 화면·게시가 완료됐다고 세지 않는다.

저장 지점 복원 대화상자·동일/변경 콘텐츠의 검토·모드 순서 접근성 표시와 오류의 검토한 고정 문구를 언어 선택에 연결한다. 개인 이름·시드·모드/Def ID·버전/해시는 치환 인수로 그대로 표시한다. 현재 SaveMode는 ID+원문 guard를 사용하며 외부/변경 정의 원문을 보존한다. 타이틀 저장 지점 요약은 읽은 이름/시드/턴의 구조화 데이터로 표시하고 한국어 문자열에서 이름을 추정 분리하지 않는다. 디스크 키·원문·복원 토큰/승인·모드 순서와 Core/저장219는 유지한다.

도구 `tools/inspect-checkpoints-v404.ts`는 실제 새 탐구 원정 생성→수동 저장→대기→변경 모드 선택 시 기존 확인 취소→재검토/취소→원본 복원→타이틀 저장 지점/새로고침 계속하기를 두 데스크톱과390px에서 검사하도록 작성했다. 표석은 기존 `checkpointFixture`의 유한 초기 장면/원래 모닥불을 명시하고 실제 두 칸 이동→저장 거절→복원만 입력한다. 초기 장면과 자연 획득을 구분하고 각 단계의 독립 Node 전체 상태를 비교한다. 구현 중 도구이며 아직 통과 근거는 없다.

모드 설치/플레이 중 적용의 바깥 제어, 동적 복구 오류 전체·시드 공유·다른 창/물품 설명/로그는 영어 미완료다. 사망/모든 결말과 현재 월드/원정1,000판·X1–X4·사람 평가는 별도로 유지한다.
