# 회수 화살 더미의 실제 상한 — v0.276 작업 중

후속 탄약 작업 검토에서 회수 화살을 바닥의 같은 Def 첫 더미에 무조건 더하는 오류를 발견했다.20발 더미가21발이 되거나 품질/오염 상태가 다른 더미에 합쳐질 수 있었다.

회수 확률·combat 난수 한 번·부위 박힘 규칙을 유지하고, 실제 현재 Def의 maxStack과 공통 canStack을 통과하는 더미에만 합치도록 수정했다. 자리가 없으면 같은 바닥 칸에 새1발을 두며 이때만 원래 방식으로 UID 하나를 쓴다. 다음 더미에 자리가 있으면 그 더미를 사용한다. 새 물품 정의/탄약/시간/추가 난수를 지급하지 않는다. 277에서는 실제 손상 깃을 회수/박힌 화살/치료·사망 반환까지 유지하며, 정상 더미와 섞지 않는다.

전용8개를 작성했다.20+1 분리/19→20·UID 무소모/뒤 더미 사용/품질·오염·신선도 구별/실제 mod 상한3/회수 실패 전체 불변/성공 전체 비교/전체 저장 복원 후 결정론을 검사한다.275의 원본 동결 통합 실행과 겹쳐 실행하지 않으며, 이 수정의 테스트 결과를275 결과로 표시하지 않는다. 276 원본 수정은 관련4파일47개를 통과했다. 이후277의 실제 깃 손상 보존·생성 시각 연결과 통합했고, 관련8파일116개도 통과했다. 전체 회귀·실제 화면·월드 검증은277 동결본에서 별도로 진행한다.
