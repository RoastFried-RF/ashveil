# 정착지에 직접 전한 공개 소식

v0.164 작업은 실제 아는 공개 소식을 곁의 현지 주민에게1턴으로 전하고, 정착지 간 대기열을 거쳐 도착한 소식을 실제N대화로 듣도록 연결한다. 소식 전하기 버튼은 견적만으로 시간/난수/대기열을 만들지 않는다. NPC의 비공개 지식 전체를 자동 게시하거나 원격 현재 사건·인구·물품을 확인하지 않는다. 지도 원본/방 좌표의 전파는 이 경로에 넣지 않는다.

`WorldSimulation.Hearth`의 PATCH에 거리6.4칸/일·수다0.5~2일·정확도손실10~25·수량1.5배/위치이웃/세력혼동/시점흐림/무변화의 가중치30/15/15/20/20·정확도20/30일 만료·지각×5%를 둔다. 가까운 세 정착지를 연결하며 거리는 월드 칸의 맨해튼 거리다. 실제 캐러밴 개체/화물과는 별도 공개 소식 대기열이다. 바다/도로/통행 차단 전체를 반영한 전용 연결 그래프는 후속이다.

명시적으로 전해진 `claims`의 항목만 왜곡하며, 옛 자유 문장에 없던 수량/장소/세력/시점을 추측해 넣지 않는다. 과거 글은 지원하는 항목이 없으면 내용을 그대로 전한다. 원래 작성 시각은30일 만료를 위해 보존하고, 소식이 주장하는 시점은 별도 필드다. 새로 게시한 일반 소식의100은 공개 이후 전달 충실도의 시작값이며 내용이 참이라는 판정이 아니다. 기존 전파 소식을 다시 게시해도 정확도/출처의 뿌리를 초기화하지 않는다.

각 정착지는 같은 뿌리의 첫 도착만 보관하고 간선 전송을 중복하지 않는다. 늦게 처리해도 도착 예정 시각을 기준으로 다음 전파를 예약하여 하루씩 처리한 결과와 독립 난수가 같다. 정확도가20 미만이면 전송하지 않고,30일 지난 공공 기록/대기열/전송 표시는 정리한다. 플레이어가 이미 들은 개인 기록은 과거 기록으로 남는다.

도착만으로 플레이어 지식이 늘지 않는다. 실제 가까운 주민과 깨어 있고 서로 들을 수 있는 대화가 필요하다. 처음 들을 때만 지각 판정을 하며 의심되는 항목 하나를 표시한다. 원래 참값·정확도·아직 도착하지 않은 경로/소식은 UI에 공개하지 않는다. 같은 소식 재탕으로 판정을 다시 하지 않는다. 주민의 전파 정보를 들었다고 물리 원본이나 직접 관찰을 얻지 않는다.

각인121→122는 버전만 이관하며 과거 공개/전파/의심을 만들지 않는다. 대기열은 실제 새 게시 또는 유효한 초기 전파 상태가 있는 경우에만 존재한다. 모든 기존 소문을 소급 만료시키지 않는다.

전용28개/관련5파일123개·골든 포함 최종2파일38개·타입/린트·Def225패치/Schema127파일 오류0을 확인했다. 기존5골든은 전체 초기/최종 상태와 오류가121→122 외에는 같아 원래v163기대값을 한 번 보관하고 두 해시만 갱신했다.

브라우저810–813의4개 주민 창 장면을 모두 직접 확인했다. 실제 게시1턴·도착 전 실제N대화1턴의 정보 차단·그다음 실제대기1턴의 도착/자동 학습 없음·도착 후 실제N대화1턴의18명 주장/인원수 의심 표시와 숨은12명/정확도 비공개를 확인했다. 각인122의3전체 복원 비교(미완료 재개 포함)와 남은19턴의 대기열/지식/난수 전체가 코어와 같고 콘솔 오류0이다. 전체167파일3,248개161.11초·월드30판330.695512734초를 통과했다. 월드의 전체30행은v163과 같으며 원래 결과를 한 번 보관했다. [전체 비교](sim-v164-diff.json).

브라우저의 근접 도착 장면은 장거리 이동을 거의 마친 유효 초기 소식을 준비하며, 과거 게시나 장거리 경과까지 실제 입력했다고 주장하지 않는다. 별도 게시 장면에서 실제1턴 버튼과 대기열 생성을 검증한다.

자동 공개 사건 원천 전체·마을 도착 시 첫 반응 전체·지도/함정/전역 지도·X1~X4의 나머지 구현은 남아 있다.
