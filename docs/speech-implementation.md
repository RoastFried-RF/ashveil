# 기록·툴팁 읽기 지원 · v0.213 / 각인153 유지

접근성 정본의 기록/툴팁 TTS 훅을 추가했다. F3에서 읽기 지원을 켜고 속도0.5–2배를 설정한다. 기본은 꺼짐이다. ‘읽기 시험’, 실제 기록의 읽기/멈춤 버튼과 재배정 가능한 Alt+R/Alt+S 명령을 제공한다. 명시적으로 요청할 때 현재 표시된 툴팁, 없으면 커서 정보, 없으면 표시된 기록을 읽는다. 읽기 요청과 설정은 턴을 쓰지 않는다.

기존 UI가 표시한 DOM의 문구만 사용한다. 보이지 않는 NPC/인벤토리/개인 기억을 코어에서 조회하지 않는다. 기록 버튼도 현재 상세도와 실제 펼친 상세만 포함한다. 한국어 Web Speech 음성 API에 연결하고 사용할 수 있는 한국어 음성이 있으면 선택한다. 한 번에 총3000자/조각220자 이내로 제한하고 새 요청은 이전 큐를 취소한다. 자동 읽기나 턴별 음성 재생은 없다. 설정을 끄거나 화면을 바꾸면 멈추며, 취소된 과거 완료/실패 이벤트가 현재 요청의 상태를 덮지 않는다. 미지원 환경은 읽기 UI에 지원 상태를 표시한다.

기존 키 재배정과 한 손 프리셋을 유지한다. 새 기본 Alt+S가 등록되었으므로 과거 ‘미배정 Alt+S’ 검사 장면은 실제 미배정 Alt+P로 옮겼다. 각인153/코어/콘텐츠는211/212와 동일하고 읽기 설정은 기존 환경 설정에만 저장한다. 새 Def/Item/각인 이관은 없다.

전용 음성 API 연결10개와 읽기 설정 호환을 포함한 관련4파일35개가 통과했다. 한국어/속도·직전 큐 취소·중단/과거 콜백/미지원·꺼짐·실패/완료 구분·문구 상한·숨긴 요소 제외/툴팁 우선과 기존 키/입력 회귀를 검사했다. 최종 타입/린트/빌드1.61초가 완료됐다.

최신214/153에서 실제1048–1051 네 장을 모두 확인했다. 실제 설정/기록 버튼/물품 툴팁Alt+R/멈춤Alt+S/꺼짐/설정 지속과 전체153복원4/전체코어불변0턴/콘솔0이다. API호출을 포착해 현재 문구와 한국어/실제 WebIDL float32속도 Math.fround(1.4)를 대조했고 실제 음향 청취는 주장하지 않는다. 초기 주입의 변환 보조함수와 속도 표현 기대값을 E2E에서 고쳤으며 제품의 speech.ts는 동결213과 바이트가 같다.
