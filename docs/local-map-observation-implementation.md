# 지도 창의 관찰 기록과 현재 시야

v0.160은 M지도 창도 세계 화면과 같은 관찰 기록/현재 시야를 사용하도록 연결한다. 보이지 않는 평지에 생긴 현재 핏자국이 지도 색으로 드러나지 않으며 다시 실제로 보면 현재 피를 표시한다. 지도 위 칸을 가리키면 직접 본 지형과 관찰 시각/현재 보임을 확인할 수 있다. 기록 없는 구형 탐험 칸의 시각은 추정하지 않는다.

다른 층의 같은 칸 번호를 현재 층의 시야로 취급하지 않는다. 직접 탐험한 다른 층은 기억만 보여준다. 방문 기록 없이 생성 캐시에만 있는 층은 탭에 공개하지 않으며, 실제 읽은 지도/소문의 층은 기존대로 주장만 표시한다. 조회로 원격 층을 생성하거나 실제 지형/피를 확인해 정보를 보완하지 않는다.

변경은 클라이언트의 관찰 표시와 검사에 한정된다. 코어·콘텐츠와 각인120을 유지한다. 전용21개/관련3파일54개, 타입·린트·빌드와 기존5골든 전체 초기/최종 상태·해시가 통과했다. 실제 M창791–794의4장을 모두 확인했다. 시야 밖 피200인 평지는기억 색RGB90/86/76이고, 실제 이동1턴+문 열기1턴 뒤에는 현재 피를RGB106/42/36으로 그린다. 실제 캔버스 원본 픽셀과 관찰 시각/미탐색·숨은 층 탭 부재를 확인했으며 조회 전후 전체 상태는 같다.3전체 저장 복원과 남은19턴의 전체 상태가 코어와 일치하고 콘솔 오류0이다.

전체 회귀는v161 NPC 독서와 통합해 최종본에서 진행한다. v160별도 전체 회귀/월드30판을 실행한 것으로 기록하지 않는다. UI만 바뀐v160의 코어/콘텐츠는v159와 같음을 파일별로 확인했다.


v0.160–161은 M지도 창의 실제 관찰/시각·현재와 다른 층의 시야 분리·숨은 층 탭 차단과NPC의 실제 쪽지 독서/개인 지도 지식·실제 대화 전달을 연결했다. 현재 보이지 않는 피는 지도 색으로 공개하지 않으며, NPC의 독서를 봤다고 비공개 내용을 자동으로 배우지 않는다. 실제 대화는 원래 작성자/시각/주장과 물리 쪽지를 보존하고 출처/전달 단계만 더한다. 각인120·통합 전체164파일3,174개150.32초·타입/린트·화면791–798의8개 장면 전체 확인/7전체 복원/저장 후19·20턴 전체 일치/콘솔0이다. 월드30판296.413703524초의30행 전체가v159와 같다. v160별도 전체 회귀/월드는 실행한 것으로 기록하지 않는다.
