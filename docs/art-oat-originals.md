# ASHVEIL 원본 귀리 알곡·귀리 씨앗 아이콘

2026-10-21 제작. `/workspace/ashveil-oat-art`에만 작성한 원본 아트 인계 묶음이다. 기존 임시 버섯 그림을 대체할 **새 sheet/frame 조각 2종**을 준비했으며, Root 게임 저장소에는 아직 등록하거나 복사하지 않았다.

## 실제 대상과 읽은 기준

Root의 `CLAUDE.md`, `docs/CANON.md`, `src/content/core/defs/oatmeal.json`, 기존 달걀·재배 원본 제작 문서, CC0 팔레트·프레임 조각과 `ItemIcon.vue` 표시 경로를 읽었다. CANON의 고유 IP 원칙과 D13의 처음부터 낡은 재질 기조를 따른다. 이번32px은 기존 소지품 UI용 원본 규격이며, 월드 타일16px이나 표시 배율 규칙을 바꾸지 않는다.

| 실제 Item | 읽은 원문 맥락 | 새 제안 키 |
| --- | --- | --- |
| `Item.Oats` | 죽을 끓일 실제 곡물. own `sprite: ash_cap`, `category: misc`, 1×1, 최대 더미5. `food`·`place` 없음 | `original_hearth_oats` |

원문과 출처 파일 SHA-256은 `tools/art/oat-reference-contract.json`에 캡처했다. 이는 읽기 시점의 원문 스냅샷이며 실제 Def DB 실행·모든 패치 적용 결과를 주장하지 않는다. 캡처 당시 두 새 키는 Root manifest의 sheets/frames/chars에 없었다. `Item.Bowl`, `Item.OatmealBowl`, `Terrain.OatPlot`, `Recipe.Oatmeal`은 대상에 포함하지 않는다. 기존 `ash_cap` 타일과 다른 공유 소비자도 변경하지 않는다.

## 직접 새로 그린 형태

**귀리 알곡**은 가느다란 마른 줄기에서 따로 처지는 귀리 이삭과 앞쪽에 모인 알곡으로 그렸다. 낱알은 비스듬한 길쭉한 껍질·세로 홈을 갖고, 이삭은 빽빽한 직립 밀 이삭과 달리 가지마다 떨어진 형태다. 16px에서 가는 식물만 보이지 않도록 앞쪽 곡립을 넓게 모았다. 색은 바랜 짚·회갈색 껍질·작은 상아색 가장자리이며, 밝은 광택이나 발광 효과를 넣지 않았다.

**귀리 씨앗**은 입구를 조여 묶은 둥근 낡은 회록색 천 주머니, 밝은 거친 끈, 비대칭 천 수선으로 그렸다. 끈 밑에 짧은 **마른** 귀리 가지를 끼워 넣어 용도를 보조한다. 기존 그늘 종자의 평평한 리넨 봉투와는 체형·천색·입구·끈·수선 좌표를 새로 만들어 구분했다. 새싹·꽃·문자·품질 도장·금고 표시를 넣지 않았다. 물리 주머니 자체를 새 Item/용량/보호 기능으로 추가한 것은 아니다.

두 물품의 알곡/주머니/이삭 도형과 픽셀은 이번에 직접 정수 좌표로 새로 작성했다. 기존 음식·주머니 이미지나 좌표를 복사해 새 원본이라고 주장하지 않는다. 외부 팩·생성 이미지·타사 도안을 입력, 추출, 크롭, 트레이싱 또는 재색칠하지 않았다. 일반 Canvas·PNG·SVG·최근접 샘플 도구 코드와 공통 재질색 일부는 이 제작 흐름에서 앞서 직접 작성해 CC0로 제공한 코드를 재사용했다. **도구/일부 색 재사용과 새 그림 도형 제작을 구분**해 출처 문서에도 기록했다. 제작기는 Python 표준 라이브러리와 포함된 계약 파일만 사용하며 Root/게임 코드를 import하지 않는다.

## 파일과 픽셀 규격

| 새 sheet/frame | 파일 stem | 불투명 경계(양 끝 포함) | 불투명 가로×세로 | 32px / 16px 불투명 픽셀 |
| --- | --- | --- | --- | --- |
| `original_hearth_oats` | `ashveil-hearth-oats` | [3,3,27,29] | 25×27 | 304 / 78 |
| `original_hearth_oat_seed` | `ashveil-hearth-oat-seed` | [5,3,27,29] | 23×27 | 444 / 114 |

두 stem은 각각 `public/sprites/original/items/`에 native **32×32 PNG/SVG**와 **16×16 `-16.png`**를 갖는다. PNG는8bit RGBA, 알파0/255,18색 팔레트, 투명 외곽이다. 작은 PNG는 `(2x+1,2y+1)` 중심 최근접 샘플이며 별도 흐림 처리를 하지 않았다. 두 그림의 불투명 바닥 끝은 **30**, 선택 아트 발점은 **[16,30]** / 정규화 anchor **[0.5,0.9375]**다. 이것은 인계용 메타데이터이며 실제 런타임 anchor를 추가하거나 바꾸지 않는다.

`tools/art/oat-manifest.fragment.json`에는 새 sheets2개와 `[sheet,0,0,32,32]` frames2개만 있다. 기존 키, char, animation, Def 패치, item alias, UI 함수는 없다. 16px 샘플은 검토/향후 대체 자료이고 조각은 native32 PNG를 참조한다. 현재 `ItemIcon.vue`는 `size / max(frame.w,frame.h)`로 프레임을 요청 정사각형에 맞추고 가운데 정렬하므로 기존 아이콘 경로에서 별도 crop 없이 사용할 수 있다. 실제 호출 크기·밭 표시·월드 바닥 아이콘 배율은 이 묶음에서 변경하지 않았다.

## 권리와 의미의 한계

새 아트·좌표·팔레트·제작/검사 도구·문서는 `LICENSE.txt`의 **CC0-1.0**으로 제공한다. 상업 이용·수정·재배포·게임/모드/에셋 묶음 포함이 가능하며 별도 허가·저작자 표시를 요구하지 않는다. 인계 시 이 파일은 Root의 **`tools/art/oat-LICENSE.txt`**로 복사해 기존 저장소 라이선스를 삭제·덮어쓰지 않는다. 검사기는 이 경로와 격리 폴더의 `LICENSE.txt`를 모두 지원한다. 기존 게임 코드·다른 이미지의 권리는 그대로이며 출처 사실/해시를 읽었다고 다른 자산의 권리가 이전되는 것은 아니다.

눈에 보이는 낱알·이삭의 개수는 실제 더미 수량이 아니다. Oats 원문에는 `food`가 없으므로 이 그림만으로 생식 기능이나 영양 수치를 추가하지 않는다. 씨앗 주머니도 발아율·성장·수확량·신선도·청결·안전·오염 보호를 보장하지 않는다. 귀리죽 조리, 수분·영양, 씨앗 배치, 제조·생산·시장 수급·균형은 변경하거나 검증하지 않았다. 실제 물품명과 수치 안내는 제품 UI가 제공한다.

## 직접 열기와 독립 검사

최종 native32 두 장,16px 두 장,384×352 접촉 시트의 **실제 PNG5개**를 직접 열었다. 알곡의 밝은 곡립·처진 이삭과 씨앗의 둥근 회록색 주머니·묶음끈이 서로 구별되고 모든 도형이 프레임 안에 들어감을 확인했다. 접촉 시트는 왼쪽 알곡/오른쪽 씨앗 순서로4배 원본, 어두운/밝은 배경의 native32·16px와 확대16px를 보여 준다. 아이콘·접촉 시트에는 문자·숫자·로고·상태 뱃지가 없다. 실제 게임 화면 캡처가 아니다.

```sh
python3 tools/art/draw-oat-items.py --check
python3 tools/art/check-oat-items.py
```

두 검사 모두 통과했다. 제작기 `--check`는 **10개 생성 파일**을 쓰지 않고 바이트 그대로 재현해 비교했다. 별도 검사기는 제작기를 import하지 않고 PNG의 CRC·단일 종료 IEND·RGBA8·팔레트·알파·투명 외곽·경계를 검사하고 SVG rect를 독립 해석해 **2쌍 전 픽셀**을 비교했다. 작은16px의 정확한 최근접 대응, 두 크기에서 서로 다른 이미지, grain/cloth 색군의 구분, 접촉 시트 **배경까지 모든 픽셀**, 생성 참조9파일과 제작기·계약 해시도 확인했다. 결과는 `docs/art-oat-originals-verification.json`에 보존했다. 출처 Root9파일의 SHA는 계약에 캡처한 이력이며, 검사 중 Root 파일을 재검증하거나 미래 Root 버전과 같다고 주장하지 않는다.

제품 아트를 합치지 않았으므로 게임 개발 스킬의 실제 입력→화면/상태 검증은 Root 통합 후의 작업이다. 여기서는 게임·GPU·브라우저·TypeScript·빌드·Full/World/프로젝트 검사를 실행하지 않았다. 실제 조리/수확/파종 동작이나 저장 복원이 통과했다고 표시하지 않는다.

## 정확한17파일 인계

`docs/art-oat-originals-integrity.json`은 자기 자신을 뺀16파일의 정확한 경로·바이트 수·SHA-256·Root 복사 목적지를 기록한다. 그 목록 파일도 함께 복사하면 **17파일**이다. 그림/도구/문서는 상대 경로 그대로, `LICENSE.txt`만 `tools/art/oat-LICENSE.txt`로 보존한다. 전체 파일은 원본6개(PNG/SVG/small), 접촉 시트, 팔레트, 출처, manifest 조각, 제작기, 독립 검사기, 계약 스냅샷, CC0 라이선스, 이 문서, 검사 기록, 해시 목록이다.

Root가 통합 시 두 신규 frame을 등록하고 정확히 두 실제 Item에만 바인딩할 수 있다. 이번에는 Root/public/manifest/Def/Core/Git·기존 문서를 수정하지 않았다. v298 제품이나 다른 원본을 교체하지 않은, 이후 통합용 독립 아트 묶음이다.
