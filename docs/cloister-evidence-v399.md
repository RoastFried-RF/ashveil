# v399 봉인된 병동의 실물 기록

수도원 봉인 내력의 공개 경로를 대조하니, 융합체에는 기존 인장 반지만 있고 마지막 기록과 씨앗 캡슐 잔해가 없었다. 새로 생성되는 융합체의 실제 소지품에 ‘수도원장의 마지막 기록’과 ‘회색 가루가 묻은 씨앗 캡슐 잔해’를 한 개씩 추가했다. 죽을 때 새 전리품을 만들지 않는다. 원래 지니던 UID를 사체 수색으로 옮기며, 같은 사망을 다시 처리해도 지급하지 않는다. 기존 인장 반지도 보존한다.

기록은 회색 가루 처치 뒤에도 이어진 갈증·마름과 서로 이어진 병상의 증언을 전한다. 캡슐은 정원사망 용기의 각인을 읽는 실물이다. 밀봉된 활성 균 캡슐이나 사용 가능한 씨앗·탄약이 아니며, 각인만 읽고 가루의 현재 활성을 판정하지 않는다. 기존 읽기·문해·온전한 완독 규칙을 그대로 쓴다. 새 두 물품 ID를 사용하며 다른 책을 읽었던 기억으로 대신하지 않는다. 부모 문헌의 도감 효과도 빈 목록으로 명시해 상속하지 않는다.

실마리 네 단계는 마지막 기록, 실제 잔해의 각인, 본인의 성공한 융합체 해부, 별도로 읽은 정착균 병리 기록을 맞춘다. 당시 기록자의 증언·자기 표본의 구조·문헌의 이름을 구분한다. 현재 환자의 진단, 모든 회색열의 결말, 잔해의 배양 검사로 확대하지 않는다. 근거가 부족한 단계는 제목/본문을 숨기며 조회는 세계를 바꾸지 않는다.

## 기존 원정과 생성

저장219와 기존 Core338파일을 유지한다. 이미 생성된 옛 융합체나 사체에는 새 ‘원래 전리품’을 소급 지급하지 않는다. 새 콘텐츠를 승인해도 기존 몸/물품/UID는 보존한다. 아직 생성하지 않은 심층이나 새 원정에서 생성되는 융합체가 새 소지품을 지닌다. 이미 처리한 옛 원정에서 새 원본을 되살리는 기능은 아니다.

새 생성의 두 추가 소지품은 정상 loadout의 UID/생성 난수 흐름을 따른다. 새로운 융합체를 만든 뒤의 할당/난수까지 옛 생성과 같다고 주장하지 않는다. 기존5골든은 이 심층 개체를 생성하지 않으며, 두 콘텐츠 해시·새 두 물품 종류/크기 설명 외에는 전체 초기/최종 세계와 명령 오류가 같다. 새 심층 전리품과 구형 소지품은 별도 검사로 확인한다.
