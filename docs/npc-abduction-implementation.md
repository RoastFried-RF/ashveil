# 현지 NPC의 실제 포획 접근과 같은 밧줄 호송

v0.205. 기존 NPC 돌봄/동료 해방을 우선하고 자기 시야의 저항 불능 적을 대상으로 포획을 시작한다. 기존 guard/raider AI 중 실제 현장의 깨어 손을 쓸 수 있는 비동료만 자기 거처·개인 배낭의 실제 밧줄을 확인해 계획1턴을 쓴다. 플레이어·동료·대상과 다른 지도의 복사 배우·캐러밴/도로 원정은 이 경로로 새 포획을 시작하지 않는다. NPC 자신의 음식/수분/피로·깨어 저항하는 위협에 기존 생존/전투가 우선한다.

계획은 같은 대상ID/예약 밧줄/거처와 마지막 실제 목격 위치 사본만 남긴다. 보이지 않는 현재 대상 위치를 추적하지 않고 마지막 목격까지 실제 경로로 걷는다. 새 실제 목격은 관찰1턴으로만 갱신한다. 실제 곁에서 기존 포박2턴을 끝낸 뒤에만 그때 옮겨진 같은 밧줄UID를 임무와 연결한다. 쌓인 밧줄 분리도 실제 완료한UID로 묶는다. 다른 사람이 잡은 포로나 다른 밧줄로 대체하지 않는다.
