# 사라진 정신붕괴·공포의 현재 상태 정리

v0.260 작업 중, 각인182/API1.4.0. 설계11§8의 상처·상태 제거를 Break/Trauma와 아직 시작하지 않은 NPC 붕괴로 확장했다. 원래 정의 종류가 실제 해당 상태와 맞고 현재 구성에서 사라진 경우에만 검토/승인 뒤 제거한다. 울음 붕괴가 만든 동반 crying 효과도 집계해 지운다. 실제 소스에서 이 효과를 만드는 곳은 startBreakdown의 울음 한 곳이며, 다른 효과는 보존한다.

이를 정상적인 붕괴 해소/공포 극복으로 실행하지 않는다. endBreakdown은 현재 없는 정의를 읽고 긴장 완화/Thought.Breakdown을 주므로 호출하지 않는다. overcome은 극복 점수·난수·새 특성을 줄 수 있으므로 호출하지 않는다. 현재 긴장·다른 공포 진행·몸/물품·시각/UID/전체 난수·과거 개인 사건/정신 기록을 보존하고 회복/극복 보상은 만들지 않는다. NPC의 아직 시작하지 않은 붕괴 pending도 실제 Break 종류일 때만 지우며 당시 사고/긴장은 그대로 둔다.

기존 네 상태도 해당 필드의 기록된 원래 종류와 맞을 때만 제거하도록 보강했다. 잘못된 종류의 살아 있는 참조와 남는 임의 값·키는 뒤의 원자적 검사에서 차단하며, 보관되지 않은 원래 수치/종류를 추정하지 않는다. 검토는 현재 상태별 수와 보상 없음/과거 기록 보존을 표시하고 실제 원문/선택 구성 토큰 승인·같은 턴 집계 로그/한 번 저장을 따른다.

실제 이전 Core의 울음 Break와 어둠 Trauma 정의를 먼저 로드한 정상 새 게임에서 startBreakdown/gainTrauma를 선언된 초기 호출로 실행했다. 과거 스트레스 원인이나 경과한 플레이를 실행한 이력으로 꾸미지 않는다. 전용7개+실제 저장 시작3개와 기존 상태/ID/모드 시작/스크립트 변경/사건 예약/골든을 포함한9파일72개가 통과했다. 첫 전용 묶음32개도 통과했다. 전체 상태·긴장/생각/특성/난수 보존과 실제 한 로그/한 번 저장·잘못된 종류/살아 있는 참조·취소/변경 원문·반복 무보상/저장 복원을 확인한다.

원래258 전체 회귀280파일5360개 중5359개는 통과했고, 기존 모드 시작 보호 검사가257에서 새로 자세해진 오류 문구에서 원래 ‘현재 소스가 다르다’ 문장을 찾지 못해 실패했다. 원래 실패를 보존하고 현재 구현에서 상세 원인 앞에 원래 오류 문장을 함께 표시하도록 고쳤다. 기존 검사의 실제 세계/화면/각인/버전/저장 불변 검사는 바꾸지 않았으며 관련72개에서 해당 기존 검사도 통과했다.258월드는 실패 뒤 실행하지 않았다.256–260 전체/월드 회귀는 새 원본260에서 통합 검증한다.

골든5개 전체 초기/최종/오류/해시가259와 정확히 같다. 기본 저장 형식/벡터·Core Def/191물품/277패치는 바꾸지 않는다. 최종 타입·린트·Def277패치/191물품·빌드1.79초를 통과한 원본260에서 실제 화면1279–1281 세 장을 모두 확인했다. 실제 초기 붕괴/공포/울음의 검토/취소 원문 유지·현재 정신 상태/집계 로그/현재 메타데이터 외 전체 일치·전체182복원1·잘못된 종류 참조의 승인 차단/원문 유지·콘솔0을 첫 실행에 통과했다.256–260 통합 전체/월드 회귀는 진행 중이다. 다른 상태/개체/설치·같은 모드 소스 이행과 나머지 전체 후속 확장은 남는다.
