# 같은 모닥불 위 한 회분 조리와 방치

v0.113. 01의 실제 굽기200턴과 중단/진행 보존, 03 §4.3의 방치10분마다 탐10%−생존 숙달1%p·탄 음식 열량×0.7/맛−4를 연결한다. 13 §4.13을 먼저 등록했다. 기존 직접 굽기를 유지하고, 실제 설치하고 땔감을 피운 자기 모닥불에 한 회분을 올리는 방법을 추가했다. 한 불에1회분과 불 위 음식70°C 부패/해동 정산은 Def 제안값이다.

올리는 실제1턴 행동은 배낭 원본 한 개만 불 위로 옮긴다. 원본이 하나면 UID를 유지하고, 더미면 기존 분리 규칙대로 한 개/새 분리UID와 배낭의 원래 나머지를 보존한다. 배낭·바닥에 중복 음식이 없다. 같은 불의 실제 연료가 타는 연속 턴만 진행한다. 불이 꺼지거나 다른 불로 교체되면 진행/탐이 멈춘다. 다른 지역에 가 있어도 원래 지도의 원래 불을 사용한다. 현재 환경으로 관측하지 않은 과거의 조리를 소급하지 않는다. 원래 조리/결과/정책 서명이 바뀌면 진행을 멈추고 원래 내용물을 회수할 수 있다.

200번째 실제 뜨거운 턴에 같은 원래 물품이 구운 음식으로 바뀐다. 신선도·재·품질/내구와 실제 해동을 보존한다. 지각/생존 숙달과 실제 모닥불 보정을 사용하는 음식Q는 원래 조리 시작 조건으로 계산하고 독립 난수를 한 번 쓴다. 배낭 물품의 원래 품질과 결과 음식Q를 구별해 표시한다. 조리만으로 몸에 영양을 주지 않는다. 덜 익은 물품을 내려도 진행이 남고 다시 올리면 이어진다. 일부 익은 것과 날것, 탄 것과 온전한 것을 합쳐 상태를 세탁할 수 없다.

익은 음식을 불 위에 남겼을 때만 추가200턴마다 실제 탐을 판정한다. 확률0은 판정 난수를 쓰지 않고 이미 탄 음식도 다시 굴리지 않는다. 태우거나 회수해서 새 음식을 증식하지 않는다. 회수는 자기 음식/실제 거리·시야·배낭 칸을 확인한다. 탄 음식의 실제 섭취자에게만 감소한 열량과 원래 단백/비타민/수분을 준다. 플레이어의 맛 사고는−4이며 좋은 식사 보상과 중복하지 않는다. 기존 NPC의 사고 수집 범위는 그대로다.
