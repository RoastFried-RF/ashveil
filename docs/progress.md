## 중간 push와 웹 미리보기

- 검증 완료271을 main에 push했다: [4ff1d35](https://github.com/RoastFried-RF/ashveil/commit/4ff1d35236e79f959a28d133d4663d910b72af91).
- Pages 자동 빌드·배포 설정을 push했다: [73e455b](https://github.com/RoastFried-RF/ashveil/commit/73e455bc410160a6f165cfc8dcd22ae0012c8ff2).
- 실제 새 게임 화면도 [README](../README.md#화면-미리보기)에 올렸다. 고정 상태 주입 없이 배포 빌드의 타이틀에서 새 게임을 시작하고 키보드 대기·소지품을 확인한 화면이다.
- GitHub Actions에서 실제 빌드/배포 아티팩트 생성은 성공했다. 저장소 Pages가 활성화되지 않아 공개 단계가 실패했고, 현재 인증으로 Pages 활성화 API는 권한 거절된다. [현재 제한과 설정 위치](web-preview.md). 확인한 외부 플레이 주소는 아직 없다.

검증한 구간마다 결과·실제 오류/수정 근거를 기록하고 push한다. 작업 중 코드는 별도로 보존한다.
