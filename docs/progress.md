현재 플레이할 수 있는 기반은 던전·지역/월드 이동, 신체·생존·정신, 전투·장비·제작, 주민·거래·동료/포로·거점, 지도/정보 전파, 선박/해상 이동과 모드 도구다. 기능마다 지원 범위가 다르며 ‘전체 생태·경제·모든 제작법/결말 완성’을 뜻하지 않는다.

주요 남은 범위는 전체 제작/탄약 경제·나머지 질병과 음식/보존법·숲/건물 화재·잠긴 문/정밀 열쇠·월드 생태/전역 경제·대규모 전투·확장의 나머지 지역/분기/결말·창작마당/자산 모드다. 실제 사람의30분 플레이 평가/외부 테스터 재플레이 기준도 자동 검사와 별도로 남는다. [전체 작업 범위](expansion-roadmap.md).

- GitHub Actions에서 실제 빌드/배포 아티팩트 생성은 성공했다. 저장소 Pages가 활성화되지 않아 공개 단계가 실패했고, 현재 인증으로 Pages 활성화 API는 권한 거절된다. [현재 제한과 설정 위치](web-preview.md). 확인한 외부 플레이 주소는 아직 없다.

검증한 구간마다 결과·실제 오류/수정 근거를 기록하고 push한다. 작업 중 코드는 별도로 보존한다.
