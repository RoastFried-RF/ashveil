# 실제 추가 순찰 인원의 비용과 지출 기록

v0.186 구현·185–186 통합 검증 완료. design/10 §4.2의 실제 근접병25/궁수30/두목60 단가를Def 옵션으로 연결한다. 원래 성향의 최소 강화 비용/사용 비율·현재 예산을 확인한 뒤 실제 편성표의 추가 인물을 확인한다. 단가를 낼 수 있을 때에만 그 원래 인물을 추가하고 정확한 비용을 쓴다. 추가 인물 단가가 부족하면 지불 가능한 기존 빈도 강화만 적용하며 새 인원/몸/물품을 만들지 않는다. 사용 비율도 실제 추가 단가에 적용한다.

성공한 실제 출발에는 현재 시각/지도/비용과 실제 추가 인물UID를 지출 기록으로 남긴다. 이 기록은 엔진의 유한 예산 감사용이며 일지에 보이지 않는 인원/위치를 공개하지 않는다. 실제 사람은 같은 원래 몸/배낭으로 기존 경로를 걷는다. 빈도만 강화한 경우에는 추가UID를 기록하지 않는다. 출발하지 않은 판정은 예산을 쓰지 않고 같은 시각에 중복 출발/지출하지 않는다.
