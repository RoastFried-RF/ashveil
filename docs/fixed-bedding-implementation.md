# 원래 지형 침대의 실제 젖음과 수분 교환

v0.118. 기존 지도에 놓인 고정 침대도 실제 비/지붕/주변 불·몸과 젖음을 교환한다. 실제 설치한 침구는 원래 물품의 wetness를 쓰고, 물품 UID가 없던 지형 침대는 그 실제 타일의 beddingWetness만 보존한다. 조회·건조한 정산만으로 물품/UID나 젖음0 기록을 만들지 않는다.

실제 생성된 지도들을10분마다 정산한다. 지붕 밖 재비는 침구를 적시고, 자연 건조2·시야가 통하는2칸 이내 불 건조10의 기존 규칙을 쓴다. 다른 지도에 가 있어도 각 실제 지역의 날씨/지붕을 사용하며 벽 뒤 불은 원격 건조하지 않는다. 새 지도나 과거 날씨/물품은 지어내지 않는다.

실제 누운 몸/수면/휴식·의식 없는 몸만 기존 시간당0.6 교환 비율로 최외곽 옷이나 맨살과 천천히 교환한다. 서 있는 것만으로 침대의 물을 가져가지 않는다. 마른 몸이 젖으면 그만큼 침대가 마르고, 젖은 몸이 마른 침대에 누우면 그 침대에도 젖음이 남는다. 정본 나무 침대의 단열0은 그대로이며 새 침낭 보너스를 만들지 않는다. 기존 휴대 침낭의 원래 젖음/품질/UID·포장은 유지한다.

원래 소유 침대를 실제 포장하면 현재 타일의 젖음도 실제 물품으로 옮긴다. 포장한 뒤 남은 바닥의 침대 젖음 기록을 지우고, 같은 UID의 물품을 실제로 다시 설치하면 같은 젖음이 남는다. 포장/재설치로 물을 지우거나 다른 침구를 겹쳐 원본을 덮을 수 없다. 제작 창과 일지의 기존 침구 젖음 표시는 같은 실제 상태를 사용한다.

각인v82는 원래 타일/실제 물품과 몸/옷의 다음 수분 교환을 보존한다. 구형81의 마른 지형 침대에는 과거 비나 새 침구 물품을 소급하지 않는다. 실제 일반 스케줄러200턴 휴식은 몸 젖음7.1279%/원래 침대88.8821%를 만들고 새 UID를 만들지 않았다. 그 뒤 실제200턴 포장/재설치는 같은 침구 물품1개와86.8821% 젖음을 보존했다. 진행 중 각인 재개도 전체 상태가 같다.
