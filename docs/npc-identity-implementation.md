# 새 주민의 이름과 실제 소개 · v0.218 / 각인156

새 정착지 주민이 원래 출생하는 시점에만 `NpcIdentity.Hearth`의 기존 이름16개와 원래 역할로 개인 이름을 정한다. 같은 마을에서는 먼저 사용하지 않은 이름을 고르고 독립 `world.npc-identity.<site>` 난수만 쓴다. 원래 NPC 수·ID·몸·물품·이동·기존 난수 흐름을 유지한다. 고정 이름과 이미 초기화된 구형 주민은 다시 이름 짓지 않는다.

플레이어가 실제로 이야기하기 전 화면 이름은 원래 역할이다. NPC끼리 실제 대화하면 그 당사자의 이름을 개인 기억에 보관하지만 플레이어가 직접 소개받은 것으로 바꾸지 않는다. 원래 주민과 같은 현장에서 실제 이야기1턴을 쓰고 양쪽 몸·거리·시청각·밝기·시야·비적대 조건이 맞을 때만 소개 시각과 화면 이름을 기록한다. 전해 들은 이웃 이름은 원래 보고서 사본이며 원격 현재 객체를 조회하지 않는다.

155→156은 버전만 바꾼다. 옛 사람에게 출생 이름·과거 소개·새 개인 관계를 소급하지 않는다. 기존 고정5개 전체 초기/최종·오류·난수·몸·현물은156버전만 달랐다.217 골든을 한 번 보관하고 명령/시드/오류를 유지하며 기대 해시만 갱신했다. 별도 고정217 엔진으로 같은 실제 마을 생성 과정을 실행한 뒤 새 이름 메타데이터와 독립 난수·버전만 추가한 전체 상태가218과 정확히 같다. 이 대조는 이름 부여 때문에 기존 몸·재고·위치·ID·난수가 바뀌지 않았음을 확인한다.

전용19개를 포함한 관련3파일79개16.09초가 통과했다. 초기 잘못된 본체 ID와 난수 키 타입을 바로잡았고, 브라우저 검사의 함수/변수 이름 중복 및 const 린트를 고쳤다. 최종 빌드1.52초를 완료했다. Item188/269패치 유지·Schema140파일이다. 최종 타입·린트·골든 및 실제 화면 결과는 아래에 완료한 수치만 추가한다.

실제 화면 장면은216에서 명시한 주민 초기 근접 배치와 원래 필요/특성을 사용한다. 준비 과정의 NPC 실제 자기 차례 대화와 플레이어 공개 이동 뒤, 화면에서는 실제 이야기 버튼과 직접 접근만 쓴다. 이름을 들은 타인이 곧바로 직접 소개받은 사람으로 표시되지 않는지, 구형155 주민의 원래 이름, 전체 복원과 미완료20턴을 검증한다. 과거 여행·장기 우정·자연 발생 빈도를 달성했다고 주장하지 않는다.
