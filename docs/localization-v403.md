# v0.403 작업 중 — 공개된 물품 이름과 소지품 검색

2026-10-28 KST. v402 검증 중의 별도 작업본이다. 아래 코드는 아직 타입/대상/Full/실제 입력/화면 검토를 통과하거나 main/Pages에 게시된 것으로 세지 않는다.

현재 초안은 core 원문/패치의 실제 물품257개 label, 알약 효과6개 label, 미감정 유물4개 unknownLabel과 저장 방식3개 label/description을 검토한 ID+원문 대응에 추가한다. 정적 수집은 최종 로더 대조를 대신하지 않으며 기존 `locale-gameplay`의 실제 로드 DB 단언을 유지한다. 소지품의 명시적 메뉴·검색·장비/배낭/루팅 조작과 접근성 표시는 번역하되 물품 상세 설명·코어 오류/진행 문구와 다른 창의 영어 완성은 아니다.

공개 물품 이름 helper는 한국어에서 원래 core itemLabel을 그대로 사용한다. 영어에서는 실제 감정 단계와 플레이어의 기존 알약 추정/확신만 표시하고 숨은 pillMap을 조회하지 않는다. 재료 그램/알약¼/더미·남은 횟수/등불/깃 상태를 표시하며 기존 UID/실물을 변경하지 않는다. 원래 정의가 사라진 물품의 기록은 번역하지 않는다. 검색은 기존 한국어 이름과 표시한 영어 이름을 같은 NFKC/공백 규칙으로 찾는다.

기존 빠른 슬롯은 미감정 유물에도 실제 Def 이름을 접근성 이름/도움말 제목/소진 안내으로 쓸 수 있었다. 같은 실제 후보 선택을 읽어 원래 실물의 공개 이름/도움말을 쓰고, 빈 참조에는 미감정 이름만 사용하도록 수정 중이다. 실제 사용 선택/물품 수/행동 비용은 유지한다. 이 문제의 실제 UI 재현과 수정 후 검증은 아직 대기한다.

v401 화면에서 발견한 캐릭터 Age 중복과 설정의 저장 방식 카드도 보완 중이다. 자동 검사/실제 입력/저장·표석/탐구 복원과 게시 근거를 채운 뒤만 완료를 기록한다. X1–X4의 남은 구현과 출시/사람 평가 게이트는 계속 열린 상태다.

실제 입력 도구 `tools/inspect-items-v403.ts`는 새 탐구 세계의 유한 초기 진단 소지품3개/빠른 슬롯/알약 추정만 선언한다. 획득·감별을 했다는 근거로 세지 않는다. 로드 뒤에는 실제 한국어/영어 전환·NFKC/원문 검색·카테고리·포인터/Tab/Enter 메뉴·원래 UID 유물 버리기·빈 참조 도움말·수동 저장·대기·계속하기만 수행하고 독립 Node 전체 상태와 비교한다. 표석/탐구의 전체 복원 대화상자 번역·실제 전체 복원 시나리오는 별도 후속이다.
