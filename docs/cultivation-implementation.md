# X2 그늘 작물의 실제 성장과 유한 관수

v0.181 구현·181–182 통합 검증 완료. CANON의 실제 자원/규칙 대칭성과GDD X2·lore T10의 저조도 재배를 연결한다. 새 종자 한 개를 실제 흙에 심으면 같은 종자UID를 기록한 여러해살이 밭이 생긴다. 배낭 씨앗은 실제 한 개 줄고 새 물이나 이미 자란 진행을 만들지 않는다. 기존 그늘뿌리/씨앗188종을 재사용한다.

새 밭의 성장에는 실제 활성 지도 턴의 햇빛(캐노피/지붕 배율)·기온·토양·관수가 필요하다. 현재 제안 기본값은햇빛3.5% 이상/0~35°C/한 성장 주기28800 유효 턴과1000ml이며Def 패치로 분리한다. 휴대 횃불이나 지하의 밝은 조명은 햇빛을 대신하지 않는다. 해당 조건이 맞는 턴에만 성장하고 물을 유한하게 쓴다. 정지한 다른 층/지역의 지난 시간을 현재 날씨로 소급 계산하지 않는다. 지붕 없는 밭의 현재 실제 재비만 시간당120ml 기본량을 공급한다. 같은 시각에 정산을 반복해도 성장/물이 늘지 않는다.

관수는 현재 보이는 인접 밭과 같은 원래 물 용기UID/실제ml·몸/손/각성·수질 염도를 확인하는1턴 행동이다. 부족/넘침/동결/남의UID·해수/부적합 염도·손/거리 실패는 물/진행/난수/시계를 바꾸지 않는다. v0.181의 물1ml는28성장턴 뒤 잔량800단위가 남았다. v0.233부터 따뜻한 열린 밭의 실제 증발도 별도 소비한다. 남은 분수 물량은 정수 관수 단위로 보존한다. 그릇은 같은UID의 빈 물 용기로 남는다.

F2의 밭 패널과 현재 보이는 밭 커서는 실제 성장률/남은 물/햇빛/기온/중단 이유를 보여 준다. 성장 완료 뒤 기존 몸 상태/저조도에 따른 실제 수확 작업으로 뿌리2개를 받으며 같은 원래 밭/종자 기록을 유지하고 성장만0으로 돌린다. 남은 실제 물이 충분하면 다음 성장도 가능하고, 부족하면 추가 관수가 필요하다. 기억 속 밭은 현재의 숨은 성장/물을 내보이지 않는다.
