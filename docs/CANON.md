## 2. IP 원칙

- RimWorld·Stoneshard의 **고유명사, 설정 용어, 문장, 에셋을 사용하지 않는다.** (예: 메카노이드, 아르코테크, 글리터월드, 이데올로기 등 금지)
- 참고하는 것은 **시스템 설계와 장르적 구조**뿐이다. 모든 이름·역사·세력은 독자 창작이다.

## 3. 세계관 핵심 (Lore Canon)

### 3.1 제목과 무대
- **제목**: ASHVEIL (애쉬베일) — "재의 장막"
- **행성**: **하스(Hearth)** — 성간 개척 회사가 '정착 계약 행성'으로 개척한 변경 행성. 원래는 춥고 척박했으나 테라포밍으로 살 만해졌다.
- **무대(프로토타입)**: 북부 변경 **회색 고원(Greymoor Highlands)** 의 폐허 지대.

### 3.2 역사 요약
| 시기 | 사건 |
|---|---|
| 개척기 (약 300년 전~) | 개척 회사가 **정원사망(Gardener Lattice)** — 궤도 중계기 + 지상 대기처리탑 + 자율 작업기계 — 으로 테라포밍. 다양한 기술 수준의 이주민 유입: 원시 회귀 공동체, 중세 재현 종교 공동체, 산업 이주민, 회사 기술자 |
| 번영기 | 궤도 중계기를 통해 성간 교역. 행성 내부는 기술 격차가 큰 채로 공존 |
| **침묵(The Hush)** (약 70년 전) | 궤도 중계기가 원인 불명으로 신호를 끊음. 정원사망의 지상 기계들이 명령을 잃고 **"야생화"** — 대기처리탑이 오작동해 재와 미세입자를 뿜어 하늘을 덮음(= **재의 장막**). 성간 연결 단절 |
| 재의 겨울 (침묵 후 ~20년) | 일조량 급감, 흉작, 대기근, **회색열(Grey Fever)** 역병. 인구 대폭 감소 |
| **현재** (침묵 후 3세대) | 하늘은 늘 흐리고 재비(산성 섞인 회색 비)가 내림. 짧은 여름, 긴 겨울. 문명은 퇴행해 대부분 근접 무기와 활을 씀. 화기는 존재하나 **탄약이 극히 귀함**(탄 한 발 ≈ 하루치 식량 가치). 옛 기술 유물은 고가 |

### 3.3 기술 수준 (세계 규칙)
- 단계: **원시 / 중세 / 산업 / 개척(회사 기술) / 정원사(정원사망 기술, 이해 불가 영역)**.
- 현재 생산 가능한 것은 대부분 **원시~중세**, 일부 정착지에서 **산업** 수준 수리·탄약 재장전 가능.
- 개척·정원사 단계 물품은 **발굴만** 가능. 수리에는 희귀 부품과 지식이 필요.

### 3.4 세력 (초기 6개)
| 세력 | 성격 | 기술 | 기본 태도 |
|---|---|---|---|
| **고원 촌락연합** (Moorhold Villages) | 농민·목축. 방어적, 외부인 경계 | 중세 | 중립 |
| **고물길드** (Salvage Guild) | 유물 발굴·교역. 돈이면 다 됨 | 중세~산업 | 우호(거래) |
| **잿빛 약탈단** (Ashen Reavers) | 약탈·노예. 사기 낮으면 쉽게 흩어짐 | 중세 | 적대 |
| **장막 순례회** (Pilgrims of the Veil) | 재의 장막을 신의 장막으로 숭배하는 교단. 정원사 기계를 '천사'로 봄 | 원시~중세 | 경계 |
| **잔존 경비대** (Remnant Wardens) | 개척 회사 경비대 후손. 규율, 소수 화기 보유 | 산업 | 경계 |
| **야생 정원사** (Feral Gardeners) | 명령을 잃은 자율 기계. 대화 불가 | 정원사 | 적대(영역 침입 시) |

### 3.5 생물 (프로토타입 우선)
- **재늑대(Ash Hound)**: 장막 이후 변이·야생화된 개 무리. 피 냄새·소음에 반응. 배고프면 대담, 배부르면 회피.
- **약탈자(Reaver)**: 인간. 플레이어와 같은 신체 규칙.
- **굴쥐(Burrow Rat)**: 작고 약하지만 물리면 감염 위험 높음.
- **수리 드론(Tender Drone)** — 야생 정원사의 소형 기계. 출혈 없음, 대신 부품 손상·과열. (프로토타입 선택 사항)

### 3.6 확장 여지 (의도적으로 열어둠)
- 궤도 중계기는 왜 침묵했나 → 후반 주제 / 확장팩
- 다른 대륙·지역(습지, 해안, 장막 아래 '검은 숲')
- 정원사 기계와의 소통 가능성
- 성간 재접촉

### 3.7 주인공
- 이름 없는 **떠돌이(Drifter)**. 생성 시 **배경 1개 + 특성 2~3개**.
- 배경 예: 탈영 경비병, 파문된 순례자, 고물 발굴꾼, 촌락 사냥꾼, 몰락한 길드 상인, 떠돌이 약초꾼.

## 5. 깊이 3층 원칙 (모든 시스템 필수)
- **L1 표면**: 첫 1시간에 알아야 할 것
- **L2 중간**: 몇 번 죽어보면 아는 것 (10~50시간)
- **L3 심층**: 파고드는 사람만 아는 것 (50시간+/위키)
- **규칙 대칭성**: 플레이어 규칙 = 적·NPC·동물 규칙
- **정보 공개**: 규칙(공식)은 투명, 세계 지식은 미지
