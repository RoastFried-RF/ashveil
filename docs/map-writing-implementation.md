# 실제 종이와 잉크로 탐험 지도 작성

v0.152는 문해1 이상인 플레이어가 직접 발견한 현재 지역/던전 층의 방과 실제 관찰한 계단을 빈 쪽지에 옮기는 작업을 연결한다. 원래 종이UID를 유지하며 완료할 때 실제 잉크1회분을 소비한다. 이미 글이 있는 쪽지는 덮어쓰지 않는다. 새 아이템은 구현 전에 인벤토리13에 등록했다. 잉크는 마른1회분 안료이며 가상의 빈 물병을 만들지 않는다.

신뢰도40+생존숙달단계×10, 오차3−⌊단계/2⌋, 누락률(100−신뢰도)/2%를 쓴다. 시간60턴과 재료/몸 조건은 Cartography.Hearth PATCH의 기본값이다. 원래 시장 재고에서 종이/잉크를 거래하고 공급할 때 정착지의 유한Fuel 저장고에서 각0.01단위를 옮긴다. 분류와 공급 비율은 콘텐츠 기본값이며 저장고0에서는 재입고하지 않는다. 기존 주화/물량 거래를 사용한다.

시작 때의 직접 탐험 기록·숙달 품질·지역·원래 재료를 묶어 보존한다. 아직 탐험하지 않은 방, 소문에만 있는 방, 숨은 현재 계단, 생물/재고는 복사하지 않는다. 도중에 새로 본 내용도 원래 초안을 바꾸지 않는다. 몸/조명/재료/지역/설정이 달라지면 진행을 남기고 멈춘다. 중단/취소/조회/실패에서는 그림 난수와 재료를 쓰지 않으며, 완료에서 독립items.cartography.종이UID 난수로 한 번만 누락/오차를 정한다. 새 경험치나 숙달 보너스를 주지 않는다.

지도 창에서 재료·품질·남은 시간·불가 사유를 확인하고 작성/재개/취소한다. 작성한 당시 문서를 자기 지식에 배우며 원래 종이와 전달된 사본은 이후 현재 지형으로 자동 갱신하지 않는다. 각인115→116은 버전만 이관하며 과거 작성 작업이나 재료를 만들지 않는다.

전용20/관련3파일57개를 통과했다. 실제 공개60턴 완료와10턴 중단→50턴 재개, 실제 잉크 버림 뒤 실패, 유한 시장 구매/저장고0, 원래 몸/종이/잉크/난수의 저장 복원을 확인했다. 미완료 장면은 최초 시계1턴 뒤 작업58회와 다음 입력까지의 정산을 포함한 실제59턴을 더 진행한다. 시작 시각에 첫 작업 단계가 실행되는 기존 스케줄러 규칙을 유지했다.

브라우저 화면/전체 각인 복원/실제 지도 창 버튼과 전체 회귀·월드 검증을 완료했다. 함정 지도/정찰 계약 결과물/전역 지도는 남은 후속 범위다.
