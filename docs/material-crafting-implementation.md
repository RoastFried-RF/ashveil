# 재료 선택과 실제 질량 상속 — v0.79

제작법은 기존의 정해진 물품 개수와 별도로 결과물의 부위별 원재료 질량을 정할 수 있다. 제작 창에서 실제 배낭의 재료·조각과 사용할 그램 수를 고르며, 모두0으로 두면 실제 UID 순서로 자동 선택한다. 각 부위의 필요량과 허용 재질·가공 작업장을 확인한다. 견적은 물품·시간·UID·RNG를 바꾸지 않는다.

시작한 작업은 같은 UID와 재질·조각당 질량을 예약한다. 한 묶음이 고정 개수와 여러 재질 부위에 쓰여도 중복 소비하지 않는다. 중단/각인/재개는 원래 예약과 진척을 이어 가고, 다른 재료로 바꾸려면 취소해야 한다. 예약된 물품이 없어지면 같은 종류의 다른 UID로 대신 완성하지 않는다. 이전 제작법의 진행에 나중에 재질 규칙을 붙여 무료로 완성하지 않는다.

완료 때 실제 사용량만 소비한다. 남은 조각은 같은 물리적 물품에서 갈라진 질량이며, 원래 묶음이 남아 있을 때에만 나눈 조각의 새 UID를 발급한다. 원래 물품을 다 썼다면 그 UID를 남은 조각에 보존한다. 남은 조각은 별도 원재료 형태여서 기존 개수 제작/목표가 작은 조각을 온전한 한 덩이로 세지 않는다. 같은 재질·조각당 그램 수·상태끼리만 쌓이고, 배낭이 차면 실제 바닥에 놓는다.

결과물의 각 부위는 실제 사용한 재질과 질량 비율을 상속한다. 같은 부위의 서로 다른 재질은 질량 가중 물성·혼합Q−5를 적용한다. 단일 재질도 실제 질량을 보존한다. 질량은 제작/물성/분해용 내부값이며 소지 무게 제한은 만들지 않는다. 사냥칼·손도끼·셔츠·사슬옷·가죽 코트의5개 제작법을 추가했다. 기존 공작 수첩과 별도의 새로운 재료 책이 해금하며, 셔츠는 기초 제작이다. 새 책은 고물길드의 실제 유한 시장 재고로 공급해 기존에 공작 수첩을 읽은 사람도 배울 수 있다.

실제 재질이 기록된 장비는 재질별로 원래 질량과 현재 내구·작업 점수를 적용해 회수한다. 회수율은10~80%이며 같은 재질의 여러 부위를 합산한 뒤 그램 단위로 내린다. 원래 물품은 사라지고, 회수한 실제 재질만 온전한 원재료와 작은 조각으로 남는다. 알맞은 온전한 원재료 형태가 없는 재질도 실제 조각으로 보존한다. 조각의 거래 가치는 실제 재질 가격과 질량을 따른다. 기존의 재질 미지정 분해는 기존 결과를 유지한다. 동료는 실제 창고 재료를 인출하고 자기 재료로 충분하면 더 꺼내지 않으며, 제작한 같은 결과물을 납품한다.
