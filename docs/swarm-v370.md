# v0.370 · 재나방 군체와 실제 채집·가루·위장

2026-10-25 KST. 저장215의 개발 묶음이다. 새 굴뚝탑 정비 구역의 군체 기부/쪽지 접근 땅을 명시적으로 비우고 원래1,000마리의 군체2개와 야행 규칙 쪽지1부를 처음 생성한다. 이미 방문한 지도/각인에는 군체·재료·쪽지를 보충하지 않는다. 나머지 관로 지네/구제기와 착용 의복·절단/보철·장기 생태 및 X1–X4/출시 게이트는 남는다.

## 환경 군체와 유한 수량

재나방은 공격하는 단일 신체가 아니다. 새 SwarmDef/MapState.swarms로 실제 사람·광원과 같은 칸에 겹칠 수 있는 환경 군체를 구현한다. 단일 머리·팔·혈액·허기/체온이나 해부 가능한 거대한 몸을 만들지 않는다. 별도의 원래 UID·시작 개체 수·남은/채집/연소 수량·위치·집결 정도·이동 시계가 각인에 남는다. `남은+채집+연소=시작 개체`를 복원 때 검사한다. 기존39Creature/12Body는 유지하고 환경 종1개를 추가했다.

밤/그늘·던전에서 실제 켜진 지도 광원과 사람이 실제로 내보내는 휴대 광원을 찾아 반경2배 안의 시선이 통하는 빛으로 이동한다. 벽/닫힌 문/막힌 대각선 모서리를 통과하지 않으며 이동40TU를 정산한다. 지도 밖의 이동·분산 과정은 기존 포자/파종기와 같은 국소 시계로 정지하고, 돌아왔을 때 장기 이동을 한꺼번에 실행하지 않는다. 실제 생존/수량은 추정해 재충전하지 않는다.

밀집한 군체가 덮으면 시야가 최대50% 줄고 날개 가루를 조금 흡입한다. 개체 수·집결 정도가 줄면 차폐/흡입도 약해진다. 기계도 광학 차폐는 받지만 생물의 흡입 피해를 받지는 않는다. 잠수 중에는 물 위의 나방 노출을 적용하지 않는다. 날씨의 재와 군체 가루는 공통 방진 면포의 실제 여과 시간을 턴당 한 번만 소비한다. 충분히 여과하지 못한 가루는 실제 기침/소음을 낸다.

덮친 노출 휴대 횃불은 원래 UID/남은 연료를 유지한 채 밀집도에 따라 턴당 최대5%로 꺼진다. 여러 군체가 겹쳐도 같은 실제 횃불에는 한 번만 판정한다. 꺼진 실제 광원은 자동 작업/이동 중단 사유다. 봉인된 등불에는 이 횃불 판정을 적용하지 않는다. 소등하면3~5턴 안에 집결이0으로 내려가 흩어지고, 다른 실제 불을 미끼로 쓸 수 있다. 모닥불·지형/침구 화재의 빛에 몰려든 원래 개체는 실제로 연소하며 식용 표본으로 다시 나오지 않는다. 빛이 돌아오면 같은 남은 개체만 다시 모인다.

표현 문구·이미지·초기 배치 마릿수와 현재 군체 정책 서명을 분리했다. 단순 번역/그림 변경으로 원래 군체를 정지시키지 않으며 실제 정책이 달라지면 원래 수량/각인을 바꾸어 새 정책으로 해석하지 않는다. 군체 Def ID 이행/구성 변경의 추가 경로는 출시 감사에 남는다.

## 실제 재료와 현장 UI

F2의 현장·야영 맨 위에서 실제 천 조각 UID를 사용해 한 턴에 최대50마리를 채집한다. 깨어 있는 손·거리·시선·대각선 접근을 검사한다. 채집한 만큼 군체가 줄고 실제 표본이 배낭에 들어가며 넘치는 분량은 바닥에 남는다. 같은 종의 여러 신선도 더미는 UI에서 총수만 묶어 보여 주고, 실제 원본 더미를 임의 병합하지 않는다.

밝은 곳에서 쓸 수 있는 날로 실제 표본 한 마리를 소비해 S3 구조를 기록한다. 노출 뒤 살아서 벗어나면 지도 경계를 넘어간 경우도 S2로 기록한다. 새 선반의 실제 야행 규칙 쪽지는 공통 완독/문헌으로 S4를 제공한다. 도감과 사망 생애의 읽기 전용 발견 기록에는 혈액/부위 대신 환경 군체의 지식을 남긴다.

표본1마리는0.2g이다. 열 마리2g을 갈아 날개 가루1g을 얻고 나머지 몸통 찌꺼기는 버린다. 쉰 마리10g은 공통 실제 모닥불 작업에서 구운 나방10g 한 줌으로 가공한다. 원료/열량/단백질/물의 입력을 늘리지 않는다. 날것·구운 것 모두 벌레를 먹은 기분을 적용한다. 표본/구운 한 줌에 최소 단가를 붙여 벌레 수로 돈을 생성하지 않는다.

가루 한 몫을 실제로 소비해 피부/겉옷을 회색으로 덮는다.1시간 동안 불빛을 끈 채 웅크리거나 잠행할 때 먼 시각 탐지를 줄인다. 인접/기존 근거리 감지는 그대로이며 열 위장이나 투명화가 아니다. 젖음50%에서 씻기고, 원래 소비 UID·적용/종료 시각·당시 규칙을 저장한다. 지도 밖에서도 실제 전역 종료 시각을 지난 위장이 되살아나지 않는다. 상태 칩은 가루가 남은 상태와 실제 위장이 작동하는 상태를 구분해 안내한다. 몸의 회색 표시는 원문에 대한 런타임 색조이며 새 의복/몸 원화가 아니다.

## 원화와 공통 비행 뷰

image_gen 원본2PNG/6고유 영역을 등록했다. 한 PNG의 한 마리4날개 포즈는 등 시점/머리 위 한 방향이다. 각 포즈의 가슴 기준점으로 맞추고, 동일한 SwarmView가 게임과 [공개 비행 미리보기](https://roastfried-rf.github.io/ashveil/artbook/swarm/)에 원본 텍스처를 빌려 쓴다. 몸의 작은 픽셀 차이·측정하지 않은 날개 힌지를 그대로 기록한다. runtime 회전/대표 나방 최대48개·분산 위치는4원문이나 실제 세계 마릿수를 늘리지 않는다.

지면 이동의 실제 순서로 보간하고, 멈춤·0/0.5/1/2배·소등 후 분산·FOV 이탈·지도/타이틀 해제와 텍스처 소유를 연결한다. 가루가 눈을 덮는 상황에 맞게 나방을 얼굴 주변으로 표시하고, 희박해질 때 넓게 흩어지며 짧게 사라지도록 했다. 원문 한 방향을 회전해 쓴 한계가 있으며 모든 광원 방향의 별도 아래면/방향 원화를 만들었다고 세지 않는다.

두 수확물 아이콘은 회색 가루의 돌그릇과 구운 갈색 곤충의 목기 그릇이다. 그릇/그림 조각 수는 별도 용기·생물 수·질량을 생성하는 규칙이 아니다. 날것 표본은 접힌 비행 원문을, 쪽지는 기존 일반 수첩 그림을 명시적으로 공유한다. 실제 PNG 편집·리샘플링·알파 제거 없이 등록했다. 원본 SHA/정확 요청·크롭·앵커·원문 계약의 한계는 `tools/art/direction-v370`과 `direction-v371`에 보존한다. 이전 v369 군체 이미지는 보류하며 비행 프레임으로 세지 않는다.
