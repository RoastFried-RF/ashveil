# 원본 식재료·실제 연료와 환경으로 진행하는 보존

v0.105. 설계03 §4.5의 훈제와 건조를 연결한다. 기존 생고기3회분+소금1의 이틀 염장육3회분은 유지한다. 발효 절임과 나머지 보존/음식은 후속 범위에 남는다.

새 훈제 준비는 실제 설치하고 땔감을 피운 원래 모닥불 바로 곁에서 실제 생고기 한 회분을 예약한다. 준비 완료 때 원본 식재료 UID·수량·신선도·품질·재 오염을 배치에 넘긴다. 그 뒤 동일 모닥불 UID와 실제 유효 연료가 있는 구간만 6시간에 합산한다. 마지막 유효 연료 구간도 센다. 연료가 떨어지거나 불을 끄면 멈추며, 같은 불에 실제 장작을 더 넣어 이어 간다. 정착지의 무한 화덕이나 새로 바꿔 놓은 모닥불로 원래 훈제를 완료하지 않는다.

새 건조는 원래 생고기 한 회분을 두 조각의 육포로 바꾼다. 실제 강한 바람 또는 피운 불은2일, 약한 바람은4일에 해당하는 진행을 쌓는다. 노출된 재비·재폭풍·잿바람에는 멈춘다. 무풍 실내는 실제 불이 없으면 진행하지 않는다. 지붕은 비를 막지만 바깥바람을 실내바람으로 취급하지 않는다. 강풍 문턱2/빠른 진행2배와20턴 준비 시간은 수정 가능한 Recipe Def 기본값이며 확정 정본 수치로 취급하지 않는다.

훈제 고기는 원래 생고기48시간의10배 보존/비타민×0.3, 직접 말린 육포는20배 보존/두 조각 합산 비타민×0.5를 따른다. 기존 상점 육포의 보존값을 전역 수정하지 않는다. 불 곁에서 익히는 훈제와 기존 육포의 조리 규칙을 사용한다. 원래 음식의 열량·단백질은 기존 식사/살코기 굶주림 흡수·구토 규칙을 거친다. 실제 훈제식의 냄새 반경+2는 기존 짐승의 후각 감지에 연결하고 수량으로 중첩하지 않는다. 음식 설명에 이 효과를 표시한다.

읽기 전용 조회는 시간·난수·UID를 소비하지 않는다. 실제 연속 턴 구간만 가공에 더하고, 현재 날씨만 있는 긴 시각 점프에 과거 며칠의 진행을 만들어 넣지 않는다. 비활성 지도와 먼 장면의 원래 배치도 같은 턴/지역 날씨로 정산한다. 가공 중과 완료 후에는 보존식 기준으로, 중단 중에는 원재료 기준으로 실제 매 턴 신선도가 감소한다. 재 오염·해동·젖음·남은 음식 상태를 씻어 내지 않는다. 원래 제작 규칙이 바뀐 배치는 다른 결과로 회수하지 않는다.

제작 창은 실제 남은 진행·중단 이유·신선도와 회수 가능 여부를 읽는다. 회수는 기존 배낭/바닥 처리와 한 번만 가능한 실제 배치를 사용한다. 각인v69는 원래 재료·불·진행·품질·남은 신선도를 보존한다. 구형68의 염장/무두질 배치와 몸·현금·난수는 버전만 올리고 과거 가공을 소급 생성하지 않는다.

전용20개는 준비/이른 회수의 원자성·원래 장작의 마지막 구간·실제 보충과6시간/한 번 회수·불 교체 방지·반복/시각 점프·실제 스케줄러·강약 바람과2일 뒤 두 조각/같은 총 재·비/지붕/무풍·중단/완료 후 부패·비활성 원래 지도·전체 각인·모드 규칙 변경·실제 후각/섭취·구형 배치를 확인한다. 관련7파일109개도 통과했다. 준비 검증에서 목재4개가 최대3 묶음으로 나뉘어 원본 ID가 달라진 테스트 준비를 실제3개 원본 묶음으로 고쳤고, 실제 첫 식사의 살코기 흡수70%를 기대값에 반영했다. 브라우저용 완료 직전 상태는 실제 장작 세 개와 일반 스케줄러로7198턴을 기다려 만들며 진행 숫자를 덮어쓰지 않는다.

v0.105에서는 원본 고기/재료 기록·같은 유한 장작불의 실제6시간 훈제·실제 바람/불의2~4일 건조와 노출 재비 중단·원래 신선도/품질/재 보존·한 번 회수/섭취·냄새 반경과 각인v69를 연결했다. 전체107파일1,828개102.37초·전용20개/관련109개·타입/린트/Def99패치/Schema92/빌드·화면452~457/6장·네 차례 전체 복원·콘솔 오류0이다. 같은 검증용 사본의 월드30시드×최대3일312.858191643초·30개 전체 행이 이전과 같다. 고정 사본에서 전체 검사를 완료했고 같은 빌드/원본 코어로 브라우저와 월드를 검증했다. 브라우저 초기 준비에서 월드를 제거해 계속하기가 구형 월드를 새로 만들던 검증 코드를 실제 월드 유지/실제 스케줄러 준비로 수정했다. 모든6장 화면을 직접 확인했다. 최종 사본은 전체 파일 SHA-256 manifest와 같다.
