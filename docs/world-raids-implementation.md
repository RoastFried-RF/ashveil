# 원래 야영지 주민의 순찰·강탈·화물 운반 — v0.96

`design/09-world-and-simulation.md` §7의 교역단 습격과 약탈 화물의 실제 야영지 유입을 연결한다. 이미 존재하고 방문한 잿빛 수도원의 원래 약탈자만 출정한다. 새 공격자나 교역단을 사건 확률로 생성하지 않는다. 현재 기본값은 셋째 날부터 하루 한 순찰, 건강하고 자유로운 원래 주민 최소 둘·최대 셋, 인근 정착지로 이어지는 실제 육로의 처음 세 칸이다. 기존 야영지 인구에는 실제로 길을 떠난 사람도 포함하며, 실제 사망만 인원에서 공제한다.

관찰 중인 야영지에서는 원래 인물들이 실제 출입구로 걸어간다. 화면 밖에서는 저장된 실제 지도 경로 길이로 출발 보행을 정산한다. 이후 실제 월드 칸과 이동 시간을 진행하고, 길목에서 하루 동안 순찰한다. 교역단이 없으면 실제 귀환 경로로 돌아온다. 무리가 같은 월드 칸에 있을 때만 습격을 시도한다. 기본 판정은 `실제 출정 당시 야영지 가용 인원×5%−살아 있는 호위 수×10%`를 0~100%로 제한하며, 같은 순찰의 같은 날에는 한 번만 판정한다. 빈 교역단은 가짜 손실이나 화물을 만들지 않는다.

## 화면 밖과 실제 현장의 차이

L2 강탈은 원래 교역 화물 중 실제 약탈자 배낭의 빈 격자에 온전한 더미로 들어가는 물건만 옮긴다. 원본 UID·수량·재질·오염·상태를 보존한다. 현금도 이동 상점에서 원래 운반자의 개인 현금으로 옮긴다. 가짜 시신이나 상처를 만드는 전투 요약은 하지 않는다. 교역단은 살아 있는 원래 사람들과 남은 물품으로 여정을 계속한다. 대금이나 물품이 목적지 또는 야영지로 즉시 이동하지 않는다.

플레이어가 같은 길목에 있으면 원래 순찰자를 현재 지도에 배치하고 보관 배열에서는 제거한다. 실제 시야에 들어온 무리만 지도 창에 표시한다. 현장에서는 실제 시야·마지막 목격 위치와 적대 관계로 걷고 싸운다. 살아서 저항하는 상인의 물건을 요약 판정으로 빼앗지 않는다. 원래 상인이 실제로 죽거나 붙잡힌 뒤 그 시체·바닥에 있는 원래 화물 곁에 도달해야 회수할 수 있다. 실제 손 기능·각성·거리·시선과 막힌 모서리를 확인하고, 유한한 시체 현금도 한 번만 가져간다. 포로는 교역/순찰 보관 인원과 중복되지 않고, 죽은 사람은 실제 시체로 남는다.

현장 회수를 마친 사람들은 실제 지도 경계까지 걸어 나온 뒤 월드 귀환 시간을 진행한다. 같은 칸에 남아 있거나 저장 후 이어하기로 이탈한 무리를 반복 소환할 수 없다. 다음 실제 월드 칸으로 이동해야 새 만남을 허용한다. 관찰 중에는 식사·식수·심한 피로 등 기존 생존 행동이 순찰 명령보다 우선한다.

## 실제 상자까지의 귀환

귀환자는 원래 도시 출입구에 들어와 실제 약탈물 상자 곁까지 걸어간다. 관찰하지 않는 지도도 실제 접근 경로 시간이 지난 뒤 정산한다. 실제 상자에 들어가는 원본 물품만 옮기며, 공간이 모자란 물건은 원래 운반자의 배낭에 남는다. 상자가 아직 열리지 않았다면 원래 전리품 표를 한 번만 초기화한다. 기존 상자 내용이나 개인 물품을 지우지 않는다. 개인 현금은 원래 인물에게 남아 실제 시체 수색으로 회수할 수 있다. 원래 시민의 거처·초소·몸·장비를 유지한다.

각인 v60은 순찰 경로·정차 종료·원래 사람·실제 강탈 원장과 운반 중 물품·현금·회수한 원본 UID를 저장한다. v59 이관은 버전만 바꾸고 과거 순찰을 만들어 내지 않는다. 화면 밖 생리·전투 전체를 턴마다 계산하는 기능은 아니다.

## 검증 상태

검증용 세계는 실제 원래 약탈자 여섯 명과 침묵원의 실제 상인·교역 재고를 사용한다. 초기 공급/부족 상태만 설정하고, 원래 주민의 순찰이 실제 도로 (24,73)에 먼저 도착한 뒤 별도로 출발한 교역단이 같은 칸에 도착한다. 최종 검증은 기본 확률에서 강탈 판정이 성공하는 고정 시드 raid-cargo-12를 사용한다. 기본 설정·난수·저장 모드 목록을 바꾸지 않는다. 이전의 독립 설정 경계 검증 뒤, 브라우저 이어하기와 같은 core 설정으로 전체 관련 경계를 재검증했다.

교역단/길목/순찰/Def 관련 4파일 134개를 통과했다. 여행/순찰 2파일 26개도 통과했다. 원래 화물 5+5+2개·현금 보존, 실제 귀환 시간/상자 보행, 배낭 가득 참, 실제 시체 회수/포획, 원래 인구 사망 공제, 각인 전체 동일 재개를 확인한다. 실제 귀환자가 상자가 아닌 원래 초소로 가던 오류와 어두운 길목 중앙에만 머물던 수색 오류를 검증 중 발견해 수정했다. 순찰자는 실제 통행 가능한 격자를 번갈아 훑으며 걸어 찾고, 목표를 실제로 보았을 때만 마지막 목격 위치를 갱신한다. 기존 여행 검증도 실제로 출정한 사람과 남은 사람을 합쳐 몸/장비/일과 전체와 인물의 단일 소유를 비교하도록 갱신했다. 기존 고정 플레이 5종의 전체 시작·종료 상태와 오류는 v0.95와 같으며 버전59→60만 변경된다(`golden-v096-diff.json`). 전체98파일1,638개86.80초·타입/린트/Def88패치·Schema86파일 오류0·빌드를 통과했다. 최초 전체 실행에서 기존 여행 검증의 실제 출정 예외가 누락됐던 것은 검증을 갱신해 재확인했다. 기본 core 설정과 고정 시드의 관련134개·실제 어두운 길목 NPC 수색/원본 시체 회수/보행 이탈도 별도로 확인했다. 최종 브라우저386~391/6장·네 차례 전체 각인v60 복원·콘솔 오류0을 확인했다. 실제 기존 시신에서 NPC가 원본 화물을 가져가 걸어 나가는 흐름과, 실제 상자에 반납된 원본 더미를 플레이어가 각각 회수하는 흐름을 검증했다. 이는 선행 전투 자체를 브라우저에서 완료했다는 뜻은 아니다. 최초 회수 검사의 모두 가져오기는 수량/오염은 보존했지만 정상적인 자동 합치기로 더미 UID가 바뀌었으므로, 동일 앱에서 온전한 더미를 개별 회수하는 실제 UI 검증으로 수정했다. 앱 동작을 바꾸지 않았다. 최종 검증용 사본 v096-browser는 원래 전체 검사한 v096과 모든 앱 파일1016개의 SHA가 같다. 같은 사본의 월드30시드×최대3일272.72009700200005초·평균0.4219895833333334일·저체온19/치명상5/과다 출혈6이며,30개 전체 결과 행이v0.95와 같다(sim-v096-diff.json).

전역 세력 영역·이주민·야영지 이전/증원·모든 정착지의 약탈 조직과 해상 교역 등 나머지 후속 범위는 남아 있다.
