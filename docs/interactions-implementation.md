# 상호작용 발견과 소식가 과식 경계

v0.147은 일지에 상호작용 탭을 추가한다. 미발견 항목은 분류와 `???`만 보여 주고, 새로 배운 항목은 반응·규칙·최초 출처·시각·지도/지역을 보존한다. 정수5방식·침구 발화/소화·염장/훈제/건조/발효의11개 Def를 실제 완료 경로에 연결했다. 원래의 물·연료·음식·도구·가공 시간과 판정은 그대로 사용한다. 정수 수식은 현재 WaterSafety Def의 병원체/재 배율을 읽어 표시하며 녹은 소금의 잔류를 구분한다.

실제 작업자는 완료 때 배우고, 현재 지도에서 의식과 시력이 유효한 관찰자는 실제로 보이는 발생 위치를 목격했을 때 배운다. 닫힌 용기 안의 물 침전과 원격 지역은 밖의 플레이어에게 지식을 주지 않는다. NPC의 개인 지식은 플레이어 지식과 별개다. 훈제·염장 등은 재료 준비나 이른 회수로 배우지 않고 완성품을 실제로 회수해야 배운다. 단위검사의 염장/발효 완료 상태는 명시적인 유효 초기 배치이며, 과거2일/14일을 실제 스케줄러로 실행했다는 주장이 아니다. 훈제/건조는 실제 처리 구간을 끝까지 정산해 검사한다.

온전히 이해한 실제 완독과 명시적인 typed 소식도 같은 지식 경로를 사용한다. 생존 수첩은 정수/보존5개, 염부 수첩은 염장1개를 가르친다. 읽지 않은 초기 책·찢긴 책·오독·일반 글의 단어만으로 추론하지 않는다. 최초 발견은 ‘알아냈다’+2를 주고 새로운 경험치/숙달 보상은 주지 않는다. 지속1일/중첩1은 Def의 조정 가능한 기본값이며 정본에 새 수치를 확정하지 않는다. 기존 실제 작업/책의 원래 숙달 보상은 유지된다. 같은 항목은 기억이 만료해도 다시 발견 보상을 주지 않는다.

소식가는 실제 음식의 열량을 더할 때+1,500 초과부터 과식한다(정본04 §8). 저장 가능한 칼로리 상한+3,000과 별개다. 일반 인물은 기존+3,000 경계를 사용한다. 저장 복원이나0/음수 열량으로 과거의 과식 사건을 만들지 않는다.

각인110→111은 버전만 이관한다. 과거의 상호작용이나 과식 기억을 소급하지 않는다. 전용37/관련7파일155개·타입/린트·Def207패치/Interaction11/Thought100·Schema124/오류0·빌드를 통과했다. 골든5개의 초기/최종 전체와 모든 오류는 버전 외v146과 같다. 화면714~719 여섯 장 전체 확인·6전체111 복원/실제200턴 끓임/남은199턴 전체 재개 일치·콘솔0·전체150파일2,944개157.58초·월드30판306.259870787초의30행 전체가v146과 같음을 확인했다. 최초 전체검사에서 옛 고정버전110을 검사하던4개 단언을 현재 버전 기준으로 고친 별도 불변 스냅샷으로 전체검사를 다시 통과했다. 제품 코드/빌드는 원래v147과 같으며 중복 실행되어 자원 경합을 겪은 중간 검사 결과는 제외했다.
