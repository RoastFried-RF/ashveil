# v0.391 공격 실물과 투척 동작

v390 공개 소스의 고정 빌드에서 오른손 손도끼와 왼손 투창을 가진 초기 각인을 불러와 실제 빠른 슬롯1→Enter로 던졌다. Core는 왼팔과 원래 투창67을 사용했지만, 렌더러가 행동 뒤 장비를 다시 조회해 남은 오른손 손도끼66을 기준으로 연출했다. 일반 투척 소품도 오른손에 붙었다. 독립 Node 전체 상태3쌍과 실제 PNG/RAF 관측은 로컬 `test-results/autonomy-v391/baseline-native-r1`에 보존한다. 이는 선언한 초기 상태의 재현이며 자연 플레이 통계가 아니다.

|---|---|---|

관찰 채널은 기존 선택적 `startActionObservation`에 붙인다. 공격 event 객체를 weak key로 사용하고 같은 객체를 소비할 때 한 번 꺼낸다. 기존 FX80개 상한과 객체 수명이 범위를 정하며, 채널 해제/새 세계에서 이전 기록을 잃는다. Core headless에서 구독하지 않으면 복제하지 않는다. `GameState`, `FxEvent`, 저장 형식에 필드를 추가하지 않는다. 기존 피해·비용·난수·UID·착지·묶음 병합 규칙도 유지한다. 분무 탱크는 기존 성공한 실물 소품/사용 가능한 손 선택을 유지하며, Core의 일반 공격용 오른팔 대용값을 결손 팔의 표시 지시로 확대하지 않는다.

기존 `equipment-motion.ts`의 투척540ms를 유지한다. 원래 휴대 각도에서.24까지 들어 올리고.48에서 실제 표적 벡터를 향한 뒤.5에 놓는다. 선택한 팔의 손도 준비/발사/정상 위치를 부드럽게 잇고 반대 손의 물건을 투척물로 대체하지 않는다. 새 PNG·새 authored 동작 프레임은0개다. 원래 물품 원화와 인간 cutout을 재사용한2D 동작이며, 실제 비행체 궤적/바닥 착지 지연이나 완전한3D 투척을 구현했다고 세지 않는다.

`tests/attack-observations.test.ts`는 관찰 유무의 전체 상태/FX/난수/UID 일치, 연속 공격의 정확한 event 소유, 묶음 분리, 실제 타격 중 무기 파손, 유효 공격 override/복제 격리, 이후 이동/장비 변경, 해제/재시작을 확인한다. 기존 두 동작 검사에는8방향×양손의 무기 각도/발사 시점과4시점×양손의 팔 경계 연속성을 더했다. 관련7파일90검사, 타입/대상 린트/빌드와 기존5개 골든의 전체 초기·최종·오류 비교가 통과했다. 골든 기대값은 변경하지 않았고 관찰 채널을 켠 재실행도 통째로 같았다.

`tools/inspect-attack-owner-v391.ts`는19개 유한 초기 상태에서 실제 빠른 슬롯/Enter와 이어하기를 사용한다.8방향·주무기/보조무기/배낭/허리띠 주머니·오른팔 결손·웅크림·0/.5/1/2배·바닥 묶음 병합·연속 묶음 투척을 포함한다. 입력 묶음 UID와 실제 분리된 한 개 UID를 구분한다. 브라우저 로드 뒤 세계를 교체하거나 장비/시각/난수를 바꾸지 않는다. 전체 세계는 독립 Node 결과와 비교하고 이미 소비된 표현 FX만 정규화한다. 원본 전체 저장 JSON은 로컬 검사 산출물이며 공개 저장소에 올리지 않는다.

초기 검사 도구에서 허리띠 내용물의 칸 좌표를 빠뜨린 저장 거절과, 소프트웨어 렌더링의 느린.5배 동작이 고정1600ms 관측 안에 끝나지 않은 실패를 보존했다. 전자는 선언한 초기 배치 좌표를 고쳤고 후자는 실제 연출 종료까지 읽기 전용 RAF 관측을 기다리도록 했다. 실패를 삭제하거나 게임 시간을 조작해 맞추지 않았다. 초기 r1의 단일 장면 검사는 확장한 최종19장면 검사와 별도로 센다.

프리뷰만0.391-dev이며 저장219·Core 버전0.1.0을 유지한다. 최종 고정본/검사/게시 근거는 [검증 기록](release-v391-proof.json)에 남긴다. 전체 v1.0/X1–X4·변형 인간의 고유 몸·미세/복합 결손·주머니 일반 사용 소품 관찰·물리 비행체·장기 생태/균형과 사람 출시 평가는 계속 남는다. 이번 수정만으로 모든 행동과 출시 게이트를 완료 처리하지 않는다.

최종 로컬 검사: 고정 runtime r2에서19상태·실제20투척·독립 전체 상태58쌍과 브라우저오류0을 확인했다. 실제 준비 PNG를 열어 왼손 원래 투창과 반대 손 손도끼를 확인했다. 확장 검사 도구의 최종 bytes/SHA와 전체 기록은 검증 JSON에 남기며 원본 전체 세계는 로컬에만 둔다. 기존 행동 회귀·전체 CI·공개 확인은 이 고정 뒤 별도로 진행하고 결과만의 추가 push는 하지 않는다.
