# 검은 숲과 실제 종자 금고

v0.81 / 각인 v45. 전체 단위/속성/브라우저와 동일 월드30판 회귀를 마쳤다. X2의 그늘 지파 사이 소식 전달·신뢰와 빛 예절, 다중 마을 등 관계 확장은 별도 후속 작업이다. X1~X4 전체 완료를 뜻하지 않는다.

`CANON.md` → `GDD.md` X2 → `lore/world-bible.md` T10과 `lore/factions.md` §8.1을 따른다. 그늘 주민은 초자연적 종족이 아니라 관로 정비공 가족의 후손이며, 종자 금고는 테라포밍 실패 때 재시작하려고 묻은 저장고다. 평판 시작 −20은 정본 P5의 확정값이 아니라 콘텐츠에 둔 제안 기본값이다.

검은 숲 정비구는 기존 지형·도로·촌락 추첨이 끝난 뒤 붙인다. 희망 좌표(45,81)에 가장 가까운 실제 육지 중 기존 지역과 겹치지 않고 도보로 닿는 칸을 고른다. 원래 도로·정착지를 다시 추첨하지 않는다. 해당 칸만 검은 숲 생물군계/자원으로 바꾼다. 기존 각인에서도 새 지역을 한 번 추가하고 새 마을의 인구·저장고·시장만 초기화한다. 기존 시계·재고·주민은 보존한다.

지역 지도는 RegionLayout Def로 정의한다. 흩어진 나무/버섯·실제 길·집/정비구·실제 NPC·상자·지상/지하 연결을 최초 한 번 생성한 뒤 같은 지도와 물품을 다시 쓴다. 숲은 낮 빛 20%의 캐노피를 쓰고 휴대 광원은 기존 실제 빛/시야 규칙대로 작동한다. 그늘 상인·간병인·경비와 수리 드론, 기존 식수·음식·침구·보온 생활을 연결한다. 지상 주민의 몸/시야는 지하 친척과 다른 Def를 쓴다.

교환 재고의 실제 열쇠를 얻어 종자 금고의 기계식 문을 연다. 문을 다시 닫아도 전용 잠금 종류가 보존된다. 열쇠는 사용해 없애지 않으며 일일 생산/소비 0인 최초 실제 재고 한 개다. 금고 상자의 씨앗과 책은 최초 생성된 UID와 격자를 보존한다. 수색이나 재진입으로 재생성하지 않는다.

씨앗 한 봉지를 빈 흙에 심으면 수확 가능 시각을 하루 뒤로 저장한다. 돌바닥이나 기존 밭에 심을 수 없다. 수확하면 실제 그늘뿌리2개를 얻고 다음 수확도 하루 뒤다. 이는 현재 채집/재생 시계에 연결한 재배 기반이며, 토양·관수·계절별 성장 전체를 구현한 것으로 보지 않는다. 메뉴는 ‘흙에 심기’, 밭 커서 정보는 남은 시간을 표시한다. 그늘뿌리는 실제 300kcal/45ml·부패/영양과 정착지 식량 저장고의0.12 단위에 연결했다.

원본 정비 기록의 온전한 완독은 종자 금고·실험 수목·두 지파의 내력을 일지 지식에 남긴다. 손상돼 빠진 쪽이 있거나 잘못 읽은 기록을 완전한 지식으로 표시하지 않는다. 같은 책을 다시 읽어 지식/숙달을 중복 얻지 않는다.
