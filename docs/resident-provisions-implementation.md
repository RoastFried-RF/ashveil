# 주민의 실제 식량 배급과 소비 원장 — v0.48

주민은 배고프고 가진 음식이 적으면 정착지의 실제 배급 창고까지 걸어가 식량을 받아 먹고 업무 자리로 돌아간다. 창고에서 받는 순간에는 허기를 회복하지 않는다. 배낭에 든 실제 음식을 먹을 때 기존 영양·오염/식중독·목마름·시간 규칙을 적용한다. 주민도 안전한 식사 전에 물과 손을 쓸 수 있으면 손을 씻는다. 경비는 보이는 적 앞에서 배급을 미루며, 민간인은 보이는 적을 먼저 피한다. 의사의 의료용 술을 갈증 해결용 물보다 먼저 마시던 선택도 비알코올 음료로 제한했다.

`ResidentProvision.Hearth`는 건빵350kcal 미만의 소지 식량·몸의 칼로리500 이하에서 배급을 찾고, 목표1750kcal까지 실제로 받을 수 있는 양만 지급한다. 하루 식량1.5인·일분, 거처 주변3칸의 창고 배치, 실패 뒤1시간 재시도는 임시 조정값이다. 한 번에 한 음식 더미 안에서 공간/재고/일일 한도를 확인한다. 부족하면 부분 지급하고, 품절·배낭 부족·한도 소진은 식량/돈/UID를 만들지 않는다. 개인 한도는 전역 날짜로 바뀌며 장소 재진입/저장으로 초기화하지 않는다.

이미 쓰던 월드 공공 물자→시장 물품 실체화와 같은 원칙으로, 공공 `Food`를 실제 음식의 대응량만큼 차감하고 주민 배낭의 물품 UID를 만든다. 건빵1개350kcal는0.14Food이고5개는0.7Food다. 실제 저장고에서 인출하며 상인 상품/현금을 대신 소모하거나 주민 돈을 새로 만들지 않는다. 원격의 창고 재고를 미리 읽지 않고 아는 위치로 간 뒤 실제 위치/창고·재고/공간을 다시 확인한다. 창고가 사라지거나 경로가 막히면 계속 같은 길을 반복하지 않고 재시도를 미룬다. 플레이어·비거주자·다른 정착지의 요청은 주민 배급을 받지 못한다.

음식의 실제 소비 원장은 별도다. 실제 주민이 먹은 물품의 공공 물자 대응량을 그 날짜에 기록하고, 자정의 요약 인구 소비에서 한 번 뺀다. 개인별 공제는 기존 인구 모형의 하루 기본량까지만 인정하므로 과식/힘든 일의 추가 소비까지 다른 주민 몫에서 빼지 않는다. 음식 지급만으로 공제하지 않아 아직 개인 배낭에 남은 식량도 보존한다. 중복 차감을 막는 것은 흡수량이 아니라 실제 소비량이며 토한 음식도 소비한 자원이다. 기존 정수 물자 소비/소수 이월과 함께 계산하고 다음 날에 같은 공제를 재사용하지 않는다. 플레이어·원격 지역·잘못된 수량은 주민 공제를 만들지 않는다.

배급 창고는 기존 주민 거처 가까운 안전한 빈 지형에 한 번 설치한다. 생물·아이템·건축·물·계단·작업장·침구를 덮어쓰지 않는다. 실제로 배급받는 모습은 보일 때만 상태 연출로 표시한다. N의 창고 장부는 실제 창고 곁에서만 공동 식량을 인·일분으로 보여 주며 여행자용 식량은 상점에서 구매하도록 안내한다. 보이지 않는 NPC의 수령/식사가 플레이어 기록·비밀 지식을 대신 얻어 주지 않는다.

각인v15는 배급 한도·재시도/복귀·개인/공공 소비 원장을 보존한다. v2~14의 몸·개인 식량·침대·수면을 유지하며 무료 배급이나 공제를 임의로 부여하지 않는다. 기존5고정 입력은 원본 명령·오류를 유지했고 전체 초기/최종 차이는 버전14→15뿐이다(`golden-v048-diff.json`).

검증14개와 Def1개는 실제 이동/수령/식사/귀환·공공/개인 식량/현금/UID 보존, 읽기 전용 견적, 품절/공간/한도·부분 지급, 원격 조회 배제/창고 훼손, 역할/거리, 실제 섭취 공제/개인 상한, 자정의 중복/다음 날·소수 이월, 위협/휴식 우선순위, 비공개/중간 원장 복원을 다룬다. 전체47파일736개가29.79초에 통과했고 lint·타입/빌드·Def·45파일 JSON Schema 검사도 통과했다. 브라우저90~93/설정은 콘솔 오류0이다. 실제 의사의 창고 이동/5개 수령/1개 식사/업무 복귀, 공공0.7Food 차감/개인·공공 소비 공제0.14, 현금/시장 재고 무변경·물품 UID1개 생성, 근처 장부와 전체 원장 각인 복원을 확인했다. 92화면도 직접 확인했다. 30시드×최대3일은239.683959967초, 평균0.42021412037037037일·생존0/저체온19/치명상5/실혈6이며 v0.47과30시드의 원인·시간·레벨·지도가 같다. 봇이 방문하지 않는 정착지 행동은 별도 검증으로 판단한다.

주민의 장기 식수·우물/연료/끓이기, 추가 급여/개인 구매·다른 인구 변화와 실제 주민 사망의 전체 연결은 남는다. 무한한 식량이나 장기 생존을 보장하는 규칙으로 세지 않는다.
