동료 처치 순서의 각 단계에 **바로 시행 / 1·5·10·60·120분 대기**를 정할 수 있다. 대기는 앞 처치를 실제로 끝낸 뒤부터 센다. 각 대기는 최대2시간, 대기 합은 최대8시간이며 단계는 기존 최대8개다. 첫 처치부터 예약하거나 다른 동료를 환자로 정하는 명령에는1턴이 들고 실제 처치에는 원래 작업 시간이 든다. 예약은 무한 반복 처방이 아니라 사용자가 검토한 유한 순서다.

기다리는 동안 환자를 진료 대기로 묶지 않는다. 환자는 이동·휴식·별도 일을 할 수 있고 동료는 현장에서 기다린다. 동료의 식사·식수·휴식은 우선한다. 예정 시각에 곁의 깨어 있는 원래 환자를 직접 보고, 원래 약·바늘·재료 UID와 현재 몸·빛·급료·안전을 다시 검사한다. 사전 확인한 간호는 환자의 일반 휴식을 끝내고 시작할 수 있지만 수면·무의식을 임의로 깨우거나 다른 작업을 빼앗지 않는다. 기한1분을 놓치거나 현장/급료/규칙이 바뀌면 중단한다. 이미 바른 약·감은 붕대·소모품은 되돌리지 않는다.

HUD에 다음 진료까지의 턴을 표시하고, 누르면 일지 **진료** 탭으로 간다. 일지에는 현재 현장에서 직접 보이는 동료에게 맡긴 순서를 모아 보여준다. 진찰 기록은 당시 소견으로 유지하고 현재 숨은 몸 값을 다시 조회하지 않는다. 처치 검토에는 실제 물품 그림·원래 물품·수량·예상 시간/품질·약효/위험을 표시한다. 같은 약을 반복 배치하면 반복 투여를 다시 확인하도록 알린다. 기존 예약을 새 처치로 덮어쓰지 않으며, 원래 계획ID의 예약 중단 또는 새 동행·대기·방어 지시로 중단한다. 중단 후 남은 순서는 새 검토를 거친다.
