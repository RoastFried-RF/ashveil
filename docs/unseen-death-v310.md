# 시야 밖 사망의 정보 노출 — v0.310

v0.309의 실제 타이틀 불러오기→남쪽 한 걸음→대기에서, 기억한 칸의 적이 벽 뒤에서 출혈사했을 때 새 시체가 표시되고 ‘과다 출혈’ 로그와 ‘죽음을 목격함’ 사고가 생겼다. 적은 처음2570ml, 가려진 뒤2510ml로 살아 있었고 다음 턴2462ml로 사망했다. 두 번째/세 번째 시점 모두 현재 시야 밖이며 공개 관찰 DTO에는 없다. 실제3PNG를 각각 열어 시체 출현을 확인했고 독립 Node와3개 전체 상태가 같다. 초기 상처/벽/비활성 AI는 유한 초기 fixture로 선언했다. 자연 부상/만남의 증거가 아니다.

첫 조사 장면은 벽의 사각을 만들지 못했고 addWound의 반환 객체 대신 실제 wound 필드를 수정해야 했다. 실패 원문과 수정한 초기 장면은 각각 `test-results/visibility-v310-investigation-r1`, `-r2`에 보존한다. 이 문제는 v0.309 과정에서 원본 픽셀 대조로 오판임을 확인한 ‘복원 화면 어두워짐’과 별개다. 그 렌더러 실험은 폐기했다.

수정은 시체를 포함한 동적 개체를 현재 관찰 범위에서만 표시한다. 숨은 개체의 사망/위치·모양/상태로 기존 뷰를 갱신하지 않는다. 다시 보인 이미 죽은 개체는 새 사망 애니메이션을 재생하지 않고 시체로 나타난다. 기억한 지형은 유지하며 동적 시체의 실시간 상태를 지형 기억으로 취급하지 않는다. 맵 클릭도 같은 관찰 문맥만 사용해 숨은 시체/생물을 직접 선택하지 않는다. 커서 정보와 공개 DTO의 기존 시야 제한은 유지한다.

타인의 보지 못한 죽음은 사인 로그·목격 기분·새 도감 기록·목격에 의한 트라우마 승리를 만들지 않는다. 자신의 원래 피해 기여에 따른 처치·경험치·책임은 보존하지만 보지 못한 정확한 사인을 중계하지 않는다. 실제 사망/혈액·시체·물품/개체 번호·다른 NPC의 규칙은 그대로 처리한다. 실제 보이는 죽음은 기존 목격과 로그를 유지한다. 새 Def·저장 필드/이행은 없으며 저장205를 유지한다.
