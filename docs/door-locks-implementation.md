# 실제 잠긴 문과 그늘 사람 원본

v0.285 작업 중. 동결284 전체 검사와 분리한다.

14의 후속 잠긴 문을 기존 물리 문/잠금쇠 작업/도구에 연결한다. 새 녹슨 잠금 문만 콘텐츠에 등록하고 최초 던전의 원래 경비실 문 중 우회로가 남는 후보 한 개만 바꾼다. 이전 각인의 문/상자/전리품을 소급해서 만들거나 잠그지 않는다. 유한30작업턴·원래 칼/도끼/망치 내구5·10작업턴마다 소음8은 콘텐츠 기본값이다. 기존 열쇠 전용/기계 봉인 문은 이 작업으로 열 수 없다.

완료는 같은 닫힌 문/잠금/지도·같은 도구/거리/시야를 재검사하고 원래 문 잠금만 해제한다. 따로 문을 여는1턴을 내야 하며 문을 다시 닫아도 자물쇠가 재생되지 않는다. 잠긴 문은 일반 경로 탐색의 통과점으로 쓰지 않는다. 잠금 상태/작업은 같은 물리 각인에 남긴다. UI/F2와 실제 입력·저장/복원/관련/전체 검증은 아직 진행 전이다.

shade0 자체 원본의 기존12보행+새16공격을 실제 manifest에 연결했다. 공용mon1/다른 외형을 재색칠하지 않았고 Root가 전체 검토 시트를 직접 확인했다. 두 번째 외형은 격리 제작 중이다. 전체 장기 확장 완료를 뜻하지 않는다.
