# 실제 침대 숙박 — v0.44

정착지 상인이 여관 침대도 관리한다. N에서 빈 침대를 빌리고 표시된 좌표로 직접 걸어가 Z로 잔다. 기존 침구 품질1.0·체온·영양·위험·약물·피로·수면 부채 규칙을 그대로 사용한다. 숙박료로 몸 상태나 피로를 즉시 바꾸지 않는다. 음식과 치료는 별도다.

`Inn.Hearth`의 침대2개·24시간(28800턴)·8전은 임시 조정값이다. 세력 평판의 기존 거래 가격 배율을 적용하며 흥정은 상품 거래에만 적용한다. 대여 확정은1턴이고 금액/좌표/기한을 확인할 수 있다. 실제 소지금에서 시장 금고로 이전하며 물건이나 돈을 생성하지 않는다. 견적은 읽기 전용이고 확정 때 접근/가격/잔액/예약/점유를 다시 확인한다.

유효한 타인 계약, 다른 생물의 현재 점유, 자신의 다른 유효한 침대 계약은 예약을 막는다. 같은 침대의 연장은 기존 기한에서24시간을 더한다. 만료된 빈 침대는 현재부터 새로 빌린다. 거리가 멀거나 적대하거나 상인이 응답할 수 없거나 침대가 사라지면 돈을 받지 않는다. 계약이 없으면 자발적으로 침대에서 잠들 수 없고 일반 수면은 만료 시 깬다. 실제 약물로 강제된 수면/의식 상실은 기존 신체 규칙을 따른다. 누워 있는 다른 생물을 순간이동으로 내보내거나 침대를 중복 배정하지 않는다.

침대는 상인의 거처 가까운 빈 지형에 한 번만 설치한다. 기존 건축·물건·생물·물·계단·작업장·침구를 덮어쓰지 않는다. 안전한 자리가 없으면 실제 배치한 수만 사용하며 자리가 없어도 계속 침대를 생성하지 않는다. 고정 침대는 휴대 침구 접기로 가져갈 수 없고 다른 설치물로 덮어쓸 수도 없다. 옛 지역에 한 번 추가한 뒤 재진입·각인 복원에서 다시 생성하거나 계약을 초기화하지 않는다. 사망한 상인을 부활시키지 않는다.

각인v11은 위치·침대·계약자·전역 기한을 저장한다. v2~10의 몸·돈·물품·진행 활동은 보존하며 새 숙박 계약을 임의로 부여하지 않는다. 기존5골든 입력은 원본 명령·오류를 유지했고 초기/최종 차이는 버전10→11뿐이다(`golden-v044-diff.json`).

숙박8개와 Def1개 검증은 현금/1턴·읽기 전용 견적, 중복/점유/부족/변경 가격 거부, 연장/재대여, 거리/의식/적대/훼손, 동일 위치의 실제 침구 회복 차이·만료 기상, 수면 도중 저장 결정론, 안전 배치/중복 생성 방지, v10 보존을 다룬다. 전체43파일684개가23.34초에 통과했다. lint·타입/빌드·Def·42파일 JSON Schema 검사도 통과했다. 브라우저77~80에서2침대/8전 실제 이전·중복 예약 거부·키보드 이동·실제 침구 일지·수면 후 몸/기한/현금 복원을 확인했다(설정 포함, 콘솔 오류0). 30시드×최대3일은243.67870391000002초, 종료 코드0이며 평균0.45796412037037043일·생존1/저체온18/치명상5/실혈6이다. v0.43과30시드의 원인·시간·레벨·지도가 같다. 봇은 숙박을 이용하지 않으므로 숙박 자체는 별도 단위/브라우저로 검증한다.
