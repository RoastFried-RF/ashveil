# v0.304 조작 검사와 수정

기본 조작의 문맥, 포커스, 반복 입력, 클릭 이동과 물품 조작을 집중 점검했다. 이번 변경은 v0.303 원화를 그대로 사용한다. 각인204와 콘텐츠/모드 정의는 유지한다. 전체 프로토타입이나 X1–X4 완성을 뜻하지 않는다.

## 플레이 중 달라진 점

| 조작 | 결과 |
| --- | --- |
| 기본 `N` / `Shift+N` | 남동 이동 / 주민·동료 창. 이전에 저장한 명시적 키 배치는 유지한다. |
| 창 안에서 방향키·대기·휴식 | 배경의 캐릭터가 움직이거나 턴을 소비하지 않는다. 창의 버튼·선택 목록은 정상 조작한다. |
| `Tab` / `Shift+Tab` | 현재 창·물품 메뉴·음식 혼합 확인 안에서 포커스를 순환한다. |
| `Escape` | 끌기·물품 메뉴·음식 확인을 먼저 취소하고, 다음 입력으로 실제 맨 위 창을 닫는다. 선택 목록에 포커스가 있어도 닫힌다. |
| 누르고 있는 키 | 이동·대기만 설정한 반복 방식을 따른다. 창·물품 사용·회전·밀기·문 조작은 새로 눌러야 다시 실행한다. |
| 아이템 `Enter` / `Space` / 메뉴 키 / `Shift+F10` | 물품 행동 창을 연다. 화살표·Home·End·Tab으로 탐색하고 Enter로 실행한다. |
| 물품 메뉴 바깥 클릭 | 메뉴만 닫는다. 같은 클릭으로 뒤의 HUD 버튼이 실행되지 않는다. 다음 의도적인 클릭은 정상 작동한다. |
| 잘못된 끌기 / 끌기 중 Escape | 원래 위치를 유지한다. 바닥 물품이 먼저 주워지거나 창이 닫히지 않는다. |
| 지도 클릭 이동 | 첫 걸음을 즉시 시작하고, 같은 거리라면 직선에 가까운 경로를 택한다. 장애물·대각선 충돌 규칙은 유지한다. |
| 자동 이동 중 창·버튼·Tab·Space·창 비활성화 | 이동을 중단한다. Space 취소 자체가 추가 대기 턴을 만들지 않는다. |
| 인접한 용기·시체 클릭 | 실제 누른 대상을 열고 소지품 창을 다시 표시한다. 다른 인접 대상이 대신 열리지 않는다. |
| HUD 전투 기술 → Enter | 지도 조준으로 포커스를 옮겨 선택한 기술을 확정한다. Tab/Shift+Tab은 표적만 바꾸며 무료다. |
| 위험 경고 확인 | 누르던 이동 키의 반복으로 즉시 걸어 나가지 않는다. 키를 놓고 새로 눌러야 이동한다. |
| 창 끌기·해상도 변경 | 창과 닫기 버튼을 화면 안에 유지한다. 물품 메뉴도 실제 크기로 위치를 제한하고 내부 스크롤한다. |
| 타이틀 → 이어하기 | 이전 화면의 창·조준·포커스 상태를 새 화면에 넘기지 않는다. |

## 검사 방법

[창을 올린 뒤 Escape](previews/v304-controls-1440-1801-top-window-escape-preserves-inventory.png) · [선택한 시체의 실제 물품](previews/v304-controls-1366-1805-exact-clicked-corpse.png) · [작은 화면의 물품 메뉴](previews/v304-controls-1366-1811-context-menu-clamped-to-small-viewport.png).

v0.303 불변본에서 키를 누른 채 소지품 창이 다시 닫힘, 창 포커스 중 방향키로100TU 이동, 올린 창과 다른 창이 Escape로 닫힘, 선택 목록에서 Escape 무시, 물품 메뉴/끌기 Escape가 소지품까지 닫는6개 문제를 실제 입력으로 재현했다. [당시 관찰](controls-v304-baseline.json)은 진단이며 녹색 전체 상태 검사가 아니다. 당시 자동 이동 항목은 이미 목적지에 도착해 재현 근거에서 제외했다.

중앙 입력 처리와 모든 창이 공유하는 Win, 아이템 메뉴·끌기, 지도 렌더러의 포인터 경로, 설정/검사기 및 HUD의 포커스를 읽고 실제 브라우저 입력으로 확인했다. 사회·제작 등 각 창의 모든 개별 콘텐츠 행동을 이번 검사에서 일일이 실행했다는 뜻은 아니다.

`tests/e2e/controls.ts`는 유한한 초기 장면을 각인204로 저장하고 실제 타이틀의 이어하기에서 불러온다. 이후 키·포인터로만 조작하고 독립 Node Core가 만든 기대값과 전체 상태를 비교한다. 불러오기 뒤 세계·시각·난수를 주입하지 않는다. 화면 표현 FX 소비만 정규화한다. 자동 이동은 취소 시점까지 실제 완료한 걸음 수를 읽고 각 걸음을 독립 재생한다. blur 한 항목은 실제 수치 변경 없는 합성 브라우저 생명주기 알림임을 구분해 기록한다.

장면에는 건강한 몸, 원래 물품/UID, 이미 수색한 용기·시체, 명시적으로 초기 배치한 적이 있다. 정상 플레이로 획득한 재산·부상 또는 장기 생존 증거로 해석하지 않는다. 기본/왼손/오른손 배치의 24방향 입력, 반복3방식, 실제 배낭 이동/소모/분할/음식 확인·루팅·조준·발사·투척·전투 기술, 자동 이동4종 중단, 저장 전체 복원과 작은 화면을 검사한다.

코어 수정은 클릭한 시체를 지정하는 선택적 search.target과 UI 클릭 경로의 선택적 preferStraight뿐이다. 기본 NPC/봇 경로와 지정 없는 수색의 우선순위는 보존한다. 새 단위검사는 정확한 대상 수색·거부의 원자성, 모든 키 배치/반복 정책, 최단 경로·장애물/대각선과 기존 경로 순서를 검증한다.

전체 범위337파일 6,127개를 검증했다. 최초4작업자 실행은335파일6,110개를 완전히 통과했고, 시간 초과3건을 포함한 나머지2파일17개는1작업자 재검에서 전부 통과했다(최초577.240초·재검21.860초, 코드·기대값·5초 제한 변경 없음). 두 해상도의 실제 조작26화면·독립 전체상태188쌍·각인204 전체복원2회와 별도 초기 선언 각인 불러오기16회·브라우저오류0을 확인했다. 공통 하네스8화면을 포함한 실제34PNG를 직접 검토했다. 월드30판/최대3일 541.991초(작업자4) 결과의30개 전체 행·평균·사인은 마지막 실측301과 같고, 5골든 전체 초기/최종/오류는303과 정확히 같다.

[최종 근거](release-v304-proof.json) · [월드 비교](sim-v304-diff.json). 검사 중 발견한 초기 시체 물품 배치 문제는 실제1×1 격자에 맞는 원래 돌 더미로 바로잡고 두 해상도 전체 입력 검사를 다시 실행했다. 이전 개발/진단 출력은 최종 성공 수에 포함하지 않는다. 자동 이동 중단의 합성 blur 한 항목과 유한 초기 장면의 한계는 위 설명을 유지한다.
