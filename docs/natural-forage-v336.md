# v336 자연 채집 군락 · 실제 성숙/소진과 기억

검은 숲의 야생 그늘뿌리와 잿딸기에 성숙/뜯긴 기부 각각4변형, 총16개 독자 원본 영역을 적용했다. 채택 PNG2개와 실패 후보2개는 생성 도구의 원문 바이트로 보존했다. 기존 산물 아이콘을 늘려 땅에 붙이거나 색만 바꾼 소진 그림이 아니다. 각 짝의 원래 기부 anchor와 배율을 공유하고, 소진 그림을 다시16px에 채워 키우거나 기존0.6축소를 중복 적용하지 않는다. 등록 최대 너비14/높이12월드px다. [원문/선택/등록 기록](../tools/art/direction-v336/forage/README.md).

새 검은 숲 지도의 동물 먹이5군락만 `Terrain.WildShadeRoots`로 분리했다. 기존 마을의 그늘 밭과 종자·관수·성장 단계는 원래 `Terrain.ShadePlot`을 사용한다. 방문한 옛 지도에는 새로운 군락을 소급해 만들거나 밭을 야생 군락으로 변환하지 않는다. 야생 뿌리는 기존 기본 채집12턴/뿌리2개/토양 비옥도에 따른 원래 재생 시계를 사용한다. 동물도 같은 원래 군락을 뜯으며 재생 전 산물을 중복 지급하지 않는다. 잿딸기는 원래 여름/기본12턴/5개/2일 규칙을 유지한다.

실제 숲 검토에서 달아나는 사슴이 다른 세력 문자열만으로 적으로 표시되어 채집을 중단하던 문제를 발견했다. 도발받지 않은 초식 동물은 인간에게 중립이며, 실제 발정기 공격/막다른 곳에서의 방어 중에는 위험으로 취급한다. 직접 공격 시도는 동물 자신에게도 원래 공격자를 기록한다. 비정치적 동물을 공격했다고 마을 평판 사건을 만들지는 않는다. 사냥개와 먹이 동물 사이의 적대, 엄니돼지의 실제 공격은 보존한다. 일반 클릭은 경계하는 동물임을 알리고 시간을 쓰지 않으며, 사거리 안의 Ctrl+왼쪽 클릭은 중립 대상에도 실제 공격을 시도한다. Ctrl+오른쪽 클릭은 기존의 방향 전환을 유지한다. 실제 다턴 작업과 방어→탈출·실제 공격 시도로 이 구분을 확인한다.

실제 시야 갱신 때 식물의 계절·재생 시각·재배 성장·불·토양 조건으로 `observed.gatherAvailable`을 기록한다. 렌더러는 이 마지막 실제 관찰만 읽는다. 시야 밖에서 현재 재생 시각을 읽어 열매를 되돌리지 않고, 보이는 곳에 다시 와야 원래 군락의 현재 모습을 갱신한다. 잠듦·의식 상실·실명·죽음으로 시야를 잃어도 기억이 몰래 최신 상태가 되지 않는다. 조회는 시간·산물·관찰·난수·UID를 변경하지 않는다. 구형 각인에 식물 상태 기록이 없으면 열매/큰 잎이 없는 중립 기부를 사용하며, 과거에 식물이 소진됐다고 새로 기록하지 않는다.

변형은 원래 타일의 `v`에서 선택해 성숙→소진→재성장/재방문에서 같은 번호를 유지한다. 원본을 각 상태에 별도 배율로 맞추지 않는다. 모드가 해당 Terrain의 visual을 바꾸면 기본 군락 표시가 그것을 덮어쓰지 않는다. 같은 source 크롭/기부/배율이 실제 화면에 사용됐는지를 읽기 전용 `render_game_presentation().forage`로 대조하며, 이 정보는 그려지는 알려진 칸/관찰만 포함한다.

검사 중 발견한 옛 감자/순무 테스트는 이미 환경 성장으로 바뀐 작물에 폐지된 `gatherAt`을 읽어 `NaN` 시각을 만들고 있었다. 동결된 v333에서도 같은 실패를 재현한 뒤, 실제 종자 UID/성장 상태/성장 전 거절과 시계 점프로 성숙하지 않는 현재 규칙을 확인하도록 바로잡았다. 실제 환경 성장/수확은 기존 cultivation 검사와 함께 실행했다. 새 기능을 통과시키려고 작물 성장을 날짜 보상으로 바꾸지 않았다.

실제 공개 입력은 선언한 밝은16영역 배치와 실제 생성된 검은 숲의 원래 지형/조명에서 확인한다. 원래 군락의 재생 경계와 플레이어 시작 위치는 유한 초기 조건이며 자연 발생 플레이를 했다고 주장하지 않는다. 기록의 실행 범위와 원문 해시는 [v336 검사 기록](release-v336-proof.json)에 남긴다. 큰 화면에서 전체 식물 원본을 보고 작은 화면에서는 숲 바닥/주변 나무/실제 채집 후 모습을 확인한다. 어두운 잎과 작은 소진 기부의 높은 확대율·다른 조명·색각 가독성, 장기 생태/식량 수지, 동물의 추가 행동과 나머지 종/착용 외형은 계속 남는다. 전체 회귀/World1,000판과 v1.0 출시 승인은 이 묶음에 포함하지 않는다.
