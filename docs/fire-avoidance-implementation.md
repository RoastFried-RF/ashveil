# 보이는 실제 화재를 피하는 NPC

v0.158은 살아 있는 실제 지형/침구 화재를 본 NPC가 원래 다음 차례에 피해 범위를 벗어나도록 연결한다. 불이 붙기 전 유한 모닥불은 그대로 사용하며, 일반 배경 불빛이나 오래된 화재 조명ID는 위험으로 만들지 않는다. 지형은 콘텐츠의 실제 피해 반경, 침구는 실제 피해를 주는 같은 칸을 피한다. 벽 너머의 불을 전역 지식으로 읽지 않는다.

깨어 볼 수 있는 NPC는 진행 중 채널을 기존 중단 경로로 멈추고 정상 이동 시간을 쓴다. 이동은 실제 바닥/문/점유·모서리·물과 몸/기계의 기존 행동 제약을 따른다. 묶인 발이나 전원 부족을 해제하지 않는다. 막힌 곳에서는 순간이동하지 않는다. 순찰·추적·생활의 공통 길찾기는 새로 본 불과 겹치는 오래된 경로를 다시 계획하고, 피해 범위의 목표에도 예외로 진입하지 않는다. 불이 꺼지면 그 칸을 영구적으로 금지하지 않는다.

저장 형식120과 콘텐츠 수치는 그대로다. 위험/대피 조회는 시간·난수·기억·물건을 만들지 않는다. 이전5개 고정 재생의 초기/최종 전체 상태·오류·해시는v157과 같고 기대값을 바꾸지 않았다. 전용21개/골든 포함2파일31개 검사, 타입·린트·빌드를 확인했다. 사람·동물·기계, 실제 침구, 전원 부족, 작업 중단, 순찰 캐시 경로 재계획과 전체 복원을 검사한다.

브라우저783–786의4개 세계 화면을 모두 확인했다. 실제 대기 키2회로 기본 확률0.02의 나무가 발화하고 같은 아군이 다음NPC차례에 한 칸 대피했다.3개 전체 저장 복원과 저장 후 실제20턴이 렌더러 연출 큐를 반영한 코어 전체 상태와 일치하고 콘솔 오류0이다. 기본 콘텐츠의 동일 초기 아군은 공개 점화100턴과139턴 대기 동안 머문다. 이 초기 아군은 고용 계약을 맺었다는 뜻이 아니다. 대피 뒤20턴 휴식의 계산 예산2는 같은 시각의NPC차례도 포함하므로 저장 시각이 아직 늘지 않을 수 있다. 전체 회귀/월드는v159 주변 소화와 통합 검증한다.

시각 없는 개체의 열 감지/자연 각성, NPC의 자율 소화/소방 역할, 원격 경보·정지 지역, 전체 건물/벽·지붕·들판, 방화 범죄, 나머지 후속 확장은 남아 있다. 고장 난 기계의 의도적인 행동 반복은 기존 오작동 규칙을 유지한다.


v0.158–159는 실제로 본 화재의NPC 대피/순찰 경로 재계획과 원래 자기 물병의 주변 소화를 연결했다. 사람·동물·기계의 기존 몸/포박/동력·정상 이동 시간을 유지하고, 조건이 되는 사람은 지형500ml/침구200ml를 실제로 쓴다. 관찰하지 않은 소화는 플레이어 로그로 공개하지 않는다. 각인120·전용38/관련6파일106·통합 전체163파일3,143개147.67초·타입/린트/Def224패치·화면783–790의8개 장면 전체 확인/6전체 복원/저장 후20·20턴 전체 일치/콘솔0이다. 월드30판327.26855848초의30행 전체가v157과 같다. v158별도 전체 회귀/월드는 실행한 것으로 기록하지 않는다.
