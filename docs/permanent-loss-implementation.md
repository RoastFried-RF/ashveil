# 실제 기아·회색열 회복 뒤의 영구 변화

v0.149는 정본05 §2.3의 두 원인을 실제 몸에 연결한다. 정본의 굶주림3에 해당하는 현재 기아 구간(균형−20,000 이하)을 연속7일 **초과**한 때 근력−1을30%로 판정하고, 회색열 면역이 실제100에 도달한 회복 시점에 활력−1을20%로 판정한다. 규칙은 Growth.Human PATCH에 있으며 다른 질병에 임의의 후유증을 붙이지 않는다. 정본의 뇌 손상 치유 후 지각/의지 감소 경로는 별도 후속으로 남아 있다.

기아 기간은 실제 대사 구간의 전후 상태를 관찰하여 기록한다. 아직 기록하지 않은 과거7일이나 관찰하지 않은 시간 점프를 채워 넣지 않는다. 같은 기아 사건에서는 성공/실패와 무관하게 한 번만 판정하고, 영양 회복은 진행 중 사건만 끝낸다. 이미 줄어든 근력은 음식을 먹어도 돌아오지 않는다. 회복된 옛 면역 기록에서는 지금 새 후유증을 만들지 않는다. 새로 실제 회복한 질병과 과거 회복 기록을 구분한다.

변화는 같은 인물의 기본 능력치와 개인 기록에 남으며, HP/기력 상한을 즉시 다시 적용한다. 최솟값은1이다. 인간형 NPC도 같은 규칙을 쓰되 개인 후유증을 플레이어의 능력이나 원격 로그로 바꾸지 않는다. 판정은 `body.permanent.ID`의 독립 난수를 사용한다. 각인112→113은 버전만 이관하고 과거의 관찰 기간·후유증을 추정하지 않는다.

기본 시드`permanent-loss-proof-0`의 실제 공개 행동에서는 기아7일 경계 직후 근력10→9, 회색열의 실제 회복에서 활력10→9/HP95가 나온다. 미완료20턴 휴식의 첫1턴을 저장한 사례는9턴 더 진행한 실제 회복 시점에 HP 상한 변화가 기존 위험 감지의 ‘다쳤다’를 일으켜 자연 중단된다. 나머지19턴을 강제로 마친 결과로 비교하지 않는다. 과거7일의 기록과 회복 직전 질병은 명시적인 유효 초기 장면이며, 그 과거를 실제 스케줄러로 실행했다는 주장이 아니다.

전용15/관련3파일55개·타입/린트·Def209패치/Schema124/오류0·빌드1.29초를 통과했다. 골든5개의 초기/최종 전체와 모든 오류는 버전 외v148과 같다. [골든 전체 비교](golden-v149-diff.json). 화면724~728 다섯 장 모두 확인·5전체113 복원/실제 회복9턴 뒤 중단 재개 전체 일치·콘솔0을 확인했다. 전체 회귀·월드는v148–149 통합으로 검증했다. v148 NPC 노화와 함께 통합 전체 검증을 수행하며 v148의 별도 전체 검사/별도 월드30판을 수행한 것으로 기록하지 않는다.


v0.148–149에서는 같은 인간 주민의 생성 나이/실제 생일/노화와 기아7일 초과·회색열 실제 회복 후의 영구 능력치 변화를 연결했다. 각인112→113·전용28·통합 전체152파일2,972개142.97초·Def209패치/Schema124·화면720~728 아홉 장 전체 확인·9전체 복원/실제19턴과 회복 시 자연 중단되는9턴 재개 전체 일치/콘솔0이다. 통합 월드30판310.654449348초의 전체 결과가v147과 같다. v148 별도 전체 검사나 별도 월드30판은 실행한 것으로 기록하지 않는다.
