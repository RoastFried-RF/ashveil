# 실제 봉쇄/해제의 공개 공고 전파

v0.165 작업은 새로 일어난 정착지의 봉쇄·해제 공고를v0.164의 실제 지연/왜곡 전파망에 넣는다. 현재 맵의 봉쇄 결정만으로는 공개하지 않으며 실제 출입 차단/해제 적용 때 게시한다. 현재 맵 밖의 정착지는 월드의 실제 새 정책 전환 시점에 공개 공고를 낸다. 원격 주민 개인의 감염이나 정확한 감염자 수를 소문에 넣지 않는다.

공고는 출입 정책·질병 이름·정착지 위치·당시 공고 시각을 담는다. 해제는 역병 발생 소식으로 분류하지 않는다. 같은 봉쇄 중 감염자가 늘었다고 반복 공고를 만들지 않는다. 같은 날 해제 후 다시 봉쇄되면 다른 사건 식별자를 사용한다. 원래 공고 뒤 실제 상태가 바뀌어도 옛 소식을 현재 사실로 고치지 않는다.

`WorldSimulation.Hearth`의 별도 PATCH로 `rumors.publicOutbreaks`를 설정한다. 새 봉쇄 변화에만 `publicAnnounced` 표시를 두며 각인122→123에서 옛 변화의 표시나 공고를 만들지 않는다. 실제 출입 적용이 지연되면 실제 공고 시각부터 전파를 예약하고 원래 결정의 사건 식별자를 유지한다. 이미 다른 정착지에 공개한 공고를 나중에 현장 적용하면서 다시 퍼뜨리지 않는다.

이 경로는 공개 공고 생성 지점에서만 호출한다. 조회·NPC 개인 병력·과거 `changes` 전체 검색으로 새 공고를 만들지 않는다. 도착 전 플레이어 지식은 그대로이며 실제 주민 대화로만 듣는다. 게시/전파에 실제 종이나 잉크가 필요하다고 주장하지 않으며 원본 지도/직접 관찰로 사용하지 않는다.
