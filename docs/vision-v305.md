## 적용 규칙

인간 공통 Def 패치로 기본12, 최대15, 지각5점 구간/5%, 어둠 감소6을 정의한다. 주인공·약탈자·주민 등 같은 인간 종은 같은 코어 함수를 사용한다. 다른 종과 기존 모드의 별도 야간 시야는 유지한다. 선택적 `Creature.vision`은 타입·배포 JSON Schema·실제 로더의 의미 검증을 모두 제공한다.

지각10에서12, 15에서12.6을 반올림한13, 20에서13.2를 반올림한13칸이다. **ASHVEIL의 유효 능력치 상한20은 유지**한다. 매의 눈의 거리+2 등 자체 특성도 적용하지만 총 상한15를 넘지 않는다. 상한 뒤 기존 안개·악천후·시각 기능 감소를 적용한다. 맑은 날의 옛 추가1.2배는 제거해 보통의 맑은 날에도 기본12칸이 된다.

어두운 대상에는 최종 거리에서6을 빼며 최소1칸이다. 기본 인간은 칠흑에서도 원형6칸을 관찰하고, 더 먼 조명된 대상은 전체12칸 안에서 볼 수 있다. 광원 사이의 보이지 않는 어둠이나 벽 뒤는 공개하지 않는다. 직접 `canSee`와 플레이어의 그림자 투사는 같은 원형 거리 경계를 사용한다. 눈 상실·수면·실신·차폐·잠행·근시는 계속 적용한다.

조명은 시야 외에도 읽기·작업·명중·보온과 연결되어 있다. 새 규칙이 횃불 반경4를6으로 늘리거나 조명 자체를 만드는 것은 아니다. 캐릭터 창은 `12칸 · 어둠 6칸`을 표시한다. 저장 필드 추가가 없으므로 각인204를 유지하며, 기존 각인은 기존 콘텐츠 변경 검토를 거쳐 새 Def로 재관찰한다. 기억한 과거 지형을 지우거나 새롭게 보이지 않는 현재 내용을 채우지 않는다.

## 검증 기록

어둠 경계는 기존 조도표의 어둠/어스름 경계0.5에 맞춰 인간 Def에 설정한다. 따라서 맑은 밤의0.25도 기본 인간의6칸 감소 대상이다. 야행성 특성의 기존0.12 임계값은 그대로 적용해 그 특성의 야간 관찰 이점을 유지한다. 이 임계값과 조도 단위는 ASHVEIL의 규칙이며 참고작에서 확인한 수치라고 주장하지 않는다.

지도 설정에 기존 화면 맞춤, 전체 시야 맞춤, 정수1~4배를 추가했다. 전체 시야 맞춤은 기본 반경 이상을 HUD 위의 사용 가능한 화면에 넣고, 수동 배율도 HUD를 제외한 중앙에 인물을 둔다. 지도 경계에서는 기존 클램프를 유지한다. 자동 기본 배율은 기존과 같으며 각인과 독립인 화면 설정에 저장한다. 배율 선택/재실행/화면 크기 변경은 코어 시야·시간·난수를 바꾸지 않는다. 최소1배에서도 화면보다 넓은 범위는 전부 들어갈 수 없다.

단위 경계·실제 화면·전체 회귀·월드 결과는 완료된 것만 이곳과 릴리스 근거에 추가한다. Native는 미리 선언한 낮/어둠/안개/실명 각인을 실제 타이틀에서 불러오고, 키 이동·장착 횃불 켜기/끄기·저장 복원을 독립 Node 전체 상태와 대조한다. 장면의 초기 몸·지형·광원은 fixture이며 정상 플레이 중 얻었다고 주장하지 않는다.
