# 실제 모드의 ZIP 배포 명령 — v0.268 작업 중

설계11 §9의 `ashveil-defs pack`에 실제 로더/격리 실행기 검증과 ZIP 포장을 연결했다. `pnpm defs pack <modId> [출력.zip] [--json]`은 실제 필수 의존 폐쇄를 검사하고 대상 모드 파일만 ZIP으로 만든다. 기존 `pnpm mod:package <id> [출력.tar.gz|출력.zip]`도 확장자로 형식을 선택한다. 기본 tar.gz와 기존 명령은 유지한다. pack의 명시 출력은 .zip을 요구하고 기존 출력/남의 임시 파일은 덮거나 지우지 않는다.

ZIP store 형식·UTF8 경로/CRC32·1980-01-01 고정 DOS 시각/0644 권한/파일 순서로 같은 입력은 같은 바이트다. 현재 8MiB/512파일 정책과 브라우저의 안전한 상대 경로/허용 파일 정책을 공유한다. 검증할 대상 패키지를 실제 캡처한 UTF8 원문 버퍼에서 파싱하고 그 버퍼를 ZIP으로 포장한다. tar.gz는 실제 GNU tar의 파일 목록/일반 파일 종류와 추출 stdout을 검증한 원문 전체와 다시 비교한다. 마지막 원본 해시 대조도 유지한다. 파일 시스템에 아카이브를 추출하지 않는다. 검증 중 실제 소스가 바뀌면 출력 전에 차단한다.
