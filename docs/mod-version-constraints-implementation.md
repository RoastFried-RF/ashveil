# 실제 게임·의존 모드의 버전 범위

v0.252 작업 중, 각인180/API1.4.0 유지. 실제 게임 버전은 배포 package.json과 같은0.1.0이다. 매니페스트의 gameVersion과 dependencies의 문자열 또는 {id,version} 형식을 지원한다. 객체의 실제 선택 모드 버전이 요구 범위를 만족해야 한다. 기존 범위 없는 문자열 의존성과 명시하지 않은 구형 게임 범위는 소급 추정/강제 변환하지 않는다.

optionalDependencies는 같은 문자열/객체 형식이다. 설치되지 않았거나 비활성이면 자동으로 켜지 않는다. 활성 상태면 버전을 확인하고 소비자보다 먼저 적용한다. 기존 loadBefore/loadAfter와 함께 실제 순환도 검사한다. 잘못된 의존 객체나 범위는 대상이 없는 선택 의존성에서도 형식 오류로 보고한다. 외부 부모 Def의 실제 객체 의존 선언도 인정하며 선언하지 않은 부모 상속의 기존 거절을 유지한다.

범위 계산은 기존 훅 API의 같은 순수 계산을 일반화했다. 문법은 정식 세 자리 버전·비교식·^·~·*·공백 AND·|| OR이다. 사전 배포/부분 버전/하이픈 범위를 지원한다고 주장하지 않는다. 기존 훅 API25개 검사 결과는 유지한다. 독립적으로 설치된 npm semver와 지원 문법의64버전×67범위=4288개 판정을 대조해 불일치0을 확인했다.

필수 의존성을 자동 켜지 않는 게임 선택 정책은 유지한다. 배포 검증은 별도의 requiredModClosure로 실제 필수 의존성만 모아 검사하며 선택 의존성은 넣지 않는다. 순환 수집은 멈추고 로더가 실제 오류를 보고한다. 압축에는 지정한 모드의 원본 파일만 넣어 외부 의존 모드의 파일을 함께 배포하지 않는다. 실제 임시 모드의 외부 부모/자식과 객체 버전 범위를 검증하고 버전 불일치 때 출력 전에 거절하는 검사도 추가했다.

실제 sample-versioned 예제는 gameVersion >=0.1.0 <0.2.0, core ^0.1.0, 선택 sample-selector ^1.0.0이다. 선택 의존성이 없어도 동작하고, 함께 켜면 먼저 적용한 뒤 조용한 흐름의 휴식 간격을48시간으로 바꾼다. 새 실제 물품/Def를 만들지 않고 기존 사건에 패치만 적용한다. 기본 게임에서는 꺼져 있다.
