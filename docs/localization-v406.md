# v406 로컬 개발 — 음식·물·약·책·화기 상세

2026-10-30 KST. [v405 로컬 장비 상세](localization-v405.md)의 후속이다. 공개 기준은 v0.404-dev/저장219이며 이 문서의 번호는 로컬 구현 묶음이다. 전체 영어 표시나 v1/X1–X4 수락과 구분한다.

## 구현 경계

음식의 영양·신선도/해동·소금/열·실제 잔량과 빈 용기, 물의 공개된 출처/탁도 또는 숙달별 위험 구간·염분/동결/침전, 추정/확정 약의 안내, 실제 책의 문해/진행/해금, 등불·조리/설치·작물/침구, 화약·탄창의 실제 탄 순서/걸림/오염·시위/부식 행을 표시한다. 모든 생성 가능한 기본 물품256종의 기본/감정 상세에서 영어 원문 잔여 여부와 상태 불변을 검사한다. 이것은 다른 창/동적 로그·문헌/보고서의 번역 완성을 뜻하지 않는다.

기본 물품 설명166개를 추가해 검토한 설명은174개다. 설치 지형18개 이름과 약효6개 설명, 물 출처8개/위험 구간5개/처리 이력5개를 ID와 정확한 현재 원문으로 보호한다. 질병7개 이름은 기존 검토 사전과 동일한 내용을 반복한다. 외부/수정된 원문과 모르는 처리 이력은 원래 텍스트로 남긴다. 새 UI 사전은 기존 키를 덮어쓰지 않는다. 철 조각 같은 실제 재질/질량 표시도 원래 물품/재질을 따른다. 빈 부위 내구 지도는 무한대 범위를 표시하지 않도록 했다.

Core의 `observeWater`는 기존 관찰만 구조화한다. 생존 미숙련자는 탁도만, 숙련자는 기존 위험 구간만 받으며 DTO에 실제 병원체/재 수치를 넣지 않는다. 기존 한국어 `waterLines`도 이 관찰을 사용한다. 규칙·난수·시간/원본 저장은 바꾸지 않았다. 기존 한국어259사례의 표시와 전체 세계가 변경 전 바이트와 일치했다. 이 비교의 초기 기준은 변경 전에 별도 보존했다.

틀린 알약 추정은 숨은 정답으로 고치지 않는다. 실제 효력/변질 상태를 조회해 번역하지 않으며 원래 지각 조건의 누런 가장자리만 표시한다. 다른 물품의 감정이나 현재 언어가 지식/숙달을 지급하지 않는다.

## 실제 입력 검증

`tools/inspect-item-supplies-v406.ts`는 세 화면 크기에서 두 종류의 선언된 초기 탐구 각인을 사용한다. 마지막 음식1회분·물5모금·틀린 약효 추정/확정 약·거의 완독한 책과 유한 등불, 원래 두 탄이 장전된 오염/걸림 총기와 여분 한 발·젖은 석궁·침구 등을 준비한다. 이 물품/진행은 진단 fixture이며 자연 획득이나 자연 독서 시간으로 세지 않는다.

타이틀 불러오기 뒤에는 실제 포인터·메뉴/더블클릭·언어·저장/계속하기만 사용한다. 음식/물 섭취·책의 마지막 턴·총기 걸림 해소/장전은 독립 Node 세계의 같은 행동과 전체 상태를 비교한다. 원래 빈 그릇·물병·책·총기/탄 UID와 잔량/진행, 잘못된 약효 추정과 비공개 상태가 그대로 저장/복원되는지 확인한다. 브라우저 세계·난수·시각의 사후 쓰기를 사용하지 않는다.

```powershell
./tools/windows/ashveil.ps1 authoring --item-supplies-locale
./tools/windows/ashveil.ps1 release --locale --item-details-locale --item-supplies-locale
```

최초 도구 타입 실패와 재시도를 보존했다. 이후 음식 장면33쌍은 통과했으나 초기 총기 fixture의 다음 탄 기록 누락을 실제 저장 검증이 거절했다. 이를 고치고 fixture의 사전 저장 검증을 추가했다. 다음 재검에서 걸림 해소는 전체 상태가 맞았지만 도구가 삭제되는 플래그를 `false`로 잘못 예상했다. 실제 Core 계약에 맞게 수정한 뒤 장비만27쌍을 재검했다. 이 결과를 새 Full 성공으로 합산하지 않는다.

최종 새15단계는 모두 통과했다. Full415파일6,777검사(643.40초/작업자2), 대상11파일84검사, 타입/린트(오류0/기존 경고1), Def·스프라이트·독립 Schema178파일/오류0, 빌드·두 화면 공통 스모크를 확인했다. 환경/계획 셀프 검사10개도 통과했다. 검사한 소스/테스트/도구4,244파일은 시작 전과 종료 후 같은 SHA-256이었다.

최종 Native는 기존 언어12쌍/14PNG, 물품45쌍/33PNG, 장비 상세30쌍/30PNG, 새 보급품60쌍/60PNG다. 전체 상태147쌍·브라우저 오류0이며 공통 스모크8PNG는 별도다. 최종 대표13PNG를 직접 열어 타이틀·지도·390px 메뉴/상세와 음식/책·약의 지식 경계·침구/총기·복원 표시를 검토했다. 재장전 직후 PNG는 재배치된 침구 도움말이 보이는 소지품 화면이며, 총기의3발/원래 UID는 해당 실제/기대 전체 상태 JSON으로 확인했다. 모든137개 Native PNG를 개별 시각 검토했다고 쓰지 않는다. [정확한 실행/소스/검토 영수증](pc-harness-v406-proof.json).

현재 기본 물품 상세의 선언한 표시 범위는 로컬 수락했다. 다른 창/로그·문헌과 X1–X4의 실제 결손, World30/원정1,000판·기기/사람 출시 게이트는 계속 남는다. 다음 기능 작업에서는 문헌에만 있는 재떡을 실제 공급·섭취/기간·재폐 비용·회색열 노출과 연결하는 경계를 우선 대조한다.
