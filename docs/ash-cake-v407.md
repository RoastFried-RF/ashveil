## 실물과 시간

침묵원의 기존 상인에 재 꾸러미30개와 재떡1회분을 기존 `initialAdditions`의 고유 표지로 한 번만 추가한다. 실제 현금과 원래 재고를 거래하며 판매/소비 뒤 하루 생산이나 저장 복원으로 다시 생기지 않는다. 이 유한 도입 재고와 플레이어의 제작은 장기적인 재 채집/순례회 작업장 생산 전체를 대신하지 않는다. 옛 각인의 몸이나 배낭에 섭취 이력/저항/음식을 소급 지급하지 않는다.

정본의 한 달/위험−30%/재폐+10은 `Disease.GreyFever.foodTraining`의 기본값이다. 루틴 세부는 최소24시간 간격의30회분과 첫 회분부터 실제30일 경과를 함께 요구한다. 미완료 중48시간을 넘겨 끊으면 간격 진행만 다시 시작하고 이미 쌓인 폐 부담은 남는다. 완료한 저항은 같은 몸에 유지하며 새 회색열 노출 확률에0.7을 곱한다. 완전 면역·현재 감염 치료·과거 물린 상처 판정의 재추첨이 아니다.

같은 날의 추가 음식과 완료 뒤의 음식도 매 회분 비용을 낸다. 정수 마이크로 단위로30회분의 폐 부담이 정확히10이 되도록 나눠 기록한다. `body.foodTraining`은 몸별 시간·회분·원래 마지막 물품 UID·비용 나머지와 폐 부담을 보존한다. 들이마신 재와 음식/물의 섭취 재 수치는 바꾸지 않고, 별도 폐 부담을 기존 재폐 단계/호흡 상한에 합산한다.

## 개인 지식과 저장

실제 행동의 간격 기록은 볼 수 있다. 완료 기간·질병 위험과 회분당 비용의 설명은 자신의 온전한 병리 문헌과 성공한 굴쥐 해부를 함께 확인한 기존 `ash-fever/rat-specimen` 단계에서만 표시한다. 신체 창은 기존 신체 관찰과 같이 이미 생긴 자기 몸의 현재 폐 부담·호흡 상한을 보여주며 미래 저항이나 연구 근거를 지급하지 않는다. 책·다른 사람의 경험·생존 배경이나 언어 선택이 몸의 저항을 주지 않는다. 먹기 자체도 문헌·해부·실마리 지식을 지급하지 않는다. 음식/폐 상세는 한국어 원문과 선택형 영어를 지원하며 다른 신체/제작/사회 창 전체의 영어 완료는 별도다.

저장220은219를 헤더 이행하며 새 이력을 채우지 않는다. 현재·휴면·이동·포획된 실제 몸의 시간/회분/비용/UID 형식을 검사한다. 질병 ID 이행은 같은 기록을 옮기고 충돌을 임의 병합하지 않는다. 없어진 질병의 옛 노출과 폐 손상은 보존하며 없는 현재 Def가 저항을 적용하지 않는다.
