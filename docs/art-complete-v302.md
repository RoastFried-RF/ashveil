# v0.302 전체 리소스 조사와 원화 적용

2026-10-22. 물품206·지형85·생물33·능력28의 해석된 정의352개와 UI26종을 조사했다. 등록 목록뿐 아니라 실제 지형 렌더 분기, 캐릭터 별칭, 바닥 물품, 기본 행동, 지도 소품, CSS 소비 경로도 확인했다. 조사 원문은 `tools/art/complete-catalog-v302-before.json`, 반복 조사 도구는 `tools/art/survey-complete.ts`다.

기존 자체 원본은 검토 후 유지했다. 외부 시트를 사용하던 바닥·벽·소품, 공용 아이콘에 의존하던 물품과 능력, 별도 캐릭터가 없던 동물4종, 공용 적 외형을 사용하던 두목·궁수를 새 좌표로 직접 그렸다. 외부 PNG 추출·트레이싱·재색칠로 신규 원본을 만들지 않았다. 가구·우물·작업대·장치·작물은 각 용도에 맞는 원화를 실제 렌더 경로에서 선택한다.

`tools/art/install-complete-art.py`는 조사 당시 목록과 다섯 묶음의 fragment를 합친다. 이전813개 프레임의 이름과 폭·높이를 보존하고, 미사용 sheet를 제거하며, 실제 등록된 모든 sheet와 UI의 경로가 `/original/`인지 검사한다. 사용하지 않는 옛 외부 PNG 파일은 삭제하지 않았다. 과거 주소나 명시적인 모드 파일의 보존과 현재 기본 게임의 사용 경로를 구분한다.

돌잔해는 유골과 분리해 돌판·벽돌·자갈로, 물에 뜬 선체는 갑판과 분리해 노출된 뼈대로 그렸다. 일반 위층 돌계단과 탑의 하강 사다리도 별도 원화를 선택한다.

동물4종은 실제 캐릭터 사전과 로딩 목록에 들어간다. 두목·궁수는 저장된 종/외형 선택을 바꾸지 않고 표시용 별칭으로 연결한다. 일반 정적 생물 sprite도 로더에 전달하도록 누락을 보완했다. 진흙3종은 실제 mud 프레임, 갑판은 새 deck 프레임, 모닥불은 손잡이가 없는 별도 불꽃 애니메이션을 사용한다. 새 원화의 기본 색을 살리도록 바닥의 기존 절반 밝기 tint를 완화했다. 시야·조명·날씨·성장·물품 수량·전투 규칙은 바꾸지 않는다.

UI는 App이 등록하던 이미지 변수를 실제 CSS에서 소비한다. 막대 테두리의 중앙은 투명하게 두어 실제 수치와 색각 보정 색을 가리지 않는다. 모든26종이 동시에 게임 화면에 나타난다는 뜻은 아니며, 호환용 변형도 보존한다.

각인 형식은204를 유지한다. 기존301각인의 콘텐츠 해시는 그림 패치로 달라지므로 타이틀의 기존 콘텐츠 변경 검토를 거친다. 이 기존 공통 절차는 새 해시와 변경 이력을 기록하고 업적을 비활성화한다. 이번 묶음에서 그 정책을 바꾸지는 않았다. 검토 전 각인 원문을 보존하고, 승인 뒤 시간·난수·몸·UID·원래 물품은 그대로 이어지는지도 별도로 비교한다.

전체 연결 원본은 독립 HTML 도감으로 제공한다. 물품206·지형85·생물33·능력28·UI26, 총378항목을 검색하고 캐릭터의 방향·동작·외형을 선택할 수 있다. 이미지를 파일 내부에 포함하며 게임 세계나 숨은 정보를 담지 않는다. 도감은 원본 열람용이며 게임의 조명·성장·열림·전투 결과를 재현하지 않는다. 생성은 `pnpm exec tsx tools/art/export-catalog.ts artifacts/새이름.html`이다.

검증은 원본 재생성/CRC/프레임 경계/실제 참조 검사, 352개 정의의 표시 필드를 제외한 전체 비교, 코어와 기존 콘텐츠 바이트 비교, 전체 초기/최종 골든5개, 실제 타이틀 불러오기/입력/저장 복원, 전체 회귀와 독립 이미지 검토로 나눈다. 실제 화면 검증용9개 방은 명시된 유한한 초기 fixture다. 초기 완성 작물·선언한 물건·사전 접촉·정지한 NPC를 정상 플레이에서 획득·성장·발견·전투한 결과로 주장하지 않는다.

새 원본·도구는 [CC0-1.0](../tools/art/complete-LICENSE.txt)이다. 각 묶음은 PNG와 픽셀 SVG, 팔레트, SHA와 재현 원문을 보관한다. 기존 자체 원본의 제작 이력과 외부 리소스의 역사적 저작자 표기는 유지한다. 최종 수치와 실행 결과는 게시 시 통합 검증 근거에 기록한다.
