# 검증한 콘텐츠 모드의 로컬 배포 · v0.215 / 각인153 유지

모드 작성/검증/호환/배포의 실제 지원 경로를 모딩 가이드로 정리하고 `pnpm mod:package <id> [출력.tar.gz]`를 추가했다. 실제 manifest id로 폴더를 찾고 JSON 콘텐츠/의존 구성의 로더 검증을 통과한 뒤 GNU tar/Node gzip으로 배포 파일을 만든다. 원본 상대 경로와 SHA-256/배포 파일 SHA-256/선택 모드·패치 수/경고를 출력한다.

manifest/defs/patches JSON과 README/LICENSE만 묶으며8MiB/512파일로 제한한다. 검사 경로의 심볼릭 링크·지원하지 않는 실행 파일/자산·중복/없는id·잘못된 Def를 거절한다. 파일 순서/권한0644/소유자0/시각0을 고정해 같은 입력은 같은 바이트가 된다. 검사 전 원본 해시와 압축 후의 해시를 대조하고 변경 중인 원본은 출력 전에 거절한다. 원자적으로 만든 자신의 임시 파일만 정리하고 기존 출력/다른 기존 임시 파일을 덮거나 삭제하지 않는다. 서버/창작마당에 게시하는 도구는 아니다.

새 선택 예제 `sample-patrol-contract`는 기존 Def를3패치한다. 보수30/기한2일/같은 경로의 표시 이름만 바꾸고 원래 세 좌표/시장/인물/현물을 보존한다. 기본20/269패치는 그대로이고 선택 때만272패치다. 새 Item/코어Def는 없다. 모드 선택 정보와 수락 뒤 실제 확인/예치 보수를 각인153에 보존한다. 기존 각인의 수락 기록을 다시 쓰는 이관 기능으로 주장하지 않는다.

패키지 전용8개와 실제 선택 모드2개/기존 순찰33개를 포함한 관련3파일43개가 통과했다. 실제 순찰3지점을 걸어 확인하고 보고하면 원래 시장1000→970/개인지갑30/예치0으로 보존된다. 같은 원래 인물/물품과 선택 모드/전체 증거의 저장 복원을 검사했다. 기본Def20은 바뀌지 않았다. 타입/린트/빌드2.25초를 완료했고 마지막 도구 해시 검사 변경 뒤 최종 타입/린트도 완료했다. 최종 관련43개7.17초/기본 Def269패치·예제272패치/Schema137파일 오류0이다. 기본5개 전체 초기/최종/오류/해시는211/153과 정확히 같으며 기대 해시/기준 보관을 다시 바꾸지 않았다.
