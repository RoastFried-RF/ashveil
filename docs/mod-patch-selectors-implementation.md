# 배열 식별자 패치와 실패한 변경 보존

v0.192 구현. 정본design/11 §4의객체배열 선택자를 연결했다. `/rows/[id=원래값]/field`처럼 실제 항목의식별필드로 찾으며 앞에 다른 항목이 삽입되어도 같은 항목을 수정한다. 문자열/숫자/불리언값을 지원하고 미일치/중복은 오류다. 선택자add는`position: before/after`를 명시한다. replace/remove/merge도 실제 선택한항목에 적용한다.

숫자 인덱스는0이상의정수만 허용하고, 배열 길이를넘는add·음수/소수/앞0·안전정수밖·replace/remove/merge의`/-`는 거절한다. JSON Pointer의`~0`/`~1`과빈키를 구별하고 잘못된escape/프로토타입경로를 거절한다. 성공한 사본만 원본에 반영한다. 기존객체add/중간객체생성의호환 동작은 유지하며, 이것이 모든정본패치연산을 완성한 것은 아니다.

선택형`sample-selector`는quiet의restHours/설명 두 항목만key로 수정한다. 코어의다른성향·수입·몸/물품/좌표는 바꾸지 않는다. 실제휴식은60시간미만일때보류하고정확한경계에서풀리며,조회는상태/난수를 바꾸지 않는다. 새게임에서예제를켜고느린압력을선택한다. [가이드](modding-guide.md). 기본268/순찰272/선택자270패치이며 새Def/Item은없다.
