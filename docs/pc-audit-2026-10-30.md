## 이 PC에 구성한 실행 경로

Windows11 Pro(10.0.26300), i7-13700KF(16코어/24스레드), 기존 Node24.19.0/Python3.12.3/Chrome156.0.8078.79를 확인했다. 전역 Node20/pnpm11은 바꾸지 않고 로컬 pnpm9.15.9, Python venv/jsonschema4.26.0와 기존 잠금파일 설치를 사용한다. [실행 명령과 경계](windows-development.md).

두 번째 전체 실행은414파일6,771검사 중6,755통과/16실패(649.62초)였으며 실패는6파일의 배포 도구/fixture에 모였다. GNU/BSD tar 차이, 배포 메타데이터의 역슬래시, Python 실행 이름과 POSIX 전용 링크/파일명 fixture를 수정했다. 후속 대상 검사56개 중55통과 뒤 남은 원문 줄바꿈 차이를 바로잡았고, 추가54개와 기존 고정 tar.gz 해시를 통과했다. 이 합계를 전체 통합 통과로 쓰지 않으며 새 전체 결과는 별도로 기록한다.

공통 Python 큐에 Windows 파일 잠금/Job Object 정리, GUI를 열지 않는 브라우저 버전 확인, 명시적 `.cjs` pnpm 실행을 추가했다. 실제 Windows 셀프 검사4개와 환경/계획 검사9개를 통과했다. POSIX 검사를 이 PC에서 실행했다고 쓰지 않는다.

최초 Full에서는 네이티브 경로의 역슬래시 때문에 예제 모드의 JS/PNG가 누락되는 결함을 발견했다. 부분 실패 로그를 남기고 해당 실행만 중단했으며, 로더 수정 후 관련162개 검사를 통과했다. 체크아웃 LF 규칙을 추가해 모드 원문/저장 해시를 보존한다. 앱 언어 변경은 [v405 로컬 기록](localization-v405.md)에 별도로 기술한다.

## 작업 수락과 다음 단계

최종 수정본의14단계가 모두 통과했다. Full414파일6,771검사(642.18초), 타입/린트·Def/스프라이트/Schema178파일·빌드, 두 화면 공통 스모크와 세 Native의 전체 상태87쌍/오류0을 확인했다. 새 상세는30쌍/30PNG이며 초기의 잘못된 모바일 도구 가정을 고친 뒤 실제 버리기·저장/복원을 포함했다. 대표 PNG를 직접 열어 검토했다. [소스/실행/검토 영수증](pc-harness-v405-proof.json)은 실패·재검과 이 최종 성공을 구분한다.

최종 검사 원문은 로컬 `test-results/windows/`에 새 디렉터리별로 보존한다. 실패/재검·Full·Native와 실제 이미지 검토 범위는 최종 영수증에서 구분한다. Core/콘텐츠·원화·저장219를 바꾸지 않는 이 작업을 World30/원정1,000판이나 v1 전체 출시 증거로 합산하지 않는다.

현재 기본 물품 상세 범위는 v406에서 로컬 수락했다. 재떡의 실물/섭취·기간/폐 비용·질병 노출은 v407의 선언한 범위로 수락했다. 다음은 자연 장기 공급과 나머지 창/로그 및 위 기능 결손을 정본·실제 자원/기억/저장 경계에 맞게 구현하는 순서다. 최종 코드·자동 검증을 먼저 닫은 후 실제 사람30분 플레이·사망 보고서·외부 테스터5명 중4명 재플레이 게이트를 별도 확인한다. 현재는 자동 구현이 남아 있어 사람 평가 대기 상태가 아니다.
