# 정착지 진료 — v0.40~0.42

02 §12.1~12.2의 시술자/환자 구분과09의 정착지 시설을 연결한다. 새 정착지의 기존4명 중 주민1명을 의사로 생성한다. 생성 때 쓰는 기존 장비·로컬ID·난수 호출 순서는 유지하고, 추가 사적 의료 물품만 세계 물품 UID 공간에 한 번 생성한다. 구형 정착지는 기존 주민·몸·물품을 보존하고 의사를1명 추가하므로 그 지역의 실체 인원은5명이 될 수 있다. 사망/물품 소모/재진입/각인 복원은 보충이나 부활을 일으키지 않는다.

의사는 지각13/의료50(4단계)/깔끔쟁이이며 의료가방2개(각5회), 술2병, 실6개, 바늘1개, 지혈대2개, 부목2개, 칼1개로 시작한다. 이 물품은 공공 저장고와 구분되는 주민의 초기 사적 재산이다. 시장/저장고에서 반복 생성하지 않는다. 초기 물품량과 의료가방5회는 임시 콘텐츠 값이며 `clinic.json`에서 바꾼다. 자동 재보급/제조/분쟁 후 복구는 아직 없다.

공통 처치는 `treatment.ts`, 다턴 배율은 `action-time.ts`, 진료 계약/견적은 `clinic.ts`다. 자가 처치는 같은 API의 기본 환자가 시술자 자신이다. 타인 처치는 시술자의 지각/숙달/손/통증/장갑/특성과 환자 위치의 조명·환경을 사용하고 자가계수1을 적용한다. 의료가방+15, 지각+6, 숙달+16, 깔끔쟁이의 기존 청결+5, 실내+5이면 Q87이다. 이 검산의 청결5는 깔끔쟁이 효과이며 별도의 손 씻기 지속 상태는 아직 없다. 손 부상은 시술자의 건강한 손을 택하고 자기 눈 제한은 타인 처치에 적용하지 않는다. 내부 장기는 진찰 없이 직접 봉합할 수 없다.

붕대/세척/지혈대/부목/봉합/결찰/힘줄 수복/이물질 제거/관절 맞추기/절단10종을 같은 효과로 처리한다. 의사가 가진 물품·바늘/칼의 UID와 실 더미별 개수를 예약하고, 매 작업 때 접근/시술자 의식·손/예약 물품을 다시 검사한다. 환자가 살아서 곁에 있으면 중간에 의식을 잃어도 시술은 계속된다. 의사가 치료한다고 환자의 출혈·감염·기아·추위가 멎거나 기력이 회복되지는 않는다. 시술 후 통증·절단·화살/파편/탈구·동맥·힘줄 결과는 환자에게 남고, 환자는 의사가 하는 일로 의료 숙달을 얻지 않는다. 현재 NPC 숙달은 기존 정책대로 진료로 증가하지 않는다.

견적은 읽기 전용이다. 물품/거리/적대/교전/정신·의식/바쁜 의사/평판/돈을 검사한 뒤 N에서 비용·대기 포함 예상 턴·Q·소모품/근거를 확인한다. 기본 요금8/4/8/12/24/40/60/16/14/80전은 각각 붕대/세척/지혈대/부목/봉합/결찰/힘줄/이물질/관절/절단의 **임시 값**이며 평판 가격 배율과 올림을 적용한다. 시작 전에 표시한 비용이 달라졌으면 지불하지 않는다. 진료비는 시작에 의사 소지금으로 옮기며 중단/위험 결과에도 환불하지 않음을 시작 전에 표시한다. 실제 소모품은 완료 때만 쓰되, 절반 진행한 부목의 기존 중단 효과는 소비와 함께 보존한다. 절단은 별도 위험 확인을 해야 시작할 수 있다.

의사와 환자는 서로 연결된 활동으로 스케줄러에서 각자 시간을 보낸다. 의사의 다음 차례와 마지막100TU를 정산하므로 주도권 차이로 진료를 즉시 완료하지 않는다. 기본5턴 붕대는500TU, 의사 차례가37TU 뒤면537TU에 입력을 받는다. 환자의 중단은 시술자의 활동도 끊고, 시술자가 물품/손/거리/의식을 잃거나 사망하면 환자 대기도 끝난다. 구형2~7의 몸·약물·물품·진행 중 자가 처치를 그대로 둔 채 형식8로 읽고, 중간 진료는 양쪽/UID/지불/남은시간을 이어서 같은 상태 해시를 낸다.

진찰은 아래v0.41에서 추가했다. 처방/투약 서비스·깨끗한 손의 지속 상태·의사 재보급·전용 진료소/침대·여관/교사·동료 치료 명령은 아직 남는다. 타인 처치 코어를 만든 것이 동료 확장 전체의 완성을 뜻하지 않는다. 기존 고정5입력은 진료를 쓰지 않으며 전체 초기/최종 상태가 형식7→8 외에 동일함을 확인했다(`golden-v040-diff.json`). 별도 진료27개/잘못된 모드1개를 추가해41파일625개를 기준으로 검증한다. 전용 브라우저64~67/설정은 실제 Q87/붕대5회분의1회 소비·지불/봉합/절단 확인/복원을 통과했다(콘솔0). 월드30판×3일은319.849479872초/평균0.45796412037037043일, 생존1/저체온18/치명상5/실혈6으로 v0.39의30개시드 원인/시간/레벨/지도와 같다. 봇은 지역 이동/진료를 하지 않는다. 불변v0.40의 전체 브라우저01~67/설정도 통과했다(콘솔0).


## v0.41 — 실제 진찰과 과거 소견

02 §8/§12.1의 진찰·복부 단단함과4단계 맥 짚기를 연결했다. 기본 진찰10턴/6전, 최소 숙달1/Q40, 최근10기록 보관은 임시 정책이며 Clinic.examination과 fees.diagnose에 있다. 복부 소견3단계와 맥4단계는 기획의 단계 기준이다. 시작 전 견적은 결과를 쓰거나 RNG를 소비하지 않는다. 기존 처치처럼 의사의 차례·손/의식/접근·중단/환자 대기·완료 시 재검사를 거치고, 검사 완료 때의 몸에서 임상 소견을 만든다. 진찰은 소모품을 소비하지 않으며 XP/AP/의료 숙달도 주지 않는다.

겉의 상처와 동맥/골절/이물질/힘줄/탈구·감염 의심을 적고,3단계는 활동 중인 복부 내출혈의 촉진 소견,4단계는 맥을 통해 혈액 손실을10%미만/10~15/15~30/30~40/40%이상 범위로 기록한다. 정확한 숨은 장기명/상처 심각도/실혈ml·감염/면역 경주 수치는 공개하지 않는다. 잠복 질병을 진찰만으로 확정하지 않는다. Q40미만은 충분히 판단하지 못했다는 기록을 남긴다. 이 진찰은 치료나 내부 수술이 아니며 움직임/휴식이 실제 몸에 미치는 효과는 기존 규칙이다.

환자마다 medicalReports에 검사 시점·시술자명/ID·단계/Q·소견을 저장한다. 과거 소견은 이후 몸 상태를 따라 갱신되지 않는다. NPC 환자의 기록은 NPC에게 남고 플레이어의 전역 지식/로그에 새지 않는다. J→진료는 날짜·시술자와 함께 지난 소견을 읽는다. 저장 형식9로 구형2~8의 몸/진행 중 자가/타인 처치/돈/물품을 보존하고, 진찰 중간 각인도 같은 결과로 잇는다.

진찰13개·잘못된 정책1개를 추가한41파일643개를 기준으로 검증한다. 기존5입력의 전체 초기/최종 상태는 형식8→9 외에 동일하며 명령·오류를 유지했다(golden-v041-diff.json). 단위41파일643개(20.39초), 형식/Def/타입/린트/빌드 검증을 통과했다. v0.40의 전체 브라우저01~67 위에 v0.41 전용64~69/설정으로 진찰/복원과 일지 화면을 확인했다(콘솔0). 날짜/탭 표시를 정리한 최종 화면68도 확인했다. 불변v0.41 월드30판×3일은253.101953181초/평균0.45796412037037043일, 생존1/저체온18/치명상5/실혈6으로 v0.40의30시드 원인/시간/레벨/지도와 같다. 봇은 지역 이동/진료를 하지 않는다. 처방·검사 도구/세부 감별·재보급·여관·교사·동료 UI는 여전히 남는다.

v0.41에서는 유효한 부목 작업5턴 뒤 의사가 손을 잃거나 환자가 멀어져도 마지막 작업Q의 반쪽 부목을 보존한다. 작업 전에 조건을 검사하므로4턴 뒤 발생한 무효 작업을 다섯번째로 세지 않는다. 예약한 부목 자체를 잃었을 때는 다른 부목을 대신 소비해 효과를 복제하지 않는다. 이 경계4개를 추가해643개를 검증한다.


## v0.42 — 실제 약품 투여와 외용 처방

의사가 실제 보유한 흰버들 차3/잠꽃 팅크2/쓴이끼 습포3/감정된 정화 앰플1을 처음 새 정착지에서 준비한다. 초기 수량과 규격 경구1턴, 최소 숙달1/2/1/3과 총 요금12/24/12/120전은 임시 정책으로 Clinic.prescriptions/doseTurns/supplies에 둔다. 앰플은 기존 유물 감정 상태2를 가진 의사 물품이다. 구형 지역의 이미 초기화된 의사는 새 약을 자동 지급받지 않는다. 의사의 상점 구매는v0.43에서 추가했다. 공공 저장고 직송/플레이어 준비물 전달은 남아 있다.

N에서 환자 내성에 따른 이번1회분 효과·지속·의식/호흡·의존/변비/이질 위험과 의사 물품/요금을 확인한다. 견적은 상태/RNG를 소비하지 않는다. 시술Q는 약품의 규격 용량을 늘리거나 줄이지 않는다. 실제 투여는 기존 administerDrug를 환자에게 호출하므로 수분200ml/열/통증/내성·의존/과용/변비·이질/재복용의 강한 기존 효과 보존과 지속 갱신이 자가 복용과 같다. 진찰처럼 XP/AP/환자 의료 숙달을 주지 않는다.

경구약은 환자가 깨어 받아야 하고, 외용약은 살아 있는 환자의 겉 상처를 골라3턴 작업한다. 환자가 중간에 의식을 잃어도 외용은 계속되며 경구 투약은 중단한다. 습포는 그 상처의 감염 진행만40% 줄이고 자극2를 남긴다. 앰플은72시간 전신 항생0.7과 기존 이질 위험0.1을 적용하며 상처를 즉시 낫게 하지 않는다. 선택 UID/Def/규격1회분을 바인딩해 잃거나 다른 약으로 바뀌면 여분 약을 대신 쓰지 않는다. 정상 완료 때만 의사 물품의1개 또는1회 사용량을 소모한다. 이미 지불한 진료비는 기존 계약대로 중단해도 환불하지 않는다.

의사가 미확인 색 정제를 진실에 접근해 골라 쓰거나 플레이어의 정제 지식을 자동 해금하지 않는다. 등록된 실제 약물 Item/Drug와 충분한 의사 숙달, 유물은 실제 감정2가 필요하다. NPC 환자도 자신의 몸/약효/기록만 바뀐다. 모드의 명시된 수면 처방은 투약의 마지막100TU와 새 피격에 깨는 조건을 보존한다. 이를 검증하면서 기존 기상 처리의 수면 플래그가 다음 신체틱까지 남던 문제를 수정했다. 위험/수동 중단은 즉시 눈을 뜨고 잠기운을 남긴다.

각인 형식10은 구형2~9의 몸/약효/내성/의료 기록/재고/진료 중 활동을 유지한다. 경구/외용의 중간 활동은 양쪽과 예약 UID/남은 시간/지불을 이어서 같은 상태 해시가 된다. 투약/기상18개·잘못된 처방1개를 더해41파일662개가17.39초에 통과했다. 기존5입력의 전체 초기/최종 상태는 형식9→10 외에 동일하다(golden-v042-diff.json). 이 입력들은 투약/수면 중단을 충분히 포함하지 않아 별도 실제 동작 검증을 병행한다. 전용 브라우저64~73/설정은 차의 수분/재고/비용, 팅크의 내성 미리보기/실제 투여, 습포/앰플의 국소·전신 약효와 전체 약물/돈/의사 재고/진료 기록의 복원을 통과했다(콘솔0). 화면70/72도 확인했다. 불변v0.42의 월드30판×3일은193.168802582초/평균0.45796412037037043일, 생존1/저체온18/치명상5/실혈6이며 v0.41의30시드 원인/시간/레벨/지도와 같다. 봇은 지역 이동/진료를 하지 않는다.
