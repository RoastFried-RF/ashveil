# 고정 침구의 실제 포장·운반·재설치 — v0.53

추운 주민은 피곤하고 자기 침대가 기억한 화덕에서 멀면, 자기 침대까지 실제로 가서 포장하고 배낭에 넣어 옮긴다. 화덕 가까이에 도착한 뒤 눈앞의 지붕 아래 빈 자리를 골라 같은 침구를 설치하고 실제 보온/수면을 이어 간다. 옷·몸의 체온·피로를 무료로 회복하거나 침대를 새로 보충하지 않는다.

고정 침구 포장은 기본200턴이며 기존 몸 상태 시간 배율을 쓴다. 실제 배낭 공간·거리/시선·막힌 모퉁이·손/의식·소유권과 점유를 확인하고 완료 때 다시 검증한다. 읽기 전용 견적과 중단은 아이템 UID/침구를 만들지 않는다. 물품 인스턴스가 없던 초기 고정 침대만 완료 때 실제 침대1개로 실체화하며 원래 타일의 침대는 제거한다. 이미 배치된 물품은 같은 UID·품질/내구·젖음·재질을 배낭으로 돌려준다. 포장 중의 실제 건조도 유지한다. 바닥의 다른 물건은 가져가거나 삭제하지 않는다.

운반은 실제 배낭의 물품으로 한다. 새 자리가 막히면 재계획/재시도하며, 설치는 기존 설치 행동으로 실제 물품1개를 소모해 배치한다. 바닥과 같은 물품 UID를 보관하고 개인 사용 권한도 새 위치를 따른다. 가구가 사라지거나 소지품을 잃어도 원래 자리에 침대를 다시 만들지 않는다. 배낭이 가득 차면 원래 침대와 UID를 바꾸지 않는다. 포장/운반 중의 몸·물품과 목표를 각인한다.

새로 배치하는 고정 침구에는 소유자를 기록하며 F2에서 자기 침구를 포장하고 I에서 다시 설치할 수 있다. 다른 사람의 고정 침구와 점유 중인 침구는 포장하지 못한다. 기존 휴대 침구의 빠른 접기는 유지한다. 물품과 소유 근거가 없는 초기 여관 침대는 포장 대상으로 삼지 않는다. 고정 침구의 포장과 일반 설치 모두 닿지 않는 대각 모퉁이를 통과하지 않는다. 설치에도 실제 손 기능이 필요하다. NPC의 포장/설치가 플레이어 로그를 대신 쓰지 않는다.

주민은 냉각36.5°C/피로 기준을 만족할 때 화덕2칸 안으로 침구를 옮기며, 접근3칸/실패 뒤1시간은 임시 Def 값이다. 운반을 시작한 물품은 몸이 잠시 따뜻해져도 설치까지 이어 간다. 현재 원격 타일의 물건/점유를 미리 읽어 자리를 고르지 않고, 실제로 화덕에 접근한 뒤 보이는 빈 자리만 고른다. 화덕·창고/우물·문/작업장·다른 침구·집무 자리·사람·바닥 물건을 덮어쓰지 않는다. 주민별 초기 침구와 기존 침대 위치를 로드 시 자동으로 옮기지 않는다.
