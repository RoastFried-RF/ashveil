# 기록 없는 각인의 실제 현재 구성 기록 시작

v0.255 통합 검증 완료, 각인182/API1.4.0. 구형 저장에 과거 구성 해시/버전이 없으면 자동으로 추정하지 않는 정책을 유지한다. 현재 플레이 중인 실제 구성을 설정에서 별도로 확인하고 명시적으로 기록을 시작할 수 있다. 이는 과거 구성을 복원했다고 주장하는 기능이 아니며 지금 실제 적용한 구성의 첫 기록이다.

검토는 현재 모드 ID/버전/해시와 실제 현재 턴을 보여 주고 전체 세계/각인/연대기를 바꾸지 않는다. 토큰은 현재 직렬화한 전체 상태와 실제 DB 해시에 묶는다. 취소, 다른 세계, 이미 기록된 각인, 진행 중 계산, 검토 뒤 실제 상태/콘텐츠 변경은 자동 기록하지 않는다. 입력 배열/보이는 목록을 바꿔도 실제 DB에서 다시 읽은 내용만 기록한다. 실제 패키지 원문 정보가 없는 수동 DB에는 기록을 지어내지 않는다.

승인 시 현재 실제 게임/계약/개별 모드/전체 해시·정의/크기·순서를 기록하고 contentAdoptedAt에 지금의 실제 턴과 해시를 남긴다. 이전 출처를 비교할 수 없으므로 업적 기록을 비활성화한다. 물품/몸/인물/시간/UID/난수는 바꾸지 않는다. 실제 연대기는 ‘이전 구성 기록 없음’에서 현재 구성으로 기록 시작을 표시한다. 존재하지 않는 과거 SHA를 contentChanges에 넣지 않는다. 이후 실제 모드 변경은 이 첫 현재 기록부터 정상 검토/실제 해시 이력으로 이어지고 첫 출처 없음 표시를 보존한다.

승인 후 한 번 저장하고 실패하면 기존 저장 상태 UI와 오류로 사실대로 보고한다. 승인한 현재 메타데이터는 메모리에 남아 재저장할 수 있고 물리 상태를 되돌리거나 새로 만들지 않는다. 설정을 닫거나 세계를 바꾸면 미승인 검토를 취소한다. 구성 상태 계산은 실제 version 갱신을 구독해 기록 직후 ‘기록 없음’ 표시가 남지 않도록 했다.

181→182 마이그레이션은 버전만 바꾼다. 새 게임이나 기존 구형 저장에 과거 기록 시작/업적 비활성을 자동으로 넣지 않는다. 원래 해시가 있는 각인은 이 흐름으로 기존 구성 변경 검토를 우회할 수 없다.

전용10개와 기존 헤더/시작/검토/모드 선택/저장 어댑터/소나무/골든의9파일100개가 통과했다. 검토/취소의 전체 상태 불변, 실제 승인 후 메타데이터 외 전체 상태 동일과 한 번 저장, 실제 한 턴 후 새 토큰/자동 기록 없음, 취소/각인 교체/기록 있음/대기 계산, 저장 실패의 실제 보고/시간·난수 보존, 전체 저장 복원과 구형 시작 기록 소급 금지, 검토 목록의 호출자 수정 격리를 확인한다.

골든5개 전체 초기·최종·오류를254와 대조해181→182 외 모든 필드/명령/오류/전체 해시가 같다. 기본 게임에 기록 시작/업적 상태를 만들지 않는다.254 벡터는 한 번 보관하고 기대 초기/최종 해시 두 필드만 바꿨다.
