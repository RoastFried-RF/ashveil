# v0.329 생애의 발견·학습 기록

지식 정본 [06 §1](design/06-knowledge.md)과 죽은 캐릭터 지식 재사용 경계는 ‘죽으면 캐릭터 지식은 사라지고 연대기에는 읽기 전용으로 남는다’고 정한다. 과거 확장 표의 ‘지식 계승’을 새 인물의 능력·지식·물품 지급으로 해석하지 않았다. 기존 은퇴자의 정보 전용 대화는 유지한다.

원정이 사망·탈출·은퇴로 끝나면 보고서에 당시 발견·학습 요약을 붙인다. 도감의 실제 관찰/전투/해부/문헌 단계와 그때 볼 수 있는 설명, 당시 감별의 확신/추정·배제/근거, 알고 있던 제작법·완독 기록, 직접 본 지도 칸과 기록된 세계 관찰/지도 기억, 현장 기록, 들은 소문/문서와 상호작용 발견을 보관한다. 소문과 해석은 당시 주장으로 남으며 현재 진실로 보정하지 않는다. 기본 제작법 전체를 새 발견으로 생성하지 않고 인물의 실제 학습 목록을 사용한다.

비밀 알약 대응표나 미관찰 지역의 현재 지형/변화를 조회하지 않는다. 도감S0은 실루엣/현재 단계만 남기고 숨은 혈액 표본 값을 노출하지 않는다. 세계 지리는 실제 저장된 관찰, 문서는 원래 작성자의 주장만 사용한다. 완독 사실은 해석이 정확했다는 보증이 아니다. 요약은 문자열 사본이므로 이후 세계/정의/몸이 달라져도 보고서를 다시 계산하지 않는다.

종료 화면과 타이틀의 전체 생애 기록에서 갈래/내용 검색·10개씩 페이지 이동을 제공한다. 기존 보고서 복사/파일 저장에도 같은 당시 요약을 넣는다. 보관 목록은 기술적으로 최대1,000개와 행별 요약이며 한도를 넘어 생략한 발견 수를 명시한다. 전체 원문/지도를 복원하는 기능과는 다르다.

타이틀 연대기는 최근12개만 보이던 제한을 없애고 실제로 보관된 최대50개 전체를8개씩 열람한다. 사망/은퇴/원정 종료/구성 변경 필터, 이름·시드·원인·발견 내용 검색과 이전 생애 이동을 추가했다. 원래 로컬 보관 개수/삭제 정책은 바꾸지 않았다.

저장212와 기존 보고서 구조의 선택 필드를 사용한다. 옛 보고서에 발견 목록이 없으면 그 사실을 표시하고 현재 DB로 과거를 추정하지 않는다. 새로운 캐릭터의 생성·시드 공유·지식/숙달/물품에는 이 기록을 입력하지 않는다. PNG와 콘텐츠/모드 정의도 바꾸지 않았다.

대상30개와 타입/린트·Def/Schema·빌드를 확인했다. 비밀 대응표를 읽으면 실패하는 검사, 미관찰 지도/도감 표본의 비공개, 실제 요약 사본·내보내기·한도와 새 지식 초기값을 확인했다. 실제 UI는 두 화면 크기에서 유한 초기 체력1/적·당시 지식·15개 과거 기록을 선언한 뒤 실제 대기→적의 공격/사망→요약/파일 저장→이전 생애/검색/갈래/페이지→옛 보고서→새 원정을 진행했다. 새 원정의 지식·제작법·완독·현장 기록·숙달을 독립 Node 초기 세계와 비교했다. 이전 자료의 자연 획득/이전 인간 플레이를 검증했다고 주장하지 않는다. [정확한 근거](release-v329-proof.json).

모든 지식/모드·지역 조합과 저장 용량/모든 기기, 전체 회귀·World/1,000판·출시 저장/사람 평가는 후속이다. 영어·남은 모드 훅 및 나머지 X1–X4를 이 한 기능으로 완료 처리하지 않는다.
