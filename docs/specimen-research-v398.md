# v398 직접 얻은 표본과 문헌의 실마리

실마리는 설비 기록과 문헌만 읽고 있어, 직접 성공한 해부를 개인 근거로 연결할 수 없었다. 새 선택 필드 `ResearchStep.dissections`는 정식 도감 항목 ID를 받고 현재 독자 본인의 성공 횟수를 확인한다. 문헌으로 도감 S4에 도달한 것, 사체 관찰·처치, 해부 실패, 다른 NPC의 성공은 대신하지 않는다. 우두머리와 보통 재늑대는 같은 도감 갈래로 연결한다. 부분·오독 문헌이나 부족한 근거에서는 연결 제목/본문을 숨기며 조회는 세계를 바꾸지 않는다.

실제 필사 문헌 두 종류와 실마리 네 단계를 추가했다. ‘정착균 병리 기록’은 정착균·재·약해진 폐와 매개 경로에 관한 기록이고, ‘가축 적응 프로그램 발췌’는 혹한·저조도 가축 형질과 정착지를 떠난 개 무리의 보존 사양이다. 새 물품 ID를 쓰므로 예전에 다른 책을 읽었다는 기억으로 새 내용이 해금되지 않는다. 각각 문해2/12쪽을 요구하며, 숲의 실제 교환 재고에서 원래 UID를 구입해 온전히 읽는다. 두 기존 자체 문헌 표지를 명시적으로 재사용하며 새 원화 두 장을 그렸다고 세지 않는다.

각 문헌을 읽으면 저자의 설명을 기록하고, 굴쥐/재늑대의 몸을 본인이 성공적으로 해부해야 두 번째 연결을 완성한다. 원정 관찰과 저자의 주장을 나란히 남긴다. 개인의 현재 질병 진단, 모든 동물의 보균 여부, 새 유전 실험을 자동으로 확정하지 않는다. UI는 ‘문헌’과 ‘해부’ 출처를 구분하고, 실제로 알려진 결말이 있을 때만 갈림길 바로가기를 표시한다.

## 기존 저장의 유한한 실물 재고

`TraderStockDef.initialAdditions`는 ID가 있는 추가 물품 묶음이며 `SettlementMarket.adoptedStockAdditions`에 적용 사실을 기록한다. 원래 시장이 모두 생성된 다음 추가분을 배치하므로 기존 물품 UID·돈·재입고 시각·흥정·인물/지도 상태를 보존한다. 구입하거나 저장을 복원해도 같은 추가분을 다시 지급하지 않는다. 이동 상점에는 적용하지 않는다. 일반 생산/소비·재입고 목록과 분리되어 문헌이 매일 재생산되지 않는다.

기존 불러오기의 콘텐츠 변경 검토를 거친 뒤, 세 그늘 정착지에 문헌 두 권씩 총6권을 한 번 보완한다. 별도 월드 상점 UID 영역에서6개를 배정하고 보통 물품/인물의 UID 흐름은 바꾸지 않는다. 새 선택 필드만 사용해 저장219를 유지한다. 새 게임과 구입 후/일 단위 재입고/전체 저장 복원·반복 초기화의 보존 검사를 포함한다.

모드에서 해부 조건은 `Creature.*`가 아닌 `BestiaryEntry.*`를 쓴다. 해부할 수 없는 항목, 잘못된 참조/중복/배열, 실제 근거 없는 단계는 거부한다. 추가 재고 ID는 같은 시장에서 한 번만 적용된다. 같은 ID의 수량을 고쳐도 재지급하지 않으며 의도한 추가 공급에는 새 ID를 쓴다. 물품 참조·정수 수량·중복·상한도 검사한다. 생성한 JSON Schema에 두 선택 필드를 반영했다.

## 조작 검사에서 발견한 자기 그림의 클릭 가림

실제 문헌 검사에서, 주인공의 큰 몸 그림이 북쪽 인접 칸까지 덮어 사체를 누른 클릭을 자기 위치로 바꾸는 것을 발견했다. 수정 전 같은 클릭은 한 턴 대기로 이어졌다. 자기 그림이 다른 칸의 포인터 판정을 가로채지 않도록 고쳤으며 자기 위치는 일반 칸 판정으로 계속 확인한다. 다른 보이는 인물의 픽셀 판정과 불투명 사물 가림은 유지한다.

이 문제의 독립 검사에는 주인공과 지정 사체만 남긴 유한 초기 장면을 사용해 다른 주민의 큰 그림이 자기 위치를 가리는 변수를 분리한다. 일반 문헌 흐름은 원래 생성된 상인/주민이 있는 별도 장면에서 실제 클릭으로 검증한다. 불러온 뒤 세계/시간/난수를 조작하지 않는다.

## 작은 화면의 실제 우클릭 메뉴

390px에서 구입한 책을 우클릭하면 메뉴가 열리지 않는 결함을 실제 입력으로 재현했다. `pointerdown` 뒤 생긴 마우스 초점이 키보드용 설명 위치를 갱신해, 뒤따르는 `contextmenu`가 책 대신 설명창에 도착했다. 마우스 도움말은 기존 포인터 경로를 사용하고, 키보드 초점일 때만 키보드용 위치를 갱신하도록 고쳤다. 설명창의 스크롤과 키보드 접근은 보존한다.

수정 전 실제 구입 각인으로 메뉴가 열리지 않는 것을 확인했고, 수정 후360·390·1366px에서 실제 우클릭과 Tab/Enter를 모두 통과했다. 이 메뉴/초점/타이틀 복원15개 전체 상태 비교는 시간·소지품·난수를 바꾸지 않는다. 같은 경계를 프로젝트 개발 스킬에도 기록했다.

## 지도 위 투명한 상단 영역

전체 흐름의390px 검사에서는 사체를 가리키는 동안 상단 수첩이 읽기 전용 정보창으로 바뀌고, 그 투명한 부모 영역이 다음 `pointerdown`을 받았다. 실제 포인터 이동은 canvas에 도착했지만 누르기는 `game-top-tools`에 도착했으며 게임 시간은 흐르지 않았다. 사체 선택이나 화면 좌표를 강제로 바꾸지 않고 이 입력 가림을 수정했다.

부모의 투명 영역은 입력을 통과시키고, 설정/도움말/타이틀·저장 오류 재시도·수첩의 실제 조작 영역만 입력을 받는다. 읽기 전용 정보창과 경고는 기존 통과 규칙을 유지한다. 별도 검사에서 실제 설정/도움말/수첩 열기·닫기, 포인터 아래 DOM 대상, 같은 사체 클릭·전체 세계·타이틀 복원을 함께 대조한다. 수정 전 실패는 성공 자료와 분리해 보존한다.

## 검증 범위

신규 관련26검사를 통과했다. 두 검사는 실제 마을 스케줄러로 구입·완독·해부를 끝내고, 나머지 근거 경계는 실제 학습/작업 완료 함수를 사용하는 국소 검사다. 최초 횃불 검사에서는 숲 주민의 불빛 반응으로 공격받아 독서가 정상 중단됐다. 독립 기능 검사는 밝은 초기 장면과 꺼진 횃불을 명시해 그 위험을 분리했다. 초기 실패·입력 가정·수정 전 화면은 로컬 자료로 보존한다.

기존5골든의 전체 초기/최종 세계와 모든 명령 오류를 v397과 비교했다. 새 두 물품의 종류/크기 설명, 콘텐츠 식별 정보, 세 시장의6권/적용 표시와 월드 상점 다음 UID+6 외에는 모두 같다. 모든 기존 물품·인물 UID를 보존했다. 대조 후 두 fixture의 기대 해시만 갱신하며 명령·초기 설정·기대 오류는 유지했다.

최종 실제 입력·새/옛 저장·두 화면·해부 실패,30시드 회귀와 게시 상태는 [검증 기록](release-v398-proof.json)에 확정한다. 전체 디버그 세계는 로컬 자료로만 보존하고 공개 문서에는 요약·SHA·선택 화면만 둔다. 유한 초기 조건 검사는 자연스러운 전체 여행·외부 사람 평가의 대체가 아니다.


최종 고정본 `v398-specimens-r4`에서 실제 입력90전체 상태 쌍을 통과했다. 상단 투명 영역15·물품 메뉴15·자기 몸 클릭8·문헌/해부/기존 저장52쌍이다. 동일30시드/최대3일은 v397과 모든 요약 행이 같고, 초기/최종60세계에서 새 콘텐츠 식별 정보·문헌6권·표시3개·상점 UID 할당+6만 차이 났다. 이후 새로 만들어진 상점 물품 UID의+6 차이는 경로별로 기록했고 원래 초기 물품/인물 UID는 바꾸지 않았다. 양쪽120저장의 전체 복원·원래 해시도 확인했다. 월드 사인은 치명상14·과다 출혈6·저체온3·3일 생존7, 평균0.963060185일이다.
