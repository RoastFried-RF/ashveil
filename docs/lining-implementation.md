# 실제 겉옷과 안감의 착탈·방어·보온 — v0.76

I의 의복 칸에 안감 한 칸을 추가했다. 코트·사슬옷 계열6종은 안감 칸을 지원하고, 누더기 셔츠·누빔 재킷은 안감으로 입을 수 있다. 지원 여부는 기존 Item Def에 대한 콘텐츠 패치다. 실제 겉옷이 있어야 새 안감을 넣을 수 있으며 다른 물품은 넣지 못한다. 배낭의 우클릭 ‘안감으로 입기’ 또는 해당 칸으로 끌기를 사용한다. 일반 셔츠 착용은 기존 몸 칸을 쓴다.

안감은 같은 UID의 실제 별도 물품이며 안쪽 층0으로 계산한다. 원래 Def를 바꾸지 않고 망토→겉옷→안감 순으로 부위별 방어·마모·품질·젖음/단열을 적용한다. 기존 비 침투·몸/침구 접촉·신체 기능을 공유한다. 제대로 입은 파손되지 않은 보온 안감은 금속의 직접 접촉 추위를 줄이며, 반착용/파손 안감은 그 보호를 주지 않는다.

짝을 입거나 벗는 작업 시간은 실제 두 의복의 합이다. 기본 사슬옷6/3턴과 재킷3/2턴의 짝은 착용9/탈의5턴이며 몸·조명에 따른 다턴 배율도 적용된다. 중단하면 두 의복이 반착용 상태와 남은 진행을 보존한다. 어느 쪽에서든 ‘마저 입기’로 남은 작업을 재개한다. 작업 중 실제 짝 UID가 달라지면 완료로 처리하지 않는다. 반착용 상태를 포함한 두 물품/진행은 전체 각인으로 보존한다.

짝 중 하나를 수동 탈의하면 두 물품을 같은 배낭에 돌려주며, 둘 다 들어갈 공간이 있는지 먼저 검사한다. 한 벌만 들어갈 공간에서는 일부 이동하지 않는다. 가득 찬 배낭에서는 같은 시간으로 두 물품을 바닥에 내려놓을 수 있다. 다른 지원 겉옷으로 갈아입으면 실제 안감을 보존하고, 안감 칸이 없는 셔츠로 바꾸면 기존 겉옷/안감을 모두 반환할 공간을 검사한다. 안감 교체도 이전 물품을 반환한다. 외부에서 겉옷만 잃은 경우에도 몸에 남은 실제 속옷을 삭제하지 않으며 따로 벗을 수 있다.

각인v40은39에서 버전만 바꾸는 순수 이관이다. 기존 사람에게 안감을 생성하지 않는다. 새 착용 위치와 짝 UID·합산 부분 진행을 저장한다. 전용20개·Def 검증1개를 추가했고 관련5파일130개와 전체78파일1,249개 검사54.07초에 통과했다. 타입·린트·빌드·Def/JSON Schema70파일 오류0이다. 기존5개 전체 초기/최종 골든은 버전39→40 외 동일하고 원래 명령/오류를 보존했다(`golden-v076-diff.json`). 고정 소스/빌드 브라우저220~226에서 메뉴의 실제9턴 안감 착용·5턴 두 벌 탈의·비지원 셔츠 교체/두 물품 반환과 중간 각인, 초기 실제 부분 착용 상태의 전체 각인/복원→남은6턴으로 두 벌 마저 입기→전체 각인 복원을 확인했다. 222/225화면 확인/콘솔 오류0이다. 초기 부분 장면의 시야를 공통 초기화로 준비한 테스트 보정이 있으며 소스/빌드는 최초 고정본과 동일하다. 30시드×최대3일191.33227399500004초 검증을 마쳤다. 평균0.419056712962963일, 저체온19·치명상5·과다 출혈6이며 몸/장비/지도/활동을 포함한30개 전체 최종 행이 v0.75와 동일하다. 나머지 생존·제작·NPC 관계와 X2~X4를 포함한 전체 후속 범위는 계속 구현한다.
