# 울림 듣는 자 — v0.311

정본은 [세계관 T9](lore/world-bible.md#t9-울림-듣는-자--p3-버티컬-슬라이스-특성)다. 기존 실제 음향 전파·몸의 청각과 기계 전원을 사용해 높은 정비음의 존재를 듣는다. 기본 반경15칸, 순례회 초기 평판+20, 가동 중인 탑 지역에서 기분−3을 Trait/Thought Def로 연결한다. 새 엔진이나 신체·저장 필드는 추가하지 않으며 저장205를 유지한다.

범위는 실제 현재 지도의 켜진 정원사 기계다. 잠·실신·죽음·청력 소실·다른 지도·전원 고갈·일시 정지는 감지를 막는다. 정상 귀의 열린 평지에서는15칸까지,16칸부터는 감지하지 않는다. 문·돌벽·주변 소음과 귀/머리 장비의 원래 음향 비용은 반경 안에서도 영향을 준다. 일반 시야와 도감은 넓히지 않는다. UI/관찰 DTO에는 두 존재 여부만 공개하며 개체 ID·수·위치·이름을 반환하지 않는다.

탑 두통의 ‘근처’는 실제 가동 탑이 있는 월드 셀로 정의했다(`towerRadius:0`). 다른 지역이나 정지된 탑에서는 해제된다. 정지 후 남는 대기 입자를 계속 가동되는 고음으로 취급하지 않는다. 이는 새 지형/탑을 만드는 기능이 아니며, 다른 반경을 원하는 모드는 Def로 바꿀 수 있다. 귀와 의식이 없으면 소리의 조건 사고도 적용하지 않는다.

초기 평판은 배경의 원래 시작값에 더해 사회의 첫 기록에 한 번 포함한다. 이미 저장된 평판은 특성 추가/제거·재조회로 덮어쓰지 않는다. 현재 감지와 두통은 기억·로그·시간·난수를 만들지 않는 조회다. 희귀 특성의 생성 가중치0.15를 두었으며 실제 타이틀과 같은 `scriptPreview` 생성의104번째 후보 `resonance-natural-103`에서 비관/울림 듣는 자를 얻었다. 임의 특성 주입이 없는 생성 결과를 원문으로 보존했다. 파문된 순례자 배경−30에+20이 더해 초기−10이다.

초기 전용26개 중24개가 통과했다. 두 실패는 존재하지 않는 테스트 벽 ID와 공개 barrel에 없는 테스트 함수 import였다. 실제 `Terrain.KtWall`과 원래 함수 모듈을 사용해 바로잡은 뒤 기존 상태/관찰을 포함한3파일83개가 통과했다. 이때 타입·변경 파일 린트도 통과했다. 실제 생성과 모드 수치 검사를 추가했고, Trait1개·Thought2개 증가에 맞춰 정의 스키마의 완성 개수887→890만 갱신했다. 골든 기대값은 아직 바꾸지 않았다.

현재 추가 검사·전체 회귀·월드30판·실제 두 화면 키/저장 복원/기계 감지·탑 작업과 최종 화면 검토는 미완료다. v0.310의1,000판 탐험은 별도 고정 원본에서 실행 중이며 이 새 콘텐츠/규칙의 최종1,000판 검증으로 집계하지 않는다. 이 문단은 초기 범위 기록이며, 지형 원화 r2의 이후 예비 연결·검토는 아래와 미술 문서를 따른다.

## 예비 통합 검토

추가28개 전용 검사와 관련 상태/관찰3파일83개, 특성·사회·평판을 포함한4파일77개, 골든·정의 스키마·첨탑4파일75개를 각각 확인했다. 집계들은 중복되므로 합쳐서 고유 검사 수로 쓰지 않는다. 스키마의 완성 정의890개와 시작 특성38/전체44개는 새 Trait1·Thought2개를 반영했다. 초기 타입 오류는 검사 모듈 import/미할당 변수 표시를 고쳤고 예비 최종 타입/린트를 통과했다.

새 추첨 후보가 생겨 `golden-surface`의 자연 생성 세 번째 특성이 튼튼한 체질→느림보으로 달라졌고80개 고정 입력이 예전 수도원 진입 대신18번 막혔다. 그 결과를 새 오류 기대값으로 채택하지 않았다. 도구에 명시적인 유한 초기 특성 목록을 추가해 이 장면만 원래 미식가/비관/튼튼한 체질으로 시작한다. 생성과 별개의 초기 장면임을 선언하며 게임의 생성 API·수치·입력 도중 상태는 바꾸지 않는다. 원래5개 기록 초기 세계를 현재 코어로 그대로 역직렬화해 재생했을 때는 전체 최종 세계·오류가310과 정확히 같았다. 현재 고정 장면의 초기/최종10개 전체 상태도 새3정의·로드/패키지 해시 외에310과 같다. 명령/오류를 유지하고 기대 해시 두 필드만 갱신했으며310 벡터를 보관했다. 첫 자연 생성 후보와 수정한 고정 장면은 별도 자료로 남긴다.

1366 예비에서 자연 타이틀의 실제 특성·설명,15→16→15칸 이동, 실제120턴 탑 정지, 원본 판/잔량20 보존, 옛205 각인의 검토 취소/승인과 복원을 실제 입력으로 확인했다.11개 전체 대조·4회 복원·15PNG·콘솔0이다. 첫 화면 검토에서 유한 초기 장면의 체력100/최대90과 빈 물품의 빠른 슬롯이 맞지 않음을 발견했다. 특성 교체 뒤 유한 초기 체력/슬롯/생성 기록을 맞춘 장면으로28개 전용 검사와 같은1366 실제 입력11대조/4복원/15PNG를 재검했다. 이는 검사용 초기 장면 정합성 수정이며 자연 생성의 이상으로 보고하지 않는다. 초기 예비15장 중6장을 열었고, 수정한 예비/최종 화면의 검토는 계속한다.
