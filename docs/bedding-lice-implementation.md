# 같은 침구의 실제 이 매개와 유한 물 세탁

v0.120. 기존 위생의 실제 이 발생/몸 씻기와 원래 침구를 연결했다. 젖음이나 침대 이름으로 질병을 만들지 않는다. 실제 이가 있는 사람형 몸이 누워 접촉해야 같은 침구에 원래 출처/접촉 시각/3일 절대 만료가 남는다. 고정 지형 침대에는 물품이나 기생충UID를 만들지 않는다.

그 침구에 실제로 누운 건강한 몸의 연속 관찰 접촉200턴마다 독립 body.bedding.lice 스트림으로 기본2%를 판정한다. 조회/199턴/같은 턴 재처리에는 판정하지 않는다. 실제 지도 좌표와 지도ID·원래 침구/물품UID·오염 시각을 결합하며, 일어남·침구 변경·관찰되지 않은 시간은 접촉으로 소급하지 않는다. 실제 수면/실신도 같은 접촉을 쓰고 기계형 몸은 사람의 이를 매개하지 않는다. 위생 선택 기능을 끄면 새 전파를 막으며, 기존 물품의 이 흔적을 임의로 지우지 않는다.

실제 포장/설치는 같은 물품의 원래 이 출처/만료를 보존한다. 만료 조회는 순수하며 실제 접촉 때 만료 기록을 지운다. 실제 타는 침구의 흔적은 사용자가 없어도 불에 사라지지만 평범한 모닥불의 온기는 세탁/소독으로 취급하지 않는다. 새 실제 이 발생은 기존 자동 활동을 가려움으로 중단하고 기존 수면 질×0.9/가려움 사고를 사용한다.

F2에 실제 이 흔적과 물2L/실제 몸 상태에 따른 세탁 시간을 표시한다. 원래 침구/지도/물품UID·실제 손/인접/시야·사용자/물량을 작업 내내 확인하고 마지막 실제 턴에만2L를 쓴다. 같은 침구를 젖음100%로 만들며 그을음은 수리하지 않는다. 침구 세탁은 몸의 이를 치료하지 않는다. 기존 몸 씻기는 별도로2L를 쓰며 같은 오염 침구에 다시 누우면 재감염될 수 있다. 실제 빈 물병은 같은UID로 남는다. 일지는 현재 몸의 이와 몸 씻기의 실제 턴 견적을 표시한다.

공개 스케줄러 검사에서 한 턴짜리 휴식의 마지막 실제 침구 접촉이 활동 종료 처리로 빠지던 문제를 발견했다. 실제로 일한 마지막 누운 턴만 다음 턴 경계까지 위치/지도에 묶어 기록하고 젖음과 이 접촉 양쪽에 반영한 뒤 지운다. 실제199턴과 다음1턴은 정확히200턴 접촉이며, 일반 대기는 누운 접촉으로 세지 않는다. 진행 중 각인은 아직 정산하지 않은 마지막 실제 접촉만 보존한다.

새 수치는 [13 등록](design/13-inventory.md)의 콘텐츠 제안값이다. 각인v84는 실제 이 흔적/접촉/같은 침구 세탁과 마지막 누운 턴을 보존하며 구형83에 과거 전염/물품/접촉을 지어내지 않는다. 지역 기상을 사용하지 않는 이 접촉은 기상 상태를 새로 생성하지 않고 실제 생성 지도/사람만 처리한다.

기본 콘텐츠 actual-bedding-lice-1377의 실제 자정/기존 위생3% 발생에서 원래 몸이 감염됐다. 실제 누움→원래 침구·실제 몸 씻기2L/300턴→실제 재접촉200턴의 기본2% 재감염·다시 몸 씻기2L/300턴과 같은 침구 세탁2L/300턴으로 실제6L를 쓰고 원래 빈 물병6개의UID를 모두 보존했다. 이는 강제로 넣은 효과나 중간 몸/물품 변경 없이 공개 행동으로 확인했다. 진행 중 실제 접촉의 전체 각인도 같은200턴의 감염 한 번과T4중단을 보존했다.
