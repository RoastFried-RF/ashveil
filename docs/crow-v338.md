# v338 재까마귀·낮은 비행·유한 사체 먹이

v1.0.0을 위한 개발 미리보기다. 확장 전체나 출시 승인이 아니다. 새 검은 숲에 재까마귀3개체를 배치하며 이미 방문한 지도와 옛 사체를 소급 채우지 않는다. 저장212의 선택 필드로 실제 비행·관찰 관심·부분 식물 재고·새 동물 사체 재고를 보존한다. 현재 구성 해시는 정상 각인 구성 검토를 따른다.

## 몸과 실제 행동

새 조류 몸은 두 다리의 이동과 두 날개의 비행을 분리한다. 부리는 섭식/쪼기를 담당하고 가짜 사람 손을 주지 않는다. 한 날개를 잃으면 비행 기능.5로 이륙하지 못한다. 실제 기력과 각100TU의 이륙/이동/착지, 최대24턴의 낮은 비행을 사용한다. 실내·지붕·벽·닫힌 문·닫힌 대각 모서리를 통과하지 않고 야외 나무/물 위를 이동한다. 비행 중에는 물속에 서 있는 것으로 익수/침수 처리하지 않으며 날개·의식 상실이나 물 위 체공 종료는 실제 그 자리의 추락/물 노출로 이어진다. 저장된 이륙 위치로 순간 이동하지 않는다.

같은 단일 점유 격자를 사용한다. 공중의 다른 새나 지상의 몸과 한 칸을 공유하는3차원 점유 모델은 아니다. 시야는 기존 거리/빛/실제 시선을 따른다. 날았다는 이유로 벽 너머를 알지 못한다. 실제 보이는 부상자·사체 위치만 관심 대상으로 기록하고40턴 뒤 잊는다. 다른 실신자를 노리는 까마귀를 무관한 인간 관찰자의 적으로 세지 않는다. 실제 공격 대상/직접 도발 기록은 적대 판정에 남긴다. 건강하고 깨어 있는 위협은 피하며, 막힌 조류가 사람 주먹으로 반격하지 않는다.

노출된 눈이 실제로 남은 의식 없는 생체만 눈을 노리는 쪼기의 대상이다. 입은 온전한 얼굴 가리개/눈 보호구는 이를 막는다. 반쯤 입은 물품·내구도0·제거된 물품은 보호로 세지 않는다. 명중/피해/부위는 기존 공통 판정을 사용한다. 눈 기능을 가진 부위에20배 가중치를 주며 눈 명중을 강제하지 않는다. 작은 공격자가 쓰러진 상대의 머리에 닿지 못하던 부위 가중 문제를 고쳤다. 근력2와 기본 피해1을 정수 계산하면 항상0이던 설정도 실제 공격 검사에서 찾아 기본 피해2로 고쳤다. 다른 무기의 피해 공식을 변경하지 않았다.

## 원래 음식과 사체 재고

까마귀는 실제 덤불에서 열매1개만 먹는다. 같은 군락의 나머지4개와 원래 재생 기한을 보존하고 사람의 채집도 남은 양만 준다. 재배 작물의 부분 재고는 원래 종자·성장과 관수 오염 한 몫을 보존한다. 조회/표현은 식물을 재생시키거나 수량을 배정하지 않는다.

바닥의 실제500g 생고기 한 회분을25g 조각20개로 찢는다. 원래 UID 또는 실제 새 분리 UID, 신선도·해동 이력·총 질량/영양·소금·재·오염수의 총 몫을 보존한다. 기존 인간 음식의 전체 한 회분을 작은 새가 한입에 먹지 않는다. 구운 조각도 실제40턴 조리 산물이다. 사체 식성은 식중독 위험을 줄이며 병원체/재를 소거하지 않는다. 물은 실제 인접 원천에서20ml를 마신다.

새 동물 사망 시 원래 도감 산물과 실제 사망 드롭을 한 유한 재고로 연결한다. 이미 바닥으로 떨어진 고기는 몸에 남겨 복제하지 않는다. 새가 뜯은 몫은 이후 해체 수확에서 빠진다. 사체 안의 고기도 실제 시간별 기온/젖음으로 상하고, 분리한다고 신선해지지 않는다. 이전 사체에는 과거 재고/부패를 추정하지 않으며 기존 경로를 유지한다. 사람 사체는 현재 도감에 고기 산물이 없으므로 임의의 인육 재고를 만들지 않는다. 사람 사체 추적과 실제 동물 사체 섭식을 구분한다.

까마귀 해체 산물은 깃털 묶음3개(각5g)와 작은 고기2조각이다. 실제 루팅한 깃털 묶음1개를 기존 화살5개 제작에서 소비한다. 그림의 깃털 개수를 보상 수량으로 해석하지 않는다.

## 원화와 표시

새로 활성화한 한 몸체는 정지/걷기/쪼기/피격/쓰러짐/수면/일어나기/먹이 작업/비행의9계열×4방향×4고유 영역=144몸 영역과 깃털 아이콘1영역이다.11PNG는 image_gen 원본 바이트 그대로다. 타 게임 픽셀·재샘플링·반전 복제로 프레임 수를 늘리지 않았다. 작은 고기 조각은 기존 생/구운 고기 자체 원화를 공유한다.

걷기1000ms, 먹이 작업1800ms, 날갯짓400ms는 표현 주기다. 비행의 가슴 중심 기부와 실제 공중 높이를 분리하고 그림자는 지면에 남긴다. 이륙/착지의 높이 연결과 짧은 포즈 전환은 렌더러 보간이며 별도의 새 이륙/착지 원화를 그렸다고 세지 않는다. 정상적인 중립 야생동물의 만피 막대는 숨기고 호버/피해/실제 공격 상황에서 표시한다. 표시된 공중 몸의 불투명 픽셀을 실제 마우스로 가리켜 비행 높이와 도달 여부를 확인할 수 있다.

비행 원본의 뒤쪽 두 crop은 간격이 좁다(유효 알파 간격2px/crop 간격0). Nearest 표본을 유지한다. 알파16이상 몸 잘림/이웃 혼입은0이며 약한 알파8–15 경계26샘플은 별도 기록한다. 실제 네 방향 렌더와 원본/확대 화면을 검토하며 필터링 atlas로 바꾸기 전 재검토해야 한다. 현재4위상은 연속 동작의 개발 수락이며 최종12프레임 밀도·기기/사람 평가 승인이 아니다.

원본 출처·정확한 생성 요청·선택 영역은 [통합 기록](../tools/art/direction-v338/README.md), 실행/실패 범위는 [검사 근거](release-v338-proof.json)에 남긴다.

## 남은 출시 범위

전서 개체·붉은 실/전서통, 번식/무리/휴면 먹이 수지, 다른 확장6종과 그 동작, 인간형의 실제 착용 의복·보철/절단 외형, 개별 이륙/착지 원화는 완료 처리하지 않는다. 전체 회귀·World·중단된1,000판은 사용자 우선순위에 따라 재개하지 않았다. v1 전체 범위는 [자율 추적](autonomous-implementation.md)에 유지한다.
