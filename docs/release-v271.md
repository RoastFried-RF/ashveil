# v0.271 검증 배포 기준

사용자의 중간 push·웹 미리보기 요청에 따라, 통합 검증을 마친 v0.271 제품 코드와 검증에 사용한 테스트를 저장했다. 이후 v0.272–275 작업은 별도 작업 디렉터리에서 계속 진행하며 이번 배포에 포함하지 않았다.

- 전체304파일5,532개 통과. 최초의 오래된 집계 기대값 실패2개와 실제 수정 범위는 자루 구현 문서에 기록했다.
- 월드30판×최대3일의 전체 결과 행·평균·사인이 v0.270과 같다.
- 실제 브라우저 자루 제작·격자 이동·중첩 거절·각인183 전체 복원2회, 콘솔 오류0.
- 제품 코드·콘텐츠·검증 코드는 불변 v271-regression-verified와 바이트가 같다. 문서는 완료된 검증 근거를 덧붙였다.
