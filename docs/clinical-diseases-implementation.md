# 실제 질병 노출·잠복·기능 손실과 유한 혈청

v0.98. 설계 02 §11의 쥐열·턱굳음병·폐렴을 같은 실제 몸·상처·의약품·진료에 연결한다. 새 발열은 목표 체온만 바꾸며 실제 체온은 기존 열수지로 서서히 변한다. 시간 경계에서 몸을 강제로 데우지 않는다. 전역 회색열·이질·늪열은 기존 규칙을 유지한다.

쥐열은 굴쥐의 실제 물림이 상처를 만든 때만25%로 전파한다. 단지 곁에 있다는 이유로 노출시키지 않는다. 원래 공격자와 물린 상처 UID, 노출 시각을 저장한다.1~3일 잠복한 뒤 진행20/일, 관절통+10과 발열을 적용한다. 잠복 중에는 질병의 통증을 주지 않는다.

턱굳음병은 흙이나 무기의 추가 오염이 묻은 깊은 찔림, 오염50이상인 실제 상처에 위험을 묶는다.6시간 판정 때도 상처가 남고 오염이 충분하며 소작하지 않았으면 한 번5%로 노출한다. 먼저 소독한 원래 상처는 이 판정을 피한다. 잠복3~10일, 진행15/일이며 자연 면역과 일반 항생제의 억제는 없다. 발병하면 조작×0.6, 실제 음식 사용 시간×3, 실제 기절과 뼈 골절을 동반할 수 있는 근경련을 적용한다. 음식이나 몸을 복제하지 않는다.

폐렴은 실제 체온34미만을 겪은 추위 구간마다 한 번 노출하거나, 실제 갈비뼈 골절 상태로3일 연속 누웠을 때 노출한다. 일반 수면만으로는 생기지 않으며 걷거나 골절이 회복되면 누운 시간은 끊긴다. 잠복1~2일, 진행20/일이며 현재 진행I에 따라 호흡×(1−I/200)을 적용한다. 같은 폐가 남고 질병이 나으면 질병으로 인한 기능 손실만 사라진다. 몸 계산 캐시에도 실제 발병/진행을 포함해 불러오기 전후의 결과가 같다.

새 노출·경련은 이름을 구분한 body.disease 난수를 써 기존 전투/신체 난수를 건드리지 않는다. 질병은 모든 유기체의 같은 규칙이며 기계 몸에는 생물학적 노출·통증을 적용하지 않는다. 기존 질병은 면역25/일·기존 항생제 반응을 기본으로 사용한다.

0호 금고의 원래 문서 상자에 유한한 개척 혈청 한 개를 추가했다. 이전 세 문서는 그대로다. 혈청은 원래 물건을 실제로 꺼내 사용해야 하며 턱굳음병만 치료한다. 원래 상처·폐렴 등 다른 질병을 지우지 않고 면역이나 새 혈청을 만들지 않는다. 의사는 용도를 확인한 같은 현물을 가진 경우에만 실제 예약·투약·요금 규칙으로 투여할 수 있다. 처방 인정은 자동 재보급을 뜻하지 않는다. 각인v61→62는 기존 몸·물품·과거를 바꾸지 않는 버전 변환이다. 이미 생성된 구형 상자에 혈청을 소급해 채우지 않는다.

신체 창은 실제 발병 질병과 현재 기능 손실을 표시한다. 진찰 여건이 충분한 의사는 같은 소견을 기록하며, 의약품 미리 보기는 치료 대상과 남는 상처/다른 질병을 보여 준다.
