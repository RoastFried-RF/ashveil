# X2 활성 밭의 실제 수분 증발

v0.233 / 각인170. 기존188종 물품/그늘 종자·그늘뿌리를 재사용한다. 새 Item/작물 Def를 추가하지 않는다. 환경 규칙 `WorldGen.Hearth.cropEvaporationMlPerHour`를 PATCH로 시간당1ml로 둔다. 안전한 정수0~1000만 허용하고 생략/0은 증발을 끈다. 작물 고유 서명을 바꾸지 않아 기존 정상 밭을 무효화하지 않는다.

증발은 활성 지상의 실제 현재 턴에만 계산한다. 지붕·비·0°C 이하·지하에서는0이고, 따뜻한 열린 땅에서는 성장이 멈추거나 수확 준비가 끝나도 남아 있는 물을 유한하게 쓴다. 성장 소비와 증발 소비를 따로 계산하고 음수가 되지 않는다. 현재 강수는 다 자란 밭에도 실제 한 턴의 물만 공급한다. 구형 밭/다른 지역/시계 점프로 과거 날씨·누락된 증발을 추정하지 않는다.

시간당1200턴과 기존 정수 관수 단위를 사용한다. 작은 성장 주기의 나눗셈 나머지는 선택적 `evaporationCarry`로 보존한다. 실제 물이 바닥나면 나머지도 지워 이후 물에 과거 손실을 청구하지 않는다. 조회/같은 시각 반복 정산은 전체 상태를 바꾸지 않는다. 구형169 각인은 버전170만 올리고 기존 물/성장/나머지를 채우거나 빼지 않는다.

F2와 실제 보이는 밭의 커서는 현재 최대 증발률을 보여 준다. 숨은 밭의 현재 수분은 공개하지 않는다. 물 주기는 같은 원래 물병의 실제ml를 한 번만 소비한다. 증발은 물병을 추가로 비우거나 UID/아이템을 만들지 않는다.
