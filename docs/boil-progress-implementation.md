# 원래 물과 열원의 물 끓이기 진행 보존

v0.116. 01 §7에 맞춰 일반 물 끓이기의 중단 진행을 보존한다. 천/숯 여과·정수정·침전은 기존 규칙을 사용한다.

원래 물병 UID/물량·전체 수질·처리 규칙·원래 연료/도구 UID와 열원, 총/남은 시간을 실제 작업에 묶는다. 직접 설치한 유한 불이 있으면 해당 원래 물품 UID를 우선 사용한다. 기존 지도의 자연 열원은 원래 지도/위치/종류/지형으로 묶으며 새 UID를 지어내지 않는다. 꺼진 불이나 다른 불로 바뀐 틱은 진행을 더하지 않는다. 같은 원래 불을 실제 목재로 다시 피운 뒤 이어 갈 수 있다.

80턴 뒤 멈추면 원래 물/수질/목재3개는 그대로이고120턴이 남는다. 같은 자원으로 남은120턴 마지막에만 원래 병원체0/재×1.1/소금 보존과 목재1개 소비를 적용한다. 실제 물200ml를 다른 병으로 옮겨800ml+200ml가 되면 이전 진행을 거절한다. 명시적 취소는 실제 자원/시각/난수를 보존하고 바뀐 물량으로 새200턴을 시작하게 한다. 다른 병이나 새로운 목재 더미 UID를 원래 기록에 대입하지 않는다.

제작 창은 실제 물병별 물량/조건·남은 시간/재개와 취소를 보여 준다. 조회는 몸/물품/난수/진행을 바꾸지 않는다. 기존 미완성 귀리죽 설명도 실제 모닥불 바로 곁 조건을 표시한다.

각인v80은 새로 시작한 원래 물/연료/열원의 진행을 보존한다. 구형79에 실제 남은120턴 물 활동이 있으면 기존 기록대로 계속하지만 기록하지 않았던 과거 열원이나 중단 작업을 만들어 내지 않는다. 완료 전에는 얼었던 물의 해동/정수를 소급하지 않는다.

전용20개·기존 물18개와 관련5파일80개·타입/린트/빌드를 확인했다. 일반 스케줄러 재현은 실제80턴 중단 뒤120턴만 추가하고 원래 목재1개만 사용해 병원체0/재0.22/염분3인 같은1L 물병을 얻었다. 진행 중 각인 재개도 전체 상태가 같고 실제 연료를 두 번 쓰지 않는다.
