# 프로젝트 리소스 검사 하네스

v0.292 전체 회귀 검증 중. 사용자 요청에 따라 이미 설치된 게임 하네스와 원본 제작 절차를 계속 확장한다. 게임/엔진/물리 규칙을 바꾸지 않는 Node 도구다. 실제 파일 검사는 `pnpm validate-sprites`, 기계용 JSON은 `pnpm --silent validate-sprites --json`이다. 활성 모드 ID를 추가 인자로 줄 수 있다. 실제 Def 로드를 사용하지만 QuickJS 스크립트와 게임 세계는 실행하지 않는다.

시트/UI PNG의 로컬 경로·헤더·청크 경계/CRC와 실제 크기, 모든 프레임 범위, 애니메이션/캐릭터4방향의 걷기·대기·공격 참조/앵커, 최종 상속·패치 뒤 Item.sprite/Ability.icon 파일을 검사한다. 같은 파일/아이콘은 한 번만 읽는다. public 밖 경로와 외부 URL·알 수 없는 PNG 꼬리 데이터는 거절한다. 오류면 종료 코드1이며 JSON에 실제 키·파일을 남긴다.

첫 실행은 기존 PNG8개의 중복 IEND를 오류로 분류했다. 조사 결과 각 파일 끝의 정확한 유효 종료12바이트 하나 중복이며 치즈 파일은 tools/art/food-sources.json의 고정 상류SHA와 완전히 같다. 해당 묶음의 모든원본SHA도 일치했다. 원본 파일을 바꾸지 않고 이 정확한 형식만 경고로 분리했다. 다른 꼬리 데이터·CRC 손상·잘림은 계속 오류다. 최초 원시 출력과 최종 JSON을 각각 보존했다.

기본 무기 통합 전 오프라인 검사는98시트/757프레임/7애니메이션/19캐릭터/26UI/75고유아이콘·163고유PNG에 오류0/호환경고8이다. 전용7개는 실제 현재 manifest, 프레임 재사용, 잘림/CRC, 중복종료와 임의꼬리 차이, 영역/참조 오류, 경로 이탈/누락, 캐릭터 방향/앵커를 검사한다. [초기 도구 단계 소스 동일성](sprite-assets-v292-source-proof.json): 무기 통합 전 src665/dist869/public470/mods81의 모든 바이트는291과 같다.

프로젝트 스킬·개발 하네스 문서·Pages 빌드 전에 연결했다. 원본 PNG/SVG 재현 도구, 픽셀 외형/알파, PNG 압축 해제 전체, 렌더러 하드코딩 키/폰트/오디오와 실제 게임 화면은 별도 검증이다. 기존 월드30판은291 근거다. 292 전체 회귀 결과는 완료 후 기록한다. 원격CI는계정결제/사용한도문제로아직실행성공을확인하지못했다.

후속으로 실제 Creature.char와 characterAliases 대상18개고유키를검사했다. 7개전용사례에없는생물표시 키의실패도포함했다. 첫린트의제어문자정규식오류는charCodeAt기반검사로고치고URL퍼센트인코딩·NUL경로거절사례를추가했다. 타입·린트오류0(기존미사용mirror경고1)·전용7개·실제CLI0오류/8경고를확인했다. 별도기본무기3원본통합은이초기도구기록과구분한다.


기본 무기3원본 통합 뒤 최종 CLI는101시트/760프레임/7애니메이션/19캐릭터/26UI/78고유아이콘/18생물키/166고유PNG, 오류0/기존호환경고8이다. 타입·빌드·린트오류0(기존mirror경고1)·Def326패치·스키마162·관련3파일21개 검사를 통과했다. 실제 무기5장·전체198복원2·전체상태6단계·실제300TU와 공통8장을 새로 검사했다. 최초 기대시간200TU는 기존 gearSwap의 해제1T+장착1T를 누락해 실패했고, Core변경 없이300TU로 수정해 통과했다. [실제 입력 근거](basic-weapon-art-v292-native-audit.json), [공통 하네스](game-harness-v292-audit.json), [최종 소스 동일성](basic-weapons-v292-final-source-proof.json).

코어289파일과 최종884Def는291과 같으며 오직 세 무기의 sprite필드만 바뀌었다. 5골든 전체 초기/최종/오류도 두 콘텐츠 해시 경로 외 동일하다. 따라서292의 월드30판을 중복 실행하지 않으며291 월드 결과를 최신 별도 측정으로 유지한다. 전체 후속 기능 완료를 뜻하지 않는다.
