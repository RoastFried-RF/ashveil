# 실제 수면 부채·당사자의 환청과 자동 휴식 중단

v0.103. 설계03 §6.1의 수면 부채24시간 이상 환각 사고와 출처 미상 소리의T3 거짓 경보를 실제 몸·사고·자동 행동·수면·각인에 연결한다.

살아 있고 깨어 있는 생물의 실제 부채가24시간 이상일 때 현재 환각 사고가 생긴다. 기계 몸·잠든 상태·실신·비유한 부채에는 새 생물학적 환청을 만들지 않는다. 충분한 실제 수면으로 부채가 문턱 아래로 내려가면 현재 사고와 당사자의 환청이 사라진다. 진정제나 휴식 버튼만으로 수면 부채를 지우지 않는다.

환청은 당사자의 원래 개체 안에 현재 지도/위치·시각/만료와 함께 보존한다. 실제 소음 목록에 넣거나 소음 발생 함수를 호출하지 않는다. 다른 사람의 듣기·기상·조사/기억에는 같은 소리를 전파하지 않고, 새 생물/물건 UID나 가짜 적·전리품·실제 위협 표식을 만들지 않는다. 당사자에게 들린 것 같은 방향만 기록한다. 실제 외부 소음은 기존 듣기 규칙대로 같은 잠든 경비를 깨울 수 있다.

자동 이동/휴식의 시작 스냅샷보다 새로 생긴 당사자의 지각은 실제T3 중단을 유발한다. 피해와 실제 새 적의T2/T1은 우선한다. 같은 환청을 들은 뒤 새로 시작한 행동을 과거 소리 하나로 계속 멈추지는 않는다. 원래3턴 재개 규칙은 보존한다. NPC도 자신의 환청을 지각하고, 실제 위협/생활/실제 소리 조사를 먼저 처리한 뒤 필요하면 실제 걸음으로 그 위치를 살펴본다. 그 실제 걸음의 발소리는 공개 소음일 수 있지만, 환청 자체를 다른 NPC가 듣는 것은 아니다.

판정은 실제 자격을 갖춘 개체의 독립된 body.hallucination 스트림에서만 한다. 같은 지도/같은 판정 턴의 재호출·각인 재개로 새 판정을 다시 뽑지 않는다. 문턱 전에는 새 스트림이나 과거 환청을 만들어 넣지 않는다. 원래 body/world/combat 난수 순서를 환청용으로 소비하지 않는다.

24시간 문턱은 설계 기준이다. 사고−6·200턴마다5%·거리3/유효6턴은 수정 가능한 Def 기본값이며 정본의 확정 수치로 취급하지 않는다. 상태 칩과 현재 사고는 실제 부채·기상 여부를 읽고, 소리의 기록은 당사자의 불확실한 지각을 설명한다.

각인v67은 원래 부채·당사자의 지각/만료·판정 시각·진행 중 자동 행동을 보존한다. 구형66은 버전만 올리고 과거 환청이나 판정을 소급 생성하지 않는다. 기존 다섯 재현의 전체 초기/최종 상태·오류는 버전66→67 외에는 같다.
