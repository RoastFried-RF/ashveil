# 해방된 사람의 동행과 기존 약속 보존 — v0.67

실제로 다른 포박자에게서 풀려난 인물에게도 자발적 동행을 제안할 수 있다. 포박을 다시 하거나 NPC를 새로 만들지 않는다. 구조 기록의 보호 기간 안에서 깨어 도움을 알아보고, 당일 실제350kcal·필요 식수200ml를 받은 뒤 양쪽 몸과 시간이 흐르는 대화를 끝내야 한다. `Recruitment.Rescue`는 기존 `Recruitment.Hearth`를 상속해 필요한 대화 날짜만1일로 정의한다. 기존 포로의3일 조건은 그대로다. 현재 조건은 후속 조정 가능한 Def 값이다.

진행에는 접근 방법별 프로필을 저장한다. 예전 포로 방식으로 받은 동의를 새 구조 방식의 동의로 가져오지 않는다. 대화 도중 위협·의식·거리·상처·보호 기간·밧줄/대상 상태가 바뀌면 양쪽 활동을 중단한다. 완료하지 않은 시간은 동의 날짜로 세지 않는다. 기존 날짜 경계 기준과 실제 수취 기록을 이어 쓴다.

짧은 초대에도 상대의 실제 대기 활동을 짝지어 귀환 AI가 협의 중 걸어 나가지 않게 했다. 자유로운 사람에게는 말하고 들을 수 있는 능력으로 시간을 계산하며, 존재하지 않는 밧줄을 풀거나 손을 요구하지 않는다. 포박된 사람의 초대는 기존 손/포박 해제 시간과 같은 밧줄 반환을 유지한다. 상대가 동의한 다음에도 직접 초대해야 영입된다. 첫 영입은 기존1일 시험 동행과 이후 실제 하루 급료6표를 사용한다. 같은 인물의 몸·배낭·소지금·원소속·관계와 구조 기억을 보존하고 돈/밧줄/경험치를 만들지 않는다.

이전에 같은 플레이어와 계약했던 인물은 시험 동행과 지급된 급료의 원래 기한, 최초 계약 시각을 보존한다. 헤어졌다 다시 영입해도 무료 기간이 늘어나지 않는다. 예전 기한이 끝났다면 무급 대기 상태로 재합류하며 실제 급료6표를 양쪽 지갑 사이에 건네야 하루가 늘어난다. 기존 관계 기억과 원래 귀환 장소도 보존한다.

각인v33은32의 실제 몸·구조/돌봄·동의·계약을 보존하는 순수 이관이다. 진행 중 자유 대화/초대의 양쪽 활동과 프로필을 보존한다. 구형32에는 프로필이 없으며 기존 포로 방식으로 해석한다. 구형의 짝 없는 포박 해제 초대도 실제 남은 작업을 이어 같은 밧줄을 돌려주고 영입한다.
