# v0.400 영어 표시 경계와 새 검증 환경

2026-10-28 KST. 원격 `main`의 `c195dfdae243c531d2a4830d3eb194162b33fd3f`에서 새 체크아웃을 만들었다. 이전 미게시 v400은 복구하지 않았다. 이 문서의 v400은 새 구현이며 v1.0.0/X1–X4 완료가 아니다.

## 구현 범위

`src/client/locale.ts`는 명시적으로 요청한 표시 문구만 번역한다. 타이틀/화면 설정의 한국어·영어 선택, 즉시 반영·다음 실행 복원, 문서 언어, 키 설정의 표시/접근성 이름과 기록 도구 모음을 연결했다. 기본은 한국어이며 구형 설정·잘못된 언어 값도 한국어로 읽는다. 영어는 미리보기이며 게임 내용/기록에는 한국어가 남는다는 안내를 표시한다.

현재 카탈로그는 338개 원문/영어 대응을 담는다. 타이틀의 배경12종·기본 특성의 문구·저장 방식·사건 흐름, 설정/키 설명 등이 포함된다. 개수는 완성률이 아니다. 문장 인수 `{0}`/`{1}`의 순서를 바꿀 수 있고, 값 안의 중괄호·HTML·달러 기호는 다시 해석하지 않는다. 등록되지 않은 문구는 원문을 표시한다. DOM 후처리나 전역 문자열 치환, 자동 번역 API, 새 번역 패키지를 사용하지 않는다.

개인 이름은 번역 함수에 넣지 않으며, 표시한 Def 필드의 원문과 저장된 로그·각인·콘텐츠 해시·코어 난수/세계는 바꾸지 않는다. 영어 읽기 시험은 영어 음성을 선택하고, 미번역 한국어 문구는 한국어 음성으로 읽는다. 언어 변경은 이전 읽기를 중단한다. 작은 타이틀은 언어 선택이 넘치지 않게 줄을 바꾸고 능력치는 영어 약어/전체 이름 툴팁을 사용한다.

`tools/localization/source-catalog.ts`의 원문 조사와 이 카탈로그는 별개다. 기존 후보8,518개 전체의 번역·검토가 끝난 것으로 세지 않는다. 전체 게임 창·판정/사건 로그·문헌/도감·보고서·동적 한국어 조사·모드 문구의 영어 표시는 계속 남는다. X1–X4 구현 및 사람 평가·1,000판 게이트도 유지한다.

## 환경

새 작업본은 Node24.22.1, 별도 pnpm9.15.9를 확인했다. 로컬 cgroup은 `cpu.max=800000 100000`, `memory.max=8589934592`이며 이전 환경의4CPU/32GiB를 그대로 인용하지 않는다. 로컬 공식 npm 레지스트리/Chromium CDN 접근은 정책에 막혔고, 오프라인 frozen 설치도 캐시 누락으로 실패했다. 권한 확대 실행도 정책에서 거절됐다. 로컬에서 타입·Full·빌드·브라우저를 실행했다고 기록하지 않는다.

`.github/workflows/cloud-development.yml`은 독립된 GitHub Actions 환경을 새로 만든다. Node24·pnpm9.15.9·frozen lockfile 설치 후 고정 Playwright CLI로 Chromium을 설치하고, 설치한 동일 실행 파일을 검사에 전달한다. 기존 Codex 환경의 조회·Publish에 의존하지 않는다. Codex 서비스의 새 환경 등록/게시까지 성공했다는 뜻은 아니다. 연결 브라우저는 사용할 수 없었고 클라우드 브라우저의 Codex 화면은 로그인 전이었다.

`environment.py`는 도구·실제HEAD·lock SHA·cgroup을 읽고, 누락되면 후속 검사를 차단한다. `plan.py`는 실제 체크아웃 경로의 명시적 계획을 만들며 기존 증거 파일을 덮지 않는다. light 최대2개, Full/빌드/Native heavy 단독은 기존 공통 하네스로 유지한다. World/원정은 이번 표시 변경의 재검 범위에 포함하지 않으며 최근 실측을 그대로 구분한다.
