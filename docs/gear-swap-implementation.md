# 실제 탈의 뒤 착용하는 장비 교체 — v0.77

같은 칸에 다른 장비를 입는 교체는 기존 장비의 탈의와 새 장비의 착용으로 나뉜다. 새 물품은 실제 배낭에 남고, 탈의 단계가 끝날 때에만 기존 장비를 몸에서 빼서 실제 발밑에 놓는다. 이어 실제 착용 시간을 써야 새 장비를 입는다. 기본 재킷2턴 탈의→코트3턴 착용의 교체는 실제5턴이다. 두 단계의 몸·조명 배율을 적용하고, 새 단계에서 시간을 다시 계산한다. 새 물품이나 기존 슬롯/짝 UID가 바뀌면 다른 물품으로 대신 완료하지 않는다.

벗는 중 취소하면 실제 입었던 기존 장비의 부분 탈의를 보존한다. 새 옷을 입기 전 취소해 반착용 방어를 얻지 못한다. 새 옷을 실제로 입다 취소하면 그 물품이 반착용 상태와 실제 남은 진행을 보존한다. 저체온 혼란도 지금 실제 입은 옷의 UID를 대상으로 하며 오래된 요청을 새 옷에 전이하지 않는다. 반복해서 중단·재개한 안감 착탈의 원래 합산 시간을 잃지 않도록 보정했다.

기존 장비를 다시 챙길 때에는 같은 지도/실제 위치에 남은 같은 UID가 곁에서 접근 가능한지와 배낭 전체 공간을 확인한다. 다른 사람이 가져간 물품을 다시 만들지 않고, 멀리 밀려났다면 원격으로 회수하지 않는다. 배낭이 차면 놓았던 곳에 남는다. 중간 사망에서도 실제 바닥/몸/배낭의 물품을 보존한다. 안감과 겉옷의 짝을 다루는 교체는 기존 짝의 합산 탈의 뒤 새 짝의 합산 착용을 쓴다. 유지하는 의복은 풀어 놓은 반착용 상태에서 새 짝과 함께 마저 입는다.

각인v41은40에서 버전만 바꾸는 순수 이관이다. 실제 교체 단계·기존 UID/바닥 위치·유지하는 짝·해당 단계의 남은 작업과 같은 몸/물품을 보존한다. 거점에서 실제 보이는 동료의 갈아입는 활동을 표시한다. 금속 접촉 추위 보호도 실제 몸통을 덮는 안감에만 적용한다.
