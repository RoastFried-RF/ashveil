# 실제 집의 나무문과 계속 타는 원본 재료

v0.156은 구별된 열린/닫힌 나무문 Def를 추가하고 검은 숲의 세 실제 주거지 가족 집 생성에 연결한다. 일반 돌문/봉인 금고 문은 가연 설정을 물려받지 않는다. 원래 집의 석벽 전체를 나무로 바꾸지 않으며 새 문 아이템/제작법을 만들지 않는다.

실제 유한 모닥불의 불씨에서 원래 생성된 나무문에 발화한다. 열고 닫는 공개1턴 행동은 같은 화재ID/출처/시각/남은 재료를 보존하고 실제 다음 턴만큼 연료가 줄어든다. 문을 열어 불을 지우거나600턴으로 연료를 채울 수 없다. 기존 막힌 문틀 조건을 따르며,600턴 소진하면 그 자리의 통로가 되어 걸어갈 수 있다. 온전한 새 문/목재/전리품을 만들지 않는다. 문 소진 시간은 Terrain의 조정 가능한 기본값이다.
