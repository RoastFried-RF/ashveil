# 소문 현장 조사 계약 — v0.56

기존 소문이 계약의 실제 조사 목표로 이어진다. 이미 읽어 지식에 기록한 방 위치 소문만 상인의 N 장부에 의뢰로 올라오며, 실제 현장을 살펴 일지에 기록하고 의뢰 정착지에서 보고하면 보수를 받는다. design/10 §9의 조사 템플릿과 보수 공식, design/06의 소문·기록된 지식과 실제 현장의 구별을 따른다.

## 실제 흐름

방 소문의 지도/방 번호·이름·구역과 원본 지도 크기가 있어야 의뢰한다. 지도 밖 구역이나 불완전한 정보, 이동 경로가 없는 곳은 게시하지 않는다. 의뢰는 이미 아는 위치를 복사하며 미방문 지도를 생성하거나 NPC 상태를 읽어 소문을 미리 정정하지 않는다. 조회는 원장·난수·물품 UID를 바꾸지 않는다.

수락은 실제 시장 돈을 예치한다. 조달 계약과 같은 정착지에서 동시에 다른 계약을 맡지 못한다. 같은 게시 기간에 취소한 의뢰를 재수락하지 못하고, 한 번 보고 완료한 소문은 다른 정착지에서도 반복 보상하지 않는다.

조사 기록은 해당 지역·층의 표시 구역 안에서만 남길 수 있다. 밝음/어스름과 조작·시야·의식이 필요하며, 구역 내부 칸을 실제로 보아 `Tile.seen`이 되어야 한다. 수면·다른 활동·인지된 교전 위협·기간 만료는 거부한다. 기록은1턴이며 보수를 즉시 지급하지 않는다. 실제 같은 구역의 방 이름/배치가 소문과 맞으면 확인, 다르면 불일치로 기록한다. 잘못된 방 번호가 가리키는 멀리 있는 방 이름은 공개하지 않는다.

조사 기록을 남긴 뒤 의뢰 정착지의 비적대 상인 곁에서1턴 보고한다. 확인/불일치 모두 실제 현장 조사 결과로 받아들이고, 예치 보수를 지갑에 한 번 지급하며 평판+2/연대기를 남긴다. 수락도1턴이며 취소·만료·플레이어 사망의 예치 반환, 시장 현금 재입고는 조달 계약과 같은 원장을 사용한다. 조사 기록·남은 예치·기한·완료를 각인v23에 보존하며 구형 조달 기록의 필드는 바꾸지 않는다.

## 데이터와 범위

`Investigation.Hearth`의 보수는 `(20 + 세계 맨해튼 거리×8 + 예상 위협×0.8)×부 배율1`이다. 예상 위협은 현재 지원하는 지하 층수×25의 잠정값이며 실제 미확인 적 수를 읽지 않는다. 기한은 현재 실제 월드 경로의 왕복 이동 시간+여유3일이다. 게시 기간3일·위협 추정/부 배율·평판은 데이터에서 조정한다. 보수를 감당할 현금이 있는 시장만 게시한다.

이 단계는 이미 있는 방 위치 소문의 조사 계약이다. 새로운 허위 소문 생성기·토벌/회수/구조/호송/발굴/순찰·공급원 정리·일반적인 계약 반전 전체는 아직 남는다. 사람의 전체 왕복 플레이 평가도 별도다.
