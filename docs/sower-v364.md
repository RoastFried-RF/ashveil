# v0.364 · 실제 파종기와 방향별 관절/작업

저장214의 개발 묶음이다. 새로 생성되는 굴뚝탑 정비 구역에 파종기1개체를 배치한다. 이미 방문한 지도·기존 인구·가방을 소급 보충하지 않는다. v356의 정책/정면 시제품 기록은 당시 범위로 유지한다. 현재 구현은 v1.0.0 출시 승인이 아니다.

## 실제 몸·행동·회수품

독립 Body.Sower의 네 구동 다리·감지/신호기·작업 헤드·냉각 회로와 전원을 사용한다. 원래 경로의 (47,14)→(51,14)→(51,20)→(47,20)를 순환하고 실제 완료한4회 이동마다 원래 종자 캡슐을1개 써서 공통 재배 규칙으로 심는다. 경유지 대기도 유급 행동이다. 새 인구에는 종자8개와 별도 균 캡슐1개만 있다.

성공/실패가 해결된 실제 공격을 감지하면 빗나감·장갑 흡수에도 경보를 한 번 수행한다. 보지 못한 공격자의 ID/현재 위치를 신호에 만들지 않는다. 신호기/전원이 기능해야 하며 구역의 실제 측량기를 원래 파종기 호출 위치로 부른다. 가까운 실제 공격자에게 원래 균 캡슐1개를 소비해 기존 유한 포자 구름을 만든다. 지도 밖에서 경로/분사 시계는 정지하지만 과거 관찰 시각을 바꾸지 않는다. 막힌 경로의 실제 몸을2칸 밀며 두 면이 막힌 대각선 모서리에서는 기존 이동과 같은 충돌 규칙을 쓴다.

사망 시 원래 남은 적재물과 몸의 부품 UID만 회수한다. 사용한 균 캡슐을 회수품에서 다시 만들지 않는다. 대형 구동기·빈4L 물탱크·중형 전원셀은 공통 부품 수리/물 옮겨 담기/전원 교환을 사용한다. 물탱크는 빈 상태로 얻고 실제 원래 물만 담는다. 장기 방치한 기계 시체가 생물 뼈를 새로 만들던 공통 정산도 수정했다. 저장213→214는 과거 공격을 추정하지 않는다.

## 실제 화면·자체 원본

기존 Pixi 엔진에서 게임과 공개 관절 도감이 같은 articulated-rig-view를 사용한다. 네 방향의 차체/upper/lower/foot를 같은 고정 링크·거리 보행/접지 모델로 조합하며 방향 전환은120ms 이전/새 방향의 교차 표시다. 각 방향은 별도의 추정2.5D 배치이며 연속 yaw/동일3D골격/실물 힙 관측을 증명한 것이 아니다. 지지 hull과 링크 도달 범위를 함께 제한한다. 고정17.5+17.5링크를 늘려 발에 맞추지 않는다.

원문16PNG에서115고유 영역을 등록했다: 기본 관절16+작업 차체14+전체 정지 참고16+피격/밀기/쓰러짐/기상64+회수품5. 관절8PNG/30영역이며 따로 그린 보행 프레임은0개다. 좌/우 작업 회복은 잘린 원문3 대신 준비0을 명시적으로 공유한다. FRONT는4영역/3기능상태, LEFT/RIGHT는 각각3영역/3기능상태, BACK은4영역/3기능상태다. 작업 차체는 움직이는 분사구 끝 대신 고정된 원문 기준점으로 붙인다. 원본 픽셀을 수정/리샘플링하지 않았다.

실제 파종/분사 행동에서만 작업 차체를 재생한다. 경보가 가짜 분사 동작을 만들지 않는다. 이동·피격·전투·사망과 작업 중단을 연결하고, 전체 몸 원화를 쓰는 상태와 관절 보행 사이를 교차 표시한다. 이미 죽은/누운 몸을 불러올 때 서 있는 관절이 먼저 보이지 않게 했다. 실제 사망 FX가 이동된 세계 시각 때문에 쓰러짐 첫 단계를 건너뛰지 않게 했다. 포인터는 실제 보이는 관절 원문 픽셀도 선택한다. 넓은 몸과 같은 지면 줄에 선 주인공은 같은 깊이의 몹보다 앞에 그려져 원문 아래에 완전히 가려지지 않는다. 전체 원화 도감의 파종기는 정지 참고로 표시하고 별도의 실제 관절/작업 도감으로 연결한다.

원본/영역/공유/보류 기록은 `tools/art/direction-v364/{installation,state-installation}.json`, 이전 원문·정확 요청/실패는 direction-v356/360/362 및 direction-v364/history에 보존한다. v363 0PNG 실패와 한 번의 수동 v365 재요청 성공을 구분한다. v366 왼쪽 마지막 쓰러짐은 방향이 달랐던 v352 후보를 대체하며 실제 화면에서 몸/탱크 크기를 확인한다. 배율.055의 접힌 정비형 자세이며 완전히 납작한 붕괴 원화는 아니다.

## 확인 범위와 남은 작업

대상 코어/공유 반응6파일69검사와 별도 리소스 등록2파일15검사를 통과했다. 전체 회귀/World/멈춘1,000판은 재개하지 않았다. 타입·변경 린트·Def624패치·Schema173파일·스프라이트371sheet/8099frame/34캐릭터/397고유PNG와 빌드의 최종 근거는 [검사 기록](release-v364-proof.json)에 둔다.

유한 초기 장면을 Title에서 불러온 뒤 실제 Period/Control+마우스로만 움직였다. 네 방향 순찰·파종은 기본1배, 전투 원문4단계는 일반 설정0.5배에서 관찰한다. 같은 실제 입력의 독립 Node 결과와 hash+전체 JSON을 비교한다. 자연 원정/모든 기기의 승인과 구분한다. 격리 관절 도감은 실제 DOM 방향/속도/정지/작업/중단/뷰 재생성과 읽기 전용 변환을 관찰한다. 최초3.08e-7px의 Pixi 거의 특이한 matrix 분해 오차를1e-7px 기준으로 실패한 원문도 유지하며 최종 수치 기준은1e-5px이다. 물리 링크 오차나 시각 품질 승인으로 바꾸어 적지 않는다.

건강한 네 다리 모델이다. 절단/손상·부러진 다리 보행, 실제 착용 의복/보철 레이어, 모든 가려진 원문 면, 나머지 기어가는 생물·군체·구제기, 새끼/장기 생태와 X1–X4/출시 게이트는 남는다. 등록 숫자나 시제품의 수치로 전체 완료율을 만들지 않는다.
