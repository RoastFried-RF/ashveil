ItemCompWorker.onApplied는 공통 치료 경로가 원래 물품을 실제로 차감한 뒤 제공자/실제 환자와 원래 UID·Def·개수/회분 감소·상처/부위/partial을 전달한다. 시작·실패·소실된 예약 재료·차감 없는 부분 진행·인물 사본에는 콜백이 없다. 실제 절반 부목이 재료를 쓴 경우 partial:true이며 완치로 기록하지 않는다. 봉합의 실은 실제 감소량을 기록하고 바늘의 내구 마모를 재료 소모로 세지 않는다. 자기/타인 치료와 마지막 회분을 구분한다. 별도 의수 설치 등 공통 치료 밖의 의료 경로는 아직 이 연결에 포함되지 않는다.

onMaterialConsumed는 실제 제작/수리/분해 작업의 개수·그램·물량 차감을 기록한다. 소비 지점에서 원래 물품의 차감량을 모으고 작업의 물리 결과 전체를 끝낸 뒤 콜백을 호출한다. 완성품이 기존 더미에 합쳐지거나 남은 질량 조각이 같은 원래 UID를 이어받아도 실제 사용량을 잃지 않는다. 준비 때 재료를 쓰는 수동 가공은 stage:preparation이며 나중 회수 때 다시 재료를 사용했다고 알리지 않는다. 실제 완성은 stage:completion이다. recipe/reason과 원래 재료 ID도 해당하는 경우 전달한다.
