# 원본 아트와 UI 개편 — v0.277

잿빛 변경과 낡은 기계 문명을 기준으로 청록·재색·상아색 천·낡은 황동을 맞췄다. 새 타이틀 풍경과 떠돌이 초상을 생성하고, 같은 후드·스카프·가방을 가진4방향28프레임의 맵 캐릭터를 직접 그렸다. 편집 원본·재생성 도구·생성 명세·파일 해시는 각 아트 문서에 보존한다.

타이틀은 원본 풍경/생성 설정·인물 미리보기2열로 배치했다. HUD는 초상·체력/기력·10개 빠른 슬롯·창 버튼을 정돈했다. 공통 창·메뉴·툴팁·상태·기록 패널은 얇은 재색/황동 프레임을 사용하며 옛 두꺼운 테두리 강제 유틸리티를 제거했다. 사건 기록의 상세도 버튼은 테두리 밖에서 패널 안의 헤더로 옮겼다. 키 설정·저장/불러오기·전투·인벤토리·기존 테스트 식별자는 유지한다.

첫 동결본277에서1440×1080과1366×768의 실제 타이틀→새 게임→대기→소지품6장과 오류0을 확인했다. 스크린샷 검토에서 타이틀 배경이 없는 문제를 발견했다. CSS 파일에서 소비한 상대 이미지 URL을 실제 이미지 요소와 BASE_URL 절대 해석으로 교체했다. 같은 검토에서 새 캐릭터의 후드 뒷모습을 옛 투구로 오인했으나 실제 저장의 sprite=hero/facing=0과 원본 등 프레임으로 확인했다. 불필요한 플레이어 강제 표시 수정은 하지 않았고 후속 촬영에 실제 제자리 방향 전환을 추가했다.

최초 깃 손상 브라우저 검사는 열린 루팅 상태에서 Space를 눌러 게임의 정상 모두 가져오기 동작을 실행했다. 배낭으로 이동한 실제 화살과 에너지/영양 차이를 전체 상태 비교가 검출했다. 원본 실패/3단계 전체 상태를 보존하고, 대기를 뜻하는 Period 입력으로 검사 경로를 수정했다. 제품의 단축키 동작을 바꾸지 않았다. 이 테스트 수정과 타이틀/남은 프레임 수정을 포함한 새 동결본277-final에서 재검증한다.

지도 타일·카메라·시야/어둠·날씨 규칙은 아트 변경으로 바꾸지 않는다. 원본 초상은 원본 바이트를 그대로 사용하고 렌더 비율/크롭만 UI에 둔다. 전체 배경/적/음식/장비 아트의 원본 교체와 모든 확장 기능의 완성을 뜻하지 않는다.

277-final에서 실제 타이틀 이미지 로드 성공과1440×1080·1366×768의 문서 가로 넘침 없음을 확인했다. 실제 타이틀→고정 시드 새 게임→대기/제자리 방향 전환→소지품6장, 오류0을 통과했고6장을 모두 시각 검토했다. 얼굴·후드·가방이 원본 캐릭터이며 타이틀에는 수도원과 등불 든 떠돌이가 정상 표시된다. 같은 동결본에서 실제 깃 손상/사격/저장6장도 모두 확인했다. 전체 회귀와 월드30판은 진행 중이며275 결과로 대신하지 않는다.

278 후속 작업 중: 일반 천/외투/화살 아이콘을 임시로 공유하던 자루·허리띠·화살통에 각각 새 원본 아이콘을 연결한다. 상아 깃 화살 묶음도 같은 팔레트로 바꾼다. 기존 공유 그림을 전부 덮지 않고 실제4개 Def의 sprite만 패치하며 별도 아틀라스 키를 사용한다. 이 내용은277의 동결 검증/중간 push에 포함되지 않는다.
