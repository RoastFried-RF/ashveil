# v0.324 동료 상호 구조·간병과 거점 작업 순서

X1에서 남아 있던 자동 응급 처치·실신자 구조와 거점의 여러 작업 지시를 연결했다. 기본 지침은 꺼짐이며 곁의 유급 동료에게 직접 맡긴다. 기존 몸·물품·UID·제작 진행·의료 엔진을 사용한다. 저장209를 추가하며208 각인에는 과거 구조 동의나 대기열을 추정하지 않는다.

## 상호 응급 처치와 집결지

주민·세력(Shift+N) → 동료 → 동행·급료 → 응급 처치 부탁에서 ‘응급 처치 맡기기’ 또는 ‘구조 맡기기·현재 위치를 집결지로’를1턴에 지시한다. 끄기와 집결지 갱신도 곁에서 직접 한다. 거점 작업·회수 지시와 별도로 저장한다. 조명·실제 관찰8칸·같은 현장·급료·시술자의 손/발/의식·허기/갈증/피로/체온과 위협을 확인한다. 다른 원본 회수/호송 임무를 수행하는 동안에는 구조를 시작하지 않는다.

자기 상처와 플레이어/같은 동행자의 외부 상처를 대상으로 한다. 동맥 지혈대 → 외부 출혈 붕대 → 오염된 상처 세척 → 골절 부목 순서로 실제 물품과 기존 `startTreatment`를 사용한다. 임의의 적대/포로/주민·기계·내부 상처를 치료 대상으로 만들지 않는다. 같은 상처를 매 턴 다시 감지 않으며, 세척은 오염20 이상·지난 처치1시간 이후에 다시 판단한다. 깨끗하고 남은 내구/사용량이 있는 배낭/접근 가능한 주머니의 도구를 고르고 시작 때 같은UID를 묶는다.

시작은 치료 완료가 아니다. 실제 시술자의 차례와 두 몸의 시간이 진행하며 완료 때만 원래 물품을 쓴다. 환자의 대기 중단·원래 물품 소실·새 위협·계약/급료/지침 변경은 외부 처치를 중단한다. 부목은 기존 절반 진행/실물 소비 규칙을 따른다. 실제 응급 상황을 관찰하면 진행 중인 거점 노동을 중단하고, 원래 제작 진행/재료는 남겨 돌아갈 수 있게 한다.

구조는 출혈이1ml/턴 이하로 가라앉은 실신자를 같은 지도/지역에 지정한 집결지 곁으로 옮긴다. 원래 환자를 한 칸씩 당기며 각 이동에 기본3턴과 기력2를 사용한다. 구조자/환자의 시작 위치, 경로, 빈 도착 칸, 모서리 차폐와 위험한 불·물, 급료·의식·기력을 매 작업 턴 재검사한다. 위치 이동은 완료 때만 일어난다. 환자가 깨어나거나 위치가 바뀌면 중단한다. 환자의 몸·장비·신원은 복제하지 않는다. 거점 작업 없는 현지 대기/방어 동료는 옮겨진 곳을 새 대기 지점으로 이어 받아, 깨어난 뒤 옛 위험 장소로 돌아가지 않는다. 독서·휴식/수면·제작·채집·수색 도중 실신한 환자는 기존 활동을 정상 중단해 구조하며, 미완료 제작의 물품과 진행은 보존한다. 다른 동료는 이미 처치/운반을 받는 환자에게 동시에 작업을 시작하지 않는다. 시술·구조 동안 손의 무기 표시는 내린다.

자동 수술·절단·마취/투약·강제 급식·시체/포로 운반·다른 지도까지의 들것 이동은 포함하지 않는다. 현재 구조 지침은 자기 실제 의료 물품을 쓰며 거점 물품의 자동 의료 보급은 다음 연결 대상으로 추적한다. 집결지는 지정된 위치이며 모든 지도를 분석한 절대 안전 판정이 아니다. 위험한 칸은 피하지만 새 전투가 발생하면 구조가 보장되지 않는다.

## 거점 작업 대기열

F2 → 현장·야영 → 거점의 동료별 ‘다음 작업 순서’에서 기존 제작법·수량·자원·모닥불 선택을 사용해 대기 지시를 넣는다. 대기 작업은8개까지다. 횟수 제작·완성품 최소 재고·운반·채집/작물 돌봄·식수·모닥불·거점 방어를 지원한다. 추가/순서 변경/삭제는 곁에서 같은 거점 명령 접근 검사와1턴을 쓴다. 잘못된 지시·가득 찬 대기열·없어진 작업ID는 시간·물품·다음ID를 바꾸지 않고 거부한다.

현재 시작한 배치를 마치고 원래 완성품을 납품한 뒤 다음 실제 작업을 고른다. 진행 중인 제작을 대기열 편집으로 교체하거나 재료를 복제하지 않는다. 재고 유지 작업은 만족되면 대기 목록으로 돌아가고, 재고가 줄었을 때 다시 실제 재료로 일한다. 아직 시작하지 못한 작업이 재료 부족 등으로 대기하면 다른 미충족 대기 작업을 살펴본다. 부분 제작이 남아 있을 때는 그 진행을 다른 작업으로 강제 교체하지 않는다. 다른 작업에 쓰지 않은 재료와 완성품은 계속 같은 작업자의 가방에 남는다.

동행/현지 대기 명령·계약 종료·작업 취소는 대기 지시도 해제한다. 대기열은 현지 동료의 기존 식사·급수·수면·방어·급료 흐름 아래에서 돌아간다. 세계가 멈춘 지역에서 노동이나 완성품을 소급 생성하지 않는다. 여러 작업자의 전역 재료 예약·자동 역할 분담·원격 지휘와 모든 작업장 경제 전체의 완료 선언은 아니다.

## 설정과 검증

숫자는 `Companion.Hearth.aid`와 `BaseCamp.Hearth.queueLimit` 패치로 분리했고, Def 범위 검사와 생성 JSON Schema를 연결했다. 과거 기본 Def에 직접 필드를 끼우지 않는다. 새 활동/행동은 명시적인 표현 계열에 등록한다.

관련 검사와 실제 입력 결과는 [검증 기록](release-v324-proof.json)에 기록한다. 유한 초기 장면의 동료/상처/점유된 창고/재고와 실제 플레이를 구분한다. 전체 회귀·World·1,000판·출시 저장 호환과 외부 사람 평가는 후속이다. v1.0.0 전체 완료를 뜻하지 않는다.
