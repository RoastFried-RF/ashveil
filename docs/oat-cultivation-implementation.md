# 실제 귀리 재배와 원래 곡물의 관수 오염 — v0.299 통합 완료

기존 귀리 종자/밭/수확5묶음/유효성장144000턴(조건을 충족한5유효일, 달력5일이 아님)/기본수확12턴과 귀리죽300kcal·원래물220ml/그릇/400턴 조리를 재사용한다. 새로 심은 귀리는 기존 실제 작물 엔진으로 햇빛·기온·남은 물을 확인한다. 새 생산품·돈·시장 재입고·주민은 만들지 않는다. 귀리/씨앗 원본2종과 땅에 자라는 귀리밭 원본1종도 별도 제작해 연결한다.

새 밭의 제안 기본값은 햇빛15% 이상·0~35°C·성장주기당1000ml·관수염도2 이하·노지의 실제 비120ml/시간이다. CANON 확정 수치로 올리지 않고 선택형 Def 패치로 둔다. 이1000ml는 성장 소비분이며 기존 증발과 토양 물 이동은 별도다. 휴대등불·밝은 지하 조명은 햇빛을 대신하지 않는다. 정지 지상 지역의 과거 날씨를 현재 날씨로 계산하지 않는다.

기존 관수 오염 계산을 실제 재배 곡물에도 적용한다. 귀리는 직접 먹는 음식이 아닌 조리 재료이므로 종전 `Item.food` 조건만으로 오염을 버리면 실제 사용한 오염수가 세탁된다. 실제 재배 밭이 있을 때에만 기존 몫을 수확 수량에 나누며, 이미 작물에 옮은 오염을 다시 만들어 늘리지 않는다. 기존 재료·죽 조리 규칙은 이 원래 `contaminantAsh`와 `foodWater`를 사용하고, 실제 가열 완료에만 기존 살균 처리를 적용한다. 맑은 관수와 옛 작물·야생 비식용 채집에는 새 오염을 소급하지 않는다.

각인202→203은 버전만 바꾼다. 기존 귀리밭의 `gatherAt`/수확 가능 여부를 보존하고 성장·물·과거 관수를 새로 채우지 않는다. 새 종자만 같은 실제UID를 기록한 `CultivationState`로 시작한다. 새 귀리 재배가 모든 주민의 자율 조리/종자 구매/판매·연간 농업·기근·장기 생태 전체를 완성한다는 뜻은 아니다.
