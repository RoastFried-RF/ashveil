# v395 항해 비용과 기록된 항로 예상

전수 감사에서 해상 탐색이 칸 수만 최소화하는 것을 발견했다. 같은 거리라도 역풍·날씨의 실제 시간 비용이 다르며, 처음 고른 짧은 길에 항행 불가능한 폭풍이 있으면 유효한 우회로까지 거절했다. 실제 구간 TU를 비용으로 탐색하고 막힌 간선을 제외했다. 동률은 고정 칸 ID로 정하며 기존 육로 큐의 비교/동작은 그대로 공유한다.

또한 세계 지도 항로 예상이 숨은 현재 원격 지형과 날씨를 직접 읽었다. 예상은 유효한 직접 관찰/충돌하지 않는 읽은 종이 지도와 현재 위치 날씨만 사용한다. 미기록 칸은 항로에 쓰지 않고, 직접 관찰이 문서보다 우선한다. 기록 부족이어도 실제 여행 버튼으로 탐험할 수 있다. 실제 항해는 원래 현재 세계/선체/승선자와 진행 중 저장 규칙을 유지하며 향후 날씨 변화를 보장하지 않는다.

- 관련5파일74검사, 타입·린트/빌드 통과. 역풍의 더 빠른 우회·폭풍 회피·육지 장벽·동률/예약 비용/선체 UID·원격 숨은 변경 불변·미탐색 장벽·현재 바람·문서 충돌/직접 관찰을 검사했다.
