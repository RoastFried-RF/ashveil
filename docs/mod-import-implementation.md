# 브라우저 모드 가져오기·설치 — v0.265 작업 중

설계11 §10.6의 웹 ZIP/폴더 가져오기와 기존 CLI tar.gz 배포 파일을 타이틀에 연결했다. 가져온 원문은 실제 packagesFromFiles/엄격한 JSON 파서와 실제 로더의 필수 의존 폐쇄로 검증하고, 스크립트는 QuickJS 검사만 수행한다. 훅을 실행하거나 과거 상태를 만들지 않는다. 검토 화면의 내용 해시는 실제 패키지 해시다. 공개 검토 객체/호출자 원문의 변경은 사적으로 보관한 승인 후보에 반영되지 않는다.

8MiB/512파일, UTF-8, 단일 manifest/모드 폴더, 안전한 상대 경로/중복/허용 파일 정책을 검사한다. CLI와 허용 파일 정책을 공유한다. ZIP은 store/deflate·로컬/중앙 경로/크기·CRC32·데이터 기록을 검사하고 암호화/분할/ZIP64/링크/특수 파일/숨은 기록을 거절한다. tar.gz는 bounded stream 해제와 ustar 헤더 체크섬·일반 파일/폴더만 허용한다. BOM을 디코딩 과정에서 지우지 않아 원래 엄격한 JSON 오류가 유지된다. 현재 배포 정책에서 허용하지 않는 텍스처/언어 자산은 가져오기 지원으로 주장하지 않는다.

명시적인 설치는 별도 ashveil.mod-packages IndexedDB에 원문/원문 체크섬을 원자적으로 저장한 뒤 사용 가능한 패키지 목록을 갱신한다. 각인 DB/현재 World/활성 모드는 이 작업에서 바뀌지 않는다. 저장 실패는 메모리 목록을 유지한다. 재시작은 체크섬을 확인하고 원문을 다시 파싱해 파일별 오류/출처도 복원한다. 서로 다른 탭은 저장소 전체 세대를 같은 쓰기 트랜잭션에서 비교하며, 오래된 검토는 목록 다시 읽기/재검토가 필요하다. 직접 설치한 패키지를 제거할 수 있고 기본 제공 패키지의 교체본 제거는 원래 패키지로 복귀한다. core 설치/교체는 금지한다.

타이틀의 모드/순서/현재 해시/생성 미리보기는 목록 갱신을 반영한다. 설치 자체로 체크박스를 켜지 않으며 기존 각인은 별도의 구성 변경 검토를 거친다. 새 게임/각인 진입의 실행 API도 브라우저 설치 목록 초기화를 기다린다. 형식182/API1.4.0과 기본 콘텐츠를 유지하고 새 Item은 추가하지 않았다.
