# 실제 내부 격자 자루 — v0.271 작업 중

설계13 §3의 마대 자루를 전체 아이템 문서 재검토와 사전 등록 뒤 추가했다. `Item.Sack`은 바깥2×2/안쪽4×3/최대1개이며 새 자루는 빈 상태다. 리넨2장과 실1꾸러미를 바늘로240작업턴 꿰매는 기본 제작법을 사용한다. 기존 sprite `cloth`를 재사용한다. 초기 지급/보상/상점 재고를 늘리지 않았다.

배낭의 자루를 더블클릭하거나 우클릭→열기로 같은 인벤토리의 내부 격자를 연다. 기존 드래그/회전/모두 가져오기/넣기/꺼내기를 사용한다. 경계/충돌/배낭 부족 실패는 물품을 먼저 바꾸지 않는다. 자기 자신/빈 가방/다른 가방을 안에 넣지 못하며 켠 광원은 먼저 꺼야 한다. 내부 물품의 UID/개수/배치/품질/오염/음식 상태를 그대로 옮긴다. 내부 소모품/도구는 배낭으로 꺼낸 뒤 사용한다.

물품 사용 검색과 환경 정산 검색을 구분했다. 같은 자루를 운반하거나 바닥/상자/시체/멈춘 지도/상점/이동 상단·습격대에 두어도 실제 음식은 경과 시간과 현지 기후로 정산한다. 내부 장비의 경과 시각도 유지한다. 사건의 재산 계산과 실제 거래 가격은 내부 실제 물품/개수를 포함한다. 상점은 내용물째 같은 UID로 자루를 사고팔며, 내부에 없어진 정의의 보관물이 있으면 거래를 거절한다. 내용물이 있는 가방을 제작 재료/분해 대상으로 없애지 않는다.

각인183은 실제 `contents`/내부 격자 선택을 저장한다.182이하는 버전만 이행하며 자루/내용물/과거 부패를 만들지 않는다. 내부 UID 중복/잘못된 배치/가방 중첩은 저장 불러오기에서 거절한다. 콘텐츠 기록에는 가방의 원래 내부 격자도 남긴다. 내부 크기를 바꾼 정의나 다른 크기로의 ID 이행은 검토에서 차단한다. 정의를 제거한 자루는 내부 실물을 유지하는 보관물이며, 다시 설치해 복원할 때 현재 내부 상태를 과거 스냅샷으로 되돌리지 않는다.
