# v0.323 보행·무기 동작

발이 지나치게 빨리 교대하던 보행을 늦추고, 실제 손에 든 무기의 손잡이와 공격 방식에 따라 준비·타격·후속 동작·회복을 연결했다. [게임](https://roastfried-rf.github.io/ashveil/) · [이전/현재 보행과 장비 비교](https://roastfried-rf.github.io/ashveil/artbook/motion/) · [검증 기록](release-v323-proof.json).

## 보행과 자세

기본 두 발 한 주기는300→720ms, 한 칸은150→360ms다. 웅크려 걷기는1000ms다. 프레임 수만 늘리지 않고 실제 타일 보간과 발의 교대를 같은 거리에 맞춘다. 밀린 이동을 따라잡는 상한은3→1.2배로 낮췄고 한 구간은 계속 인접한 한 칸이다. 자동 이동은 표현이 끝난 뒤 다음 칸을 진행한다. 애니메이션 설정0/.5/1/2배와 게임의 TU는 구분한다.

| 몸체 | 걷기 한 주기 | 웅크린 이동 한 주기 |
|---|---:|---:|
| 사람8모델 | 720ms | 1000ms |
| 재늑대 | 600ms | 850ms |
| 융합체 | 1050ms | 1300ms |
| 드론 | 900ms | 1150ms |
| 굴쥐 | 500ms | 750ms |
| 늪거머리 | 1200ms | 1500ms |

정지 호흡은3200ms다. 행동·방향 전환에120ms의 이전 포즈 혼합을 사용하고, 걷는 동안에는 각각의 단일 포즈를 그대로 그린다. 기존 웅크리기/서기·기상·피격·방어·수면·지속 작업·사용·투척·상호작용 연결을 유지한다. 걷기 중 발의 위상은 이동 거리에서 얻으며 정지 때는 정지 원화로 전환한다. 모든 정지에서 별도의 추가 발 디딤 그림을 만든 것은 아니다.

## 손에 든 물품과 공격

활성 손 장비와 투척물28정의를 조사하고15종의 연출 규격을 둔다. 칼·양손검·도끼·곤봉·망치·창·지팡이·활·석궁·소총·권총·방패·횃불·등불·일반 물품이다. 실제 정의의 공격 계열·피해 종류·양손 여부와 원화 방향을 사용한다. 각 물품의 원래 그림은 그대로 두고 손잡이 앵커·무기 길이·회전 기준을 등록했다.

게임의 공격 FX에서 읽기 전용 `meleeWield/wield`로 실제 선택한 팔·공격 모드·물품을 잡는다. 그 시점의 방향·표적 벡터·물품을 표현 큐에 보존해 다음 공격이 앞 동작을 돌려버리지 않게 한다. 사격 무기를 든 근접 공격은 기존 규칙이 고른 맨손을 따른다. 투척과 사용 소품은 기존 행동 관찰을 따른다.

- 베기520ms, 찌르기480ms, 도끼640ms, 둔기620ms, 맨손400ms, 사격500ms, 투척540ms다. 양손검의 근접 연출은120ms를 더한다. 준비·짧은 접촉 유지·후속 동작·회복을 두고 시작/끝의 무기 각도를 휴대 자세에 연결한다. 방향에는 대각선 표적 벡터도 사용한다.
- 창은 접촉 때 손을 앞으로 내밀고, 양손 무기에는 보조 손의 장갑/소매를 겹친다. 손잡이를 가리는 작은 손 레이어와 앞/뒤 가림을 사용한다. 몸의 팔 그림을 매 프레임 새로 합성하는 관절 IK는 아니다.
- 방어 때 장비를 올렸다 내리고 장전 때 원거리 무기를 낮춘다. 활의 시위, 실제 사격 포즈의 총기 반동·짧은 총구 빛을 추가했다. 보조 손의 횃불은 주무기의 사격 방향으로 함께 돌아가지 않는다. 불발·빈 석궁의 장전을 발사 FX로 꾸미지 않는다.
- 장비 UID가 바뀌면180ms에 걸쳐 들고 나타난다. 사망/누운 전환에는 장비를 내리고 감추며 소품을 쓰는 동안 겹치는 장비를 감춘다. 애니메이션0 설정에서는 즉시 장비가 표시된다. 불꽃은 실제 켜짐·연료를 따르며 이동 광원의 기존 위치 보간을 유지한다.

모든 무기가 독립적인 새 몸체 그림을 가진 것은 아니다. 기본 몸체 포즈는 공유하고 무기별 손 위치/각도/시간을 결합한다. 방패·총·부상·의료·모든221Action/능력별 특수 동작의 모든 조합을 실제 플레이로 검토한 것은 아니다. 절단된 팔을 원화에서 제거하는 변형과 모든 모드 제작자의 그림에 대한 개별 손잡이 등록은 후속이다.

## 제작 스킬과 재사용

[캐릭터 동작 스킬](../.agents/skills/ashveil-character-motion/SKILL.md)을 저장소에 추가하고 `CLAUDE.md`에서 사용하도록 연결했다. 기존 [게임 개발 스킬](../.agents/skills/ashveil-game-development/SKILL.md)과 함께 쓴다. 거리/시간부터 정하고 실제 Def·손잡이·4방향·중단·0배를 검토하는 절차와 새 원화 생성 시 방향/사지/복장·알파·원본 보존/프롬프트·해시/재시도 기록을 포함한다.

```sh
pnpm art:motion:audit --output test-results/새이름
python3 tools/art/direction-v323/apply-rigs.py
pnpm art:motion:export
```

조사·등록·내보내기는 도구가 반복 수행한다. 이미지 생성은 제공된 생성 도구와 자체 원화를 사용하고 화면에서 의미·손 위치·자연스러움을 검토해야 한다. 스킬이 모델의 생성 능력을 바꾸거나 자동으로 모든 그림의 품질을 보장하지 않는다. 비교 페이지의 무기 자세는 게임의 `equipment-motion.ts`에서 내보낸 같은 코드로 계산한다. 장비 선택은 미리보기 전용이며 게임 장비를 바꾸지 않는다. 비교 페이지의 장비에는 생존/팔 기능/마모 규칙이 적용되지 않는다.
