# 실제 Def의 읽기 전용 조회

v0.241 작업 중. 각인177/API1.4.0을 유지한다. 타이틀의 선택 모드와 플레이 중 로드된 모드 구성을 각각 실제 로더에 전달해 조회한다. 게임의 선택 모드·전역 로드 오류·월드·시간·코어 난수·스크립트 실행 상태는 수정하지 않는다.

ID/한국어 이름 검색·종류 필터·추상 정의 포함·100개 단위 목록, 실제 현재 부모/직접 자식 탐색, 상속·패치 적용값과 패치 후 원시값, 코어만 로드한 값과 JSON Pointer 차이, 적용값의 정확한 문자열 ID 역참조를 제공한다. 스크립트 내부 참조는 검색하지 않는다. 데이터 검증 결과와 실제 로드 순서를 표시하며 VM 검증이라고 부르지 않는다. 플레이어 지식/일지에는 추가하지 않는다.

원본 모드·상대 JSON 파일·배열 항목(1부터 표시), 현재 정의와 부모에 실제 성공한 패치의 적용 순서를 별도로 표시한다. JSON 배열 항목을 소스 줄 번호로 표시하지 않는다. 조건으로 건너뛴 패치는 성공한 이력에 넣지 않는다. 부모 패치가 자식 재정의에 가려져도 최종 비교는 실제 해석값을 사용한다. 이 기능은 필드별 최종 값의 인과 출처 추적이 아니다. 문서의 resolve CLI/필드별 출처와 핫 리로드·번역·창작마당은 후속으로 남는다.

파일 위치는 ModPackage 바깥 WeakMap에 저장하므로 기존 패키지 직렬화·스크립트 설정 해시를 바꾸지 않는다. 로더의 snapshot은 요청한 경우에만 원시/해석/원본/성공 패치를 복사한다. 기존 반환 형태와 기본 해석값은 유지한다. 조회의 반환값도 복사해 패널 변경이 데이터에 되먹임되지 않는다.

게임 중 F3 설정에서 열며 조회가 위에 있는 동안 게임 키를 처리하지 않는다. Tab/Shift+Tab은 조회 창 안에서 이동하고 Escape는 조회만 닫는다. 조회 중 F3은 설정으로 돌아간다. 창을 닫을 때 이전 포커스를 복원한다. 원래 설정 창을 유지하므로 열기 전부터 자동 이동이 정지한 상태다.

전용16개와 기존 골든10개가 통과했다. 실제 파일 항목/다단 상속/가려진 부모 패치/역참조/추상 정의/조건부 패치/누락 모드·부모/순환/JSON Pointer/반환값 변경 격리·전체 게임 순수성·스크립트 소스 해시를 검사한다. 첫 타입 검사에서 부모 임시 변수 추론과 테스트용 Terrain의 DefBase 타입이 맞지 않아 명시 타입으로 수정했다. 생산 규칙은 바꾸지 않았다. 기존5개 전체 초기·최종·오류·해시는 저장177까지240과 완전히 같고, 벡터와 해시를 갱신하지 않았다.

최종 타입·린트·Def 검증과 Vite1.66초 빌드를 통과했다. 실제1215–1218 네 장을 모두 직접 확인했고 선택 모드/시드 보존·조회 중 실제 게임 키 차단·전체177 게임/스크립트 상태 동일과 저장·재접속 전체 복원1회를 통과했다. 콘솔 오류0이다. 전체250파일4984개369.0382587890625초와 월드30판352.13689323299997초를 통과했고 30개 전체 결과 행·평균·사인이240과 같다. 전체 후속 구현 완료를 뜻하지 않는다.
