# 실제 고용 동료에게 맡긴 같은 현장 원본 회수

v0.201 작업 중. 현재 함께 있는 고용 동료에게 진행 중인 회수 의뢰의 원래 물품을 가져오도록 맡긴다. 새 사람/물품을 만들거나 원격으로 옮기지 않는다. 현재 같은 지역/지도에 있는 현장만 지원하며 다른 지역으로 가는 독립 원정은 후속 범위다.

배정1턴은 원래 계약의 원본ID/종류/위치/지도/용기를 사본으로 맡기고 기존 거점 작업을 해제한다. 대화/급료/몸/현재 실제 지도와 배우를 확인하며 이미 맡긴 원본을 다른 동료에게 중복 배정하지 않는다. 기존 식사/식수/휴식·위협 대응을 회수보다 우선한다. 동료는 아는 위치까지 직접 걸어가고, 실제로 곁에서 식별할 밝기와 시야를 얻기 전에는 내용물을 읽거나 물품을 꺼내지 않는다.

실제 원래 용기를 수색하고 배낭 공간을 확인한 뒤 같은 원본을 자신의 배낭으로 옮긴다. 물품을 찾지 못하거나 공간이 부족하면 원본을 만들지 않고 실제 확인 사실을 곁에 돌아와 보고한다. 자기 등불이 꺼진 어둠에서는 식별을 기다린다. NPC의 확인을 플레이어의 직접 용기 관찰로 복사하지 않는다.

원본을 들면 마지막으로 알고 있는 고용주의 위치로 걸어 돌아와 서로 보고 들을 수 있는 곁에서 건넨다. 받을 배낭이 차 있으면 동료가 실제 원본을 계속 보관한다. 지시 중단/일반 대기/고용 해산으로 물품을 삭제하지 않으며 맡겼던 운반 원본은 곁에서 자발적으로 돌려받을 수 있다. 계약이 만료돼도 이미 전달한 물리 지시를 원격으로 지우지 않는다. 다만 계약 예치금은 기존 기한 규칙으로 반환하며 원본을 받은 것만으로 보수/납품을 완료하지 않는다.

수색은 원래 임무/지도/용기와 연결해 검증하며 변경된 장소에서 다른 용기를 열지 않는다. 실패 입력/복사 배우/다른 지도/원격 수령은 전체 상태를 보존한다. 사회 화면의 동료 회수 패널은 가까이서 확인할 수 있을 때만 실제 진행/운반 정보를 보여준다.
