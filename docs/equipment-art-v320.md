# v0.320 옷·장신구·생활 도구 원화

319의 위키 목록/분류/601이미지 검토와 [제작 방향](wiki-resource-study-v319.md)을 이어서 실제23의복·25도구·2장신구를 새 자체 원본으로 연결했다.206물품 중319의30무기/탄약과 합쳐80개를 이번 방향으로 다시 그렸다. 나머지126물품과 지형/능력/UI의 기존 자체 원화는 유지한다. 전체 목록 조사와 전 자산의 신규 재제작 완료를 구분한다.

기존 물품 그림 키를 보존하고 실제 가방 크기×24px로 그린50프레임을 한800×440PNG에 넣었다. 사슬옷은 어긋난 고리와 틈, 누빔은 선과 단, 가죽은 봉제·마모·주머니, 양모는 짧은 결, 방수포는 접힌 면으로 구분했다. 모자·면포·장갑·장화·허리띠/화살통, 뼈 부적/인장, 깔개·침낭·침대,5작업장 조립품, 집게/망치/바늘, 잠금 도구/등불/전원셀·여과통/여과포·접은 배를 각각 그렸다. 등불 아이콘은 불이 꺼진 도구이며 실제 점등 표시는 원래 세계 상태를 따른다.

기본 그림은 정의의 품목/재질을 구분한다. 같은 Custom 물품에 저장된 모든 임의 재질·품질·젖음·오염을 자동으로 새 그림에 합성하는 것은 아니다. 원래 상태 수치/배지는 유지한다. 휴대용 침대/설비 아이콘과 지도에 설치된 원래 사물 그림도 구분한다.

검토 중 여백이 남은 atlas에서 등록 프레임의 최대 범위를 실제 PNG 전체 크기로 쓰는 문제를 찾았다. `sheetSizes`에170PNG의 실제 너비/높이를 기록하고 CSS·SVG·도감은 이를 쓴다. 생략된 기존 형식은 이전 계산을 유지한다. 파일 검사기는 메타데이터가 있으면 모든 시트의 실제 크기 일치와 알 수 없는 시트/잘못된 숫자를 검사한다. Pixi의 원래 texture 영역과 세계 규칙은 바뀌지 않는다.

[제작 코드/원본SVG](../tools/art/direction-v320/) · [개별50종과 이전/현재 매핑](../tools/art/direction-v320/usage-audit.json) · [CC0](../tools/art/direction-v320/LICENSE.txt). 외부 이미지 픽셀·트레이싱·팔레트 샘플 없이 직접 작성한 SVG를 Inkscape로 렌더링했다. `node tools/art/direction-v320/draw-equipment.mjs --install`, `node tools/art/update-sheet-sizes.mjs`, `node --import tsx tools/art/export-public-artbook.ts` 순서로 재현한다.319 원화까지 새로 만들려면 그 전에319의 build를 실행한다.

[공개 도감](https://roastfried-rf.github.io/ashveil/artbook/)의 물품 탭에서 `v320`으로 검색하면50종이 나온다. 최근 원화 필터는319/320이며 개별 카드에 버전을 표시한다. 현재 시트170/프레임3,485/Char28/UI26/고유PNG196이다.50개 실제 프레임의 비어 있지 않은 픽셀과 매핑을 확인하고 도감의 두 페이지/모바일3PNG를 모두 직접 열었다. Core300/콘텐츠290/모드86파일의 경로·내용은319와 같고 저장208을 유지한다.

타입·대상 린트·스프라이트 파일·빌드를 확인했다. 실제 게임은319의 제한된 원화 장면 도구에 옷/사슬옷/두건/장갑/등불/여과통/화살통 가방을 넣어 두 화면 크기의 표현을 점검했다. 타이틀 이어하기·I·머리 호버/투명 여백·머리 클릭을 실제 입력으로 실행했고 각각 대화100TU/플레이어 제자리·오류0이었다. 유한한 초기 각인이며 로드 뒤 세계를 바꾸지 않았다.12PNG를 생성하고 그중 작은 가방과 큰 주민 창2장을 직접 열었다. 도감의3PNG와 구분한다. [근거](release-v320-proof.json). 전체 회귀·World30/1000·새 저장208 전체 비교는 사용자 지시에 따라 후속이다. v1.0.0 전체 완료와 사람 평가를 주장하지 않는다.
