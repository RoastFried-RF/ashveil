## 1. 실행

```bash
pnpm install

pnpm test               # vitest: 단위·속성·결정론·던전 연결성 (최근 통합 결과는 §8)

pnpm schema && pnpm validate-schema # Def 계약 (Python jsonschema 필요)

pnpm sim 30 3           # 헤드리스 봇 30판 × 최대 3일 → 터미널 출력
pnpm build && node --import tsx tests/e2e/smoke.ts test-results   # 브라우저 스모크 + 생존 일지 체온 표시 검증

```

### 2.2 아래층 (v0.1에서 유지·조정)

인간형 44부위 신체, 상처 개체(베임·찔림·내출혈·타박·물림·화상·절단면·괴사), 동맥·골절·절단, 출혈(혈액 5,000ml, 30% 쇼크·50% 사망), 응고, 처치(압박·천/붕대·지혈대·소작·부목·소독), 감염 경주, 체온·젖음·단열, 열량·수분·비타민, 사고·기분·정신붕괴, 소음·냄새·바람, 미확인 알약, 사망 보고서·연대기, 모드(Def 상속·패치·의존성).

현재 규칙 (v0.13, 정본 수치는 체크리스트·CANON):
- 출혈 = 심각도 × 유형 계수(베임 2.0 · 찔림 1.5 · 타박 0) × 부위 혈관 계수 × 배율(묽은 피 ×1.5 등). 작은 상처(심각도 < 부위 HP 15%)는 × 0.5(D34). 동맥은 심각도 ≥ 부위 HP 30%일 때만 판정하고(D33), 걸리면 명명 동맥 고정값(대퇴 150 ml/턴 등)을 더한다.
- 통증 = Σ(심각도 − 치유) × 유형 통증 계수 × 부위 계수 + 골절·감염·지혈대(15)·재관류. 단계 15/30/50/70/90. 쇼크: 실혈 30% 이상이면 10턴마다 (실혈% − 25) × 4%, 통증 70 이상이 30턴 지속되면 15%. 회복은 실혈 25% 미만·통증 50 미만·누움·체온 36 이상 1시간. 실혈 40% 이상 기절 저항, 50% 사망.
- 사망 원인: HP 0(치명상), 실혈 50%, 뇌·심장 파괴, 간은 멎은 지 24시간 뒤. 몸통 파괴는 즉사가 아니다.
- 골절·절단·기절·무기 떨굼·넘어짐은 07 2차 효과(체크리스트 E8): 골절 (D − 뼈 강도) × 8% 등.
- 비틀거림(01 §5.2) = 다리 + 지형(얕은 물 10 · 잔해 5 · 포자 바닥 5 · 핏자국 5) + 몸(실혈 5/10 · 극심 통증 5 · 술 5 · 혼미 10 · 잠기운 5 · 탈수 10 · 탈진 5 · 저체온 10/15), 상한 60. 양다리 불구면 기어가기(2턴).
- 숙련은 폐지(D23): 의료·생존 **숙달** 0~5단계(성공 5/15/30/50/80회, 같은 대상 1회·시간당 3회), 처치 품질 +4/단계.
- 체온(v0.13): `thermal.ts`에서 03 §7.1~7.3의 영역 가중 단열·바지 1·품질·반쯤 입음·층별 방수·방풍·증발 냉각·활동·거리별 불·지붕을 계산한다. 노출을 매 턴 적산해 200턴(10분)마다 체온을 갱신하며, 떨림·고체온 사망도 반영한다. 단일 젖음 v2 세이브는 첫 틱에 영역별로 옮기며, 젖은 옷과 틱 누적은 저장된다. 동상·땀에 의한 내의 젖음 등 남은 범위는 체크리스트에 기록한다.

제작(v0.15): F2에서 의료·조리·목공·대장·직물·생존 레시피 57개를 확인하고 제작한다. 예약 재료는 배낭에 두고 완료 때만 소비한다. 위험으로 중단해도 작업 진행은 남으며 저장 뒤 이어 할 수 있다. 도구·알맞은 인접 작업장·제작서 지식이 필요하고, 몸 상태와 조리 숙달이 시간에 반영된다. 나무/돌을 채집해 작업대 키트를 만들고 바라보는 방향에 설치한다. 정비 탭은 수리 회복·영구 최대 내구 손실과 분해 회수량을 보여준다. 무두질은 준비 뒤 3일을 기다려 작업장 곁에서 회수한다. 투입/회수 재료는 현재 개수 단위이며 임의 입력의 질량 자동 상속과 작업장 연료는 아직 없다.

침구(v0.16): 풀·가지 깔개/침낭/짚 침대/나무 침대/좋은 침대를 제작해 설치한다. 발밑의 침구가 수면 질 0.65/0.8/0.9/1.0/1.1을 결정한다(맨땅 0.5). 침낭은 수면 중에만 전신 단열 +6에 품질·젖음 배율을 적용한다. 비에 젖고 불·지붕 아래서 마르며, 휴대 침구는 F2에서 접으면 UID·젖음·품질과 설치 전 지형을 보존한다. 침구 젖음은 활성 지역에서만 진행한다. 정착지/여관·NPC 침대 점유·안감은 아직 없다.

접근성(v0.17): 타이틀과 게임 중 F3에서 로그 글자 12~24px, 연출 즉시/0.5/1/2배, 흔들림·조명/횃불 깜빡임·피격 섬광·경고 맥동, 떠오르는 표시 숨김/1.5배를 조절한다. 상태 막대는 기본·적록·청황 보조 팔레트를 선택한다(배경 에셋 전체 색 변환은 아니다). 설정은 각인과 별도 저장하며 운영체제의 동작 줄이기를 첫 실행에 반영한다. 설정 창의 키 입력은 턴을 진행하지 않고 Tab 포커스가 창 안에서 순환한다. 키 재지정·TTS·한 손 프리셋은 남아 있다.

재질(v0.18): 정본 물성 17종과 7개 장비 형태의 재질 슬롯을 추가했다. 강철/부싯돌/폐합금 손도끼·강철/뼈칼·폐합금 곤봉·연철/강철 사슬옷·양모 셔츠/장갑·재늑대 코트·기름 먹인 천 셔츠를 별도 제작법으로 만든다. 재질에 따라 피해·관통·구조 내구·방어·단열·젖음 손실이 실제 전투와 체온에 반영된다. 재질 미지정 기존 인스턴스의 피해·관통·방어 결과값은 유지한다. 구조 내구를 가진 무기는 명중·막기 마모를 실제 내구 단위에서 %로 환산하며 품질도 반영한다. 질량은 내부 계산 전용이며 칸·둔중·운반 제한을 바꾸지 않는다. 동일 슬롯 혼합 물성/품질 감점 코어는 있으나 임의 재료 선택 UI·입력 질량 자동 상속과 재질별 복수 분해 회수는 아직 없다. 정비는 지정된 주재료의 개수 단위다.

진료 물품 재보급(v0.43): 부족해진 의사는 실제 상점까지 걸어가 자기 돈으로 현재 상품을 사서 돌아온다. 시장 재고/현금과 의사 물품/현금이 실제로 옮겨가며, 지불 불가·품절·가격 한도·공간 부족 때는 일정 시간 후 재확인한다. 유물 앰플은 재보급 목록에서 제외한다. 저장 형식10과 기존5입력 전체 상태·해시를 유지한다. [재보급 기록](clinic-supply-implementation.md).

숙박(v0.44): 상인 곁의 N에서 유한한 실제 침대를 빌려 직접 이동하고 Z로 잔다. 현금은 실제 시장 금고로 들어가며 기한·타인 예약/점유·중복 예약·연장·수면 중 만료·각인v11을 연결한다. 침대 수2/24시간8전은 임시값이다. [숙박 기록](inn-implementation.md).

손 위생(v0.45): 물200ml·3턴 손 씻기, 손 씻음/보통/접촉 오염과 처치Q·상처 오염·음식 위험, 의사의 실제 물과 환자 사이 손 씻기·N대기, 몸 씻기 연계·정확한 물 잔량·각인v12를 추가했다. [구현 기록](hand-hygiene-implementation.md).

공유 수면 상태(v0.46): 일반 수면 시작 때도 실제 수면 상태를 켜 시야·대화·기습 규칙과 맞췄다. NPC 수면의 소리/피격·허기/갈증/체온·완전 회복·시간 종료도 수면 활동을 끝내고 잠기운을 남긴다. 구형 각인v12의 수면 활동을 보정하며 몸/잔량은 유지한다. [수면 상태 기록](sleep-state-implementation.md).

주민 취침(v0.47): 정착지의 실제 개인 짚 침대·소유/대여 구분·피로/수면 부채에 따른 이동/수면·업무 귀환·막힌 침대의 재시도와 각인v14를 추가했다. 공개 배급/우물·주거 전체는 남는다. [주민 휴식 기록](resident-rest-implementation.md).

주민 식수(v0.49): 덮개가 있는 실제 공용 우물·주민의 비알코올 음료/재사용 병·급수/음수/손 씻을 물 보충·업무 귀환·원격 정보 배제·정확한 인접 수원 선택·N창과 각인v16을 연결했다. 물 오염은 기존 규칙을 유지하며 주민의 끓이기/연료 보급은 남는다. [급수 기록](resident-water-implementation.md).

주민 정수(v0.50): 공용 창고의 실제 연료/공간·일일 한도→실제 화덕 이동→기존 끓이기/완료 연료 소비→음수·귀환을 연결했다. 중단/훼손/연료 상실은 멸균하지 않으며, 실제 연료 소비의 인구 요약 중복 차감을 막는다. 장기 연료 생산/공공 소비 균형과 모든 주민 건강은 별도 범위다. [정수 기록](resident-purification-implementation.md).

문해 수업(v0.51): 실제 상인이 기초 글자를 가르치는 역할을 겸한다. 실제 수업/수업료·교사와 학생의 몸·거리/조명/교전·상호 중단·다른10일 수료의0→1 이정표·다른 교사에게 진도 유지·N/C창/각인v18을 연결했다. 수업1시간/비용6은 임시 Def 값이다. [수업 기록](teaching-implementation.md).

주민 장기 생활(v0.52): 익숙한 작은 소리에 깬 주민이 경보12로 생활 소음을 증폭하던 경로를 수정했다. 취침 전 실제 음식/물로 준비하고, 추운 주민은 실제 화덕으로 이동해 몸을 움직이며 기존 작업 대사/체온 적산으로 데운다. J에서 플레이어도 같은 행동을 쓴다. 실제 지역·관찰자만 재설정한 동일 시드 진단은 v0.51의5.6944일 의사 저체온 사망에서 주민4명 전원10일 생존으로 개선됐으나 일부 주민의 높은 피로/침구·보온은 남는다. [장기 생활 기록](resident-life-implementation.md).

고정 침구 이동(v0.53): 실제 포장 시간/공간·같은 물품 UID/품질/내구/젖음·원래 바닥·소유권을 보존해 배낭으로 운반하고 다시 설치한다. 추운 주민은 자기 침구를 실제로 화덕 가까이 옮긴다. 같은1시드10일 진단에서4명 생존/종료 피로39.7~68.5를 확인했으며 모든 지역/계절의 완료로 세지 않는다. [침구 이동 기록](bedding-move-implementation.md).

### v0.54 주민 사망·개인 소지금

실제 주민이 죽으면 S/I/R 중 가능한 구획에서 사망자로 한 번 옮기며 조사 인구 N은 유지한다. 당일 공공 소비의 중복 공제와 첫 방문의 과다 실체화/죽은 의사 무료 재보급을 막는다. 수색한 시체의 개인 동전을 실제 지갑으로 옮길 수 있고 I창에서 양쪽 금액을 확인한다. 시장 공금은 별도다. [구현·검증 기록](resident-death-implementation.md).

### v0.55 조달 계약

N창의 상인 계약 장부는 실제 시장의 붕대/건빵/목재 부족분만 게시한다. 수락 시 실제 시장 돈을 예치하고, 같은 물품을 납품한 뒤 지갑으로 보수를 지급한다. 기한 만료/취소/플레이어 사망은 예치를 반환하며 수락·납품·취소는 각각1턴이다. 현재 계약과 조건·기한·결과는 일지에도 남는다. [구현·검증 기록](contracts-implementation.md).

### v0.56 소문 현장 조사

이미 읽은 방 위치 소문을 바탕으로 실제 현장을 조사하는 계약을 맡는다. 표시된 지역/층/구역의 내부를 실제 시야로 살피고 일지에서 조사 기록을 남긴 뒤, 의뢰 정착지로 돌아가 보고해야 예치 보수를 받는다. 소문과 다른 현장도 그대로 보고한다. [구현·검증 기록](investigation-implementation.md).

### v0.57 키 배정·한 손 조작

F3 설정에서 이동/생활/전투·창·빠른 칸의 키를 변경/해제하거나 왼손 배치를 쓴다. 배정 충돌·예약 키를 검사하고 한글 입력 상태에서도 같은 물리 키 위치로 동작한다. 현재 키는 HUD/도움말에 반영되며 각인과 별개로 저장한다. [구현·검증 기록](keybindings-implementation.md).

### v0.58 세력 관계·들은 정책

실제 현지 NPC 습격과 목격된 주민 사망이 방향별 세력 관계/원한에 반영되고, 관계는 매일1씩 기저로 돌아간다. 대화한 주민 세력의 당시 정책만 N창에 남으며 이후 비공개 사건을 자동 공개하지 않는다. 개인 평판과 영역 세력 규칙은 따로 처리한다. [구현·검증 기록](faction-relations-implementation.md).

### v0.59 저체온 혼란·착탈 진행

체온33°C 미만·의식0.6 미만이면10분마다5%로 실제 겉옷을 벗으려 한다. 플레이어와 NPC가 같은 몸/착탈 규칙을 쓰며 정상 차례와 작업 시간이 든다. 같은 옷을 바닥에 놓고, 중단한 착탈은 남은 작업량과 현재 몸 상태로 재개한다. [구현·검증 기록](cold-confusion-implementation.md).

### v0.60 동료 고용·실제 동행

정착지의 기존 경비를 실제 고용료로 고용하고 동행/현지 대기/주변 방어를 지시한다. 각자의 몸·장비·개인 현금과 식수/식량은 유지한다. 계단·지역·길목 이동도 같은 인물을 넘기며, 떨어진/잠든 동료는 순간 이동하지 않는다. 기간 만료 때 곁에서 급료를 건네야 다시 동행한다. 장비 교체는 꺼낸 물품의 자리까지 포함해 기존 장비 모두의 공간을 먼저 검사한다. [구현·검증 기록](companions-implementation.md).

### v0.61 동료 관계·들은 태도

함께 깨어서 보며 지낸 시간, 성향의 공통점/충돌과 급료 약속이 동료 관계에 쌓인다. 관계는 사기에 영향을 주고, 심해지면 같은 몸과 물품을 남긴 채 동행을 끝낸다. 내부 수치는 자동 공개하지 않으며 N창에는 대화로 들은 당시 태도만 남긴다. 고용주가 공격하면 계약이 해제되고 공통 반격/목격 평판을 따른다. [구현·검증 기록](companion-bonds-implementation.md).

### v0.62 항복 이후 선택

F2에서 천2개로 밧줄을 만들고, N창에서 실제 항복자를 포박/석방/심문/처형한다. 포박에는 밧줄1개와 기본2턴, 처형은 기본3턴이 든다. 실제 밧줄은 포로에게 옮겨졌다가 풀거나 사망하면 남는다. 심문은 그 인물의 현지 공급원 대략값을 소문으로 듣고, 석방/처형 평판은 실제 목격과 기존 소식 도착 규칙을 쓴다. [구현·검증 기록](prisoners-implementation.md).

### v0.63 포로 돌봄·감시와 탈출

N창에서 실제 배낭의 음식/같은 물병으로 깨어 있는 포로를 먹이고 조심스럽게 깨운다. 양쪽 몸/손 위생·영양/수질·시간과 원정 소비 공제를 공유한다. 포로도 자연 수면/잠기운을 쓰며, 깨어 지켜보는 실제 경비가 없으면200턴 동안 밧줄을 풀려 애쓴다. 완료에만 품질별 마모와 독립 확률을 적용하고 같은 밧줄 UID/몸·지갑/저장을 보존한다. [구현·검증 기록](prisoner-care-implementation.md). 호송·회유와 구출 영입은 후속이다.

### v0.64 실제 호송과 손 점유

N창에서 실제 포로의 발목을 풀어 빈손으로 밧줄을 잡고 호송한다. 손 점유/남은 손의 조작·장비 제한, 실제 경로/거리/시선과 잠/실신 시 놓침,1턴 밧줄 놓기와 실제 재포박을 연결했다. 출입구를 막으면1턴 비키기 요청 후 포로 자신의 차례에 이동한다. 같은NPC/밧줄·몸/지갑을 계단·지역·길목·여행으로 넘기며 복제/빈 도착지·밧줄 거리/잠든 인물의 여행 중단을 검사한다. [구현·검증 기록](prisoner-escort-implementation.md). 회유·구출 후 영입은 이어서 구현한다.

### v0.65 돌봄과 여러 날의 대화 뒤 영입

실제 받은 음식/필요 수분을 돌본 서로 다른3일에 양쪽 활동으로 대화하고, 동의 뒤 실제 밧줄 풀기 작업을 끝내면 같은 인물이 동행한다. 몸/원래 세력·물품·현금/관계를 보존하며 시험 기간 뒤 기존 실제 급료를 받는다. 반복/중단/날짜만 이동·원격/불안/손/정원/공격 철회·저장 복원과 현지 적 병력 중복 집계를 검사한다. [구현·검증 기록](recruitment-implementation.md). 자연 발생 납치·구출과 구조된 사람의 영입 경로는 이어서 구현한다.

### v0.66 실제 실신 포박·해방과 동료 구조

의식 없는 인간형에게 실제 밧줄/2턴 포박과 해방을 연결하고, 해방으로 실신이나 상처를 치료하지 않는다. 몸/물품·기존 동료 계약과 급료를 유지하며 붙잡힌 동료의 원본 명부/출입·저장을 보존한다. 깨어 실제 구조자를 알아본 뒤에만 소식과 관계를 기록하고, 실신자 해방으로 항복 경험치를 만들지 않는다. 시험 동행과 이후 실제 선불 급료/원소속 국가 관계를 나눠 표시하며, 실제 급식 수취량의 소수점 오차와 깨운 직후 재수면을 수정했다.
