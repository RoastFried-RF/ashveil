## 1. 실행

```bash
pnpm install
pnpm dev                # 브라우저에서 플레이
pnpm test               # vitest: 단위·속성·결정론·던전 연결성 (6파일 30개)
pnpm lint               # ESLint Flat (코어 Math.random·초월함수 금지)
pnpm sim 30 3           # 헤드리스 봇 30판 × 최대 3일 → docs/sim-latest.txt
pnpm build && node --import tsx tests/e2e/smoke.ts test-results   # 브라우저 스모크 + 스크린샷 9장
python3 -I tools/art/build-sprites.py <팩 압축 해제 폴더> .         # 에셋 시트 재생성 (팩은 저장소 밖)
```

`?debug`로 열면 `window.__ashveil.botSteps(n)`으로 봇이 대신 플레이한다.

### 2.2 아래층 (v0.1에서 유지·조정)

인간형 44부위 신체, 상처 개체(베임·찔림·내출혈·타박·물림·화상·절단면·괴사), 동맥·골절·절단, 출혈(혈액 5,000ml, 30% 쇼크·50% 사망), 응고, 처치(압박·천/붕대·지혈대·소작·부목·소독), 감염 경주, 체온·젖음·단열, 열량·수분·비타민, 사고·기분·정신붕괴, 소음·냄새·바람, 미확인 알약, 사망 보고서·연대기, 모드(Def 상속·패치·의존성).

v0.2 조정:
- 출혈 = 심각도 × clamp((심각도/12)^1.5, 0.1, 1.6) × 상처계수 × **0.35** × 부위계수 (× 동맥 4). 작은 상처는 거의 안 흐르고 큰 상처만 위험하다.
- 통증 = 상처 심각도 합 × **0.6** (생사는 HP가 맡으므로). 쇼크 판정은 통증 80부터.
- 골절은 부위 체력 대비 피해 30%를 넘어야 위험이 생긴다. 절단은 단일 피해가 부위 체력의 60% 이상 + 누적 파괴일 때만.
- 몸통(뿌리 부위) 파괴는 즉사가 아니다. 뇌·심장 파괴, HP 0, 출혈 50%가 사망 원인. 간은 멎은 지 24시간 뒤.
- 비틀거림(01 §5.2) = 다리 + 지형(얕은 물 10 · 잔해 5 · 포자 바닥 5 · 핏자국 5) + 몸(실혈 5/10 · 극심 통증 5 · 술 5 · 혼미 10), 상한 60. 양다리 불구면 기어가기(2턴).
- 숙련은 폐지(D23): 의료·생존 **숙달** 0~5단계(성공 5/15/30/50/80회, 같은 대상 1회·시간당 3회), 처치 품질 +4/단계, 감별 = 50 + (지각 + 숙달×5 − 25)×3 %.

## 4. 밸런스 현황 (봇 기준)

v0.6 봇 전술(`src/core/bot.ts`): 결과는 [sim-latest.txt](sim-latest.txt).
- **승산 계산** `fightRisk`: 양쪽 명중률(previewHit)·무기 피해·대상 HP로 '내가 차례로 다 쓰러뜨리는 동안 받는 피해 ÷ 버틸 몸(HP 절반, 실혈 반영)'. 기력이 바닥나면 내 피해 절반.
- **후퇴**: 불리하면 지하에선 올라가는 계단(그늘 사람은 지상까지 안 따라온다), 지상에선 내려가는 계단이나 반대 방향. 같은 속도의 적이 이미 붙어 있으면 계단이 2칸 안일 때만 물러난다. 계단을 탄 직후 30턴은 다시 계단으로 도망치지 않는다(왕복 방지). 물러난 뒤 1시간은 다시 내려가지 않는다.
- **보이지 않는 적**: 최근 40턴 안에 맞았고 다쳤으면(달려들기 후 빠지기) 위층으로 올라가 처치·회복.
- **피할 방 기억**: 불리했던 무리·잠든 무리의 방은 탐색에서 뺀다(상태에 저장 → 세이브·결정론 유지).
- **잠든 단독 적 기습**: 잠행으로 다가가 첫 타(명중 +40 · ×1.5). 단, 깬 뒤 1:1 승산이 될 때만.
- **정면 맞기**: 2칸까지 다가온 추적자 쪽으로 몸을 돌린다(측면 +10을 주지 않음). 좁은 곳에서 기다린다.
- **무기**: 떨군 무기는 3칸 안에서 찾아 줍고 다시 든다. 더 좋은 근접 무기(기댓값 15%↑)로 바꾼다. 활은 4~6칸에서 먼저.
- **몸 관리**: 내려가기 전 HP 90%·기력 80%·출혈 없음. 춥거나 젖으면 모닥불·지붕 밑. 모닥불은 몸을 녹일 때만 켜고 떠나기 전에 끈다(수색대 흔적). 배낭이 차면 값어치 없는 짐을 버린다. 같은 상자는 한 번만 턴다.
