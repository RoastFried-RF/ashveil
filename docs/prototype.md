| 항목 | 내용 |
|---|---|
| 작성 | 2026-10-13 KST (v0.1: 같은 날 16:47) |
| 방향 | **턴제 던전 RPG가 뼈대**(1행동 = 1턴, HP·6부위, 격자 배낭, 레벨·능력, 정해진 장소의 적) + **정밀 신체 시뮬레이션을 아래층에**(상처 개체·출혈·감염·처치·생존). CANON §7 D7~D14 |

## 1. 실행

```bash
pnpm install
pnpm dev                # 브라우저에서 플레이
pnpm test               # vitest: 단위·속성·결정론·던전 연결성 (6파일 30개)
pnpm lint               # ESLint Flat (코어 Math.random·초월함수 금지)

pnpm build && node --import tsx tests/e2e/smoke.ts test-results   # 브라우저 스모크 + 스크린샷 9장

```

### 2.2 아래층 (v0.1에서 유지·조정)

인간형 44부위 신체, 상처 개체(베임·찔림·내출혈·타박·물림·화상·절단면·괴사), 동맥·골절·절단, 출혈(혈액 5,000ml, 30% 쇼크·50% 사망), 응고, 처치(압박·천/붕대·지혈대·소작·부목·소독), 감염 경주, 체온·젖음·단열, 열량·수분·비타민, 사고·기분·정신붕괴, 소음·냄새·바람, 미확인 알약, 사망 보고서·연대기, 모드(Def 상속·패치·의존성).

v0.2 조정:
- 출혈 = 심각도 × clamp((심각도/12)^1.5, 0.1, 1.6) × 상처계수 × **0.35** × 부위계수 (× 동맥 4). 작은 상처는 거의 안 흐르고 큰 상처만 위험하다.
- 통증 = 상처 심각도 합 × **0.6** (생사는 HP가 맡으므로). 쇼크 판정은 통증 80부터.
- 골절은 부위 체력 대비 피해 30%를 넘어야 위험이 생긴다. 절단은 단일 피해가 부위 체력의 60% 이상 + 누적 파괴일 때만.
- 몸통(뿌리 부위) 파괴는 즉사가 아니다. 뇌·심장 등 치명 기관 파괴, HP 0, 출혈 50%가 사망 원인.

## 4. 밸런스 현황 (봇 기준)

봇은 전술이 거의 없다(정면 교전, 잠행·문·좁은 통로 미활용, 보물실 우두머리도 피하지 않음). 사람보다 훨씬 빨리 죽는다. 결과는 [sim-latest.txt](sim-latest.txt).

- 2026-10-13 측정(30판 × 최대 3일): **평균 생존 0.48일, 치명상(HP 0) 53% · 과다 출혈 37% · 심장 파괴 3% · 저체온 3%, 시간 종료 생존 1판.** 최고 레벨 3, 지하 2층 도달 6판, 3층 0판.
- v0.1(몸통 파괴 53%가 1위)과 달리 사망 원인 1위가 HP 0이 되었다 — 의도한 구조(HP가 생사, 상처는 그 아래 층)와 맞는다.

- 조정 이력(v0.2): 명중 감점이 겹쳐 5%까지 떨어짐 → 어둠·통증·손 상태 감점 축소 / 경비가 서로의 발소리에 반응해 야영지를 비움 → 같은 편 소음 무시 / 상자가 문을 막아 진행 불가 → 문·복도에 닿은 물체 제거 + 석상 배치 조건 / 기본 공격 기력 소모로 금방 탈진 → 15%로 / 통증 쇼크로 기절 후 사망 → 통증 0.6배 / 작은 타격 골절 과다 → 30% 문턱 / 그늘 사람 명중 과다 → 정확도·민첩 하향 / 이미 뒤진 상자를 반복해 여는 무한 루프 → 안 뒤진 용기 우선.
- 남은 과제: ① 지하 1층에서 레벨 1~2 봇이 자주 죽는다(사람 기준 체감 확인 필요) ② 약초꾼(무기 약함) 생존율이 가장 낮다 ③ 지하에 물이 없어 오래 머물면 탈수 — 봇은 지상으로 올라가 물을 마신다.
