# 실제 귀리·물과 같은 원래 그릇의 귀리죽

v0.109. 03 §4.1의 귀리죽300kcal/단백10g/비타민0/수분220ml/신선12시간과 §4.3의 따뜻한 음식 체온+0.2°C, 01의 국 조리400턴(20분)을 연결한다. 13 §4.9에 귀리·씨앗1×1/쌓임5, 원래 빈 그릇/죽 그릇1×1/쌓임1을 먼저 등록했다. 귀리1묶음/물220ml/그릇1, 귀리5일 성장/5묶음 수확, 완성 후20분 보온/체온 상한37.2°C는 조정 가능한 콘텐츠 기본값이다.

연합의 유한 재고에 귀리10/씨앗4/그릇4를 추가한다. 원래 씨앗을 실제 빈 흙에 심으면 성장 시각이 남고, 성장 전에는 수확할 수 없다. 실제 수확은 기존 흙/토양 비옥도·원본 채집/배낭·재생 규칙을 쓴다. 해당 물품은 자동 생성된 수확물이나 과거 조리로 대체하지 않는다.

정상 제작 작업은 실제 귀리/그릇 UID와 원래 물병의 실제220ml/양·수질, 같은 설치된 유한 장작불 UID를 묶는다. 정적 무료 화덕은 대신하지 못한다. 작업 중에는 몸에 영양을 주거나 재료를 미리 소비하지 않는다.400턴 마지막에 원래 귀리1과 물220ml만 소비하며, 같은 그릇 UID/품질/내구에 한 회분의 죽을 담는다. 남은 원래 물병도 같은 UID로 남고, 마지막220ml를 썼으면 빈 병이 된다. 요리 Q와 원래 그릇 품질은 구별한다.

불이 꺼지거나 곁을 떠나면 원래 제작 진행은 남는다. 같은 불을 다시 피워 재개할 수 있지만 새 불 UID/새 물/새 그릇/새 귀리/달라진 조리 규칙에 원래 진행을 대입하지 않는다. 실제 완료 때만 소비한다. 취소하면 자원을 소비하지 않고 진행만 버린다. 방치 중 음식이 타는 전체 요리 모델은 이 단계의 완료 범위에 포함하지 않으며 전체 후속 구현 대상으로 남는다.

원래 물은 기존 끓임 규칙으로 처리해 병원체를 제거하고 재×1.1/염분을 보존한다. 원래 재 노출은 기존 음식 오염으로, 실제 소금량은 같은 그릇에 기록해 실제 섭취자의 추가 수분 손실로 전달한다. 다 먹으면 같은 원래 빈 그릇이 남고 잔여 음식/열/소금/재 기록을 지운다. 다른 사람에게 먹여도 그 몸에만 열량·수분·소금·재와 따뜻함이 전달된다.

완성 시각이 있는 실제 음식만20분 동안 따뜻하다. 처음 생성된 음식이나 구형 저장에 과거 조리 온도를 만들지 않는다. 먹은 순간 실제 따뜻한 경우에만 체온이+0.2°C(설정된 상한까지)이며, 발열을 내려 주지 않는다. 시간이 지난 음식은 동일 영양을 주되 보온 효과가 없다.12시간 부패와 기존 식중독/손 위생·조리 숙달을 사용한다.

F2 제작법에 실제 물220ml/원래 그릇/같은 장작불과 부족한 이유를 표시한다. 음식 설명은 실제 보온/식음·원래 소금·남은 회분과 같은 빈 용기를 보여 준다. 각인v73은 원래 조리 진행/물·재료·불·그릇/완성 보온 시각을 보존하고 구형72의 과거 뜨거운 음식을 만들지 않는다.
