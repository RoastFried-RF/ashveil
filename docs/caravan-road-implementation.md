# 교역단의 실제 길목 정차와 계속 걷기 — v0.95

v0.94의 원래 주민·화물·현금 교역단을 이어, 관찰 중인 길목에서도 무리가 여정을 계속한다. 같은 칸에서 만난 원래 상인과 호위는 설정된 20턴 동안 정차한다. N창은 실제 남은 정차 시간을 표시한다. 이후 각 인물이 다음 월드 구간 방향의 통과 가능한 실제 지도 경계까지 한 칸씩 걷는다. 모두 도착해야 같은 인물들을 보관 상태로 옮기고 남은 월드 구간 시간을 이어간다. 막힌 경계를 건너뛰거나 물 위로 강제 이동하지 않는다.

이미 만난 월드 칸을 기록하므로, 같은 칸에서 대기하거나 저장 후 이어하기로 나간 무리를 반복 소환할 수 없다. 실제 다음 월드 칸에 도착하면 이 기록과 이전 목격 기록을 지워 새 현지 만남을 허용한다. 보행 중 사망·포획·적대자 발견은 기존 몸·포로·전투 규칙을 사용한다. 원래 화물·현금·주민의 식별자는 그대로다.

각인 v59는 정차 종료 시각·이미 만난 칸·기존 NPC 보행 경로를 보존한다. v58 이관은 버전만 바꾼다. 예전 각인에서 이미 현장에 있던 교역단은 다음 실제 틱에 앞으로의 정차 시간을 배정받는다. 과거에 걸었다는 기록을 만들지 않는다.
