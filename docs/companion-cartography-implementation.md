# 동료 자신의 관찰로 작성한 원래 지도

v0.162는 NPC가 현재 실제로 서 본 방/계단만 개인 기록에 남기도록 연결한다. 현재 층의 실제NPC차례와 깨어서 볼 수 있는 몸을 사용한다. 플레이어의 발견한 방·관찰 기록, 들은 지도, 생성 캐시/원격 방을 복사하지 않는다. 같은 알려진 구조를 조회할 때 최초 기록 시각과 난수를 임의로 갱신하지 않으며 실제로 달라진 구조를 그 자리에서 새로 보면 기록을 바꾼다.

동료는 자신의 빈 종이와 잉크로 자신이 기록한 현재 지역 지도를 작성한다. 문해/빛/손/몸·기본60턴과 생존 숙달별 신뢰도/오차는 기존 작성 규칙을 쓴다. 처음 초안을 고정하고 완료 때만 같은 종이UID에 글을 쓰고 잉크1회분을 소비한다. 중단/남은 진행 재개, 원래 재료 변경 거절과 취소를 보존한다. 새 물건이나 플레이어의 재료/경험치를 만들지 않는다. NPC의 문서는 개인 지식에 먼저 남고 플레이어 정찰 의뢰의 자기 작성 원본으로 납품할 수 없다.

N동료 창에서 실제1턴으로 부탁/중단/취소하고 완성된 원래 종이를 건네받는다. 배낭 공간을 먼저 검사하며 같은 원본을 두 번 받을 수 없다. 동료의 종이를 받아도 내용은 자동으로 배우지 않는다. 실제1턴 독서나 실제 대화가 필요하다. 작성 중에는 동료가 정상 차례마다 작업하고 플레이어는 별도로 행동한다. 긴급 화재 같은 기존 중단을 따르고 원래 초안/재료는 남는다.

각인120→121은 버전만 이관한다. 과거NPC의 탐험·방/계단을 지어내지 않으며 이후 실제 현재 차례부터 기록한다. 기존5개 명령/오류를 그대로 재생한 전체 초기/최종 상태는 버전121과 실제NPC개인 기록 외 같다. 적절한v161 골든 원본을 한 번 보관하고 감사한 기대 해시만 갱신했다. 기대 필드명은expectedInitialHash/expectedHash이며 명령을 새로 생성하지 않았다.

전용22개와 기존 작성/동료/지도/골든의5파일95개가 통과했고 타입·린트·빌드·Def224패치/Item188/Terrain80도 확인했다. 유효한 초기 동의 동료/원래 재료에서 시작하며 과거 돌봄·영입·물품 전달 턴까지 실행했다고 주장하지 않는다.
