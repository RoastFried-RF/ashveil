# v0.385 · 동료 처치 순서와 의수족 아이콘

2026-10-25 KST. 개발 미리보기이며 v1.0 출시 완료가 아니다.

곁의 고용 동료에게 같은 환자의 진찰·투약·상처 처치를 최대8개까지 순서대로 맡긴다. 주민·세력(Shift+N) → 동료 → 돌봄 부탁 → 진찰·처치·약에서 처치 내용을 선택하고 **처치 순서에 추가**한다. 위/아래·제거로 순서를 정리하고 각 단계의 시간·예상Q·약효/위험·원래 도구와 소모품을 검토한 뒤 맡긴다. 절단은 기존의 별도 영구 상실 확인을 거친 단일 상담만 가능하다.

검토는 실제 세계를 바꾸지 않는다. 독립 재고 사본에서 앞 단계에 할당한 수량을 차감하므로 같은 한 몫을 여러 단계에 중복 예약할 수 없다. 실제 단계에는 승인한 환자·상처·약·도구·재료 UID/Def와 수량을 기록한다. 완료할 때 기존 진료 엔진이 원래 물품을 소비하고 실제 효과를 적용한다. 다음 단계는 현재 의식·안전·빛·몸·급료·재고를 재검토하며, 승인한 물품이 없어졌다면 같은 종류의 새 물품으로 자동 교체하지 않는다. 이미 붕대를 감은 상처를 다시 감는 등 변화한 조건도 중단 이유를 남긴다. 미래 처치를 검토 때 미리 적용하거나 회복을 보장하지 않는다.

나를 돌볼 때는 실제 진료 대기로 시간이 흐른다. 다른 동료를 돌보게 부탁하는 명령은1턴이며 이후 플레이어가 별도 일을 해도 그 환자와 시술자가 원래 현장에 있으면 계속한다. 완료 단계 수·원래 순서·중단 이유를 보존한다. 환자/시술자 취소·위협·실신·물품 상실 등으로 끊기면 남은 순서는 자동 재개하지 않는다. **남은 순서 다시 검토**로 현 상태와 재고를 확인해 새로 맡긴다. 기존 반쪽 부목·사용한 물품·이미 끝난 처치는 되돌리지 않는다. 완료란 실제 시행을 마쳤다는 뜻이며 치료 성공·후유증 제거를 보장하지 않는다.

저장218은 이 유한 순서와 진행 중 활동의 연결을 보존한다.217→218은 헤더만 올리며 기존 환자·재고·동의·치료계획을 만들지 않는다. 저장 형식은 환자/단계/수량/진행 범위와 원래 활동 연결을 검사한다. 함께 반복 정비종의 음수/소수/범위초과 카운터 저장도 거부한다.
