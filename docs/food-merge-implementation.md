# 신선도 단계가 다른 음식의 명시 병합 — v0.273 작업 중

설계13 §5의 음식 더미 병합을 실제 배낭 드래그에 연결했다. 같은 음식/품질/오염/해동/수확 출처 등 모든 다른 상태가 일치해야 한다. 각각의 원래 부패 시각부터 현재 기온/젖음까지 사본에서 먼저 정산하고, 현재의 신선도 단계를 비교한다. 조회/드래그/확인 화면/취소는 실제 물품/시간/UID/난수를 바꾸지 않는다.

같은 단계 안의 다른 퍼센트는 더 낮은 퍼센트로 합친다. 다른 단계는 옮길 개수와 기존 개수·결과 단계/퍼센트를 실제 값으로 보여 주고 ‘이 상태로 합치기’를 눌러야 한다. 취소/Escape는 원본을 유지하며 확인 중 게임 이동/사용 키는 실행하지 않는다. 확인은 두 UID/전체 물품 상태/개수·현재 시각/기온/젖음/정의 해시에 묶여 있고 바뀌면 다시 확인해야 한다.

합친 목표는 원래 UID/배치와 두 음식 중 더 낮은 신선도를 가지며 부분 이동 때 원래 더미의 남은 물품은 자신의 실제 신선도를 유지한다. 현재 시각까지 정산한 부패는 다음 시간 정산에서 중복하지 않는다. 원래 시각 없는 구형 음식에 과거 시간을 추정해 채우지 않는다. 일반 줍기/자동 넣기는 기존 엄격 쌓임을 유지해 다른 신선도를 조용히 섞지 않는다. 새 아이템/정의/각인/API 변화는 없다.

최초 관련3파일64개 중63개가 통과했다. 동결 시험이 한낮의 실제 지상 온도에서 동결을 기대한 시험 오류여서, 다음날 새벽5시의 실제 영하 기온으로 고쳤다. 생산 기후/부패 코드를 바꾸지 않았다. 후속 관련/정적/브라우저/전체 회귀는 진행 중이다.
