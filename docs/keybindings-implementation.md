# 키 재지정·왼손 조작 — v0.57

F3 설정에서 이동·생활/전투·창·빠른 칸의 키를 변경하거나 해제하고, 왼손 배치 또는 기본 키를 복원할 수 있다. 기기/입력 접근성 후속을 실제 키 처리·설정 저장·현재 표시까지 연결한다.

## 입력과 저장

입력은 `KeyboardEvent.code`의 물리 위치를 쓴다. 한글 입력 상태·Caps Lock·넘패드 잠금에 따라 키 문자가 달라도 같은 위치가 같은 게임 동작을 낸다. 재배정하면 그 명령의 기존 별칭은 모두 대체한다. 다른 명령과 같은 키는 원인을 표시하고 거부한다. 운영체제 키, 설정 F3·확정 Enter·브라우저 기본 단축키 등 사용할 수 없는 키도 거부한다. Esc는 배정 중 취소하고 다음 Esc에서 설정을 닫는다. 설정 캡처와 창 초점 이동 중에는 게임 명령이 발생하지 않는다.

방향에 추가한 Ctrl/Shift는 기존 제자리 회전/밀치기를 유지한다. 재배정 자체에 든 수식 키는 동작에 다시 적용하지 않는다. 기본 Shift+K/B/J 등 별도 명령이 있으면 그 배정이 먼저다. 기본 N은 기존 실제 동작과 같은 주민·세력이고 남동쪽은 넘패드를 쓴다. 조준 중 Tab/Enter, 창/활동 취소 Esc, 물건을 끌 때의 R/우클릭 회전은 해당 문맥의 입력으로 유지한다. 소지품의 정렬/기본 공백 루팅 문맥도 보존한다. 텍스트 입력과 버튼/summary의 Enter·공백 활성화는 게임 키가 가로채지 않는다.

왼손 배치는 QWE/ASD/ZXC의8방향과 가운데S대기, R줍기/F수색/T휴식/G수면을 중심으로 하고 창은 기능키, 그 밖의 명령은 표시된 조합 키를 쓴다. 모든 명령에 키가 남는다. 현재 배정은 HUD 창 버튼·방어/공격·빠른 칸, 도움말의 전체 키 표와 주민 창 제목에 반영한다.

키 설정은 기존 화면 설정 저장소에 각인과 별개로 저장한다. 예전 설정의 누락 필드, 잘못된 형식/예약 키·충돌한 저장은 기본 배치로 복구하고 정상적인 키 해제/다른 명령으로 이동은 보존한다. 전체 설정 초기화와 키만 초기화를 구분한다. 저장소가 지원되지 않을 때는 기존과 같이 현재 실행에서 쓴다.

## 검증과 범위

키 배정10개+기존 화면 설정3개 회귀는 모든 기본 별칭/충돌, 한글/넘패드 코드, 변경/해제한 키의 기존 동작 차단, Ctrl/Shift 및 Alt방향의 수식 키 소비, 왼손 모든 명령, 예약 키·손상 저장/JSON 왕복·표시를 검증한다. 전체57파일877개가 첫 검사41.17초에 통과했고 Alt방향 조합 보완 뒤 관련13개를 다시 확인했다. 기본 넘패드 Enter의 계단 입력과 Shift+공백 대기 별칭도 유지했고 관련13개를 다시 확인했다. 브라우저 키 배정 구간과 설정 회귀의 콘솔 오류는0개다. 중복/예약 키와 Esc 캡처 취소·설정 중0턴, 새 키로 실제1턴 이동/기존 키 미동작·새 소지품 키와 HUD, 타이틀/재실행 뒤 설정 복원, 왼손 D이동/S대기/Ctrl+D회전 총3턴·F4소지품/F10현재 도움말·기본 키 복원을 확인했다. 화면127~130을 저장했고130을 시각 확인했다.

기본 키의 기존 침구 조작 구간도 재검증해 F2포장/실제200턴·I우클릭 같은UID재설치·NPC침구 포장/운반/설치와 중간 각인을 통과했다(111~115·설정 회귀, 콘솔 오류0개). 최종 고정 소스 전체57파일877개 테스트도32.65초에 통과했고 lint/type/build/Def 검증 오류는0개다.

코어/콘텐츠 파일은 고정v0.56과 동일하고 저장 버전23·기존 골든 입력/해시를 유지한다. 규칙/밸런스 변경이 없어30판 회귀는 직전v0.56 결과를 유지한다. 영어 현지화·TTS·추가 기기/한 손 배치와 실제 접근성 사용자 평가는 별도 후속이다.
