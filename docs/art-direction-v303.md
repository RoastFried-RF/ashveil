## 공통 제작 규칙

CANON D13의 16×16 타일·정수 배율·좌상단 광원을 유지한다. 현재 모든 프레임 키와 논리 크기, 캐릭터 방향·포즈, UI 슬라이스 영역을 보존한다. Core·Def·저장 규격·수치·난수·시야 판정은 바꾸지 않는다.

- 기조: 잿빛 수도원, 젖은 석회암, 흙빛 천, 그을린 철, 말라붙은 목재. 화면 전체를 녹색으로 물들이지 않는다.
- 공통 기준색: 먹 `#19191b`, 그늘 `#29282a`, 흙 `#49413b`, 돌 `#68645c`, 닳은 면 `#969080`, 천 `#a69a7b`, 피부 `#b3a18b`, 양피지 `#d0c2a0`, 철 `#697075`, 녹 `#78503c`, 이끼 `#4d5644`.
- 바닥: 중간 이하 명도, 3~5개 재질색, 잔디는 낮고 드문 잎. 칸마다 동일한 큰 S자·싹·테두리 금지. 마른 땅/젖은 흙/물/목재는 형태와 명도로 구분.
- 벽·사물: 윗면/앞면/두께, 파손의 원인, 기울어진 못·마모된 모서리·접지 그림자. 소품마다 실제 용도와 닮은 실루엣. 임의로 붙인 문양보다 구조.
- 인물: 성인 체형, 작은 머리, 어깨와 골반·무릎이 읽히는 옷주름, 피부와 천의 구분. 같은 몸에 색만 바꾼 직업/적 금지. 지도상 크기는 현 규격을 유지.
- 아이콘: 물품의 구조를 크게, 천·금속·유리의 다른 반사면. 음식·약·재료는 실제 조리/보관 상태를 표현. 능력은 행동 주체·도구·방향이 읽히는 짧은 새김 그림.
- UI: 녹색 카드·둥근 웹 버튼을 먹색 철·해진 종이·작은 황동 고정구로 변경. 본문 대비를 확보하고 키 힌트·수치·색약 설정을 보존. 장식은 클릭 영역을 막지 않는다.
- 정보색: 붉은색=피/위험, 호박=경고/불, 차가운 파랑=냉기/기력, 청록=유물. 일반 바닥에 정보색을 크게 쓰지 않는다.
- 기존 그림에 일괄 색 필터를 씌우는 작업으로 끝내지 않는다. 각 자산의 구조·실루엣·마모 위치를 새로 그려 적용한다.

## 전수 적용과 검증

v0.302의 1,266 프레임 키·26 UI 등록을 기준으로 각 담당자가 새 원본과 재현 가능한 생성 도구·매핑을 제공한다. 미사용 호환 프레임도 누락 여부를 기록한다. 최종 수량·변경 해시·실제 게임 및 독립 카탈로그 검토·결정론 결과는 작업 완료 후 추가한다.

등록 이미지 외의 신체 UI도 `BodyDiagram.vue`의 새 해부 스케치로 통일한다. 작은 상태 인형과 신체 창은 같은 성인 비례·여섯 부위 경로를 공유하며, 부위별 실제 상태·상처 단계 무늬·설명은 유지한다. 정상 부위는 종이/천 명도이며 전체 초록 채움을 사용하지 않는다.

하단 HUD는 체력·기력을 나란히 표시하고 경험치 프레임을 얇게 한다. 기록창은 실제 HUD 높이를 따라 위에 놓이며, 카메라의 지도 남쪽 경계도 HUD 표시 영역을 비워 인물 하체를 가리지 않는다. 이는 클라이언트 배치만 바꾸며 시야·좌표·시간·판정은 그대로다. 작은 화면 타이틀은 후드가 보이도록 별도 크롭을 사용한다.

## 최종 적용·검증

전수 적용 완료: 지형124·소품152·물품/능력272·캐릭터718 = 1,266 프레임, UI26개. 모든 이전 프레임 키·논리 크기와28캐릭터/8애니메이션 정의를 보존했다. 206물품·28능력·33생물·85지형의 기본 표시와 호환 프레임 모두 새 원본에 연결하며 79atlas/26UI의105PNG를 사용한다. 별도 타이틀·초상2장과 신체 SVG도 교체했다.

지형은 실제 접촉판과 게임 검토에서 큰 이음·벽돌 대시가 먼저 읽히는 문제를 발견해 R2/R3로 수정했다. 최종 원본63이미지와 게임/도감48이미지를 독립 전수 검토했다. [독립 검토](art-direction-v303-independent-review.md) · [픽셀/범위 감사](art-direction-v303-source-final-audit.json).

최종 불변 빌드에서 전체334파일6,110개가 한 번의 실행으로 통과했다. 실제 게임36PNG/도감12PNG, 독립 Node 전체 상태44쌍, 저장204복원13회, 실제900TU 입력을 검증했다. 5골든의 전체 초기/최종/오류/해시는 v302와 같고 두 해상도의 공통6세계도 v302와 같다. [검증 원문](release-v303-proof.json).

검토 장면에는 미리 선언한 유한 재료/성숙 작물/접촉한 주민/멈춘 NPC가 있으며 정상 획득·농사·AI·전투 결과를 주장하지 않는다. 해부도 장면은 건강 상태6부위이며 부상4무늬의 실제 상황 검증을 주장하지 않는다. World30판을 이번 미술 작업에서 다시 실행하지 않았고 Core/콘텐츠/모드 원문은 v302와 같다. 중간 구도·레이어 수정 전 화면과 중단한 검사 기록은 최종 통과 수량에 포함하지 않는다.
