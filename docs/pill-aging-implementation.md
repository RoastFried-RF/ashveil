# 발굴 정제의 더미별 노화

v0.287 작업 중. design/06 §4.3의 새 발굴 정제에 더미별50~100% 정수 효력과10% 변질을 연결한다. 새 Item을 추가하지 않으며 기본 붕대/물/음식과 고정 약초는 바꾸지 않는다. Knowledge.Human의 새 패치에 수치를 분리했다. 제작/생성 때만 items.pill-aging 하위 스트림을 두 번 소비하며 원래 loot/world.knowledge 스트림은 보존한다.

같은 더미는 같은 효력/변질을 공유한다. 나누기·이동·맛보기의 원래 UID/분량은 기존 실물 흐름을 따른다. 효력/변질이 다르면 합치지 않는다. 효력은 실제 복용/¼맛보기·남은¾에 곱하고, 변질된 더미는 원래 약 대신 약한 독(기존 Pill.Toxin의¼량)을 적용한다. 기존 내성/복용량/기력/수면 규칙을 재사용한다.

지각12 이상만 ‘가장자리가 누렇다’를 관찰한다. 실제 효력값과 변질 판정은 공개 tooltip에 넣지 않는다. 문헌/감별 지식은 외형의 원래 정체이며 더미의 보존 상태를 보증하지 않는다. 변질 정제의 독 반응이나 맛보기로 같은 외형 전체를 독으로 확정/배제하지 않는다. 현재 알려진 약의 tooltip은100% 원래 약 기준임을 명시한다.

각인195는194에서 버전만 이행한다. 필드 없는 과거 정제는100%·미변질로 유지하며 다시 굴리지 않고 기존 실제 효력을 소급 변경하지 않는다. 약물 종류/지식/원래 수량·UID를 지급하지 않는다.

현재 구현 코드 작성 단계다. 타입/관련 검사·전체 골든/실제 UI/복원/전체 회귀와 월드 검증은 아직 통과로 기록하지 않는다.

첫 기존2파일56개는33통과/23실패였다. 새 loot.pill-aging 이름이 기존 RNG 하위 스트림 허용 규약에 없던 실제 제품 오류다. RNG 검사를 넓히지 않고 기존 허용 items.pill-aging 도메인으로 수정했다. 원래 실패 결과/로그를 보존했다.

두 번째 기존2파일56개는48통과/8실패였다. 새 더미의 실제73%/65% 효력으로 예전100% 진통/비타민/수면·NPC 기대가 달라진 것을 확인했다. 기존 종류 감별/분량·약리 검사는 명시적인100%·미변질 표본으로 고정하고 원래50/10/30/2시간 단정을 보존했다. 새 전용 검사는 실제 생성/50%/변질/구형100%를 별도로 대조한다.

전용16개를 포함한3파일72개와 실제 상인 감정까지4파일94개를 통과했다. 첫 타입 검사는 새 테스트의 splitInBag 실제 목적 좌표 인수 두 개 누락을 잡아(기존 함수 오류가 아님) 실제 빈 칸2,0으로 고쳤고 두 번째 타입을 통과했다. 이후 새 Native와 대형/기계 아트 통합·변질 효과의 외부 약물 우회 보호 검사를 추가했으므로 최종 타입/관련/브라우저 검사는 다시 진행한다.

마지막 관련 명령에 존재하지 않는 defs-cli.test.ts 경로가 포함되어 실제 실행 파일 수는4개다. 실제CLI 파일명 definition-validation-cli.test.ts를 확인해 새패치1개에 따른 집계296→297/301→302만 갱신했고 기존 정의884/아이템206·원시 차이/오류 검사 단정은 보존했다. 별도4개 CLI 실행으로 확인한다.

변질 독에 수면 약물을 달아 정상 약물처럼 투여되는 우회도 로더가 거절하도록 보완했다. 이후 실제4파일95개와 별도CLI4개를 통과했다. Native는 실제8개체(환자/사제/포자2/우두머리/융합체/드론2)와 원래 정제3더미를 명시한 유한초기로 작성했으며 실행 전이다. 융합체는 방향형에서도 원래 큰 그림자/24px 체력 막대를 유지하고 피해 숫자는 실제 머리높이를 따른다.
