# v0.375 · 관로 지네의 실제 신체·독샘·천장 행동

2026-10-25 KST. 저장216의 개발 묶음이다. 새 굴뚝탑 정비실과 흐린 늪 점검실에 각각 원래 지네1개체와 정비 일지1부를 최초 생성한다. 이미 방문한 지도/각인에는 개체·독샘·재료·책을 보충하지 않는다. 구제기와 착용/손상 외형·장기 확장/출시 검증은 남는다.

## 몸과 유한 독샘

머리·신경 중추/겹눈/더듬이/독턱/두 독샘9부위, 여덟 체절의 판·신경절·숨구멍·등쪽 혈관·좌우 다리48부위로 총57부위다. 혈림프2,000ml와 실제 신체/상처/의식 규칙을 사용한다. 절지동물의 숨구멍·등쪽 혈관·분절 신경절을 실제 부위와 능력에 연결한다. 체절 신경절/판이 파괴되면 그 체절의 두 다리 기능이 멈추고, 뒤쪽 절반의 기능을 잃어도 앞부분은 움직인다. 실제 절단 missing은 뒤쪽 자손에도 전파한다. 파괴·일시 마비·절단을 구분해 표시한다.

원래 독샘 두 개에는 각3회분과 고유 Item UID가 생성 때만 주어진다. 실제 피부를 연 상처에 물기가 닿을 때 한 회분을 쓰며 갑옷에 막혀 생긴 타박상에는 주입하지 않는다. 부위의30~120턴 마비는 당시 원래 독샘 UID/Def·실제 상처 UID·부위/시각을 저장한다. 팔이면 해당 손의 실제 물건을 바닥에 놓고 다리면 이동 시간이 두 배다. 마비가 풀려도 상처를 지우지 않는다. 기계·의수족의 금속 손상에는 생물 신경독을 넣지 않는다.

독샘의 실제 파괴로 잃은 양, 물기에 쓴 양, 해부로 회수한 양과 아직 몸 안에 남은 양의 합을 각인 복원 때 검사한다. 일시 마비만으로 온전한 독샘/외골격을 파괴 처리하지 않는다. 해부는 그때 남은 원래 독샘 객체를 같은 UID로 한 번만 옮긴다. 새3회분으로 재충전하지 않는다. 정책 구성이 달라진 원래 개체에 새 독샘/해부 재고를 만들어 주지 않는다.

## 실제 지상·천장과 먹이

지상과 천장을 별도 상태로 저장한다. 천장 개체는 지상 통로를 막지 않고 실제 지붕/열린 경로를 따라 이동한다. 닫힌 문·벽·열린 하늘을 통과하지 않는다. 아래로 접근한 실제 감지 대상을 향해 내려설 빈자리를 골라 낙하 공격하고, 평면의 뒤/옆 방향 가산과 구분한다. F2 현장·야영의 천장 살피기는 실제 한 턴을 쓰며, 곁에서 미리 본 개체의 낙하 가산을 잠시 막는다. 부상/마비로 붙들 힘을 잃으면 곁의 빈 지상으로 내려오고 몸과 원래 수량을 유지한다.

실제 시각/소음으로만 먹이를 추적하며 숨은 대상의 현재 위치를 읽어 추격하지 않는다. 배가 고프면 굴쥐를 사냥하고, 실제 바닥 고기 UID나 사체의 남은 살을 한 번씩 소비한다. 음식·물의 영양/오염은 기존 공통 동물 섭취 경로를 사용한다. 실제 보이는 물가로 이동해 마시며 지상 경로는 물을 피한다. 켜져 있는 실제 모닥불/화재의 연기는 회피하지만 꺼진 광원이나 배낭 속 불을 만들어 쓰지 않는다.

독립 벽면 좌표/보행, 긴 몸의 다중 칸 점유·자체 충돌과 완전한3D 골격은 구현한 것으로 세지 않는다. 현재는 실제 한 타일의 개체와 그 실제 보간 경로를 따르는2D 분절 표현이다.

## 채집품·화살·장비 UI

해부 재고는 실제 남은 외골격 판/다리와 유한 고기다. 분리된 원래 포션만 합법적인 더미 크기로 묶어 바닥에 놓고, 회수 후 다시 생성하지 않는다. 외골격8장과 천2조각으로 흉갑을 엮고, 다리 마디1개와 깃털2몫으로 범용 화살 한 발을 만든다. 날고기 한 몫은 모닥불에서 같은 질량의 구운 고기로 만든다. 지네 고기를 먹는 기분−3을 유지한다.

F2에서 원래 독샘 한 회분을 실제 화살 한 발에 바른다. 원래 화살 더미/UID와 쪼갠 화살을 구분하고 일반 화살과 합치지 않는다. 다음 사격 선택·석궁 장전도 실제 독의 원래 출처를 옮기며, 발사 때 한 발과 독을 소모한다. 명중해 실제 열린 상처가 생겼을 때만 국소 마비를 준다. 빗나감/금속/갑옷의 닫힌 타박상에 독 효과를 만들거나 회수 화살에 쓴 독을 다시 채우지 않는다. 상태 칩은 마비 부위·남은 시간과 붙잡힘을 표시한다.

흉갑은 실제 장비/방어 데이터와 아이콘이다. 새로운 사람 착용 몸 원화까지 제작했다고 세지 않는다. 일반 정비 일지 그림은 기존 수첩을 명시적으로 공유한다.

## 원화·표현·저장

기존 자체 v372 PNG1장의6영역을 지네에 등록하고, 신규 v376 PNG1장의6아이콘을 등록했다. 신규 image_gen 호출은 아이콘1회이며 기존 지네 원문은 재사용이다. 머리 닫힘/열림·단일 몸판·꼬리·다리 상하6영역이 화면41인스턴스에 공유된다. 새 전체 보행41프레임이나4방향 원화가 아니다. 등 시점1방향의 회전/명시적 좌우 반전과 추정 소켓·갈고리 접촉 한계를 보존한다.

실제 보간 위치를 정확히 따르고 거리 기반 접지/회복·급회전·정지·재출발, 실제 부위 소실/파괴/마비·피격/공격·천장5px/낙하·사망을 공통 CrawlerView에 연결했다. FOV/벽 가림과 픽셀 선택이 같은 영역을 사용한다. 맵/모델/타이틀 전환 때 표시 객체를 없애고, 원문 텍스처는 기존 atlas 수명 관리에 맡긴다. [공개 조립 미리보기](https://roastfried-rf.github.io/ashveil/artbook/crawler/)는 같은 표시 클래스를 사용하며 실제 세계/재고를 변경하는 게임 성공 검증과 구분한다.

저장215→216은 헤더만 이행하며 과거 몸에 지네/독샘/마비 이력을 보충하지 않는다. 마비는 전역 종료 시각을 따르고 재방문으로 연장하지 않는다. 천장 복귀의 국소 처리 시계는 다른 국소 과정처럼 떠난 동안 정지한다. v370 뒤 확인한 마지막 방진 여과 턴의 불필요한 기침도 이 묶음에 포함한다.

## 검토 범위

변경 관련 짧은 Core 검사·타입/린트·Def/Schema/PNG와 빌드를 확인하고 동결한 뒤 실제 Title 불러오기/키·UI·사격·저장 복원을 독립 Node 전체 JSON/hash와 비교한다. 최초 비동결 Native의 해부/회수/제작 경로는 일치했지만 천장 장면의 연속 피격으로 플레이어가 사망해 동작 관찰을 완료하지 못했다. 원래 실패 기록을 보존하고, 최종 유한 장면은 선언된 초기 combat seed와 원거리 시작 위치로 단일 사건을 분리한다. 불러온 뒤 세계/수치/RNG를 바꾸지 않는다. 정확한 최종 동결·실행·남은 한계는 release-v375-proof.json에 기록한다. 전체 회귀/World/중단한1,000판과 자연 캠페인/사람 품질 평가는 재개하거나 승인하지 않았다.
