# 의사의 실제 재보급 — v0.43

의사가 가진 재료가 줄면 같은 정착지의 상점까지 실제 이동하고, 자신의 소지금으로 현재 물품을 산 뒤 진료 자리로 돌아온다. 진료 중이거나 돈이 없으면 구매하러 떠나지 않는다. 이동 중 환자가 부탁한 진료는 기존 조건으로 시작할 수 있다. NPC가 보이는 적을 피하고 먹고 마시는 판단이 재보급보다 먼저다.

`Clinic.restock`은 선택적 정책이다. 기본값은 아래와 같으며 최소/목표/가격 한도와 재시도1시간(1200턴)은 임시 조정값이다. 개수로 묶인 완제품을 사므로 사용 횟수 목표를 조금 넘길 수 있다. 유물 앰플은 구매 목록에 넣지 않았다.

| 물품 | 최소 미만이면 구매 | 목표 | 개당 지불 한도 |
|---|---:|---:|---:|
| 붕대 | 2회분 | 5회분 | 6전 |
| 실 | 2개 | 6개 | 4전 |
| 바늘 | 1개 | 1개 | 6전 |
| 부목 | 1개 | 2개 | 9전 |
| 지혈대 | 1개 | 2개 | 22전 |
| 소독용 술 | 2회분 | 5회분 | 18전/병 |
| 흰버들 차 | 1개 | 3개 | 12전 |
| 잠꽃 팅크 | 1개 | 2개 | 24전 |
| 쓴이끼 습포 | 1개 | 3개 | 10전 |

붕대 수량은 의료가방의 실제 남은 사용 횟수도 센다. 고장난 도구는 사용 가능한 재고로 세지 않는다. N에서 붕대 재료 횟수와 부족한 품목을 확인한다. 재고 조회는 상태와 난수를 바꾸지 않는다.

의사는 상점 위치를 향해 가고 상품은 거래할 수 있는 위치에서 확인한다. 원격의 시장 재고가 비어도 이동 계획은 같으며 도착해서 품절을 알게 된다. 지불 한도·현재 현금·상품 수량 안에서 목표까지 살 수 있는 양만 사며, 실제 `exchange`와 같은 배낭/UID/현금 규칙을 쓴다. 부분 구매도 가능하다. 배낭 부족/가격 초과/품절/돈 부족/상인과 거래할 수 없는 상태는 물품이나 돈을 만들지 않고 재시도 시각만 남긴다. 돌아온 뒤 즉시 같은 상점을 계속 왕복하지 않는다. 재시도는 전역 시각을 따른다.

시장 물품/현금과 의사 물품/현금의 실제 이전이다. 기존 공공 저장고→시장 입고 규칙 위에서 거래하며 의사가 공공 물자나 유물 약을 새로 생성하지 않는다. 상점에서 팔지 않는 물건과 품절한 약은 구하지 못한다. 공공 물자 생산/캐러밴/제조 전반과 직접 준비물 전달은 별도로 남는다.

NPC의 거래는 플레이어 전역 로그/지식을 바꾸지 않으며, 플레이어가 얻은 흥정 할인/거절은 의사의 개인 거래에 전파하지 않는다. 플레이어 거래의 기존 가격·로그는 그대로다. 실제 이동으로 관찰되는 NPC의 위치와 소모/구매 뒤 달라진 상품은 게임의 기존 관찰 규칙을 따른다.

기존 이동/거래와 선택적인 재시도 시각을 사용하므로 저장 형식10을 유지한다. 이동 중 각인도 경로/현금/상품/UID를 같은 결과로 잇는다. 재보급 정책을 정의하지 않은 구형 Clinic 모드는 기존 진료 기능을 유지한다. 기존5입력의 초기/최종 전체 상태·오류·해시가 동일하다(`golden-v043-diff.json`). 해시 핀이나 원본 명령을 바꾸지 않았다.

검증은 실제 스케줄러의 왕복/5개 구매, 부족한 돈으로2개만 구매, 품절/가격/배낭/지불 거부의 무생성, 재시도, 원격 재고 조회 배제, NPC 거래 비공개/개인 흥정, 이동 중 복원과 모드 계약을 포함한다. 재보급11개·Def2개를 더해42파일675개가22.75초에 통과했다. 최종 브라우저는 서로 다른8부위의 실제 붕대 처치로 재료를9→1회분까지 소모한 뒤, 의사의 상점 왕복·붕대4개/20전 구매·복귀·각인 복원을 확인했다(74~76, 앞선 진료64~73 및 설정 포함, 콘솔 오류0). 30시드×최대3일은295.329328183초에 종료 코드0으로 완료했고, 평균0.45796412037037043일·생존1/저체온18/치명상5/실혈6이다. v0.42와30시드의 원인·시간·레벨·지도가 모두 같다. 봇은 진료를 이용하지 않으므로 재보급 행동은 별도 단위/브라우저 검증으로 판단한다.

후속 v0.45에서는 환자 사이 손 씻기를 위한 실제 물 재고/소비도 연결했다. 진료용으로3병(3L)을 추가하며 기존 정착민 물2병까지 총5L다. 재보급 물병 최소1/목표3회분·병 가격 상한12전이며 임시 조정값이다. 물도 실제 시장 상품으로 구입한다. [손 위생 구현](hand-hygiene-implementation.md).
