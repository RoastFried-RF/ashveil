# 실제 흡입 재·영구 폐 손상과 유한 방진 면포

v0.99. 설계 02 §11의 재폐와 03의 재 먼지 흡입 경로를 실제 날씨·몸·물건·제작/교체에 연결한다. 엔진 독립 코어와 기존 화면을 유지한다.

현재 지상 지도에서 지붕 밖에 있고 공기를 들이마실 때만 실제 재바람/재비 폭풍이 흡입량을 더한다. 지하·지붕·맑은 날씨·실제로 잠겨 숨을 참는 상태에서는 바깥 먼지를 더하지 않는다. 기계나 수중 호흡 종·시신에는 생물학적 재폐를 만들지 않는다. 흡입량은 음식/물로 섭취한 재, 신장 손상과 별개의 몸 기록이다.

누적 흡입량이 문턱을 넘으면 원래 폐의 호흡 상한을95/90/80%로 제한한다. 더 나쁜 실제 폐렴·장기 손실을 다시 곱해 과도하게 줄이지 않는다. 몸 계산 캐시도 현재 흡입량을 포함한다. 씻기·일반 의약품·섭취한 재의 일일 감소·새 여과포는 이미 생긴 폐 손상을 지우지 않는다. 기침은 실제 소리로 주변의 듣기·기상·조사 행동을 유발한다. 재바람의 환경 소음에 기침이 가려질 수 있으며 벽이나 먼 거리를 건너 모든 적에게 위치를 알려 주지는 않는다.

방진 면포는 원래 천2개와 숯1개로 실제 제작하는 목 슬롯 의복이다. 가방에 든 면포는 보호하지 않는다. 실제 착용한 한 벌의 원래 여과 시간이 먼지에 노출된 턴에만 줄고, 마지막 한 턴도 정확히 보호한다. 반쯤 걸쳤거나 실제로 젖은 면포는 보호가 줄고, 찢어졌거나 여과 시간이 다한 면포는 보호하지 않는다. 여러 장비를 겹쳐 여과율을 곱하지 않는다. 소모된 원래 천 물건은 몸에 그대로 남는다.

교체는 손을 쓸 수 있는 소유자가 배낭의 사용하지 않은 원래 천 여과포 UID를 예약하고 실제 시간 동안 진행한다. 같은 면포·남은 시간·설정·원래 여과 재료를 작업 중 확인한다. 완료 때만 그 재료를 한 번 소비하고 같은 면포를 채운다. 작업 중인 면포는 보호하지 않고, 중단하면 소모하지 않은 두 원래 물건이 남는다. 물 정수에 일부 사용한 여과포를 새 방진 여과포로 바꾸지는 못한다. 교체할 때 버리는 잔여 시간과 작업 중 노출을 버튼 설명에 표시한다.

신체 창의 흡입/여과 표시와 소지품 도움말은 실제 몸·착용·남은 턴을 읽는다. 진찰 여건이 충분한 의사는 같은 초기 재폐의 영구 호흡 손상도 소견에 기록한다. 각인v63은 원래 누적 흡입량과 진행 중 두 현물의 예약을 보존하며 구형 몸에 과거 흡입을 만들어 넣지 않는다.

문턱 흡입량120/300/600, 날씨별 유입량·여과율/포화 기준·여과 시간/교체 시간·기침 주기/소리는 변경 가능한 Def 기본값이다. 정본의 호흡 상한95/90/80%를 제외한 미확정 수치를 정본으로 확정하지 않는다. 방진 면포를 모든 가스나 병원체를 막는 장비로 설명하지 않는다.

22개 전용 검사는 실제 노출/보호 환경·기계/시신/잠수·가방과 실제 착용·반쯤/젖음/손상·마지막 여과 턴/무한값 거부·원래 폐 상한/폐렴·씻기/약·실제 제작·원본 예약/한 번 소비/중단/교체 중 노출·각인v63·실제 조용한 곳의 기침/경비 기상을 확인한다. 관련212개와 타입·Def93패치·Schema89파일, 기존 다섯 재현의 전체 초기/최종 상태·오류가 버전62→63 외에는 같음을 확인했다. v0.99에서는 실제 재바람 흡입량과 영구 폐 상한95/90/80%, 실제 기침·듣기·기상, 원래 천/숯으로 만드는 유한 방진 면포·마지막 여과 시간·원본 여과포 예약 교체·각인v63을 연결했다. 전체101파일1,705개91.41초·전용22개/관련212개·타입/린트/Def93패치/Schema89/빌드·화면408~417/10장·다섯 차례 전체 복원·콘솔 오류0이다. 같은 검증용 사본의 월드30시드×최대3일274.904370468초·30개 전체 행을 대조해 30개가 같고 0개의 실제 변경을 검토했다. 월드 평균0.4219895833333334일·원인{'저체온': 19, '치명상': 5, '과다 출혈': 6}이다. 최종 검증은 변경하지 않는 v099 사본에서 실행했다.

거품병의 잠복/응급 처치, 다른 장기 질병과 생존/사회/전체 확장 기능은 계속 구현한다.
